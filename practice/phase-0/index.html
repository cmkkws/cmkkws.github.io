Phase 0 · Environment setup

Phase 0Phase 1
준비할 것

Python 3.12 · PowerShell · 편집기(Orca 등). GPU가 없는 경우에도 CPU 기초 실습을 진행할 수 있다. 코드 실행은 본인의 Python 환경에서 한다.

환경 용어

Python / .venv
인터프리터가 코드를 실행한다. .venv는 프로젝트의 패키지를 분리한다.
Driver / CUDA
nvidia-smi의 CUDA 표시는 드라이버가 지원하는 버전이다. Toolkit 설치 여부를 뜻하지 않는다.
PyTorch CUDA / nvcc
torch.version.cuda는 PyTorch 빌드 버전, nvcc는 별도 Toolkit 컴파일러 버전이다.
RAM / VRAM
시스템 메모리와 GPU 메모리다. VRAM에는 weight·gradient·optimizer state·activation·cache 등이 들어간다.

    환경 확인 코드를 실행한다. Python 경로·CUDA 사용 여부와 GPU 이름을 읽는다. 이 코드는 matmul과 backward를 확인하며 optimizer update는 P01에서 다룬다.

    패키지로 가져오기

    루트에 다음 pyproject.toml을 만든다. P05 이후 테스트의 llm_lab import와 직접 작성할 script에 개발용 설치가 필요하다. P01·P02 테스트는 내부 sys.path 설정으로 설치 전에 실행할 수 있다.

    확인할 결과

    아래 개발용 설치 후, 루트에서 from llm_lab.seed import set_seed를 가져올 수 있다.

  6. 06

    환경 기록

    개발용 설치와 패키지 목록을 기록한다. .venv·__pycache__·.pytest_cache는 .gitignore에 추가한다. freeze 외에도 설치 명령·OS·드라이버를 기록해야 환경을 설명할 수 있다.

    확인할 결과

    requirements-lock.txt가 생성된다. P01–P08의 기본 테스트 16개가 수집되는지 확인하고 실제 실행은 각 강의에서 진행한다.

Troubleshooting

ModuleNotFoundError: torch
출력한 sys.executable과 설치에 사용한 Python 경로를 비교한다. .venv의 Python으로 설치한다.
CUDA Available=False
CPU용 패키지·드라이버·GPU 지원 환경을 확인한다. CPU 실습 성공은 GPU 검증 완료를 뜻하지 않는다.
llm_lab import 실패
프로젝트 루트와 src 경로를 확인하고 pyproject.toml을 작성한 뒤 pip install -e .를 실행한다.
실행 중 OOM
batch·context·dtype·다른 프로그램의 VRAM 사용을 확인한다. 작은 smoke만으로 전체 모델 학습의 적합성을 판단하지 않는다.
