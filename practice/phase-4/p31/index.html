Follow along

  1. 01

    입력·출력 계약

    config·model revision·adapter를 검사하고 요청별 cache를 초기화한다. predict/evaluate/benchmark 명령의 입력과 출력 경로를 정한다.

    확인할 결과 · 예상 형태

    식·shape·dtype·device와 실패 입력을 메모한다. 작은 CPU FP64/FP32 예제를 먼저 정한다.

  2. 02

    핵심 구현

    scripts/predict.py을 만들고 predict/evaluate/benchmark 명령과 입력·revision 검사를 구현한다. 각 중간 연산을 작은 값으로 확인한 뒤 연결한다.

    확인할 결과 · 예상 형태

    함수/모듈별 입력·중간 tensor·출력을 출력해 계약과 비교한다. reference를 사용한 부분은 구분해 기록한다.

  3. 03

    검증 코드

    tests/test_p31.py에 아래 통과 기준별 검사를 작성한다. 같은 weight·입력·seed·dtype·dropout 조건을 맞추고 output과 gradient의 실제 오차를 기록한다.

    확인할 결과 · 예상 형태

    tiny smoke 명령과 inference-only 실행을 검사한다. 요청별 cache 분리, 잘못된 config·adapter 처리를 확인한다.

  4. 04

    실행·실패 기록

    구현과 테스트 파일을 작성한 다음 실행한다. 실패하면 reference 조건과 최초로 값이 달라지는 중간 tensor를 확인한다. 지원하지 않는 조건·원인·수정 내용을 함께 남긴다.

    확인할 결과 · 예상 형태

    작성한 검사가 모두 통과해야 한다. 원본 ZIP에는 이 실습의 구현·테스트가 없으며, 이 명령은 파일을 만든 뒤 실행한다.

Try it yourself

경계 입력과 통제 비교

요청별 cache 분리, 잘못된 config·adapter 처리를 확인한다. 정상 입력 하나와 실패 입력 하나를 추가하고, 조건을 한 번에 하나씩 바꿔 차이를 설명한다.

힌트 보기

shape만 확인하지 말고 실제 값과 gradient를 비교한다. 허용 오차는 연산·dtype에 맞춰 미리 정하고 실제 오차도 남긴다.

Verification

  • tiny smoke 명령과 inference-only 실행을 검사한다.
  • 요청별 cache 분리, 잘못된 config·adapter 처리를 확인한다.
