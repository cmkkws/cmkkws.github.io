Learning goal

Parameter별 moment와 step을 추적하고 bias correction·weight decay·epsilon의 위치를 reference와 비교한다.

입력·출력 계약

m=β₁m+(1−β₁)g, v=β₂v+(1−β₂)g²다. 보정 후 m̂/(√v̂+eps)를 update에 쓰며 weight decay는 gradient moment에 더하지 않는다.

파일 역할

src/llm_lab/optim/adamw.py
Optimizer state 초기화, decoupled decay, moment와 step update를 정의한다.
tests/test_p06_adamw.py
기본 epsilon의 10-step reference 비교와 zero-gradient decay를 검사한다.

현재 bias-correction 분기의 epsilon 위치는 PyTorch의 수식과 다르다. 기본 epsilon의 근접 비교와 수식의 동치를 구분해 검사한다.

PyTorch AdamW 수식 ↗

Follow along

  1. 01

    한 step의 순서

    p.grad is None이면 건너뛰고, 실제 zero tensor gradient이면 decay도 실행한다. state의 step·exp_avg·exp_avg_sq를 초기화한 뒤 decay → moment → parameter update 순서로 읽는다.

    확인할 결과 · 예상 형태

    p=10, lr=0.1, weight_decay=0.05, zero gradient이면 첫 step은 10×0.995=9.95다.

  2. 02

    기본 reference 검사

    같은 model state와 batch를 사용한 두 optimizer의 10-step 결과를 비교한다. 현재 테스트는 eps=1e-8과 제한된 입력의 근접 오차를 검사하며 epsilon 위치의 동치를 증명하지 않는다.

    확인할 결과 · 예상 형태

    통과하면 2 passed. 실제 parameter 최대 오차를 기록한다.

  3. 03

    Epsilon 위치의 차이

    현재 step_size는 √(1−β₂ᵗ)를 분자에 포함하지만 denom의 eps는 보정하지 않는다. 정규화하면 유효 eps가 eps/√(1−β₂ᵗ)가 된다. correct_bias 분기를 아래처럼 교체해 reference 수식을 맞춘다.

    확인할 결과 · 예상 형태

    분모는 √(v/(1−β₂ᵗ))+eps다. correct_bias=False 분기는 이 수정 대상에 포함하지 않는다.

  4. 04

    큰 epsilon으로 차이 드러내기

    tests/test_p06_epsilon.py를 작성한다. FP64·eps=0.1·동일 scalar gradient를 사용하면 작은 epsilon에 가려진 차이가 드러난다.

  5. 05

    수정과 기존 동작 확인

    수정 전에는 새 비교가 실패하는지 확인하고 수정 후에 다시 실행한다. 기존 10-step 및 zero-gradient 테스트도 다시 실행해 decay와 moment가 유지되는지 확인한다.

    확인할 결과 · 예상 형태

    수정 후 기대 결과: 1 passed. 실제 reference 오차를 함께 기록한다.

Source walkthrough

None gradient · L55–59

None은 parameter update를 건너뛴다. Sparse gradient는 지원하지 않아 오류를 낸다.

Try it yourself

State 저장·재개

몇 step 진행한 뒤 parameter와 optimizer state를 따로 저장하고, 같은 다음 gradient의 update를 중단 없는 실행과 비교한다. grad=None과 zero gradient도 별도 검사한다.

힌트 보기

Optimizer state_dict는 parameter 값 자체를 복원하지 않는다. 새 parameter에 값을 복사한 뒤 state를 로딩하고 step·m·v도 비교한다.
