P07 · Dataset·label shift

Phase 0Phase 1
목표·파일 역할따라하기코드 해설연습문제학습 체크
Phase 목록으로 돌아가기

Learning goal

한 token 목록에서 chunk·shift·PAD mask를 만들고 DataLoader batch의 input/label 위치를 확인한다.

입력·출력 계약

Chunk는 max_seq_len+1개다. input=chunk[:-1], labels=chunk[1:]로 한 번 shift하며, 짧은 입력의 PAD target은 -100으로 바꾼다.

파일 역할

src/llm_lab/data/dataset.py
고정 길이 chunk와 short-input padding, tensor 반환 및 stack collator를 정의한다.
tests/test_p07_dataset.py
첫 chunk의 정확한 shift 값과 DataLoader의 [B,T] shape를 검사한다.

현재 Dataset은 한 token 목록을 처리하고 collator는 같은 길이의 tensor를 stack한다. 문서별 split·response mask·가변 길이 padding은 확장 과제다. Trainer에서 label을 다시 shift하지 않는다.

Follow along

  1. 01

    Chunk의 추가 token

    max_seq_len=4라면 chunk_size=5다. [100,101,102,103,104]에서 마지막 104는 마지막 input의 다음 target을 제공한다. 입력과 label을 각각 다시 shift하지 않는다.

    확인할 결과 · 예상 형태

    input=[100,101,102,103], labels=[101,102,103,104].

  2. 02

    짧은 입력 확인

    scripts/trace_dataset.py를 작성한다. P08의 기본 tokenizer와 연결할 때 PAD ID는 1이므로 명시한다. 빈 입력도 출력해 현재 구현의 all-ignore sample을 확인한다.

    확인할 결과 · 예상 형태

    짧은 입력: input=[100,101,102,1], labels=[101,102,-100,-100]. 빈 입력: input=[1,1,1,1], labels=[-100,-100,-100,-100].

  3. 03

    예제 실행

    예제를 실행하고 short-input 분기의 i < n_tokens−1 조건을 읽는다. 현재 Dataset 기본 pad_token_id=0과 tokenizer의 PAD=1이 다르므로 연결할 때 실제 ID를 전달한다.

    확인할 결과 · 예상 형태

    PAD가 input에는 남아도 loss target에서는 -100으로 표시된다. Attention의 key padding mask는 별도 구현이다.

  4. 04

    Shift와 batch 검사

    원본 검사는 첫 chunk와 fixed-length stack batch를 확인한다. collate_text_batch의 padding 인자는 현재 실제 padding에 사용되지 않는다. 길이가 다른 tensor를 stack할 수 있는지 추가 확인한다.

    확인할 결과 · 예상 형태

    통과하면 2 passed. batch_size=2, max_seq_len=8의 input/labels는 각각 [2,8]이다.
