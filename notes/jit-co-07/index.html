CO-07 — Matrix Calculus (Identities & Layouts)

Matrix Calculus의 주요 미분 항등식과 numerator·denominator layout을 정리한다.

수정 2026.09.18약 61분상태 작성 완료
학습 내용
  • Matrix Calculus
  • Scalar-by-Vector Derivative
  • Scalar-by-Matrix Derivative
  • Gradient Shape

1. Matrix Calculus

Deep Learning에서는 Parameter가 Scalar 하나가 아니라 대부분 Vector 또는 Matrix 형태다.

예를 들어

\[\mathbf x\in\mathbb R^D\]
\[\mathbf W\in\mathbb R^{M\times N}\]

와 같은 Parameter가 사용된다.

Loss Function은 일반적으로 Scalar다.

\[\boxed{ L\in\mathbb R }\]

따라서 학습에서는 다음과 같은 미분이 반복적으로 등장한다.

\[\boxed{ \frac{\partial L}{\partial\mathbf x} }\]
\[\boxed{ \frac{\partial L}{\partial\mathbf W} }\]

Matrix Calculus는 이러한 Vector·Matrix Parameter에 대한 미분을 체계적으로 다룬다.

2. Scalar-by-Vector Derivative

Scalar Function

\[f(\mathbf x)\in\mathbb R\]

과 Column Vector

\[\mathbf x = \begin{bmatrix} x_1\\ x_2\\ \vdots\\ x_D \end{bmatrix} \in\mathbb R^D\]

를 생각한다.

각 Component에 대한 Partial Derivative를 모으면

\[\boxed{ \nabla_{\mathbf x}f = \begin{bmatrix} \dfrac{\partial f}{\partial x_1}\\ \dfrac{\partial f}{\partial x_2}\\ \vdots\\ \dfrac{\partial f}{\partial x_D} \end{bmatrix} }\]

를 얻는다.

이 Lecture에서는 이를 Column Gradient 형태로 사용한다.

3. Scalar-by-Matrix Derivative

이번에는

\[f(\mathbf X)\in\mathbb R\]

이고

\[\mathbf X\in\mathbb R^{M\times N}\]

이라고 하자.

Matrix의 각 Element에 대해

\[\frac{\partial f}{\partial X_{ij}}\]

를 계산하여 다시 Matrix 형태로 모은다.

이 Lecture에서 사용하는 Gradient Convention에서는

\[\boxed{ \left[ \frac{\partial f} {\partial\mathbf X} \right]_{ij} = \frac{\partial f} {\partial X_{ij}} }\]

따라서

\[\boxed{ \frac{\partial f}{\partial\mathbf X} \in \mathbb R^{M\times N} }\]

4. Gradient Shape

Loss가

\[L\in\mathbb R\]

이고 Parameter가

\[\mathbf W \in \mathbb R^{M\times N}\]

이라면 이 Lecture에서 사용하는 Gradient는

\[\boxed{ \frac{\partial L}{\partial\mathbf W} \in \mathbb R^{M\times N} }\]

즉 Parameter와 Gradient의 Shape을 동일하게 유지한다.

5. Layout Convention

Matrix Calculus에서는 문헌에 따라 Derivative를 배열하는 Convention이 달라질 수 있다.

원자료에서는 대표적으로

  • Numerator Layout
  • Denominator Layout

을 구분한다.

특히 Vector 또는 Matrix를 미분할 때 Transpose 위치가 달라질 수 있으므로 Formula만 외우는 것보다 Shape을 함께 확인하는 것이 중요하다.

6. Scalar-by-Vector Layout

Scalar

\[f\in\mathbb R\]

를 Column Vector

\[\mathbf x\in\mathbb R^D\]

로 미분할 때 원자료의 Convention은 다음과 같다.

Numerator Layout

\[\boxed{ \frac{\partial f}{\partial\mathbf x} \in \mathbb R^{1\times D} }\]

Denominator Layout

\[\boxed{ \frac{\partial f}{\partial\mathbf x} \in \mathbb R^{D\times1} }\]

후자는 CO-02에서 사용한 Gradient Vector

\[\nabla_{\mathbf x}f\]

와 같은 Column 형태다.

7. Vector-by-Vector Layout

\[\mathbf y\in\mathbb R^M\]
\[\mathbf x\in\mathbb R^N\]

이라고 하자.

원자료에서는 Numerator Layout에서 Jacobian을

\[\boxed{ \frac{\partial\mathbf y} {\partial\mathbf x} \in \mathbb R^{M\times N} }\]

형태로 두고, 반대 Layout에서는 Transposed Shape을 사용한다.

따라서 다른 문헌의 Matrix Calculus Formula를 사용할 때 어떤 Convention을 사용하는지 먼저 확인해야 한다.

8. Deep Learning Gradient Convention

이 Lecture에서는 Deep Learning Backpropagation을 다루기 위해 Parameter와 Gradient의 Shape을 동일하게 표현한다.

예를 들어

\[\mathbf W \in \mathbb R^{M\times N}\]

이면

\[\boxed{ \frac{\partial L} {\partial\mathbf W} \in \mathbb R^{M\times N} }\]

Gradient Descent Update도

\[\boxed{ \mathbf W^{(t+1)} = \mathbf W^{(t)} - \eta \frac{\partial L} {\partial\mathbf W} }\]

로 Shape이 그대로 일치한다.

9. Dimension Check

Matrix Calculus에서는 결과 Formula가 올바른지 확인할 때 Shape을 사용할 수 있다.

예를 들어

\[\mathbf W \in \mathbb R^{D_{\mathrm{in}}\times D_{\mathrm{out}}}\]

이면

\[\boxed{ \frac{\partial L} {\partial\mathbf W} \in \mathbb R^{D_{\mathrm{in}}\times D_{\mathrm{out}}} }\]

이어야 한다.

이 Lecture의 Backpropagation Formula에서도 모든 결과를 Dimension과 함께 확인한다.

10. Linear Form

첫 번째 핵심 항등식은 Linear Form이다.

\[\boxed{ f(\mathbf x) = \mathbf a^T\mathbf x }\]

여기서

\[\mathbf a,\mathbf x \in \mathbb R^D\]

Column Gradient Convention에서는

\[\boxed{ \frac{\partial( \mathbf a^T\mathbf x )} {\partial\mathbf x} = \mathbf a }\]

11. Linear Form 성분 전개

Inner Product를 Component로 전개한다.

\[\mathbf a^T\mathbf x = \sum_{i=1}^{D} a_ix_i\]

즉

\[f(\mathbf x) = a_1x_1 + a_2x_2 + \cdots + a_Dx_D\]

12. Linear Form 편미분

\(x_k\)에 대해 편미분하면

\[\frac{\partial f} {\partial x_k} = \frac{\partial} {\partial x_k} \left( \sum_{i=1}^{D}a_ix_i \right)\]

\(x_k\)가 포함된 항만 남으므로

\[\boxed{ \frac{\partial f} {\partial x_k} = a_k }\]

13. Linear Form Gradient

모든 Partial Derivative를 Column Vector로 모으면

\[\frac{\partial f} {\partial\mathbf x} = \begin{bmatrix} a_1\\ a_2\\ \vdots\\ a_D \end{bmatrix}\]

따라서

\[\boxed{ \nabla_{\mathbf x} ( \mathbf a^T\mathbf x ) = \mathbf a }\]

14. Quadratic Form

두 번째 핵심 항등식은 Quadratic Form이다.

\[\boxed{ f(\mathbf x) = \mathbf x^T \mathbf A \mathbf x }\]

여기서

\[\mathbf x\in\mathbb R^D\]
\[\mathbf A\in\mathbb R^{D\times D}\]

일반적인 Gradient는

\[\boxed{ \nabla_{\mathbf x} ( \mathbf x^T\mathbf A\mathbf x ) = ( \mathbf A+\mathbf A^T ) \mathbf x }\]

15. Quadratic Form 성분 전개

Quadratic Form은 Double Summation으로

\[\boxed{ f(\mathbf x) = \sum_{i=1}^{D} \sum_{j=1}^{D} A_{ij}x_ix_j }\]

\(x_k\)에 대해 미분할 때

  • \(i=k\)인 항
  • \(j=k\)인 항

이 영향을 준다.

16. Quadratic Form의 $k$번째 편미분

원자료의 전개에 따라

\[\frac{\partial f} {\partial x_k} = \sum_{j=1}^{D} A_{kj}x_j + \sum_{i=1}^{D} A_{ik}x_i\]

첫 번째 Sum은

\[(\mathbf A\mathbf x)_k\]

두 번째 Sum은

\[(\mathbf A^T\mathbf x)_k\]

따라서

\[\boxed{ \frac{\partial f} {\partial x_k} = [ ( \mathbf A+\mathbf A^T ) \mathbf x ]_k }\]

17. Quadratic Form Gradient

모든 Component를 결합하면

\[\boxed{ \nabla_{\mathbf x} ( \mathbf x^T\mathbf A\mathbf x ) = ( \mathbf A+\mathbf A^T ) \mathbf x }\]

18. Symmetric Matrix Case

만약

\[\mathbf A=\mathbf A^T\]

이면

\[\mathbf A+\mathbf A^T = 2\mathbf A\]

따라서

\[\boxed{ \nabla_{\mathbf x} ( \mathbf x^T\mathbf A\mathbf x ) = 2\mathbf A\mathbf x }\]

19. Least-Squares Objective

다음 함수는 Machine Learning과 Linear Algebra에서 매우 자주 등장한다.

\[\boxed{ f(\mathbf x) = \| \mathbf A\mathbf x - \mathbf b \|_2^2 }\]

여기서

\[\mathbf A \in \mathbb R^{M\times N}\]
\[\mathbf x \in \mathbb R^N\]
\[\mathbf b \in \mathbb R^M\]

20. Norm을 Inner Product로 전개

\(L_2\) Norm의 정의를 사용하면

\[\|\mathbf y\|_2^2 = \mathbf y^T\mathbf y\]

따라서

\[f(\mathbf x) = ( \mathbf A\mathbf x-\mathbf b )^T ( \mathbf A\mathbf x-\mathbf b )\]

21. Least-Squares 완전 전개

Transpose를 적용하면

\[( \mathbf A\mathbf x-\mathbf b )^T = \mathbf x^T\mathbf A^T - \mathbf b^T\]

따라서

\[\begin{aligned} f(\mathbf x) &= ( \mathbf x^T\mathbf A^T-\mathbf b^T ) ( \mathbf A\mathbf x-\mathbf b )\\ &= \mathbf x^T\mathbf A^T\mathbf A\mathbf x - \mathbf x^T\mathbf A^T\mathbf b\\ &\quad- \mathbf b^T\mathbf A\mathbf x + \mathbf b^T\mathbf b \end{aligned}\]

22. Scalar Transpose Identity

\[\mathbf x^T \mathbf A^T \mathbf b\]

는 \(1\times1\) Scalar다.

따라서 Transpose를 취해도 값이 같다.

\[\boxed{ \mathbf x^T \mathbf A^T \mathbf b = \mathbf b^T \mathbf A \mathbf x }\]

따라서 Least-Squares Objective는

\[\boxed{ f(\mathbf x) = \mathbf x^T \mathbf A^T\mathbf A \mathbf x - 2\mathbf b^T\mathbf A\mathbf x + \mathbf b^T\mathbf b }\]

로 정리된다.

23. Least-Squares Gradient

\(\mathbf A^T\mathbf A\)는 Symmetric이다.

\[( \mathbf A^T\mathbf A )^T = \mathbf A^T\mathbf A\]

따라서 Quadratic Form Formula를 적용하면

\[\nabla_{\mathbf x} \left( \mathbf x^T \mathbf A^T\mathbf A \mathbf x \right) = 2\mathbf A^T\mathbf A\mathbf x\]

Linear Term은

\[-2\mathbf b^T\mathbf A\mathbf x = -2( \mathbf A^T\mathbf b )^T \mathbf x\]

이므로

\[\nabla_{\mathbf x} = -2\mathbf A^T\mathbf b\]

24. Least-Squares 최종식

두 항을 합치면

\[\begin{aligned} \nabla_{\mathbf x}f &= 2\mathbf A^T\mathbf A\mathbf x - 2\mathbf A^T\mathbf b\\ &= 2\mathbf A^T ( \mathbf A\mathbf x-\mathbf b ) \end{aligned}\]

따라서

\[\boxed{ \frac{ \partial \| \mathbf A\mathbf x-\mathbf b \|_2^2 }{ \partial\mathbf x } = 2\mathbf A^T ( \mathbf A\mathbf x-\mathbf b ) }\]

25. Trace Operator

Square Matrix

\[\mathbf M \in \mathbb R^{N\times N}\]

의 Trace는 대각 원소의 합이다.

\[\boxed{ \operatorname{Tr}(\mathbf M) = \sum_iM_{ii} }\]

Matrix Calculus에서는 Scalar-Valued Matrix Expression을 표현할 때 Trace가 사용된다.

26. Trace Linear Form

다음 Scalar Function을 생각한다.

\[\boxed{ f(\mathbf X) = \operatorname{Tr} ( \mathbf A\mathbf X ) }\]

원자료의 Gradient Convention에서는

\[\boxed{ \frac{ \partial \operatorname{Tr} ( \mathbf A\mathbf X ) }{ \partial\mathbf X } = \mathbf A^T }\]

27. Trace Linear Form 성분 전개

Trace를 전개하면

\[\operatorname{Tr} ( \mathbf A\mathbf X ) = \sum_i ( \mathbf A\mathbf X )_{ii}\]

Matrix Multiplication 정의를 사용하면

\[= \sum_i \sum_k A_{ik}X_{ki}\]

28. Trace의 Element-wise Derivative

\(X_{rs}\)에 대해 편미분하면

\[k=r, \qquad i=s\]

인 항만 남는다.

따라서

\[\boxed{ \frac{ \partial \operatorname{Tr} ( \mathbf A\mathbf X ) }{ \partial X_{rs} } = A_{sr} }\]

그리고

\[A_{sr} = ( \mathbf A^T )_{rs}\]

이므로

\[\boxed{ \frac{ \partial \operatorname{Tr} ( \mathbf A\mathbf X ) }{ \partial\mathbf X } = \mathbf A^T }\]

29. Trace Quadratic Form

원자료에서는 다음 Matrix Identity도 제시한다.

\[\boxed{ f(\mathbf X) = \operatorname{Tr} ( \mathbf X^T \mathbf A \mathbf X ) }\]

Gradient는

\[\boxed{ \frac{ \partial f }{ \partial\mathbf X } = ( \mathbf A+\mathbf A^T ) \mathbf X }\]

특히

\[\mathbf A=\mathbf A^T\]

이면

\[\boxed{ \frac{ \partial f }{ \partial\mathbf X } = 2\mathbf A\mathbf X }\]

30. 핵심 Matrix Calculus Identities

지금까지의 Formula를 정리하면 다음과 같다.

Linear Form

\[\boxed{ \nabla_{\mathbf x} ( \mathbf a^T\mathbf x ) = \mathbf a }\]

Quadratic Form

\[\boxed{ \nabla_{\mathbf x} ( \mathbf x^T\mathbf A\mathbf x ) = ( \mathbf A+\mathbf A^T ) \mathbf x }\]

Symmetric Quadratic Form

\[\boxed{ \nabla_{\mathbf x} ( \mathbf x^T\mathbf A\mathbf x ) = 2\mathbf A\mathbf x }\]

Least Squares

\[\boxed{ \nabla_{\mathbf x} \| \mathbf A\mathbf x-\mathbf b \|_2^2 = 2\mathbf A^T ( \mathbf A\mathbf x-\mathbf b ) }\]

Trace

\[\boxed{ \nabla_{\mathbf X} \operatorname{Tr} ( \mathbf A\mathbf X ) = \mathbf A^T }\]

31. Neural Network Linear Layer

이제 Matrix Calculus를 Neural Network의 Linear Layer에 적용한다.

Mini-batch Input을

\[\boxed{ \mathbf X \in \mathbb R^{ B\times D_{\mathrm{in}} } }\]

이라고 하자.

Weight Matrix는

\[\boxed{ \mathbf W \in \mathbb R^{ D_{\mathrm{in}} \times D_{\mathrm{out}} } }\]

Bias는

\[\boxed{ \mathbf b \in \mathbb R^{ 1\times D_{\mathrm{out}} } }\]

32. Linear Layer Forward Pass

출력은

\[\boxed{ \mathbf Y = \mathbf X\mathbf W + \mathbf1_B\mathbf b }\]

여기서

\[\mathbf1_B \in \mathbb R^{B\times1}\]

은 모든 Element가 \(1\)인 Column Vector다.

따라서

\[\boxed{ \mathbf Y \in \mathbb R^{ B\times D_{\mathrm{out}} } }\]

33. Forward Shape Check

Matrix Multiplication은

\[( B\times D_{\mathrm{in}} ) ( D_{\mathrm{in}} \times D_{\mathrm{out}} )\]

이므로

\[\boxed{ \mathbf X\mathbf W \in \mathbb R^{ B\times D_{\mathrm{out}} } }\]

Bias Broadcasting Term도

\[( B\times1 ) ( 1\times D_{\mathrm{out}} )\]

이므로

\[B\times D_{\mathrm{out}}\]

Shape을 가진다.

따라서 \(\mathbf Y\)의 Shape과 일치한다.

34. Upstream Gradient

최종 Loss를

\[L\in\mathbb R\]

라고 하자.

상위 Layer에서 \(\mathbf Y\)로 전달된 Gradient를

\[\boxed{ \mathbf G = \frac{\partial L} {\partial\mathbf Y} }\]

라고 정의한다.

Shape은

\[\boxed{ \mathbf G \in \mathbb R^{ B\times D_{\mathrm{out}} } }\]

목표는 이 Gradient로부터

\[\frac{\partial L}{\partial\mathbf W}, \qquad \frac{\partial L}{\partial\mathbf X}, \qquad \frac{\partial L}{\partial\mathbf b}\]

를 구하는 것이다.

35. Weight Gradient

Linear Layer의 핵심 Backpropagation Formula는

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \mathbf X^T \mathbf G }\]

또는

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \mathbf X^T \frac{\partial L} {\partial\mathbf Y} }\]

36. Weight Gradient Element-wise Setup

Forward Pass의 각 Element는

\[\boxed{ Y_{ij} = \sum_{k=1}^{D_{\mathrm{in}}} X_{ik}W_{kj} + b_j }\]

Weight Element

\[W_{rs}\]

는 Output의 \(s\)번째 Column에 영향을 준다.

37. $Y$를 $W$로 미분

\(Y_{is}\)에 대해

\[Y_{is} = \sum_k X_{ik}W_{ks} + b_s\]

이를 \(W_{rs}\)로 미분하면

\[\boxed{ \frac{\partial Y_{is}} {\partial W_{rs}} = X_{ir} }\]

38. Weight Gradient Chain Rule

Multivariate Chain Rule을 적용한다.

\[\frac{\partial L} {\partial W_{rs}} = \sum_{i=1}^{B} \frac{\partial L} {\partial Y_{is}} \frac{\partial Y_{is}} {\partial W_{rs}}\]

\(\mathbf G=\partial L/\partial\mathbf Y\)이므로

\[= \sum_{i=1}^{B} G_{is}X_{ir}\]

순서를 바꾸면

\[\boxed{ \frac{\partial L} {\partial W_{rs}} = \sum_{i=1}^{B} X_{ir}G_{is} }\]

39. Weight Gradient Matrix Form

Matrix Multiplication에서

\[[ \mathbf X^T\mathbf G ]_{rs} = \sum_{i=1}^{B} ( X^T )_{ri} G_{is}\]

그리고

\[( X^T )_{ri} = X_{ir}\]

이므로 앞의 Chain Rule과 동일하다.

따라서

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \mathbf X^T\mathbf G }\]

40. Weight Gradient Shape

\[\mathbf X^T \in \mathbb R^{ D_{\mathrm{in}} \times B }\]

이고

\[\mathbf G \in \mathbb R^{ B\times D_{\mathrm{out}} }\]

따라서

\[\boxed{ \mathbf X^T\mathbf G \in \mathbb R^{ D_{\mathrm{in}} \times D_{\mathrm{out}} } }\]

이는

\[\mathbf W \in \mathbb R^{ D_{\mathrm{in}} \times D_{\mathrm{out}} }\]

와 정확히 같은 Shape이다.

41. Input Gradient

다음 핵심 Formula는 Input에 대한 Gradient다.

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \mathbf G\mathbf W^T }\]

즉

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \frac{\partial L} {\partial\mathbf Y} \mathbf W^T }\]

이 Gradient가 이전 Layer로 전달된다.

42. Input Gradient Element-wise Setup

Input Element

\[X_{rs}\]

는 같은 Batch Row에 있는 Output

\[Y_{rj}\]

들에 영향을 준다.

Forward Formula는

\[Y_{rj} = \sum_{k=1}^{D_{\mathrm{in}}} X_{rk}W_{kj} + b_j\]

43. $Y$를 $X$로 미분

\(X_{rs}\)에 대해 편미분하면

\[\boxed{ \frac{\partial Y_{rj}} {\partial X_{rs}} = W_{sj} }\]

따라서 Chain Rule에 의해

\[\frac{\partial L} {\partial X_{rs}} = \sum_{j=1}^{D_{\mathrm{out}}} \frac{\partial L} {\partial Y_{rj}} W_{sj}\]

44. Input Gradient Matrix Form

\(\mathbf G\)를 사용하면

\[\frac{\partial L} {\partial X_{rs}} = \sum_j G_{rj}W_{sj}\]

그리고

\[( W^T )_{js} = W_{sj}\]

이므로

\[\boxed{ \frac{\partial L} {\partial X_{rs}} = [ \mathbf G\mathbf W^T ]_{rs} }\]

따라서

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \mathbf G\mathbf W^T }\]

45. Input Gradient Shape

\[\mathbf G \in \mathbb R^{ B\times D_{\mathrm{out}} }\]

이고

\[\mathbf W^T \in \mathbb R^{ D_{\mathrm{out}} \times D_{\mathrm{in}} }\]

따라서

\[\boxed{ \mathbf G\mathbf W^T \in \mathbb R^{ B\times D_{\mathrm{in}} } }\]

이는 Input

\[\mathbf X \in \mathbb R^{ B\times D_{\mathrm{in}} }\]

과 같은 Shape이다.

46. Bias Gradient

Bias Gradient는 Batch Dimension에 대해 Upstream Gradient를 합한 값이다.

\[\boxed{ \frac{\partial L} {\partial\mathbf b} = \mathbf1_B^T\mathbf G }\]

또는

\[\boxed{ \frac{\partial L} {\partial\mathbf b} = \sum_{i=1}^{B} \mathbf G_{i,:} }\]

47. Bias Gradient 유도

\(b_s\)는 모든 Batch Sample의

\[Y_{is}\]

에 동일하게 더해진다.

따라서

\[\boxed{ \frac{\partial Y_{is}} {\partial b_s} = 1 }\]

Chain Rule을 적용하면

\[\frac{\partial L} {\partial b_s} = \sum_{i=1}^{B} \frac{\partial L} {\partial Y_{is}}\]

즉

\[\boxed{ \frac{\partial L} {\partial b_s} = \sum_{i=1}^{B}G_{is} }\]

48. Linear Layer Backpropagation 정리

Forward Pass는

\[\boxed{ \mathbf Y = \mathbf X\mathbf W + \mathbf1_B\mathbf b }\]

Upstream Gradient를

\[\boxed{ \mathbf G = \frac{\partial L} {\partial\mathbf Y} }\]

라고 하면

Weight

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \mathbf X^T\mathbf G }\]

Input

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \mathbf G\mathbf W^T }\]

Bias

\[\boxed{ \frac{\partial L} {\partial\mathbf b} = \mathbf1_B^T\mathbf G }\]

49. Numerical Example — Inputs

원자료의 Mini-batch Input은

\[\boxed{ \mathbf X = \begin{bmatrix} 1&2&0\\ 0&1&3 \end{bmatrix} }\]

Shape은

\[\boxed{ 2\times3 }\]

따라서

\[B=2, \qquad D_{\mathrm{in}}=3\]

50. Numerical Example — Weights

Weight Matrix는

\[\boxed{ \mathbf W = \begin{bmatrix} 0.5&-1.0\\ 1.0&0.0\\ -0.5&2.0 \end{bmatrix} }\]

Shape은

\[\boxed{ 3\times2 }\]

이므로

\[D_{\mathrm{out}}=2\]

51. Numerical Example — Upstream Gradient

Upstream Gradient는

\[\boxed{ \mathbf G = \frac{\partial L} {\partial\mathbf Y} = \begin{bmatrix} 2.0&-1.0\\ 0.5&1.5 \end{bmatrix} }\]

Shape은

\[\boxed{ 2\times2 }\]

52. Numerical Example — $X^T$

Input Transpose는

\[\boxed{ \mathbf X^T = \begin{bmatrix} 1&0\\ 2&1\\ 0&3 \end{bmatrix} }\]

따라서 Weight Gradient는

\[\frac{\partial L} {\partial\mathbf W} = \mathbf X^T\mathbf G\]

53. Numerical Example — Weight Gradient

Matrix Multiplication을 수행한다.

\[\begin{aligned} \frac{\partial L} {\partial\mathbf W} &= \begin{bmatrix} 1&0\\ 2&1\\ 0&3 \end{bmatrix} \begin{bmatrix} 2.0&-1.0\\ 0.5&1.5 \end{bmatrix} \end{aligned}\]

각 Row를 계산하면

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \begin{bmatrix} 2.0&-1.0\\ 4.5&-0.5\\ 1.5&4.5 \end{bmatrix} }\]

54. Weight Gradient Shape Check

결과 Shape은

\[\boxed{ 3\times2 }\]

이는

\[\mathbf W \in \mathbb R^{3\times2}\]

와 동일하다.

55. Numerical Example — $W^T$

Weight Transpose는

\[\boxed{ \mathbf W^T = \begin{bmatrix} 0.5&1.0&-0.5\\ -1.0&0.0&2.0 \end{bmatrix} }\]

Input Gradient는

\[\frac{\partial L} {\partial\mathbf X} = \mathbf G\mathbf W^T\]

56. Numerical Example — Input Gradient

Matrix Multiplication을 수행하면

\[\begin{aligned} \frac{\partial L} {\partial\mathbf X} &= \begin{bmatrix} 2.0&-1.0\\ 0.5&1.5 \end{bmatrix} \begin{bmatrix} 0.5&1.0&-0.5\\ -1.0&0.0&2.0 \end{bmatrix} \end{aligned}\]

결과는

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \begin{bmatrix} 2.0&2.0&-3.0\\ -1.25&0.5&2.75 \end{bmatrix} }\]

57. Input Gradient Shape Check

결과는

\[2\times3\]

Matrix다.

즉

\[\boxed{ \frac{\partial L} {\partial\mathbf X} \in \mathbb R^{2\times3} }\]

원래 Input

\[\mathbf X \in \mathbb R^{2\times3}\]

와 Shape이 같다.

58. Numerical Example — Bias Gradient

Bias Gradient는 Column Sum이다.

\[\frac{\partial L} {\partial\mathbf b} = \mathbf1_2^T\mathbf G\]

따라서

\[\begin{aligned} \frac{\partial L} {\partial\mathbf b} &= [ 2.0+0.5, \; -1.0+1.5 ]\\ &= \boxed{ [ 2.5, 0.5 ] } \end{aligned}\]

Shape은

\[\boxed{ 1\times2 }\]

59. Numerical Example 결과 정리

Weight Gradient

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \begin{bmatrix} 2.0&-1.0\\ 4.5&-0.5\\ 1.5&4.5 \end{bmatrix} }\]

Input Gradient

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \begin{bmatrix} 2.0&2.0&-3.0\\ -1.25&0.5&2.75 \end{bmatrix} }\]

Bias Gradient

\[\boxed{ \frac{\partial L} {\partial\mathbf b} = [ 2.5, 0.5 ] }\]

60. Transformer Linear Projection

Transformer에서는 Token Representation Matrix

\[\mathbf X\]

에서 Query, Key, Value를 Linear Projection으로 생성한다.

\[\boxed{ \mathbf Q = \mathbf X\mathbf W_Q }\]
\[\boxed{ \mathbf K = \mathbf X\mathbf W_K }\]
\[\boxed{ \mathbf V = \mathbf X\mathbf W_V }\]

이 구조는 앞에서 다룬

\[\mathbf Y = \mathbf X\mathbf W\]

와 동일한 Matrix Multiplication 구조다.

61. Query Projection Shape

원자료에서는

\[\mathbf X \in \mathbb R^{ N\times d_{\mathrm{model}} }\]

이라고 둔다.

Query Weight는

\[\boxed{ \mathbf W_Q \in \mathbb R^{ d_{\mathrm{model}} \times d_k } }\]

그러면

\[\boxed{ \mathbf Q = \mathbf X\mathbf W_Q \in \mathbb R^{ N\times d_k } }\]

62. Query Weight Gradient

Attention의 상위 연산에서

\[\frac{\partial L} {\partial\mathbf Q}\]

가 전달되었다고 하자.

앞의 Linear Layer Formula를 그대로 적용하면

\[\boxed{ \frac{\partial L} {\partial\mathbf W_Q} = \mathbf X^T \frac{\partial L} {\partial\mathbf Q} }\]

Shape은

\[\boxed{ d_{\mathrm{model}} \times d_k }\]

즉 원래

\[\mathbf W_Q\]

와 동일한 Shape이다.

63. Key와 Value Projection

같은 구조를 적용하면

\[\boxed{ \frac{\partial L} {\partial\mathbf W_K} = \mathbf X^T \frac{\partial L} {\partial\mathbf K} }\]

이고

\[\boxed{ \frac{\partial L} {\partial\mathbf W_V} = \mathbf X^T \frac{\partial L} {\partial\mathbf V} }\]

라는 동일한 형태로 이해할 수 있다.

핵심은 세 Projection 모두

\[\boxed{ \mathbf Y=\mathbf X\mathbf W }\]

라는 Linear Map을 사용한다는 점이다.

64. Projection에서 Input으로의 Gradient

하나의 Projection

\[\mathbf Q = \mathbf X\mathbf W_Q\]

만 생각하면 \(\mathbf X\)로 전달되는 Gradient는

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \frac{\partial L} {\partial\mathbf Q} \mathbf W_Q^T }\]

형태가 된다.

즉 Weight Gradient에는

\[\mathbf X^T\]

가 등장하고, Input Gradient에는

\[\mathbf W^T\]

가 등장하는 Linear-Layer Backpropagation 구조가 그대로 적용된다.

65. Matrix Multiplication과 Backpropagation의 핵심 구조

Forward에서

\[\boxed{ \mathbf Y = \mathbf X\mathbf W }\]

라면 Backward에서는

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \mathbf X^T \frac{\partial L} {\partial\mathbf Y} }\]
\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \frac{\partial L} {\partial\mathbf Y} \mathbf W^T }\]

즉 Transpose가 Backpropagation Formula에 자연스럽게 등장한다.

66. Shape로 Backpropagation Formula 기억하기

Forward Shape이

\[(B\times D_{\mathrm{in}}) (D_{\mathrm{in}}\times D_{\mathrm{out}}) = (B\times D_{\mathrm{out}})\]

이라고 하자.

Weight Gradient는

\[(D_{\mathrm{in}}\times B) (B\times D_{\mathrm{out}})\]

이어야 하므로

\[\boxed{ X^TG }\]

Input Gradient는

\[(B\times D_{\mathrm{out}}) (D_{\mathrm{out}}\times D_{\mathrm{in}})\]

이어야 하므로

\[\boxed{ GW^T }\]

67. 혼동하기 쉬운 부분 — Layout

Matrix Calculus Formula는 문헌에 따라 Transpose 위치가 다르게 보일 수 있다.

따라서

\[\boxed{ \text{Derivative Convention} }\]

을 먼저 확인해야 한다.

이 Lecture에서는 Deep Learning Backpropagation에서 Parameter와 Gradient의 Shape을 동일하게 유지하는 표현을 사용한다.

68. 혼동하기 쉬운 부분 — Matrix Gradient

\[\frac{\partial L} {\partial\mathbf W}\]

는 Scalar 하나가 아니다.

Weight Matrix의 각 Element에 대한 Partial Derivative를 모두 모은 Matrix다.

\[\boxed{ \left[ \frac{\partial L} {\partial\mathbf W} \right]_{ij} = \frac{\partial L} {\partial W_{ij}} }\]

69. 혼동하기 쉬운 부분 — $X^TG$의 의미

\[\frac{\partial L} {\partial\mathbf W} = \mathbf X^T\mathbf G\]

는 단순히 Shape을 맞추기 위해 만든 공식이 아니다.

각 Weight

\[W_{rs}\]

가 Batch 전체의 Output에 미치는 영향을 Chain Rule로 합산하면

\[\sum_i X_{ir}G_{is}\]

가 나오고, 이것이 정확히

\[[ X^TG ]_{rs}\]

와 같다.

70. 혼동하기 쉬운 부분 — Bias Gradient

Bias는 각 Batch Sample에 동일하게 더해진다.

따라서 Bias Gradient는 Batch 방향으로 Gradient를 합산한다.

\[\boxed{ \frac{\partial L} {\partial\mathbf b} = \sum_{i=1}^{B} G_{i,:} }\]

Weight Gradient처럼 Matrix Multiplication을 수행하는 구조와 구분해야 한다.

71. 핵심 Cheat Sheet

Linear Form

\[\boxed{ \nabla_{\mathbf x} ( \mathbf a^T\mathbf x ) = \mathbf a }\]

Quadratic Form

\[\boxed{ \nabla_{\mathbf x} ( \mathbf x^T\mathbf A\mathbf x ) = ( \mathbf A+\mathbf A^T ) \mathbf x }\]

Least Squares

\[\boxed{ \nabla_{\mathbf x} \| \mathbf A\mathbf x-\mathbf b \|_2^2 = 2\mathbf A^T ( \mathbf A\mathbf x-\mathbf b ) }\]

Trace

\[\boxed{ \nabla_{\mathbf X} \operatorname{Tr} ( \mathbf A\mathbf X ) = \mathbf A^T }\]

Linear Layer — Weight

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \mathbf X^T \frac{\partial L} {\partial\mathbf Y} }\]

Linear Layer — Input

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \frac{\partial L} {\partial\mathbf Y} \mathbf W^T }\]

Linear Layer — Bias

\[\boxed{ \frac{\partial L} {\partial\mathbf b} = \mathbf1_B^T \frac{\partial L} {\partial\mathbf Y} }\]

72. 정리

Matrix Calculus는 Scalar Loss를 Vector와 Matrix Parameter에 대해 미분하는 도구다.

Scalar Function을 Vector로 미분하면 Gradient를 얻는다.

\[\boxed{ \nabla_{\mathbf x}f }\]

Scalar Function을 Matrix로 미분하면 각 Matrix Element의 Partial Derivative를 모은 Gradient Matrix를 얻는다.

\[\boxed{ \left[ \frac{\partial f} {\partial\mathbf X} \right]_{ij} = \frac{\partial f} {\partial X_{ij}} }\]

이 Lecture에서는 Parameter와 Gradient가 같은 Shape을 가지도록 표현한다.

Linear Form은

\[\boxed{ \nabla_{\mathbf x} ( \mathbf a^T\mathbf x ) = \mathbf a }\]

Quadratic Form은

\[\boxed{ \nabla_{\mathbf x} ( \mathbf x^T\mathbf A\mathbf x ) = ( \mathbf A+\mathbf A^T ) \mathbf x }\]

Least-Squares Objective는

\[\boxed{ \nabla_{\mathbf x} \| \mathbf A\mathbf x-\mathbf b \|_2^2 = 2\mathbf A^T ( \mathbf A\mathbf x-\mathbf b ) }\]

Neural Network의 Linear Layer

\[\boxed{ \mathbf Y = \mathbf X\mathbf W + \mathbf1_B\mathbf b }\]

에서는 Upstream Gradient

\[\mathbf G = \frac{\partial L} {\partial\mathbf Y}\]

로부터

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \mathbf X^T\mathbf G }\]
\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \mathbf G\mathbf W^T }\]
\[\boxed{ \frac{\partial L} {\partial\mathbf b} = \mathbf1_B^T\mathbf G }\]

를 얻는다.

Transformer의 Query Projection

\[\mathbf Q = \mathbf X\mathbf W_Q\]

에서도 동일한 구조를 사용한다.

\[\boxed{ \frac{\partial L} {\partial\mathbf W_Q} = \mathbf X^T \frac{\partial L} {\partial\mathbf Q} }\]

따라서 전체 흐름은

\[\boxed{ \text{Partial Derivative} \rightarrow \text{Vector Gradient} \rightarrow \text{Matrix Gradient} }\]

로 확장된다.

행렬 미분의 기본 항등식은

\[\boxed{ \text{Linear Form} \rightarrow \text{Quadratic Form} \rightarrow \text{Least Squares} \rightarrow \text{Trace} }\]

로 연결된다.

Deep Learning에서는

\[\boxed{ \text{Forward Matrix Multiplication} \rightarrow \text{Upstream Gradient} \rightarrow \text{Matrix Chain Rule} \rightarrow \text{Backpropagation} }\]

이 된다.

Transformer에서는 다시

\[\boxed{ X \rightarrow Q,K,V \rightarrow W_Q,W_K,W_V \text{ Gradient} }\]

로 직접 연결된다.
