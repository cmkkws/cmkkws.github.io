CO-09 — Gradient Descent & Stochastic Gradient Descent (SGD)

Gradient Descent와 Stochastic Gradient Descent의 업데이트 식과 차이를 정리한다.

수정 2026.09.18약 52분상태 작성 완료
학습 내용
  • Gradient Descent
  • Gradient Descent Update
  • Dataset Objective
  • Full Gradient

Gradient Descent

Machine Learning Training에서는 Parameter

\[\mathbf{\theta} \in \mathbb R^D\]

를 조정하여 Loss 또는 Objective Function

\[L(\mathbf{\theta})\]

를 최소화한다.

Gradient는 현재 Parameter에서 Loss가 가장 빠르게 증가하는 방향을 나타낸다.

\[\boxed{ \nabla L(\mathbf{\theta}) }\]

따라서 Negative Gradient는 Euclidean Geometry에서 Loss를 국소적으로 가장 빠르게 감소시키는 방향이다.

\[\boxed{ -\nabla L(\mathbf{\theta}) }\]

Gradient Descent는 이 방향으로 Parameter를 반복적으로 이동시키는 First-Order Optimization Method다.

Gradient Descent Update

기본 Update Rule은

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \nabla L( \mathbf{\theta}^{(t)} ) }\]

여기서

\[\eta>0\]

는 Learning Rate다.

각 Iteration에서

  1. 현재 Parameter에서 Gradient 계산
  2. Negative Gradient 방향 결정
  3. Learning Rate만큼 이동

을 반복한다.

Dataset Objective

Dataset을

\[\mathcal D = \{ (\mathbf x_i,y_i) \}_{i=1}^{N}\]

라고 하자.

각 Sample의 Loss를

\[\ell_i(\mathbf{\theta}) = \ell \left( f_{\mathbf{\theta}}(\mathbf x_i), y_i \right)\]

라고 하면 전체 Dataset의 평균 Loss는

\[\boxed{ L(\mathbf{\theta}) = \frac1N \sum_{i=1}^{N} \ell_i(\mathbf{\theta}) }\]

Full Gradient

기댓값과 미분의 선형성에 따라 전체 Gradient는

\[\boxed{ \nabla L(\mathbf{\theta}) = \frac1N \sum_{i=1}^{N} \nabla \ell_i(\mathbf{\theta}) }\]

즉 Dataset의 모든 Sample Gradient를 계산한 뒤 평균한 값이다.

Batch Gradient Descent

전체 \(N\)개 Dataset을 매 Update마다 모두 사용하는 방식을 Batch Gradient Descent 또는 Full-Batch Gradient Descent라고 한다.

Update는

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \frac1N \sum_{i=1}^{N} \nabla \ell_i( \mathbf{\theta}^{(t)} ) }\]

즉

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \nabla L( \mathbf{\theta}^{(t)} ) }\]

Batch GD의 특징

Batch GD에서는 매 Step마다 Dataset 전체를 사용한다.

따라서 현재 Dataset Objective에 대한 정확한 Full Gradient

\[\nabla L(\mathbf{\theta})\]

를 계산한다.

원자료에서는 이를 상대적으로 매끄러운 Deterministic Optimization Path와 연결한다.

하지만 Dataset이 매우 크면 한 번의 Parameter Update를 위해 모든 Sample을 처리해야 한다.

따라서 대규모 Deep Learning에서는 계산 비용이 매우 커질 수 있다.

Stochastic Gradient Descent

Full Dataset 대신 일부 Sample만 사용하여 Gradient를 추정할 수 있다.

가장 극단적인 경우 한 Sample

\[i_t\]

만 선택한다.

그러면 Stochastic Gradient는

\[\boxed{ \mathbf g^{(t)} = \nabla \ell_{i_t} ( \mathbf{\theta}^{(t)} ) }\]

Update는

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \mathbf g^{(t)} }\]

Mini-Batch SGD

실제 Deep Learning에서는 보통 Sample 하나보다 Mini-batch를 사용한다.

Mini-batch를

\[\mathcal B^{(t)} \subset \mathcal D\]

라고 하고 Batch Size를

\[\boxed{ |\mathcal B^{(t)}|=B }\]

라고 하자.

이때 Mini-batch Gradient는

\[\boxed{ \mathbf g^{(t)} = \frac1B \sum_{i\in\mathcal B^{(t)}} \nabla \ell_i( \mathbf{\theta}^{(t)} ) }\]

Mini-Batch Update

Parameter Update는

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \mathbf g^{(t)} }\]

즉 Full Gradient

\[\nabla L\]

대신 Mini-batch Gradient Estimate

\[\mathbf g\]

를 사용한다.

Full Gradient vs Mini-Batch Gradient

Batch GD에서는

\[\boxed{ \mathbf g = \nabla L }\]

Mini-batch SGD에서는 일반적으로

\[\boxed{ \mathbf g \neq \nabla L }\]

하지만 적절한 Sampling 조건에서는 기대값 수준에서 Full Gradient와 일치한다.

\[\boxed{ \mathbb E[ \mathbf g ] = \nabla L }\]

Unbiased Gradient Estimator

Mini-batch Gradient를

\[\mathbf g = \frac1B \sum_{i\in\mathcal B} \nabla \ell_i(\mathbf{\theta})\]

라고 하자.

원자료에서는 Mini-batch가 적절하게 Random Sampling된다는 설정에서

\[\boxed{ \mathbb E_{\mathcal B} [ \mathbf g ] = \nabla L(\mathbf{\theta}) }\]

을 사용한다.

따라서 Mini-batch Gradient는 Full Gradient의 Unbiased Estimator로 해석한다.

Unbiasedness 유도

Expectation의 선형성을 사용하면

\[\begin{aligned} \mathbb E_{\mathcal B} [ \mathbf g ] &= \mathbb E_{\mathcal B} \left[ \frac1B \sum_{i\in\mathcal B} \nabla \ell_i(\mathbf{\theta}) \right]\\ &= \frac1B \sum_{i=1}^{B} \mathbb E[ \nabla \ell_i(\mathbf{\theta}) ] \end{aligned}\]

각 Sample Gradient의 기대값이 Population 또는 Dataset Gradient와 일치한다고 두면

\[\mathbb E[ \nabla\ell_i ] = \nabla L\]

이므로

\[\boxed{ \mathbb E[ \mathbf g ] = \nabla L }\]

Gradient Noise

Mini-batch Gradient는 Full Gradient와 일반적으로 정확히 같지 않다.

따라서

\[\boxed{ \mathbf{\epsilon} = \mathbf g - \nabla L }\]

를 Gradient Noise로 생각할 수 있다.

Unbiasedness가 성립하면

\[\boxed{ \mathbb E[ \mathbf{\epsilon} ] = 0 }\]

즉 평균적으로는 Full Gradient 방향과 일치하지만 각 Step에서는 Random Fluctuation이 존재한다.

Batch Size

Batch Size는

\[\boxed{ B }\]

Full Batch에서는

\[B=N\]

Single-sample SGD에서는

\[B=1\]

Mini-batch Training에서는

\[\boxed{ 1<B<N }\]

인 중간 영역을 사용한다.

Batch Size의 핵심 Trade-off

원자료의 수학적 초점은 Batch Size와 Gradient Estimate의 Variance 관계다.

Batch Size가 작으면 Gradient Estimate의 변동성이 커진다.

Batch Size가 커지면 더 많은 Sample을 평균하므로 Gradient Estimate가 안정된다.

이 관계는 이후

\[\boxed{ \operatorname{Var}(\mathbf g) = \frac1B \mathbf{\Sigma} }\]

로 유도한다.

Learning Rate

Learning Rate

\[\eta\]

는 Gradient Direction으로 얼마나 크게 이동할지를 결정한다.

Update는

\[\boxed{ \Delta\mathbf{\theta} = -\eta\nabla L }\]

또는 SGD에서는

\[\boxed{ \Delta\mathbf{\theta} = -\eta\mathbf g }\]

따라서

\[\boxed{ \text{Gradient} = \text{Direction and local scale} }\]
\[\boxed{ \eta = \text{Step-size multiplier} }\]

로 구분할 수 있다.

너무 작은 Learning Rate

\(\eta\)가 매우 작으면 한 Step의 이동량도 작다.

\[\| \Delta\mathbf{\theta} \| = \eta \| \nabla L \|\]

따라서 Objective가 감소하더라도 Optimization Progress가 매우 느릴 수 있다.

너무 큰 Learning Rate

Learning Rate가 지나치게 크면 Negative Gradient Direction으로 이동하더라도 Local Minimum을 지나쳐 반대편으로 크게 이동할 수 있다.

따라서

\[\boxed{ \text{Descent Direction} \neq \text{arbitrarily large safe step} }\]

학습률이 어느 범위에서 Loss 감소를 보장할 수 있는지를 분석하기 위해 원자료에서는 \(L\)-Smoothness를 사용한다.

\(L\)-Smoothness

함수

\[f: \mathbb R^D \rightarrow \mathbb R\]

의 Gradient가 \(L\)-Lipschitz Continuous하다고 하자.

정의는

\[\boxed{ \| \nabla f(\mathbf x) - \nabla f(\mathbf y) \|_2 \le L \| \mathbf x-\mathbf y \|_2 }\]

여기서

\[L>0\]

이를 \(L\)-Smooth Function이라고 한다.

\(L\)-Smoothness의 의미

두 Point가 가까우면 Gradient 역시 지나치게 급격하게 변하지 않는다는 조건이다.

\[\| \mathbf x-\mathbf y \|_2 \text{ small}\]

이면

\[\| \nabla f(\mathbf x) - \nabla f(\mathbf y) \|_2\]

도 \(L\)에 의해 제한된다.

즉 \(L\)은 Gradient 변화율의 상한과 연결된다.

Descent Lemma

\(L\)-Smoothness가 성립하면 다음 Upper Bound를 사용할 수 있다.

\[\boxed{ f(\mathbf y) \le f(\mathbf x) + \nabla f(\mathbf x)^T ( \mathbf y-\mathbf x ) + \frac L2 \| \mathbf y-\mathbf x \|_2^2 }\]

이를 Descent Lemma라고 한다.

이는 함수의 Local 1차 근사에 Quadratic Upper Bound를 추가한 형태다.

Gradient Descent Step 대입

현재 Parameter를

\[\mathbf{\theta}^{(t)}\]

라고 한다.

Gradient Descent Update는

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \nabla f( \mathbf{\theta}^{(t)} ) }\]

Descent Lemma에서

\[\mathbf x = \mathbf{\theta}^{(t)}\]
\[\mathbf y = \mathbf{\theta}^{(t+1)}\]

로 둔다.

Parameter Difference

Update Formula에 의해

\[\begin{aligned} \mathbf y-\mathbf x &= \mathbf{\theta}^{(t+1)} - \mathbf{\theta}^{(t)}\\ &= -\eta \nabla f( \mathbf{\theta}^{(t)} ) \end{aligned}\]

따라서

\[\boxed{ \mathbf y-\mathbf x = -\eta\nabla f }\]

Descent Lemma에 Update 대입

다음을 얻는다.

\[\begin{aligned} f( \mathbf{\theta}^{(t+1)} ) &\le f( \mathbf{\theta}^{(t)} ) + \nabla f( \mathbf{\theta}^{(t)} )^T \left[ -\eta \nabla f( \mathbf{\theta}^{(t)} ) \right]\\ &\quad+ \frac L2 \left\| -\eta \nabla f( \mathbf{\theta}^{(t)} ) \right\|_2^2 \end{aligned}\]

First-Order Term

Inner Product Term은

\[\nabla f^T ( -\eta\nabla f )\]

따라서

\[\boxed{ \nabla f^T ( -\eta\nabla f ) = -\eta \| \nabla f \|_2^2 }\]

Quadratic Term

Norm Term은

\[\left\| -\eta\nabla f \right\|_2^2\]

Norm의 Homogeneity에 의해

\[\boxed{ \left\| -\eta\nabla f \right\|_2^2 = \eta^2 \| \nabla f \|_2^2 }\]

Loss Upper Bound

두 결과를 결합하면

\[\begin{aligned} f( \mathbf{\theta}^{(t+1)} ) &\le f( \mathbf{\theta}^{(t)} ) - \eta \| \nabla f( \mathbf{\theta}^{(t)} ) \|_2^2\\ &\quad+ \frac{ L\eta^2 }{2} \| \nabla f( \mathbf{\theta}^{(t)} ) \|_2^2 \end{aligned}\]

공통항 정리

Gradient Norm을 묶으면

\[\boxed{ f( \mathbf{\theta}^{(t+1)} ) \le f( \mathbf{\theta}^{(t)} ) - \eta \left( 1-\frac{L\eta}{2} \right) \| \nabla f( \mathbf{\theta}^{(t)} ) \|_2^2 }\]

이 식에서 Learning Rate 조건을 읽을 수 있다.

Loss 감소 조건

Gradient가 0이 아닌 상황에서 Upper Bound의 감소항이 Positive가 되려면

\[\eta \left( 1-\frac{L\eta}{2} \right) >0\]

이어야 한다.

\(\eta>0\)이므로

\[1-\frac{L\eta}{2}>0\]

따라서

\[\boxed{ 0<\eta<\frac2L }\]

을 얻는다.

Learning Rate Upper Bound

원자료의 \(L\)-Smooth Setting에서는

\[\boxed{ \eta<\frac2L }\]

가 Gradient Descent Step의 Loss 감소 Upper-Bound 조건으로 제시된다.

즉 Curvature Scale \(L\)이 클수록 허용되는 Learning Rate가 작아진다.

\[\boxed{ L\uparrow \Rightarrow \eta_{\max}\downarrow }\]

Descent Bound를 최대화하는 \(\eta\)

Upper Bound에서 한 Step의 보장 감소 계수는

\[\eta \left( 1-\frac{L\eta}{2} \right)\]

이를

\[q(\eta) = \eta-\frac L2\eta^2\]

라고 하자.

미분하면

\[q'(\eta) = 1-L\eta\]

이를 0으로 두면

\[\boxed{ \eta^\ast = \frac1L }\]

\(\eta=1/L\)일 때

학습률을

\[\eta=\frac1L\]

로 두면

\[\eta \left( 1-\frac{L\eta}{2} \right) = \frac1L \left( 1-\frac12 \right)\]

따라서

\[\boxed{ = \frac1{2L} }\]

그러므로

\[\boxed{ f( \mathbf{\theta}^{(t+1)} ) \le f( \mathbf{\theta}^{(t)} ) - \frac1{2L} \| \nabla f( \mathbf{\theta}^{(t)} ) \|_2^2 }\]

이 \(1/L\)의 의미

이 결과는 원자료의 Descent-Lemma Upper Bound 안에서 한 Step의 보장 감소량을 최대화하는 값이다.

\[\boxed{ \eta^\ast=\frac1L }\]

즉 모든 Optimization Problem에서 항상 실제 최적 학습률이라는 의미로 사용하기보다, 현재 \(L\)-Smoothness 기반 분석에서 자연스럽게 나타나는 기준값이다.

Quadratic Function에서 \(L\)

Quadratic Function을

\[f(\mathbf x) = \frac12 \mathbf x^T \mathbf H \mathbf x\]

라고 하고 \(\mathbf H\)가 Symmetric Positive Semi-Definite라고 하자.

Gradient는

\[\nabla f(\mathbf x) = \mathbf H\mathbf x\]

이 경우 Gradient Lipschitz Constant는 Hessian의 최대 Eigenvalue와 연결된다.

\[\boxed{ L = \lambda_{\max}(\mathbf H) }\]

라는 구조를 사용할 수 있다.

Mini-Batch Gradient Variance

이제 Mini-batch Gradient를

\[\boxed{ \mathbf g = \frac1B \sum_{i=1}^{B} \mathbf g_i }\]

라고 하자.

여기서

\[\mathbf g_i = \nabla \ell_i( \mathbf{\theta} )\]

각 Sample Gradient가 i.i.d.이고 Covariance Matrix가

\[\boxed{ \operatorname{Var}( \mathbf g_i ) = \mathbf{\Sigma} }\]

라고 가정한다.

Variance Scaling

상수배에 대한 Covariance Scaling을 적용하면

\[\operatorname{Var} \left( \frac1B \sum_{i=1}^{B} \mathbf g_i \right) = \frac1{B^2} \operatorname{Var} \left( \sum_{i=1}^{B} \mathbf g_i \right)\]

Independent Gradient Samples

각 \(\mathbf g_i\)가 독립이면 Cross-Covariance Term이 사라진다.

따라서

\[\boxed{ \operatorname{Var} \left( \sum_{i=1}^{B} \mathbf g_i \right) = \sum_{i=1}^{B} \operatorname{Var}( \mathbf g_i ) }\]

각 Variance가

\[\mathbf{\Sigma}\]

이므로

\[= B\mathbf{\Sigma}\]

Mini-Batch Gradient Variance 유도

따라서

\[\begin{aligned} \operatorname{Var}( \mathbf g ) &= \frac1{B^2} ( B\mathbf{\Sigma} )\\ &= \boxed{ \frac1B \mathbf{\Sigma} } \end{aligned}\]

즉

\[\boxed{ \operatorname{Var}( \mathbf g ) \propto \frac1B }\]

Batch Size와 Variance

Batch Size를 \(k\)배 증가시키면

\[B \rightarrow kB\]

Gradient Variance는

\[\frac{\mathbf{\Sigma}}{kB}\]

따라서

\[\boxed{ \operatorname{Var}( \mathbf g_{\mathrm{new}} ) = \frac1k \operatorname{Var}( \mathbf g_{\mathrm{old}} ) }\]

Gradient Standard Deviation

Variance가

\[\frac1B\]

로 줄어들면 Standard Deviation Scale은

\[\frac1{\sqrt B}\]

로 감소한다.

즉 Gradient Noise의 전형적인 크기는

\[\boxed{ \text{noise scale} \propto \frac1{\sqrt B} }\]

로 연결할 수 있다.

Small Batch

\(B\)가 작으면

\[\operatorname{Var}( \mathbf g )\]

가 상대적으로 크다.

따라서 Update Direction이 Full Gradient 주변에서 더 크게 흔들릴 수 있다.

\[\boxed{ \mathbf g = \nabla L + \text{larger stochastic fluctuation} }\]

Large Batch

\(B\)가 증가하면

\[\operatorname{Var}( \mathbf g )\]

가 감소한다.

따라서 Mini-batch Gradient가 Full Gradient 주변에 더 집중된다.

\[\boxed{ B\uparrow \Rightarrow \operatorname{Var}( \mathbf g )\downarrow }\]

Full Batch Limit

단순한 Sampling 관점에서 Batch Size가 Dataset 전체에 접근하면 Gradient Estimate는 Full Gradient에 가까워진다.

\[B \rightarrow N\]

일 때

\[\mathbf g \rightarrow \nabla L\]

라는 방향으로 이해할 수 있다.

Full-Batch GD에서는 Dataset에 대한 Sampling Noise가 사라진다.

Numerical Example — Objective

다음 Quadratic Loss를 생각한다.

\[\boxed{ f(x,y) = 2x^2 + 8y^2 }\]

목표는

  1. Gradient 계산
  2. Hessian 계산
  3. \(L\) 계산
  4. Learning Rate Bound 계산
  5. Gradient Descent 1 Step 계산

Example — Gradient

\(x\)에 대해 미분하면

\[\frac{\partial f}{\partial x} = 4x\]

\(y\)에 대해 미분하면

\[\frac{\partial f}{\partial y} = 16y\]

따라서

\[\boxed{ \nabla f(x,y) = \begin{bmatrix} 4x\\ 16y \end{bmatrix} }\]

Example — Hessian

Gradient를 다시 미분하면

\[\boxed{ \mathbf H = \begin{bmatrix} 4&0\\ 0&16 \end{bmatrix} }\]

Hessian은 Constant Matrix다.

Example — Eigenvalues

Diagonal Matrix이므로 Eigenvalue는 대각 원소와 같다.

\[\boxed{ \lambda_1=4 }\]
\[\boxed{ \lambda_2=16 }\]

따라서 최대 Eigenvalue는

\[\boxed{ \lambda_{\max} = 16 }\]

Example — Lipschitz Constant

Quadratic Function에서

\[L = \lambda_{\max}( \mathbf H )\]

이므로

\[\boxed{ L=16 }\]

Example — Learning Rate Bound

앞서 유도한 조건은

\[\eta<\frac2L\]

\(L=16\)을 대입하면

\[\eta < \frac2{16}\]

따라서

\[\boxed{ \eta<0.125 }\]

Example — Bound 기준 \(\eta^\ast\)

원자료의 Descent-Bound 기준값은

\[\eta^\ast = \frac1L\]

따라서

\[\boxed{ \eta = \frac1{16} = 0.0625 }\]

Example — Initial Point

초기점은

\[\boxed{ \mathbf x^{(0)} = \begin{bmatrix} 4\\ 2 \end{bmatrix} }\]

초기 Loss는

\[\begin{aligned} f(4,2) &= 2(4)^2 + 8(2)^2\\ &= 32+32\\ &= \boxed{64} \end{aligned}\]

Example — Initial Gradient

Gradient Formula는

\[\nabla f(x,y) = \begin{bmatrix} 4x\\ 16y \end{bmatrix}\]

초기점에서

\[\begin{aligned} \nabla f(4,2) &= \begin{bmatrix} 4(4)\\ 16(2) \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} 16\\ 32 \end{bmatrix} } \end{aligned}\]

Example — One Gradient Descent Step

Update는

\[\mathbf x^{(1)} = \mathbf x^{(0)} - \eta \nabla f( \mathbf x^{(0)} )\]

\(\eta=1/16\)을 대입하면

\[\begin{aligned} \mathbf x^{(1)} &= \begin{bmatrix} 4\\ 2 \end{bmatrix} - \frac1{16} \begin{bmatrix} 16\\ 32 \end{bmatrix}\\ &= \begin{bmatrix} 4\\ 2 \end{bmatrix} - \begin{bmatrix} 1\\ 2 \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} 3\\ 0 \end{bmatrix} } \end{aligned}\]

Example — Updated Loss

새로운 Point는

\[(3,0)\]

따라서

\[\begin{aligned} f(3,0) &= 2(3)^2 + 8(0)^2\\ &= 18 \end{aligned}\]

즉

\[\boxed{ 64 \rightarrow 18 }\]

로 Loss가 감소한다.

Example — \(y\) Direction

\(y\) Gradient는

\[16y\]

초기값 \(y=2\)에서

\[16y=32\]

이고 Step은

\[-\frac1{16}(32) = -2\]

따라서

\[y: 2 \rightarrow 0\]

으로 한 Step에 해당 축의 최솟값에 도달한다.

Curvature와 Update

\(x\) 방향 Curvature는

\[4\]

이고 \(y\) 방향 Curvature는

\[16\]

즉 \(y\) 방향이 더 높은 Curvature를 가진다.

\[\boxed{ \lambda_y > \lambda_x }\]

하나의 Learning Rate를 모든 방향에 사용하므로 가장 큰 Curvature가 안정적인 Step Size의 상한을 제한한다.

Ill-Conditioned Geometry와 연결

Eigenvalue Scale이 방향마다 크게 다르면 Gradient Descent의 한 Learning Rate가

  • 높은 Curvature 방향에서는 너무 크고
  • 낮은 Curvature 방향에서는 너무 작을 수 있다.

이번 예제에서도

\[4 \quad\text{vs}\quad 16\]

의 Curvature 차이가 존재한다.

원자료는 이러한 Optimization Geometry를 이후 Adam/AdamW와 연결한다.

Large-Batch Training

원자료에서는

\[\operatorname{Var}( \mathbf g ) = \frac1B \mathbf{\Sigma}\]

라는 결과를 Large-Batch Training과 연결한다.

Batch Size가 커지면 Gradient Noise가 감소한다.

\[\boxed{ B\uparrow \Rightarrow \text{Gradient variance}\downarrow }\]

Linear Scaling Rule과의 연결

원자료에서는 Large-Batch Training에서 Batch Size를 늘릴 때 Learning Rate도 증가시키는

\[\boxed{ \eta \propto B }\]

형태의 Linear Scaling Rule을 소개하고, 이를 Batch Size 증가에 따른 Gradient Noise 감소와 연결한다.

다만 이 Lecture에서는 이를 현대 대규모 Training과 연결되는 직관으로 사용한다.

앞에서 유도한

\[\operatorname{Var}( \mathbf g ) = \frac1B \mathbf{\Sigma}\]

자체가 모든 Training Regime에서

\[\eta\propto B\]

를 독립적으로 증명하는 것은 아니다.

Saddle Point

CO-01에서 Saddle Point에서는

\[\boxed{ \nabla L=0 }\]

이면서 Hessian에 Positive와 Negative Curvature Direction이 함께 존재할 수 있음을 확인했다.

Full-Batch Gradient Descent에서 정확히

\[\nabla L=0\]

이면 Update는

\[\boxed{ \Delta\mathbf{\theta}=0 }\]

SGD Noise와 Saddle Point

원자료에서는 Mini-batch SGD의 Stochastic Gradient를

\[\mathbf g = \nabla L + \text{noise}\]

로 보고, Gradient Noise가 Saddle Region에서 Parameter에 Perturbation을 제공할 수 있다는 관점으로 연결한다.

따라서 Full Gradient가 작거나 0에 가까운 영역에서도

\[\boxed{ \mathbf g \neq0 }\]

일 수 있다.

Batch Size와 Stochastic Perturbation

원자료의 Variance Model에서는

\[\operatorname{Var}( \mathbf g ) = \frac1B \mathbf{\Sigma}\]

따라서 작은 Batch에서는 Stochastic Fluctuation이 더 크고, 큰 Batch에서는 더 작다.

\[\boxed{ B\downarrow \Rightarrow \text{more gradient noise} }\]
\[\boxed{ B\uparrow \Rightarrow \text{less gradient noise} }\]

SGD의 Optimization Path

Full-Batch GD는 같은 Parameter에서 항상 같은 Dataset Gradient를 계산하는 Deterministic Path를 가진다.

반면 Mini-batch SGD에서는 선택된 Batch가 달라질 수 있으므로

\[\boxed{ \mathbf g^{(t)} }\]

가 Step마다 달라진다.

따라서 Parameter Trajectory 역시 Stochastic하게 변할 수 있다.

Adam / AdamW로의 연결

원자료에서는 단순 Gradient Descent 또는 SGD가 Curvature가 방향마다 크게 다른 Ravine 형태에서 진동하거나 느리게 이동할 수 있다는 점을 이후 Adaptive Optimizer와 연결한다.

대표적으로

  • Momentum
  • Adam
  • AdamW

등이 있다.

이 Lecture에서는 세부 Algorithm을 유도하기보다

\[\boxed{ \text{GD / SGD} \rightarrow \text{Momentum / Adaptive Optimization} }\]

으로 연결되는 출발점으로 사용한다.

GD와 SGD 비교

핵심 식 — Batch GD

Dataset Loss는

\[\boxed{ L(\mathbf{\theta}) = \frac1N \sum_{i=1}^{N} \ell_i(\mathbf{\theta}) }\]

Full Gradient는

\[\boxed{ \nabla L(\mathbf{\theta}) = \frac1N \sum_{i=1}^{N} \nabla\ell_i(\mathbf{\theta}) }\]

Update는

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \nabla L( \mathbf{\theta}^{(t)} ) }\]

핵심 식 — Mini-Batch SGD

Mini-batch Gradient는

\[\boxed{ \mathbf g^{(t)} = \frac1B \sum_{i\in\mathcal B^{(t)}} \nabla \ell_i( \mathbf{\theta}^{(t)} ) }\]

Update는

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \mathbf g^{(t)} }\]

적절한 Random Sampling 조건에서는

\[\boxed{ \mathbb E[ \mathbf g^{(t)} ] = \nabla L( \mathbf{\theta}^{(t)} ) }\]

핵심 식 — \(L\)-Smoothness

Gradient Lipschitz Condition은

\[\boxed{ \| \nabla f(\mathbf x) - \nabla f(\mathbf y) \|_2 \le L \| \mathbf x-\mathbf y \|_2 }\]

Descent Lemma는

\[\boxed{ f(\mathbf y) \le f(\mathbf x) + \nabla f(\mathbf x)^T ( \mathbf y-\mathbf x ) + \frac L2 \| \mathbf y-\mathbf x \|_2^2 }\]

핵심 식 — Learning Rate

Gradient Descent를 대입하면

\[\boxed{ f( \mathbf{\theta}^{(t+1)} ) \le f( \mathbf{\theta}^{(t)} ) - \eta \left( 1-\frac{L\eta}{2} \right) \| \nabla f( \mathbf{\theta}^{(t)} ) \|_2^2 }\]

따라서 원자료의 Loss-Decrease 조건은

\[\boxed{ 0<\eta<\frac2L }\]

Bound의 감소계수를 최대화하는 값은

\[\boxed{ \eta=\frac1L }\]

핵심 식 — Batch Variance

Sample Gradient Covariance를

\[\mathbf{\Sigma}\]

라고 하면 i.i.d. 가정 아래

\[\boxed{ \operatorname{Var}( \mathbf g ) = \frac1B \mathbf{\Sigma} }\]

따라서 Batch Size를 \(k\)배 늘리면

\[\boxed{ \operatorname{Var} \rightarrow \frac1k \operatorname{Var} }\]

혼동하기 쉬운 부분 — SGD라는 용어

엄밀한 의미의 Stochastic Gradient Descent는 Sample 하나

\[B=1\]

을 사용하는 형태를 가리킬 수 있다.

실제 Deep Learning에서는 Mini-batch Gradient Descent도 일반적으로 SGD Training이라고 부르는 경우가 많다.

이 Lecture에서는

\[\boxed{ B=1 \text{ or } 1<B\ll N }\]

을 함께 SGD 계열로 다룬다.

혼동하기 쉬운 부분 — Unbiased는 Exact가 아니다

\[\mathbb E[ \mathbf g ] = \nabla L\]

이라고 해서 모든 Mini-batch에서

\[\mathbf g = \nabla L\]

이라는 뜻은 아니다.

각 Step에서는 차이가 존재할 수 있다.

\[\boxed{ \mathbf g = \nabla L + \mathbf{\epsilon} }\]

이고

\[\boxed{ \mathbb E[ \mathbf{\epsilon} ] = 0 }\]

이라는 의미다.

혼동하기 쉬운 부분 — Variance 감소

Batch Size를 키우면 원자료의 i.i.d. Model에서

\[\operatorname{Var}( \mathbf g ) \propto \frac1B\]

로 감소한다.

하지만 이것만으로 Training Speed, Generalization 또는 최적 Learning Rate가 자동으로 결정되는 것은 아니다.

이 Lecture에서의 핵심 수학 결과는

\[\boxed{ B \rightarrow kB \quad\Rightarrow\quad \operatorname{Var}( \mathbf g ) \rightarrow \frac1k \operatorname{Var}( \mathbf g ) }\]

혼동하기 쉬운 부분 — \(\eta<2/L\)

\[\boxed{ \eta<\frac2L }\]

은 원자료의 \(L\)-Smooth Gradient Descent 분석에서 나온 Loss-Reduction 조건이다.

이는 모든 Stochastic Optimizer와 모든 Neural Network에서 동일한 값으로 직접 적용되는 Universal Hyperparameter Rule이라는 뜻은 아니다.

이 Lecture에서는 Gradient Descent의 Step Size와 Curvature의 관계를 이해하기 위한 기본 결과로 사용한다.

정리

Gradient Descent는 Objective의 Negative Gradient 방향으로 Parameter를 이동시킨다.

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \nabla L( \mathbf{\theta}^{(t)} ) }\]

Full-Batch Gradient는 Dataset 전체에서 계산한다.

\[\boxed{ \nabla L = \frac1N \sum_{i=1}^{N} \nabla \ell_i }\]

Mini-batch SGD에서는 크기 \(B\)의 Sample Subset을 사용한다.

\[\boxed{ \mathbf g = \frac1B \sum_{i\in\mathcal B} \nabla \ell_i }\]

적절한 Random Sampling 조건에서는

\[\boxed{ \mathbb E[ \mathbf g ] = \nabla L }\]

이므로 Full Gradient의 Unbiased Estimate로 볼 수 있다.

\(L\)-Smooth Function에서는

\[\boxed{ \| \nabla f(\mathbf x) - \nabla f(\mathbf y) \|_2 \le L \| \mathbf x-\mathbf y \|_2 }\]

이고 Descent Lemma를 통해

\[\boxed{ f( \mathbf{\theta}^{(t+1)} ) \le f( \mathbf{\theta}^{(t)} ) - \eta \left( 1-\frac{L\eta}{2} \right) \| \nabla f \|_2^2 }\]

를 얻는다.

따라서 원자료의 GD Loss-Decrease 조건은

\[\boxed{ 0<\eta<\frac2L }\]

그리고 이 Upper Bound의 감소계수는

\[\boxed{ \eta=\frac1L }\]

에서 최대가 된다.

Mini-batch Gradient의 Covariance는 i.i.d. 가정 아래

\[\boxed{ \operatorname{Var}( \mathbf g ) = \frac1B \mathbf{\Sigma} }\]

따라서 Batch Size가 증가할수록 Gradient Noise가 감소한다.

\[\boxed{ B\uparrow \Rightarrow \text{Gradient Variance}\downarrow }\]

수치 예제에서는

\[f(x,y) = 2x^2+8y^2\]

에 대해

\[\boxed{ \nabla f = \begin{bmatrix} 4x\\ 16y \end{bmatrix} }\]
\[\boxed{ \mathbf H = \begin{bmatrix} 4&0\\ 0&16 \end{bmatrix} }\]

이고

\[\boxed{ L = \lambda_{\max}( \mathbf H ) = 16 }\]

을 얻는다.

따라서

\[\boxed{ \eta<0.125 }\]

이고

\[\eta=\frac1{16}\]

에서 초기점

\[\begin{bmatrix} 4\\ 2 \end{bmatrix}\]

은 한 Step 후

\[\boxed{ \begin{bmatrix} 3\\ 0 \end{bmatrix} }\]

으로 이동한다.

Loss는

\[\boxed{ 64 \rightarrow 18 }\]

로 감소한다.

전체 흐름은 다음과 같다.

\[\boxed{ \text{Objective} \rightarrow \nabla L \rightarrow \text{Gradient Descent} }\]

대규모 Dataset에서는

\[\boxed{ \text{Full Gradient} \rightarrow \text{Mini-batch Gradient Estimate} \rightarrow \text{SGD} }\]

로 확장된다.

Batch Size와 Gradient Noise는

\[\boxed{ B \rightarrow \operatorname{Var}( \mathbf g ) = \frac{\mathbf{\Sigma}}{B} }\]

로 연결된다.

그리고 이후 Optimization Algorithm은

\[\boxed{ \text{SGD} \rightarrow \text{Momentum} \rightarrow \text{Adam / AdamW} }\]

와 연결된다.

정리

Gradient Descent는 \(\theta_{t+1}=\theta_t-\eta\nabla J(\theta_t)\)처럼 목적함수의 gradient 반대 방향으로 parameter를 갱신한다. SGD는 전체 데이터 대신 mini-batch gradient를 사용해 계산량을 낮추지만 추정 잡음이 생기므로 learning rate와 batch 구성에 따라 수렴 속도와 변동성이 달라진다.
