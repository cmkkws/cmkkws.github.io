DL-17 — Pretraining, Fine-Tuning & Supervised Fine-Tuning

사전학습과 지도 미세조정의 목적함수와 학습 범위를 비교한다.

ML·딥러닝 · DL-17업데이트 2026.09.27

개념

학습 목표 — 사전학습과 지침·응답 SFT의 조건부 목적을 구별한다. Prompt loss masking, 정규화 방식, catastrophic forgetting, KL·LoRA의 정확한 역할을 유도한다. 원자료의 3단어·2응답토큰 예제를 검산한다.

학습 단계의 큰 흐름 — 사전학습은 대규모 텍스트의 다음 토큰 예측으로 기본 가중치를 얻는다. Fine-tuning은 이 가중치에서 별도 데이터 목적을 최적화하는 넓은 범주이며 SFT는 목표 응답을 지도 신호로 쓰는 한 방식이다. 이후 선호 최적화나 강화학습을 더할 수도 있다.

Self-supervision의 뜻 — 언어 모델은 텍스트에서 다음 토큰을 학습 표적으로 자동 추출한다. 사람이 각 문장의 정답 클래스를 따로 붙이지 않아도 된다는 뜻이지, 모든 데이터 품질 문제가 자동으로 해결된다는 뜻은 아니다.

분포 학습의 범위 — 원자료의 “\(P(X)\)를 학습한다”는 말은 모델 가족과 자료 분포 아래에서 시퀀스 우도를 맞춘다는 목표다. 유한 데이터·제한된 모델에서는 참 분포를 정확히 복원한다는 정리가 아니다.

Fine-tuning과 SFT의 데이터 — SFT 데이터 \(\mathcal D_{\rm SFT}=\{(u_i,v_i)\}_{i=1}^{M}\)에서 \(u_i\)는 프롬프트/지시문, \(v_i=(v_{i,1},\ldots,v_{i,T_i})\)는 지도 응답이다. 원자료의 \(x_i,y_i\)와 같은 역할이며 사전학습 토큰열 \(x_{1:T}\)와 인덱스를 구분한다.

데이터 품질과 목적 — 사전학습은 broad distribution의 예측 능력을, SFT는 지정된 응답 분포와 형식의 조건부 예측을 목표로 한다. SFT 데이터가 오류나 편향을 담으면 모델도 그것을 배울 수 있다. 형식 적응만 일어난다고 한정할 수 없다.

표기·차원

시퀀스와 logit 표기 — \(x_{1:T}\)를 토큰열, 어휘 크기를 \(V\), \(\theta\)를 모델 파라미터, \(z_t\in\mathbb R^V\)를 \(x_{<t}\)로부터 만든 logit이라고 하자.

\[p_\theta(x_t\mid x_{<t}) =\operatorname{softmax}(z_t)_{x_t}.\]

시작 토큰이나 빈 prefix의 처리는 구현에서 정한다.

Loss mask의 정의 — 연결된 token열의 목표 위치에 \(m_t\in\{0,1\}\)을 붙이면

\[\mathcal L_{\rm masked} =-\sum_t m_t\log p_\theta(s_t\mid s_{<t}).\]

일반적인 응답 전용 SFT에서는 prompt 예측 위치에 \(m_t=0\), 응답 예측 위치에 \(m_t=1\)이다. Segment boundary, EOS, 여러 turn에서는 mask 범위를 명시한다.

인덱스 이동 — Decoder 출력 위치 \(t-1\)의 logit이 목표 \(s_t\)를 예측하는 convention이 많다. Shifted logit과 label을 맞춰야 첫 응답 token을 누락하거나 prompt 마지막 token을 목표에 잘못 넣지 않는다.

Masked 평균과 경계 — \(n_{\rm eff}=\sum_t m_t>0\)이면 token 평균은 \(\mathcal L_{\rm masked}/n_{\rm eff}\)다. 유효 응답 token이 없으면 분모가 0이므로 배치를 제외하거나 별도 처리해야 한다.

구현의 ignore label — 일부 PyTorch-style cross-entropy에서 무시할 label에 -100을 넣는다. 이는 loss의 목표 label에 넣는 sentinel이며 입력 token id로 모델에 보내는 값이 아니다. 구체적 trainer의 masking과 shift convention은 설정에 따라 확인한다.

LoRA의 shape — 한 가중치 \(W_0\in\mathbb R^{d_{\rm out}\times d_{\rm in}}\)에 대한 LoRA 업데이트는

\[W_{\rm eff} =W_0+\frac{\alpha_{\rm L}}{r}BA,\quad A\in\mathbb R^{r\times d_{\rm in}},\quad B\in\mathbb R^{d_{\rm out}\times r}.\]

\(r\ll\min(d_{\rm in},d_{\rm out})\)면 추가 학습 행렬 수가 적다.

Rank 제약의 뜻 — \(\operatorname{rank}(BA)\le r\)이지만 여러 layer와 비선형 조합의 전체 기능 변화가 낮은 차원에서만 발생한다는 뜻은 아니다. \(\alpha_{\rm L}\)은 LoRA scaling 계수로 SFT 손실 가중치와 구별한다.

핵심 연산

Chain rule에 따른 시퀀스 우도 — 확률의 chain rule로

\[p_\theta(x_{1:T}) =\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t}).\]

이 분해에 독립성 가정은 없다. 인과적 mask는 미래 토큰을 현재 예측 위치에 노출하지 않도록 한다.

사전학습의 NLL — 원자료의 한 시퀀스 손실은

\[\mathcal L_{\rm PT}(\theta;x_{1:T}) =-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).\]

여러 문서라면 각각 합하거나 유효 토큰 수로 평균한다. 원자료의 \(T\)는 한 문서 길이이며 말뭉치의 모든 토큰 수와 혼동하지 않는다.

NLL과 Cross-Entropy — 정답 token one-hot target \(e_{x_t}\)에 대한 cross-entropy가 \(-\log p_\theta(x_t\mid x_{<t})\)다. 이것은 한 관측의 log-loss이고, 모델의 출력이 참 생성 분포와 같다고 보장하지 않는다.

Per-token 평균 — 길이가 다른 예시를 묶을 때는

\[\bar{\mathcal L}_{\rm PT} =\frac{\sum_i\sum_{t\in M_i}-\log p_\theta(x_{i,t}\mid x_{i,<t})} {\sum_i|M_i|}\]

처럼 유효 토큰 집합 \(M_i\)로 나눌 수 있다. 문서별 평균을 다시 평균하면 긴 문서의 가중치가 달라진다.

조건부 응답 우도 — Teacher forcing에서는 정답 응답 prefix를 조건으로 각 token을 예측한다.

\[p_\theta(v_i\mid u_i) =\prod_{t=1}^{T_i}p_\theta(v_{i,t}\mid u_i,v_{i,<t}).\]

생성 시에는 실제 생성 token을 조건으로 하므로 학습과 추론의 prefix 분포가 다를 수 있다.

기본 SFT 손실 —

\[\mathcal L_{\rm SFT}(\theta) =-\sum_{i=1}^{M}\sum_{t=1}^{T_i} \log p_\theta(v_{i,t}\mid u_i,v_{i,<t}).\]

프롬프트 토큰에 대한 예측 손실을 제거한 응답 전용 목적이다. 흔한 선택이지만 모든 fine-tuning의 필수 조건은 아니다.

Prompt를 보는 것과 평가하는 것 — 프롬프트를 loss에서 제외해도 응답 token의 logit은 프롬프트 내용에 조건화된다. “마스킹하면 prompt를 모델이 읽지 않는다”는 해석은 틀리다. Causal attention은 앞선 프롬프트 표현을 계속 사용한다.

사전학습 이후의 초기점 — \(\theta_{\rm PT}\)는 새 목적함수를 최적화할 때의 초기점이다. Random initialization보다 빠른 적응과 좋은 성능은 자주 관찰되지만 데이터·아키텍처·최적화 조건에 의존한다.

핵심 식 —

\[\begin{aligned} \mathcal L_{\rm PT}&=-\sum_t\log p_\theta(x_t\mid x_{<t}),\\ \mathcal L_{\rm SFT}&=-\sum_i\sum_{t=1}^{T_i} \log p_\theta(v_{i,t}\mid u_i,v_{i,<t}),\\ \bar{\mathcal L}_{\rm SFT}&= \frac{\sum_i\sum_t-\log p_\theta(v_{i,t}\mid u_i,v_{i,<t})} {\sum_i T_i},\\ W_{\rm eff}&=W_0+\frac{\alpha_{\rm L}}rBA. \end{aligned}\]

성질·유도

엔트로피 관계의 올바른 범위 — 참 분포에서는 \(H(Y\mid X)\le H(Y)\)가 성립한다. 하지만 사전학습이 “\(H(X)\) 자체를 낮춘다”는 원자료 문장은 부정확하다. 참 데이터의 엔트로피는 모델 파라미터 업데이트만으로 바뀌지 않는다.

Manifold 비유의 한계 — 파라미터를 넓은 데이터 매니폴드에서 저차원 정렬 하위매니폴드로 사영한다는 서술은 비유다. 일반 네트워크에 그런 매니폴드가 식별되거나 SFT 업데이트가 실제 직교 사영임을 보장하는 수식은 제시되지 않았다.

Hessian 국소 전개 — 두 번 미분 가능한 손실 \(\mathcal L\)의 작은 이동 \(\Delta\)에 대해

\[\mathcal L(\theta+\Delta) =\mathcal L(\theta)+\nabla\mathcal L(\theta)^T\Delta +\frac12\Delta^TH(\theta)\Delta+o(\|\Delta\|^2).\]

이는 국소 근사이지 학습 전 과정이나 일반화의 증명이 아니다.

곡률 해석의 조건 — 고유값은 매개변수화와 측정 위치에 의존한다. \(\lambda_{\max}(H)\)가 작다는 것만으로 모든 방향의 곡률이 작거나 일반화가 보장된다고 할 수 없다. SFT도 사전학습 Hessian의 주성분을 반드시 보존하지 않는다.

Flat minimum 주장 검토 — 원자료의 “사전학습은 평탄한 최적점을 형성하며 일반화를 보장한다”는 강한 진술을 제거한다. 평탄성, loss landscape, 재매개변수화와 데이터 분포 사이 관계는 설정을 고정하고 경험적으로 검토해야 한다.

Catastrophic forgetting — 특정 작업에 맞춰 업데이트한 뒤 이전 작업 또는 범용 능력의 성능이 떨어지는 현상이다. 매개변수 변화 자체가 forgetting은 아니며 이전 분포의 평가 지표를 함께 측정한다.

이동 제약의 한 방식 — 사전학습 점 근처로 제한하려면

\[\mathcal L_{\rm SFT}(\theta) +\frac{\lambda}{2}\|\theta-\theta_{\rm PT}\|_2^2\]

처럼 명시적 penalty를 추가할 수 있다. 모든 SFT에서 쓰는 것은 아니다. 변화량이 작아도 기능 변화가 작다는 보장은 별도로 필요하다.

Reference KL의 정의 — 프롬프트와 prefix의 평가 분포 \(\rho(u,c)\)를 정하면 한 형태는

\[R_{\rm KL}(\theta) =\mathbb E_{(u,c)\sim\rho} \left[D_{\rm KL}\bigl(p_{\theta_{\rm PT}}(\cdot\mid u,c) \parallel p_\theta(\cdot\mid u,c)\bigr)\right].\]

원자료의 조건부 분포 KL을 계산하려면 \(X\)의 분포, sequence-level 또는 token-level divergence, 방향을 정해야 한다.

KL 방향과 지원 집합 — KL은 비대칭이다. Reference가 양의 확률을 준 지점에서 현재 모델의 확률이 0이면 forward KL이 발산할 수 있다. 큰 KL penalty가 출력 이동을 억제할 수는 있지만 모든 이전 능력을 보존하지 않는다.

Reference 선택 — \(\beta>0\)일 때

\[\mathcal L_{\rm total}=\mathcal L_{\rm SFT}+\beta R_{\rm KL}\]

는 가능한 설계다. 언제나 사전학습 모델을 reference로 쓰거나 SFT 전체에서 KL을 사용해야 하는 것은 아니다. 지나치면 새 작업 적응을 방해한다.

Frozen base와 forgetting — \(W_0\)를 freeze하더라도 추론 때는 \(W_0+(\alpha_{\rm L}/r)BA\)로 계산한다. 새 업데이트가 예전 입력의 출력을 바꿀 수 있으므로 파괴적 망각이 대수적으로 차단되지 않는다. Adapter를 제거하면 원래 base로 돌아갈 수 있는 것은 별개 장점이다.

Full fine-tuning과 PEFT — 많은 파라미터를 업데이트하는 full fine-tuning과 LoRA처럼 일부 추가 파라미터를 학습하는 PEFT를 구별한다. 우열은 데이터, 랭크, 대상 layer, 예산과 평가 과제에 달려 있다.

오개념 교정 — 이론 — 조건부 엔트로피와 모델 NLL, 참 데이터 엔트로피를 구별한다. 작은 Hessian 고유값이나 평탄한 손실 표면에서 일반화가 자동 증명되지 않는다. LoRA의 낮은 rank는 추론 행동의 보존 보장이 아니다.

오개념 교정 — 구현 — Prompt masking은 조건 정보를 지우지 않는다. Ignore sentinel은 입력 token과 다르다. 평균 손실의 분모, teacher forcing, shift convention을 함께 확인해야 예제를 재현할 수 있다.

사전학습과 SFT는 모두 조건부 다음 토큰 NLL을 사용할 수 있지만 데이터 분포와 loss mask가 다르다. 예제의 두 CE는 약 \(0.40760596\), \(0.30635571\)이고 응답 평균은 \(0.35698084\)다. KL 정규화와 LoRA는 가능한 forgetting 대응이며 어느 쪽도 이전 능력 보존의 보편적 증명은 아니다.

예제·적용

예제의 어휘와 목표 — 원자료처럼 \(V=\{w_1,w_2,w_3\}\), prompt token 하나 \(u=x_1\), 응답 두 개 \(v_1=w_1\), \(v_2=w_2\)다. 첫 응답 예측 logit은 \((2,1,0)\), 두 번째는 \((0.5,2.5,1)\)이다. 별도의 prompt 예측 손실은 계산하지 않는다.

첫 위치의 지수합 —

\[Z_1=e^2+e^1+e^0 \approx7.3890561+2.7182818+1 =11.1073379.\]

원자료의 네 자리 중간값으로는 \(11.1074\)다.

첫 위치의 softmax —

\[p_1=\frac{(e^2,e,1)}{Z_1} \approx(0.66524096,\ 0.24472847,\ 0.09003057).\]

세 확률의 합은 1이다.

첫 응답 토큰 손실 — 목표 \(w_1\)에 대해 안정한 log-sum-exp 표현을 쓰면

\[\ell_1=-\log p_1(w_1) =\log Z_1-2 \approx0.4076059644.\]

둘째 위치의 지수합 —

\[Z_2=e^{0.5}+e^{2.5}+e^1 \approx1.6487213+12.1824940+2.7182818 =16.5494971.\]

둘째 위치의 softmax —

\[p_2 =\frac{(e^{0.5},e^{2.5},e)}{Z_2} \approx(0.09962365,\ 0.73612472,\ 0.16425163).\]

조건부 확률의 문맥은 \((u,v_1)\)이다.

둘째 응답 토큰 손실 —

\[\ell_2=-\log p_2(w_2) =\log Z_2-2.5 \approx0.3063557122.\]

원 예제의 평균 손실 — 응답 토큰 둘에 대한 평균은

\[\bar{\mathcal L}_{\rm SFT} =\frac{\ell_1+\ell_2}{2} \approx0.3569808383.\]

원자료의 \(0.3570\)은 네 자리 반올림으로 맞다. 합 손실은 \(0.7139616767\)로 평균과 구분한다.

첫 token의 gradient — 정답 one-hot \(e_{w_1}\)에 대해 \(\partial\ell_1/\partial z_1=p_1-e_{w_1}\)다. Prompt mask는 앞선 문맥 입력을 통과하는 gradient 경로 자체를 모두 막는 연산이 아니다.

평균 gradient의 스케일 — 두 token 평균이면 각 CE의 logit gradient 앞에 \(1/2\)가 붙는다. 합, per-sequence 평균, per-token 평균은 길이가 다른 데이터에서 sample weighting도 달리 만든다.

제품 흐름의 선택 — 사전학습 base 모델에 SFT를 더하고 필요하면 선호 데이터나 reward를 이용한 단계를 거칠 수 있다. RLHF, DPO, GRPO의 순서·사용 여부는 프로젝트마다 다르며 하나의 필수 파이프라인은 아니다.

Preference learning과의 접점 — SFT의 지도 응답 NLL과 선호쌍을 이용한 DPO는 다른 데이터와 손실을 쓴다. PS-15의 Bradley–Terry·DPO 해석에서는 상대적 응답 선호를 별도로 모델링한다.

LIMA 관찰의 범위 — 원자료의 LIMA 관련 주장은 고품질의 작은 지침 데이터로 일부 상호작용 능력을 이끌어낼 수 있다는 가설·실험 관찰로 설명한다. “모든 지식은 사전학습에서 완료”되거나 “정확히 1,000개면 언제나 충분”하다는 정리는 아니다.

예시 규모의 비교 조건 — 수만 개 SFT 예시와 1,000개의 정제 예시를 비교하려면 base 모델, 중복, 평가 과제와 데이터 품질을 맞춰야 한다. 라벨 없는 사전학습 자료와 지침 데이터는 목적이 다르므로 개수만으로 우열을 결론 내리지 않는다.

DL-16의 ICL과 연결 — SFT는 \(\theta_{\rm PT}\to\theta_{\rm SFT}\)의 실제 optimizer 갱신이다. ICL은 추론 시 고정된 \(\theta\) 아래 예시 프롬프트에 조건화한다. SFT 모델도 few-shot 프롬프트에 조건화할 수 있다.

DL-15의 KD와 연결 — SFT의 응답 target은 대개 hard token이며, KD는 teacher의 soft distribution 또는 생성 시퀀스 등 추가 신호를 쓴다. Teacher가 만든 응답을 hard target으로 쓰는 경우 두 절차가 겹칠 수 있다.

학습 점검 —

  1. Prompt token을 loss에서 제외해도 왜 첫 응답 예측에 영향을 주는가?
  2. 응답 길이가 다를 때 sequence 평균과 token 평균의 weighting은 어떻게 다른가?
  3. Frozen LoRA base가 있어도 adapter를 켠 모델은 이전 작업에서 왜 나빠질 수 있는가?
  4. 원자료의 \(0.3570\)은 합 손실인가, 토큰 평균인가?

정리

Pretraining과 SFT는 다음 token 예측을 공유할 수 있지만, 전자는 대규모 텍스트 분포를 학습하고 후자는 prompt에 대한 응답 token에 loss를 적용한다. Sequence 길이별 평균 방식, loss mask, KL regularization과 LoRA의 역할을 구분해야 하며 이 기법들은 forgetting을 줄이는 선택지이지 이전 능력 보존의 보장은 아니다.
