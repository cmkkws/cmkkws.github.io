IT-06 — Entropy Chain Rule

Entropy Chain Rule의 전개와 결합·조건부 엔트로피의 관계를 정리한다.

정보이론 · IT-06업데이트 2026.09.18
  • #Entropy Chain Rule
  • #Joint Entropy
  • #Conditional Entropy
  • #Information Theory

개념

Entropy Chain Rule여러 개의 이산 확률변수 \(X_1,X_2,\dots,X_n\) 을 생각한다.

전체 Random Vector를 \(X_{1:n} = (X_1,X_2,\dots,X_n)\) 라고 하자.

이 변수들의 Joint Entropy는 \(H(X_1,X_2,\dots,X_n)\)이다.

Entropy Chain Rule은 이 Joint Entropy를 각 변수의 순차적인 Conditional Entropy의 합으로 분해한다.

\[\boxed{ H(X_1,\dots,X_n) = \sum_{i=1}^{n} H( X_i\mid X_{<i} ) }\]

Chain Rule의 직관전체 시스템의 불확실성을 한꺼번에 측정하는 대신 순차적으로 생각한다.

먼저 \(X_1\) 을 알기 위해 필요한 평균 정보량은 \(H(X_1)\)이다.

그다음 이미 \(X_1\)을 알고 있다고 할 때 \(X_2\)를 추가로 알기 위해 필요한 평균 정보량은 \(H(X_2\mid X_1)\)이다.

그다음 \(X_1,X_2\) 를 모두 알고 있을 때 \(X_3\)에 남아 있는 불확실성은 \(H(X_3\mid X_1,X_2)\)이다.

이 과정을 계속 더한다.

Sequential Information Decomposition따라서 Joint Entropy는 total uncertainty = first uncertainty + additional uncertainty at each step 로 해석할 수 있다.

수식으로는 다음과 같다.

\[\boxed{ H(X_{1:n}) = H(X_1) + \sum_{i=2}^{n} H(X_i\mid X_{<i}) }\]

표기·차원

Previous Variables Notation다음을 정의한다.

\[\boxed{ X_{<i} = (X_1,\dots,X_{i-1}) }\]

따라서 \(X_{<1} = \varnothing\) 으로 생각할 수 있고:

\[\boxed{ H(X_1\mid X_{<1}) = H(X_1) }\]

그러므로 Chain Rule을 완전히 전개하면 다음과 같다.

\[\boxed{ H(X_1,\dots,X_n) = H(X_1) + H(X_2\mid X_1) + \cdots + H(X_n\mid X_1,\dots,X_{n-1}) }\]

핵심 연산

Probability Chain Rule확률론에서 Joint Probability는 Chain Rule에 의해 \(p(x_1,\dots,x_n) = \prod_{i=1}^{n} p( x_i\mid x_{<i} )\) 로 분해된다.

완전히 전개하면 다음과 같다.

\[\boxed{ p(x_1,\dots,x_n) = p(x_1) p(x_2\mid x_1) p(x_3\mid x_1,x_2) \cdots p(x_n\mid x_{<n}) }\]

Probability와 Entropy의 대칭성Probability Chain Rule은 곱셈이다.

\[\boxed{ p(x_{1:n}) = \prod_i p(x_i\mid x_{<i}) }\]

여기에 Negative Log를 적용하면 곱셈이 덧셈으로 변한다.

\[\boxed{ -\log p(x_{1:n}) = -\sum_i \log p(x_i\mid x_{<i}) }\]

그리고 Expectation을 취하면 Entropy Chain Rule이 된다.

\[\boxed{ H(X_{1:n}) = \sum_i H(X_i\mid X_{<i}) }\]

Self-Information Chain Rule특정 Sequence \(x_{1:n} = (x_1,\dots,x_n)\) 의 Self-Information은 다음과 같다.

\[\boxed{ I(x_{1:n}) = -\log p(x_{1:n}) }\]

Probability Chain Rule을 사용하면 다음과 같다.

\[\begin{aligned} I(x_{1:n}) &= -\log \prod_{i=1}^{n} p(x_i\mid x_{<i})\\ &= -\sum_{i=1}^{n} \log p(x_i\mid x_{<i}) \end{aligned}\]

Conditional Self-Information각 항을 \(I( x_i\mid x_{<i} ) = -\log p( x_i\mid x_{<i} )\) 라고 하면 다음과 같다.

\[\boxed{ I(x_{1:n}) = \sum_{i=1}^{n} I( x_i\mid x_{<i} ) }\]

즉 Sequence 하나의 정보량도 단계별 Conditional Information의 합으로 분해된다.

Expectation을 취하면전체 Joint Distribution에 대해 Expectation을 취한다.

\[\mathbb E[ I(X_{1:n}) ] = \mathbb E \left[ \sum_{i=1}^{n} I( X_i\mid X_{<i} ) \right]\]

Expectation의 선형성에 의해:

\[= \sum_{i=1}^{n} \mathbb E[ I( X_i\mid X_{<i} ) ]\]

Entropy Chain Rule 도출정의에 의해 \(\mathbb E[ I(X_{1:n}) ] = H(X_{1:n})\) 이고:

\[\mathbb E[ I( X_i\mid X_{<i} ) ] = H( X_i\mid X_{<i} )\]

따라서 \(H(X_{1:n}) = \sum_{i=1}^{n} H( X_i\mid X_{<i} )\) 를 얻는다.

2변수 Chain Rule먼저 두 변수 \(X,Y\) 에 대해 증명한다.

목표는 \(H(X,Y) = H(X) + H(Y\mid X)\) 임을 보이는 것이다.

Joint Entropy 정의Joint Entropy는 다음과 같다.

\[\boxed{ H(X,Y) = -\sum_x\sum_y p(x,y) \log_2p(x,y) }\]

Joint Probability 분해조건부 확률의 Product Rule을 사용하면 다음과 같다.

\[\boxed{ p(x,y) = p(x)p(y\mid x) }\]

이를 Joint Entropy에 대입한다.

\[H(X,Y) = -\sum_x\sum_y p(x,y) \log_2 [ p(x)p(y\mid x) ]\]

3변수 Chain Rule세 변수 \(X_1,X_2,X_3\) 에 대해 Chain Rule은 다음과 같다.

\[\boxed{ H(X_1,X_2,X_3) = H(X_1) + H(X_2\mid X_1) + H(X_3\mid X_1,X_2) }\]

\(n\)변수 일반식동일한 구조를 반복하면 다음과 같다.

\[\boxed{ H(X_1,\dots,X_n) = H(X_1) + H(X_2\mid X_1) + \cdots + H(X_n\mid X_1,\dots,X_{n-1}) }\]

압축하면 다음과 같다.

\[\boxed{ H(X_{1:n}) = \sum_{i=1}^{n} H(X_i\mid X_{<i}) }\]

핵심 식 — Probability Chain Rule

\[\boxed{ P( X_{1:n} ) = \prod_{i=1}^{n} P( X_i\mid X_{<i} ) }\]

핵심 식 — Information Chain Rule

\[\boxed{ -\log P( X_{1:n} ) = \sum_{i=1}^{n} -\log P( X_i\mid X_{<i} ) }\]

핵심 식 — Entropy Chain Rule

\[\boxed{ H( X_{1:n} ) = \sum_{i=1}^{n} H( X_i\mid X_{<i} ) }\]

완전히 전개하면 다음과 같다.

\[\boxed{ H(X_1,\dots,X_n) = H(X_1) + H(X_2\mid X_1) + \cdots + H(X_n\mid X_{1:n-1}) }\]

핵심 식 — Two Variables\(H(X,Y) = H(X) + H(Y\mid X)\) 이고:

\[\boxed{ H(X,Y) = H(Y) + H(X\mid Y) }\]

핵심 식 — Independence독립이면 다음과 같다.

\[\boxed{ H(X_i\mid X_{<i}) = H(X_i) }\]

따라서 다음과 같다.

\[\boxed{ H(X_{1:n}) = \sum_{i=1}^{n} H(X_i) }\]

핵심 식 — Autoregressive LLMSequence Probability는 다음과 같다.

\[\boxed{ Q_\theta( y_{1:T} ) = \prod_{t=1}^{T} Q_\theta( y_t\mid y_{<t} ) }\]

Sequence NLL은 다음과 같다.

\[\boxed{ -\log Q_\theta( y_{1:T} ) = \sum_{t=1}^{T} -\log Q_\theta( y_t\mid y_{<t} ) }\]

핵심 식 — Expected LLM Loss

\[\boxed{ \mathcal L_{\mathrm{LM}}(\theta) = \sum_{t=1}^{T} \mathbb E_{P_{\mathrm{data}}} \left[ -\log Q_\theta( Y_t\mid Y_{<t} ) \right] }\]

즉 전체 Language Modeling Loss가 Position별 Conditional Cross-Entropy의 합으로 분해된다.

핵심 식 — PerplexityBase 2 Cross-Entropy에서는 다음과 같다.

\[\boxed{ \mathrm{PPL} = 2^{ \text{average token cross-entropy} } }\]

Natural Log NLL에서는 다음과 같다.

\[\boxed{ \mathrm{PPL} = e^{ \text{average token NLL} } }\]

성질·유도

Logarithm 분해Logarithm의 성질 \(\log(ab) = \log a+\log b\) 를 사용한다.

따라서 다음과 같다.

\[\begin{aligned} H(X,Y) &= -\sum_x\sum_y p(x,y) \log_2p(x)\\ &\quad- \sum_x\sum_y p(x,y) \log_2p(y\mid x) \end{aligned}\]

첫 번째 항첫 번째 항은 다음과 같다.

\[-\sum_x\sum_y p(x,y) \log_2p(x)\]

\(\log_2p(x)\)는 \(y\)에 의존하지 않으므로 다음과 같이 쓴다.

\[= -\sum_x \left[ \sum_y p(x,y) \right] \log_2p(x)\]

MarginalizationMarginal Probability에 의해:

\[\boxed{ \sum_y p(x,y) = p(x) }\]

따라서 첫 번째 항은 다음과 같다.

\[\boxed{ -\sum_x p(x)\log_2p(x) = H(X) }\]

두 번째 항두 번째 항은 다음과 같다.

\[-\sum_x\sum_y p(x,y) \log_2p(y\mid x)\]

이는 Conditional Entropy 정의와 정확히 같다.

\[\boxed{ -\sum_x\sum_y p(x,y) \log_2p(y\mid x) = H(Y\mid X) }\]

2변수 Chain Rule 완성따라서 다음과 같다.

\[\boxed{ H(X,Y) = H(X) + H(Y\mid X) }\]

순서를 반대로 하면Joint Probability를 \(p(x,y) = p(y)p(x\mid y)\) 로 분해할 수도 있다.

같은 과정을 적용하면 다음과 같다.

\[\boxed{ H(X,Y) = H(Y) + H(X\mid Y) }\]

Symmetric Identity따라서 다음과 같다.

\[\boxed{ H(X) + H(Y\mid X) = H(Y) + H(X\mid Y) }\]

Joint Entropy 자체는 변수의 순서와 무관하지만 각 Conditional Entropy Term의 형태는 순서에 따라 달라진다.

IT-05와 연결IT-05에서 \(H(Y\mid X) = H(Y)-I(X;Y)\) 를 배웠다.

이를 \(H(X,Y) = H(X)+H(Y\mid X)\) 에 대입하면 다음과 같다.

\[\boxed{ H(X,Y) = H(X) + H(Y) - I(X;Y) }\]

Joint Entropy와 Mutual Information따라서 다음과 같다.

\[\boxed{ I(X;Y) = H(X) + H(Y) - H(X,Y) }\]

즉 Mutual Information은 두 Marginal Entropy를 단순히 합했을 때 겹쳐 계산되는 정보량으로 해석할 수 있다.

Independence\(X,Y\)가 독립이면 다음과 같다.

\[H(Y\mid X) = H(Y)\]

따라서 Chain Rule은 다음과 같다.

\[\boxed{ H(X,Y) = H(X)+H(Y) }\]

Dependence일반적으로는 \(H(Y\mid X) \le H(Y)\) 따라서 \(H(X,Y) = H(X)+H(Y\mid X)\) 에서 \(H(X,Y) \le H(X)+H(Y)\) 를 바로 얻는다.

즉 IT-04의 Subadditivity가 Chain Rule에서도 자연스럽게 나온다.

3변수 유도먼저 \((X_1,X_2)\) 를 하나의 Random Vector로 본다.

2변수 Chain Rule에 의해:

\[\boxed{ H(X_1,X_2,X_3) = H(X_1,X_2) + H(X_3\mid X_1,X_2) }\]

앞부분 다시 분해다시:

\[\boxed{ H(X_1,X_2) = H(X_1) + H(X_2\mid X_1) }\]

따라서 \(H(X_1,X_2,X_3) = H(X_1) + H(X_2\mid X_1) + H(X_3\mid X_1,X_2)\) 를 얻는다.

Mathematical Induction원자료에서는 이 일반식을 수학적 귀납법으로도 증명한다.

구조는 다음과 같다.

  1. Base Step
  2. Inductive Hypothesis
  3. Inductive Step

이 식의 세 단계다.

Base Step\(n=2\)일 때 \(H(X_1,X_2) = H(X_1) + H(X_2\mid X_1)\) 임을 이미 증명했다.

따라서 Base Step이 성립한다.

Inductive Hypothesis어떤 자연수 \(k\ge2\) 에 대해 \(H(X_1,\dots,X_k) = \sum_{i=1}^{k} H( X_i\mid X_{<i} )\) 가 성립한다고 가정한다.

\(k+1\)개 변수이제 \(H(X_1,\dots,X_k,X_{k+1})\) 를 생각한다.

첫 \(k\)개의 변수들을 하나의 Random Vector \(Y = (X_1,\dots,X_k)\) 로 두고 \(Z=X_{k+1}\) 라고 하자.

2변수 Chain Rule 적용그러면:

\[H(X_1,\dots,X_k,X_{k+1}) = H(Y,Z)\]

2변수 Chain Rule을 적용하면 다음과 같다.

\[\boxed{ H(Y,Z) = H(Y) + H(Z\mid Y) }\]

First Term\(Y=(X_1,\dots,X_k)\)이므로 다음과 같이 쓴다.

\[H(Y) = H(X_1,\dots,X_k)\]

귀납 가정을 사용하면 다음과 같다.

\[\boxed{ H(Y) = \sum_{i=1}^{k} H(X_i\mid X_{<i}) }\]

Second Term\(Z=X_{k+1}\) 이고 \(Y=(X_1,\dots,X_k)\) 이므로 다음과 같이 쓴다.

\[\boxed{ H(Z\mid Y) = H( X_{k+1} \mid X_1,\dots,X_k ) }\]

즉 다음과 같다.

\[\boxed{ H(Z\mid Y) = H( X_{k+1} \mid X_{<k+1} ) }\]

Inductive Step두 결과를 더하면 다음과 같다.

\[\begin{aligned} &H(X_1,\dots,X_k,X_{k+1})\\ &= \sum_{i=1}^{k} H( X_i\mid X_{<i} ) + H( X_{k+1}\mid X_{<k+1} ) \end{aligned}\]

따라서 다음과 같다.

\[\boxed{ H(X_1,\dots,X_{k+1}) = \sum_{i=1}^{k+1} H( X_i\mid X_{<i} ) }\]

Induction ConclusionBase Step과 Inductive Step이 모두 성립하므로 모든 \(n\ge2\) 에 대해 \(H(X_{1:n}) = \sum_{i=1}^{n} H( X_i\mid X_{<i} )\) 가 성립한다.

Chain Rule은 Independence를 요구하지 않는다중요하게도 Entropy Chain Rule은 \(X_1,\dots,X_n\)이다.

이 서로 독립이어야만 성립하는 식이 아니다.

임의의 Joint Distribution에 대해 \(H(X_{1:n}) = \sum_i H(X_i\mid X_{<i})\) 가 성립한다.

Independent Special Case만약 모든 \(X_i\)가 Mutual Independence를 만족한다면:

\[p(x_i\mid x_{<i}) = p(x_i)\]

따라서 \(H(X_i\mid X_{<i}) = H(X_i)\) 이고:

\[\boxed{ H(X_{1:n}) = \sum_{i=1}^{n} H(X_i) }\]

Dependent Case일반적인 Dependent Sequence에서는 \(H(X_i\mid X_{<i})\) 가 Marginal Entropy \(H(X_i)\) 보다 작거나 같다.

따라서 다음과 같다.

\[\boxed{ H(X_{1:n}) \le \sum_{i=1}^{n} H(X_i) }\]

이는 다변수 Subadditivity와 연결된다.

혼동하기 쉬운 부분

  • Chain Rule과 Independence:Chain Rule을 적용하기 위해 Independence를 가정할 필요가 없다.

    \(H(X_{1:n}) = \sum_i H(X_i\mid X_{<i})\) 는 임의의 Joint Distribution에 대해 성립한다.

    독립성은 각 Conditional Entropy를 Marginal Entropy로 단순화할 때만 필요하다.

  • Joint Entropy와 Entropy Sum:일반적으로 다음과 같이 쓴다.

    \[\boxed{ H(X_{1:n}) \neq \sum_iH(X_i) }\]

    정확한 일반식은 다음과 같다.

    \[\boxed{ H(X_{1:n}) = \sum_i H(X_i\mid X_{<i}) }\]

  • 각 항의 크기:Chain Rule은 \(H(X_1), \quad H(X_2\mid X_1), \quad H(X_3\mid X_1,X_2)\) 가 반드시 순서대로 감소한다고 말하지 않는다.

    서로 다른 Target Variable을 측정하기 때문이다.

  • True Entropy vs Model Loss:\(H_P(Y_{1:T})\) 는 True Distribution \(P\) 자체의 Entropy다.

    반면 실제 Language Model의 Expected Loss는 \(\mathbb E_P[ -\log Q_\theta(Y_{1:T}) ]\)이다.

    두 Distribution이 다르면 후자는 Cross-Entropy다.

  • PPL:원자료의 \(\mathrm{PPL} = 2^{ H(Y_{1:T})/T }\) 는 True Entropy를 사용한다면 이상적인 Distribution 관점의 표현이다.

    실제 Model PPL은 일반적으로 Model Cross-Entropy를 사용한다.

    \[\boxed{ \mathrm{PPL} = 2^{ \text{average model cross-entropy} } }\]

    Entropy Chain Rule은 여러 Random Variable의 Joint Entropy를 단계별 Conditional Entropy의 합으로 분해한다.

    \[\boxed{ H(X_1,\dots,X_n) = \sum_{i=1}^{n} H( X_i\mid X_{<i} ) }\]

    두 변수에서는 다음과 같다.

    \[\boxed{ H(X,Y) = H(X) + H(Y\mid X) }\]

    이는 Joint Probability의 Chain Rule \(p(x,y) = p(x)p(y\mid x)\) 에서 직접 유도된다.

    \[\begin{aligned} H(X,Y) &= -\sum_{x,y} p(x,y) \log [ p(x)p(y\mid x) ]\\ &= H(X) + H(Y\mid X) \end{aligned}\]

    \(n\)개의 변수에 대해서는 2변수 Chain Rule을 반복하거나 Mathematical Induction을 사용하여 \(H(X_{1:n}) = H(X_1) + H(X_2\mid X_1) + \cdots + H(X_n\mid X_{<n})\) 을 얻는다.

    원자료의 수치 예제에서는 다음과 같다.

    \[H(X_1)=2.0\]
    \[H(X_2\mid X_1)=1.2\]
    \[H(X_3\mid X_1,X_2)=0.5\]

    bits이므로 다음과 같이 쓴다.

    \[\boxed{ H(X_1,X_2,X_3) = 2.0+1.2+0.5 = 3.7\text{ bits} }\]

    Autoregressive Language Model에서는 Probability Chain Rule이 \(Q_\theta( Y_{1:T} ) = \prod_{t=1}^{T} Q_\theta( Y_t\mid Y_{<t} )\) 로 나타난다.

    따라서 Sequence NLL은 \(-\log Q_\theta( Y_{1:T} ) = \sum_{t=1}^{T} -\log Q_\theta( Y_t\mid Y_{<t} )\) 로 정확히 분해된다.

    참 Distribution 자체의 Entropy에서는 \(H_P(Y_{1:T}) = \sum_{t=1}^{T} H_P( Y_t\mid Y_{<t} )\) 이고, 실제 Language Model Training Loss에서는 \(\mathcal L_{\mathrm{LM}}(\theta) = \sum_{t=1}^{T} \mathbb E_P [ -\log Q_\theta( Y_t\mid Y_{<t} ) ]\) 이라는 Conditional Cross-Entropy 합을 사용한다.

    Perplexity는 평균 Token Cross-Entropy/NLL의 Exponential이다.

    Base 2라면 \(\mathrm{PPL} = 2^{ \text{average token cross-entropy} }\) 이고 Natural Log를 사용하면 다음과 같다.

    \[\boxed{ \mathrm{PPL} = e^{ \text{average token NLL} } }\]

    따라서 IT-06의 가장 중요한 연결은 Joint Probability → Probability Chain Rule → Conditional Probabilities 그리고 다음과 같다.

    \[\boxed{ -\log \rightarrow \text{Sum} \rightarrow \text{Entropy Chain Rule} }\]

    LLM 관점에서는 이것이 그대로 Sequence Probability → Token Conditional Probability → Token NLL → Sequence Training Loss 로 이어진다.

예제·적용

Numerical Example — Given Values원자료의 3개 Token Random Variable을 생각한다.

\(X_1,X_2,X_3\) 에 대해:

\[\boxed{ H(X_1) = 2.0\text{ bits} }\]

또한 \(H(X_2\mid X_1) = 1.2\text{ bits}\) 이고:

\[\boxed{ H(X_3\mid X_1,X_2) = 0.5\text{ bits} }\]

Partial Joint Entropy먼저 \(H(X_1,X_2)\) 를 계산한다.

Chain Rule에 의해:

\[\begin{aligned} H(X_1,X_2) &= H(X_1) + H(X_2\mid X_1)\\ &= 2.0+1.2\\ &= \boxed{ 3.2\text{ bits} } \end{aligned}\]

Full Joint Entropy다시 Chain Rule을 적용하면 다음과 같다.

\[\begin{aligned} H(X_1,X_2,X_3) &= H(X_1,X_2) + H(X_3\mid X_1,X_2)\\ &= 3.2+0.5\\ &= \boxed{ 3.7\text{ bits} } \end{aligned}\]

Direct Chain Rule 계산일반식을 바로 사용해도:

\[\begin{aligned} H(X_1,X_2,X_3) &= H(X_1) + H(X_2\mid X_1)\\ &\quad+ H(X_3\mid X_1,X_2)\\ &= 2.0+1.2+0.5\\ &= \boxed{ 3.7\text{ bits} } \end{aligned}\]

Example의 정보론적 해석이 수치 예제에서는 단계별 Conditional Entropy가:

\[\boxed{ 2.0 \rightarrow 1.2 \rightarrow 0.5 }\]

bits로 나타난다.

따라서 이 특정 예제에서는 뒤 단계로 갈수록 이전 Context를 조건으로 했을 때 추가되는 평균 불확실성이 작다.

단계별 Entropy 감소에 대한 주의하지만 다음 관계 \(H(X_1) > H(X_2\mid X_1) > H(X_3\mid X_1,X_2)\) 가 Entropy Chain Rule 자체가 보장하는 일반 정리는 아니다.

각 항은 서로 다른 Random Variable을 대상으로 하기 때문이다.

일반적으로 보장되는 Conditioning Inequality는 같은 Target Variable에 대해 \(H(Y\mid X,Z) \le H(Y\mid X) \le H(Y)\) 와 같은 형태다.

Chain Rule과 OrderingJoint Entropy는 변수 순서를 바꾸어도 동일하다.

예를 들어 \(H(X,Y,Z)\) 는 \(H(Z,Y,X)\) 와 같다.

하지만 Chain Rule의 각 항은 Ordering에 따라 달라진다.

다른 Ordering예를 들어 \(H(X,Y,Z) = H(Z) + H(Y\mid Z) + H(X\mid Y,Z)\) 라고 써도 된다.

전체 합은 동일한 Joint Entropy다.

Sequence ModelingSequence \(X_1,X_2,\dots,X_T\) 의 Joint Entropy는 다음과 같다.

\[\boxed{ H(X_{1:T}) = \sum_{t=1}^{T} H( X_t\mid X_{<t} ) }\]

이는 순차적인 데이터를 다루는 모델에서 매우 자연스러운 형태다.

Autoregressive Probability ModelAutoregressive Model은 Joint Distribution을 \(P( Y_{1:T} ) = \prod_{t=1}^{T} P( Y_t\mid Y_{<t} )\) 형태로 Factorization한다.

GPT와 LLaMA 계열 Decoder-only Language Model의 기본적인 확률 구조가 이 형태다.

Sequence Log-Probability특정 Sequence \(y_{1:T}\) 에 대해:

\[\log P_\theta( y_{1:T} ) = \log \prod_{t=1}^{T} P_\theta( y_t\mid y_{<t} )\]

따라서 다음과 같다.

\[\boxed{ \log P_\theta( y_{1:T} ) = \sum_{t=1}^{T} \log P_\theta( y_t\mid y_{<t} ) }\]

Sequence NLL양변에 음수를 붙이면 다음과 같다.

\[\boxed{ -\log P_\theta( y_{1:T} ) = \sum_{t=1}^{T} -\log P_\theta( y_t\mid y_{<t} ) }\]

즉 Sequence NLL이 Token-Level Conditional NLL의 합으로 정확하게 분해된다.

Dataset Expectation실제 데이터의 Sequence Distribution을 \(P_{\mathrm{data}}\) 라고 하자.

Model Distribution을 \(Q_\theta\) 라고 구분해서 쓰면 Expected Sequence NLL은 다음과 같다.

\[\boxed{ \mathcal L_{\mathrm{LM}}(\theta) = \mathbb E_{ Y_{1:T}\sim P_{\mathrm{data}} } \left[ -\log Q_\theta( Y_{1:T} ) \right] }\]

Expected Sequence NLL 분해Autoregressive Factorization을 사용하면 다음과 같다.

\[\begin{aligned} \mathcal L_{\mathrm{LM}}(\theta) &= \mathbb E_{P_{\mathrm{data}}} \left[ \sum_{t=1}^{T} -\log Q_\theta( Y_t\mid Y_{<t} ) \right]\\ &= \boxed{ \sum_{t=1}^{T} \mathbb E_{P_{\mathrm{data}}} [ -\log Q_\theta( Y_t\mid Y_{<t} ) ] } \end{aligned}\]

즉 전체 Language Modeling Loss는 Token별 Conditional Cross-Entropy의 합으로 분해된다.

원자료 LLM 식의 표기 구분원자료에서는 \(\mathbb E[ -\log_2P_\theta(Y_{1:T}) ] = \sum_t H_\theta( Y_t\mid Y_{<t} )\) 형태로 표현한다.

여기서는 의미를 더 명확하게 하기 위해 다음 두 경우를 구분한다.

True Distribution Entropy

\[\boxed{ H_{P_{\mathrm{data}}} ( Y_{1:T} ) = \sum_t H_{P_{\mathrm{data}}} ( Y_t\mid Y_{<t} ) }\]

Model Cross-Entropy

\[\boxed{ \mathcal L_{\mathrm{LM}}(\theta) = \sum_t \mathbb E_{P_{\mathrm{data}}} [ -\log Q_\theta( Y_t\mid Y_{<t} ) ] }\]

왜 구분해야 하는가Entropy에서는 Probability inside the logarithm과 Expectation을 취하는 Distribution이 동일하다.

\[\boxed{ H(P) = \mathbb E_{Y\sim P} [ -\log P(Y) ] }\]

반면 Language Model Training Loss는 실제 데이터가 \(P_{\mathrm{data}}\) 에서 나오고 Log Probability는 Model \(Q_\theta\) 를 사용한다 (\(\mathbb E_{P_{\mathrm{data}}} [ -\log Q_\theta(Y) ]\)).

따라서 일반적으로는 Cross-Entropy다.

Perfect Model Case만약 \(Q_\theta = P_{\mathrm{data}}\) 라면 Model Cross-Entropy와 True Entropy가 일치한다.

\[\boxed{ \mathcal L_{\mathrm{LM}} = H_{P_{\mathrm{data}}} ( Y_{1:T} ) }\]

그리고 Entropy Chain Rule에 의해:

\[\boxed{ = \sum_{t=1}^{T} H_{P_{\mathrm{data}}} ( Y_t\mid Y_{<t} ) }\]

Conditional Cross-Entropy 분해IT-05의 결과를 각 Token Position에 적용하면 \(\mathbb E_P[ -\log Q_\theta( Y_t\mid Y_{<t} ) ]\) 은 \(H_P( Y_t\mid Y_{<t} ) + \mathbb E_{Y_{<t}} D_{KL} \left( P( Y_t\mid Y_{<t} ) \| Q_\theta( Y_t\mid Y_{<t} ) \right)\) 로 분해된다.

Sequence Cross-Entropy 전체 분해따라서 전체 Expected Sequence NLL은 \(\mathcal L_{\mathrm{LM}} = \sum_{t=1}^{T} H_P( Y_t\mid Y_{<t} ) + \sum_{t=1}^{T} \mathbb E_{Y_{<t}} D_{KL} ( P_t\|Q_{\theta,t} )\) 형태가 된다.

첫 번째 합은 Data Distribution 자체의 불확실성이고, 두 번째 합은 Model Mismatch에 해당한다.

Teacher Forcing과 연결Standard Autoregressive Training에서는 Position \(t\)의 Prediction을 계산할 때 실제 이전 Token \(y_{<t}\) 를 Context로 제공한다.

각 Position에서 \(-\log Q_\theta( y_t\mid y_{<t} )\) 를 계산한다.

따라서 하나의 Sequence에 대한 Loss는 자연스럽게:

\[\boxed{ \sum_{t=1}^{T} -\log Q_\theta( y_t\mid y_{<t} ) }\]

Token-Level Average LossSequence Length가 \(T\) 이면 평균 Token NLL은 다음과 같다.

\[\boxed{ \bar{\mathcal L} = -\frac1T \sum_{t=1}^{T} \log Q_\theta( y_t\mid y_{<t} ) }\]

Dataset 전체에서는 유효 Token 전체에 대해 이 값을 평균할 수 있다.

PerplexityLog Base 2를 사용한다면 Average Token Cross-Entropy를 \(\bar{\mathcal H}\) 라고 할 때 Perplexity는 \(\mathrm{PPL} = 2^{\bar{\mathcal H}}\) 로 정의할 수 있다.

Sequence Cross-Entropy와 PPL길이 \(T\)의 Sequence에서 \(\bar{\mathcal H} = \frac1T \mathbb E_P [ -\log_2 Q_\theta( Y_{1:T} ) ]\) 이면 다음과 같다.

\[\boxed{ \mathrm{PPL} = 2^{ \frac1T \mathbb E_P[ -\log_2Q_\theta(Y_{1:T}) ] } }\]

True Entropy와 PPL만약 Model Distribution이 True Distribution과 일치한다면 \(Q_\theta=P\) 이므로 다음과 같이 쓴다.

\[\mathbb E_P[ -\log_2P(Y_{1:T}) ] = H_P(Y_{1:T})\]

이 특별한 경우 \(\mathrm{PPL} = 2^{ H_P(Y_{1:T})/T }\) 로 쓸 수 있다.

일반적인 Model PPL하지만 실제 Model Evaluation에서는 일반적으로 다음과 같이 쓴다.

\[Q_\theta \neq P_{\mathrm{data}}\]

따라서 실제 Model PPL은 True Entropy가 아니라 Model의 평균 Cross-Entropy/NLL로 계산한다.

\[\boxed{ \mathrm{PPL} = 2^{ \frac1T \sum_t \mathbb E_P[ -\log_2Q_\theta( Y_t\mid Y_{<t} ) ] } }\]

Natural Log를 사용하는 경우Machine Learning에서는 Natural Log를 사용하는 경우가 많다.

평균 NLL이 \(\bar{\mathcal L}_{\mathrm{nats}}\) 이면 다음과 같다.

\[\boxed{ \mathrm{PPL} = \exp( \bar{\mathcal L}_{\mathrm{nats}} ) }\]

따라서 \(2^{\text{bits}} = e^{\text{nats}}\) 라는 Base 변환 관계가 적용된다.

Chain Rule과 ContextChain Rule에서 \(t\)번째 Term은 다음과 같다.

\[\boxed{ H( Y_t\mid Y_{<t} ) }\]

즉 이전 Context가 주어진 상태에서 다음 Token에 추가로 남아 있는 불확실성을 나타낸다.

Context가 제공하는 정보IT-05에서 다음과 같이 쓴다.

\[\boxed{ H(Y_t) - H( Y_t\mid Y_{<t} ) = I( Y_t;Y_{<t} ) }\]

즉 이전 Token Sequence가 다음 Token에 대해 제공하는 평균 정보량이 Mutual Information으로 표현된다.

Context Length와 조건화동일한 Target Random Variable \(Y_t\)에 대해 Conditioning Variable을 더 추가하면 평균 Conditional Entropy는 증가하지 않는다.

예를 들어 \(H( Y_t\mid Y_{t-1},Y_{t-2} ) \le H( Y_t\mid Y_{t-1} )\)

Context Length 해석의 주의점그러나 이 정보이론적 결과가 곧 longer context window ⇒ every practical LLM prediction improves 를 의미하지는 않는다.

정리는 True Joint Distribution에 관한 것이며 실제 Model은 Context를 불완전하게 사용할 수 있다.

원자료 예제와 Context 감소원자료에서는 \(2.0 \rightarrow 1.2 \rightarrow 0.5\) 라는 Conditional Entropy 값을 이용해 Context 누적에 따라 불확실성이 감소하는 직관을 설명한다.

이 값은 해당 예제에서는 유효하다.

다만 서로 다른 \(X_1,X_2,X_3\)의 Entropy를 비교한 것이므로 이것 자체가 Conditioning Reduces Entropy 정리의 직접적인 증명은 아니다.

전체 개념 연결IT-01에서는 한 Outcome의 정보량을 정의했다.

\[\boxed{ I(x) = -\log p(x) }\]

IT-02에서는 이를 평균하여 Entropy를 정의했다.

\[\boxed{ H(X) = \mathbb E[ I(X) ] }\]

IT-04에서는 여러 변수를 Joint Distribution으로 묶었다 (\(H(X,Y)\)).

IT-05에서는 관측 이후 남는 불확실성을 정의했다 (\(H(Y\mid X)\)).

IT-06에서는 이들을 결합한다.

\[\boxed{ H(X,Y) = H(X) + H(Y\mid X) }\]

그리고 일반화하면 다음과 같다.

\[\boxed{ H(X_{1:n}) = \sum_i H(X_i\mid X_{<i}) }\]

LLM 관점의 전체 흐름Autoregressive LLM에서는 다음과 같다.

\[\boxed{ P(Y_{1:T}) = \prod_t P( Y_t\mid Y_{<t} ) }\]

Negative Log를 적용하면 다음과 같다.

\[\boxed{ -\log P(Y_{1:T}) = \sum_t -\log P( Y_t\mid Y_{<t} ) }\]

True Distribution 아래에서 Expectation을 취하면 Entropy Chain Rule이 되고, Model Distribution의 Log Probability를 사용하면 LLM의 Token-Level Cross-Entropy Loss 분해가 된다.

따라서 Probability Chain Rule → Log-Probability Sum → Entropy / Cross-Entropy Chain Structure

정리

Entropy chain rule은 여러 변수의 결합 불확실성을 순서대로 조건부 entropy의 합으로 분해한다: \(H(X_1,\ldots,X_n)=\sum_i H(X_i\mid X_{<i})\). 전개 순서는 바뀔 수 있지만 각 조건에 포함되는 앞선 변수 집합을 일관되게 유지해야 한다.
