1. 논문 정보

2. 핵심 요약

GPT-2는 대규모 웹 문서로 언어 모델을 학습하면 별도의 과제별 지도학습 없이도 번역·질의응답·요약·독해와 같은 작업을 수행하기 시작한다는 가설을 검증한다.

학습 데이터 WebText는 Reddit에서 일정 수준 이상의 추천을 받은 외부 링크를 수집·정제한 말뭉치이며, 논문에 사용된 버전은 800만 개 이상의 문서와 약 40 GB의 텍스트로 구성된다.

가장 큰 모델은 48개 Transformer layer와 약 15억 개 parameter를 사용하며, zero-shot 조건에서 평가한 8개 language modeling dataset 중 7개에서 당시 최고 성능을 기록한다.

3. 배경 및 제안

당시 머신러닝 시스템은 대규모 dataset, 높은 model capacity, supervised learning을 결합해 학습한 과제에서는 높은 성능을 보였다. 그러나 data distribution이나 task specification이 조금만 바뀌어도 성능이 불안정했고, 많은 과제를 수행하는 generalist보다 하나의 과제와 domain에 맞춘 narrow expert에 가까웠다. 과제마다 dataset을 수집하고 label을 부여하는 방식에서 벗어나 더 넓은 범위로 일반화하는 학습 방법이 필요했다.

기존 해결 사례

NLP의 transfer learning은 pre-trained word vector를 task-specific architecture의 입력으로 사용하는 방식에서 출발해, recurrent network의 contextual representation과 여러 self-attention block을 전이하는 방식으로 발전했다. GPT-1과 같은 pre-training은 architecture 변경을 줄였지만 새로운 과제를 수행하려면 여전히 labeled data와 supervised fine-tuning이 필요했다. 다른 연구 흐름에서는 label이 거의 없거나 전혀 없는 조건에서도 language model이 commonsense reasoning과 sentiment analysis를 수행할 가능성을 보여주었다.

두 가지 한계

  1. 명시적 multitask learning의 확장 한계 — 당시 주요 연구도 10개 또는 17개의 dataset·objective 조합을 학습하는 수준이었다. 더 넓은 일반화를 위해 수백·수천 개의 조합을 직접 만들고 각각의 objective를 설계하는 방식은 확장하기 어려웠다.
  2. 과제별 supervision과 adaptation — pre-training으로 범용 representation을 얻어도 downstream task마다 labeled dataset과 supervised fine-tuning이 필요했다. Single-task·single-domain 학습은 data distribution과 task specification의 작은 변화에도 취약했다.

제안

GPT-2는 pre-training을 통한 representation transfer와 language model의 zero-shot task 수행이라는 두 연구 흐름을 연결한다. 자연어는 task, input, output을 하나의 sequence 안에 함께 표현할 수 있으므로, 충분한 capacity를 가진 language model이 다양한 text를 예측하는 과정에서 자연스럽게 등장하는 task demonstration을 학습할 수 있다고 본다. 이를 검증하기 위해 model parameter나 architecture를 수정하지 않고 여러 downstream task를 zero-shot setting에서 평가한다.

하나의 task는 \(p(\text{output}\mid\text{input})\)으로 나타낼 수 있지만, 여러 task를 수행하는 system은 \(p(\text{output}\mid\text{input},\text{task})\)를 모델링해야 한다. 기존 multitask learning은 task 정보를 architecture나 별도의 optimization procedure에 반영했다. GPT-2는 자연어 context 자체로 task를 조건화하고, language modeling만으로 그 관계를 학습할 수 있는지를 묻는다. 이 능력이 실제로 나타난다면 model은 별도의 task별 supervision 없이 unsupervised multitask learning을 수행하는 셈이다.
