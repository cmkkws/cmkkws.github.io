ML-01 — Loss, Risk & Empirical Risk Minimization (ERM)

Loss와 Risk의 정의, Empirical Risk Minimization의 학습 원리를 정리한다.

ML·딥러닝 · ML-01업데이트 2026.09.21
  • #Loss
  • #Risk
  • #Empirical Risk Minimization
  • #ERM

Machine Learning의 기본 문제

Supervised Learning에서는 입력

\[\mathbf x\in\mathcal X\]

와 Target

\[y\in\mathcal Y\]

의 관계를 학습한다.

Parameter를

\[\mathbf{\theta}\]

라고 하고 Prediction Model을

\[\boxed{ f_{\mathbf{\theta}}: \mathcal X \rightarrow \mathcal Y }\]

라고 하자.

Machine Learning Training의 핵심 문제는

\[\boxed{ \text{어떤 }\mathbf{\theta} \text{를 선택해야 미래 데이터에서도 좋은 예측을 하는가?} }\]

Data Generating Distribution

원자료에서는 데이터 Pair

\[(\mathbf x,y)\]

가 알려지지 않은 True Data Generating Distribution

\[\boxed{ p(\mathbf x,y) }\]

로부터 생성된다고 둔다.

즉

\[\boxed{ (\mathbf x,y) \sim p(\mathbf x,y) }\]

Input Space

입력은

\[\boxed{ \mathbf x \in \mathcal X \subseteq \mathbb R^D }\]

로 표현한다.

여기서

  • \(D\): Input Dimension
  • \(\mathcal X\): Input Space

Target은

\[\boxed{ y\in\mathcal Y }\]

Training Dataset

관측된 Dataset을

\[\boxed{ \mathcal D = \{ (\mathbf x_1,y_1), \dots, (\mathbf x_N,y_N) \} }\]

라고 하자.

원자료의 기본 통계적 설정에서는 이 Sample들이

\[\boxed{ (\mathbf x_i,y_i) \overset{\mathrm{i.i.d.}}{\sim} p(\mathbf x,y) }\]

라고 가정한다.

즉 Independent and Identically Distributed Sample을 가정한다.

Loss Function

Loss Function은 Model Prediction과 Target 사이의 오차를 Scalar로 측정한다.

\[\boxed{ \mathcal L : \mathcal Y\times\mathcal Y \rightarrow \mathbb R_{\ge0} }\]

Sample \((\mathbf x,y)\)에서 Loss는

\[\boxed{ \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x), y \right) }\]

Loss는 Sample-Level Quantity

Loss는 하나의 Sample에서 계산된다.

즉

\[\boxed{ \mathcal L_i = \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x_i), y_i \right) }\]

따라서

\[\boxed{ \text{Loss} = \text{one-example prediction error} }\]

로 이해할 수 있다.

Squared Error Loss

Regression에서 대표적인 Loss는 Squared Error다.

\[\boxed{ \mathcal L_{\mathrm{SE}} = \left( y-f_{\mathbf{\theta}}(\mathbf x) \right)^2 }\]

Prediction과 Target의 차이가 커질수록 Loss가 제곱으로 증가한다.

Cross-Entropy / NLL Loss

Classification이나 Language Modeling에서는 정답 Class 또는 Token의 Probability를 사용한다.

정답 Index를 \(y\)라고 하면

\[\boxed{ \mathcal L_{\mathrm{CE}} = -\log p_y }\]

형태를 사용할 수 있다.

Autoregressive LLM에서는

\[\boxed{ -\log P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

가 Token-Level NLL이 된다.

Loss와 Risk의 차이

Loss는 한 Sample의 Error다.

\[\boxed{ \mathcal L( f_{\mathbf{\theta}}(\mathbf x),y ) }\]

Risk는 이러한 Loss를 Data Distribution 전체에 대해 평균낸 Quantity다.

\[\boxed{ \mathcal R( f_{\mathbf{\theta}} ) }\]

따라서

\[\boxed{ \text{Loss} \rightarrow \text{Expected Loss} \rightarrow \text{Risk} }\]

로 연결된다.

True Risk

True Risk 또는 Expected Risk는

\[\boxed{ \mathcal R( f_{\mathbf{\theta}} ) = \mathbb E_{ (\mathbf x,y) \sim p(\mathbf x,y) } \left[ \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x), y \right) \right] }\]

즉 참 데이터 분포 전체에 대한 Expected Loss다.

Continuous Representation

연속형 변수라면 기대값을 Integral로 나타낼 수 있다.

\[\boxed{ \mathcal R( f_{\mathbf{\theta}} ) = \int_{\mathcal X} \int_{\mathcal Y} \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x), y \right) p(\mathbf x,y) \,dy\,d\mathbf x }\]

True Risk의 의미

True Risk는 Training Dataset 하나에만 대한 성능이 아니다.

참 Distribution

\[p(\mathbf x,y)\]

에서 새롭게 Sample을 뽑았을 때 기대되는 Loss를 나타낸다.

따라서 개념적으로

\[\boxed{ \text{True Risk} \leftrightarrow \text{expected performance on future data} }\]

와 연결된다.

Generalization과 True Risk

Training에서 궁극적으로 원하는 것은 단순히 Training Loss를 작게 만드는 것이 아니라

\[\boxed{ \mathcal R( f_{\mathbf{\theta}} ) }\]

를 작게 만드는 것이다.

즉 좋은 Generalization은 낮은 Expected Risk와 연결된다.

True Risk의 실질적 문제

하지만 실제 학습에서는

\[p(\mathbf x,y)\]

를 정확히 알 수 없는 경우가 대부분이다.

따라서

\[\boxed{ \mathcal R( f_{\mathbf{\theta}} ) }\]

를 직접 계산할 수 없다.

이 때문에 관측 Sample을 이용한 근사 Quantity가 필요하다.

Empirical Risk

Dataset

\[\mathcal D = \{ (\mathbf x_i,y_i) \}_{i=1}^{N}\]

에서 계산한 평균 Loss를 Empirical Risk라고 한다.

\[\boxed{ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) = \frac1N \sum_{i=1}^{N} \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x_i), y_i \right) }\]

Empirical Risk의 의미

Empirical Risk는 알려지지 않은 Distribution 전체를 평균하는 대신 실제 관측된 Dataset에 대해 평균을 계산한다.

즉

\[\boxed{ \text{Population expectation} \rightarrow \text{sample average} }\]

로 대체한 것이다.

Population vs Sample

True Risk:

\[\boxed{ \mathcal R(f) = \mathbb E_P[ \mathcal L ] }\]

Empirical Risk:

\[\boxed{ \mathcal R_{\mathrm{emp}}(f) = \frac1N \sum_{i=1}^{N} \mathcal L_i }\]

따라서 Machine Learning에서는 Population Quantity를 Sample Quantity로 근사한다.

Empirical Risk Minimization

True Risk를 직접 최소화할 수 없으므로 Empirical Risk를 최소화한다.

이를 Empirical Risk Minimization, ERM이라고 한다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{ERM}} = \arg\min_{ \mathbf{\theta}\in\Theta } \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) }\]

ERM 완전 전개

Empirical Risk 정의를 대입하면

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{ERM}} = \arg\min_{ \mathbf{\theta}\in\Theta } \frac1N \sum_{i=1}^{N} \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x_i), y_i \right) }\]

ERM의 핵심 논리

ERM의 기본 흐름은

\[\boxed{ p(\mathbf x,y) \text{ unknown} }\]
\[\Downarrow\]
\[\boxed{ \mathcal R(f) \text{ cannot be directly evaluated} }\]
\[\Downarrow\]
\[\boxed{ \mathcal R_{\mathrm{emp}}(f) \text{ from observed samples} }\]
\[\Downarrow\]
\[\boxed{ \min \mathcal R_{\mathrm{emp}} }\]

Loss와 Objective

Regularization이 없는 기본 ERM에서는 Empirical Risk 자체가 Training Objective다.

\[\boxed{ J( \mathbf{\theta} ) = \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) }\]

따라서 Optimization에서는

\[\boxed{ \min_{\mathbf{\theta}} J( \mathbf{\theta} ) }\]

를 해결한다.

CO 시리즈와 연결

Optimization 관점에서는

\[J( \mathbf{\theta} ) = \frac1N \sum_i \mathcal L_i\]

에 대해 Gradient를 계산한다.

\[\boxed{ \nabla_{\mathbf{\theta}} J }\]

그리고 Gradient Descent나 SGD를 이용해

\[\boxed{ \mathbf{\theta}_{t+1} = \mathbf{\theta}_t - \eta \nabla J }\]

형태로 Parameter를 업데이트한다.

ERM과 SGD

Full Empirical Risk Gradient는

\[\boxed{ \nabla \mathcal R_{\mathrm{emp}} = \frac1N \sum_{i=1}^{N} \nabla \mathcal L_i }\]

SGD에서는 Dataset 전체 대신 Mini-batch를 사용하여 이 Gradient를 추정한다.

따라서

\[\boxed{ \text{ERM} = \text{statistical objective} }\]

이고

\[\boxed{ \text{SGD} = \text{optimization method} }\]

Empirical Risk가 True Risk를 근사하는 이유

원자료에서는 Law of Large Numbers를 이용하여 Empirical Risk와 True Risk의 관계를 설명한다.

고정된 Model

\[f_{\mathbf{\theta}}\]

에 대해 Random Variable을

\[\boxed{ Z_i = \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x_i), y_i \right) }\]

라고 하자.

Loss Random Variable

\((\mathbf x_i,y_i)\)가 i.i.d.라면 고정된 \(f_{\mathbf{\theta}}\)에 대해

\[Z_1,\dots,Z_N\]

도 동일한 Distribution에서 생성된 Loss Random Variable로 볼 수 있다.

기댓값은

\[\boxed{ \mathbb E[Z_i] = \mathcal R( f_{\mathbf{\theta}} ) }\]

Empirical Risk as Sample Mean

Empirical Risk는

\[\boxed{ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) = \bar Z_N = \frac1N \sum_{i=1}^{N} Z_i }\]

즉 Loss Random Variable의 Sample Mean이다.

Expected Empirical Risk

고정된 \(f_{\mathbf{\theta}}\)에 대해

\[\begin{aligned} \mathbb E[ \bar Z_N ] &= \mathbb E \left[ \frac1N \sum_{i=1}^{N} Z_i \right]\\ &= \frac1N \sum_{i=1}^{N} \mathbb E[Z_i]\\ &= \mu_Z \end{aligned}\]

여기서

\[\boxed{ \mu_Z = \mathcal R( f_{\mathbf{\theta}} ) }\]

Empirical Risk의 Unbiasedness

따라서 고정된 Model에 대해서는

\[\boxed{ \mathbb E[ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) ] = \mathcal R( f_{\mathbf{\theta}} ) }\]

즉 Empirical Risk는 고정된 Model의 True Risk에 대한 Unbiased Estimate가 된다.

Variance Assumption

원자료의 Chebyshev 증명에서는

\[\boxed{ \operatorname{Var}(Z_i) = \sigma_Z^2 < \infty }\]

를 사용한다.

i.i.d. 가정에서 서로 다른 Sample의 Covariance가 0이므로 Sample Mean의 Variance를 계산할 수 있다.

Sample Mean Variance

\[\begin{aligned} \operatorname{Var}( \bar Z_N ) &= \operatorname{Var} \left( \frac1N \sum_{i=1}^{N} Z_i \right)\\ &= \frac1{N^2} \sum_{i=1}^{N} \operatorname{Var}(Z_i)\\ &= \frac1{N^2} N\sigma_Z^2 \end{aligned}\]

따라서

\[\boxed{ \operatorname{Var}( \bar Z_N ) = \frac{ \sigma_Z^2 }{N} }\]

Data Size와 Variance

위 결과에서

\[N\uparrow\]

이면

\[\boxed{ \operatorname{Var}( \mathcal R_{\mathrm{emp}} ) \downarrow }\]

구체적으로

\[\boxed{ \operatorname{Var} \propto \frac1N }\]

따라서 Sample Mean의 변동성이 감소한다.

Chebyshev's Inequality

Chebyshev's Inequality는

\[\boxed{ P( |X-\mu| \ge \epsilon ) \le \frac{ \operatorname{Var}(X) }{ \epsilon^2 } }\]

이를

\[X=\bar Z_N\]

에 적용한다.

Chebyshev 적용

따라서

\[\boxed{ P \left( | \bar Z_N-\mu_Z | \ge \epsilon \right) \le \frac{ \sigma_Z^2 }{ N\epsilon^2 } }\]

\(N\rightarrow\infty\)

\(N\)을 증가시키면

\[\frac{ \sigma_Z^2 }{ N\epsilon^2 } \rightarrow 0\]

따라서

\[\boxed{ \lim_{N\rightarrow\infty} P \left( | \mathcal R_{\mathrm{emp}}(f_{\mathbf{\theta}}) - \mathcal R(f_{\mathbf{\theta}}) | \ge \epsilon \right) = 0 }\]

Convergence in Probability

위 식은

\[\boxed{ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) \xrightarrow{P} \mathcal R( f_{\mathbf{\theta}} ) }\]

라는 Convergence in Probability를 의미한다.

즉 고정된 Model에 대해 Sample Size가 증가하면 Empirical Risk가 True Risk에 가까워질 확률이 커진다.

중요한 수정 — “완전히 일치”의 의미

원자료에서는 \(N\rightarrow\infty\)에서 경험적 위험과 참 위험이 “완전히 일치한다”고 표현한다.

더 엄밀하게는 현재 증명이 보이는 것은

\[\boxed{ \mathcal R_{\mathrm{emp}} \xrightarrow{P} \mathcal R }\]

라는 확률수렴이다.

이는 유한한 \(N\)에서 두 값이 정확히 같다는 뜻이 아니다.

Pointwise Convergence

또 하나 중요한 조건은 현재 LLN 결과가 고정된

\[f_{\mathbf{\theta}}\]

에 대해 성립한다는 점이다.

즉

\[\boxed{ \text{fixed }f : \quad \mathcal R_{\mathrm{emp}}(f) \rightarrow \mathcal R(f) }\]

ERM Solution과는 다른 문제

실제 Training에서는

\[\hat f_{\mathrm{ERM}}\]

자체가 Training Dataset에 의존한다.

따라서 고정된 \(f\)에 대한 LLN만으로

\[\boxed{ \mathcal R( \hat f_{\mathrm{ERM}} ) \approx \mathcal R_{\mathrm{emp}} ( \hat f_{\mathrm{ERM}} ) }\]

가 자동으로 보장되는 것은 아니다.

이 차이가 Generalization Theory가 필요한 이유다.

Pointwise vs Uniform Convergence

고정된 \(f\)에 대한 Pointwise Convergence와

\[\sup_{f\in\mathcal F} | \mathcal R_{\mathrm{emp}}(f) - \mathcal R(f) | \rightarrow0\]

와 같은 Uniform Convergence는 다른 개념이다.

원자료는 LLN 수준의 Pointwise Convergence를 중심으로 다룬다.

Generalization Gap

True Risk와 Empirical Risk의 차이를 Generalization Gap이라고 한다.

\[\boxed{ \operatorname{Gap} ( f_{\mathbf{\theta}} ) = \mathcal R( f_{\mathbf{\theta}} ) - \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) }\]

Gap의 의미

Training Error가 작더라도 True Risk가 크면 Generalization Gap이 커진다.

즉

\[\boxed{ \text{low training loss} \not\Rightarrow \text{low population risk} }\]

Machine Learning에서 중요한 것은 두 값을 구분하는 것이다.

Overfitting

Overfitting은 Training Dataset에 대한 Empirical Risk는 매우 작지만 새로운 Data에 대한 Risk가 상대적으로 큰 상황을 말한다.

개념적으로

\[\boxed{ \mathcal R_{\mathrm{emp}} \ll \mathcal R }\]

인 상황과 연결할 수 있다.

Model Complexity에 대한 원자료 설명

원자료에서는 Parameter Dimension

\[D\]

가 Dataset Size

\[N\]

에 비해 지나치게 큰 경우 Training Noise를 암기하여 Overfitting할 수 있다고 설명한다.

이는 고전적인 Model Complexity 직관이다.

Parameter Count만으로 Overfitting을 판단할 수는 없음

다만

\[\boxed{ D\gg N \Rightarrow \text{necessarily severe overfitting} }\]

은 일반적인 수학적 정리는 아니다.

현대 Deep Learning에서는 Parameter 수 외에도

  • Architecture
  • Optimization
  • Regularization
  • Data Distribution
  • Inductive Bias

등이 Generalization에 영향을 준다.

따라서 원자료의 \(D\) vs \(N\) 관계는 직관적인 복잡도 설명으로 이해한다.

Zero Training Loss

Overparameterized Model에서는

\[\boxed{ \mathcal R_{\mathrm{emp}} \approx0 }\]

을 달성할 수 있다.

하지만 이것만으로

\[\boxed{ \mathcal R }\]

가 작거나 크다고 결정할 수 없다.

Training Error와 Generalization Error는 별개의 Quantity다.

Regularization

원자료에서는 Overfitting을 줄이기 위한 방법으로 Parameter Complexity Penalty

\[\boxed{ \Omega( \mathbf{\theta} ) }\]

를 Objective에 추가한다.

Regularized Objective

Regularized ERM의 대표적인 형태는

\[\boxed{ J( \mathbf{\theta} ) = \frac1N \sum_{i=1}^{N} \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x_i), y_i \right) + \lambda \Omega( \mathbf{\theta} ) }\]

Regularization Parameter

\[\boxed{ \lambda>0 }\]

는 Data Fitting과 Regularization 사이의 Trade-off를 조절한다.

\(\lambda\)가 커지면 Penalty의 영향이 커지고,

\(\lambda\)가 작아지면 Empirical Loss의 영향이 상대적으로 커진다.

Structural Risk Minimization

원자료에서는 이 Regularized Objective를 Structural Risk Minimization, SRM과 연결한다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{SRM}} = \arg\min_{\mathbf{\theta}} \left[ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) + \lambda \Omega( \mathbf{\theta} ) \right] }\]

L2 Regularization

대표적인 Penalty는

\[\boxed{ \Omega( \mathbf{\theta} ) = \| \mathbf{\theta} \|_2^2 }\]

따라서 Objective는

\[\boxed{ J( \mathbf{\theta} ) = \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) + \lambda \| \mathbf{\theta} \|_2^2 }\]

형태가 된다.

Weight Decay와의 관계

원자료는 L2 Regularization을 Weight Decay와 연결한다.

SGD와 같은 일부 Update Setting에서는 L2 Penalty가 Weight Shrinkage 형태와 직접 연결된다.

다만 Adaptive Optimizer, 특히 AdamW에서는 Decoupled Weight Decay가 사용되므로

\[\boxed{ \text{L2 regularization} = \text{all implementations of weight decay} }\]

라고 일반화하지 않는다.

Numerical Example — Dataset

원자료의 Dataset은

\[\boxed{ \mathcal D = \{ (1,2), (2,3.5), (3,5), (4,7) \} }\]

Sample Size는

\[\boxed{ N=4 }\]

Numerical Example — Model

Linear Model을

\[\boxed{ f_w(x) = wx }\]

라고 한다.

Bias는

\[b=0\]

으로 가정한다.

Parameter는 Scalar

\[\boxed{ w }\]

하나다.

Numerical Example — Loss

Squared Error를 사용한다.

\[\boxed{ \mathcal L_i = ( wx_i-y_i )^2 }\]

Empirical Risk는

\[\boxed{ \mathcal R_{\mathrm{emp}}(w) = \frac14 \sum_{i=1}^{4} ( wx_i-y_i )^2 }\]

Empirical Risk 완전 대입

Dataset을 대입하면

\[\begin{aligned} \mathcal R_{\mathrm{emp}}(w) = \frac14 \Big[ &(w-2)^2\\ &+(2w-3.5)^2\\ &+(3w-5)^2\\ &+(4w-7)^2 \Big] \end{aligned}\]

First Term

\[\boxed{ (w-2)^2 = w^2-4w+4 }\]

Second Term

\[\begin{aligned} (2w-3.5)^2 &= 4w^2 - 14w + 12.25 \end{aligned}\]

따라서

\[\boxed{ (2w-3.5)^2 = 4w^2-14w+12.25 }\]

Third Term

\[\boxed{ (3w-5)^2 = 9w^2 - 30w + 25 }\]

Fourth Term

\[\boxed{ (4w-7)^2 = 16w^2 - 56w + 49 }\]

Quadratic Coefficient 합

\(w^2\)의 Coefficient는

\[1+4+9+16 = \boxed{30}\]

Linear Coefficient 합

\(w\)의 Coefficient는

\[-4-14-30-56 = \boxed{-104}\]

Constant 합

상수항은

\[4+12.25+25+49\]

따라서

\[\boxed{ 90.25 }\]

Sum of Losses

따라서 Sample Loss의 합은

\[\boxed{ \sum_{i=1}^{4} \mathcal L_i = 30w^2 - 104w + 90.25 }\]

Empirical Risk Function

4로 나누면

\[\begin{aligned} \mathcal R_{\mathrm{emp}}(w) &= \frac{30}{4}w^2 - \frac{104}{4}w + \frac{90.25}{4}\\ &= \boxed{ 7.5w^2 - 26w + 22.5625 } \end{aligned}\]

First-Order Condition

최솟값을 찾기 위해 미분한다.

\[\boxed{ \frac{ d\mathcal R_{\mathrm{emp}} }{ dw } = 15w-26 }\]

Stationary Point에서

\[15w-26=0\]

ERM Parameter

따라서

\[15w=26\]

이고

\[\boxed{ \hat w_{\mathrm{ERM}} = \frac{26}{15} }\]

수치적으로

\[\boxed{ \hat w_{\mathrm{ERM}} \approx 1.7333 }\]

Second Derivative

\[\boxed{ \frac{ d^2 \mathcal R_{\mathrm{emp}} }{ dw^2 } = 15 }\]
\[15>0\]

이므로 Objective는 Convex Quadratic이고

\[\boxed{ \hat w_{\mathrm{ERM}} }\]

은 Global Minimum이다.

Exact Minimum Empirical Risk

원자료에서는 반올림한 \(w=1.7333\)을 이용해 약

\[0.0291\]

을 얻는다.

Exact Value

\[w=\frac{26}{15}\]

를 대입하면

\[\begin{aligned} \mathcal R_{\mathrm{emp}} \left( \frac{26}{15} \right) &= 7.5 \left( \frac{26}{15} \right)^2 - 26 \left( \frac{26}{15} \right) + 22.5625 \end{aligned}\]

Numerical Minimum

수치적으로

\[\boxed{ \mathcal R_{\mathrm{emp}} ( \hat w_{\mathrm{ERM}} ) \approx 0.0292 }\]

정도로 얻는다.

원자료의 반올림 계산

\[0.0291\]

과 사실상 동일하다.

Numerical Example의 의미

이 Example에서는

\[\boxed{ \text{Dataset} \rightarrow \text{Loss} \rightarrow \text{Empirical Risk} \rightarrow \text{Differentiation} \rightarrow \hat w_{\mathrm{ERM}} }\]

이라는 ERM 전체 흐름을 직접 확인한다.

LLM Pre-training과 ERM

원자료는 LLM Pre-training을 ERM Framework와 연결한다.

Autoregressive Language Model은 Context

\[y_{<t}\]

에서 다음 Token

\[y_t\]

의 Conditional Probability를 모델링한다.

\[\boxed{ P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

Token-Level NLL

각 Token의 Loss는

\[\boxed{ \mathcal L_t( \mathbf{\theta} ) = -\log P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

이는 정답 Token에 모델이 높은 Probability를 부여할수록 작아진다.

LLM Empirical Objective

Training Corpus에서 유효한 Prediction Position이 \(N\)개라고 하면 평균 Token NLL은

\[\boxed{ \mathcal R_{\mathrm{emp}} ( \mathbf{\theta} ) = -\frac1N \sum_{i=1}^{N} \log P_{\mathbf{\theta}} ( y_i\mid y_{<i} ) }\]

형태로 나타낼 수 있다.

이 Quantity를 최소화하는 것이 일반적인 Autoregressive Pre-training Objective다.

LLM의 ERM 해석

따라서 구조적으로는

\[\boxed{ \text{Training tokens} \rightarrow \text{token-level NLL} \rightarrow \text{average NLL} \rightarrow \text{parameter optimization} }\]

즉 LLM Training도 관측된 Training Corpus 위의 평균 Loss를 최소화한다는 의미에서 ERM 관점으로 이해할 수 있다.

중요한 주의 — LLM Token은 i.i.d.가 아니다

원자료의 초기 ERM 이론에서는 Sample

\[(\mathbf x_i,y_i)\]

가 i.i.d.라고 가정한다.

하지만 Autoregressive Text Sequence의 연속 Token들은 일반적으로 서로 독립이 아니다.

따라서

\[\boxed{ \text{token count }N \uparrow \Rightarrow \text{classical i.i.d. LLN applies directly} }\]

라고 그대로 연결하면 엄밀하지 않다.

Sequence Dependency

LLM에서

\[P( y_{1:T} ) = \prod_{t=1}^{T} P( y_t\mid y_{<t} )\]

즉 각 Token Probability가 Context에 조건화된다.

따라서 Language Data의 통계적 의존성을 고려하려면 단순 i.i.d. Sample Mean보다 더 일반적인 확률 과정의 관점이 필요할 수 있다.

Data Scale의 올바른 직관

Training Data가 많아지면 다양한 Context와 Linguistic Pattern을 더 많이 관측할 가능성이 증가한다.

따라서 Empirical Objective가 Data Distribution을 더 잘 반영할 가능성은 있다.

하지만

\[\boxed{ N\text{ tokens large} \Rightarrow \mathcal R_{\mathrm{emp}} \approx \mathcal R }\]

를 고전적 i.i.d. LLN만으로 직접 증명했다고 해석하지 않는다.

Human Language “True Distribution” 주의

원자료는 매우 큰 Corpus의 Empirical Risk가 “인간 언어 전 공간의 참 위험”에 접근한다고 설명한다.

이는 직관적인 ERM 관점이다.

실제로는

  • Data Collection Process
  • Domain Mixture
  • Sampling Bias
  • Temporal Shift
  • Deduplication
  • Token Dependence

등 때문에 Training Corpus Distribution과 실제 Deployment Distribution이 동일하다고 가정하기 어렵다.

Scaling Laws 연결

원자료에서는 Data Size 증가에 따른 Loss 감소를 Scaling Laws와 연결한다.

대표적인 형태를

\[\boxed{ L(N) \approx \left( \frac{ N_c }{ N } \right)^\alpha }\]

와 같이 표현한다.

이는 Dataset Scale 증가에 따라 Empirical/Validation Loss가 경험적으로 감소하는 Power-Law Behavior를 나타내는 형태로 이해할 수 있다.

Scaling Law와 LLN은 다른 결과

중요하게도 Scaling Law의 경험적 Power Law와 고전적인 LLN은 서로 같은 정리가 아니다.

LLN은 고정된 Random Variable의 Sample Mean 수렴에 관한 확률론적 결과다.

Scaling Law는 Model/Data/Compute Scale과 Loss 사이에서 관측되는 경험적 Scaling Relation을 다룬다.

따라서

\[\boxed{ \text{Scaling Law} \neq \text{proof of LLN convergence rate} }\]

Irreducible Entropy와의 관계

원자료는 Scaling Laws가 Irreducible Entropy로의 접근을 보여준다고 설명한다.

이러한 해석은 Language Modeling Loss에 존재할 수 있는 비가역적인 Data Uncertainty와 연결되는 직관으로 볼 수 있다.

하지만 주어진 원자료만으로

\[\boxed{ \text{observed power law} \Rightarrow \text{mathematical proof of convergence to true irreducible entropy} }\]

까지 결론내릴 수는 없다.

ERM과 Maximum Likelihood

Autoregressive Dataset의 평균 NLL을 최소화하는 것은 Log-Likelihood를 최대화하는 것과 동치다.

\[\boxed{ \arg\min_{\mathbf{\theta}} \left[ -\frac1N \sum_i \log P_{\mathbf{\theta}} ( y_i\mid y_{<i} ) \right] }\]

은 상수 \(1/N\)을 무시하면

\[\boxed{ \arg\max_{\mathbf{\theta}} \sum_i \log P_{\mathbf{\theta}} ( y_i\mid y_{<i} ) }\]

와 같다.

따라서

\[\boxed{ \text{ERM with NLL} \leftrightarrow \text{Maximum Likelihood} }\]

로 연결된다.

Loss–Risk–MLE 연결

전체 관계는

\[\boxed{ -\log P_{\mathbf{\theta}} ( y_i\mid y_{<i} ) }\]

라는 Sample-Level Loss에서 시작한다.

이를 평균하면

\[\boxed{ \mathcal R_{\mathrm{emp}} }\]

가 되고,

이를 최소화하면

\[\boxed{ \text{ERM} }\]

이 된다.

NLL을 사용했다면 이 Optimization은 MLE와 동일한 목적을 가진다.

핵심 식 — Loss

\[\boxed{ \mathcal L_i = \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x_i), y_i \right) }\]

핵심 식 — True Risk

\[\boxed{ \mathcal R( f_{\mathbf{\theta}} ) = \mathbb E_P \left[ \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x), y \right) \right] }\]

핵심 식 — Empirical Risk

\[\boxed{ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) = \frac1N \sum_{i=1}^{N} \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x_i), y_i \right) }\]

핵심 식 — ERM

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{ERM}} = \arg\min_{\mathbf{\theta}} \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) }\]

핵심 식 — LLN

고정된 \(f_{\mathbf{\theta}}\)와 적절한 i.i.d./moment 조건 아래에서

\[\boxed{ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) \xrightarrow{P} \mathcal R( f_{\mathbf{\theta}} ) }\]

원자료의 Chebyshev 증명에서는

\[\boxed{ P \left( | \mathcal R_{\mathrm{emp}} - \mathcal R | \ge \epsilon \right) \le \frac{ \sigma_Z^2 }{ N\epsilon^2 } }\]

핵심 식 — Generalization Gap

\[\boxed{ \operatorname{Gap}(f) = \mathcal R(f) - \mathcal R_{\mathrm{emp}}(f) }\]

핵심 식 — Regularized ERM

\[\boxed{ \hat{\mathbf{\theta}} = \arg\min_{\mathbf{\theta}} \left[ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) + \lambda \Omega( \mathbf{\theta} ) \right] }\]

혼동하기 쉬운 부분 — Loss와 Risk

Loss는 하나의 Sample에 대한 Quantity다.

\[\boxed{ \mathcal L_i }\]

Risk는 Population Average다.

\[\boxed{ \mathcal R }\]

Empirical Risk는 Sample Average다.

\[\boxed{ \mathcal R_{\mathrm{emp}} }\]

세 개념을 구분해야 한다.

혼동하기 쉬운 부분 — Training Loss와 True Risk

\[\mathcal R_{\mathrm{emp}}\]

가 낮다고 자동으로

\[\mathcal R\]

도 낮아지는 것은 아니다.

Generalization Gap이 존재하기 때문이다.

\[\boxed{ \text{training fit} \neq \text{generalization guarantee} }\]

혼동하기 쉬운 부분 — LLN

LLN은 고정된 모델의 Sample Average Loss가 Expected Loss로 수렴한다는 결과다.

Dataset에서 선택된 ERM Solution 전체에 대해 Generalization을 보장하려면 추가적인 이론이 필요하다.

따라서

\[\boxed{ \text{pointwise LLN} \neq \text{full ERM generalization theorem} }\]

혼동하기 쉬운 부분 — Model Size

Parameter Count가 많다는 이유만으로 Overfitting 여부를 결정할 수 없다.

원자료의

\[D\gg N\]

설명은 Classical Complexity Intuition으로 이해한다.

혼동하기 쉬운 부분 — Regularization

Regularization은 Training Objective에 Bias를 추가하여 특정 Solution을 선호하도록 만드는 방법이다.

그러나

\[\boxed{ \lambda>0 \Rightarrow \text{always better generalization} }\]

은 아니다.

\(\lambda\) 자체도 적절하게 선택해야 한다.

혼동하기 쉬운 부분 — LLM Dataset Size

Token 수가 수조 개라는 사실만으로 Classical i.i.d. LLN을 바로 적용할 수는 없다.

Natural Language Token들은 Context Dependence를 가진다.

따라서 Data Scale과 ERM의 관계를 설명할 때 i.i.d. Theory와 Sequence Modeling을 구분해야 한다.

혼동하기 쉬운 부분 — Scaling Laws

Scaling Laws에서 관측되는

\[L(N) \propto N^{-\alpha}\]

형태는 Empirical Scaling Relation이다.

이를 그대로

\[\boxed{ \text{LLN convergence rate} }\]

라고 부르지 않는다.

전체 개념 연결

Machine Learning은 Sample-Level Loss에서 시작한다.

\[\boxed{ \mathcal L }\]

이를 True Distribution에서 평균하면

\[\boxed{ \mathcal R = \mathbb E[ \mathcal L ] }\]

하지만 True Distribution을 모르므로 Training Dataset 평균을 사용한다.

\[\boxed{ \mathcal R_{\mathrm{emp}} = \frac1N \sum_i \mathcal L_i }\]

그리고 이를 최소화한다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{ERM}} = \arg\min \mathcal R_{\mathrm{emp}} }\]

통계적 연결

고정된 Model에서는 LLN에 의해

\[\boxed{ \mathcal R_{\mathrm{emp}} \rightarrow \mathcal R }\]

라는 통계적 연결이 존재한다.

하지만 실제 학습된 Model은 Dataset에 따라 선택되므로

\[\boxed{ \text{ERM} \rightarrow \text{Generalization Theory} }\]

라는 추가 단계가 필요하다.

100. Optimization 연결

ERM Objective가 정의되면 Optimization 문제는

\[\boxed{ \min_{\mathbf{\theta}} \mathcal R_{\mathrm{emp}} ( \mathbf{\theta} ) }\]

이를 Gradient-Based Method로 풀면

\[\boxed{ \text{ERM Objective} \rightarrow \nabla_{\mathbf{\theta}} \mathcal R_{\mathrm{emp}} \rightarrow \text{SGD / AdamW} }\]

로 연결된다.

101. LLM 연결

LLM에서는 Sample-Level Loss가 Token NLL이다.

\[\boxed{ -\log P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

이를 Training Corpus 전체에 평균하면 Empirical Risk다.

\[\boxed{ -\frac1N \sum_t \log P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

따라서

\[\boxed{ \text{Next-token NLL} \rightarrow \text{Empirical Risk} \rightarrow \text{ERM} \rightarrow \text{Pre-training} }\]

으로 연결된다.

102. 정리

Machine Learning의 출발점은 Model Prediction과 Target 사이의 Error를 정의하는 Loss Function이다.

\[\boxed{ \mathcal L \left( f_{\mathbf{\theta}}(\mathbf x), y \right) }\]

참 Data Generating Distribution

\[p(\mathbf x,y)\]

전체에서 Loss를 평균하면 True Risk를 얻는다.

\[\boxed{ \mathcal R( f_{\mathbf{\theta}} ) = \mathbb E_P[ \mathcal L ] }\]

True Risk는 미래 Data에서 기대되는 Prediction Loss와 연결되지만 실제 Distribution을 모르기 때문에 직접 계산하기 어렵다.

따라서 관측된 Dataset에서 Sample Average Loss를 계산한다.

\[\boxed{ \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) = \frac1N \sum_{i=1}^{N} \mathcal L_i }\]

이를 최소화하는 것이 ERM이다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{ERM}} = \arg\min_{\mathbf{\theta}} \mathcal R_{\mathrm{emp}} ( f_{\mathbf{\theta}} ) }\]

고정된 Model과 i.i.d. Sample에 대해 Loss Random Variable을

\[Z_i = \mathcal L_i\]

라고 하면

\[\boxed{ \mathbb E[ \mathcal R_{\mathrm{emp}} ] = \mathcal R }\]

이고

\[\boxed{ \operatorname{Var} ( \mathcal R_{\mathrm{emp}} ) = \frac{ \sigma_Z^2 }{N} }\]

Chebyshev's Inequality에 의해

\[\boxed{ P \left( | \mathcal R_{\mathrm{emp}} - \mathcal R | \ge \epsilon \right) \le \frac{ \sigma_Z^2 }{ N\epsilon^2 } }\]

이므로

\[\boxed{ \mathcal R_{\mathrm{emp}} \xrightarrow{P} \mathcal R }\]

다만 이는 고정된 Model에 대한 Pointwise LLN 결과이며, Dataset으로부터 선택된 ERM Solution의 Generalization을 자동으로 보장하는 정리는 아니다.

True Risk와 Empirical Risk의 차이는

\[\boxed{ \operatorname{Gap} = \mathcal R - \mathcal R_{\mathrm{emp}} }\]

으로 표현한다.

Training Data에 지나치게 특화되어 Gap이 커지는 현상을 Overfitting과 연결할 수 있다.

Regularization을 사용하면

\[\boxed{ J( \mathbf{\theta} ) = \mathcal R_{\mathrm{emp}} ( \mathbf{\theta} ) + \lambda \Omega( \mathbf{\theta} ) }\]

형태의 Objective를 최적화한다.

원자료의 Linear Model 예제에서는

\[f_w(x)=wx\]

이고

\[\boxed{ \mathcal R_{\mathrm{emp}}(w) = 7.5w^2 - 26w + 22.5625 }\]

미분하면

\[\boxed{ \frac{ d\mathcal R_{\mathrm{emp}} }{ dw } = 15w-26 }\]

이고

\[\boxed{ \hat w_{\mathrm{ERM}} = \frac{26}{15} \approx 1.7333 }\]

최소 Empirical Risk는 약

\[\boxed{ 0.029 }\]

LLM Pre-training에서는 Token-Level Loss

\[\boxed{ \mathcal L_t = -\log P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

를 사용하고, 이를 Corpus 전체에서 평균한다.

\[\boxed{ \mathcal R_{\mathrm{emp}} ( \mathbf{\theta} ) = -\frac1N \sum_t \log P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

따라서 Autoregressive Pre-training 역시 관측 Data에서 평균 Loss를 최소화한다는 ERM 구조로 볼 수 있다.

다만 자연어 Token은 일반적인 i.i.d. Sample이 아니므로, 고전적인 LLN 결과를 Token 수 증가에 그대로 대입하여 “수조 Token이면 True Language Risk에 수렴한다”고 단정해서는 안 된다.

또한 Scaling Laws의

\[\boxed{ L(N) \propto N^{-\alpha} }\]

와 같은 경험적 Power Law는 Data Scale과 Loss 사이의 경험적 관계이며, Classical LLN의 수렴 속도를 증명하는 결과와는 구분해야 한다.

전체 구조는

\[\boxed{ \text{Data Generating Distribution} \rightarrow \text{Loss} \rightarrow \text{True Risk} }\]

에서 시작한다.

실제 Training에서는

\[\boxed{ \text{Observed Dataset} \rightarrow \text{Empirical Risk} \rightarrow \text{ERM} \rightarrow \text{Optimization} }\]

으로 진행된다.

그리고 LLM에서는

\[\boxed{ \text{Context} \rightarrow P_\theta( y_t\mid y_{<t} ) \rightarrow \text{Token NLL} \rightarrow \text{Average NLL} \rightarrow \text{Pre-training ERM} }\]

으로 연결된다.

103. 정리

Loss는 한 example의 예측 오차, risk는 데이터 분포에 대한 기대 loss, empirical risk는 관측 표본에서 계산한 평균 loss다. ERM은 \(\hat R(\theta)=\frac1N\sum_i\ell(f_\theta(x_i),y_i)\)를 최소화하지만, 작은 training error만으로 unseen data의 generalization이 보장되지는 않는다.
