CO-01 — Objective Function & Stationary Point

목적함수와 최적화 문제, stationary point의 정의와 판별 구조를 정리한다.

수정 2026.09.18약 52분상태 작성 완료
학습 내용
  • Loss Function
  • Empirical Risk
  • Objective Function
  • Loss, Risk, Objective의 관계

Loss Function

기계학습에서 모델을

\[\hat y = f(\mathbf x;\mathbf{\theta})\]

라고 하자.

여기서

  • \(\mathbf x\): 입력
  • \(y\): 실제 Target
  • \(\hat y\): 모델 Prediction
  • \(\mathbf{\theta}\): 학습할 Parameter

Loss Function은 하나의 Sample에서 모델의 Prediction과 Target 사이의 차이를 측정하는 Scalar Function이다.

\[\boxed{ L( y, f(\mathbf x;\mathbf{\theta}) ) }\]

예를 들어 Regression의 Squared Error는

\[\boxed{ L(y,\hat y) = (y-\hat y)^2 }\]

Classification에서는 Cross-Entropy와 같은 Loss를 사용할 수 있다.

Empirical Risk

Dataset을

\[\mathcal D = \{ (\mathbf x_1,y_1), \dots, (\mathbf x_N,y_N) \}\]

이라고 하자.

각 Sample의 Loss를 평균하면 Empirical Risk를 얻는다.

\[\boxed{ R_{\mathrm{emp}}(\mathbf{\theta}) = \frac1N \sum_{i=1}^{N} L \left( y_i, f(\mathbf x_i;\mathbf{\theta}) \right) }\]

즉

\[\boxed{ \text{Loss} = \text{single-sample error} }\]

이고

\[\boxed{ \text{Empirical Risk} = \text{dataset-average loss} }\]

Objective Function

Optimization Algorithm이 실제로 최소화하거나 최대화하는 최종 함수를 Objective Function이라고 한다.

대표적으로 Empirical Risk에 Regularization을 추가할 수 있다.

\[\boxed{ J(\mathbf{\theta}) = R_{\mathrm{emp}}(\mathbf{\theta}) + \lambda \Omega(\mathbf{\theta}) }\]

L2 Regularization을 사용하는 경우

\[\boxed{ J(\mathbf{\theta}) = \frac1N \sum_{i=1}^{N} L \left( y_i, f(\mathbf x_i;\mathbf{\theta}) \right) + \frac{\lambda}{2} \|\mathbf{\theta}\|_2^2 }\]

와 같이 표현할 수 있다.

Objective Function이 항상 Regularization을 포함해야 하는 것은 아니며, 이 Lecture에서는 대표적인 Regularized Objective의 형태로 사용한다.

Loss, Risk, Objective의 관계

세 개념의 관계는 다음과 같다.

\[\boxed{ \text{Sample} \rightarrow L_i }\]
\[\boxed{ \{L_1,\dots,L_N\} \rightarrow R_{\mathrm{emp}} }\]
\[\boxed{ R_{\mathrm{emp}} + \text{Regularization} \rightarrow J }\]

즉

\[\boxed{ L_i = L( y_i, f(\mathbf x_i;\mathbf{\theta}) ) }\]
\[\boxed{ R_{\mathrm{emp}} = \frac1N\sum_iL_i }\]
\[\boxed{ J = R_{\mathrm{emp}} + \lambda\Omega }\]

로 연결된다.

Optimization Problem

Machine Learning Training을 수학적으로 단순화하면 다음 문제다.

\[\boxed{ \mathbf{\theta}^\ast = \arg\min_{\mathbf{\theta}\in\Theta} J(\mathbf{\theta}) }\]

여기서

\[\Theta\subseteq\mathbb R^D\]

는 Parameter Space다.

Deep Learning에서는 \(D\)가 매우 큰 고차원 공간이 될 수 있다.

Global Minimum

\(\mathbf{\theta}^\ast\)가 Parameter Space 전체에서 가장 작은 함수값을 갖는다면 Global Minimum이다.

\[\boxed{ f(\mathbf{\theta}^\ast) \le f(\mathbf{\theta}) \qquad \forall \mathbf{\theta}\in\Theta }\]

즉 비교 범위가 전체 Parameter Space다.

Local Minimum

\(\mathbf{\theta}^\ast\) 주변의 작은 Neighborhood 안에서만 최소이면 Local Minimum이다.

반경 \(\delta>0\)의 Open Ball을

\[\boxed{ B_\delta(\mathbf{\theta}^\ast) = \left\{ \mathbf{\theta}: \| \mathbf{\theta}- \mathbf{\theta}^\ast \|_2 < \delta \right\} }\]

라고 하자.

어떤 \(\delta>0\)가 존재하여

\[\boxed{ f(\mathbf{\theta}^\ast) \le f(\mathbf{\theta}) }\]

가 모든

\[\mathbf{\theta} \in B_\delta(\mathbf{\theta}^\ast)\]

에 대해 성립하면 Local Minimum이다.

Strict Local Minimum

근방의 모든 다른 점에서 함수값이 엄밀하게 더 크면 Strict Local Minimum이다.

\[\boxed{ f(\mathbf{\theta}^\ast) < f(\mathbf{\theta}) }\]

for

\[\mathbf{\theta} \neq \mathbf{\theta}^\ast\]

in some neighborhood.

즉

\[\boxed{ \text{Strict Local Minimum} \Rightarrow \text{Local Minimum} }\]

Local Maximum

반대로 어떤 Neighborhood에서

\[\boxed{ f(\mathbf{\theta}^\ast) \ge f(\mathbf{\theta}) }\]

가 성립하면 Local Maximum이다.

Strict Local Maximum에서는 주변의 다른 모든 점에 대해

\[\boxed{ f(\mathbf{\theta}^\ast) > f(\mathbf{\theta}) }\]

가 성립한다.

Global과 Local의 차이

Global Minimum은 Parameter Space 전체와 비교한다.

\[\boxed{ \forall\mathbf{\theta}\in\Theta }\]

Local Minimum은 특정 Neighborhood만 비교한다.

\[\boxed{ \mathbf{\theta} \in B_\delta(\mathbf{\theta}^\ast) }\]

따라서 일반적으로

\[\boxed{ \text{Global Minimum} \Rightarrow \text{Local Minimum} }\]

이지만 Local Minimum이 반드시 Global Minimum인 것은 아니다.

Stationary Point

미분 가능한 함수

\[f:\mathbb R^D\rightarrow\mathbb R\]

를 생각한다.

Gradient가 Zero Vector가 되는 점을 Stationary Point라고 한다.

\[\boxed{ \nabla f(\mathbf{\theta}^\ast) = \mathbf0 }\]

Gradient는

\[\boxed{ \nabla f(\mathbf{\theta}) = \begin{bmatrix} \dfrac{\partial f}{\partial\theta_1}\\ \dfrac{\partial f}{\partial\theta_2}\\ \vdots\\ \dfrac{\partial f}{\partial\theta_D} \end{bmatrix} }\]

따라서 Stationary Point에서는 모든 1차 편미분이 동시에 0이다.

Stationary Point의 의미

미소한 Parameter 변화

\[\Delta\mathbf{\theta}\]

에 대해 함수의 1차 변화는

\[\boxed{ \Delta f \approx \nabla f(\mathbf{\theta})^T \Delta\mathbf{\theta} }\]

Stationary Point에서는

\[\nabla f(\mathbf{\theta}^\ast)=0\]

이므로

\[\boxed{ \Delta f_{\text{first-order}} = 0 }\]

즉 1차 Gradient 정보만으로는 어느 방향으로 함수가 증가하거나 감소하는지 알 수 없게 된다.

Critical Point와 Stationary Point

이 Lecture에서는 연속 미분 가능한 Unconstrained Function을 중심으로 다루기 때문에

\[\nabla f(\mathbf{\theta}^\ast)=0\]

인 지점을 주요 Critical Point로 사용한다.

엄밀하게는 Critical Point라는 용어가 Gradient가 존재하지 않는 특이점까지 포함하여 더 넓게 사용될 수도 있다.

여기서는

\[\boxed{ \text{Differentiable setting} \Rightarrow \nabla f=0 }\]

인 Stationary Point에 집중한다.

Stationary Point는 Minimum이 아니다

매우 중요한 점은

\[\boxed{ \nabla f(\mathbf{\theta}^\ast)=0 }\]

만으로

\[\mathbf{\theta}^\ast\]

가 Minimum이라고 결론낼 수 없다는 것이다.

Stationary Point에는

  • Local Minimum
  • Local Maximum
  • Saddle Point
  • Degenerate / Flat Critical Point

등이 포함될 수 있다.

따라서 2차 정보가 필요하다.

Saddle Point

Saddle Point는 어떤 방향으로 움직이면 함수값이 증가하고 다른 방향에서는 감소하는 Stationary Point다.

즉

\[\boxed{ \nabla f(\mathbf{\theta}^\ast) = 0 }\]

이면서 \(\mathbf{\theta}^\ast\)의 임의의 작은 근방에서

\[f(\mathbf{\theta}) > f(\mathbf{\theta}^\ast)\]

인 점과

\[f(\mathbf{\theta}) < f(\mathbf{\theta}^\ast)\]

인 점이 모두 존재한다.

First-Order Necessary Condition

미분 가능한 Unconstrained Function의 내부 Local Extremum에서는 다음 조건이 필요하다.

\[\boxed{ \nabla f(\mathbf{\theta}^\ast) = \mathbf0 }\]

이를 First-Order Necessary Condition, FONC라고 한다.

Necessary Condition이므로

\[\boxed{ \text{Local Optimum} \Rightarrow \nabla f=0 }\]

이지만

\[\boxed{ \nabla f=0 \not\Rightarrow \text{Local Optimum} }\]

FONC 증명 — Direction 설정

임의의 Unit Direction Vector를

\[\mathbf v\in\mathbb R^D, \qquad \|\mathbf v\|_2=1\]

이라고 하자.

다변수 Function을 이 방향으로 제한하여 1변수 보조함수를 정의한다.

\[\boxed{ g(t) = f( \mathbf{\theta}^\ast+t\mathbf v ) }\]

\(\mathbf{\theta}^\ast\)가 Local Minimum이면 \(t=0\)은 \(g(t)\)의 Local Minimum이다.

FONC 증명 — Right Derivative

작은

\[t>0\]

에 대해

\[g(t)\ge g(0)\]

따라서

\[\frac{g(t)-g(0)}{t} \ge0\]

이고

\[\boxed{ g'(0^+)\ge0 }\]

FONC 증명 — Left Derivative

이번에는

\[t<0\]

역시

\[g(t)-g(0)\ge0\]

이지만 분모가 음수이므로

\[\frac{g(t)-g(0)}{t} \le0\]

따라서

\[\boxed{ g'(0^-)\le0 }\]

FONC 증명 — Differentiability

\(g\)가 \(t=0\)에서 미분 가능하면

\[g'(0^-) = g'(0^+)\]

이어야 한다.

그러나

\[g'(0^-)\le0\]

이고

\[g'(0^+)\ge0\]

이므로 두 값이 같으려면

\[\boxed{ g'(0)=0 }\]

이어야 한다.

FONC 증명 — Chain Rule

Chain Rule에 의해

\[g'(0) = \nabla f( \mathbf{\theta}^\ast )^T \mathbf v\]

따라서 모든 Unit Vector \(\mathbf v\)에 대해

\[\boxed{ \nabla f( \mathbf{\theta}^\ast )^T \mathbf v = 0 }\]

이어야 한다.

모든 방향과 Inner Product가 0인 Vector는 Zero Vector뿐이므로

\[\boxed{ \nabla f( \mathbf{\theta}^\ast ) = \mathbf0 }\]

Hessian Matrix

1차 Gradient가 Stationary Point를 찾는 데 사용된다면, 그 점의 형태를 판별하기 위해 2차 미분을 사용한다.

Hessian은 모든 2차 편미분을 모은 Matrix다.

\[\boxed{ \mathbf H(\mathbf{\theta}) = \nabla^2 f(\mathbf{\theta}) }\]

성분은

\[\boxed{ H_{ij} = \frac{ \partial^2f }{ \partial\theta_i \partial\theta_j } }\]

따라서

\[\mathbf H \in \mathbb R^{D\times D}\]

Hessian Symmetry

\(f\)의 Mixed Partial Derivative가 적절한 Regularity Condition 아래 연속이면 Clairaut's Theorem에 의해

\[\frac{ \partial^2f }{ \partial\theta_i \partial\theta_j } = \frac{ \partial^2f }{ \partial\theta_j \partial\theta_i }\]

따라서

\[\boxed{ \mathbf H = \mathbf H^T }\]

즉 Hessian은 Symmetric Matrix다.

Second-Order Taylor Expansion

Stationary Point

\[\mathbf{\theta}^\ast\]

주변에서 작은 Perturbation

\[\Delta\mathbf{\theta}\]

를 생각한다.

2차 Taylor Expansion은

\[\begin{aligned} f( \mathbf{\theta}^\ast + \Delta\mathbf{\theta} ) &= f( \mathbf{\theta}^\ast ) + \nabla f( \mathbf{\theta}^\ast )^T \Delta\mathbf{\theta}\\ &\quad+ \frac12 \Delta\mathbf{\theta}^T \mathbf H( \mathbf{\theta}^\ast ) \Delta\mathbf{\theta} + R_2 \end{aligned}\]

Stationary Point에서의 Taylor Expansion

Stationary Point에서는

\[\nabla f( \mathbf{\theta}^\ast ) = 0\]

따라서 1차 항이 사라진다.

\[\boxed{ \Delta f \approx \frac12 \Delta\mathbf{\theta}^T \mathbf H \Delta\mathbf{\theta} }\]

즉 Stationary Point 근방에서는 Hessian의 Quadratic Form이 함수의 Local Curvature를 결정한다.

Hessian Eigendecomposition

Hessian은 Symmetric Matrix이므로 Orthogonal Eigendecomposition이 가능하다.

\[\boxed{ \mathbf H = \mathbf Q \mathbf\Lambda \mathbf Q^T }\]

여기서

\[\mathbf Q^T\mathbf Q = \mathbf I\]

이고

\[\mathbf\Lambda = \operatorname{diag} ( \lambda_1,\dots,\lambda_D )\]

\(\lambda_i\)는 Hessian Eigenvalue다.

Quadratic Form과 Eigenvalue

다음을 정의한다.

\[\mathbf y = \mathbf Q^T \Delta\mathbf{\theta}\]

그러면

\[\begin{aligned} \Delta\mathbf{\theta}^T \mathbf H \Delta\mathbf{\theta} &= \Delta\mathbf{\theta}^T \mathbf Q \mathbf\Lambda \mathbf Q^T \Delta\mathbf{\theta}\\ &= \mathbf y^T \mathbf\Lambda \mathbf y\\ &= \boxed{ \sum_{i=1}^{D} \lambda_i y_i^2 } \end{aligned}\]

따라서 Hessian Eigenvalue의 부호가 각 Principal Direction의 Curvature를 결정한다.

Positive Definite Hessian

모든 Eigenvalue가 양수라고 하자.

\[\boxed{ \lambda_i>0 \qquad \forall i }\]

그러면 모든

\[\Delta\mathbf{\theta}\neq0\]

에 대해

\[\Delta\mathbf{\theta}^T \mathbf H \Delta\mathbf{\theta} > 0\]

즉

\[\Delta f>0\]

이므로

\[\boxed{ \mathbf H\succ0 \Rightarrow \text{Strict Local Minimum} }\]

Negative Definite Hessian

모든 Eigenvalue가 음수라면

\[\boxed{ \lambda_i<0 \qquad \forall i }\]

따라서

\[\Delta\mathbf{\theta}^T \mathbf H \Delta\mathbf{\theta} < 0\]

이고

\[\Delta f<0\]

그러므로

\[\boxed{ \mathbf H\prec0 \Rightarrow \text{Strict Local Maximum} }\]

Indefinite Hessian

Hessian에 양수 Eigenvalue와 음수 Eigenvalue가 동시에 존재하면

\[\boxed{ \exists i,j: \lambda_i>0, \quad \lambda_j<0 }\]

어떤 Eigenvector 방향으로는 함수가 증가하고 다른 방향으로는 감소한다.

따라서

\[\boxed{ \mathbf H \text{ indefinite} \Rightarrow \text{Saddle Point} }\]

Semi-Definite Hessian

Hessian Eigenvalue 중 0이 존재하고 나머지가 한쪽 부호만 가진다면 2차 Test만으로 판정하지 못할 수 있다.

예를 들어

\[\mathbf H\succeq0\]

이지만 Zero Eigenvalue가 있다면 Higher-Order Term을 확인해야 할 수 있다.

따라서

\[\boxed{ \text{Semi-definite Hessian} \Rightarrow \text{2nd-order test may be inconclusive} }\]

0 Eigenvalue가 있다고 해서 반드시 Minimum이 아니라는 뜻도 아니고 반드시 Saddle이라는 뜻도 아니다.

Hessian 판별 정리

Stationary Point에서 다음과 같이 정리할 수 있다.

Example — Objective Function

다음 함수를 생각한다.

\[\boxed{ f(x,y) = x^3 - 3xy + y^3 }\]

목표는

  1. 모든 Stationary Point 찾기
  2. 각 점에서 Hessian 계산
  3. Eigenvalue를 이용해 Point Type 판별

Example — Gradient

\(x\)에 대해 편미분하면

\[\boxed{ \frac{\partial f}{\partial x} = 3x^2-3y }\]

\(y\)에 대해 편미분하면

\[\boxed{ \frac{\partial f}{\partial y} = -3x+3y^2 }\]

Stationary Point에서는

\[\nabla f(x,y)=0\]

이므로

\[3x^2-3y=0\]
\[-3x+3y^2=0\]

Example — Stationary Equation

첫 번째 식에서

\[\boxed{ y=x^2 }\]

두 번째 식에서는

\[\boxed{ x=y^2 }\]

\(y=x^2\)를 두 번째 식에 대입한다.

\[x=(x^2)^2\]

따라서

\[x=x^4\]

이고

\[x^4-x=0\]

인수분해하면

\[\boxed{ x(x^3-1)=0 }\]

Example — Stationary Points

실수 범위에서

\[x=0\]

또는

\[x=1\]

\(x=0\)이면

\[y=x^2=0\]

이므로

\[\boxed{ \mathbf p_1 = (0,0) }\]

\(x=1\)이면

\[y=1\]

이므로

\[\boxed{ \mathbf p_2 = (1,1) }\]

따라서 Stationary Point는

\[\boxed{ (0,0), \qquad (1,1) }\]

두 개다.

Example — Hessian

2차 편미분은

\[\frac{\partial^2f}{\partial x^2} = 6x\]
\[\frac{\partial^2f}{\partial x\partial y} = -3\]
\[\frac{\partial^2f}{\partial y\partial x} = -3\]
\[\frac{\partial^2f}{\partial y^2} = 6y\]

따라서 Hessian은

\[\boxed{ \mathbf H(x,y) = \begin{bmatrix} 6x & -3\\ -3 & 6y \end{bmatrix} }\]

Example — \((0,0)\)의 Hessian

\((0,0)\)을 대입한다.

\[\boxed{ \mathbf H(0,0) = \begin{bmatrix} 0 & -3\\ -3 & 0 \end{bmatrix} }\]

Eigenvalue를 구하기 위해

\[\det( \mathbf H-\lambda\mathbf I ) = 0\]

을 계산한다.

Example — \((0,0)\)의 Eigenvalue

특성방정식은

\[\det \begin{bmatrix} -\lambda & -3\\ -3 & -\lambda \end{bmatrix} = 0\]

따라서

\[\lambda^2-9=0\]

이고

\[\boxed{ \lambda_1=3, \qquad \lambda_2=-3 }\]

양의 Eigenvalue와 음의 Eigenvalue가 동시에 존재한다.

따라서 Hessian은 Indefinite다.

\[\boxed{ (0,0) = \text{Saddle Point} }\]

함수값은

\[\boxed{ f(0,0)=0 }\]

Example — \((1,1)\)의 Hessian

\((1,1)\)을 Hessian에 대입한다.

\[\boxed{ \mathbf H(1,1) = \begin{bmatrix} 6 & -3\\ -3 & 6 \end{bmatrix} }\]

특성방정식은

\[\det \begin{bmatrix} 6-\lambda & -3\\ -3 & 6-\lambda \end{bmatrix} = 0\]

따라서

\[(6-\lambda)^2-9=0\]

Example — \((1,1)\)의 Eigenvalue

\[(6-\lambda)^2=9\]

이므로

\[6-\lambda=\pm3\]

따라서

\[\boxed{ \lambda_1=9, \qquad \lambda_2=3 }\]

두 Eigenvalue가 모두 양수이므로

\[\boxed{ \mathbf H(1,1)\succ0 }\]

따라서

\[\boxed{ (1,1) = \text{Strict Local Minimum} }\]

Example — Local Minimum Value

함수값을 계산하면

\[\begin{aligned} f(1,1) &= 1^3 - 3(1)(1) + 1^3\\ &= 1-3+1\\ &= \boxed{-1} \end{aligned}\]

따라서

\[\boxed{ f(1,1)=-1 }\]

이 결과는 Local Minimum에 대한 판정이다.

함수

\[x^3-3xy+y^3\]

은 전체 공간에서 아래로 제한되어 있지 않으므로 \((1,1)\)을 Global Minimum이라고 결론내리면 안 된다.

Gradient와 Hessian의 역할

Gradient는 현재 Point의 1차 변화 정보를 나타낸다.

\[\boxed{ \nabla f }\]

Hessian은 Gradient가 Parameter에 따라 어떻게 변하는지 나타내는 2차 정보다.

\[\boxed{ \mathbf H = \nabla^2f }\]

따라서

\[\boxed{ \text{Gradient} \rightarrow \text{Slope} }\]
\[\boxed{ \text{Hessian} \rightarrow \text{Curvature} }\]

로 해석할 수 있다.

Hessian Eigenvector의 의미

Hessian Eigendecomposition을

\[\mathbf H = \mathbf Q \mathbf\Lambda \mathbf Q^T\]

라고 하자.

각 Eigenvector는 Local Curvature의 Principal Direction을 나타낸다.

각 Eigenvalue는 해당 방향의 Curvature Scale을 나타낸다.

\[\boxed{ \mathbf q_i \rightarrow \text{Curvature Direction} }\]
\[\boxed{ \lambda_i \rightarrow \text{Curvature Magnitude and Sign} }\]

Positive Curvature

Eigenvalue가

\[\lambda_i>0\]

이면 해당 Eigenvector 방향으로

\[\Delta f>0\]

이 되는 2차 Curvature를 가진다.

즉 해당 방향은 Bowl처럼 위로 열린다.

Negative Curvature

Eigenvalue가

\[\lambda_i<0\]

이면 해당 방향으로

\[\Delta f<0\]

즉 그 방향에서는 현재 Point에서 이동할수록 함수값이 감소할 수 있다.

Saddle Point에서는 이러한 Negative Curvature Direction이 존재한다.

Flat Direction

Eigenvalue의 절댓값이 매우 작으면

\[|\lambda_i|\approx0\]

해당 방향에서는 2차 Curvature가 작다.

따라서 Parameter를 어느 정도 이동시켜도 함수값 변화가 상대적으로 작을 수 있다.

\[\boxed{ |\lambda_i|\ll1 \rightarrow \text{locally flat direction} }\]

Deep Learning Loss Landscape

Deep Learning에서는 Parameter Dimension이 매우 크다.

\[\boxed{ \mathbf{\theta} \in \mathbb R^D }\]

이고 대규모 Neural Network에서는 \(D\)가 수십억 이상이 될 수도 있다.

따라서 실제 Loss Landscape는 2D 또는 3D 그림으로 완전히 표현할 수 없는 초고차원 공간이다.

고차원 Saddle Point에 대한 원자료의 직관

원자료에서는 고차원 공간에서 Saddle Point가 중요해지는 직관을 설명하기 위해 매우 단순한 Toy Assumption을 사용한다.

각 Hessian Eigenvalue의 부호가 독립적으로

\[P(\lambda_i>0)=\frac12\]

라고 가정한다면 모든 Eigenvalue가 양수일 확률은

\[\boxed{ \left(\frac12\right)^D }\]

\(D\)가 매우 크면 이 값은 빠르게 0으로 간다.

고차원 해석의 주의점

앞의

\[\left(\frac12\right)^D\]

계산은 실제 Neural Network Hessian Eigenvalue의 분포를 설명하는 정리가 아니다.

실제 Eigenvalue들은 독립적인 Bernoulli Sign Variable이 아니며 Loss Landscape의 구조도 훨씬 복잡하다.

따라서 이 식은

\[\boxed{ \text{High dimension makes mixed-curvature configurations combinatorially plausible} }\]

하다는 직관을 제공하는 단순화된 예로 이해한다.

이를 이용해 실제 LLM의 임계점 중 정확히 몇 퍼센트가 Saddle이라고 계산할 수는 없다.

Saddle Point와 Optimization

Saddle Point에서는

\[\nabla f\approx0\]

일 수 있지만 Negative Curvature Direction이 존재할 수 있다.

따라서 Gradient Magnitude만 보면 학습이 정체된 것처럼 보일 수 있다.

Optimization에서는

  • stochastic gradient noise
  • momentum
  • adaptive update
  • curvature
  • batch noise

등 여러 요소가 이러한 영역의 Dynamics에 영향을 준다.

원자료에서는 Momentum, AdamW, RMSprop 등의 Optimizer를 이러한 정체 영역에서 이동하는 문제와 연결한다.

Plateau

Hessian Eigenvalue의 상당수가 매우 작은 영역에서는

\[|\lambda_i|\approx0\]

인 방향이 많을 수 있다.

이러한 영역에서는 Loss가 Parameter 변화에 대해 천천히 변한다.

이를 직관적으로 Plateau 또는 Flat Region이라고 부를 수 있다.

Gradient 역시 작다면 Optimization Progress가 느려질 수 있다.

Flat Minimum

원자료에서는 Local Minimum 주변의 Curvature가 비교적 작은 경우를 Flat Minimum으로 설명한다.

직관적으로

\[\boxed{ \lambda_{\max}(\mathbf H) \text{ relatively small} }\]

이면 여러 방향에서 Parameter Perturbation에 대한 Loss 증가가 비교적 완만할 수 있다.

2차 근사에서는

\[\Delta f \approx \frac12 \Delta\mathbf{\theta}^T \mathbf H \Delta\mathbf{\theta}\]

이므로 Curvature가 작으면 동일한 Parameter Perturbation에 대한 Loss 변화도 작아질 수 있다.

Sharp Minimum

반대로 Hessian의 큰 Positive Eigenvalue가 존재하면 특정 방향의 Curvature가 매우 크다.

\[\boxed{ \lambda_{\max}(\mathbf H) \text{ large} }\]

이면 해당 방향으로 작은 Parameter Perturbation을 가해도 Loss가 빠르게 증가할 수 있다.

이를 직관적으로 Sharp Minimum이라고 부른다.

Flatness와 Generalization

원자료에서는 Flat Minimum을 Parameter Perturbation에 상대적으로 Robust한 Solution과 연결하고 Sharp Minimum을 Generalization Risk와 연결한다.

다만 현대 Deep Learning에서 단순한 Hessian Eigenvalue나 Sharpness 값과 Generalization 사이의 관계는 Parameterization과 Scaling 등에 영향을 받을 수 있다.

따라서

\[\boxed{ \text{flat} \Rightarrow \text{always better generalization} }\]

이라는 절대적인 정리로 이해하지 않는다.

이 Lecture에서는 Loss Landscape의 Local Curvature를 이해하기 위한 직관으로 사용한다.

Quantization과 Parameter Perturbation

원자료에서는 Flatness를 Quantization이나 Fine-Tuning 과정의 Parameter Perturbation과도 연결한다.

2차 근사에서 Parameter 변화

\[\Delta\mathbf{\theta}\]

에 대한 Loss 변화는

\[\boxed{ \Delta f \approx \frac12 \Delta\mathbf{\theta}^T \mathbf H \Delta\mathbf{\theta} }\]

따라서 동일한 Perturbation이라도 높은 Curvature Direction에서는 Loss 변화가 더 클 수 있다는 직관을 얻을 수 있다.

핵심 최적성 조건

First-Order Necessary Condition

\[\boxed{ \nabla f( \mathbf{\theta}^\ast ) = 0 }\]

Positive Definite Hessian

\[\boxed{ \mathbf H( \mathbf{\theta}^\ast ) \succ0 \Rightarrow \text{Strict Local Minimum} }\]

Negative Definite Hessian

\[\boxed{ \mathbf H( \mathbf{\theta}^\ast ) \prec0 \Rightarrow \text{Strict Local Maximum} }\]

Indefinite Hessian

\[\boxed{ \mathbf H( \mathbf{\theta}^\ast ) \text{ indefinite} \Rightarrow \text{Saddle Point} }\]

Necessary와 Sufficient를 구분하기

Local Minimum에서 Gradient가 0이라는 것은 Necessary Condition이다.

\[\boxed{ \text{Local Min} \Rightarrow \nabla f=0 }\]

하지만 그 역은 성립하지 않는다.

\[\boxed{ \nabla f=0 \not\Rightarrow \text{Local Min} }\]

반면 Stationary Point에서 Hessian이 Positive Definite라면 Strict Local Minimum을 보장하는 Sufficient Condition이 된다.

\[\boxed{ \nabla f=0 \;\land\; \mathbf H\succ0 \Rightarrow \text{Strict Local Min} }\]

Semi-Definite Case 주의

다음 조건만으로는

\[\nabla f=0\]

그리고

\[\mathbf H\succeq0\]

인 점을 항상 Strict Local Minimum이라고 할 수 없다.

Zero Curvature Direction에서는 3차, 4차 이상의 Higher-Order Term이 Point Type을 결정할 수 있기 때문이다.

따라서

\[\boxed{ \mathbf H\succeq0 \text{ with zero eigenvalues} \Rightarrow \text{inconclusive in general} }\]

Objective Function 관점의 전체 연결

Machine Learning에서는 먼저 Sample-Level Loss를 정의한다.

\[\boxed{ L_i }\]

이를 Dataset 전체에서 평균한다.

\[\boxed{ R_{\mathrm{emp}} = \frac1N \sum_iL_i }\]

필요하면 Regularization을 추가한다.

\[\boxed{ J = R_{\mathrm{emp}} + \lambda\Omega }\]

Optimization은

\[\boxed{ \min_{\mathbf{\theta}} J(\mathbf{\theta}) }\]

를 수행한다.

Local Geometry 관점의 전체 연결

Optimization Point를 분석할 때 먼저

\[\boxed{ \nabla J( \mathbf{\theta}^\ast ) = 0 }\]

인 Stationary Point를 찾는다.

그다음

\[\boxed{ \mathbf H = \nabla^2J }\]

를 계산한다.

Eigenvalue를 통해 Local Geometry를 판별한다.

\[\boxed{ \text{Gradient} \rightarrow \text{Stationary Point} \rightarrow \text{Hessian} \rightarrow \text{Eigenvalues} \rightarrow \text{Local Geometry} }\]

Example 결과 정리

주어진 함수는

\[f(x,y) = x^3-3xy+y^3\]

Stationary Point는

\[\boxed{ (0,0), \qquad (1,1) }\]

\((0,0)\)에서는

\[\boxed{ \lambda_1=3, \qquad \lambda_2=-3 }\]

이므로

\[\boxed{ (0,0) = \text{Saddle Point} }\]

\((1,1)\)에서는

\[\boxed{ \lambda_1=9, \qquad \lambda_2=3 }\]

이므로

\[\boxed{ (1,1) = \text{Strict Local Minimum} }\]

그리고

\[\boxed{ f(1,1)=-1 }\]

정리

Machine Learning의 Optimization은 모델의 Parameter를 조정하여 Objective Function을 최소화하는 문제다.

단일 Sample에서는 Loss를 계산한다.

\[\boxed{ L( y, f(\mathbf x;\mathbf{\theta}) ) }\]

Dataset 전체에서는 Empirical Risk를 계산한다.

\[\boxed{ R_{\mathrm{emp}} = \frac1N \sum_{i=1}^{N} L_i }\]

Regularization을 포함한 대표적인 Objective는

\[\boxed{ J( \mathbf{\theta} ) = R_{\mathrm{emp}}( \mathbf{\theta} ) + \lambda \Omega( \mathbf{\theta} ) }\]

Optimization은

\[\boxed{ \mathbf{\theta}^\ast = \arg\min_{\mathbf{\theta}} J( \mathbf{\theta} ) }\]

를 찾는다.

미분 가능한 Unconstrained Problem의 Interior Local Optimum에서는

\[\boxed{ \nabla J( \mathbf{\theta}^\ast ) = 0 }\]

이 필요하다.

하지만 Gradient가 0이라는 사실만으로 Minimum이라고 판단할 수 없다.

따라서 Hessian을 사용한다.

\[\boxed{ \mathbf H = \nabla^2J }\]

Stationary Point에서

\[\boxed{ \mathbf H\succ0 \Rightarrow \text{Strict Local Minimum} }\]
\[\boxed{ \mathbf H\prec0 \Rightarrow \text{Strict Local Maximum} }\]
\[\boxed{ \mathbf H \text{ indefinite} \Rightarrow \text{Saddle Point} }\]

Hessian의 Eigenvalue는 각 Principal Direction의 Local Curvature를 나타낸다.

\[\boxed{ \Delta J \approx \frac12 \sum_{i=1}^{D} \lambda_i y_i^2 }\]

따라서 Optimization의 핵심 흐름은

\[\boxed{ \text{Objective Function} \rightarrow \text{Gradient} \rightarrow \text{Stationary Point} \rightarrow \text{Hessian} \rightarrow \text{Curvature} }\]

Deep Learning에서는 이 구조가 초고차원 Parameter Space로 확장된다.

\[\boxed{ \mathbf{\theta} \in \mathbb R^D, \qquad D\gg1 }\]

이때 Saddle Direction, Flat Direction, Sharp Curvature와 같은 Local Geometry가 Optimization Dynamics를 이해하는 중요한 도구가 된다.

전체 연결은 다음과 같다.

\[\boxed{ \text{Loss} \rightarrow \text{Empirical Risk} \rightarrow \text{Objective} \rightarrow \text{Optimization} }\]

그리고 Local Geometry는

\[\boxed{ \nabla J \rightarrow \nabla J=0 \rightarrow \nabla^2J \rightarrow \text{Eigenvalues} \rightarrow \begin{cases} \text{Local Minimum}\\ \text{Local Maximum}\\ \text{Saddle Point} \end{cases} }\]

로 연결된다.

정리

최적화는 feasible set 안에서 목적함수 \(J(\theta)\)의 최솟값 또는 최댓값을 찾는 문제다. \(\nabla J(\theta)=0\)은 미분 가능한 내부점의 후보 조건이며, Hessian의 곡률과 제약 조건을 함께 살펴야 local optimum, global optimum, saddle point를 구분할 수 있다.
