IT-02 — Shannon Entropy

Shannon Entropy의 정의와 성질, 불확실성의 평균 정보량을 정리한다.

정보이론 · IT-02업데이트 2026.09.18

  • #Uncertainty
  • #Expected Information
  • #Information Theory

개념

Shannon EntropyIT-01에서 하나의 사건 \(x\)가 발생했을 때 얻는 자기정보량(Self-Information)을 \(I(x) = -\log_b p(x)\) 로 정의했다.

Shannon Entropy는 이 자기정보량을 확률변수 전체에 대해 평균낸 값이다.

\[\boxed{ H(X) = \mathbb E[I(X)] }\]

즉 Self-Information → Expected Self-Information → Entropy 로 연결된다.

Entropy의 의미Self-Information은 특정 Outcome 하나의 Surprise를 나타낸다.

\[\boxed{ I(x) = \text{information of one outcome} }\]

Entropy는 가능한 모든 Outcome의 Self-Information을 Probability로 가중평균한다.

\[\boxed{ H(X) = \text{average information} }\]

따라서 분포 전체의 평균적인 불확실성을 측정한다.

Weighted Average 구조Entropy Formula는 다음과 같다.

\[H(X) = \sum_x p(x)I(x)\]

즉 각 Outcome의 Information \(I(x)\) 에 그 Outcome이 실제로 관측될 Probability \(p(x)\) 를 가중치로 사용한다.

따라서 매우 희귀한 사건은 개별 Self-Information은 크더라도 발생 Probability 자체가 작기 때문에 Entropy에는 \(p(x)I(x)\) 만큼 기여한다.

표기·차원

Discrete Random Variable이산 확률변수 \(X\in\mathcal X\) 를 생각한다.

가능한 값의 집합을 \(\mathcal X = \{x_1,\dots,x_V\}\) 라고 하고 PMF를 \(P(X=x) = p(x)\) 라고 하자.

확률은 \(p(x)\ge0\) 이고 \(\sum_{x\in\mathcal X} p(x)=1\) 을 만족한다.

Self-Information특정 Outcome \(x\)가 관측되었을 때 자기정보량은 다음과 같다.

\[\boxed{ I(x) = -\log_b p(x) }\]

확률이 높으면 정보량은 작고, \(p(x)\uparrow \Rightarrow I(x)\downarrow\) 확률이 낮으면 정보량은 커진다 (\(p(x)\downarrow \Rightarrow I(x)\uparrow\)).

핵심 연산

Entropy as Expected Self-InformationShannon Entropy는 자기정보량의 기댓값이다.

\[H(X) = \mathbb E_{X\sim P} [ I(X) ]\]

\(I(X)=-\log_b p(X)\)를 대입하면 다음과 같다.

\[\boxed{ H(X) = \mathbb E_{X\sim P} [ -\log_b p(X) ] }\]

Shannon Entropy Formula이산 확률변수의 기댓값 정의를 적용하면 다음과 같다.

\[H(X) = \sum_{x\in\mathcal X} p(x) [ -\log_b p(x) ]\]

따라서 다음과 같다.

\[\boxed{ H(X) = -\sum_{x\in\mathcal X} p(x)\log_b p(x) }\]

\(0\log0\) Convention어떤 Outcome의 Probability가 \(p(x)=0\) 일 수 있다.

Entropy Formula에는 \(p(x)\log p(x)\) 가 등장하므로 직접 대입하면 \(\log0\) 문제가 발생한다.

정보이론에서는 다음 극한을 사용한다.

\[\boxed{ \lim_{p\rightarrow0^+} p\log p = 0 }\]

따라서 \(0\log0 \triangleq 0\) 으로 정의한다.

왜 \(p\log p\rightarrow0\)인가\(p\rightarrow0^+\)이면 다음과 같다.

\[\log p\rightarrow-\infty\]

이지만 동시에:

\[p\rightarrow0\]

곱 전체의 극한은 다음과 같다.

\[\boxed{ \lim_{p\rightarrow0^+} p\log p=0 }\]

따라서 Probability가 0인 Outcome은 Entropy Sum에 0만큼 기여한다.

Information UnitIT-01과 마찬가지로 Logarithm의 Base가 Entropy 단위를 결정한다.

Base 2

\[\boxed{ H_2(X) = -\sum_xp(x)\log_2p(x) }\]

단위는 bits이다.

Base \(e\)

\[\boxed{ H_e(X) = -\sum_xp(x)\ln p(x) }\]

단위는 nats이다.

Base 10

\[\boxed{ H_{10}(X) = -\sum_xp(x)\log_{10}p(x) }\]

단위는 Hartley 또는 dit다.

Non-Negativity모든 Probability는 \(0\le p(x)\le1\)이다.

\(p(x)>0\)이면 \(\log_b p(x)\le0\) 따라서 \(-p(x)\log_bp(x)\ge0\) 모든 항을 더하면 \(H(X)\ge0\)

핵심 식 — Definition

\[\boxed{ H(X) = \mathbb E[ I(X) ] }\]

Self-Information을 대입하면 다음과 같다.

\[\boxed{ H(X) = \mathbb E[ -\log_b p(X) ] }\]

이산형에서는 다음과 같다.

\[\boxed{ H(X) = -\sum_x p(x)\log_bp(x) }\]

핵심 식 — Bounds\(V\)개의 Outcome에 대해 \(0 \le H(X) \le \log_bV\) Minimum:

\[\boxed{ H(X)=0 }\]

for a deterministic distribution.

Maximum:

\[\boxed{ H(X)=\log_bV }\]

for:

\[\boxed{ p_i=\frac1V }\]

핵심 식 — TemperatureSoftmax with Temperature는 다음과 같다.

\[\boxed{ p_i(T) = \frac{ e^{z_i/T} }{ \sum_j e^{z_j/T} } }\]

고정된 유한 Logit에 대해 \(T\rightarrow\infty \Rightarrow p_i\rightarrow\frac1V\) 이고:

\[\boxed{ H\rightarrow\log V }\]

고유한 최대 Logit이 있는 경우 \(T\rightarrow0^+ \Rightarrow \mathbf p \rightarrow \text{one-hot}\) 이고:

\[\boxed{ H\rightarrow0 }\]

성질·유도

Zero Entropy어떤 하나의 Outcome \(x_k\)가 확실하게 발생한다고 하자.

\(p(x_k)=1\) 이고 다른 모든 Outcome에 대해:

\[p(x_i)=0 \qquad (i\neq k)\]

그러면 \(-\log_b1=0\) 이고 \(0\log0=0\)이므로 다음과 같이 쓴다.

\[\boxed{ H(X)=0 }\]

Deterministic DistributionEntropy가 0인 대표적인 분포는 \(\mathbf p = [1,0,\dots,0]\) 과 같은 Deterministic Distribution이다.

어떤 Outcome이 발생할지 이미 확실하므로 관측 전의 불확실성이 없다.

따라서 다음과 같다.

\[\boxed{ \text{Deterministic} \rightarrow H(X)=0 }\]

Uniform Distribution가능한 Outcome이 \(V\)개이고 모두 동일한 Probability를 가진다고 하자.

\[\boxed{ p(x_i)=\frac1V }\]

이때 어느 Outcome이 발생할지 가장 구분하기 어려운 형태의 분포가 된다.

원자료에서는 이것이 \(V\)개의 Outcome을 가진 이산분포 가운데 Maximum Entropy Distribution임을 증명한다.

Uniform EntropyUniform Distribution에서는 다음과 같다.

\[H(X) = -\sum_{i=1}^{V} \frac1V \log_b \frac1V\]

모든 항이 같으므로 다음과 같이 쓴다.

\[H(X) = - V\frac1V \log_b\frac1V\]

따라서 다음과 같다.

\[\boxed{ H(X) = \log_bV }\]

Entropy Range\(V\)개의 가능한 Outcome을 가진 이산 확률변수에 대해 원자료가 다루는 Entropy Range는 \(0 \le H(X) \le \log_bV\)이다.

Base 2라면 \(0 \le H(X) \le \log_2V\) 최솟값은 Deterministic Distribution에서, 최댓값은 Uniform Distribution에서 얻어진다.

Maximum Entropy Problem가능한 Outcome의 수를 \(V = |\mathcal X|\) 라고 하자.

Entropy를 최대화하는 Probability Vector \(\mathbf p = [p_1,\dots,p_V]^T\) 를 찾는다.

목적함수는 다음과 같다.

\[\boxed{ H(\mathbf p) = -\sum_{i=1}^{V} p_i\ln p_i }\]

여기서는 편의를 위해 Natural Log를 사용한다.

Probability ConstraintProbability Vector는 정규화 조건을 만족해야 한다.

\[\boxed{ \sum_{i=1}^{V}p_i=1 }\]

따라서 Optimization Problem은 다음과 같다.

\[\boxed{ \max_{\mathbf p} - \sum_{i=1}^{V} p_i\ln p_i }\]

subject to:

\[\boxed{ \sum_{i=1}^{V}p_i=1 }\]

LagrangianConstraint를 포함한 Lagrangian을 구성한다.

\[\boxed{ \mathcal L( p_1,\dots,p_V,\lambda ) = -\sum_{i=1}^{V} p_i\ln p_i + \lambda \left( \sum_{i=1}^{V}p_i-1 \right) }\]

First-Order Condition각 \(p_k\)에 대해 편미분한다.

\[\frac{\partial}{\partial p_k} [ -p_k\ln p_k ] = -(\ln p_k+1)\]

따라서 다음과 같다.

\[\boxed{ \frac{\partial\mathcal L} {\partial p_k} = -1-\ln p_k+\lambda }\]

Stationary Condition은 다음과 같다.

\[\boxed{ -1-\ln p_k+\lambda=0 }\]

Probability Solution식을 정리하면 다음과 같다.

\[\ln p_k = \lambda-1\]

따라서 다음과 같다.

\[\boxed{ p_k = e^{\lambda-1} }\]

오른쪽은 \(k\)에 의존하지 않는다.

즉 모든 Probability가 동일해야 한다.

\[\boxed{ p_1 = p_2 = \cdots = p_V = C }\]

Normalization 적용정규화 조건에 대입하면 다음과 같다.

\[\sum_{i=1}^{V}C = VC = 1\]

따라서 다음과 같다.

\[\boxed{ C = \frac1V }\]

즉 Entropy를 극대화하는 Candidate는 다음과 같다.

\[\boxed{ p_i = \frac1V }\]

Maximum Entropy ValueUniform Distribution을 Entropy Formula에 대입한다.

\[\begin{aligned} H_{\max}(X) &= -\sum_{i=1}^{V} \frac1V \log_2\frac1V\\ &= - V \frac1V \log_2\frac1V\\ &= -\log_2\frac1V\\ &= \boxed{ \log_2V } \end{aligned}\]

따라서 \(H(X)\le\log_2V\)

왜 이것이 Maximum인가함수 \(-p\ln p\) 의 두 번째 미분은 다음과 같다.

\[-\frac1p\]

\(p>0\)에서 \(-\frac1p<0\) 이므로 각 항은 Concave하다.

따라서 Entropy:

\[-\sum_i p_i\ln p_i\]

역시 Probability Simplex 내부에서 Concave Function이다.

원자료의 Lagrange 유도로 얻은 Uniform Stationary Point가 Entropy Maximum과 연결된다.

Maximum Entropy 결과결론은 다음과 같다.

\(p_1=\cdots=p_V=\frac1V\) 일 때:

\[\boxed{ H(X)=\log_2V }\]

따라서 \(0 \le H(X) \le \log_2V\)

Jensen's Inequality원자료에서는 동일한 Upper Bound \(H(X)\le\log_2V\) 를 Jensen's Inequality로도 증명한다.

Logarithm \(f(t)=\log_2t\) 를 생각한다.

Concavity of Log1차 미분은 다음과 같다.

\[f'(t) = \frac1{t\ln2}\]

2차 미분은 다음과 같다.

\[\boxed{ f''(t) = - \frac1{t^2\ln2} <0 }\]

for:

\[t>0\]

따라서 \(\log_2t \text{ is strictly concave}\)

Jensen's Inequality for Concave FunctionsConcave Function \(f\)에 대해 Jensen's Inequality는 \(\mathbb E[f(Y)] \le f( \mathbb E[Y] )\)이다.

Logarithm을 사용하면 \(\mathbb E[ \log Y ] \le \log \mathbb E[Y]\)

Entropy의 새로운 표현Entropy는 다음과 같다.

\[H(X) = -\sum_i p_i\log_2p_i\]

이를 \(-\log_2p_i = \log_2\frac1{p_i}\) 로 바꾸면:

\[\boxed{ H(X) = \sum_i p_i \log_2 \frac1{p_i} }\]

따라서 다음과 같다.

\[\boxed{ H(X) = \mathbb E \left[ \log_2 \frac1{p(X)} \right] }\]

Jensen 적용다음을 정의한다.

\[\boxed{ Y = \frac1{p(X)} }\]

그러면:

\[H(X) = \mathbb E[\log_2Y]\]

Jensen's Inequality에 의해 \(H(X) \le \log_2 \mathbb E[Y]\)

Expectation 계산원자료의 양의 Probability를 갖는 \(V\)개 Outcome 설정에서는 다음과 같다.

\[\begin{aligned} \mathbb E[Y] &= \sum_{i=1}^{V} p_i \frac1{p_i}\\ &= \sum_{i=1}^{V}1\\ &= V \end{aligned}\]

따라서 \(H(X) \le \log_2V\)

Jensen Equality ConditionStrictly Concave Function에서 Jensen Equality가 성립하려면 \(Y\)가 거의 확실하게 상수여야 한다.

여기서는 \(\frac1{p(X)} = C\) 이어야 하므로 \(p(X)\) 도 동일한 값을 가져야 한다.

정규화에 의해:

\[\boxed{ p_i = \frac1V }\]

따라서 Jensen 관점에서도 Uniform Distribution에서 Maximum Entropy를 얻는다.

두 증명의 관계

Lagrange Multiplier

\[\boxed{ \text{Constrained Optimization} \rightarrow p_i=\frac1V }\]

Jensen's Inequality

\[\boxed{ \text{Concavity} \rightarrow H(X)\le\log V }\]

두 방식 모두 \(H_{\max} = \log V\) 를 얻는다.

혼동하기 쉬운 부분

  • Entropy와 Surprise:특정 Token의 Probability가 낮을 때 그 Token의 Self-Information은 높다 (\(p(x)\downarrow \Rightarrow I(x)\uparrow\)).

    하지만 Entropy는 하나의 Token Probability만으로 결정되지 않는다.

    전체 Probability Distribution을 사용한다.

    \[\boxed{ H(X) = -\sum_xp(x)\log p(x) }\]

  • High Entropy:High Entropy는 uncertainty / spread 가 크다는 의미다.

    그 자체로 다음과 같이 쓴다.

    • 좋다
    • 나쁘다
    • 정확하다
    • 환각한다

    중 어느 것도 직접 의미하지 않는다.

    Entropy는 Probability Distribution의 불확실성을 나타내는 Quantity다.

  • Low Entropy:Low Entropy는 Probability Mass가 일부 Outcome에 강하게 집중되어 있다는 뜻이다.

    하지만 Low Entropy ≠ Correct Prediction

    잘못된 Token에 거의 모든 Probability를 부여해도 Entropy는 낮다.

  • Maximum Entropy:Maximum Entropy는 가능한 Outcome 수 \(V\) 가 고정된 상황에서 Uniform Distribution이 갖는다.

    \[\boxed{ H_{\max} = \log V }\]

    Support Size가 달라지면 Maximum Entropy 자체도 달라진다.

    IT-01의 Self-Information은 하나의 Outcome이 주는 Information을 나타낸다.

    \[\boxed{ I(x) = -\log_b p(x) }\]

    Shannon Entropy는 이를 Distribution 전체에 대해 평균한 값이다.

    \[\boxed{ H(X) = \mathbb E[I(X)] }\]

    따라서 이산 확률변수에서는 다음과 같다.

    \[\boxed{ H(X) = -\sum_{x\in\mathcal X} p(x)\log_b p(x) }\]

    Probability가 0인 항은 \(0\log0 \triangleq0\) 으로 처리한다.

    Entropy는 항상 비음수다 (\(H(X)\ge0\)).

    하나의 Outcome이 확실하면 다음과 같다.

    \[\boxed{ H(X)=0 }\]

    \(V\)개의 가능한 Outcome이 있을 때 Maximum Entropy는 Uniform Distribution에서 발생한다.

    \(p_i = \frac1V\) 이고:

    \[\boxed{ H_{\max} = \log_bV }\]

    따라서 \(0 \le H(X) \le \log_bV\) 원자료에서는 이 결과를 두 방식으로 확인한다.

    \[\boxed{ \text{Lagrange Multipliers} \rightarrow p_i=\frac1V }\]

    그리고 다음과 같다.

    \[\boxed{ \text{Jensen's Inequality} \rightarrow H(X)\le\log V }\]

    Temperature Softmax에서는 \(p_i(T) = \frac{ e^{z_i/T} }{ \sum_j e^{z_j/T} }\) 를 사용한다.

    원자료의:

    \[\mathbf z = [4,2,1,0]^T\]

    예제에서는 다음과 같다.

    \[\boxed{ H_{T=10} \approx 1.9837\text{ bits} }\]
    \[\boxed{ H_{T=1} \approx 0.8586\text{ bits} }\]
    \[\boxed{ H_{T=0.2} \approx 0.0007\text{ bits} }\]

    즉 높은 Temperature에서는 분포가 Uniform에 가까워지고 Entropy가 증가하며, 낮은 Temperature에서는 Probability Mass가 최대 Logit에 집중되어 Entropy가 감소한다.

    LLM에서는 특정 Context \(y_{<t}\) 가 주어졌을 때 Next-Token Distribution의 Entropy \(H( Y_t\mid y_{<t} )\) 를 해당 Position에서 모델이 가진 Predictive Uncertainty의 척도로 볼 수 있다.

    전체 개념 흐름은 Probability → Self-Information → Expected Self-Information → Shannon Entropy이다.

    IT-01과 연결하면 \(-\log p(x) \rightarrow \mathbb E[-\log p(X)]\) 이고 Self-Information → Entropy

    LLM 관점에서는 Logits → Softmax Distribution → Entropy → Next-Token Uncertainty 로 연결된다.

따라서 다음과 같다.

\[\boxed{ H_{T=10} \approx 1.9837\text{ bits} }\]

최대값 \(2\text{ bits}\) 에 매우 가깝다.

Example — \(T=1\)Temperature가 \(T=1\) 이면 원래 Logit을 그대로 Softmax에 사용한다.

\[\boxed{ \mathbf z = [4,2,1,0]^T }\]

Exponential은 다음과 같다.

\[e^4\approx54.5982\]
\[e^2\approx7.3891\]
\[e^1\approx2.7183\]
\[e^0=1\]

\(T=1\) Softmax분모는 다음과 같다.

\[\boxed{ Z \approx 65.7056 }\]

따라서 다음과 같다.

\[\boxed{ \mathbf p_{T=1} \approx \begin{bmatrix} 0.8309\\ 0.1125\\ 0.0414\\ 0.0152 \end{bmatrix} }\]

\(T=1\) Entropy각 Contribution은 다음과 같다.

\[-0.8309 \log_2(0.8309) \approx 0.2220\]
\[-0.1125 \log_2(0.1125) \approx 0.3546\]
\[-0.0414 \log_2(0.0414) \approx 0.1902\]
\[-0.0152 \log_2(0.0152) \approx 0.0918\]

따라서 다음과 같다.

\[\boxed{ H_{T=1} \approx 0.8586\text{ bits} }\]

Example — \(T=0.2\)Temperature가 \(T=0.2\) 이면 다음과 같다.

\[\boxed{ \frac{\mathbf z}{0.2} = \begin{bmatrix} 20\\ 10\\ 5\\ 0 \end{bmatrix} }\]

가장 큰 Logit과 나머지 Logit 사이의 차이가 크게 확대된다.

\(T=0.2\) Softmax원자료의 Probability는 근사적으로 다음과 같이 쓴다.

\[\boxed{ \mathbf p_{T=0.2} \approx \begin{bmatrix} 0.999955\\ 0.000045\\ 0.000000\\ 0.000000 \end{bmatrix} }\]

이 식보다 정확히는 뒤의 두 Probability도 0은 아니지만 매우 작다.

분포는 거의 One-Hot 형태가 된다.

\(T=0.2\) EntropyEntropy는 원자료의 계산에서 다음과 같이 쓴다.

\[\boxed{ H_{T=0.2} \approx 0.0007\text{ bits} }\]

즉 다음과 같다.

\[\boxed{ H_{T=0.2} \approx0 }\]

분포의 Probability Mass가 거의 하나의 Token에 집중되기 때문이다.

Temperature별 비교세 결과를 비교하면 다음과 같다.

이번 고정된 Logit Example에서는 \(T\uparrow \Rightarrow H\uparrow\) \(T\downarrow \Rightarrow H\downarrow\) 가 명확하게 나타난다.

High-Temperature Limit고정된 유한 Logit \(z_1,\dots,z_V\) 에 대해 \(T\rightarrow\infty\) 이면 다음과 같다.

\[\frac{z_i}{T} \rightarrow0\]

따라서 \(e^{z_i/T} \rightarrow1\) 이고:

\[\boxed{ p_i(T) \rightarrow \frac1V }\]

High-Temperature EntropyUniform Distribution으로 수렴하므로 다음과 같이 쓴다.

\[\boxed{ T\rightarrow\infty \Rightarrow H(X) \rightarrow \log_2V }\]

\(V=4\)라면:

\[\boxed{ H(X)\rightarrow2\text{ bits} }\]

Low-Temperature Limit고유한 최대 Logit이 존재한다고 하자.

\[z_c > z_j \qquad (j\neq c)\]

\(T\rightarrow0^+\)이면 최대 Logit과 나머지 Logit의 Softmax Ratio가 극단적으로 커진다.

따라서 \(p_c\rightarrow1\) 이고:

\[\boxed{ p_j\rightarrow0 \qquad (j\neq c) }\]

Low-Temperature Entropy분포가 One-Hot 형태로 수렴하므로 다음과 같이 쓴다.

\[\boxed{ T\rightarrow0^+ \Rightarrow H(X)\rightarrow0 }\]

즉 Temperature는 고정된 Logit Distribution의 Concentration과 Entropy를 변화시킨다.

Temperature와 LLMAutoregressive LLM의 한 Token Position에서 Logit Vector를 \(\mathbf z_t\) 라고 하자.

Temperature를 적용하면 다음과 같다.

\[\boxed{ P_T( y_t=w_i \mid y_{<t} ) = \frac{ e^{z_{t,i}/T} }{ \sum_j e^{z_{t,j}/T} } }\]

이 분포의 Entropy는 \(H_T( Y_t\mid y_{<t} ) = -\sum_i p_{t,i}(T) \log p_{t,i}(T)\) 와 같이 계산할 수 있다.

Next-Token Uncertainty특정 Context \(y_{<t}\) 가 고정된 상태에서 Next-Token Distribution의 Entropy가 높으면 여러 Token에 Probability Mass가 넓게 퍼져 있다.

반대로 Entropy가 낮으면 Probability Mass가 일부 Token에 집중되어 있다.

따라서 High Entropy → more diffuse next-token distribution

Low Entropy → more concentrated next-token distribution 으로 해석할 수 있다.

Entropy와 Model Confidence원자료에서는 낮은 출력 Entropy를 높은 Confidence와 연결한다.

이는 출력 Distribution 자체에 대해서는 다음과 같은 의미를 가진다 (\(H\downarrow \Rightarrow \text{probability mass becomes more concentrated}\)).

하지만 낮은 Entropy가 곧 모델의 Prediction이 정확하다는 뜻은 아니다.

틀린 Token에 \(p\approx1\) 을 부여하는 경우에도 Entropy는 낮을 수 있다.

따라서 Low Entropy ≠ Guaranteed Correctness 로 구분해야 한다.

Entropy와 Pre-training Monitoring원자료에서는 Training 과정에서 출력 Entropy의 변화를 Model Confidence와 연결한다.

이때 관찰할 수 있는 Quantity는 특정 Context에서의 출력 Probability Distribution \(P_\theta( Y_t\mid y_{<t} )\) 의 Entropy다.

하지만 Training이 진행되면 모든 Context에서 Entropy가 단조롭게 감소해야 한다는 일반 법칙은 이 자료에서 증명되지 않는다.

따라서 출력 Entropy는 하나의 분포 집중도 지표로 이해하는 것이 적절하다.

High Temperature와 Generation원자료에서는 높은 Temperature를 생성 다양성 증가와 연결한다.

수학적으로 직접 보장되는 부분은 \(T\uparrow \Rightarrow \text{distribution becomes flatter}\) 이고 극한적으로 \(T\rightarrow\infty \Rightarrow p_i\rightarrow1/V\) 라는 점이다.

이 때문에 Sampling 시 다양한 Token이 선택될 가능성이 증가할 수 있다.

Hallucination에 대한 주의원자료에서는 높은 Temperature와 Hallucination 증가를 연결하지만, \(T\uparrow \Rightarrow \text{Hallucination necessarily increases}\) 는 Shannon Entropy 정의만으로 도출되는 수학적 정리는 아니다.

Entropy가 직접 측정하는 것은 출력 Distribution의 불확실성이지 사실성(Factuality)이 아니다.

이 Lecture에서는 두 개념을 구분한다.

Low Temperature와 Generation낮은 Temperature에서는 분포가 최대 Logit Token에 집중된다.

고유한 최대값이 있다면 \(T\rightarrow0^+\) 에서 Argmax Token에 Probability 1이 집중된다.

따라서 Sampling Result는 Greedy Decoding과 가까워진다.

Repetition에 대한 주의원자료에서는 매우 낮은 Temperature를 Repetition Loop와 연결한다.

하지만 \(H\rightarrow0 \Rightarrow \text{repetition must occur}\) 라는 수학적 결과는 아니다.

낮은 Entropy는 다음 Token Distribution이 집중되어 있음을 의미하며, 실제 반복 발생 여부는 Context, Model, Decoding Algorithm 등에 의존한다.

Top-\(k\)와 Top-\(p\)원자료에서는 Top-\(k\)와 Top-\(p\) Filtering을 Tail Probability를 제거하여 Sampling Distribution을 다시 제한하는 과정과 연결한다.

기본적으로 Filtering 이후에는 선택된 후보들의 Probability를 다시 정규화한다.

따라서 원래 Distribution과 다른 새로운 Categorical Distribution이 만들어진다.

Filtering 이후 EntropyFiltering 후 Probability Vector를 \(\tilde{\mathbf p}\) 라고 하면 새 Entropy는 \(H(\tilde{\mathbf p}) = -\sum_i \tilde p_i \log \tilde p_i\) 로 다시 계산해야 한다.

후보를 줄이고 Probability를 재정규화하면 Distribution의 Entropy가 달라질 수 있다.

특정 Entropy 목표값에 대한 주의원자료에서는 Top-\(k\)/Top-\(p\)와 함께 \(H\approx0.8\sim1.5\text{ bits}\) 라는 값을 언급한다.

하지만 이 자료 안에서는 이 범위가 일반적인 최적 Entropy라는 수학적 유도나 근거가 제공되지 않는다.

따라서 \(0.8\sim1.5\text{ bits}\) 를 Vocabulary Size나 Task와 무관한 Universal Target으로 사용하지 않는다.

Entropy와 Vocabulary SizeMaximum Entropy는 Vocabulary Size에 의존한다.

\[\boxed{ H_{\max} = \log_2V }\]

예를 들어 \(V=4\) 이면 다음과 같다.

\[H_{\max}=2\text{ bits}\]

반면 다음과 같다.

\[V=65536\]

이라면:

\[H_{\max} = 16\text{ bits}\]

따라서 Entropy의 절댓값을 비교할 때 Support Size도 함께 고려해야 한다.

Entropy와 Self-Information의 차이Self-Information은 실제로 관측된 한 Outcome에 대한 Quantity다.

\[\boxed{ I(x) = -\log p(x) }\]

Entropy는 아직 Outcome이 무엇인지 모르는 상태에서 가능한 모든 Outcome에 대한 Self-Information의 평균이다.

\[\boxed{ H(X) = \mathbb E[I(X)] }\]

따라서 Self-Information = outcome-level

Entropy = distribution-level

IT-01과 IT-02 연결IT-01에서는 \(I(x) = -\log p(x)\) 를 배웠다.

IT-02에서는 이를 평균한다.

\[\boxed{ H(X) = \sum_x p(x)I(x) }\]

따라서 다음과 같다.

\[\boxed{ I(x) \rightarrow \mathbb E[I(X)] \rightarrow H(X) }\]

Entropy와 NLL의 관계IT-01에서 특정 관측값 \(x\)의 NLL 형태는 \(-\log p_\theta(x)\) 이고 이는 해당 관측값의 Self-Information과 같은 형태였다.

Entropy는 동일한 Quantity를 자기 자신의 Distribution 아래에서 평균한다.

\[\boxed{ H(P) = \mathbb E_{x\sim P} [ -\log P(x) ] }\]

즉 \(-\log p(x)\) 가 Sample-Level Information이고 \(\mathbb E[-\log p(X)]\) 가 Distribution-Level Entropy다.

Shannon Entropy의 Coding Interpretation원자료는 Entropy를 정보를 표현하기 위해 필요한 최소 평균 Bit 수와 연결한다.

이 연결은 Information Theory의 Source Coding 관점에서 이해할 수 있다.

현재 Lecture에서 직접 사용하는 핵심 Quantity는 \(H(X) = -\sum_x p(x)\log_2p(x)\) 이며 이후 Coding Theory에서는 이 값이 Average Code Length의 Fundamental Limit와 연결된다.

정리

Shannon entropy \(H(X)=\mathbb{E}[-\log p(X)]\)는 결과의 self-information을 평균한 불확실성이다. 같은 support에서 분포가 균등할수록 entropy가 최대가 되고, 한 결과에 확률이 집중될수록 작아지므로 분포의 퍼짐과 평균 정보량을 함께 표현한다.
