투자 비중 α를 추정하는 문제

본 포스팅의 내용은 Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, Jonathan Taylor(2023)의 『An Introduction to Statistical Learning with Applications in Python』, Springer를 참고했습니다.

자산 X와 Y에 투자할 때 X에 α, Y에 1−α의 비중을 배분한다고 하자. 목표는 포트폴리오 수익의 분산, 즉 위험을 가장 작게 만드는 α를 찾는 것이다.

\[\operatorname{Var}\!\left(\alpha X+(1-\alpha)Y\right)=\alpha^2\sigma_X^2+(1-\alpha)^2\sigma_Y^2+2\alpha(1-\alpha)\sigma_{XY}\]
\[\alpha^*=\frac{\sigma_Y^2-\sigma_{XY}}{\sigma_X^2+\sigma_Y^2-2\sigma_{XY}}\]

현실에서는 모집단의 분산과 공분산을 알 수 없으므로 표본에서 계산한 추정값으로 α를 추정한다.

\[\widehat{\alpha}=\frac{\widehat{\sigma}_Y^2-\widehat{\sigma}_{XY}}{\widehat{\sigma}_X^2+\widehat{\sigma}_Y^2-2\widehat{\sigma}_{XY}}\]

같은 모집단에서 100쌍의 수익을 네 번 독립적으로 생성하면 α의 추정값은 0.576, 0.532, 0.657, 0.651처럼 달라진다. 이 변동이 추정량의 불확실성이다.

이상적인 반복 표본추출과 표준오차

왼쪽은 모집단에서 1,000개의 독립 데이터셋을 생성해 얻은 α 추정값의 분포다. 모집단 모수를 \(\sigma_X^2=1\), \(\sigma_Y^2=1.25\), \(\sigma_{XY}=0.5\)로 두면 참값은 \(\alpha=0.6\)이다.

\(SE(\widehat{\alpha})\approx0.083\)이라는 값은 추정값의 평균과 참값이 그만큼 차이 난다는 뜻이 아니다. 같은 크기의 표본을 반복해서 얻을 때 \(\widehat{\alpha}\)가 보이는 전형적인 변동 규모를 뜻한다.

표준오차는 추정량의 편향이 아니라 표본이 달라질 때 생기는 변동성을 측정한다.

하나의 데이터셋으로 반복 표본을 모방하기

현실에서는 같은 모집단에서 독립 데이터셋을 계속 새로 얻기 어렵다. 부트스트랩은 관측된 데이터에서 크기가 같은 표본을 복원추출하여 새로운 데이터셋을 얻는 과정을 컴퓨터로 모방한다.

  1. 원본 데이터 Z에서 관측값을 복원추출해 \(Z^{*1}\)을 만든다.
  2. \(Z^{*1}\)에서 관심 통계량 \(\widehat{\alpha}^{*1}\)을 계산한다.
  3. 이 과정을 B번 반복해 \(\widehat{\alpha}^{*1},\ldots,\widehat{\alpha}^{*B}\)를 얻는다.
  4. B개 추정값의 표준편차로 원래 추정량의 표준오차를 근사한다.
\[\widehat{SE}_{B}(\widehat{\alpha})=\sqrt{\frac{1}{B-1}\sum_{r=1}^{B}\left(\widehat{\alpha}^{*r}-\overline{\widehat{\alpha}^{*}}\right)^2}\]

그림 5.10의 가운데 부트스트랩 분포는 모집단 반복 표본으로 만든 왼쪽 분포와 모양과 산포가 비슷하다. 부트스트랩 표준오차도 이상적인 반복 표본추출로 얻은 값과 가깝게 나타나, 하나의 데이터셋만으로 추정량의 변동성을 효과적으로 근사할 수 있음을 보여 준다.

다만 부트스트랩이 모든 상황에서 자동으로 정확한 것은 아니다. 표본이 모집단을 충분히 대표해야 하며, 시계열처럼 관측값이 의존하거나 극단적으로 작은 표본에서는 문제 구조에 맞는 재표집 방법이 필요하다.
