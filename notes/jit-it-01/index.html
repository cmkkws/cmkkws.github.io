IT-01 — Self-Information

Self-Information의 정의와 로그 구조, 확률과 정보량의 관계를 정리한다.

정보이론 · IT-01업데이트 2026.09.18
  • #Self-Information
  • #Surprisal
  • #Logarithm
  • #Information Theory

개념

Self-Information — 어떤 사건 \(x\)가 발생했다는 사실을 관측했을 때 얻는 정보의 양을 Self-Information 또는 자기정보량이라고 한다. 이를 \(\boxed{ I(x) }\) 로 표현한다. 자기정보량의 핵심 직관은 다음과 같다.

\[\boxed{ \text{Rare Event} \rightarrow \text{Large Surprise} \rightarrow \text{Large Information} }\]

반대로

\[\boxed{ \text{Expected Event} \rightarrow \text{Small Surprise} \rightarrow \text{Small Information} }\]

Probability와 Information — 사건 \(x\)의 확률을 \(P(x)\) 라고 하자. 자기정보량은 이 확률의 함수로 정의한다. \(\boxed{ I(x) = f(P(x)) }\) 즉 정보량은 사건 자체의 이름이 아니라 그 사건이 얼마나 예상 가능했는가에 의해 결정된다.

Highly Probable Event — 사건이 거의 확실하다면 \(P(x)\approx1\) 이 사건이 실제로 발생하더라도 새롭게 얻는 정보는 거의 없다. 따라서

\[\boxed{ P(x)\rightarrow1 \Rightarrow I(x)\rightarrow0 }\]

특히 \(P(x)=1\) 이면 \(\boxed{ I(x)=0 }\)

Rare Event — 반대로 사건의 확률이 매우 작으면 \(P(x)\rightarrow0^+\) 이 사건이 실제로 관측되면 매우 큰 Surprise를 제공한다. 따라서

\[\boxed{ P(x)\rightarrow0^+ \Rightarrow I(x)\rightarrow\infty }\]

와 같은 방향으로 정보량이 증가한다.

Information as Surprise — 자기정보량은 다음 세 개념을 연결한다.

\[\boxed{ \text{Probability} \rightarrow \text{Surprise} \rightarrow \text{Information} }\]

확률이 작으면 Surprise가 커지고, Surprise가 클수록 얻는 정보량도 커진다. 따라서 정보량은 확률에 대해 감소하는 함수여야 한다.

표기·차원

Information Function — 확률 \(p=P(x)\) 만을 사용해 자기정보량을 표현하면 \(\boxed{ I(p) }\) 라고 쓸 수 있다. 이 함수가 합리적인 Information Measure가 되기 위해 원자료에서는 세 가지 요구조건을 제시한다.

  1. Non-negativity & Certainty
  2. Monotonicity
  3. Additivity for Independent Events

핵심 연산

Axiom 1 — Non-Negativity — 정보량은 음수가 될 수 없다. \(\boxed{ I(x)\ge0 }\) 관측을 통해 얻는 Surprise 또는 Information Content를 음의 양으로 정의하지 않는다.

Axiom 1 — Certainty — 반드시 발생하는 사건의 확률은 \(P(x)=1\) 이 사건의 발생은 새로운 정보를 제공하지 않는다. 따라서 \(\boxed{ P(x)=1 \Rightarrow I(x)=0 }\)

Axiom 2 — Monotonicity — 두 사건 \(x_1,x_2\)가 있고 \(P(x_1)<P(x_2)\) 라고 하자. \(x_1\)이 더 희귀한 사건이므로 더 많은 정보를 제공해야 한다. 따라서

\[\boxed{ P(x_1)<P(x_2) \Rightarrow I(x_1)>I(x_2) }\]

즉 자기정보량은 확률에 대한 단조감소 함수다.

Axiom 3 — Additivity — 서로 독립인 두 사건 \(A,B\)를 생각한다. 독립이면 \(\boxed{ P(A\cap B) = P(A)P(B) }\) 두 사건이 함께 발생했을 때 얻는 정보량은 각각을 관측했을 때 얻는 정보량의 합이어야 한다. \(\boxed{ I(A\cap B) = I(A)+I(B) }\)

LLM 핵심 식 — Autoregressive Token Probability는

\[\boxed{ P_\theta( y_t \mid y_{<t} ) }\]

Conditional Self-Information은

\[\boxed{ I( y_t \mid y_{<t} ) = -\log P_\theta( y_t \mid y_{<t} ) }\]

Natural Log를 사용하면 Token NLL과 같다.

\[\boxed{ \mathcal L_t = I_e( y_t^\ast \mid y_{<t} ) }\]

성질·유도

Additivity의 핵심 요구 — 독립 사건에서는 Probability가 곱해진다. \(\boxed{ P(A\cap B) = P(A)P(B) }\) 하지만 Information은 더해져야 한다. \(\boxed{ I(A\cap B) = I(A)+I(B) }\) 따라서 우리가 원하는 함수는

\[\boxed{ \text{Product} \rightarrow \text{Sum} }\]

을 만족해야 한다. 이 조건이 Logarithm과 직접 연결된다.

Functional Equation — 두 독립 사건의 확률을 \(p_1=P(A)\) \(p_2=P(B)\) 라고 하자. 정보량 함수 \(f(p)=I(p)\) 는 다음을 만족해야 한다. \(\boxed{ f(p_1p_2) = f(p_1)+f(p_2) }\) for \(p_1,p_2\in(0,1]\)

Variable Transformation — 확률은 \(0<p\le1\) 다음을 정의한다. \(\boxed{ x=\ln p_1 }\) \(\boxed{ y=\ln p_2 }\) 그러면 \(x,y\le0\)

New Function — 새로운 함수 \(\boxed{ g(z) = f(e^z) }\) 를 정의한다. 그러면

\[\begin{aligned} g(x+y) &= f(e^{x+y})\\ &= f(e^xe^y) \end{aligned}\]

Cauchy Functional Equation — 정보량의 Additivity Condition을 적용하면 \(f(e^xe^y) = f(e^x)+f(e^y)\) 따라서 \(\boxed{ g(x+y) = g(x)+g(y) }\) 를 얻는다. 이는 Cauchy Functional Equation 형태다.

Linear Solution — 원자료의 단조성 및 정규성 가정 아래에서 Cauchy Functional Equation의 해는 선형 형태가 된다. \(\boxed{ g(z)=cz }\) 여기서 \(c\in\mathbb R\)

Original Variable 복원 — \(g(z) = f(e^z)\) 였으므로 \(p=e^z\) 라고 하면 \(z=\ln p\) 따라서 \(\boxed{ f(p) = c\ln p }\)

Coefficient의 부호 — 확률 \(p\)가 커질수록 정보량은 작아져야 한다. 즉 \(f(p)\) 는 감소함수다. 하지만 \(\ln p\) 는 \(p>0\)에서 증가함수다. 따라서 \(c<0\) 이어야 한다. \(c=-k\), \(k>0\) 라고 두면 \(\boxed{ I(p) = -k\ln p }\)

Self-Information Formula — Logarithm의 Base를 선택하여 상수를 흡수하면 자기정보량은 \(\boxed{ I(x) = -\log_bP(x) }\) 동일하게

\[\boxed{ I(x) = \log_b \frac1{P(x)} }\]

여기서 \(b>1\)

왜 Negative Log인가 — 확률 범위에서는 \(0<P(x)\le1\) 따라서 \(\log_bP(x)\le0\) 앞에 음수를 붙이면 \(\boxed{ -\log_bP(x)\ge0 }\) 가 되어 Non-Negativity를 만족한다.

Certainty 검증 — 확실한 사건에서는 \(P(x)=1\) 따라서

\[\begin{aligned} I(x) &= -\log_b1\\ &= \boxed{0} \end{aligned}\]

Certainty Axiom을 만족한다.

Monotonicity 검증 — \(b>1\)일 때 \(\log_b p\) 는 증가함수다. 따라서 \(-\log_b p\) 는 감소함수다. 즉 \(P(x_1)<P(x_2)\) 이면 \(-\log_bP(x_1) > -\log_bP(x_2)\) 따라서

\[\boxed{ P(x_1)<P(x_2) \Rightarrow I(x_1)>I(x_2) }\]

Additivity 검증 — 독립 사건 \(A,B\)에서는 \(P(A\cap B) = P(A)P(B)\) 따라서

\[\begin{aligned} I(A\cap B) &= -\log_b [ P(A)P(B) ]\\ &= -\log_bP(A) - \log_bP(B)\\ &= I(A)+I(B) \end{aligned}\]

즉 \(\boxed{ I(A\cap B) = I(A)+I(B) }\) 를 만족한다.

Logarithm이 자연스럽게 등장하는 이유 — 확률은 독립 사건을 결합할 때 곱셈 구조를 가진다. \(\boxed{ p_{AB} = p_Ap_B }\) 정보량은 가법적이어야 한다. \(\boxed{ I_{AB} = I_A+I_B }\) Logarithm은 곱셈을 덧셈으로 바꾼다. \(\boxed{ \log(ab) = \log a+\log b }\) 따라서

\[\boxed{ \text{Probability Multiplication} \xrightarrow{-\log} \text{Information Addition} }\]

이 된다.

Information Unit — 자기정보량에서 Logarithm의 Base는 단위를 결정한다. \(\boxed{ I_b(x) = -\log_bP(x) }\) 대표적인 Base는

  • \(2\)
  • \(e\)
  • \(10\)

Bit — Base를 \(b=2\) 로 사용하면 단위는 bit다.

\[\boxed{ I_2(x) = -\log_2P(x) \quad [\mathrm{bits}] }\]

예를 들어

\[P(x)=\frac12\]

라면

\[I_2(x) = -\log_2\frac12 = \boxed{1\text{ bit}}\]

Nat — Base를 자연상수 \(b=e\) 로 사용하면 단위는 nat이다.

\[\boxed{ I_e(x) = -\ln P(x) \quad [\mathrm{nats}] }\]

자연로그는 미분과 최적화에서 편리하기 때문에 Machine Learning Loss에서 자주 사용된다.

Hartley — Base를 \(b=10\) 으로 사용하면 \(\boxed{ I_{10}(x) = -\log_{10}P(x) }\) 이 단위를 Hartley 또는 dit라고 부를 수 있다.

Base Conversion — Logarithm Base Conversion에 의해

\[\log_2p = \frac{\ln p}{\ln2}\]

따라서

\[\boxed{ I_2(x) = \frac{ I_e(x) }{ \ln2 } }\]

수치적으로

\[\boxed{ I_2(x) \approx 1.4427 I_e(x) }\]

Nat에서 Bit로 — 반대로 \(\boxed{ I_e(x) = I_2(x)\ln2 }\) 수치적으로

\[\boxed{ I_e(x) \approx 0.6931 I_2(x) }\]

따라서 단위가 바뀌어도 정보량 사이에는 일정한 Scale Factor만 존재한다.

주요 식 정리 —

Self-Information — \(\boxed{ I(x) = -\log_bP(x) }\)

Equivalent Form —

\[\boxed{ I(x) = \log_b \frac1{P(x)} }\]

Certainty — \(\boxed{ P(x)=1 \Rightarrow I(x)=0 }\)

Monotonicity —

\[\boxed{ P(x_1)<P(x_2) \Rightarrow I(x_1)>I(x_2) }\]

Independent Additivity — \(\boxed{ I(A\cap B) = I(A)+I(B) }\) when \(P(A\cap B) = P(A)P(B)\)

Units 정리 —

Bit — \(\boxed{ I_2(x) = -\log_2P(x) }\)

Nat — \(\boxed{ I_e(x) = -\ln P(x) }\)

Hartley — \(\boxed{ I_{10}(x) = -\log_{10}P(x) }\)

혼동하기 쉬운 부분 — Probability와 Information — 확률이 높다고 정보량도 높은 것이 아니다. 둘은 반대 방향으로 움직인다.

\[\boxed{ P\uparrow \Rightarrow I\downarrow }\]
\[\boxed{ P\downarrow \Rightarrow I\uparrow }\]

혼동하기 쉬운 부분 — \(P=0\) — Self-Information Formula는 \(-\log P(x)\) 만약 \(P(x)\rightarrow0^+\) 이면 \(\boxed{ I(x)\rightarrow\infty }\) 따라서 Probability가 정확히 0인 사건을 실제로 관측했다고 가정하면 해당 Model 아래에서는 무한한 Surprise가 발생하는 형태가 된다.

혼동하기 쉬운 부분 — Additivity — 다음 식 \(I(A,B) = I(A)+I(B)\) 은 두 사건이 독립일 때 직접 적용된다. \(\boxed{ P(A,B) = P(A)P(B) }\) Autoregressive Token Sequence는 일반적으로 독립적이지 않다. 따라서 LLM에서는 조건부 형태

\[\boxed{ I(y_{1:T}) = \sum_t I( y_t \mid y_{<t} ) }\]

를 사용하는 것이 적절하다.

혼동하기 쉬운 부분 — Bit와 Nat — \(-\log_2P(x)\) 와 \(-\ln P(x)\) 는 서로 다른 정보 개념이 아니다. 단위만 다르다.

\[\boxed{ 1\text{ nat} = \frac1{\ln2} \text{ bits} \approx 1.4427\text{ bits} }\]

자기정보량은 어떤 사건이 발생했을 때 얻는 Surprise 또는 Information Content를 측정한다. 확률이 낮은 사건일수록 정보량이 크다.

\[\boxed{ P(x)\downarrow \Rightarrow I(x)\uparrow }\]

합리적인 정보량 함수는 원자료의 세 요구조건을 만족한다.

Non-Negativity and Certainty —

\[\boxed{ I(x)\ge0, \qquad P(x)=1 \Rightarrow I(x)=0 }\]

Monotonicity —

\[\boxed{ P(x_1)<P(x_2) \Rightarrow I(x_1)>I(x_2) }\]

Independent Additivity — \(\boxed{ I(A\cap B) = I(A)+I(B) }\) 독립 사건에서 \(P(A\cap B) = P(A)P(B)\) 이고 정보량은 더해져야 하므로 \(\boxed{ f(p_1p_2) = f(p_1)+f(p_2) }\) 라는 Functional Equation을 얻는다. 단조성 등의 정규성 조건을 사용하면 이 관계는 Logarithm 형태로 이어진다. \(\boxed{ I(x) = -\log_bP(x) }\) Base에 따라 단위가 달라진다.

\[\boxed{ b=2 \rightarrow \text{bits} }\]
\[\boxed{ b=e \rightarrow \text{nats} }\]
\[\boxed{ b=10 \rightarrow \text{hartleys} }\]

LLM에서는 이전 Context가 주어진 다음 Token의 Self-Information을

\[\boxed{ I( y_t \mid y_{<t} ) = -\log P( y_t \mid y_{<t} ) }\]

로 해석할 수 있다. 정답 Token에 자연로그를 사용하면

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\ln P_\theta( y_t^\ast \mid y_{<t} ) }\]

이고 이는 정답 Token의 nat 단위 Self-Information과 동일한 수식이다. 따라서 전체 연결은

\[\boxed{ \text{Probability} \rightarrow \text{Surprise} \rightarrow \text{Self-Information} }\]

Information Theory에서는

\[\boxed{ \text{Self-Information} \rightarrow \text{Entropy} }\]

로 이어지고, LLM Training에서는

\[\boxed{ \text{Next-Token Probability} \rightarrow -\log P \rightarrow \text{NLL / Cross-Entropy} }\]

로 연결된다.

예제·적용

Example — Token Distribution — Vocabulary Size가 \(V=4\) 라고 하자. Token Set은

\[\boxed{ \mathcal V = \{t_1,t_2,t_3,t_4\} }\]

Softmax Probability가

\[\boxed{ \mathbf p = \begin{bmatrix} 0.50\\ 0.25\\ 0.125\\ 0.125 \end{bmatrix} }\]

라고 하자.

Example — \(t_1\) — 첫 번째 Token의 확률은 \(P(t_1)=0.50\) Bits 단위에서는

\[\begin{aligned} I_2(t_1) &= -\log_2(0.50)\\ &= -\log_2(2^{-1})\\ &= \boxed{1\text{ bit}} \end{aligned}\]

Example — \(t_1\) in Nats — Nat 단위에서는

\[\begin{aligned} I_e(t_1) &= -\ln(0.50)\\ &\approx \boxed{0.693\text{ nat}} \end{aligned}\]

Example — \(t_2\) — \(P(t_2)=0.25\) 따라서

\[\begin{aligned} I_2(t_2) &= -\log_2(0.25)\\ &= -\log_2(2^{-2})\\ &= \boxed{2\text{ bits}} \end{aligned}\]

Nat 단위에서는

\[\boxed{ I_e(t_2) = -\ln(0.25) \approx 1.386\text{ nats} }\]

Example — \(t_3,t_4\) — \(P(t_3) = P(t_4) = 0.125\) 따라서

\[\begin{aligned} I_2(t_3) &= I_2(t_4)\\ &= -\log_2(0.125)\\ &= -\log_2(2^{-3})\\ &= \boxed{3\text{ bits}} \end{aligned}\]

Nat 단위에서는

\[\boxed{ I_e(t_3) = I_e(t_4) \approx 2.079\text{ nats} }\]

Example 결과 비교 — 확률은 \(0.50 > 0.25 > 0.125\) 반면 정보량은 \(1 < 2 < 3\) bits다. 즉

\[\boxed{ P\downarrow \Rightarrow I\uparrow }\]

가 수치적으로 확인된다.

Independent Joint Event — 원자료의 가합성 예제처럼 두 사건을 독립이라고 가정하자. 첫 번째 사건에서 \(t_2\) 가 발생하고 두 번째 독립 사건에서 \(t_3\) 가 발생한다고 하자. 그러면 Joint Probability는

\[\begin{aligned} P(t_2,t_3) &= P(t_2)P(t_3)\\ &= 0.25\times0.125\\ &= \boxed{0.03125} \end{aligned}\]

Joint Self-Information — \(0.03125 = 2^{-5}\) 이므로

\[\begin{aligned} I(t_2,t_3) &= -\log_2(0.03125)\\ &= -\log_2(2^{-5})\\ &= \boxed{5\text{ bits}} \end{aligned}\]

Additivity 검증 — 개별 정보량은 \(I(t_2)=2\text{ bits}\) \(I(t_3)=3\text{ bits}\) 따라서

\[\begin{aligned} I(t_2)+I(t_3) &= 2+3\\ &= \boxed{5\text{ bits}} \end{aligned}\]

즉 \(\boxed{ I(t_2,t_3) = I(t_2)+I(t_3) }\)

Independent Event 조건 — 앞의 가합성 계산은 \(\boxed{ P(A,B)=P(A)P(B) }\) 인 독립 사건을 가정한다. Autoregressive Language Model의 연속 Token들은 일반적으로 독립이라고 가정하지 않는다. LLM에서는

\[\boxed{ P(y_{1:T}) = \prod_{t=1}^{T} P( y_t \mid y_{<t} ) }\]

처럼 조건부 확률을 사용한다. 따라서 LLM에서는 이후 Conditional Self-Information 형태로 연결하는 것이 적절하다.

Conditional Self-Information — Context가 주어진 Token의 자기정보량은 다음과 같이 표현할 수 있다.

\[\boxed{ I( y_t \mid y_{<t} ) = -\log P( y_t \mid y_{<t} ) }\]

즉 같은 Token이라도 앞의 Context에 따라 Probability가 달라지므로 Self-Information도 달라질 수 있다.

Autoregressive LLM — Autoregressive Language Model은 이전 Token Sequence \(y_{<t}\) 를 조건으로 다음 Token Distribution을 출력한다.

\[\boxed{ P_\theta( y_t \mid y_{<t} ) }\]

실제로 Token \(y_t\)가 관측되면 해당 Token의 Surprise는

\[\boxed{ -\log P_\theta( y_t \mid y_{<t} ) }\]

Token Surprise in Bits — Base 2를 사용하면

\[\boxed{ I_2( y_t \mid y_{<t} ) = -\log_2 P( y_t \mid y_{<t} ) }\]

단위는 \(\boxed{ \text{bits} }\)

Token Surprise in Nats — 자연로그를 사용하면

\[\boxed{ I_e( y_t \mid y_{<t} ) = -\ln P( y_t \mid y_{<t} ) }\]

단위는 \(\boxed{ \text{nats} }\)

High-Probability Token — 모델이 실제 정답 Token에 높은 확률을 부여했다고 하자. \(P( y_t^\ast \mid y_{<t} ) \approx1\) 그러면

\[-\ln P( y_t^\ast \mid y_{<t} ) \approx0\]

따라서

\[\boxed{ \text{Correctly expected token} \rightarrow \text{small surprise} }\]

Low-Probability Token — 반대로 모델이 실제 Token에 매우 낮은 확률을 부여했다면 \(P( y_t^\ast \mid y_{<t} ) \ll1\) 그러면 \(-\ln P( y_t^\ast \mid y_{<t} )\) 가 커진다. 따라서

\[\boxed{ \text{Unexpected token} \rightarrow \text{large surprise} }\]

NLL과 Self-Information — 정답 Token을 \(y_t^\ast\) 라고 하자. Token-Level Negative Log-Likelihood는

\[\boxed{ \mathcal L_t = -\ln P_\theta( y_t^\ast \mid y_{<t} ) }\]

이는 자연로그 기반 Self-Information과 정확히 같은 수식이다.

\[\boxed{ \mathcal L_t = I_e( y_t^\ast \mid y_{<t} ) }\]

NLL의 정보이론적 해석 — 따라서 Token-Level NLL을 최소화한다는 것은 관측된 정답 Token의 Self-Information을 모델 분포 아래에서 작게 만드는 것과 같다. 즉 Training은

\[\boxed{ -\ln P_\theta( y_t^\ast \mid y_{<t} ) \downarrow }\]

가 되도록 Parameter를 조정한다. 이는 다시

\[\boxed{ P_\theta( y_t^\ast \mid y_{<t} ) \uparrow }\]

와 연결된다.

Sequence NLL — 전체 Token Sequence에서는 Token-Level NLL을 합산한다.

\[\boxed{ \mathcal L_{\mathrm{seq}} = - \sum_{t=1}^{T} \ln P_\theta( y_t \mid y_{<t} ) }\]

각 항이 해당 Position의 Conditional Self-Information이므로

\[\boxed{ \mathcal L_{\mathrm{seq}} = \sum_{t=1}^{T} I_e( y_t \mid y_{<t} ) }\]

로 볼 수 있다.

Chain Rule과 Self-Information — Autoregressive Chain Rule은

\[P(y_{1:T}) = \prod_{t=1}^{T} P( y_t \mid y_{<t} )\]

전체 Sequence의 Self-Information은 \(-\ln P(y_{1:T})\) 따라서

\[\begin{aligned} -\ln P(y_{1:T}) &= -\ln \prod_{t=1}^{T} P( y_t \mid y_{<t} )\\ &= -\sum_{t=1}^{T} \ln P( y_t \mid y_{<t} ) \end{aligned}\]

즉

\[\boxed{ I(y_{1:T}) = \sum_{t=1}^{T} I( y_t \mid y_{<t} ) }\]

이라는 형태로 연결된다.

Softmax Output — Vocabulary Size를 \(V\) 라고 하자. Logit을 \(\mathbf z = [z_1,\dots,z_V]^T\) 라고 하면 Softmax Probability는

\[\boxed{ p_k = \frac{ e^{z_k} }{ \sum_j e^{z_j} } }\]

정답 Token Index를 \(c\) 라고 하자.

Token NLL — 정답 Token의 Loss는 \(\boxed{ \mathcal L = -\ln p_c }\) 이는 정답 Token의 Self-Information이다. \(\boxed{ I_e(c) = -\ln p_c }\)

NLL Gradient w.r.t. Logits — Softmax + NLL의 Gradient는

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_k } = p_k - \mathbf1(k=c) }\]

여기서 \(\mathbf1(k=c)\) 는 Indicator Function이다.

Correct-Token Logit Gradient — 정답 Token에서는 \(k=c\) 이므로

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_c } = p_c-1 }\]

Gradient Magnitude는

\[\boxed{ \left| \frac{ \partial\mathcal L }{ \partial z_c } \right| = 1-p_c }\]

Large Surprise와 Output Gradient — 정답 Probability가 매우 낮으면 \(p_c\rightarrow0\) 이때 \(I_e(c) = -\ln p_c \rightarrow\infty\) 이고 정답 Logit에 대한 Gradient Magnitude는 \(1-p_c \rightarrow1\) 따라서

\[\boxed{ p_c\downarrow \Rightarrow \text{self-information}\uparrow }\]

와 동시에

\[\boxed{ \left| \frac{\partial L}{\partial z_c} \right| \uparrow }\]

하는 관계를 가진다.

Small Surprise와 Output Gradient — 반대로 \(p_c\rightarrow1\) 이면 \(-\ln p_c \rightarrow0\) 정답 Logit Gradient도 \(p_c-1 \rightarrow0\) 즉

\[\boxed{ \text{high confidence on correct token} \rightarrow \text{small NLL} \rightarrow \text{small correct-logit gradient} }\]

Gradient 해석의 주의점 — 앞의 관계는 Softmax 출력 Logit에 대한 Gradient

\[\frac{\partial L}{\partial z_k}\]

에 대한 직접적인 결과다. 전체 Network Parameter Gradient \(\nabla_\theta L\) 의 크기는

  • hidden activation
  • Jacobian
  • network depth
  • normalization
  • parameterization

등에도 영향을 받는다. 따라서

\[\boxed{ \text{large self-information} \not\Rightarrow \text{all parameter gradients are necessarily large} }\]

라고 구분한다.

Self-Information과 Entropy의 연결 — 이 Lecture의 중심은 하나의 관측 결과에 대한 정보량 \(\boxed{ I(x) = -\log P(x) }\) 확률변수 전체의 평균적인 정보량을 생각하면 이후 Entropy로 연결된다. 개념적 흐름은

\[\boxed{ \text{Self-Information} \rightarrow \text{Expected Self-Information} \rightarrow \text{Entropy} }\]

Information과 NLL 연결 — 확률론에서 \(P(x)\) 는 Event의 Probability다. 정보이론에서는 \(-\log P(x)\) 를 관측 결과의 Information으로 해석한다. Machine Learning에서는 같은 Quantity를 \(\boxed{ -\log P_\theta(x) }\) 형태의 NLL로 사용한다. 따라서 동일한 수학식이

\[\boxed{ \text{Probability} \rightarrow \text{Information Theory} \rightarrow \text{Loss Function} }\]

을 연결한다.

정리

Self-information은 사건 확률의 로그 역수 \(I(x)=-\log p(x)\)로 정의되어 드문 사건일수록 더 큰 정보를 준다. 로그 밑은 단위를 정하고 독립 사건의 정보량을 더할 수 있게 하며, 이 정의가 entropy와 negative log-likelihood의 출발점이다.
