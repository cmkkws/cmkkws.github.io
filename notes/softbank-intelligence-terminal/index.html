프로젝트 개요

SoftBank의 가격과 투자 자산, 관련 기업, 거시지표와 뉴스를 한곳에서 살펴보기 위해 만든 개인용 로컬 앱이다. 서로 다른 데이터의 통화·단위·기준 시각을 정리하고, 원본을 확인할 수 있는 형태로 화면에 연결했다.

기업·시장, 매크로, 뉴스의 세 화면으로 구성했다. 가격과 일별 이력은 차트로, 기준일의 공식 NAV는 자산 구성으로, 영어 뉴스는 로컬 번역과 원문을 함께 제공한다.

전체 파이프라인

브라우저가 각 공급자를 직접 호출하는 대신, 서버에서 데이터를 수집·검증하고 공통 snapshot으로 전달한다. 같은 소스에 대한 중복 요청을 합치고, 정해진 수집 주기에 맞춰 캐시를 갱신한다.

기업·시장

SoftBank의 도쿄 상장 주식과 SFTBY ADR을 선택해 일봉과 거래량을 확인한다. 기간은 1·3·6개월, 차트 종류는 캔들과 라인으로 전환하며, 키보드로 날짜를 이동하면 해당 봉의 OHLC와 거래량이 바뀐다.

공식 NAV의 자산 구성은 원차트로, 주요 투자기업과 반도체·AI 관련 기업은 표로 표시한다. 투자기업의 보유 지분율과 NAV 자산 비중은 다른 값으로 구분하며, 비상장 기업에는 임의의 주가를 넣지 않는다.

  • NAV는 공식 기준일의 snapshot으로 표시하고 자산 합계와 순자산 관계를 검증한다.
  • OpenAI의 기업 보유 지분율을 SoftBank 전체 NAV에서 차지하는 비중으로 바꾸지 않는다.
  • 현재 시장가·주식 수·동기화된 환율이 연결되지 않은 NAV 추정과 할인율은 빈 값으로 유지한다.

매크로

USDJPY·USDKRW·JPYKRW 환율, 미국 국채 2·5·10·30년 금리, WTI·Brent 연속 선물의 일별 추이를 작은 차트로 제공한다. 각 카드에는 단위와 기준 시각을 함께 표시한다.

가격 관측값과 일별 참고값을 구분한다. 국채·ECB 자료처럼 날짜만 확인되는 값에는 공표 시각이 제공되지 않았음을 표시하며, 원유 연속 선물과 현물 가격도 구분한다.

뉴스와 로컬 번역

뉴스는 전체·소프트뱅크·OpenAI·Anthropic·매크로로 필터링하고 한국어·원문 제목으로 검색한다. 게시 시각, 취득 시각, 출처와 원문 링크를 함께 제공한다.

QuickMT와 CTranslate2를 이용한 Python CPU worker로 영어 제목과 RSS에 제공된 짧은 설명을 번역한다. 번역은 외부 번역 API로 보내지 않고 로컬에서 처리하며, 결과는 캐시에 저장한다.

데이터 품질과 오류 처리

화면에 숫자가 있다는 이유만으로 최신 값으로 취급하지 않는다. 원본의 관측 시각, 서버의 취득 시각, 자료의 기준일을 별도로 보존하고 공급자 상태에 따라 표시를 바꾼다.

구현 기술

TypeScript와 Node.js의 HTTP 서버로 수집·조회 계층을 구성하고, HTML·CSS·JavaScript·SVG로 화면과 차트를 구현했다. 가격·NAV·뉴스의 공통 형식과 UI 표시용 변환을 분리했다.

  • 다크·라이트 모드 선택을 기기에 저장한다.
  • 차트와 가격 표는 모바일에서 세로로 배치하며, 키보드 날짜 선택을 지원한다.
  • JUA 웹폰트를 로컬에서 제공하고 클릭 전환에는 짧은 모션과 동작 줄이기 설정을 적용한다.
  • 로컬 API는 loopback과 동일 출처 요청을 기준으로 동작한다.

검증과 운영 범위

프로젝트의 2026-10-06 검증 기록에는 오프라인 테스트 47개, TypeScript 검사, PC·모바일 화면과 차트·필터·모드 전환 확인 결과가 남아 있다. 기록된 성능 측정은 개인 PC의 로컬 API 조건이며 대규모 서비스 성능으로 일반화하지 않는다.

포트폴리오 정리 과정에서도 실행 중인 로컬 snapshot을 조회해 UI 버전 2.0.0, 31개 소스 상태, 32개 이력 레코드, 캐시 복원을 확인했다. 이 수치는 확인 시점의 구성과 응답이며 시세의 최신성이나 모든 소스의 정상 연결을 보장하는 지표는 아니다.

현재 한계와 다음 단계

이 프로젝트의 결과는 금융 데이터의 수집·정규화·상태 표시·시각화와 로컬 번역을 연결한 앱이다. 가격 예측이나 수익률의 인과 기여도는 검증된 결과로 제시하지 않는다.

  • 공개 가격 피드의 지연이 보장되지 않으므로, 원본 시각과 마지막 확인 상태를 계속 표시한다.
  • Reuters 관련 코드와 현재 실행 앱의 차이를 정리하고 실제 수집·출처 표시를 검증한다.
  • 번역 검수는 보수적인 규칙 검사다. 의미 보존 품질은 별도의 검수 표본으로 평가할 필요가 있다.
  • NAV는 공식 기준일 snapshot이다. 현재 가치 추정은 가격·주식 수·환율의 시점 정합성을 확보한 뒤 검증한다.
  • 상시 운영으로 확장하려면 데이터 제공 범위와 배포·모니터링 조건을 별도로 정리한다.
