꿈꾸는 책길 — SQF 진로 독서 로드맵

SQF 직업·수준과 지역 도서관 장서를 연결해 INTRO·CORE·ADVANCED 독서 순서를 구성하는 추천 서비스

SQF 1,637 JOB_CODE · 도서관정보나루 장서·대출 · 국립중앙도서관 서지
구조
SQF·장서 ETL → Parquet·SQLite BM25F → 추천 엔진 → FastAPI → React·Kakao Maps·Leaflet

1. 프로젝트 개요

꿈꾸는 책길은 학생이 관심 진로와 지역을 선택하면, SQF가 제시하는 직업별 지식·기술·역량을 분석하여 가까운 도서관의 실제 소장 도서를 진로 이해·핵심 역량·전문 심화의 순서로 추천하는 서비스입니다.

해결하려는 문제

  • 학생은 희망 직업을 공부할 때 어떤 책부터 읽어야 하는지 판단하기 어렵다.
  • 일반 도서 추천은 직업의 수행 수준과 실제 지역 소장 여부를 함께 고려하지 않는다.
  • 도서관 장서는 많지만 진로 학습 순서로 연결되어 있지 않다.

차별성

  • 직업명만 비교하지 않고 JOB_CODE와 SQF_LEVEL을 추천 기준으로 사용한다.
  • 지역도서관의 실제 소장자료와 연결하고, 추천 이유를 일치한 역량·지식·기술로 설명한다.
  • 임베딩의 불투명한 결과보다 BM25F와 규칙 기반 기준선을 사용해 판단 근거를 추적한다.
  • 관련 도서가 부족하면 무관한 책으로 15권을 억지로 채우지 않는다.

2. 문제 정의와 서비스 차별성

많은 책을 나열하는 대신 직무 관련성, 학습 순서, 실제 이용 가능성을 하나의 추천 과정으로 연결한다.

추천 관련성과 소장 가능성을 분리한다. 가까운 도서관에 있다는 이유만으로 직무 관련성이 높아지지 않는다.

3. 실제 사용자 이용 흐름

사용자는 진로 분야와 지역·학습 깊이를 선택하고, 시스템은 이를 JOB_CODE와 SQF_LEVEL로 확정해 단계별 로드맵을 생성한다.

4. 전체 데이터 파이프라인

지역 장서 139,237,042행을 SQF 직무 근거로 검색한 뒤, 사용자가 선택한 지역의 실제 소장관계와 연결한다.

5. 원천 데이터와 연결키

SQF, 지역 장서, 국가서지 데이터는 ISBN과 내부 식별키로 연결하며 원본 추적키를 최종 결과까지 보존한다.

6. 전처리·품질관리·행 수 변화

원본 장서 행은 ISBN 보강까지 유지하고, 같은 책과 도서관의 관계 및 고유 도서를 집계하는 단계에서만 목적에 맞게 통합한다.

SQF 원천은 탐색·시연에 사용할 수 있지만, HIGH 692건과 참조 무결성 86건이 남아 있어 확정 기준 데이터로 표현하지 않는다.

7. SQF 용어 계층과 수준 비교 설계

현재 설정 2.14.14는 네 계층과 지식·과업·자율성·책임 기반 수준 프로필을 사용한다. 아래 여섯 계층과 수준별 용어 비교 방식은 다음 실험을 위한 개편 설계이며 아직 코드·회귀검증에 반영되지 않았다.

CAREER_COMMON은 직업 관련성에는 강하지만 수준을 구분하지 않는다. SQF_LEVEL_SPECIFIC은 수준 구분에는 강하지만 단독 직업 앵커로 사용하지 않는다.
\[\operatorname{CAREER\_LEVEL\_COVERAGE}(t)=\frac{N_{\text{levels containing }t}}{N_{\text{career levels}}}\]
  • CAREER_COMMON은 최소 두 수준에 등장하고 다른 진로보다 해당 진로의 출현 비율이 높아야 한다.
  • 역량·지식·기술 등 복수 출처에서 확인하고 GLOBAL_COMMON은 제외한다.
  • 일반 단일명사보다 직무를 구별하는 구체적인 복합명사를 우선한다.
\[\operatorname{LEVEL\_LIFT}(t,l)=\frac{P(t\mid \text{career},l)+\alpha}{P(t\mid \text{career},\text{other levels})+\alpha}\]
\[\operatorname{LEVEL\_SPECIFICITY}=\operatorname{LEVEL\_LIFT}\times\operatorname{SOURCE\_DIVERSITY}\times\operatorname{UNIT\_COVERAGE}\times\operatorname{TERM\_DISTINCTIVENESS}\]
\[\operatorname{CURRENT\_LEVEL\_EVIDENCE}=\sum_{t\in\text{matched}}\operatorname{LEVEL\_SPECIFICITY}(t,l)\]
\[\operatorname{OTHER\_LEVEL\_EVIDENCE}=\max_{k\ne l}\sum_{t\in\text{matched}}\operatorname{LEVEL\_SPECIFICITY}(t,k)\]
\[\operatorname{LEVEL\_EVIDENCE\_MARGIN}=\operatorname{CURRENT\_LEVEL\_EVIDENCE}-\operatorname{OTHER\_LEVEL\_EVIDENCE}\]
같은 진로의 공통 정체성은 CAREER_COMMON으로 유지하고, 수준별 결과 차이는 실제 SQF 수준 간 용어 분포에서 만든다. 이 용어 계층은 후보 검색과 추천 이유에 사용하며 로드맵 단계 적합도 점수에는 넣지 않는다.

8. 추천 알고리즘과 3단계 구성

상위 점수 구조는 직업 관련성 60%, SQF 수준 적합도 20%, 로드맵 단계 적합도 20%를 유지한다. 아래 개편안에서는 로드맵 단계 적합도 20%를 제목 단계 키워드에 전부 배정한다. 이 변경과 6계층 수준 비교 방식은 2.14.14 코드·회귀검증에 아직 반영되지 않았다.

\[\operatorname{TEXT\_RELEVANCE}=0.65\,\operatorname{NORMALIZED\_BM25F}+0.35\,\operatorname{JOB\_ANCHOR\_EVIDENCE}\]

현행 2.14.14 수준 적합도

\[\operatorname{SQF\_LEVEL\_PROFILE\_FIT}=0.35\,\operatorname{KNOWLEDGE\_DEPTH}+0.35\,\operatorname{TASK\_COMPLEXITY}+0.15\,\operatorname{AUTONOMY}+0.15\,\operatorname{RESPONSIBILITY}\]
\[\operatorname{ROADMAP\_STAGE\_FIT}=\operatorname{TITLE\_STAGE\_MARKER}\]
\[\operatorname{CONTENT\_SCORE}=0.60\,\operatorname{TEXT\_RELEVANCE}+0.20\,\operatorname{SQF\_LEVEL\_PROFILE\_FIT}+0.20\,\operatorname{ROADMAP\_STAGE\_FIT}\]
세 점수는 자료 필터와 직무 앵커를 통과한 후보에만 적용한다. 제목의 ‘입문·기초·실무·심화’는 단계 배치를 돕지만, 이 표현만으로 직업 관련 도서가 되지는 않는다.
SQF 원문에 특정 차원의 근거가 없으면 확인 가능한 차원의 가중치를 다시 조정하므로 7%·7%·3%·3%는 일반적인 기준이다.

6계층 직무 앵커 가중치 실험안

\[\operatorname{JOB\_RELEVANCE}_{\text{proposal}}=\operatorname{BM25F}+\operatorname{CAREER\_FIELD}+\operatorname{CAREER\_COMMON}+\operatorname{SUPPORTING\_EVIDENCE}\]
이 가중치는 초기 실험값이다. 현재 2.14.14 운영 점수가 아니며 수동평가와 회귀검증 후 조정한다.
  • 현재 설정 파일 버전은 2.14.14, 운영 인덱스는 bm25f_job_anchor_material_sidecar_v4다.
  • 출판사·거리·소장 도서관 수는 CONTENT_SCORE를 높이지 않는다.
  • 논문·학회지·보고서·그림책·기관 발간자료 등은 점수 계산 전에 자료형과 서지 규칙으로 제외한다.
  • 직접 관련 후보가 부족하면 단계별 5권을 강제로 채우지 않는다.

9. 실제 추천 사례 한 건

데이터 분석가·SQF 5·서울 중구 조건을 예로 들어 사용자 입력부터 후보 검색, 제외 규칙, 최종 추천과 소장처 출력까지 연결 과정을 확인한다.

위 도서명과 소장처는 기존 수동검토·소장관계 데이터에서 확인한 실제 예시다. 설정 2.14.13의 현재 최종 순위라고 주장하지 않으며, 최신 대표 표본 재실행 후 순위와 단계가 달라질 수 있다.
  • ‘분석’ 한 단어만 일치한 책은 직무 앵커를 통과하지 못한다.
  • 논문·학위연구·보고서·일반 정책자료는 학습용 단행본 기준에 맞지 않으면 제외한다.
  • R·SQL·시각화 등 한 도구군만 반복되지 않도록 주제가족과 제목 유사도를 제한한다.

10. 지역도서관·중앙자료 연결 정책

도서의 직무 관련성을 먼저 계산한 뒤 사용자의 지역 소장관계와 중앙자료 포함 여부를 적용한다.

지역에 관련 도서가 부족하더라도 중앙자료를 자동으로 섞지 않는다. 사용자의 중앙자료 선택을 그대로 지킨다.

11. 검증 결과와 성능

완료된 검증 근거는 2.14.12 전체 테스트와 2.14.13 집중 회귀다. 현재 설정 파일 2.14.14 이후의 6계층 용어 구조와 제목 키워드 단일 단계 적합도는 별도 구현·회귀검증이 필요하다.

응답시간은 2.14.12 기준이다. 점수식이 변경된 2.14.13의 성능으로 해석하지 않는다.

12. 현재 한계와 향후 개선

추천 기준선은 검증했지만 대표 표본 재실행, SQF 품질 보완, 라벨 기반 정확도 평가와 운영 환경 확정이 남아 있다.

13. 구현 구성과 근거 문서

추천 설정과 데이터 품질의 근거를 코드·설정 파일·상태 보고서·QA 산출물로 나누어 추적한다.
