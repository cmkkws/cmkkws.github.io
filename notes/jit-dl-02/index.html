DL-02 — Activation Functions

활성화 함수의 비선형성과 미분이 신경망 학습에 미치는 영향을 다룬다.

ML·딥러닝 · DL-02업데이트 2026.09.27
  • #Activation Functions
  • #ReLU
  • #GELU
  • #SiLU
  • #Transformer

개념

학습 목표활성화 함수가 필요한 이유를 아핀 합성과 구분하고, ReLU·GELU·SiLU의 정의와 도함수를 유도한다. 세 입력점의 값·gradient를 직접 검산한다. 매끄러움과 학습 안정성, Transformer FFN의 게이팅을 연결할 때의 조건도 밝힌다.

활성화가 없을 때두 아핀 함수를 합성하면 \(W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)\)다. 따라서 활성화 없이 여러 층을 쌓아도 하나의 아핀 함수 \(W_{\rm eff}x+b_{\rm eff}\)로 표현된다.

선형과 아핀의 구별편향이 모두 0일 때 합성은 선형이고, 편향이 있으면 아핀이다. 원자료의 \(\tilde W x\) 식은 편향 0일 때에만 그대로 맞는다. 차원 중간에 병목이 있으면 합성행렬의 rank에도 제한이 생긴다.

비선형성의 역할일반적인 비선형 함수를 표현하려면 선형/아핀 합성 이외의 요소가 필요하다. 활성화의 삽입은 그 한 방식이다. 보편적 근사 정리는 적절한 활성화·폭·정의역 조건 아래의 표현 가능성에 관한 것이며 임의의 구조가 모든 함수를 학습한다는 보장은 아니다.

표기·차원

층의 아핀 변환층 \(l\)에서 \(z^{(l)}=W_lh^{(l-1)}+b_l\), \(h^{(l)}=\phi(z^{(l)})\)로 둔다. \(\phi\)는 좌표별로 작용할 수 있고, \(W_l\)의 shape는 앞뒤 층의 차원에 맞는다.

핵심 연산

ReLU 정의

\[\operatorname{ReLU}(x)=\max(0,x) =\begin{cases}0,&x\le0,\\x,&x>0.\end{cases}\]

연속이고 구간별 선형이다. 네트워크 전체의 함수는 여러 선형 조각의 조합이 될 수 있다.

양수 구간의 장점과 한계양수 preactivation에서 국소 미분은 1이므로 sigmoid 포화와 다른 성질을 가진다. 그러나 깊은 네트워크의 gradient는 \(W_l\) 및 다른 층의 Jacobian 곱에도 좌우되므로 ReLU만으로 gradient 소멸이 절대 발생하지 않는다는 주장은 성립하지 않는다.

GELU 정의표준정규분포의 누적분포함수를 \(\Phi\), 밀도를 \(\varphi\)라 하면 다음과 같다.

\[\operatorname{GELU}(x)=x\Phi(x), \quad \Phi(x)=\frac12\left[1+\operatorname{erf}\left(\frac{x}{\sqrt2}\right)\right].\]

\(\operatorname{erf}(u)=\frac2{\sqrt\pi}\int_0^u e^{-t^2}\,dt\)이다.

GELU 도함수 유도곱의 미분법과 \(\Phi'(x)=\varphi(x)\)로 다음과 같이 쓴다.

\[\operatorname{GELU}'(x) =\Phi(x)+x\varphi(x), \qquad \varphi(x)=\frac{e^{-x^2/2}}{\sqrt{2\pi}}.\]

음수 \(x\)에서는 두 항의 부호가 달라 도함수가 음수일 수 있다.

GELU tanh 근사원자료의 계산용 근사식은 다음과 같다.

\[\operatorname{GELU}(x)\approx \frac{x}{2}\left[ 1+\tanh\left(\sqrt{\frac2\pi}(x+0.044715x^3)\right) \right].\]

이는 정의식과 정확히 같지 않다. 이 근사 구현의 역전파 도함수는 근사식 자체를 미분한 값이다.

GELU 근사의 도함수\(u(x)=\sqrt{2/\pi}(x+0.044715x^3)\)로 두면:

\[\frac d{dx}\left[\frac x2(1+\tanh u)\right] =\frac12(1+\tanh u) +\frac x2(1-\tanh^2u)\sqrt{\frac2\pi}(1+3\cdot0.044715x^2).\]

정확 도함수 \(\Phi(x)+x\varphi(x)\)와 같은 기호로 혼용하지 않는다.

핵심 식

\[\operatorname{ReLU}(x)=\max(0,x),\quad \operatorname{GELU}(x)=x\Phi(x),\quad \operatorname{GELU}'(x)=\Phi(x)+x\varphi(x),\quad \operatorname{SiLU}(x)=x\sigma(x),\quad \operatorname{SiLU}'(x)=\sigma(x)+x\sigma(x)(1-\sigma(x)).\]

성질·유도

ReLU 도함수

\[\operatorname{ReLU}'(x) =\begin{cases}0,&x<0,\\1,&x>0.\end{cases}\]

\(x=0\)에서 고전적 도함수는 없으며 부분미분(subgradient) 집합은 \([0,1]\)이다. 구현은 보통 하나의 값을 정해 사용한다.

음수 구간과 dead unitReLU 입력이 지속적으로 음수인 샘플들에서는 해당 활성화를 통한 가중치 gradient가 0이다. 데이터나 다른 매개변수 업데이트로 부호가 바뀔 수도 있으므로 ‘한 번 음수면 영구적으로 죽는다’는 일반정리는 아니다. 여러 학습 샘플에서 계속 음수인 경우 학습이 어려울 수 있다.

GELU의 ‘확률’ 해석\(G\sim\mathcal N(0,1)\)라는 보조변수를 쓰면 \(\Phi(x)=P(G\le x)\)라서 \(xP(G\le x)\)로 쓸 수 있다. 입력 \(x\) 자체가 표준정규분포를 따른다는 가정은 정의에 필요하지 않다. 출력도 확률적 샘플이 아니라 주어진 \(x\)의 결정적 함수값이다.

GELU의 원점과 극한\(\operatorname{GELU}(0)=0\), \(\operatorname{GELU}'(0)=1/2\)다. \(x\to+\infty\)에서 함수와 도함수는 각각 \(x\), 1에 가까워진다. \(x\to-\infty\)에서 함수와 도함수는 0으로 접근하며 도함수는 충분히 음수인 영역에서 0의 음의 쪽으로 접근한다.

GELU의 비단조성음수 영역의 극솟값은 \(\Phi(x)+x\varphi(x)=0\)의 해 부근 \(x\approx-0.7518\)에서 생기며 함수값은 약 \(-0.1700\)이다. 음수 입력을 ReLU처럼 모두 0으로 자르지 않는다.

Sigmoid 복습

\[\sigma(x)=\frac1{1+e^{-x}}, \qquad \sigma'(x)=\sigma(x)(1-\sigma(x)).\]

이 sigmoid는 DL-02에서 SiLU 게이트와 DL-09의 SwiGLU에 들어간다.

SiLU와 Swish

\[\operatorname{SiLU}(x)=x\sigma(x)=\frac{x}{1+e^{-x}}.\]

\(\operatorname{Swish}_{\beta}(x)=x\sigma(\beta x)\)라는 매개변수형에서 \(\beta=1\)이면 SiLU다. 일부 문맥에서 Swish가 이 \(\beta=1\) 형태를 가리킨다.

SiLU 도함수의 첫 단계곱의 미분으로 다음과 같이 쓴다.

\[\operatorname{SiLU}'(x) =\sigma(x)+x\sigma'(x) =\sigma(x)+x\sigma(x)(1-\sigma(x)).\]

SiLU 도함수의 동치형

\[\operatorname{SiLU}'(x) =\sigma(x)[1+x(1-\sigma(x))] =\operatorname{SiLU}(x)+\sigma(x)[1-\operatorname{SiLU}(x)].\]

마지막 항등식은 \(\operatorname{SiLU}(x)=x\sigma(x)\)를 대입해 검산할 수 있다.

SiLU의 극솟값과 부호대략 \(x\approx-1.2785\)에서 함수 극솟값은 약 \(-0.2785\)다. 음수 입력에서의 함수값은 음수지만 도함수가 음수인 구간과 양수인 구간이 모두 있다. 원자료의 \(x=-1\)에서는 도함수가 양수다.

SiLU의 원점과 극한\(\operatorname{SiLU}(0)=0\), \(\operatorname{SiLU}'(0)=1/2\)다. 양의 큰 입력에서는 함수가 \(x\), 도함수가 1에 접근하고, 음의 큰 입력에서는 둘 다 0에 접근한다.

매끄러움 비교ReLU는 \(C^0\)이지만 0에서 미분 불가능하다. GELU와 SiLU는 실수축에서 매끄럽다. 매끄러운 활성화가 전체 손실 Hessian을 언제나 더 작게 하거나 모든 optimizer의 수렴을 보장한다는 결론은 나오지 않는다.

단조성 비교ReLU는 비감소 함수다. GELU와 SiLU는 음수 구간 일부의 도함수가 음수여서 비단조다. 비단조라는 사실만으로 일반화 성능이 항상 좋아진다고 추론할 수 없다.

연산량과 실제 지연세 함수 모두 스칼라 입력 하나당 상수 개수의 연산으로 평가할 수 있다. 그러나 ReLU의 비교 연산, GELU의 erf/tanh, SiLU의 지수 계산은 구현 비용이 다르다. GPU에서의 실제 속도는 kernel과 fusion에 영향을 받는다.

원자료의 모델 연결원자료는 고전 CNN의 ReLU, 일부 Transformer의 GELU, SwiGLU 블록의 SiLU를 비교한다. SwiGLU는 단순히 모든 위치에서 SiLU 한 번을 적용한 FFN과 다르며 두 사영 가지의 곱이 추가된다. 특정 모델 계열 전체에 한 활성화만 보편 적용된다고 해석하지 않는다.

오개념 교정비선형성이 없으면 아핀 합성으로 축퇴하지만 비선형성 하나로 UAT 조건이 자동 충족되지는 않는다. ReLU 양수 구간 미분 1은 전체 gradient 보존 정리가 아니다. GELU 정의에 입력 정규성은 필요하지 않고, SiLU의 \(x=-1\) 도함수는 음수가 아니다.

ReLU는 간단하고 양수에서 국소 기울기 1이지만 음수에서 정확히 0이다. GELU와 SiLU는 매끄럽고 일부 음수 구간에서 비단조이며, 도함수의 부호와 값은 입력에 따라 달라진다. 수치 예제의 0 지점에서는 ReLU만 미분 불가능하고 두 매끄러운 함수의 기울기는 \(1/2\)다.

예제·적용

수치 예제의 방법\(x\in\{-1,0,1\}\)에서 함수값과 도함수를 계산한다. 원자료는 문제에서 0도 요구했지만 풀이 본문에 \(-1\)과 \(1\)만 적었으므로 0 계산을 보완한다. 소수점 네 자리 반올림은 원식으로 계산한 뒤 마지막에 적용한다.

x = −1의 ReLU

\[\operatorname{ReLU}(-1)=0,\qquad \operatorname{ReLU}'(-1)=0.\]

이는 엄밀히 음수 구간의 값이므로 0에서의 미분 선택과 무관하다.

x = −1의 GELU\(\Phi(-1)\approx0.158655254\), \(\varphi(-1)\approx0.241970725\)다. 따라서 다음과 같다.

\[\operatorname{GELU}(-1)\approx-0.158655254,\quad \operatorname{GELU}'(-1) =0.158655254-0.241970725\approx-0.083315471.\]

네 자리 값은 \(-0.1587\)과 \(-0.0833\)이다.

x = −1의 SiLU\(\sigma(-1)\approx0.268941421\)이므로 다음과 같이 쓴다.

\[\operatorname{SiLU}(-1)\approx-0.268941421,\quad \operatorname{SiLU}'(-1) =0.268941421[1-(1-0.268941421)] \approx0.072329488.\]

x = 0의 ReLU\(\operatorname{ReLU}(0)=0\)이다. 수학적 도함수는 존재하지 않으며 subgradient \([0,1]\) 가운데 선택한 값이 구현 gradient가 된다. 원자료의 다른 두 함수와 동일하게 하나의 ‘정확 도함수 숫자’를 억지로 배정하지 않는다.

x = 0의 GELU·SiLU

\[\operatorname{GELU}(0)=\operatorname{SiLU}(0)=0,\qquad \operatorname{GELU}'(0)=\operatorname{SiLU}'(0)=\frac12.\]

\(\Phi(0)=\sigma(0)=1/2\)를 각각 대입했다.

x = 1의 ReLU

\[\operatorname{ReLU}(1)=1,\qquad \operatorname{ReLU}'(1)=1.\]

x = 1의 GELU

\[\operatorname{GELU}(1)=\Phi(1)\approx0.841344746, \quad \operatorname{GELU}'(1) =\Phi(1)+\varphi(1) \approx1.083315471.\]

도함수가 1을 초과하는 것도 가능하다.

x = 1의 SiLU

\[\operatorname{SiLU}(1)=\sigma(1)\approx0.731058579, \quad \operatorname{SiLU}'(1) =\sigma(1)[2-\sigma(1)] \approx0.927670512.\]

수치 결과표

표의 값은 정확식에서 끝에서만 반올림했다.

Gradient가 0이 아니라는 의미GELU와 SiLU의 음수 입력에서 도함수가 여러 점에서 0이 아닌 것은 그 지점의 국소적 미분 경로가 존재한다는 뜻이다. 큰 음수 입력에서는 두 도함수 모두 0에 가까우며, 신경망 전체 gradient가 반드시 흐른다는 뜻은 아니다.

Hessian과 최적화의 연결GELU·SiLU의 연속된 고차 미분은 매끄러운 함수 분석에 유리할 수 있다. 하지만 loss의 Hessian은 가중치·데이터·깊이·잔차 구조에도 달려 있다. ‘곡률 고유값을 항상 완만하게 하여 AdamW 진동을 줄인다’는 원자료의 진술은 일반 보장이 아니라 가능한 실험적 경향이다.

Transformer FFN의 기본형행벡터 입력 \(x\in\mathbb R^{1\times d}\)에 표준 FFN은 다음과 같다.

\[\operatorname{FFN}(x)=\phi(xW_{\rm up}+b_{\rm up})W_{\rm down}+b_{\rm down}.\]

활성화는 은닉 차원에서 요소별로 적용된다.

SwiGLU의 두 가지DL-09에서 다룰 SwiGLU는 다음과 같다.

\[\operatorname{SwiGLU}(x) =\bigl[\operatorname{SiLU}(xW_{\rm gate}+b_{\rm gate}) \odot(xW_{\rm up}+b_{\rm up})\bigr]W_{\rm down}+b_{\rm down}.\]

gate·up 출력의 shape가 같아야 한다.

SwiGLU의 미분 연결gate 좌표 \(a=\operatorname{SiLU}(h_1)\), value 좌표 \(v=h_2\)면 \(g=a v\)다. \(\partial g/\partial h_1=v\operatorname{SiLU}'(h_1)\), \(\partial g/\partial h_2=a\)다. 활성화 함수의 도함수가 실제로 어느 가지의 gradient에 곱해지는지 드러난다.

게이트는 확률이 아니다\(\operatorname{SiLU}(h)\)는 음수도 되고 양의 큰 입력에서 1을 초과한다. 따라서 gate를 항상 \([0,1]\)의 통과 확률이나 확실한 차단 스위치로 해석하지 않는다.

학습 점검

  1. 편향이 있을 때 활성화 없는 층의 합성이 왜 아핀 함수인가?
  2. \(\Phi(x)\)의 정의에서 입력 자체의 분포 가정이 왜 필요 없는가?
  3. \(x=0\)의 ReLU gradient를 수학적으로 어떻게 표기하고 구현에서 어떻게 정하는가?
  4. SiLU gate가 확률이라는 해석이 틀린 이유는?

정리

Activation function은 affine 변환 사이에 비선형성을 넣어 여러 linear layer의 합성이 단일 선형변환으로 붕괴하지 않게 한다. ReLU·GELU·SiLU는 값과 미분 특성이 달라 gradient 흐름과 FFN 게이팅에 서로 다른 효과를 내므로, 매끄러움이나 gradient 보존을 모든 입력에서 보장한다고 일반화하지 않는다.
