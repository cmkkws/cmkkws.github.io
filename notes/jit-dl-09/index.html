DL-09 — GLU and SwiGLU

GLU 계열 게이트의 순·역전파를 전개하고 SwiGLU의 폭·행렬 차원·연산량을 계산 예제로 검산한다.

ML·딥러닝 · DL-09업데이트 2026.09.27
  • #GLU
  • #SwiGLU
  • #GEGLU
  • #ReGLU
  • #Feed-Forward Network

개념

학습 목표표준 FFN과 GLU 계열을 shape와 함께 정의한다. SwiGLU의 두 사영 가지를 따라 역전파를 유도하고, 같은 파라미터 예산의 은닉 차원을 계산한다. 원자료의 \(2\times2\) 예제를 반올림 전 수치로 검산한다.

표준 FFN

\[\operatorname{FFN}_{\rm std}(x) =\phi(xW_{\rm up}+b_{\rm up})W_{\rm down}+b_{\rm down}, \quad W_{\rm up}\in\mathbb R^{d\times m},\quad W_{\rm down}\in\mathbb R^{m\times d}.\]

원자료의 예에서는 \(m=4d\)로 두지만 모든 모델에 같은 폭을 쓰지는 않는다.

조건부 작용표준 FFN도 입력에 따라 \(\phi(xW_{\rm up})\)가 변하므로 조건부 비선형 표현을 한다. GLU의 특징은 독립한 두 사영의 좌표별 곱이 추가되는 것이다. 표준 FFN에 입력별 선택 능력이 전혀 없다는 원자료의 서술은 지나치다.

표기·차원

행벡터 규약한 토큰 입력은 \(x\in\mathbb R^{1\times d}\)이고 은닉폭은 \(m\)이다. DL-02의 열벡터 표기와 방향만 다르다.

세 행렬의 shape\(W_1,W_2\in\mathbb R^{d\times m}, \qquad W_3\in\mathbb R^{m\times d}.\)

\(xW_1\)과 \(xW_2\)는 모두 \(1\times m\)이다. 두 출력의 Hadamard 곱이 정의되고 최종 출력은 \(1\times d\)다.

순전파 중간 변수

\[h_1=xW_1,\quad a=\operatorname{SiLU}(h_1),\quad h_2=xW_2,\quad g=a\odot h_2,\quad y=gW_3.\]

\(h_1,a,h_2,g\)는 \(1\times m\), \(y\)는 \(1\times d\)다.

핵심 연산

Sigmoid GLU와 bilinear 변형기본 sigmoid gate GLU의 한 형태는 다음과 같다.

\[\operatorname{GLU}_{\sigma}(x) =\bigl[(xW_2)\odot\sigma(xW_1)\bigr]W_3.\]

원자료가 ‘Bilinear GLU’라고 부르는 \([(xW_1)\odot(xW_2)]W_3\)는 sigmoid 없는 bilinear 변형이다. 두 함수를 동일시하지 않는다.

ReGLU

\[\operatorname{ReGLU}(x) =\bigl[\operatorname{ReLU}(xW_1)\odot(xW_2)\bigr]W_3.\]

ReLU의 음수 gate 좌표는 정확히 0이 된다.

GEGLU

\[\operatorname{GEGLU}(x) =\bigl[\operatorname{GELU}(xW_1)\odot(xW_2)\bigr]W_3.\]

GELU의 음수 출력은 반드시 0이 아니다.

Swish와 SiLU

\[\operatorname{Swish}_{\beta}(z)=z\sigma(\beta z),\qquad \operatorname{Swish}_{1}(z)=\operatorname{SiLU}(z).\]

\(\beta\)가 1이 아니거나 학습되는 변형은 이 장의 고정 SiLU gate와 구분한다.

SwiGLU 정의

\[\operatorname{SwiGLU}(x) =\bigl[\operatorname{SiLU}(xW_1)\odot(xW_2)\bigr]W_3.\]

원자료의 \(W_1,W_2,W_3\)는 차례로 gate, value(up), down projection이다.

Bias를 포함한 변형\(h_1=xW_1+b_1\), \(h_2=xW_2+b_2\), \(y=[\operatorname{SiLU}(h_1)\odot h_2]W_3+b_3\)도 가능하다. 원자료의 주된 유도와 예제는 bias-free 형태다.

Gate의 값 범위\(\operatorname{SiLU}(z)\)는 음수일 수 있고 양의 큰 \(z\)에서는 1을 초과한다. \([0,1]\)의 확률이나 이진 스위치로 해석하지 않는다. 해당 좌표의 value와 국소 gradient를 입력에 따라 크기 조절한다.

핵심 식

\[y=[\operatorname{SiLU}(xW_1)\odot(xW_2)]W_3,\quad \delta_g=\delta_yW_3^T,\quad \delta_{h_1}=\delta_g\odot h_2\odot\operatorname{SiLU}'(h_1),\quad \delta_{h_2}=\delta_g\odot\operatorname{SiLU}(h_1),\quad m_{\rm parity}=\frac83d.\]

성질·유도

SiLU 도함수DL-02에서 다음과 같이 쓴다.

\[\operatorname{SiLU}'(z) =\sigma(z)+z\sigma(z)(1-\sigma(z)).\]

양의 큰 입력에서 1에 접근하지만 음수 일부에서는 음수이고 큰 음수에서는 0에 가깝다.

출력 gradient\(\delta_y=\partial\mathcal L/\partial y\in\mathbb R^{1\times d}\)를 행 gradient로 쓴다. \(y=gW_3\)의 연쇄법칙은 전치된 가중치로 돌아간다.

Down projection의 역전파

\[\delta_g=\delta_yW_3^T\in\mathbb R^{1\times m},\qquad \nabla_{W_3}\mathcal L=g^T\delta_y\in\mathbb R^{m\times d}.\]

Value 가지 역전파\(g=a\odot h_2\)이므로 다음과 같이 쓴다.

\[\delta_{h_2}=\delta_g\odot a =\delta_g\odot\operatorname{SiLU}(h_1).\]

gate 값이 0인 좌표는 해당 위치의 value gradient가 이 단계에서 0이다.

Gate 가지 역전파

\[\delta_a=\delta_g\odot h_2,\qquad \delta_{h_1} =\delta_g\odot h_2\odot\operatorname{SiLU}'(h_1).\]

gate gradient는 value의 크기에도 의존한다.

Gate의 연쇄법칙 상세

\[\delta_{h_1} =\delta_g\odot h_2\odot \{\sigma(h_1)+h_1\odot\sigma(h_1)\odot[1-\sigma(h_1)]\}.\]

중괄호 안의 연산은 모두 좌표별이다.

입력 gradient

\[\boxed{\delta_x=\delta_{h_1}W_1^T+\delta_{h_2}W_2^T.}\]

두 가지가 같은 입력에서 갈라졌으므로 합한다. 결과 차원은 \(1\times d\)다.

두 입력 사영의 가중치 gradient

\[\nabla_{W_1}\mathcal L=x^T\delta_{h_1},\qquad \nabla_{W_2}\mathcal L=x^T\delta_{h_2}.\]

둘 다 \(d\times m\)이다. 여러 토큰에 대해서는 각 토큰의 기여를 합산한다.

Gradient 보장의 한계\(\operatorname{SiLU}'(z)\)가 큰 양수에서 1에 접근해도 \(\delta_g\), \(h_2\), 가중치 규모가 커지면 gradient가 폭발할 수 있다. 음수에서의 비영 도함수가 모든 dead unit을 해결하지도 않는다. ‘gradient highway’는 직관적 표현이다.

국소 곱 상호작용0 부근에서 \(\operatorname{SiLU}(u)=u/2+O(u^2)\)이므로 다음과 같이 쓴다.

\[g\approx\frac12(xW_1)\odot(xW_2).\]

입력의 2차 교차항이 생긴다. 이 국소 전개만으로 모든 문제에서 적은 파라미터로 높은 정확도를 보장하지는 않는다.

파라미터 수Bias를 제외하면 표준 FFN은 \(2dm\)개, SwiGLU는 \(3dm\)개의 가중치 스칼라를 갖는다. Attention, embedding, normalization의 매개변수는 여기에 포함하지 않는다.

표준 \(4d\) 폭원자료처럼 \(m_{\rm std}=4d\)라면:

\[P_{\rm std}=2d(4d)=8d^2.\]

이는 FFN의 가중치 행렬에 관한 값이다.

SwiGLU의 parity 폭

\[P_{\rm SwiGLU}=3d\,m_{\rm SwiGLU},\quad P_{\rm SwiGLU}=P_{\rm std} \quad\Longrightarrow\quad m_{\rm SwiGLU}=\frac83d.\]

은닉폭이 정수여야 하므로 실제 폭은 반올림된다.

FLOPs와 지연행렬곱의 주도적 연산량은 행렬 가중치 수와 유사하게 움직인다. 하지만 sigmoid·요소별 곱, kernel 호출, activation 저장이 추가되므로 파라미터 parity가 정확한 FLOPs·지연·메모리 parity는 아니다.

배수 정렬하드웨어 효율을 위해 은닉폭을 64·128·256 등의 배수로 고를 수 있다. \(d=4096\)에서는 \(\frac83d=10922\frac23\)이고 다음 256의 배수는 \(11008\)이다. 이는 한 가지 rounding 규칙이다.

4096→11008 표의 검산

\[\frac{P_{\rm SwiGLU}}{P_{\rm std}} =\frac{3(11008)}{8(4096)} =\frac{33024}{32768} =1.0078125.\]

원자료의 ‘완벽 정렬’은 엄밀히는 FFN 행렬 수 약 \(0.78125\%\) 초과다.

4096→14336 표의 검산

\[\frac{3(14336)}{8(4096)}=1.3125.\]

원자료가 LLaMA-3 8B 및 Mistral 7B의 예로 든 폭은 표준 \(4d\) FFN보다 31.25% 더 많은 FFN 행렬 매개변수를 갖는 설정이다.

8192→28672 표의 검산

\[\frac{3(28672)}{8(8192)}=1.3125.\]

원자료의 LLaMA-2 70B 행도 동일한 31.25% 차이다. 모델 전체 파라미터 증가율과는 구별한다.

원자료 표의 네 예시를 동일한 비교 기준으로 다시 쓰면 다음과 같다.

이름과 폭은 원자료의 표를 재현한 것이며 여기서 외부 모델 사양을 재검증한 값은 아니다. 앞의 비율은 각 표 행의 FFN 부분에 한정한다.

모델 사례의 적용 범위원자료의 LLaMA·Mistral·PaLM·Gemma·DeepSeek 언급은 GLU 계열 구조를 설명하는 사례다. 특정 버전의 상세 폭과 성능 변화는 별도 사양·실험 대상이다. ‘전 모델에서 3–5% 벤치마크 향상’이라는 보편 주장으로 옮기지 않는다.

Bias-free 원점 성질Bias-free에서 \(x=0\)이면 \(h_1=h_2=g=y=0\)이다. \(x\to0\)에서 \(\operatorname{SiLU}(u)\approx u/2\)이므로 중간 곱은 대략 \(O(\|x\|^2)\)다. 이것만으로 RMSNorm 결합의 훈련 안정성을 보증하지 않는다.

Bias를 넣으면\(x=0\)에서도 \(b_1,b_2,b_3\)에 따라 출력이 남을 수 있다. 하지만 bias가 있다고 언제나 불필요한 활성화나 발산이 생기는 것은 아니다. 제거 여부는 아키텍처의 설계 선택이다.

오개념 교정원자료의 bilinear GLU는 sigmoid GLU와 다르다. SiLU gate는 음수·1 초과도 가능하다. \(8d/3\)은 반올림 전 parity이며 14336/28672 표의 폭은 parity가 아니다. gate 출력 0인 좌표의 value gradient와 gate gradient를 따로 본다.

SwiGLU는 독립적인 gate와 value 사영을 곱해 FFN의 비선형 상호작용을 만든다. 표준 \(4d\) FFN의 행렬 파라미터 수를 맞추려면 \(m\approx8d/3\)이나 실제 모델 폭은 다르다. 원자료 예제의 최종 네 자리 값은 \((0.2431,-0.4863)\)이다.

예제·적용

수치 예제 입력과 행렬\(d=m=2\), \(x=(1,0.5)\)이고:

\[W_1=\begin{bmatrix}0.5&-0.2\\0.8&0.4\end{bmatrix},\quad W_2=\begin{bmatrix}1.2&0.1\\-0.5&0.6\end{bmatrix},\quad W_3=\begin{bmatrix}0.4&-0.8\\0.5&0.2\end{bmatrix}.\]

모든 값은 bias-free 순전파에 쓴다.

첫 Gate 좌표

\[(h_1)_1=1(0.5)+0.5(0.8)=0.9.\]

둘째 Gate 좌표

\[(h_1)_2=1(-0.2)+0.5(0.4)=0.\]

따라서 \(h_1=(0.9,0)\)다.

Sigmoid 검산

\[\sigma(0.9)=\frac1{1+e^{-0.9}} \approx0.710949502625,\qquad \sigma(0)=0.5.\]

원자료의 \(0.7109\)는 계산 중간 반올림이다.

SiLU gate

\[a=(0.9\sigma(0.9),0) \approx(0.639854552363,0).\]

두 번째 게이트는 \(\operatorname{SiLU}(0)=0\)이라 정확히 0이다.

Value 첫 좌표

\[(h_2)_1=1(1.2)+0.5(-0.5)=0.95.\]

Value 둘째 좌표

\[(h_2)_2=1(0.1)+0.5(0.6)=0.4.\]

따라서 \(h_2=(0.95,0.4)\)다.

게이팅 곱

\[g=a\odot h_2 =\bigl(0.95\cdot0.9\sigma(0.9),0\cdot0.4\bigr) \approx(0.607861824744,0).\]

최종 출력의 첫 좌표

\[y_1=0.4g_1+0.5g_2 \approx0.243144729898 \longrightarrow0.2431.\]

최종 출력의 둘째 좌표

\[y_2=-0.8g_1+0.2g_2 \approx-0.486289459796 \longrightarrow-0.4863.\]

원자료의 \(-0.4862\)는 \(a\approx0.6398\) 등의 중간 반올림 값을 다시 곱해 생긴 차이다.

수치 예제의 결론

\[\boxed{y\approx(0.243144729898,-0.486289459796)}\]

네 자리 반올림값은 \((0.2431,-0.4863)\)이다. 두 번째 gate가 0이어도 첫 번째 중간 좌표가 \(W_3\)의 첫 행을 통해 출력 두 좌표에 기여한다.

역전파 점검 설정원자료는 순전파만 계산한다. 역전파 수식의 shape를 확인하기 위해 별도의 예로 \(\delta_y=(1,1)\)을 둔다. 이는 원자료가 지정한 loss가 아니라 임의의 상위 gradient다.

Down gradient의 계산

\[\delta_g=(1,1)W_3^T=(-0.4,0.7).\]

\(g_2=0\)인데도 \(\delta_{g,2}=0.7\)이다.

두 가지의 gradient

\[\delta_{h_2}=\delta_g\odot a\approx(-0.255941820945,0).\]

\(\operatorname{SiLU}'(0)=1/2\)를 이용하면 다음과 같다.

\[\delta_{h_1} =\delta_g\odot h_2\odot\operatorname{SiLU}'(h_1) \approx(-0.340441916109,0.14).\]

둘째 value gradient가 0이어도 둘째 gate gradient는 남는다.

입력 gradient 검산

\[\delta_x=\delta_{h_1}W_1^T+\delta_{h_2}W_2^T \approx(-0.505351143188,-0.088382622414).\]

게이트의 국소 역할과 전체 입력 gradient의 크기는 서로 다른 대상이다.

가중치별 미분도 행·열 차원을 확인할 수 있다.

\[\nabla_{W_1}\mathcal L =x^T\delta_{h_1} \approx\begin{bmatrix} -0.340441916&0.14\\ -0.170220958&0.07 \end{bmatrix}, \quad \nabla_{W_2}\mathcal L =x^T\delta_{h_2} \approx\begin{bmatrix} -0.255941821&0\\ -0.127970910&0 \end{bmatrix}.\]

\(\nabla_{W_3}\mathcal L=g^T(1,1)\)의 첫 행은 \((0.607861825,0.607861825)\)이고 둘째 행은 \((0,0)\)이다. 서로 다른 매개변수의 gradient 0 여부를 구별한다.

합친 사영 행렬

\[W_{12}=[W_1\;\;W_2]\in\mathbb R^{d\times2m}, \qquad xW_{12}=[h_1\;\;h_2].\]

두 사영을 하나의 큰 행렬곱으로 계산할 수 있다. 수학적 두 분기의 곱 구조는 그대로 남는다.

Kernel fusion의 범위큰 GEMM과 SiLU·Hadamard 곱을 결합하면 launch 수나 중간 메모리 쓰기를 줄일 수 있다. 하드웨어·shape·메모리·컴파일러에 따라 실제 이득은 달라지며 DRAM I/O 병목을 ‘완전히 제거’할 수 있다는 일반 보장은 없다.

학습 점검

  1. \(\delta_{h_1}\)과 \(\delta_{h_2}\)에 각각 어떤 요소별 항이 곱해지는가?
  2. 4096→14336과 4096→11008의 파라미터 비율이 다른 이유는?
  3. 게이트 출력 0인 예제 둘째 좌표에서 gate gradient는 왜 남는가?
  4. \(W_{12}\) 결합이 실제 속도 향상을 항상 보장하지 않는 이유는?

정리

GLU 계열 FFN은 value 변환과 gate 변환을 원소별 곱으로 결합해 입력별로 통과량을 조절한다. SwiGLU는 SiLU gate를 사용하며, 추가 projection의 parameter·연산 비용과 hidden width를 함께 비교해야 표준 FFN과 공정하게 평가할 수 있다.
