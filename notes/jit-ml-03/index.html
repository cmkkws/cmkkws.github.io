ML-03 — Overfitting, Underfitting & Generalization

Overfitting과 Underfitting, Generalization의 관계와 진단 기준을 정리한다.

수정 2026.09.21약 61분상태 작성 완료
학습 내용
  • Generalization
  • Training Dataset
  • Training Error
  • In-Sample Error
011. Generalization022. Training Dataset033. Training Error044. In-Sample Error055. True Data Distribution066. Generalization Error

1. Generalization

Machine Learning의 목표는 Training Dataset에만 잘 맞는 Model을 만드는 것이 아니다.

관측하지 않은 새로운 Data에 대해서도 낮은 Prediction Error를 갖는 Model을 만드는 것이 핵심이다.

이를

\[\boxed{ \text{Generalization} }\]

이라고 한다.

2. Training Dataset

관측된 Dataset을

\[\boxed{ \mathcal D = \{ (\mathbf x_i,y_i) \}_{i=1}^{N} }\]

라고 하자.

Model을

\[\boxed{ f }\]

라고 하고 Sample Loss를

\[\boxed{ \mathcal L( f(\mathbf x_i),y_i ) }\]

라고 한다.

3. Training Error

Training Dataset 위에서 계산한 평균 Loss를 Training Error 또는 Empirical Risk라고 한다.

\[\boxed{ \mathcal R_{\mathrm{emp}}(f) = \frac1N \sum_{i=1}^{N} \mathcal L \left( f(\mathbf x_i), y_i \right) }\]

4. In-Sample Error

Training Error는 동일하게

\[\boxed{ \text{In-sample Error} }\]

라고 부를 수 있다.

이미 학습 과정에서 사용한 Sample 위에서 측정한 Error이기 때문이다.

5. True Data Distribution

새로운 Data는 어떤 모집단 Distribution

\[\boxed{ p(\mathbf x,y) }\]

에서 생성된다고 생각한다.

이 Distribution은 일반적으로 Training 과정에서 직접 알려져 있지 않다.

6. Generalization Error

참 Data Distribution 전체에서의 Expected Loss를 Generalization Error 또는 True Risk라고 한다.

\[\boxed{ \mathcal R(f) = \mathbb E_{ (\mathbf x,y)\sim p(\mathbf x,y) } \left[ \mathcal L( f(\mathbf x),y ) \right] }\]

7. Integral Form

연속형 변수의 경우

\[\boxed{ \mathcal R(f) = \int \mathcal L( f(\mathbf x),y ) p(\mathbf x,y) \,d\mathbf x\,dy }\]

로 쓸 수 있다.

8. Out-of-Sample Error

True Risk는 Training에 사용하지 않은 새로운 Observation에 대한 평균적인 Error를 의미한다.

따라서

\[\boxed{ \mathcal R(f) = \text{expected out-of-sample error} }\]

로 이해할 수 있다.

9. Training Error vs Generalization Error

Training Error:

\[\boxed{ \mathcal R_{\mathrm{emp}}(f) }\]

Generalization Error:

\[\boxed{ \mathcal R(f) }\]

두 Quantity가 같다고 가정해서는 안 된다.

10. Generalization Gap

두 Error의 차이를 Generalization Gap이라고 한다.

\[\boxed{ \operatorname{Gap}(f) = \mathcal R(f) - \mathcal R_{\mathrm{emp}}(f) }\]

11. Gap의 의미

Training Error가 매우 작더라도

\[\mathcal R(f)\]

가 크다면

\[\boxed{ \operatorname{Gap}(f) }\]

도 크게 나타난다.

따라서

\[\boxed{ \text{small training error} \not\Rightarrow \text{good generalization} }\]

12. ML-01과 연결

ML-01에서는 Empirical Risk Minimization을

\[\boxed{ \hat f_{\mathrm{ERM}} = \arg\min_f \mathcal R_{\mathrm{emp}}(f) }\]

로 정의했다.

ML-03에서는 여기서 한 단계 더 나아가

\[\boxed{ \mathcal R_{\mathrm{emp}}(f) \text{를 줄인 결과가 } \mathcal R(f) \text{에도 잘 이어지는가?} }\]

를 다룬다.

13. Underfitting

Underfitting은 Model이 Data의 구조를 충분히 표현하지 못하는 상태를 말한다.

원자료에서는 Model Capacity가 너무 낮은 경우와 연결한다.

14. Underfitting의 Error Pattern

Underfitting에서는 일반적으로

\[\boxed{ \mathcal R_{\mathrm{emp}}(f) \text{ high} }\]

이고

\[\boxed{ \mathcal R(f) \text{ high} }\]

인 상태를 생각한다.

즉 Training Data조차 충분히 설명하지 못한다.

15. High Bias

원자료는 Underfitting을

\[\boxed{ \text{High Bias} }\]

와 연결한다.

Model이 지나치게 단순하여 참 함수의 구조를 체계적으로 놓치는 상황을 의미한다.

16. Overfitting

Overfitting은 Model이 Training Data에는 매우 잘 맞지만 새로운 Data에서는 성능이 상대적으로 나빠지는 현상이다.

원자료에서는 Training Data의 Noise나 Random Fluctuation까지 Memorization하는 상황으로 설명한다.

17. Overfitting의 Error Pattern

전형적인 경우

\[\boxed{ \mathcal R_{\mathrm{emp}}(f) \text{ low} }\]

이지만

\[\boxed{ \mathcal R(f) \text{ relatively high} }\]

따라서

\[\boxed{ \operatorname{Gap}(f) }\]

가 커진다.

18. High Variance

원자료는 Overfitting을

\[\boxed{ \text{High Variance} }\]

와 연결한다.

Training Dataset이 조금만 바뀌어도 학습된 Model Prediction이 크게 달라지는 상황이다.

19. Model Capacity

Model Capacity는 Model이 얼마나 다양한 Function을 표현할 수 있는지를 나타내는 개념이다.

원자료는 Capacity가 증가할수록

  • Underfitting이 감소할 수 있고
  • 지나치게 높은 Capacity에서는 Overfitting 위험이 존재할 수 있다

는 Classical Intuition을 제시한다.

20. Capacity와 Training Error

일반적으로 Model Class가 더 풍부해질수록 Training Data를 맞출 수 있는 자유도가 커진다.

따라서

\[\boxed{ \text{capacity}\uparrow \Rightarrow \mathcal R_{\mathrm{emp}} \text{ can decrease} }\]

라는 방향을 생각할 수 있다.

21. Capacity와 Test Error

하지만 Generalization Error는 Training Error처럼 단순하게 감소하지 않을 수 있다.

Classical Statistical Learning에서는 Capacity가 증가할수록

  1. Bias 감소
  2. Variance 증가

사이의 Trade-off를 고려한다.

22. Bias–Variance Trade-off

원자료의 핵심 수학적 내용은 MSE를 다음 세 항으로 분해하는 것이다.

\[\boxed{ \text{Expected MSE} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Noise} }\]

23. Data Generating Process

다음 Regression Setting을 가정한다.

\[\boxed{ y = f(\mathbf x) + \epsilon }\]

여기서

\[f(\mathbf x)\]

는 True Function이고

\[\epsilon\]

은 Noise다.

24. Noise Assumptions

원자료는

\[\boxed{ \mathbb E[\epsilon]=0 }\]

그리고

\[\boxed{ \operatorname{Var}(\epsilon) = \sigma^2 }\]

를 가정한다.

25. Irreducible Noise

Noise Variance

\[\boxed{ \sigma^2 }\]

는 Input만으로 제거할 수 없는 Random Variation을 나타낸다.

원자료에서는 이를

\[\boxed{ \text{Irreducible Error} }\]

와 연결한다.

26. Random Training Dataset

학습 Dataset 자체도 Random Sample이다.

따라서 학습 Algorithm을 같은 방식으로 적용하더라도 Dataset

\[\mathcal D\]

가 달라지면 학습된 Model도 달라질 수 있다.

이를

\[\boxed{ \hat f( \mathbf x; \mathcal D ) }\]

로 표기한다.

27. Random Predictor

고정된 Input

\[\mathbf x\]

에서도 Training Dataset에 따라

\[\hat f(\mathbf x;\mathcal D)\]

가 달라진다.

따라서

\[\boxed{ \hat f(\mathbf x) }\]

자체를 Dataset Randomness에 따른 Random Variable로 볼 수 있다.

28. Mean Predictor

여러 가능한 Training Dataset에 대해 학습한 Model Prediction의 평균을

\[\boxed{ \bar f(\mathbf x) = \mathbb E_{\mathcal D} [ \hat f(\mathbf x) ] }\]

라고 정의한다.

29. Bias Definition

Prediction Bias는

\[\boxed{ \operatorname{Bias} ( \hat f(\mathbf x) ) = \mathbb E_{\mathcal D} [ \hat f(\mathbf x) ] - f(\mathbf x) }\]

즉

\[\boxed{ \operatorname{Bias} = \bar f(\mathbf x)-f(\mathbf x) }\]

30. Squared Bias

MSE Decomposition에서는 Bias 자체가 아니라 Squared Bias가 등장한다.

\[\boxed{ \operatorname{Bias}^2 = \left( \bar f(\mathbf x)-f(\mathbf x) \right)^2 }\]

31. Variance Definition

Prediction Variance는

\[\boxed{ \operatorname{Var} ( \hat f(\mathbf x) ) = \mathbb E_{\mathcal D} \left[ \left( \hat f(\mathbf x) - \bar f(\mathbf x) \right)^2 \right] }\]

32. Variance의 의미

Variance가 크다는 것은 Training Dataset이 달라질 때 Prediction

\[\hat f(\mathbf x)\]

가 크게 변한다는 뜻이다.

즉

\[\boxed{ \text{dataset sensitivity} }\]

와 연결된다.

33. Expected Prediction Error

새로운 Input \(\mathbf x\)에서 새로운 Target

\[y=f(\mathbf x)+\epsilon\]

이 생성된다고 하자.

Expected Squared Prediction Error는

\[\boxed{ \mathbb E_{\mathcal D,\epsilon} \left[ \left( y-\hat f(\mathbf x) \right)^2 \right] }\]

34. Bias–Variance Decomposition Goal

증명하려는 식은

\[\boxed{ \mathbb E_{\mathcal D,\epsilon} \left[ ( y-\hat f(\mathbf x) )^2 \right] = \operatorname{Bias}^2 + \operatorname{Var} + \sigma^2 }\]

35. Target Substitute

Data Generating Process

\[y=f(\mathbf x)+\epsilon\]

을 대입하면

\[y-\hat f(\mathbf x) = f(\mathbf x) + \epsilon - \hat f(\mathbf x)\]

36. Mean Predictor 더하고 빼기

중간에

\[\bar f(\mathbf x)\]

를 더하고 뺀다.

\[\begin{aligned} y-\hat f(\mathbf x) &= f(\mathbf x)-\bar f(\mathbf x)\\ &\quad+ \bar f(\mathbf x)-\hat f(\mathbf x)\\ &\quad+ \epsilon \end{aligned}\]

37. Three Components

다음을 정의한다.

\[\boxed{ A = f(\mathbf x) - \bar f(\mathbf x) }\]
\[\boxed{ B = \bar f(\mathbf x) - \hat f(\mathbf x) }\]
\[\boxed{ C = \epsilon }\]

따라서

\[\boxed{ y-\hat f(\mathbf x) = A+B+C }\]

38. Square Expansion

\[(A+B+C)^2\]

을 전개하면

\[\boxed{ A^2+B^2+C^2 + 2AB + 2BC + 2CA }\]

39. Expected Error Expansion

따라서

\[\begin{aligned} & \mathbb E_{\mathcal D,\epsilon} [ ( y-\hat f )^2 ]\\ &= \mathbb E[ A^2 ] + \mathbb E[ B^2 ] + \mathbb E[ C^2 ]\\ &\quad+ 2\mathbb E[ AB ] + 2\mathbb E[ BC ] + 2\mathbb E[ CA ] \end{aligned}\]

40. First Squared Term

\(A\)는 Dataset Randomness와 Noise에 대해 Constant다.

따라서

\[\boxed{ \mathbb E[ A^2 ] = \left( f(\mathbf x)-\bar f(\mathbf x) \right)^2 }\]

41. Bias Term

Squared Bias는

\[\left( \bar f(\mathbf x)-f(\mathbf x) \right)^2\]

제곱이므로 부호와 관계없이

\[\boxed{ \mathbb E[ A^2 ] = \operatorname{Bias}^2 }\]

42. Second Squared Term

\[B = \bar f(\mathbf x) - \hat f(\mathbf x)\]

이므로

\[B^2 = \left( \hat f(\mathbf x)-\bar f(\mathbf x) \right)^2\]

43. Variance Term

Dataset에 대해 Expectation을 취하면

\[\boxed{ \mathbb E_{\mathcal D} [ B^2 ] = \operatorname{Var}_{\mathcal D} ( \hat f(\mathbf x) ) }\]

44. Third Squared Term

\[C=\epsilon\]

이고

\[\mathbb E[\epsilon]=0\]

이므로

\[\boxed{ \mathbb E[ C^2 ] = \mathbb E[ \epsilon^2 ] = \sigma^2 }\]

45. First Cross Term

첫 번째 Cross Term은

\[2AB\]

\(A\)는 Constant이므로

\[\mathbb E[ 2AB ] = 2A \mathbb E_{\mathcal D}[B]\]

46. Mean of $B$

\[\begin{aligned} \mathbb E_{\mathcal D}[B] &= \mathbb E_{\mathcal D} [ \bar f-\hat f ]\\ &= \bar f - \mathbb E_{\mathcal D}[\hat f]\\ &= \bar f-\bar f\\ &= \boxed{0} \end{aligned}\]

47. First Cross Term Vanishes

따라서

\[\boxed{ \mathbb E[ 2AB ] = 0 }\]

48. Noise Mean

원자료의 가정에 의해

\[\boxed{ \mathbb E[\epsilon]=0 }\]

이 성질 때문에 Noise를 포함한 Cross Term도 사라진다.

49. $AC$ Cross Term

\[A\]

는 Noise와 무관한 Constant이므로

\[\begin{aligned} \mathbb E[ 2AC ] &= 2A \mathbb E[\epsilon]\\ &= \boxed{0} \end{aligned}\]

50. $BC$ Cross Term

원자료는 Noise가 Training Dataset 및 Predictor Randomness와 독립이라는 설정을 사용한다.

따라서

\[\mathbb E[ BC ] = \mathbb E[B] \mathbb E[C]\]

이고 두 평균 모두 0이다.

따라서

\[\boxed{ \mathbb E[ 2BC ] = 0 }\]

51. All Cross Terms

결국

\[\boxed{ \mathbb E[AB] = \mathbb E[BC] = \mathbb E[CA] = 0 }\]

52. Final Decomposition

남는 세 항을 결합하면

\[\boxed{ \mathbb E_{\mathcal D,\epsilon} [ ( y-\hat f(\mathbf x) )^2 ] = \operatorname{Bias}^2 ( \hat f(\mathbf x) ) + \operatorname{Var} ( \hat f(\mathbf x) ) + \sigma^2 }\]

53. Bias Term Interpretation

\[\boxed{ \operatorname{Bias}^2 }\]

는 평균 Predictor가 True Function으로부터 얼마나 체계적으로 떨어져 있는지를 측정한다.

큰 Bias는 Model Class가 Data Structure를 충분히 표현하지 못할 때 나타날 수 있다.

54. Variance Term Interpretation

\[\boxed{ \operatorname{Var} }\]

는 Training Dataset의 작은 변화가 Prediction을 얼마나 크게 변화시키는지를 측정한다.

Variance가 크면 Model Prediction이 Dataset에 민감하다.

55. Noise Term Interpretation

\[\boxed{ \sigma^2 }\]

는 현재 Data Generating Assumption 아래에서 Predictor가 제거할 수 없는 Noise Variation이다.

이를 줄이기 위해 단순히 Model Capacity를 증가시키는 것은 해결책이 아니다.

56. Bias–Variance Trade-off

Classical Intuition에서는 Model Complexity가 증가하면서

\[\boxed{ \text{Bias} \downarrow }\]

하고

\[\boxed{ \text{Variance} \uparrow }\]

할 수 있다.

Generalization Error는 이 두 효과의 합에 의해 결정된다.

57. Underfitting과 Bias

Underfitting은 일반적으로

\[\boxed{ \text{High Bias} }\]

와 연결된다.

평균 Predictor 자체가 True Function으로부터 크게 벗어나 있기 때문이다.

58. Overfitting과 Variance

Classical Setting에서 Overfitting은

\[\boxed{ \text{High Variance} }\]

와 연결된다.

Training Dataset이 달라질 때 Model Prediction이 크게 흔들릴 수 있기 때문이다.

59. 중요한 범위 — MSE Decomposition

현재 Bias–Variance 식

\[\boxed{ \text{Bias}^2+\text{Variance}+\sigma^2 }\]

은 원자료처럼 Squared Error Regression Setting에서 유도한 결과다.

모든 Loss Function에 동일한 형태로 그대로 적용되는 일반 항등식이라고 생각하면 안 된다.

60. Numerical Example — True Function

원자료의 True Function은

\[\boxed{ f(x)=2x }\]

평가 Point는

\[\boxed{ x=3 }\]

따라서 Noise가 없는 True Output은

\[\boxed{ f(3)=6 }\]

61. Noise Variance

Noise Variance는

\[\boxed{ \sigma^2=0.5 }\]

두 Model 모두 동일한 Data Generating Process를 예측하므로 같은 Irreducible Noise를 가진다.

62. Model $M_1$

서로 다른 Dataset에 대해 학습된 Model \(M_1\)의 \(x=3\) Prediction Distribution은 원자료에서

\[\boxed{ \mathbb E[ \hat f_1(3) ] = 4.5 }\]

이고

\[\boxed{ \operatorname{Var} ( \hat f_1(3) ) = 0.2 }\]

로 주어진다.

63. $M_1$ Bias

\[\begin{aligned} \operatorname{Bias}(M_1) &= \mathbb E[ \hat f_1(3) ] - f(3)\\ &= 4.5-6\\ &= \boxed{ -1.5 } \end{aligned}\]

64. $M_1$ Squared Bias

\[\boxed{ \operatorname{Bias}^2(M_1) = (-1.5)^2 = 2.25 }\]

65. $M_1$ Variance

원자료에서

\[\boxed{ \operatorname{Var}(M_1) = 0.2 }\]

66. $M_1$ Expected MSE

따라서

\[\begin{aligned} \operatorname{EPE}(M_1) &= 2.25+0.2+0.5\\ &= \boxed{ 3.05 } \end{aligned}\]

67. $M_1$ Interpretation

\(M_1\)은

\[\boxed{ \text{High Bias} + \text{Low Variance} }\]

형태를 가진다.

즉 Dataset에 따라 Prediction은 안정적이지만 평균 Prediction이 True Value 6에서 상당히 떨어져 있다.

68. Model $M_2$

원자료에서 \(M_2\)의 Prediction Distribution은

\[\boxed{ \mathbb E[ \hat f_2(3) ] = 5.9 }\]

이고

\[\boxed{ \operatorname{Var} ( \hat f_2(3) ) = 2.5 }\]

69. $M_2$ Bias

\[\begin{aligned} \operatorname{Bias}(M_2) &= 5.9-6.0\\ &= \boxed{ -0.1 } \end{aligned}\]

70. $M_2$ Squared Bias

\[\boxed{ \operatorname{Bias}^2(M_2) = (-0.1)^2 = 0.01 }\]

71. $M_2$ Variance

원자료에서

\[\boxed{ \operatorname{Var}(M_2) = 2.5 }\]

72. $M_2$ Expected MSE

\[\begin{aligned} \operatorname{EPE}(M_2) &= 0.01+2.5+0.5\\ &= \boxed{ 3.01 } \end{aligned}\]

73. $M_2$ Interpretation

\(M_2\)는

\[\boxed{ \text{Low Bias} + \text{High Variance} }\]

형태다.

평균적으로 True Function에 매우 가깝지만 Training Dataset에 따라 Prediction이 크게 달라질 수 있다.

74. 두 Model 비교

수치적으로

\[\boxed{ \operatorname{EPE}(M_1) = 3.05 }\]

이고

\[\boxed{ \operatorname{EPE}(M_2) = 3.01 }\]

따라서 이 예제에서는 \(M_2\)의 Expected MSE가 아주 조금 낮다.

75. Trade-off 확인

\(M_1\):

\[\boxed{ 2.25 + 0.2 + 0.5 = 3.05 }\]

\(M_2\):

\[\boxed{ 0.01 + 2.5 + 0.5 = 3.01 }\]

하나는 Bias가 크고 Variance가 작으며, 다른 하나는 Bias가 작고 Variance가 크다.

76. Irreducible Error는 동일

두 Model에서

\[\boxed{ \sigma^2=0.5 }\]

는 동일하다.

이는 Model 선택으로 제거되는 항이 아니다.

따라서 비교의 핵심은

\[\boxed{ \operatorname{Bias}^2 + \operatorname{Variance} }\]

77. Classical U-Shaped Picture

원자료는 Classical Statistical Learning에서 Model Capacity와 Test Error 관계를 U-shaped Curve 직관으로 설명한다.

Capacity가 너무 낮으면 Underfitting이 발생할 수 있다.

Capacity를 증가시키면 Bias가 감소하면서 Test Error가 낮아질 수 있다.

78. Classical Overfitting Region

Capacity가 더 증가하면서 Variance가 크게 증가하면 Test Error가 다시 증가할 수 있다는 것이 고전적인 Bias–Variance Trade-off 그림이다.

즉

\[\boxed{ \text{too simple} \rightarrow \text{underfit} }\]
\[\boxed{ \text{intermediate complexity} \rightarrow \text{better balance} }\]
\[\boxed{ \text{too flexible} \rightarrow \text{possible overfit} }\]

라는 직관이다.

79. Modern Deep Learning과 Classical Picture

원자료는 Modern Deep Learning에서는 단순 U-shaped Curve만으로 설명되지 않는 현상이 존재한다고 연결한다.

대표적으로

\[\boxed{ \text{Double Descent} }\]

를 제시한다.

80. Double Descent

Double Descent는 Model Capacity가 증가할 때 Test Error가

  1. 처음 감소하고
  2. Interpolation Threshold 부근에서 증가한 뒤
  3. 더 큰 Overparameterized 영역에서 다시 감소

하는 형태를 가리킨다.

81. Interpolation Threshold

Training Error가 거의 0까지 내려가며 Training Data를 정확히 Fit할 수 있게 되는 근처를

\[\boxed{ \text{Interpolation Threshold} }\]

라고 부르는 맥락이 있다.

원자료는 이 근처에서 Test Error가 커질 수 있다고 설명한다.

82. Overparameterized Regime

Parameter 수 또는 Function Class Capacity가 Training Sample 수를 크게 넘어서는 영역을

\[\boxed{ \text{Overparameterized Regime} }\]

이라고 표현할 수 있다.

Modern Deep Neural Network는 흔히 이러한 영역에서 학습된다.

83. Double Descent에 대한 주의

Double Descent는 실제로 관찰될 수 있는 중요한 현상이지만

\[\boxed{ \text{모든 deep network에서 반드시 동일한 curve가 나온다} }\]

는 뜻은 아니다.

Data, Model, Noise, Optimization, Regularization에 따라 형태가 달라질 수 있다.

84. SGD와 Double Descent

원자료는 Overparameterized 영역의 재하강을

  • SGD의 Implicit Regularization
  • Flat Minima 선호

와 연결한다.

이는 현대 Deep Learning Generalization을 설명하려는 직관 중 하나로 볼 수 있다.

85. 인과적 단정에 대한 주의

하지만

\[\boxed{ \text{SGD prefers flat minima} \Rightarrow \text{therefore double descent must occur} }\]

와 같은 단일 인과 정리는 원자료에서 수학적으로 증명되지 않는다.

따라서 이 부분은 현대 Deep Learning의 해석적 연결로 구분한다.

86. Overparameterization과 Generalization

중요한 점은

\[\boxed{ \text{many parameters} \not\Rightarrow \text{automatic poor generalization} }\]

이라는 것이다.

Modern Neural Network는 Parameter 수가 매우 많아도 좋은 Test Performance를 보일 수 있다.

87. Capacity만으로는 부족

실제 Generalization은

  • Architecture
  • Optimization
  • Data Distribution
  • Regularization
  • Initialization
  • Training Dynamics

등 여러 요인의 영향을 받는다.

따라서 Parameter Count 하나만으로 Overfitting 여부를 결정하지 않는다.

88. Regularization

Generalization을 제어하기 위해 원자료는 여러 Regularization Mechanism을 제시한다.

대표적으로

  • Weight Decay
  • Dropout
  • Early Stopping

89. Weight Decay

원자료는 Weight Decay를

\[\boxed{ L_2\text{-type regularization} }\]

과 연결한다.

대표적인 Regularized Objective는

\[\boxed{ J(\theta) = \mathcal R_{\mathrm{emp}}(\theta) + \lambda \| \theta \|_2^2 }\]

형태다.

90. Weight Norm Constraint Intuition

Weight Magnitude를 Penalize하면 일부 Model Parameter가 지나치게 큰 값을 가지는 것을 억제할 수 있다.

원자료는 이를 Model의 Effective Capacity와 Variance를 줄이는 방향으로 해석한다.

91. Weight Decay 주의

다만

\[\boxed{ \text{weight decay} \Rightarrow \text{variance always decreases by a fixed amount} }\]

같은 일반적 수치 법칙은 아니다.

실제 효과는 Optimization과 Architecture에 의존한다.

92. Dropout

Dropout은 Training 중 일부 Unit 또는 Activation을 Random하게 제거하는 방법이다.

원자료는 이를 Ensemble-like Effect와 연결하여 특정 Parameter Combination에 대한 과도한 의존을 줄이는 방식으로 설명한다.

93. Dropout의 목적

직관적으로

\[\boxed{ \text{single brittle representation} \rightarrow \text{more distributed representation} }\]

을 유도하려는 Regularization Mechanism으로 볼 수 있다.

94. Early Stopping

Training이 진행되면서 Training Loss는 계속 감소할 수 있지만 Validation Loss가 악화될 수 있다.

이때 Validation Performance가 나빠지기 전에 Training을 중단하는 방법이

\[\boxed{ \text{Early Stopping} }\]

95. Validation Set

Early Stopping을 사용하려면 Training Set과 별도로 Model Selection에 사용할 Validation Set을 두는 것이 일반적이다.

즉

\[\boxed{ \text{Training} \rightarrow \text{Validation monitoring} \rightarrow \text{stop} }\]

구조다.

96. Train / Validation / Test 구분

Training Set:

\[\boxed{ \text{parameter optimization} }\]

Validation Set:

\[\boxed{ \text{hyperparameter / stopping decision} }\]

Test Set:

\[\boxed{ \text{final evaluation} }\]

으로 구분하는 것이 중요하다.

97. Test Set Leakage

Test Set을 반복적으로 보고 Hyperparameter를 조정하면 Test Set도 사실상 Model Selection에 사용된다.

그러면 Test Error가 순수한 Out-of-Sample Estimate 역할을 잃을 수 있다.

Generalization 평가에서는 Data Split의 역할을 구분해야 한다.

98. LLM Pre-training과 Generalization

LLM에서도 Training Objective는 Training Corpus의 Average NLL을 줄이는 것이다.

\[\boxed{ \mathcal L_{\mathrm{train}} = -\frac1N \sum_t \log P_\theta( y_t\mid y_{<t} ) }\]

하지만 Training Loss가 낮다고 해서 모든 새로운 Domain에서 낮은 Loss가 보장되는 것은 아니다.

99. Distribution Shift

LLM Deployment Distribution이 Training Corpus Distribution과 다르면 Generalization 문제가 더 복잡해진다.

즉

\[\boxed{ P_{\mathrm{train}} \neq P_{\mathrm{test}} }\]

인 Distribution Shift 상황에서는 단순한 i.i.d. Generalization Setting과 구분해야 한다.

100. SFT와 Overfitting

원자료는 Supervised Fine-Tuning에서 Dataset이 작고 동일한 Example을 과도하게 반복하면 Memorization 위험이 커질 수 있다고 설명한다.

즉

\[\boxed{ \text{small SFT dataset} + \text{too much optimization} \rightarrow \text{possible overfitting} }\]

101. Memorization

Memorization은 Training Example의 특정 문장이나 Label Pattern을 매우 정확히 재현하는 현상을 의미할 수 있다.

그러나 Memorization과 Generalization은 완전히 반대되는 개념으로만 볼 수는 없다.

Model이 일부 Data를 Memorize하면서 동시에 다른 Pattern을 Generalize할 수도 있다.

102. SFT Epoch 수에 대한 주의

원자료는 SFT에서

\[\boxed{ 1\sim2\text{ epochs} }\]

를 권장한다고 적고 있다.

하지만 이것을 모든 Dataset과 Model에 적용되는 Universal Rule로 해석하면 안 된다.

적절한 Epoch 수는

  • Dataset Size
  • Learning Rate
  • Model Size
  • Data Diversity
  • Regularization
  • Objective

등에 따라 달라진다.

103. Validation이 중요한 이유

SFT에서도 고정된 Epoch 숫자보다

\[\boxed{ \text{validation loss} }\]

또는 Task-specific Validation Metric을 관찰하여 Overfitting 여부를 확인하는 것이 더 직접적이다.

104. Alignment와 Generalization

Alignment Training에서도 Training Preference Data에만 특화된 Model이 Deployment Prompt 전체에 잘 일반화하는지는 별개의 문제다.

즉

\[\boxed{ \text{alignment training fit} \neq \text{universal alignment generalization} }\]

105. Bias–Variance와 Deep Learning

Classical Bias–Variance Decomposition은 Deep Learning에서도 중요한 직관을 제공한다.

하지만 매우 큰 Neural Network의 Generalization Behavior 전체를

\[\boxed{ \text{bias down, variance up} }\]

라는 단순한 한 방향 Trade-off만으로 완전히 설명할 수 있는 것은 아니다.

106. 핵심 식 — Training Error

\[\boxed{ \mathcal R_{\mathrm{emp}}(f) = \frac1N \sum_{i=1}^{N} \mathcal L( f(\mathbf x_i),y_i ) }\]

107. 핵심 식 — Generalization Error

\[\boxed{ \mathcal R(f) = \mathbb E_P [ \mathcal L( f(\mathbf x),y ) ] }\]

108. 핵심 식 — Generalization Gap

\[\boxed{ \operatorname{Gap}(f) = \mathcal R(f) - \mathcal R_{\mathrm{emp}}(f) }\]

109. 핵심 식 — Data Model

\[\boxed{ y = f(\mathbf x) + \epsilon }\]
\[\boxed{ \mathbb E[\epsilon]=0 }\]
\[\boxed{ \operatorname{Var}(\epsilon) = \sigma^2 }\]

110. 핵심 식 — Bias

\[\boxed{ \operatorname{Bias} ( \hat f(\mathbf x) ) = \mathbb E_{\mathcal D} [ \hat f(\mathbf x) ] - f(\mathbf x) }\]

111. 핵심 식 — Variance

\[\boxed{ \operatorname{Var} ( \hat f(\mathbf x) ) = \mathbb E_{\mathcal D} \left[ \left( \hat f(\mathbf x) - \mathbb E_{\mathcal D}[ \hat f(\mathbf x) ] \right)^2 \right] }\]

112. 핵심 식 — Bias–Variance Decomposition

\[\boxed{ \mathbb E_{\mathcal D,\epsilon} [ ( y-\hat f(\mathbf x) )^2 ] = \operatorname{Bias}^2 + \operatorname{Variance} + \sigma^2 }\]

113. 혼동하기 쉬운 부분 — Training Error

Training Error가 낮다고 해서 Model이 좋은 것은 아니다.

중요한 것은

\[\boxed{ \mathcal R(f) }\]

즉 새로운 Data에 대한 Expected Error다.

114. 혼동하기 쉬운 부분 — Generalization Gap

Generalization Gap이 작더라도 두 Error가 모두 매우 클 수 있다.

예를 들어

\[\mathcal R_{\mathrm{emp}} = 10\]

이고

\[\mathcal R = 10.1\]

이면 Gap은 작지만 Model 자체의 Error는 크다.

따라서 Gap만으로 Model 품질 전체를 판단하지 않는다.

115. 혼동하기 쉬운 부분 — Underfitting

Underfitting은 단순히 Training Error가 0이 아니라는 뜻이 아니다.

Model이 표현해야 하는 Pattern에 비해 Function Class나 학습 상태가 충분하지 않아 Training과 Generalization Performance 모두 좋지 않은 상황을 의미한다.

116. 혼동하기 쉬운 부분 — Overfitting

Overfitting은 반드시

\[\mathcal R_{\mathrm{emp}}=0\]

이어야 하는 것은 아니다.

핵심은 Training Performance에 비해 Out-of-Sample Performance가 불필요하게 악화되는 것이다.

117. 혼동하기 쉬운 부분 — High Variance

High Variance는 단일 학습된 Model의 Output이 시간에 따라 Random하게 흔들린다는 뜻이 아니다.

서로 다른 Training Dataset을 사용했을 때 학습 결과가 얼마나 달라지는지를 나타내는 통계적 Quantity다.

118. 혼동하기 쉬운 부분 — Bias

Bias는 단일 Prediction Error와 동일하지 않다.

\[\boxed{ \operatorname{Bias} = \mathbb E_{\mathcal D}[\hat f]-f }\]

이므로 여러 가능한 Training Dataset에 대한 평균 Predictor가 필요하다.

119. 혼동하기 쉬운 부분 — Irreducible Error

\[\sigma^2\]

는 현재 Data Generating Assumption에서 Target Noise가 갖는 Variance다.

Model을 더 복잡하게 만든다고 제거되는 항이 아니다.

120. 혼동하기 쉬운 부분 — Bias–Variance Formula

\[\boxed{ \operatorname{Bias}^2 + \operatorname{Variance} + \sigma^2 }\]

는 원자료의 Squared Error Regression Setting에서 유도한 식이다.

Cross-Entropy와 같은 다른 Loss에서도 동일한 대수식이 자동으로 성립한다고 가정하지 않는다.

121. 혼동하기 쉬운 부분 — Capacity

Capacity가 크면 무조건 Overfitting하고 Capacity가 작으면 무조건 Generalization이 좋다는 뜻이 아니다.

Modern Deep Learning에서는 매우 큰 Model이 우수한 Generalization을 보이는 경우가 있다.

122. 혼동하기 쉬운 부분 — Double Descent

Double Descent는 Classical Bias–Variance Trade-off를 완전히 무효화한다는 의미가 아니다.

Model Complexity와 Generalization의 관계가 단순 U-curve보다 복잡할 수 있음을 보여주는 현상으로 이해한다.

123. 혼동하기 쉬운 부분 — Regularization

Weight Decay, Dropout, Early Stopping은 Generalization을 개선하기 위한 대표적인 Mechanism이지만

\[\boxed{ \text{regularization} \Rightarrow \text{always lower test error} }\]

라는 보장은 없다.

Regularization Strength 역시 조절해야 한다.

124. 혼동하기 쉬운 부분 — SFT Epoch

\[1\sim2\]

Epoch은 원자료에서 제시한 실전적 권장 범위이지, 모든 SFT 설정의 수학적 최적값은 아니다.

Validation Signal과 Dataset 규모를 함께 봐야 한다.

125. ML-01과 전체 연결

ML-01의 핵심은

\[\boxed{ \text{Empirical Risk} \rightarrow \text{ERM} }\]

이었다.

ML-03에서는

\[\boxed{ \text{ERM} \rightarrow \text{Generalization Gap} \rightarrow \text{Underfitting / Overfitting} }\]

으로 확장된다.

126. Statistical Learning 전체 흐름

관측된 Dataset에서

\[\boxed{ \mathcal R_{\mathrm{emp}} }\]

를 최소화한다.

하지만 실제 관심 대상은

\[\boxed{ \mathcal R }\]

따라서 Machine Learning의 핵심 문제는

\[\boxed{ \text{training fit} \rightarrow \text{generalization} }\]

이라고 볼 수 있다.

127. Bias–Variance 연결

Squared Error Setting에서는 Expected Prediction Error를

\[\boxed{ \text{systematic error} + \text{dataset sensitivity} + \text{noise} }\]

로 나눌 수 있다.

즉

\[\boxed{ \operatorname{Bias}^2 + \operatorname{Variance} + \sigma^2 }\]

128. Deep Learning 연결

Classical Statistics에서는 Capacity를 늘리면 Variance가 커지는 그림이 중요하다.

Modern Deep Learning에서는 Overparameterization, Implicit Regularization, Optimization Dynamics 등 때문에 더 복잡한 Generalization Behavior가 나타날 수 있다.

따라서

\[\boxed{ \text{Classical Bias–Variance} \rightarrow \text{Modern Generalization} }\]

로 개념이 확장된다.

129. LLM 연결

LLM에서도 Training Loss와 Deployment Performance는 동일한 개념이 아니다.

\[\boxed{ \text{Pre-training / SFT Loss} \neq \text{all downstream generalization} }\]

따라서

\[\boxed{ \text{Training Objective} \rightarrow \text{Validation} \rightarrow \text{Generalization} }\]

의 구분이 중요하다.

130. 정리

Machine Learning에서 Training Error는 관측된 Dataset 위의 평균 Loss다.

\[\boxed{ \mathcal R_{\mathrm{emp}}(f) = \frac1N \sum_i \mathcal L( f(\mathbf x_i),y_i ) }\]

Generalization Error 또는 True Risk는 실제 Data Distribution에서 새로운 Sample에 대해 기대되는 Loss다.

\[\boxed{ \mathcal R(f) = \mathbb E_P[ \mathcal L( f(\mathbf x),y ) ] }\]

두 값의 차이는

\[\boxed{ \operatorname{Gap}(f) = \mathcal R(f) - \mathcal R_{\mathrm{emp}}(f) }\]

Underfitting에서는 Model이 Data의 구조를 충분히 표현하지 못하여 Training Error와 Generalization Error가 모두 높을 수 있으며 원자료는 이를 High Bias와 연결한다.

Overfitting에서는 Training Data에는 매우 잘 맞지만 새로운 Data의 Error가 상대적으로 커지며, 원자료는 이를 High Variance와 연결한다.

Squared Error Regression에서

\[\boxed{ y = f(\mathbf x)+\epsilon }\]
\[\boxed{ \mathbb E[\epsilon]=0, \qquad \operatorname{Var}(\epsilon)=\sigma^2 }\]

라고 하자.

Dataset \(\mathcal D\)에 따라 학습되는 Predictor를

\[\hat f(\mathbf x;\mathcal D)\]

라고 하면

\[\boxed{ \bar f(\mathbf x) = \mathbb E_{\mathcal D} [ \hat f(\mathbf x) ] }\]

Prediction Error에 \(\bar f(\mathbf x)\)를 더하고 빼면

\[y-\hat f = (f-\bar f) + (\bar f-\hat f) + \epsilon\]

으로 분해할 수 있다.

이를 제곱하고 Expectation을 취하면 Cross Term이 0이 되어

\[\boxed{ \mathbb E_{\mathcal D,\epsilon} [ ( y-\hat f(\mathbf x) )^2 ] = \operatorname{Bias}^2 + \operatorname{Variance} + \sigma^2 }\]

를 얻는다.

여기서

\[\boxed{ \operatorname{Bias} = \mathbb E_{\mathcal D}[\hat f] - f }\]

이고

\[\boxed{ \operatorname{Variance} = \mathbb E_{\mathcal D} [ ( \hat f - \mathbb E_{\mathcal D}[\hat f] )^2 ] }\]

원자료의 수치 예제에서는

\[f(3)=6\]

이고

\[\sigma^2=0.5\]

Model \(M_1\)은

\[\boxed{ \operatorname{Bias}^2 = 2.25 }\]
\[\boxed{ \operatorname{Variance} = 0.2 }\]

이므로

\[\boxed{ \operatorname{EPE} = 3.05 }\]

Model \(M_2\)는

\[\boxed{ \operatorname{Bias}^2 = 0.01 }\]
\[\boxed{ \operatorname{Variance} = 2.5 }\]

이므로

\[\boxed{ \operatorname{EPE} = 3.01 }\]

따라서 \(M_1\)은 High-Bias/Low-Variance, \(M_2\)는 Low-Bias/High-Variance의 대비를 보여준다.

Classical Statistical Learning에서는 이를 Model Complexity와 Test Error 사이의 Trade-off와 연결한다.

하지만 Modern Deep Learning에서는 단순한 U-shaped Curve뿐 아니라

\[\boxed{ \text{Double Descent} }\]

같은 현상도 관찰될 수 있다.

따라서

\[\boxed{ \text{more parameters} \Rightarrow \text{necessarily worse generalization} }\]

이라고 단정할 수 없다.

원자료는 Generalization Control Mechanism으로

\[\boxed{ \text{Weight Decay} }\]
\[\boxed{ \text{Dropout} }\]
\[\boxed{ \text{Early Stopping} }\]

을 제시한다.

LLM SFT와 Alignment에서도 작은 Dataset에 지나치게 오래 Fit하면 Memorization 및 Overfitting이 발생할 수 있다는 점을 고려해야 한다.

다만 원자료의

\[\boxed{ 1\sim2\text{ epochs} }\]

는 모든 SFT에 적용되는 Universal Rule이라기보다 설정에 따라 조정해야 하는 경험적 권장으로 해석한다.

전체 개념 흐름은

\[\boxed{ \text{Training Error} \rightarrow \text{Generalization Error} \rightarrow \text{Generalization Gap} }\]

에서 시작한다.

Classical Analysis에서는

\[\boxed{ \text{Model Capacity} \rightarrow \text{Bias–Variance Trade-off} \rightarrow \text{Underfitting / Overfitting} }\]

으로 연결된다.

Modern Deep Learning에서는

\[\boxed{ \text{Overparameterization} \rightarrow \text{Regularization / Optimization Dynamics} \rightarrow \text{Generalization} }\]

이라는 더 복잡한 문제로 확장된다.

LLM 관점에서는

\[\boxed{ \text{Pre-training / SFT Loss} \rightarrow \text{Validation} \rightarrow \text{Generalization} \rightarrow \text{Deployment Performance} }\]

라는 흐름으로 연결된다.
