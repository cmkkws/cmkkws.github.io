운영 기준 (지정일: 2026-11-02)

  • 논문을 읽으며 지정한 확인 항목을 누적 관리하며, 추가 항목은 지정 시 반영한다.
  • 작성 5원칙
    1. 연구 질문·기여 통합: 별도 절로 분리하지 않고 앞쪽 논문 설명 한 줄에 통합한다.
    2. 성능 요인 제한 기재: 해당 요인의 효과를 분리 확인한 실험(ablation 등)이 있을 때만 결과에 짧게 통합한다.
    3. 하단 고정 항목: 각 논문 검토 맨 아래에 한계·후속 연구 질문 한 줄과 자료·코드 링크 한 줄을 배치한다.
    4. 연구 연계 미기재: 본 연구와의 연계성은 별도 항목으로 작성하지 않는다.
    5. 근거·구현 구분: 저자 제시 실제 사례와 설명용 도식을 구분하고, 논문 본문 서술과 공개 코드 구현을 대조하여 기록한다.

Part 2. 검토 사례 요약 — Yun 등(2024)

0. 한눈에 보는 논문 요약

  • 대상 논문: Automatically Extracting Numerical Results from Randomized Controlled Trials with Large Language Models (Yun 등, 2024; MLCB / PMLR 252)
  • 논문 설명: LLM이 메타분석용 임상 수치를 정확히 추출할 수 있는지 검증하기 위해 임상논문 120편·699문항의 정답 자료를 구축하고, 8개 모델의 추출 성능·오류 유형·통계적 영향을 비교한 연구.
  • 결과: GPT-4의 문항 전체 값 일치율이 이분형 65.5%·연속형 48.7%로 가장 높았으며, 다른 치료군·시점의 수치를 선택하거나 추출 가능한 값을 unknown(x)으로 출력하는 오류가 관찰됨.
  • 한계: 소규모·제로샷 평가이며, 모델별 문맥 한도·입력 전처리·생성 설정 차이와 제한적인 프롬프트 탐색으로 인해 순수 모델 성능과 프롬프트·전처리 효과를 분리해 판단하기 어려움.

  • 사례 1 — 결과 유형 분류 (부록 Table 6)

    • 입출력: 입력 survival → 저자 정답 continuous / GPT-4 출력 binary
    • 핵심 해석: 생존 여부(이분형)와 생존 기간(연속형)처럼 지표명만으로 모호할 때 오분류가 발생함 (survival이라는 명칭 자체만으로는 단정 불가).

  • 사례 2 — 이분형 수치 추출: 비율·건수 혼동 및 표본 수 누락 (부록 Figure 6)

    • 문항 맥락: 아미포스틴 사용 여부에 따른 중증 구내염 (원문 발췌: 총 환자 40명, 사용군 발생률 0%, 대조군 25%)
    • 채점·오류: 4개 중 1개 일치(전체 일치 실패, 1개 이상 부분 일치 통과). 대조군 발생 비율 25%를 사건 수 25명으로 오추출하고, 군별 표본 수에는 x(unknown)를 출력함.
    • 검수 유의사항: 저자 정답은 군별 20명으로 기재되어 있으나, 발췌문 내 총인원(40명)만으로는 균등 배정을 단정할 수 없으므로 데이터 구축 시 원문의 군별 배정 근거를 직접 확인해야 함.
  • 사례 3 — 연속형 수치 추출: 치료 전·후 시점 귀속 오류 (부록 Figure 7)
    • 문항 맥락: 일상생활 수행능력의 치료 결과 추출 (입력 발췌 표에는 치료 전 기초값만 제시)
    • 채점·오류: 6개 중 2개 일치(전체 일치 실패). 프롬프트에 치료 후 값을 선택하라는 지시가 있음에도 원문의 치료 전 기초값을 치료 결과로 잘못 연결한 시점 귀속 오류에 해당함(원문에 없는 수치를 생성한 환각과 구분).

Part 3. 검토 사례 요약 — Pronesti 등(2025, URCA)

0. 한눈에 보는 논문 요약

  • 대상 논문: Query-driven Document-level Scientific Evidence Extraction from Biomedical Studies (Pronesti·Bettencourt-Silva 등, 2025; ACL, 28034–28051쪽)
  • 논문 설명: 상반된 임상 근거가 섞인 문헌들에서 연구별 결론을 정확히 판정할 수 있는지 검증하기 위해 CochraneForest(923문항)를 구축하고, 논문별 균등 검색과 질의 중심 군집화를 결합한 URCA를 비교한 연구.
  • 결과: Mistral-Large 기반 URCA의 결론 분류 F1은 67.3%였으며, GPT-3.5에서는 GraphRAG(56.6%) 대비 5.8%p 높은 62.4%(상대 개선 10.3%)를 기록함.
  • 한계: 공개 전문이 확보된 연구와 상반된 결론이 포함된 forest plot으로 평가 대상이 제한되며, 정답 근거 구간(span) 주석이 없어 검색 누락과 추론 오류를 정량 분리하기 어려움.

    • 문항 맥락: 줄기세포 치료와 위약(placebo)의 누공 폐쇄 효과를 비교하는 질문.
    • 채점·오류: 군집화를 제외한 비교 방식이 동일 논문 내 다른 지표(CDAI·PDAI)의 비유의성 문구를 근거로 채택해 목표 결과도 유의한 차이가 없다고 오판함.
    • 핵심 해석: 동일 연구 내 문장이라도 질문이 요구하는 목표 결과 지표와 연결된 근거인지 구분해야 함.
  • 사례 2 — 질의 중심 군집화를 통한 결과 지표 분리
    • 입출력: 누공 폐쇄율, 폐쇄까지의 시간, 기타 임상 지표를 다루는 검색 청크들을 의미 군집별로 묶은 뒤 질문 관련 근거만 추출함.
    • 핵심 해석: 복수 결과 지표가 혼재된 논문에서 질의 중심 군집화가 지표 간 혼동을 줄이는 과정을 보여줌.

Part 4. 검토 사례 요약 — Wang 등(2025, TrialMind)

0. 한눈에 보는 논문 요약

    • 채점·오류: 인간 단독 검토에서 누락되기 쉬운 종단 소견을 AI가 원문 근거 문구와 함께 제시하여, 초기 인간 판정과 AI 출력이 불일치한 사례 중 **77.78%**에서 AI 추출이 타당했던 것으로 재검토됨(77.78%는 불일치 표본 내 조건부 비율).

2.3 원문 확인 프롬프트 및 추론 구조

  • 확인 기준: 본문 4~5쪽의 RAG·few-shot·Structured Outputs 및 다중 후보 선택 설명 기준 (보충자료 내 상세 프롬프트 전문·휴리스틱 코드는 추가 확인 필요).
  • 프롬프트 공통 규칙 요약
    1. 환자 기록에서 FAISS 벡터 검색으로 가져온 관련 청크를 목표 변수 추출 지시문 및 소수의 입출력 예시(few-shot)와 결합함.
    2. 변수별 JSON Schema(Structured Outputs)를 적용해 값, 날짜, 원문 인용구, 문서 위치를 출력하도록 강제함.
    3. 요청당 5개 후보(n=5)를 생성해 근거 중첩도·신뢰도 기준으로 최적 후보를 선택하고, 시계열 검사값·합병증은 다회 호출 결과를 누적해 목표 시점 기준으로 후처리함.
