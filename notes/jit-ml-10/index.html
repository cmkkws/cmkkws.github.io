ML-10 — Ensemble Methods: Bagging, Boosting & Gradient Trees

Bagging과 Boosting이 여러 모델의 예측을 결합하는 원리를 다룬다.

개념

학습 목표 — 여러 예측기를 평균하거나 순차적으로 더하는 앙상블의 목적을 구분한다. Bagging의 분산 공식에 필요한 공분산 가정, AdaBoost의 지수 손실 유도, Gradient Boosting과 XGBoost식 리프·분할 이득을 단계별로 확인한다. 원자료의 세 관측 회귀 예제를 학습 데이터 손실과 규제 목적 모두로 검산한다.

앙상블의 기본 아이디어 — 입력 \(x\)에 대한 기반 예측기 \(f_1(x),\ldots,f_M(x)\)의 출력을 결합한다. 회귀에서는 평균이 대표적이고 분류에서는 확률 평균, 점수 합, 다수결 등이 가능하다. 결합의 결과가 단일 모델보다 항상 정확하다는 수학적 보장은 없다.

약한 학습기의 의미 — 원자료의 “약한 학습기를 모아 강한 학습기를 만든다”는 동기다. AdaBoost의 약한 학습 조건은 각 가중 분포에서 오차가 무작위 추측보다 낮은 분류기를 얻을 수 있느냐에 관한 조건이며 모든 앙상블 기법이 약한 모델만 사용해야 한다는 정의는 아니다.

Bias와 variance의 기준 — ML-02의 제곱손실 분해는 주어진 데이터 생성 과정과 학습 알고리즘의 무작위성에 대한 기대를 전제로 한다. “Bagging은 오직 variance, Boosting은 오직 bias”라는 구분은 학습 알고리즘의 경향을 설명하는 단순화이며 일반 정리가 아니다.

표기·차원

가중 합의 표기 —

\[F_M(x)=\sum_{m=1}^{M}\alpha_m f_m(x).\]

\(\alpha_m\)의 부호와 합에 아무 제약이 없다면 이는 일반적인 가중 합이다. 확률의 가중 평균으로 쓰려면 각 \(f_m\)이 같은 사건에 대한 확률이어야 하고 \(\alpha_m\ge0\), \(\sum_m\alpha_m=1\)을 요구한다.

회귀 평균과 분류 결정 — 회귀의 단순 평균은 \(\hat F_{\rm avg}(x)=M^{-1}\sum_m f_m(x)\)다. 분류 점수를 합친 뒤 \(\operatorname{sign}\)을 적용하는 AdaBoost와 각 모델의 class probability를 평균하는 방법은 서로 다른 연산이다.

핵심 연산

Bagging의 재표본화 — 훈련 데이터 \(\mathcal D=\{(x_i,y_i)\}_{i=1}^N\)에서 각각 크기 \(N\)인 bootstrap 표본 \(\mathcal D_m\)을 복원 추출하고, 동일한 학습 절차로 \(f_m\)을 만든다. 표본에는 어떤 원 관측이 여러 번 들어가고 다른 관측은 빠질 수 있다.

Bagging의 출력 —

\[\hat F_{\rm bag}(x)=\frac1M\sum_{m=1}^{M}f_m(x).\]

분류에서 각 \(f_m\)이 hard label이면 다수결에 연결되고, class probability를 내면 먼저 확률을 평균할 수 있다. 두 결합은 모든 입력에서 같은 결정을 낸다고 보장되지 않는다.

Bootstrap 표본과 예측기의 독립성 — 재표본화의 무작위 seed를 각각 독립적으로 뽑을 수 있어도 모델들이 원래의 같은 관측 데이터 \(\mathcal D\)를 공유한다. 특히 훈련 데이터의 무작위성까지 포함하는 분산에서는 예측값이 일반적으로 서로 독립이지 않다.

한 점에서의 분산 분석 — 고정된 test 입력 \(x\)에서 학습된 각 예측을 확률변수 \(Z_m=f_m(x)\)로 둔다. 랜덤성의 원천을 훈련 표본, bootstrap, 알고리즘 seed 중 무엇으로 정하는지 먼저 결정해야 분산과 공분산이 의미를 갖는다.

평균 분산의 일반식 —

\[\operatorname{Var}\!\left(\frac1M\sum_m Z_m\right) =\frac1{M^2} \left[\sum_m\operatorname{Var}(Z_m) +2\sum_{m<j}\operatorname{Cov}(Z_m,Z_j)\right].\]

원자료의 \(\sum_{m\ne j}\operatorname{Cov}\) 표기와 정확히 같다. 공분산 항을 그냥 제거하려면 독립성보다 약한 pairwise uncorrelated 조건이 필요하다.

동일 분산과 공통 상관 — 모든 \(\operatorname{Var}(Z_m)=\sigma^2>0\)이고 모든 서로 다른 쌍의 \(\operatorname{Corr}(Z_m,Z_j)=\rho\)이면 각 off-diagonal 공분산이 \(\rho\sigma^2\)다. 실제 random forest에서 모든 쌍의 상관이 정확히 같을 필요는 없으며 아래 식은 이상화된 경우다.

Bagging 분산 공식 유도 —

\[\begin{aligned} \operatorname{Var}(\bar Z) &=\frac{M\sigma^2+M(M-1)\rho\sigma^2}{M^2}\\ &=\sigma^2\left[\rho+\frac{1-\rho}{M}\right]. \end{aligned}\]

원자료의 대수는 가정 아래 정확하다.

독립 예측기와 완전 상관의 경계 — \(\rho=0\)이면 분산은 \(\sigma^2/M\)이다. \(\rho=1\)이면 분산은 \(\sigma^2\)로 남는다. 평균이 큰 효과를 내려면 각 예측기의 오차가 충분히 다르고 개별 오차도 너무 크지 않아야 한다.

음의 상관도 가능 — \(M\)개 동일 분산 확률변수의 공통 상관계수는 Gram 공분산이 PSD가 되려면

\[-\frac1{M-1}\le\rho\le1\]

일 수 있다. 원자료의 \(\rho\in[0,1]\)은 흔한 상황의 제한이지 상관계수의 일반 정의역이 아니다. 음의 상관이 있으면 평균 분산이 더 작아질 수 있다.

Boosting의 순차 결합 — Boosting은 이전 결합 모델 \(F_{m-1}\)을 보고 새 학습기를 선택한다. \(F_m(x)=F_{m-1}(x)+\eta_m f_m(x).\) 이는 독립된 bootstrap 예측기의 단순 평균과 다른 학습 의존성이다.

잔차와 pseudo-residual — 제곱손실 \(L(y,F)=\tfrac12(y-F)^2\)의 음의 출력 gradient는 \(y-F\)로 관측 잔차다. 일반 손실에서는 \(-\partial L/\partial F\)가 pseudo-residual이다. Boosting이 모든 손실에서 원래의 \(y-F\)를 맞춘다는 식으로 일반화하지 않는다.

Boosting과 과적합 — 각 단계의 training objective를 줄여도 population risk가 반드시 개선되지는 않는다. 트리 크기, 학습률, iteration 수, 데이터 noise, regularization, early stopping을 함께 고려한다.

AdaBoost의 분류 조건 — 이진 라벨 \(y_i\in\{-1,+1\}\), 기반 분류기 \(h_m(x)\in\{-1,+1\}\)를 사용한다. 점수는 \(F_m(x)=F_{m-1}(x)+\alpha_m h_m(x)\) 이고 최종 label은 \(\operatorname{sign}F_M(x)\)다.

정규화 인자 —

\[Z_m=(1-\epsilon_m)e^{-\alpha_m} +\epsilon_m e^{\alpha_m} =2\sqrt{\epsilon_m(1-\epsilon_m)}.\]

\(0<\epsilon_m<1/2\)이면 \(Z_m<1\)이다. 지수 손실의 훈련상 감소와 0–1 test error의 단조 감소를 혼동하지 않는다.

AdaBoost와 generic Gradient Boosting — AdaBoost는 ±1 분류기, 재가중, 지수 손실이라는 특정 구성이다. Gradient Boosting은 선택한 미분 가능 손실의 출력 공간 gradient 방향에 약한 학습기를 적합시키는 더 넓은 틀이다. 모든 boosting 구현이 AdaBoost의 \(\alpha\) 공식을 쓰지는 않는다.

Gradient Boosting의 초기값 — 상수 초기 예측은 보통

\[F_0\in\arg\min_c\sum_iL(y_i,c)\]

로 선택할 수 있다. 제곱손실에서는 표본평균, 이진 log-loss에서는 라벨 평균에 해당하는 log-odds가 되는 등 손실마다 다르다.

핵심 식 — Bagging과 AdaBoost —

\[\begin{aligned} \operatorname{Var}(\bar Z) &=\sigma^2\left(\rho+\frac{1-\rho}{M}\right) \quad\text{(동일 분산·공통 상관)},\\ \epsilon_m &=\frac{\sum_iw_i^{(m)} \mathbf1\{y_i\ne h_m(x_i)\}}{\sum_iw_i^{(m)}},\\ \alpha_m&=\frac12\log\frac{1-\epsilon_m}{\epsilon_m},\\ w_i^{(m+1)} &=w_i^{(m)}e^{-\alpha_m y_ih_m(x_i)}. \end{aligned}\]

핵심 식 — Gradient tree —

\[\begin{aligned} G_j&=\sum_{i\in I_j}g_i,\quad H_j=\sum_{i\in I_j}h_i,\quad v_j^*=-\frac{G_j}{H_j+\lambda},\\ \operatorname{Gain} &=\frac12\left[ \frac{G_L^2}{H_L+\lambda} +\frac{G_R^2}{H_R+\lambda} -\frac{(G_L+G_R)^2}{H_L+H_R+\lambda} \right]-\gamma. \end{aligned}\]

성질·유도

\(M\to\infty\)의 조건 — 고정된 비음수 \(\rho\)가 유지되는 교환가능한 이상화에서 분산은 \(\rho\sigma^2\)로 간다. 유한 \(M\)의 음의 하한 \(-1/(M-1)\)은 \(M\)과 함께 변하므로 고정된 음의 \(\rho\)를 모든 \(M\)에 적용해 음의 극한 분산을 주장할 수 없다.

서로 다른 분산의 경우 — 예측기별 분산 또는 쌍별 공분산이 다르면 §11의 일반식으로 돌아가야 한다. 크게 상관된 불량 예측기를 더 포함하면 정확도가 낮아질 수도 있다. 분산 감소는 bias나 label noise의 제거와 동일하지 않다.

Bagging과 불안정한 학습기 — 훈련 자료의 작은 변화에 민감한 깊은 결정트리는 bootstrap 평균의 이득을 얻기 쉽다. 매우 안정한 학습기를 반복 학습하면 예측들이 비슷해져 평균 이득이 작을 수 있다. 이 판단도 데이터 분포와 기준 손실에 의존한다.

Random Forest의 feature subspacing — Random Forest는 bootstrap 및 노드별 후보 feature 일부를 무작위로 고려하는 설계를 결합할 수 있다. 강한 feature에 모든 트리가 의존하는 현상을 줄여 트리 사이의 유사성을 낮출 수 있으나, 항상 상관을 감소시키거나 test error를 개선한다는 보장은 없다.

Feature 무작위화의 교환 — 후보 feature 수를 줄이면 트리 사이의 상관이 낮아질 수 있지만 개별 트리의 분할 품질도 떨어질 수 있다. 따라서 §13의 \(\rho\)만 최소화하는 것이 목표가 아니라 평균의 총 예측 오차를 검증해야 한다.

Out-of-bag 관측 — 크기 \(N\)의 복원 표본 한 개에서 특정 원 관측이 한 번도 선택되지 않을 확률은

\[\left(1-\frac1N\right)^N\longrightarrow e^{-1}\approx0.3679.\]

해당 관측을 제외한 트리들의 예측을 모아 out-of-bag 평가를 만들 수 있다. 관측마다 제외 트리 수가 다르고, 모든 평가 상황에서 독립 test set을 대체하는 것은 아니다.

지수 손실 —

\[\mathcal L_{\exp}(F) =\sum_{i=1}^{N}\exp[-y_iF(x_i)].\]

분류가 틀리거나 signed margin \(y_iF(x_i)\)가 작으면 해당 항이 크다. 이 손실은 0–1 error의 상계를 제공하지만 시험 일반화 성능과 정확히 같은 목적은 아니다.

현재 샘플 가중치 — 단계 \(m\)에 앞서

\[w_i^{(m)}=\exp[-y_i F_{m-1}(x_i)]>0, \qquad W_m=\sum_i w_i^{(m)}.\]

\(F_0=0\)이면 처음에는 모든 가중치가 1이다. 필요하면 \(D_i^{(m)}=w_i^{(m)}/W_m\)로 확률분포로 정규화한다.

가중 오류율 — 현재 선택한 \(h_m\)에 대해

\[\epsilon_m=\sum_i D_i^{(m)}\mathbf1\{y_i\ne h_m(x_i)\} =\frac{\sum_{y_i\ne h_m(x_i)}w_i^{(m)}}{W_m}.\]

원자료의 가중 오류율이며 일반 unweighted training error와 다르다.

정확·오류 집합으로 분리 — \(y_ih_m(x_i)=+1\)이면 새 손실 인자는 \(e^{-\alpha_m}\), 틀리면 \(e^{+\alpha_m}\)다. 그래서

\[\mathcal L_{\exp}(F_{m-1}+\alpha_mh_m) =W_m[(1-\epsilon_m)e^{-\alpha_m} +\epsilon_m e^{\alpha_m}].\]

이 단계는 기반 분류기의 출력값이 정확히 \(\pm1\)이라는 조건을 사용한다.

계수의 미분 — \(0<\epsilon_m<1\)에서

\[\frac{\partial\mathcal L}{\partial\alpha_m} =W_m[-(1-\epsilon_m)e^{-\alpha_m} +\epsilon_m e^{\alpha_m}].\]

정상조건은 \(e^{2\alpha_m}=(1-\epsilon_m)/\epsilon_m\)이다.

AdaBoost 계수 —

\[\alpha_m=\frac12\log\frac{1-\epsilon_m}{\epsilon_m}.\]

두 번째 미분은 \(W_m[(1-\epsilon_m)e^{-\alpha_m}+\epsilon_m e^{\alpha_m}]>0\)이므로 \(0<\epsilon_m<1\)에서 유일한 최소다.

계수의 부호와 특이값 — \(0<\epsilon_m<1/2\)이면 \(\alpha_m>0\), \(\epsilon_m=1/2\)이면 \(\alpha_m=0\), \(\epsilon_m>1/2\)이면 음수다. 분류기 \(-h_m\)을 쓸 수 있으면 오류율을 \(1-\epsilon_m\)으로 뒤집을 수 있다. \(\epsilon_m=0\)이면 무제한 \(\alpha_m\to+\infty\)가 나오는 이상적 식이라 수치 구현에서는 종료 또는 clipping을 고려한다.

가중치 업데이트 —

\[w_i^{(m+1)} =w_i^{(m)}e^{-\alpha_m y_i h_m(x_i)}.\]

맞춘 관측은 \(e^{-\alpha_m}\), 틀린 관측은 \(e^{+\alpha_m}\)배로 변한다. 정규화 분포를 유지하려면 새 합으로 나눈다.

출력에 대한 미분 — 현재 예측 \(a_i=F_{m-1}(x_i)\)에서

\[g_i=\left.\frac{\partial L(y_i,z)}{\partial z}\right|_{z=a_i}, \qquad h_i=\left.\frac{\partial^2 L(y_i,z)}{\partial z^2}\right|_{z=a_i}.\]

신경망 전체 파라미터 gradient와 달리, 여기서는 표본별 스칼라 예측값에 관한 미분이다.

2차 Taylor 근사 — 새 트리 출력 \(\delta_i=f_m(x_i)\)가 작을 때

\[L(y_i,a_i+\delta_i) \approx L(y_i,a_i)+g_i\delta_i+\frac12h_i\delta_i^2.\]

제곱손실이면 2차식이므로 이 식은 정확하다. 일반 손실에서는 국소 근사이며 적절한 미분 가능성과 충분히 작은 이동이 중요하다.

XGBoost식 트리의 구조 — 트리의 leaf mapping \(q(x)\in\{1,\ldots,T\}\), 리프 출력 \(v_j\)를 두면 \(f_m(x)=v_{q(x)}\)다. 원자료의 \(w_j\)와 같은 값이지만 AdaBoost의 sample weight \(w_i^{(m)}\)와 혼동하지 않기 위해 \(v_j\)로 쓴다.

리프 규제 —

\[\Omega(f_m)=\gamma T+\frac{\lambda}{2}\sum_{j=1}^{T}v_j^2, \qquad \lambda\ge0,\ \gamma\ge0.\]

\(\gamma\)는 리프 수의 비용이며 ML-11의 기하 마진 \(\gamma\)와 전혀 다른 하이퍼파라미터다.

상수항을 제거한 목적 — 원자료의 \(\sum_iL(y_i,F_{m-1}(x_i))\)는 새 트리 구조·값에 무관하므로 후보 비교에서 제거한다.

\[\tilde{\mathcal O} =\sum_i\left[g_i f_m(x_i)+\frac12h_i f_m(x_i)^2\right] +\gamma T+\frac{\lambda}{2}\sum_jv_j^2.\]

리프별 충분통계 — \(I_j=\{i:q(x_i)=j\}\), \(G_j=\sum_{i\in I_j}g_i\), \(H_j=\sum_{i\in I_j}h_i\)로 두면

\[\tilde{\mathcal O} =\sum_{j=1}^{T} \left[G_jv_j+\frac12(H_j+\lambda)v_j^2\right]+\gamma T.\]

원자료의 각 관측 미분을 리프 단위 합으로 묶은 것이다.

최적 리프 출력의 조건 — \(H_j+\lambda>0\)이면 리프별 목적이 엄격 볼록이고

\[\frac{\partial\tilde{\mathcal O}}{\partial v_j} =G_j+(H_j+\lambda)v_j=0 \quad\Longrightarrow\quad v_j^*=-\frac{G_j}{H_j+\lambda}.\]

\(H_j+\lambda=0\)이면 이 나눗셈은 정의되지 않는다. 일반 비볼록 손실에서 \(H_j+\lambda<0\)이면 유한한 최소도 보장되지 않는다.

구조 점수 유도 — 완전제곱으로

\[G_jv_j+\frac12(H_j+\lambda)v_j^2 =\frac{H_j+\lambda}{2} \left(v_j+\frac{G_j}{H_j+\lambda}\right)^2 -\frac{G_j^2}{2(H_j+\lambda)}.\]

따라서 구조 \(q\)의 근사 최적 목적은

\[\tilde{\mathcal O}^{*}(q) =-\frac12\sum_j\frac{G_j^2}{H_j+\lambda}+\gamma T.\]

Split gain의 부호 — 기존 리프 \(I\)를 \(I_L,I_R\)로 바꾸면 리프 수가 하나 증가한다. “분할 전 최적 목적 − 분할 후 최적 목적”을 이득으로 정의하면

\[\operatorname{Gain} =\frac12\left[ \frac{G_L^2}{H_L+\lambda} +\frac{G_R^2}{H_R+\lambda} -\frac{(G_L+G_R)^2}{H_L+H_R+\lambda} \right]-\gamma.\]

식은 두 새 리프의 정규화 비용을 각각 포함한다.

분할을 채택하는 조건 — 모든 분모가 양수이고 구조 후보의 다른 제약이 없다면 양의 gain은 근사 목적을 줄인다. 실제 트리 구현에는 최소 리프 크기, 최소 Hessian 합, depth, feature 제약 등이 있을 수 있다. 양의 gain이라고 holdout 손실의 감소는 보장하지 않는다.

Shrinkage의 위치 — 리프 구조와 \(v_j^*\)를 고른 뒤 \(F_m=F_{m-1}+\eta f_m\)에 \(0<\eta\le1\)을 둘 수 있다. 위 score와 gain은 보통 완전 step의 최적 리프값을 기준으로 계산한다. \(\eta<1\)인 실제 step의 목적 감소량은 위 gain과 일반적으로 같지 않다.

오개념 교정 — 통계 — 상관계수는 반드시 \([0,1]\)이 아니고, bootstrap 모델은 훈련 데이터의 무작위성까지 볼 때 대체로 독립이 아니다. 낮은 pairwise 상관 하나만으로 ensemble test risk가 개선된다는 보장도 없다. Bagging과 boosting을 각각 순수 variance·bias 제거 정리로 읽지 않는다.

오개념 교정 — 최적화와 LLM — AdaBoost 계수 공식에는 이진 \(\pm1\) 기반 분류기와 \(0<\epsilon<1\)이 필요하다. XGBoost leaf 공식에는 \(H_j+\lambda>0\)이 필요하다. Split gain은 regularization을 포함한 한 단계 목적 차이이며 test gain이 아니다. LLM voting, MoA, MoE, dropout, residual network는 각각 명확히 구별한다.

Bagging은 복원 표본으로 학습한 모델을 평균하고, 효과는 예측기의 분산과 상관에 달려 있다. AdaBoost는 현재 오분류 가중치 아래의 지수 손실을 이용해 \(\alpha_m\)을 구한다. Gradient tree는 출력값에 대한 미분과 리프별 합으로 구조를 비교한다. 원자료의 예제에서 후보 B의 gain \(3.75\)와 leaf 출력 \((-1,1.5)\), 예측 \((3,3,5.5)\)는 맞다. 데이터 손실은 \(7\to1.625\), 리프 penalty는 \(1.625\)이므로 규제 목적의 개선 \(3.75\)와 데이터 손실의 개선 \(5.375\)를 나눠 읽는다.

예제·적용

예제의 차원과 입력 — 원자료의 “2차원 1차원 회귀” 표기는 정정한다. 입력 특징은 스칼라 \(x=1,2,3\), 목표 \(y=(2,3,7)\)인 1차원 입력 회귀다. 초기 \(F_0(x)=\bar y=4\), \(\lambda=1\), \(\gamma=0\), \(\eta=1\)이다.

초기 예측의 최적성 — 제곱손실에서 \(c\)를 일정한 출력으로 두면 \(\partial_c\sum_i(y_i-c)^2/2=\sum_i(c-y_i)=0\). 따라서 \(F_0=(2+3+7)/3=4\)가 원자료의 상수 최소제곱 초기값이다.

초기 손실 —

\[\mathcal L_0 =\frac12[(2-4)^2+(3-4)^2+(7-4)^2] =\frac12(4+1+9)=7.\]

이는 세 점의 합 손실이며 평균 손실은 \(7/3\)이다.

Gradient와 Hessian — \(L(y,z)=\tfrac12(y-z)^2\)에서는 \(g_i=z-y_i\), \(h_i=1\). \(z=4\)이므로

\[(g_1,g_2,g_3)=(2,1,-3),\qquad (h_1,h_2,h_3)=(1,1,1).\]

\(\sum_i g_i=0\)은 상수 초기값이 제곱손실 최적점인 것과 일치한다.

분할 전 단일 리프 — 전부 한 리프이면 \(G=2+1-3=0\), \(H=3\), \(v^*=0\), score는 0이다. 두 후보의 parent 항 \(G^2/(H+\lambda)\)도 0이다.

후보 A의 집합 — \(x<1.5\)이면 좌측 \(I_L=\{1\}\)에 \((G_L,H_L)=(2,1)\), 우측 \(I_R=\{2,3\}\)에 \((G_R,H_R)=(-2,2)\)다. 양쪽 분모는 각각 \(1+1=2\), \(2+1=3\)이다.

후보 A의 이득 —

\[\operatorname{Gain}_A =\frac12\left(\frac{2^2}{2}+\frac{(-2)^2}{3}\right) =\frac12\left(2+\frac43\right) =\frac53\approx1.6666667.\]

원자료의 \(1.6667\)과 같다.

후보 A의 리프값 검산 —

\[v_L^{(A)}=-\frac2{1+1}=-1,\qquad v_R^{(A)}=-\frac{-2}{2+1}=\frac23.\]

이 값을 대입한 정규화 예측은 \((3,\ 14/3,\ 14/3)\)이다. 뒤 두 점은 하나의 리프값을 공유하므로 동시에 개별 정답에 맞출 수 없다.

후보 B의 집합 — \(x<2.5\)이면 \(I_L=\{1,2\}\)에서 \((G_L,H_L)=(3,2)\), \(I_R=\{3\}\)에서 \((G_R,H_R)=(-3,1)\)이다.

후보 B의 이득 —

\[\operatorname{Gain}_B =\frac12\left(\frac{3^2}{2+1}+\frac{(-3)^2}{1+1}\right) =\frac12\left(3+\frac92\right) =\frac{15}{4}=3.75.\]

제시된 두 후보 중 \(B\)가 더 큰 훈련 근사 목적의 개선을 준다.

최적 분할의 범위 — 입력값이 정확히 \(1,2,3\)인 1차원 자료의 서로 다른 비자명한 이분할은 \(1.5\)와 \(2.5\) 사이 대표 임계값 두 개로 평가된다. 같은 partition을 내는 다른 threshold도 있다. “\(x<2.5\)가 유일한 실수 임계값”이라는 뜻은 아니다.

후보 B의 리프 출력 —

\[v_L^{(B)}=-\frac3{2+1}=-1,\qquad v_R^{(B)}=-\frac{-3}{1+1}=\frac32=1.5.\]

원자료의 두 값은 정확하다.

갱신 예측과 잔차 — \(\eta=1\)이므로

\[(F_1(1),F_1(2),F_1(3)) =(4-1,\ 4-1,\ 4+1.5) =(3,3,5.5).\]

목표 \(y=(2,3,7)\)에 대한 예측 − 목표 잔차는 \((1,0,-1.5)\)다. 첫째와 셋째가 초기보다 목표에 가까워지고 둘째는 정확히 일치한다.

새 데이터 손실 —

\[\mathcal L_{\rm data}(F_1) =\frac12[(3-2)^2+(3-3)^2+(5.5-7)^2] =\frac12(1+0+2.25) =\frac{13}{8}=1.625.\]

초기 \(7\)에서 데이터 손실만의 감소는 \(7-13/8=43/8=5.375\)다.

리프 규제를 포함한 손실 — 후보 B의 리프 norm penalty는

\[\frac{\lambda}{2}(v_L^2+v_R^2) =\frac12\left(1+\frac94\right) =\frac{13}{8}=1.625.\]

\(\gamma=0\)이므로 전체는 \(13/8+13/8=13/4=3.25\), 초기 7 대비 개선은 \(7-13/4=15/4=3.75\)다. 따라서 split gain \(3.75\)와 데이터 손실 감소 \(5.375\)는 서로 다른 양이다.

후보 A의 별도 손실 검산 — 후보 A의 예측 \((3,14/3,14/3)\)는 데이터 손실 \(83/18\approx4.6111\)과 리프 penalty \(13/18\approx0.7222\)를 준다. 합은 \(16/3\approx5.3333\)이고 처음 7과의 차이는 \(5/3\), 정확히 \(\operatorname{Gain}_A\)다.

이 예제에서 Taylor의 지위 — 제곱손실은 예측값에 대해 정확히 이차함수라 §38의 Taylor 전개에 버린 고차항이 없다. 따라서 \(\eta=1\)에서 계산한 gain과 정규화 훈련 목적 차이가 정확히 일치한다. 일반 손실과 \(\eta<1\)에서는 이 등식을 그대로 보장하지 않는다.

Bagging과 boosting의 비교 —

이 표는 목표와 분석 틀의 비교이며 어느 한쪽의 bias/variance 변화가 항상 한 방향이라는 정리는 아니다.

LLM voting과 앙상블 — 여러 LLM 답을 받아 일치도를 보거나 점수화해 선택할 수 있다. 서로 다른 모델을 그냥 호출하는 것은 원래 데이터의 bootstrap 재표본화를 쓰는 고전적 bagging과 동일하지 않다. 투표 규칙, 답 비교 가능성, 오류 상관을 명시해야 한다.

Mixture of Agents의 결합 — 서로 다른 agent가 응답을 제안하고 aggregator가 최종 응답을 만들면 stacking 또는 learned aggregation과 닮은 구조가 된다. 그러나 aggregator가 공통된 오류를 증폭하거나 잘못 요약할 수도 있어 정답률 향상을 보편적 결론으로 쓰지 않는다.

DL-13의 MoE와 구별 — MoE는 한 모델의 router가 token별로 일부 expert를 활성화하는 조건부 계산 구조다. 여러 독립 모델의 완성된 답을 모으는 voting·MoA와 계산 단위, 훈련 방식, 가중치 공유 여부가 다르다.

Dropout의 앙상블 직관 — 훈련 때 무작위 unit mask를 쓰면 같은 가중치를 공유하는 여러 subnet 구조를 보게 된다. 이를 암묵적 ensemble로 해석할 수 있으나 각 subnet을 독립 bootstrap 표본으로 따로 최적화하는 bagging과는 다르다.

Dropout scaling의 정확한 범위 — Inverted dropout은 유지확률 \(p\)일 때 훈련 활성화를 \(m a/p\)로 만들고 추론에는 보통 mask 없이 \(a\)를 쓴다. 다른 convention은 훈련에서 \(ma\), 추론에서 \(pa\)를 쓴다. 두 경우 선형 활성화의 기대 스케일은 맞지만 임의의 깊은 비선형 네트워크에서 추론 출력이 모든 subnet 출력의 정확한 기하 평균이라는 정리는 아니다.

Gradient Boosting과 residual network — 둘 다 이전 상태에 새 항을 더하는 표면적 수식 \(F_m=F_{m-1}+f_m\), \(h_{\ell+1}=h_\ell+\mathcal F_\ell(h_\ell)\)을 가진다. Residual network는 보통 모든 layer를 함께 end-to-end 학습한다. 출력 손실의 음의 functional gradient를 새 트리로 순차 적합하는 Gradient Boosting과 자동으로 동일하지 않다.

정형 데이터에 관한 경험적 비교 — 원자료의 XGBoost/LightGBM 대 Transformer 효율 비교는 데이터 크기, 누락값, 범주형 feature, tuning, 컴퓨팅 예산과 평가 지표를 정한 실험에서 판단한다. 모든 tabular 작업에서 한 계열의 성능과 연산 효율이 “월등”하다는 보편 법칙으로 쓰지 않는다.

Stacking을 사용할 때의 분리 — 기반 모델의 훈련 데이터 내 예측을 그대로 meta learner에 주면 누수가 생길 수 있다. Out-of-fold 예측이나 별도 validation을 사용해 meta learner의 입력을 구성한다. 이는 단순 bagging 평균보다 강한 결합을 학습할 때 필요한 검증 조건이다.

학습 점검 —

  1. \(\rho<0\)인 공통 상관을 임의로 큰 \(M\)에 고정할 수 없는 이유는?
  2. AdaBoost에서 \(\epsilon_m=0\), \(1/2\), \(>1/2\)일 때 계수는 어떻게 해석하는가?
  3. 예제 후보 B의 데이터 손실 감소가 gain보다 큰 이유는?
  4. Dropout과 bagging, residual network와 gradient boosting의 학습 절차는 각각 어떻게 다른가?

정리

Ensemble은 여러 예측기를 결합하며 bagging은 bootstrap 표본의 평균으로 분산을 줄이고 boosting은 이전 residual 또는 negative gradient를 따라 모델을 순차적으로 더한다. Gradient tree의 split gain은 손실 감소를 비교하는 기준이므로, 분할 제약과 regularization을 포함해 계산해야 한다.
