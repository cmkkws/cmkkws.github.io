한눈에 보는 결론

대형 언어 모델의 역사는 파라미터 수가 커진 기록만으로 설명되지 않는다. 2017년 Transformer가 병렬화 가능한 공통 골격을 만들었다면, 이후의 진전은 모델 용량, 데이터 배분, 인간 선호 정렬, 추론 시 계산량, 장기 기억, 도구 사용이라는 서로 다른 병목을 차례로 해결한 결과다.

최근의 frontier는 하나의 더 큰 Transformer가 아니라, 여러 종류의 계산과 기억을 필요한 순간에 조합하는 작업 수행형 AI 시스템에 가깝다.

따라서 이 글은 모델 이름을 연도순으로 나열하기보다, 각 기술이 어떤 병목을 해결했으며 다음 세대의 설계에 무엇을 남겼는지를 중심으로 계보를 재구성한다. 2026년 모델은 공개된 공식 자료만을 사례로 사용하고, 변동이 큰 단일 리더보드 순위는 핵심 근거에서 제외했다.

전체 계보: 병목은 어디로 이동했는가

2017–2022: 현대 LLM의 공통 기반

Transformer의 직접적인 기여는 recurrence를 제거하고 self-attention과 feed-forward network를 중심 연산으로 세운 것이다. 토큰을 순서대로 처리하던 병목을 줄이면서 대규모 병렬 학습이 쉬워졌고, encoder 중심의 BERT, decoder 중심의 GPT, encoder–decoder 구조의 T5가 같은 골격 위에서 갈라졌다.

\[\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V\]
\[p(x_{1:T})=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t}),\qquad \mathcal L_{\mathrm{NTP}}=-\sum_t\log p_\theta(x_t\mid x_{<t})\]

같은 2017년에 제안된 sparsely-gated Mixture-of-Experts는 모든 파라미터를 매 토큰마다 활성화하지 않고 일부 expert만 선택했다. 이 아이디어는 전체 모델 용량과 실제 토큰당 연산량을 분리했고, 이후 Switch Transformer와 여러 open-weight MoE 모델의 핵심 선조가 됐다.

\[y=\sum_{i\in\operatorname{TopK}(g(x))}p_i\,E_i(x)\]

Scaling Laws는 손실이 모델 크기, 데이터 크기, 학습 연산량에 대해 일정한 경향으로 감소함을 보였다. Chinchilla는 여기서 한 걸음 더 나아가, 고정된 연산 예산에서는 모델 크기와 학습 토큰을 함께 늘려야 한다는 경험적 기준을 제시했다. 이때부터 ‘더 큰 모델’보다 ‘같은 계산을 어떻게 배분했는가’가 중요한 비교 기준이 됐다.

2022–2024: 효율성과 긴 문맥

동일한 Attention을 더 싸게 계산하기

FlashAttention은 attention을 근사한 것이 아니라, 같은 scaled dot-product attention을 GPU 메모리 계층에 맞게 타일링했다. 핵심은 FLOPs만 세는 관점에서 벗어나 HBM과 SRAM 사이의 데이터 이동을 병목으로 다룬 점이다. 긴 context 경쟁은 알고리즘과 hardware co-design이 함께 움직여야 한다는 사실을 보여줬다.

Attention 밖의 선형 시간 계열 처리

Mamba는 입력에 따라 상태 전이를 조절하는 selective state space model과 hardware-aware scan을 결합했다. 시퀀스 길이에 따라 선형으로 확장되는 recurrent state를 사용하면서도 언어 모델링에서 경쟁력 있는 성능을 보였고, 이후 연구는 attention과 SSM을 서로 배타적인 선택이 아니라 섞을 수 있는 계산 블록으로 보기 시작했다.

\[h_t=A_t h_{t-1}+B_t x_t,\qquad y_t=C_t h_t\]

한 번에 다음 토큰보다 더 멀리 보기

Multi-Token Prediction은 하나의 hidden state에서 여러 미래 토큰을 보조 head로 함께 예측한다. 이는 학습 신호를 풍부하게 하고, 여러 후보를 한 번에 제안한 뒤 검증하는 speculative decoding 계열과 연결된다. 다만 학습 목적의 MTP와 실제 디코딩 가속 알고리즘은 구분해서 보아야 한다.

\[\mathcal L_{\mathrm{MTP}}=-\sum_t\sum_{k=1}^{K}\log p_{\theta,k}(x_{t+k}\mid h_t)\]

Reasoning: 학습 후 계산이 새로운 확장축이 되다

Instruction tuning과 RLHF가 ‘사용자 지시를 따르는 assistant’를 만들었다면, 2024년 이후의 핵심 질문은 고정된 모델이 추론 시 더 많은 후보를 만들고 검증하면 얼마나 좋아지는가였다. Test-time compute 연구는 문제 난이도에 따라 sampling, search, verifier 호출에 예산을 배분하는 것이 단순한 모델 크기 증가보다 효율적일 수 있음을 보였다.

\[\hat y=\arg\max_{y_i\sim\pi_\theta(\cdot\mid x)}V(x,y_i)\]

DeepSeek-R1의 중요한 결과는 R1-Zero에서 사전 SFT 없이도 검증 가능한 reward를 이용한 대규모 강화학습으로 self-verification과 reflection에 가까운 행동이 나타났다는 점이다. 실제 R1은 가독성과 언어 혼합 문제를 줄이기 위해 cold-start SFT와 다단계 학습을 다시 더했다. 즉 ‘SFT가 필요 없다’가 아니라, reasoning 행동의 일부가 정답 검증만으로도 강화될 수 있음을 보여준 사례로 읽는 편이 정확하다.

Memory: 긴 Context와 기억은 다르다

Context window는 현재 요청에서 모델이 직접 참조할 수 있는 입력 범위다. 이를 길게 만드는 일은 유용하지만, 매번 모든 기록을 다시 넣는 방식은 KV cache와 attention 비용을 키운다. 장기 기억은 무엇을 저장하고, 언제 불러오며, 언제 잊을지를 결정하는 별도의 시스템 문제다.

Titans는 attention을 정확하지만 유한한 short-term memory로 보고, inference 중 별도의 neural memory를 갱신해 오래된 정보를 압축한다. Gated Attention은 softmax attention 출력에 query-dependent gate를 더해 attention sink를 줄이는 구조 개선이다. Titans가 먼저 공개되었으므로 두 연구는 ‘Gated Attention 다음에 Titans’라는 직선 계보가 아니라, memory와 attention 안정성을 각각 다룬 병렬 발전축이다.

\[\ell_t=\left\|\mathcal M_{t-1}(k_t)-v_t\right\|_2^2\]

2026 Frontier: 모델에서 작업 수행 시스템으로

2026년의 공개 자료에서 공통적으로 강조되는 것은 단발성 문답보다 장기 작업 완수다. 적응형 reasoning budget, native multimodality, 도구 사용, 실행 환경의 피드백, 여러 agent의 병렬 조율이 제품과 모델 카드의 중심 언어가 됐다. 이는 base model의 능력과 agent harness의 능력을 함께 평가해야 한다는 뜻이다.

이제 capability는 pretraining 하나의 함수가 아니라 post-training, 추론 예산, memory, tool, verifier, orchestration이 함께 만드는 시스템 속성이다.
\[\operatorname{Capability}=f(\text{pretraining},\text{post-training},\text{test-time compute},\text{memory},\text{tools},\text{agents})\]

평가: 점수보다 평가함수를 먼저 보라

고정된 시험 문제가 웹에 오래 공개되면 학습 데이터에 포함될 수 있다. 이때 높은 점수는 일반화가 아니라 기억을 일부 반영할 수 있다. 반대로 실제 저장소 이슈를 해결하는 agent 평가는 모델 자체뿐 아니라 prompt, tool, scaffold, 시간 제한에 크게 좌우된다. 어떤 리더보드도 독립적인 ‘AI IQ’로 읽어서는 안 된다.

\[\boxed{\text{Evaluation}=\text{Capability}+\text{Preference}+\text{Task success}+\text{Cost}+\text{Latency}+\text{Contamination resistance}}\]
  • 모델 비교 시 benchmark 버전, 평가 날짜, sampling 설정, reasoning budget을 함께 기록한다.
  • Agent 평가에서는 모델과 harness, 도구 권한, 시간 제한을 분리해 보고한다.
  • 제작사 자체 수치는 재현 조건과 함께 읽고, 독립 평가와 실제 업무 표본으로 교차 확인한다.
  • 평균 점수뿐 아니라 실패 유형, 비용, 지연, 재시도 후 복구 능력을 남긴다.

핵심 해석과 다음 연구 질문

지난 10년의 변화를 압축하면 연구의 병목이 architecture에서 scale과 data로, 다시 alignment와 inference로, 이제 memory와 agency로 이동했다고 볼 수 있다. 앞 단계가 사라진 것은 아니다. 오히려 여러 층이 쌓이면서 한 모델의 능력을 시스템 수준에서 조율하는 문제가 더 중요해졌다.

특히 검증 가능한 수학과 코드 밖에서는 reward hacking, verifier bias, self-generated curriculum의 붕괴가 여전히 어렵다. 미래의 확장 자원은 인터넷 텍스트만이 아니라 environment, verifier, self-generated experience가 될 가능성이 크지만, 이 셋의 품질을 측정하는 방법이 함께 발전해야 한다.

2017년의 질문이 ‘RNN 없이 시퀀스를 어떻게 처리할 것인가’였다면, 2026년의 질문은 ‘무엇을 기억하고, 얼마나 생각하며, 어떤 도구와 agent를 사용해 작업을 끝낼 것인가’다.

권장 읽기 순서와 참고문헌

처음 읽는다면 Transformer → Scaling Laws와 Chinchilla → InstructGPT → FlashAttention → Mamba → test-time compute → DeepSeek-R1 → Titans → Gated Attention → Absolute Zero 순서를 권한다. 구조, 학습, 추론, 기억의 병목이 어떻게 이동했는지 가장 자연스럽게 연결된다.
