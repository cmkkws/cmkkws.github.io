LA-09 — Kernel & Range (Null Space & Column Space)

Kernel과 Range, 네 기본 부분공간, Rank–Nullity와 선형 시스템의 관계를 정리한다.

1. 핵심 개념

행렬 \(\mathbf{A}\in\mathbb{R}^{M\times N}\)은 다음 선형 변환을 정의한다.

\[T:\mathbb{R}^{N}\rightarrow\mathbb{R}^{M},\qquad T(\mathbf{x})=\mathbf{A}\mathbf{x}\]

이 변환에서 입력은 \(\mathbb{R}^{N}\)에 있고 출력은 \(\mathbb{R}^{M}\)에 있다. 행렬 \(\mathbf A\)와 관련된 핵심 부분공간은 네 개다.

  • Null Space / Kernel: \(\mathcal N(\mathbf A)\)
  • Column Space / Range: \(\mathcal C(\mathbf A)\)
  • Row Space: \(\mathcal C(\mathbf A^T)\)
  • Left Null Space: \(\mathcal N(\mathbf A^T)\)

이 Lecture에서는 그중 Kernel과 Range를 중심으로 네 공간의 관계까지 연결한다.

2. Kernel / Null Space

행렬 \(\mathbf A\)를 곱했을 때 영벡터로 변하는 모든 입력 벡터의 집합을 Null Space 또는 Kernel이라고 한다.

\[\boxed{\mathcal N(\mathbf A)=\{\mathbf x\in\mathbb R^N\mid\mathbf A\mathbf x=\mathbf0\}}\]

즉,

\[\mathbf x\in\mathcal N(\mathbf A)\quad\Longleftrightarrow\quad\mathbf A\mathbf x=\mathbf0\]

Null Space의 벡터는 모두 입력 공간에 존재한다.

\[\boxed{\mathcal N(\mathbf A)\subseteq\mathbb R^N}\]

Null Space의 차원을 Nullity라고 한다.

\[\boxed{\operatorname{nullity}(\mathbf A)=\dim\mathcal N(\mathbf A)}\]

선형 변환 관점에서는 서로 다른 입력이 Kernel 방향으로 차이가 나더라도 그 차이가 출력에서는 사라질 수 있다. 예를 들어 \(\mathbf n\in\mathcal N(\mathbf A)\)라면

\[\mathbf A(\mathbf x+\mathbf n)=\mathbf A\mathbf x+\mathbf A\mathbf n=\mathbf A\mathbf x\]

따라서 Kernel 방향의 변화는 선형 변환의 출력에서 구별되지 않는다.

3. Range / Column Space

모든 입력 \(\mathbf x\in\mathbb R^N\)에 대해 만들 수 있는 출력 \(\mathbf y=\mathbf A\mathbf x\)의 집합을 Range라고 한다. 행렬 표현에서는 Column Space와 같다.

\[\boxed{\mathcal C(\mathbf A)=\{\mathbf y\in\mathbb R^M\mid\mathbf y=\mathbf A\mathbf x,\ \mathbf x\in\mathbb R^N\}}\]

행렬의 열을

\[\mathbf A=\begin{bmatrix}\mathbf a_{:,1}&\mathbf a_{:,2}&\cdots&\mathbf a_{:,N}\end{bmatrix}\]

라고 하면

\[\mathbf A\mathbf x=x_1\mathbf a_{:,1}+x_2\mathbf a_{:,2}+\cdots+x_N\mathbf a_{:,N}\]

이므로 Range는 행렬의 열들이 생성하는 Span과 같다.

\[\boxed{\mathcal C(\mathbf A)=\operatorname{Span}(\mathbf a_{:,1},\mathbf a_{:,2},\dots,\mathbf a_{:,N})}\]

Column Space는 출력 공간의 부분공간이다.

\[\boxed{\mathcal C(\mathbf A)\subseteq\mathbb R^M}\]

Column Space의 차원이 행렬의 Rank다.

\[\boxed{\operatorname{rank}(\mathbf A)=\dim\mathcal C(\mathbf A)}\]

따라서 \(\mathbf A\)가 실제로 출력 공간에서 몇 개의 독립적인 방향을 생성할 수 있는지가 Rank다.

4. Kernel과 Range 비교

Kernel과 Range는 같은 행렬에서 만들어지지만 서로 다른 공간에 존재한다.

변환 흐름으로 보면 다음과 같다.

\[\boxed{\mathbb R^N\xrightarrow{\mathbf A}\mathcal C(\mathbf A)\subseteq\mathbb R^M}\]

입력 공간 내부에서

\[\mathcal N(\mathbf A)\]

방향은 변환 과정에서 \(\mathbf0\)으로 사라진다.

5. Four Fundamental Subspaces

\(\mathbf A\in\mathbb R^{M\times N}\)에는 네 개의 기본 부분공간이 연결된다.

여기서

\[r=\operatorname{rank}(\mathbf A)\]

입력 공간 \(\mathbb R^N\)에서는 Row Space와 Null Space가 서로 직교 보공간을 이룬다.

\[\boxed{\mathbb R^N=\mathcal C(\mathbf A^T)\oplus\mathcal N(\mathbf A)}\]

출력 공간 \(\mathbb R^M\)에서는 Column Space와 Left Null Space가 서로 직교 보공간을 이룬다.

\[\boxed{\mathbb R^M=\mathcal C(\mathbf A)\oplus\mathcal N(\mathbf A^T)}\]

따라서 네 공간은 두 개씩 같은 전체 공간을 분할한다.

6. Rank–Nullity Theorem

\(\mathbf A\in\mathbb R^{M\times N}\)의 입력 공간 차원은 \(N\)이다. Rank–Nullity Theorem은 이 \(N\)차원이 Rank와 Nullity로 분해된다는 정리다.

\[\boxed{\operatorname{rank}(\mathbf A)+\operatorname{nullity}(\mathbf A)=N}\]

동일하게 쓰면 다음과 같다.

\[\boxed{\dim\mathcal C(\mathbf A)+\dim\mathcal N(\mathbf A)=N}\]

Rank가 \(r\)이면 Nullity는 자동으로 다음과 같이 결정된다.

\[\boxed{\operatorname{nullity}(\mathbf A)=N-r}\]

즉 입력 공간의 \(N\)개 독립 방향 중 \(r\)개 방향이 출력 공간의 독립적인 방향과 연결되고 나머지 \(N-r\)개 방향은 Kernel을 구성한다.

7. Null Space가 부분공간인 이유

Null Space가 실제 벡터 부분공간인지 세 조건을 확인한다.

영벡터 포함

행렬에 영벡터를 곱하면 항상 영벡터가 된다.

\[\mathbf A\mathbf0_N=\mathbf0_M\]

따라서 다음과 같다.

\[\boxed{\mathbf0_N\in\mathcal N(\mathbf A)}\]

덧셈에 대한 닫힘

\(\mathbf u,\mathbf v\in\mathcal N(\mathbf A)\)라고 하자. 정의에 의해

\[\mathbf A\mathbf u=\mathbf0,\qquad\mathbf A\mathbf v=\mathbf0\]

두 벡터를 더한 후 \(\mathbf A\)를 적용하면

\[\mathbf A(\mathbf u+\mathbf v)=\mathbf A\mathbf u+\mathbf A\mathbf v=\mathbf0+\mathbf0=\mathbf0\]

따라서 다음과 같다.

\[\boxed{\mathbf u+\mathbf v\in\mathcal N(\mathbf A)}\]

스칼라배에 대한 닫힘

\(\mathbf u\in\mathcal N(\mathbf A)\), \(c\in\mathbb R\)라고 하자.

\[\mathbf A(c\mathbf u)=c(\mathbf A\mathbf u)=c\mathbf0=\mathbf0\]

이므로

\[\boxed{c\mathbf u\in\mathcal N(\mathbf A)}\]

영벡터 포함, 덧셈 닫힘, 스칼라배 닫힘을 모두 만족하므로

\[\boxed{\mathcal N(\mathbf A)\text{는 }\mathbb R^N\text{의 부분공간이다.}}\]

8. Null Space와 Row Space의 직교 관계

행렬 \(\mathbf A\)의 각 행을 다음과 같이 나타내자.

\[\mathbf A=\begin{bmatrix}\mathbf a_{1,:}^{T}\\\mathbf a_{2,:}^{T}\\\vdots\\\mathbf a_{M,:}^{T}\end{bmatrix}\]

\(\mathbf x\in\mathcal N(\mathbf A)\)이면

\[\mathbf A\mathbf x=\mathbf0\]

행렬 곱을 행과 열의 내적으로 보면 다음과 같다.

\[\mathbf A\mathbf x=\begin{bmatrix}\mathbf a_{1,:}^{T}\mathbf x\\\mathbf a_{2,:}^{T}\mathbf x\\\vdots\\\mathbf a_{M,:}^{T}\mathbf x\end{bmatrix}=\begin{bmatrix}0\\0\\\vdots\\0\end{bmatrix}\]

따라서 모든 행벡터에 대해

\[\boxed{\mathbf a_{i,:}^{T}\mathbf x=0}\]

즉 \(\mathbf x\)는 \(\mathbf A\)의 모든 행벡터와 직교한다. Row Space의 임의의 벡터 \(\mathbf r\)은 행벡터들의 선형 결합이다.

\[\mathbf r=\sum_{i=1}^{M}c_i\mathbf a_{i,:}\]

따라서 \(\mathbf r\)과 \(\mathbf x\)의 내적은

\[\begin{aligned}\langle\mathbf r,\mathbf x\rangle&=\left\langle\sum_{i=1}^{M}c_i\mathbf a_{i,:},\mathbf x\right\rangle\\&=\sum_{i=1}^{M}c_i\langle\mathbf a_{i,:},\mathbf x\rangle\\&=0\end{aligned}\]

따라서

\[\boxed{\mathcal N(\mathbf A)\perp\mathcal C(\mathbf A^T)}\]

이고 차원까지 합쳐 \(\mathbb R^N\) 전체를 구성하므로 결과는 다음과 같다.

\[\boxed{\mathcal N(\mathbf A)=\mathcal C(\mathbf A^T)^\perp}\]

9. Column Space와 Left Null Space의 직교 관계

동일한 관계를 \(\mathbf A^T\)에 적용할 수 있다. \(\mathbf y\in\mathcal N(\mathbf A^T)\)이면

\[\mathbf A^T\mathbf y=\mathbf0\]

이는 \(\mathbf y\)가 \(\mathbf A\)의 모든 열과 직교한다는 뜻이다. 따라서

\[\boxed{\mathcal N(\mathbf A^T)\perp\mathcal C(\mathbf A)}\]

이며

\[\boxed{\mathcal N(\mathbf A^T)=\mathcal C(\mathbf A)^\perp}\]

두 직교 관계를 함께 정리하면 다음과 같다.

\[\boxed{\begin{gathered}\mathcal N(\mathbf A)=\mathcal C(\mathbf A^T)^\perp\subseteq\mathbb R^N\\[6pt]\mathcal N(\mathbf A^T)=\mathcal C(\mathbf A)^\perp\subseteq\mathbb R^M\end{gathered}}\]

10. Rank–Nullity를 RREF로 유도

\(\mathbf A\in\mathbb R^{M\times N}\)에 가우스-조던 소거법을 적용하여 RREF 행렬 \(\mathbf R\)을 만든다고 하자. 행 기본 연산은 가역 행렬 \(\mathbf E\)의 좌곱으로 표현할 수 있다.

\[\mathbf R=\mathbf E\mathbf A\]

\(\mathbf E\)는 가역이므로

\[\mathbf A\mathbf x=\mathbf0\quad\Longleftrightarrow\quad\mathbf E\mathbf A\mathbf x=\mathbf0\]

따라서

\[\boxed{\mathcal N(\mathbf A)=\mathcal N(\mathbf R)}\]

RREF에서 피봇 열의 개수를 \(r\)이라고 하자. 이 수가 Rank다.

\[\boxed{\operatorname{rank}(\mathbf A)=r}\]

전체 열 개수는 \(N\)이므로 피봇이 없는 열은 \(N-r\)개다. 동차방정식 \(\mathbf R\mathbf x=\mathbf0\)에서는 이 열들에 대응하는 변수들이 자유 변수가 된다. 따라서 자유 변수의 개수는

\[N-r\]

각 자유 변수 하나를 1로 두고 나머지 자유 변수를 0으로 두어 특수해를 만들 수 있다.

\[\mathbf n_1,\mathbf n_2,\dots,\mathbf n_{N-r}\]

이 특수해들은 영공간의 기저를 형성한다. 따라서

\[\boxed{\operatorname{nullity}(\mathbf A)=N-r}\]

Rank와 Nullity를 더하면 다음 결과를 얻는다.

\[\boxed{\operatorname{rank}(\mathbf A)+\operatorname{nullity}(\mathbf A)=r+(N-r)=N}\]

11. 입력 공간의 직교 분해

입력 공간은 다음 두 공간으로 분해된다.

\[\mathbb R^N=\mathcal C(\mathbf A^T)\oplus\mathcal N(\mathbf A)\]

따라서 임의의 입력 벡터 \(\mathbf x\in\mathbb R^N\)는 다음과 같이 쓸 수 있다.

\[\boxed{\mathbf x=\mathbf x_r+\mathbf x_n}\]

여기서

\[\mathbf x_r\in\mathcal C(\mathbf A^T),\qquad\mathbf x_n\in\mathcal N(\mathbf A)\]

두 성분은 서로 직교한다.

\[\mathbf x_r^T\mathbf x_n=0\]

행렬 \(\mathbf A\)를 적용하면 다음과 같다.

\[\mathbf A\mathbf x=\mathbf A(\mathbf x_r+\mathbf x_n)=\mathbf A\mathbf x_r+\mathbf A\mathbf x_n\]

Kernel 성분은

\[\mathbf A\mathbf x_n=\mathbf0\]

이므로

\[\boxed{\mathbf A\mathbf x=\mathbf A\mathbf x_r}\]

즉 출력에는 입력의 Row Space 성분만 남고 Null Space 성분은 사라진다.

12. 선형 시스템과 Column Space

비동차 선형 시스템을 생각한다.

\[\mathbf A\mathbf x=\mathbf b\]

Column Space의 정의는

\[\mathcal C(\mathbf A)=\{\mathbf A\mathbf x\mid\mathbf x\in\mathbb R^N\}\]

이므로 방정식에 해가 존재하려면 \(\mathbf b\)가 Column Space 안에 있어야 한다.

\[\boxed{\mathbf A\mathbf x=\mathbf b\text{가 해를 가짐}\quad\Longleftrightarrow\quad\mathbf b\in\mathcal C(\mathbf A)}\]

따라서 Column Space는 행렬 \(\mathbf A\)가 실제로 만들어 낼 수 있는 모든 우변 \(\mathbf b\)의 공간이다.

13. 비동차 시스템의 일반해

\(\mathbf A\mathbf x=\mathbf b\)의 한 특수해를 \(\mathbf x_p\)라고 하자.

\[\mathbf A\mathbf x_p=\mathbf b\]

그리고 \(\mathbf x_n\in\mathcal N(\mathbf A)\)라고 하자.

\[\mathbf A\mathbf x_n=\mathbf0\]

두 벡터를 더하면

\[\mathbf A(\mathbf x_p+\mathbf x_n)=\mathbf A\mathbf x_p+\mathbf A\mathbf x_n=\mathbf b\]

따라서 일반해는

\[\boxed{\mathbf x=\mathbf x_p+\mathbf x_n,\qquad\mathbf x_n\in\mathcal N(\mathbf A)}\]

Nullity가 0이면

\[\mathcal N(\mathbf A)=\{\mathbf0\}\]

이므로 가능한 \(\mathbf x_n\)은 영벡터뿐이고 해가 존재한다면 유일하다. 반면 Nullity가 0보다 크면 하나의 특수해에 여러 Null Space 벡터를 더할 수 있으므로 해가 존재할 경우 무한히 많은 해를 갖는다.

14. 가역성과 Null Space

정방행렬

\[\mathbf A\in\mathbb R^{N\times N}\]

에 대해서는 다음 조건들이 서로 동치다.

  1. \(\mathbf A\)가 가역이다.
  2. \(\mathbf A^{-1}\)가 존재한다.
  3. \(\mathcal N(\mathbf A)=\{\mathbf0\}\)이다.
  4. \(\operatorname{nullity}(\mathbf A)=0\)이다.
  5. \(\operatorname{rank}(\mathbf A)=N\)이다.
  6. \(\mathcal C(\mathbf A)=\mathbb R^N\)이다.

Rank–Nullity를 사용하면 이 관계가 직접 연결된다.

\[\operatorname{rank}(\mathbf A)+\operatorname{nullity}(\mathbf A)=N\]

Full Rank이면

\[\operatorname{rank}(\mathbf A)=N\]

이므로

\[\operatorname{nullity}(\mathbf A)=0\]

반대로 Nullity가 0이면 다음과 같다.

\[\operatorname{rank}(\mathbf A)=N\]

15. 딥러닝 관점의 Kernel

원본 자료에서는 Kernel을 모델의 출력을 변화시키지 않는 방향과 연결한다. 예를 들어 활성화 행렬을 \(\mathbf X\)라고 하고 가중치의 변화량을 \(\Delta\mathbf W\)라고 하자. 만약

\[\boxed{\mathbf X\Delta\mathbf W=\mathbf0}\]

이면 다음 관계가 성립한다.

\[\begin{aligned}\mathbf X(\mathbf W+\Delta\mathbf W)&=\mathbf X\mathbf W+\mathbf X\Delta\mathbf W\\&=\mathbf X\mathbf W+\mathbf0\\&=\mathbf X\mathbf W\end{aligned}\]

즉 해당 입력 \(\mathbf X\)에 대해서는 \(\Delta\mathbf W\)를 추가해도 출력이 변하지 않는다. 원본 자료는 이러한 방향을 과매개변수화 모델에서 나타나는 불변 방향과 연결해 설명한다.

16. Overparameterization과 Nullity

\(\mathbf A\in\mathbb R^{M\times N}\)에서 \(N\)이 \(M\)보다 매우 크다면 Rank에는 다음 상한이 있다.

\[\operatorname{rank}(\mathbf A)\le M\]

Rank–Nullity에 의해

\[\operatorname{nullity}(\mathbf A)=N-\operatorname{rank}(\mathbf A)\]

이므로 \(N\gg M\)인 경우 큰 Null Space가 존재할 수 있다. 원본 자료에서는 이를 현대 대규모 모델의 과매개변수화와 연결해 해석한다. 많은 파라미터 방향 중 일부는 특정 활성화 또는 출력 관점에서 동일한 결과를 생성할 수 있고, 이러한 자유도가 모델 해석이나 경량화와 관련될 수 있다는 관점이다.

17. 수치 예제 — $3\times4$ 행렬

다음 행렬을 사용한다.

\[\mathbf A=\begin{bmatrix}1&2&1&4\\2&4&3&10\\3&6&4&14\end{bmatrix}\in\mathbb R^{3\times4}\]

목표는 다음을 모두 구하는 것이다.

  • RREF
  • Pivot columns
  • Rank
  • Column Space의 기저
  • Null Space의 기저
  • Nullity
  • Rank–Nullity 검증

18. RREF 계산

먼저

\[R_2\leftarrow R_2-2R_1\]

을 적용한다.

\[\begin{bmatrix}2&4&3&10\end{bmatrix}-2\begin{bmatrix}1&2&1&4\end{bmatrix}=\begin{bmatrix}0&0&1&2\end{bmatrix}\]

다음으로

\[R_3\leftarrow R_3-3R_1\]

을 적용한다.

\[\begin{bmatrix}3&6&4&14\end{bmatrix}-3\begin{bmatrix}1&2&1&4\end{bmatrix}=\begin{bmatrix}0&0&1&2\end{bmatrix}\]

따라서 중간 결과는 다음과 같다.

\[\begin{bmatrix}1&2&1&4\\0&0&1&2\\0&0&1&2\end{bmatrix}\]

이제

\[R_3\leftarrow R_3-R_2\]

를 수행하면

\[R_3=\begin{bmatrix}0&0&0&0\end{bmatrix}\]

그리고

\[R_1\leftarrow R_1-R_2\]

를 적용하면 첫 번째 행은 다음과 같이 변한다.

\[\begin{bmatrix}1&2&1&4\end{bmatrix}-\begin{bmatrix}0&0&1&2\end{bmatrix}=\begin{bmatrix}1&2&0&2\end{bmatrix}\]

최종 RREF는 다음과 같다.

\[\boxed{\mathbf R=\begin{bmatrix}1&2&0&2\\0&0&1&2\\0&0&0&0\end{bmatrix}}\]

19. Pivot과 Rank

RREF에서 Pivot이 있는 열은 1번째 열과 3번째 열이다. 따라서 Pivot의 개수는

\[r=2\]

이고

\[\boxed{\operatorname{rank}(\mathbf A)=2}\]

Pivot이 없는 열은 2번째 열과 4번째 열이다. 따라서 동차 시스템에서는

\[x_2,\qquad x_4\]

가 자유 변수다.

20. Column Space의 기저

Column Space의 기저는 RREF 자체의 Pivot 열이 아니라 원본 행렬 \(\mathbf A\)에서 Pivot 위치에 해당하는 열을 선택한다. 원본 행렬의 첫 번째 열은

\[\mathbf a_{:,1}=\begin{bmatrix}1\\2\\3\end{bmatrix}\]

이고 세 번째 열은

\[\mathbf a_{:,3}=\begin{bmatrix}1\\3\\4\end{bmatrix}\]

따라서

\[\boxed{\operatorname{Basis}\mathcal C(\mathbf A)=\left\{\begin{bmatrix}1\\2\\3\end{bmatrix},\begin{bmatrix}1\\3\\4\end{bmatrix}\right\}}\]

이고

\[\boxed{\dim\mathcal C(\mathbf A)=2}\]

즉

\[\boxed{\operatorname{rank}(\mathbf A)=2}\]

가 다시 확인된다.

21. Null Space의 기저

RREF에 대해

\[\mathbf R\mathbf x=\mathbf0\]

을 푼다. \(\mathbf x\)를

\[\mathbf x=\begin{bmatrix}x_1\\x_2\\x_3\\x_4\end{bmatrix}\]

라고 하면 방정식은 다음과 같다.

\[\begin{aligned}x_1+2x_2+2x_4&=0\\x_3+2x_4&=0\end{aligned}\]

Pivot 변수를 자유 변수로 표현한다.

\[\begin{gathered}x_1=-2x_2-2x_4\\[6pt]x_3=-2x_4\end{gathered}\]

따라서 전체 해는 다음과 같다.

\[\mathbf x=\begin{bmatrix}-2x_2-2x_4\\x_2\\-2x_4\\x_4\end{bmatrix}\]

자유 변수별로 분리하면

\[\boxed{\mathbf x=x_2\begin{bmatrix}-2\\1\\0\\0\end{bmatrix}+x_4\begin{bmatrix}-2\\0\\-2\\1\end{bmatrix}}\]

따라서 Null Space의 기저는 다음과 같다.

\[\boxed{\operatorname{Basis}\mathcal N(\mathbf A)=\left\{\mathbf n_1=\begin{bmatrix}-2\\1\\0\\0\end{bmatrix},\mathbf n_2=\begin{bmatrix}-2\\0\\-2\\1\end{bmatrix}\right\}}\]

기저 벡터가 두 개이므로 다음과 같다.

\[\boxed{\operatorname{nullity}(\mathbf A)=2}\]

22. Null Space 기저 검증

첫 번째 기저 벡터에 \(\mathbf A\)를 곱한다.

\[\mathbf A\mathbf n_1=\begin{bmatrix}1&2&1&4\\2&4&3&10\\3&6&4&14\end{bmatrix}\begin{bmatrix}-2\\1\\0\\0\end{bmatrix}\]

각 성분은 다음과 같다.

\[\mathbf A\mathbf n_1=\begin{bmatrix}-2+2\\-4+4\\-6+6\end{bmatrix}=\boxed{\begin{bmatrix}0\\0\\0\end{bmatrix}}\]

두 번째 기저 벡터도 확인한다.

\[\mathbf A\mathbf n_2=\begin{bmatrix}1&2&1&4\\2&4&3&10\\3&6&4&14\end{bmatrix}\begin{bmatrix}-2\\0\\-2\\1\end{bmatrix}\]

각 성분은 다음과 같다.

\[\mathbf A\mathbf n_2=\begin{bmatrix}-2-2+4\\-4-6+10\\-6-8+14\end{bmatrix}=\boxed{\begin{bmatrix}0\\0\\0\end{bmatrix}}\]

따라서 두 벡터 모두 실제로 \(\mathcal N(\mathbf A)\)에 속한다.

23. Rank–Nullity 수치 검증

행렬 \(\mathbf A\)의 열 개수는

\[N=4\]

앞에서

\[\operatorname{rank}(\mathbf A)=2\]

와

\[\operatorname{nullity}(\mathbf A)=2\]

를 구했다. 따라서

\[\boxed{\operatorname{rank}(\mathbf A)+\operatorname{nullity}(\mathbf A)=2+2=4=N}\]

으로 Rank–Nullity Theorem이 확인된다.

24. 중요한 성질

정방행렬의 가역성

\(\mathbf A\in\mathbb R^{N\times N}\)에서는 다음 조건이 동치다.

\[\boxed{\mathbf A\text{ invertible}\Longleftrightarrow\mathcal N(\mathbf A)=\{\mathbf0\}\Longleftrightarrow\operatorname{nullity}(\mathbf A)=0\Longleftrightarrow\operatorname{rank}(\mathbf A)=N\Longleftrightarrow\mathcal C(\mathbf A)=\mathbb R^N}\]

선형 시스템의 해 존재성

\[\boxed{\mathbf A\mathbf x=\mathbf b\text{에 해가 존재}\Longleftrightarrow\mathbf b\in\mathcal C(\mathbf A)}\]

선형 시스템의 일반해

특수해가 존재한다면 결과는 다음과 같다.

\[\boxed{\mathbf x=\mathbf x_p+\mathbf x_n,\qquad\mathbf x_n\in\mathcal N(\mathbf A)}\]

해의 유일성

해가 존재한다고 가정하면 Nullity가 0일 때 해가 유일하다.

\[\boxed{\operatorname{nullity}(\mathbf A)=0\Longrightarrow\text{unique solution}}\]

Nullity가 0보다 크면 특수해에 여러 Kernel 벡터를 더할 수 있다.

\[\boxed{\operatorname{nullity}(\mathbf A)>0\Longrightarrow\text{infinitely many solutions, if a solution exists}}\]

25. 헷갈리는 부분

Kernel과 Range가 존재하는 공간

Kernel은 입력 벡터들의 공간이다.

\[\boxed{\mathcal N(\mathbf A)\subseteq\mathbb R^N}\]

Range는 출력 벡터들의 공간이다.

\[\boxed{\mathcal C(\mathbf A)\subseteq\mathbb R^M}\]

\(\mathbf A\)가 장방행렬이면 \(M\)과 \(N\)이 다를 수 있으므로 두 공간을 같은 주변 공간에 있다고 생각하면 안 된다.

Column Space와 Row Space

Column Space는 \(\mathbf A\)의 열들이 만드는 공간이다.

\[\mathcal C(\mathbf A)\subseteq\mathbb R^M\]

Row Space는 \(\mathbf A\)의 행들이 만드는 공간이며 \(\mathbf A^T\)의 Column Space로 표현한다.

\[\mathcal C(\mathbf A^T)\subseteq\mathbb R^N\]

두 공간의 차원은 모두 Rank와 같다.

\[\boxed{\dim\mathcal C(\mathbf A)=\dim\mathcal C(\mathbf A^T)=\operatorname{rank}(\mathbf A)}\]

RREF에서 Column Space 기저를 바로 가져오면 안 된다

행 기본 연산은 Null Space의 해집합은 보존하지만 원래 Column Space 자체는 바꿀 수 있다. 따라서 RREF

\[\mathbf R=\operatorname{RREF}(\mathbf A)\]

을 구한 뒤 \(\mathbf R\)의 Pivot 열 자체를 \(\mathcal C(\mathbf A)\)의 기저로 사용하면 안 된다. RREF에서는 Pivot의 위치만 확인한다. 예를 들어 Pivot이 1번째와 3번째 열이라면 Column Space의 기저는 반드시 원본 \(\mathbf A\)의 1번째와 3번째 열에서 가져온다.

\[\boxed{\operatorname{Basis}\mathcal C(\mathbf A)=\{\mathbf a_{:,1},\mathbf a_{:,3}\}}\]

반면 Null Space는

\[\mathbf A\mathbf x=\mathbf0\quad\Longleftrightarrow\quad\mathbf R\mathbf x=\mathbf0\]

이므로 RREF를 이용해 특수해를 계산해도 된다.

26. 정리

행렬

\[\mathbf A\in\mathbb R^{M\times N}\]

은

\[T:\mathbb R^N\rightarrow\mathbb R^M\]

인 선형 변환을 정의한다. Kernel은 영벡터로 보내지는 모든 입력의 집합이다.

\[\boxed{\mathcal N(\mathbf A)=\{\mathbf x\in\mathbb R^N\mid\mathbf A\mathbf x=\mathbf0\}}\]

Range는 실제로 만들 수 있는 모든 출력의 집합이며 Column Space와 같다.

\[\boxed{\mathcal C(\mathbf A)=\{\mathbf A\mathbf x\mid\mathbf x\in\mathbb R^N\}=\operatorname{Span}(\mathbf a_{:,1},\dots,\mathbf a_{:,N})}\]

두 공간의 차원은 각각 Nullity와 Rank다.

\[\begin{gathered}\boxed{\operatorname{nullity}(\mathbf A)=\dim\mathcal N(\mathbf A)}\\[6pt]\boxed{\operatorname{rank}(\mathbf A)=\dim\mathcal C(\mathbf A)}\end{gathered}\]

Rank–Nullity Theorem은 입력 공간의 차원을 두 성분으로 분해한다.

\[\boxed{\operatorname{rank}(\mathbf A)+\operatorname{nullity}(\mathbf A)=N}\]

입력 공간에서는 Row Space와 Null Space가 직교 보공간이다.

\[\boxed{\mathbb R^N=\mathcal C(\mathbf A^T)\oplus\mathcal N(\mathbf A)}\]

출력 공간에서는 Column Space와 Left Null Space가 직교 보공간이다.

\[\boxed{\mathbb R^M=\mathcal C(\mathbf A)\oplus\mathcal N(\mathbf A^T)}\]

선형 시스템의 해 존재 여부는 \(\mathbf b\)가 Column Space에 있는지로 결정된다.

\[\boxed{\mathbf A\mathbf x=\mathbf b\text{ solvable}\Longleftrightarrow\mathbf b\in\mathcal C(\mathbf A)}\]

해가 존재할 때 모든 해는 특수해와 Null Space의 합으로 표현된다.

\[\boxed{\mathbf x=\mathbf x_p+\mathbf x_n,\qquad\mathbf x_n\in\mathcal N(\mathbf A)}\]

전체 구조를 한 줄로 연결하면 다음과 같다.

\[\boxed{\text{Domain }\mathbb R^N=\text{Row Space}\oplus\text{Null Space}\xrightarrow{\mathbf A}\text{Column Space}\subseteq\mathbb R^M}\]
