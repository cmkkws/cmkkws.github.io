PS-13 — Sampling Strategies (Decoding Sampling)

Softmax·temperature·Top-k·Top-p와 speculative decoding의 확률 구조를 정리한다.

1. Decoding이 필요한 이유

Autoregressive Language Model은 각 decoding step에서 vocabulary 전체에 대한 logit vector를 출력한다.

현재 context를

\[x_{<t} = (x_1,\dots,x_{t-1})\]

라고 하고 vocabulary size를

\[V=|\mathcal V|\]

라고 하면 model은 보통

\[\boxed{ \mathbf z_t = [z_{t,1},\dots,z_{t,V}]^T \in\mathbb R^V }\]

를 출력한다.

이 logit vector 자체는 probability distribution이 아니다.

Decoding은 이 score vector를 probability distribution으로 바꾸고, 그 distribution에서 실제 next token을 선택하는 단계다.

2. 원자료의 핵심 범위

원자료는 다음 decoding mechanism을 중심으로 구성된다.

  • Softmax
  • Temperature Scaling
  • Top-\(k\) Sampling
  • Top-\(p\) / Nucleus Sampling
  • Min-\(p\)
  • Presence / Frequency / Repetition Penalty
  • Speculative Decoding
  • GPU decoding overhead

또한 temperature의 극한과 entropy 변화를 수학적으로 유도한다.

3. 중요한 용어 교정 — Posterior가 아니다

원자료는 logit을 “사후 확률 분포”로 변환한다고 표현한다.

그러나 일반적인 autoregressive LLM의 Softmax 출력은

\[\boxed{ P_\theta( X_t=x_i \mid x_{<t} ) }\]

라는 conditional categorical distribution이다.

Bayesian inference의 의미에서 posterior라고 부를 필요는 없다.

따라서

\[\boxed{ \text{Softmax output} = \text{next-token conditional distribution} }\]

로 표현하는 것이 정확하다.

4. Output Projection

Transformer hidden state를

\[h_t\in\mathbb R^{d_{\text{model}}}\]

라고 하자.

보통 vocabulary logits는

\[\boxed{ \mathbf z_t = W_{\text{out}}h_t+b }\]

형태의 affine output projection으로 계산된다.

5. Shape

\[W_{\text{out}} \in \mathbb R^{V\times d_{\text{model}}}\]

이면

\[\boxed{ \mathbf z_t\in\mathbb R^V }\]

원자료의 “최종 비선형 선형 레이어”라는 표현보다는 output linear/affine projection이라고 부르는 것이 적절하다.

6. Softmax

Logits를 categorical probability로 변환하기 위해 Softmax를 사용한다.

\[\boxed{ p_i = P_\theta( X_t=x_i \mid x_{<t} ) = \frac{ e^{z_i} }{ \sum_{j=1}^{V}e^{z_j} } }\]

7. Probability 조건

Softmax는

\[p_i>0\]

이고

\[\boxed{ \sum_{i=1}^{V}p_i=1 }\]

을 만족한다.

8. Logit Translation Invariance

모든 logit에 동일한 constant \(c\)를 더해도 probability는 변하지 않는다.

\[\frac{ e^{z_i+c} }{ \sum_j e^{z_j+c} } = \frac{ e^c e^{z_i} }{ e^c\sum_j e^{z_j} } = \boxed{ p_i }\]

9. Numerical Stability

실제 Softmax 계산에서는 overflow를 막기 위해

\[m=\max_i z_i\]

를 빼고

\[\boxed{ p_i = \frac{ e^{z_i-m} }{ \sum_j e^{z_j-m} } }\]

를 사용한다.

Translation invariance 때문에 결과는 동일하다.

10. Decoding Policy

Softmax distribution이 정해졌다고 해서 token 선택 방식이 하나로 고정되는 것은 아니다.

대표적으로

  • Greedy decoding
  • Sampling
  • Top-\(k\)
  • Top-\(p\)
  • Beam search

등이 존재한다.

11. Greedy Decoding

Greedy decoding은

\[\boxed{ x_t = \arg\max_i z_i }\]

또는 equivalently

\[\boxed{ x_t = \arg\max_i p_i }\]

를 선택한다.

12. Greedy는 Sampling이 아니다

Greedy decoding은 distribution에서 random sample을 뽑지 않는다.

동일한 context와 model state라면 tie-breaking까지 고정했을 때 deterministic하다.

13. Full Sampling

가장 단순한 stochastic decoding은

\[\boxed{ X_t \sim \operatorname{Categorical}(p_1,\dots,p_V) }\]

로 전체 vocabulary distribution에서 sample하는 것이다.

14. Tail 문제

Language model distribution에는 매우 낮은 probability를 가진 많은 token이 존재할 수 있다.

전체 distribution에서 그대로 sampling하면 낮은 probability의 이상한 token이 가끔 선택될 수 있다.

Top-\(k\), Top-\(p\), Min-\(p\)는 이러한 candidate tail을 제한하는 전략이다.

15. Temperature Scaling

Temperature

\[\boxed{ T>0 }\]

를 도입하여

\[\boxed{ p_i(T) = \frac{ e^{z_i/T} }{ \sum_{j=1}^{V}e^{z_j/T} } }\]

로 정의한다.

16. Temperature의 의미

Temperature는 logit difference의 effective scale을 바꾼다.

두 token \(i,j\)의 probability ratio는 다음과 같다.

\[\boxed{ \frac{ p_i(T) }{ p_j(T) } = \exp \left( \frac{ z_i-z_j }{ T } \right) }\]

17. Low Temperature

\[0<T<1\]

이면

\[\frac1T>1\]

이므로 logit difference가 확대된다.

따라서 distribution이 더 sharp해진다.

18. High Temperature

\[T>1\]

이면

\[\frac1T<1\]

이므로 logit difference가 축소된다.

따라서 distribution이 더 flat해진다.

19. $T=1$

\[\boxed{ p_i(1) = \frac{ e^{z_i} }{ \sum_j e^{z_j} } }\]

이므로 original Softmax와 동일하다.

20. $T=0$은 식에 직접 넣을 수 없다

Temperature formula는

\[T>0\]

에서 정의된다.

따라서

\[\boxed{ T=0 }\]

을 직접 대입하는 것은 수학적으로 정의되지 않는다.

실무 API에서 temperature=0을 greedy decoding convention으로 처리할 수는 있지만, 이는 구현상의 convention이다.

수학적으로는

\[\boxed{ T\to0^+ }\]

극한을 다룬다.

21. $T\to0^+$ — Unique Maximum

logit maximum이 유일하다고 하자.

\[m = \arg\max_i z_i\]

이고

\[z_m>z_i \quad (i\ne m)\]

라고 하자.

22. Maximum Logit로 나누기

\[p_i(T) = \frac{ \exp((z_i-z_m)/T) }{ \sum_j \exp((z_j-z_m)/T) }\]

23. Non-maximum Terms

\(i\ne m\)이면

\[z_i-z_m<0\]

이므로

\[\boxed{ \lim_{T\to0^+} \exp \left( \frac{ z_i-z_m }{ T } \right) = 0 }\]

24. Maximum Term

\(i=m\)이면

\[\boxed{ \exp \left( \frac{ z_m-z_m }{ T } \right) = 1 }\]

25. Unique-Max Limit

따라서

\[\boxed{ \lim_{T\to0^+} p_m(T) = 1 }\]

이고

\[\boxed{ \lim_{T\to0^+} p_i(T) = 0 \qquad (i\ne m) }\]

26. 이산 분포 표현

Finite vocabulary에서는 이를

\[\boxed{ p_T \to \delta_m }\]

처럼 maximum token에 대한 point mass로 표현할 수 있다.

“Dirac delta”라는 표현보다 discrete categorical setting에서는 point mass 또는 degenerate categorical distribution이라고 부르는 것이 더 자연스럽다.

27. 중요한 Edge Case — Maximum Tie

최대 logit이 하나가 아니라

\[M = \{ i:z_i=z_{\max} \}\]

이고

\[|M|=r\]

이라고 하자.

28. Tied-Max Limit

모든 \(i\in M\)에 대해서 exponent term은 1이고, 나머지는 0으로 수렴한다.

따라서

\[\boxed{ \lim_{T\to0^+} p_i(T) = \begin{cases} 1/r,&i\in M\\ 0,&i\notin M \end{cases} }\]

29. 따라서 Greedy와 정확히 동일하지 않을 수 있다

Greedy decoder가 tied maximum에서 특정 index 하나를 deterministic하게 고르면

\[T\to0^+\]

의 Softmax limit와 greedy tie-breaking은 동일하지 않을 수 있다.

원자료의 증명은 unique maximum 조건에서는 정확하다.

30. $T\to\infty$

각 fixed logit \(z_i\)에 대해

\[\lim_{T\to\infty} \frac{z_i}{T} = 0\]

따라서

\[\boxed{ \lim_{T\to\infty} e^{z_i/T} = 1 }\]

31. Uniform Limit

따라서

\[\boxed{ \lim_{T\to\infty} p_i(T) = \frac1V }\]

즉 finite vocabulary에서는 uniform categorical distribution으로 수렴한다.

32. Shannon Entropy

Temperature-scaled distribution의 Shannon entropy를

\[\boxed{ H(T) = -\sum_{i=1}^{V} p_i(T)\log p_i(T) }\]

라고 하자.

Natural log를 사용하면 unit은 nats다.

33. Partition Function

\[\boxed{ Z_T = \sum_i e^{z_i/T} }\]

라고 두면

\[\log p_i(T) = \frac{z_i}{T} - \log Z_T\]

34. Entropy 재표현

\[\begin{aligned} H(T) &= -\sum_i p_i(T) \left[ \frac{z_i}{T} - \log Z_T \right]\\ &= \boxed{ \log Z_T - \frac1T \mathbb E_{p_T}[z] } \end{aligned}\]

35. $\log Z_T$ 미분

\[\boxed{ \frac{d}{dT} \log Z_T = - \frac1{T^2} \mathbb E_{p_T}[z] }\]

36. Probability derivative

Softmax derivative를 temperature에 대해 계산하면

\[\boxed{ \frac{dp_i(T)}{dT} = \frac1{T^2} p_i(T) \left( \mathbb E_{p_T}[z] - z_i \right) }\]

37. Expected Logit derivative

\[\begin{aligned} \frac{d}{dT} \mathbb E_{p_T}[z] &= \sum_i z_i \frac{dp_i}{dT}\\ &= - \frac1{T^2} \operatorname{Var}_{p_T}(z) \end{aligned}\]

38. Entropy derivative

따라서

\[\boxed{ \frac{dH}{dT} = \frac{ \operatorname{Var}_{p_T}(z) }{ T^3 } }\]

39. Monotonicity

\[T>0\]

이고

\[\operatorname{Var}_{p_T}(z)\ge0\]

이므로

\[\boxed{ \frac{dH}{dT}\ge0 }\]

따라서 fixed finite logits에 대해 temperature가 증가하면 entropy는 감소하지 않는다.

40. Strictly Increasing의 조건

원자료는 entropy가 “엄밀하게 단조 증가”한다고 표현한다.

그러나 모든 logits가 동일하면

\[z_1=\cdots=z_V\]

이고 distribution은 모든 \(T\)에서 이미 uniform이다.

이때

\[\operatorname{Var}_{p_T}(z)=0\]

이고

\[\boxed{ \frac{dH}{dT}=0 }\]

따라서 정확한 표현은

\[\boxed{ H(T)\text{ is nondecreasing in }T }\]

이며, logits가 모두 같지 않다면 finite \(T>0\)에서 strict increase가 성립한다.

41. Entropy Limits

Unique maximum이면

\[\boxed{ \lim_{T\to0^+} H(T) = 0 }\]

42. Maximum Tie Case

Maximum이 \(r\)개 tied라면

\[\boxed{ \lim_{T\to0^+} H(T) = \log r }\]

43. Infinite-Temperature Entropy

\[T\to\infty\]

에서 uniform distribution으로 수렴하므로

\[\boxed{ \lim_{T\to\infty} H(T) = \log V }\]

이는 \(V\)개 categorical outcomes의 최대 entropy다.

44. Top-$k$ Sampling

Temperature-adjusted distribution을

\[p_i\]

라고 쓰자.

Top-\(k\)는 probability가 높은 상위 \(k\)개 token만 남긴다.

45. Ordering

\[p_{(1)} \ge p_{(2)} \ge \cdots \ge p_{(V)}\]

라고 정렬한다.

\(T>0\)이면 Softmax는 strictly monotone transformation이므로 logit ordering과 probability ordering은 동일하다.

46. Candidate Set

\[\boxed{ S_k = \{ x_{(1)},\dots,x_{(k)} \} }\]

47. Truncated Distribution

\[\boxed{ q_i^{(k)} = \begin{cases} \dfrac{p_i}{ \sum_{j:x_j\in S_k}p_j }, & x_i\in S_k\\[1.2ex] 0, & x_i\notin S_k \end{cases} }\]

48. Renormalization

Top-\(k\)에서 단순히 하위 probability를 0으로 만드는 것만으로는 probability sum이 1이 되지 않는다.

따라서 remaining mass를 다시 normalize해야 한다.

49. $k=1$

Tie를 무시하면

\[\boxed{ k=1 }\]

은 greedy token만 남기므로 deterministic decoding과 동일해진다.

50. $k=V$

\[\boxed{ k=V }\]

이면 truncation이 없으므로 full sampling과 동일하다.

51. Top-$k$의 장점

Fixed number의 candidate만 남기므로 tail token을 제거할 수 있고 candidate set size가 일정하다.

52. Top-$k$의 한계

Distribution shape이 context마다 달라도 항상 정확히 \(k\)개를 유지한다.

따라서 어떤 step에서는 \(k\)가 너무 크고, 다른 step에서는 너무 작을 수 있다.

53. Source의 “hallucination 차단” 표현 보완

Tail token 제거가 이상한 token의 sampling 가능성을 낮출 수는 있다.

하지만

\[\boxed{ \text{Top-}k \not\Rightarrow \text{hallucination prevention} }\]

높은 probability token 자체가 사실적으로 틀릴 수도 있다.

54. Top-$p$ / Nucleus Sampling

Top-\(p\)는 fixed candidate count 대신 cumulative probability mass를 기준으로 candidate set을 정한다.

Threshold를

\[\boxed{ p\in(0,1] }\]

라고 하자.

55. Probability Sorting

\[p_{(1)} \ge p_{(2)} \ge \cdots \ge p_{(V)}\]

라고 정렬한다.

56. 정확한 $k^\ast$ 정의

원자료의 argmin Boolean 표현보다 다음 정의가 명확하다.

\[\boxed{ k^\ast = \min \left\{ k\in\{1,\dots,V\}: \sum_{m=1}^{k} p_{(m)} \ge p \right\} }\]

57. Nucleus Set

\[\boxed{ S_p = \{ x_{(1)},\dots,x_{(k^\ast)} \} }\]

58. Renormalized Nucleus Distribution

\[\boxed{ q_i^{(p)} = \begin{cases} \dfrac{p_i}{ \sum_{j:x_j\in S_p}p_j }, & x_i\in S_p\\[1.2ex] 0, & x_i\notin S_p \end{cases} }\]

59. Adaptive Candidate Size

Distribution이 sharp하면 적은 token만으로 threshold를 넘을 수 있다.

Distribution이 flat하면 더 많은 token이 필요하다.

이것이 Top-\(p\)의 핵심 동적 특성이다.

60. $p=1$

모든 probability mass를 포함해야 하므로

\[\boxed{ p=1 }\]

에서는 일반적으로 full vocabulary가 candidate가 된다.

Zero-probability token이 없다면 모든 token이 포함된다.

61. 매우 작은 $p$

Threshold \(p\)가 top token probability보다 작거나 같다면

\[\boxed{ k^\ast=1 }\]

이므로 greedy-like candidate set이 된다.

단 실제 선택은 candidate가 하나이므로 deterministic하다.

62. Boundary Tie

Candidate cutoff 위치에서 여러 token이 동일한 probability를 가질 수 있다.

수학적 set definition과 실제 library의 stable sorting/tie-breaking에 따라 어떤 tied token이 포함되는지가 달라질 수 있다.

63. Top-$k$와 Top-$p$ 결합

실제 decoder에서는 먼저 Top-\(k\)로 후보를 제한한 뒤 Top-\(p\)를 적용하거나, 반대 순서 또는 framework-specific filtering sequence를 사용할 수 있다.

64. 순서가 결과에 영향을 줄 수 있다

Top-\(k\)와 Top-\(p\)는 nonlinear truncation이다.

따라서 일반적으로

\[\boxed{ \text{Top-}k\circ\text{Top-}p \neq \text{Top-}p\circ\text{Top-}k }\]

일 수 있다.

Implementation order를 확인해야 한다.

65. Min-$p$

Source의 Min-\(p\) 정의는 top token probability를 reference scale로 사용한다.

\[p_{\max} = \max_i p_i\]

라고 하자.

66. Candidate Rule

한 일반적 형태는 다음과 같다.

\[\boxed{ S_{\min p} = \{ x_i: p_i \ge p_{\min}p_{\max} \} }\]

67. Relative Threshold

Top-\(p\)는 cumulative mass를 사용하지만 Min-\(p\)는 최고 probability에 대한 상대 threshold를 사용한다.

따라서 distribution sharpness에 따라 absolute cutoff가 바뀐다.

68. 구현 차이

Min-\(p\)의 precise implementation과 다른 sampling filter와의 적용 순서는 framework마다 다를 수 있다.

따라서 하나의 API formula를 universal standard로 생각하면 안 된다.

69. Presence Penalty

Source는 이미 등장한 token에 constant logit penalty를 주는 형태를 제시한다.

개념적으로

\[\boxed{ z_i' = z_i - \lambda_{\text{presence}} \mathbf 1\{c_i>0\} }\]

70. Frequency Penalty

token count \(c_i\)에 비례하여

\[\boxed{ z_i' = z_i - \lambda_{\text{frequency}}c_i }\]

처럼 적용할 수 있다.

71. Combined Additive Form

두 penalty를 함께 쓰면 source의 형태는 다음과 같다.

\[\boxed{ z_i' = z_i - \lambda_p \mathbf1\{c_i>0\} - \lambda_f c_i }\]

72. Repetition Penalty는 별도 구현일 수 있다

“Repetition penalty”라는 이름이 항상 위 additive formula를 뜻하지는 않는다.

예를 들어 일부 framework에서는 sign-aware multiplicative/divisive logit transformation을 사용한다.

따라서

\[\boxed{ \text{presence/frequency penalty} \neq \text{all repetition penalty implementations} }\]

73. Penalty는 Probability를 직접 빼는 것이 아니다

보통 penalty는 Softmax 이전 logit에 적용된다.

따라서 probability 변화는 Softmax를 거쳐 비선형적으로 결정된다.

74. Sampling Pipeline

한 decoding step을 높은 수준에서 다음처럼 볼 수 있다.

\[\boxed{ h_t \rightarrow z_t \rightarrow \text{logit transforms} \rightarrow \text{temperature} \rightarrow \text{truncation} \rightarrow \text{renormalization} \rightarrow \text{sampling} }\]

정확한 transform ordering은 engine/API에 따라 다를 수 있다.

93. Corrected Numerical Summary

94. Why Temperature Changes Entropy but not Ranking

For

\[T>0\]

the map

\[z_i\mapsto z_i/T\]

preserves order.

Therefore temperature changes relative probability gaps but not token ranking.

95. Top-$k$ Candidate Set and Temperature

Because ranking is preserved for \(T>0\), Top-\(k\) candidate identities are unchanged by temperature when there are no numerical/tie complications.

However the renormalized probabilities inside that set do change.

96. Top-$p$ Candidate Set and Temperature

Top-\(p\) depends on cumulative probabilities, not only ordering.

Therefore temperature can change

\[\boxed{ k^\ast }\]

even though token ranking stays the same.

97. Low Temperature + Top-$p$

Low temperature sharpens the distribution.

Thus the cumulative threshold may be reached with fewer tokens.

98. High Temperature + Top-$p$

High temperature flattens the distribution.

Thus more tokens may be required to reach the same \(p\) threshold.

99. Decoding Quality Is Not Monotonic in Entropy

Higher entropy means more uncertainty/diversity in the sampling distribution.

It does not imply higher generation quality.

Likewise lower entropy does not guarantee correctness.

100. Reasoning Tasks and Determinism

Source는 mathematics/code reasoning에서 very low temperature 또는 greedy를 추천한다.

이는 practical heuristic으로 이해할 수 있지만 universal optimum은 아니다.

101. 왜 고정 추천값이 보편적이지 않은가

Best decoding parameters depend on

  • model
  • training method
  • prompt
  • task
  • evaluation metric
  • whether multiple samples are allowed
  • whether self-consistency / verifier is used

등에 따라 달라진다.

102. Sampling Can Help Reasoning Too

하나의 deterministic trajectory보다 여러 stochastic reasoning paths를 sample한 뒤 verifier 또는 majority aggregation을 사용하는 방식이 더 나은 경우도 있다.

따라서

\[\boxed{ \text{reasoning} \Rightarrow T\approx0 }\]

를 theorem처럼 받아들이면 안 된다.

103. Creative Tasks

높은 temperature와 nucleus sampling이 lexical diversity를 높일 수 있다.

하지만 너무 높은 temperature는 coherence를 악화시킬 수 있다.

104. Fact-based QA

낮은 sampling entropy가 factuality를 항상 보장하지 않는다.

Model distribution 자체가 잘못되었으면 greedy answer도 틀릴 수 있다.

105. Parameter Tuning의 정확한 표현

Source의 task별 parameter range는 illustrative heuristic로 유지할 수 있지만 model-independent “최적 설정”이라고 부르면 안 된다.

106. Beam Search

Beam Search는 stochastic sampling과 다르다.

각 step에서 높은 cumulative score의 여러 partial sequences를 유지하는 approximate search algorithm이다.

107. Beam Width

Beam width를

\[B\]

라고 하면 여러 candidate sequence를 병렬적으로 유지한다.

Beam search는 local greedy보다 wider search를 하지만 global optimum을 항상 보장하는 것은 아니다.

108. Length Bias

Raw sequence log-probability는 token 수가 늘수록 더 negative해지는 경향이 있다.

Beam search에서는 length normalization 또는 length penalty가 사용될 수 있다.

109. Sampling vs Search

높은 수준에서

\[\boxed{ \text{sampling} = \text{probabilistic draw} }\]

이고

\[\boxed{ \text{search} = \text{high-score sequence exploration} }\]

둘을 구분한다.

110. Speculative Decoding

Speculative Decoding은 작은 draft model을 사용하여 여러 candidate token을 먼저 제안하고, target model이 이를 검증하여 target-model sampling과 동일한 distribution을 보존하면서 decoding latency를 줄이는 방법이다.

111. Draft와 Target Distribution

한 step에서 draft distribution을

\[q(x)\]

target distribution을

\[p(x)\]

라고 쓰자.

Draft가 token

\[x\sim q\]

를 제안한다.

112. Acceptance Probability

표준적인 rejection-correction 구조의 acceptance probability는 다음과 같다.

\[\boxed{ \alpha(x) = \min \left( 1, \frac{p(x)}{q(x)} \right) }\]

Draft가 실제로 proposal할 수 있는 \(q(x)>0\) token에 대해 사용한다.

113. Accepted Mass

Draft proposal probability와 acceptance probability의 곱은 다음과 같다.

\[q(x)\alpha(x) = \min(q(x),p(x))\]

114. Rejected Probability Mass

전체 rejection probability는 다음과 같다.

\[\boxed{ 1- \sum_x \min( p(x),q(x) ) }\]

115. Residual Distribution

Reject된 경우 residual distribution은 다음과 같다.

\[\boxed{ r(x) = \frac{ [p(x)-q(x)]_+ }{ \sum_y [p(y)-q(y)]_+ } }\]

여기서

\[[a]_+ = \max(a,0)\]

116. 왜 Target Distribution이 복원되는가

Accepted branch에서 token \(x\)의 mass는 다음과 같다.

\[\min(p(x),q(x))\]

Residual branch는 부족한 target mass

\[[p(x)-q(x)]_+\]

를 채운다.

117. Total Mass

따라서 최종 mass는 다음과 같다.

\[\boxed{ \min(p(x),q(x)) + [p(x)-q(x)]_+ = p(x) }\]

적절한 normalization을 포함하면 target distribution을 정확히 복원한다.

118. Exactness의 조건

Source의 “완벽하게 동일한 distribution” 주장은 ideal algorithm 아래에서 맞다.

그러나 다음 조건이 중요하다.

  • acceptance/rejection correction을 정확히 구현
  • 실제 target/draft distributions 사용
  • token별 sequential conditional structure를 올바르게 반영
  • numerical approximation이 algorithm semantics를 크게 바꾸지 않음

119. Truncated Sampling과 Speculation

Target distribution 자체에 Top-\(p\), Top-\(k\), temperature 등의 transform을 적용한다면 speculative correction은 그 transformed target distribution을 기준으로 설계되어야 한다.

120. Block Proposal

실제 speculative decoding에서는 draft가 여러 token을 제안하고 target이 block을 한 번에 score할 수 있다.

하지만 acceptance decisions는 autoregressive conditional structure에 맞춰 순차적으로 해석된다.

121. Speedup의 원리

Target model forward를 매 token마다 단독 수행하는 대신 여러 candidate token을 함께 검증할 수 있어 accelerator utilization을 높일 수 있다.

122. 항상 빨라지는 것은 아니다

Draft accuracy가 낮아 rejection이 많거나 draft overhead가 크면 speedup이 작거나 없어질 수 있다.

123. KV Cache

Autoregressive generation에서는 이미 처리한 prefix의 key/value states를 KV cache에 저장하여 매 step마다 prefix 전체를 다시 계산하지 않는다.

124. Cache의 역할

다음 token step에서는 새로운 query가 과거 cached keys/values를 attend한다.

따라서 decoder는 past token의 K/V를 재사용한다.

125. Memory-bound 경향

Single-token decoding은 matrix operations와 KV-cache reads 사이의 balance 때문에 accelerator에서 memory-bandwidth-bound 경향을 보일 수 있다.

하지만 정확한 bottleneck은

  • batch size
  • model size
  • quantization
  • hardware
  • attention implementation

등에 따라 달라진다.

126. “극도로 낮은 Arithmetic Intensity”는 조건부 표현

Source의 설명은 일반적인 low-batch autoregressive decode의 직관으로 유용하다.

다만 모든 decoding workload가 동일한 bottleneck을 갖는다고 일반화하면 안 된다.

127. Top-$k$ Complexity

Top-\(k\) candidate selection은 full sorting 없이 selection algorithm으로 구현할 수 있다.

Algorithm에 따라 theoretical/work complexity가 달라진다.

128. $O(V\log k)$는 하나의 가능성일 뿐

Heap-based selection에서는

\[O(V\log k)\]

를 생각할 수 있다.

하지만 GPU kernels는 radix selection, partition, hierarchical reduction 등 다른 방식을 사용할 수 있다.

따라서

\[\boxed{ \text{Top-}k = O(V\log k) }\]

를 모든 inference engine의 universal complexity로 단정하지 않는다.

129. Top-$p$ Complexity

Naive implementation은 full sort 후 cumulative sum을 할 수 있어

\[O(V\log V)\]

sorting work가 발생할 수 있다.

하지만 optimized algorithms가 항상 full sort를 요구하는 것은 아니다.

130. 따라서 GPU complexity의 정확한 표현

\[\boxed{ \text{Top-}p \text{ often requires more global probability-order/mass work than fixed Top-}k }\]

라는 qualitative statement는 가능하다.

그러나 exact asymptotic complexity와 latency는 implementation-dependent다.

131. Vocabulary Size

Vocabulary가 커질수록 logit processing과 sampling kernel의 cost도 증가할 수 있다.

하지만 전체 decode latency에서 sampling kernel이 차지하는 비율은 model/hardware/batch에 따라 달라진다.

132. Numerical Precision

Large vocabulary에서 probabilities를 explicit Softmax로 모두 materialize하지 않고 logits-space thresholding이나 fused kernels를 사용할 수 있다.

따라서 high-level mathematical formula와 kernel implementation은 구분해야 한다.

133. Logits Processor

Modern inference frameworks는 decoding 전에 여러 logit transforms를 연속 적용할 수 있다.

예를 들어

  • temperature
  • repetition penalty
  • bad-word filtering
  • min tokens
  • top-k
  • top-p

등이 있다.

134. Transform Order

이 연산들은 일반적으로 commutative하지 않다.

따라서 동일 parameter라도 framework의 processing order에 따라 아주 작은 차이가 발생할 수 있다.

135. Random Seed

Stochastic sampling에서는 random seed와 PRNG state가 output reproducibility에 영향을 준다.

136. Determinism caveat

같은 seed라도

  • hardware
  • kernel
  • batching
  • distributed execution

차이로 완전히 동일한 generation이 항상 보장되는 것은 아니다.

137. Sequence Probability

Sampling policy가 매 step 원래 model distribution을 truncation/temperature로 변환하면 generated sequence distribution도 원래 model joint distribution과 달라진다.

138. Base Model Joint Distribution

Model 자체는

\[\boxed{ P_\theta(x_{1:T}) = \prod_{t=1}^{T} P_\theta( x_t\mid x_{<t} ) }\]

를 정의한다.

139. Decoding-induced Distribution

Temperature/top-\(p\)/top-\(k\)를 적용하면 실제 sampling distribution을

\[Q_t( x_t\mid x_{<t} )\]

라고 할 수 있고

\[\boxed{ Q(x_{1:T}) = \prod_t Q_t( x_t\mid x_{<t} ) }\]

가 실제 generation policy가 된다.

140. 중요한 구분

따라서

\[\boxed{ \text{model probability} \neq \text{post-processed decoding probability} }\]

일 수 있다.

141. Sampling이 Calibration을 바꾼다

Temperature scaling은 output distribution의 entropy와 probability ratios를 바꾸므로 model의 raw probability calibration도 바꾼다.

Decoding diversity를 조절하는 temperature와 probability calibration을 위한 temperature scaling은 목적이 다를 수 있다.

142. Training-time Temperature와 Inference Temperature

Distillation, contrastive loss, calibration 등에서도 temperature가 등장한다.

같은 기호 \(T\)를 사용하더라도 inference decoding temperature와 목적/역할이 다를 수 있다.

143. Entropy와 Diversity

높은 token-level entropy는 일반적으로 더 다양한 next-token sampling 가능성을 만든다.

하지만 sequence-level semantic diversity와 완전히 동일한 개념은 아니다.

144. Entropy와 Uncertainty

Softmax entropy를 uncertainty proxy로 사용할 수 있지만, neural model이 miscalibrated하면 entropy가 epistemic uncertainty를 정확히 나타낸다고 보장할 수 없다.

145. Top-$p$의 “High Uncertainty” 표현 보완

Distribution이 flat하면 entropy가 높은 경향이 있고 nucleus set이 커질 수 있다.

그러나 이를 model이 세계에 대해 실제 epistemic uncertainty를 정확히 안다는 의미로 해석하면 안 된다.

146. Greedy의 Local Optimality

Greedy decoding은 각 step에서 가장 높은 conditional probability token을 선택한다.

147. Sequence Global Optimum과 다름

Greedy choices가 전체 sequence probability를 최대화하는 sequence를 항상 만들지는 않는다.

즉

\[\boxed{ \arg\max_{x_t} P(x_t\mid x_{<t}) }\]

를 반복하는 것과

\[\boxed{ \arg\max_{x_{1:T}} P(x_{1:T}) }\]

는 일반적으로 다르다.

148. Beam Search의 동기

Beam search는 이러한 greedy의 myopic limitation을 줄이기 위해 여러 partial sequences를 유지한다.

149. Sampling의 동기

Sampling은 가장 높은 probability sequence만 찾는 대신 model distribution의 여러 plausible modes를 탐색한다.

150. Decoding은 Training Objective를 바꾸지 않는다

Inference-time temperature/top-\(p\)/top-\(k\)는 이미 학습된 model parameter를 바꾸지 않는다.

이는 generation policy를 바꾸는 것이다.

151. 핵심 식 — Softmax

\[\boxed{ p_i = \frac{ e^{z_i} }{ \sum_j e^{z_j} } }\]

152. 핵심 식 — Temperature

\[\boxed{ p_i(T) = \frac{ e^{z_i/T} }{ \sum_j e^{z_j/T} } }\]

153. 핵심 식 — Temperature Ratio

\[\boxed{ \frac{ p_i(T) }{ p_j(T) } = e^{(z_i-z_j)/T} }\]

154. 핵심 식 — Temperature Entropy Derivative

\[\boxed{ \frac{dH}{dT} = \frac{ \operatorname{Var}_{p_T}(z) }{ T^3 } \ge0 }\]

155. 핵심 식 — Top-$k$

\[\boxed{ S_k = \{ x_{(1)},\dots,x_{(k)} \} }\]

156. 핵심 식 — Top-$p$

\[\boxed{ k^\ast = \min \left\{ k: \sum_{m=1}^{k} p_{(m)} \ge p \right\} }\]

157. 핵심 식 — Min-$p$

한 대표적 정의는 다음과 같다.

\[\boxed{ S_{\min p} = \{ x_i: p_i\ge p_{\min}p_{\max} \} }\]

158. 핵심 식 — Speculative Acceptance

\[\boxed{ \alpha(x) = \min \left( 1, \frac{p(x)}{q(x)} \right) }\]

159. 핵심 식 — Speculative Residual

\[\boxed{ r(x) \propto [p(x)-q(x)]_+ }\]

160. 혼동하기 쉬운 부분 — Softmax는 Posterior인가

일반 next-token Softmax는 Bayesian posterior라고 부르지 않는다.

이는 context-conditioned categorical distribution이다.

161. 혼동하기 쉬운 부분 — $T=0$

Softmax temperature formula에 \(T=0\)을 직접 넣을 수 없다.

Greedy decoding은 \(T\to0^+\) limit 또는 API convention과 연결한다.

162. 혼동하기 쉬운 부분 — Tied Maximum

Maximum logit이 여러 개면 \(T\to0^+\) limit은 tied maxima 사이에 probability를 나눈다.

Unique maximum assumption을 확인해야 한다.

163. 혼동하기 쉬운 부분 — Temperature와 Ranking

\(T>0\)에서는 ranking이 바뀌지 않는다.

Probability gap과 entropy가 바뀐다.

164. 혼동하기 쉬운 부분 — Entropy Strictness

Entropy는 temperature에 대해 nondecreasing이다.

모든 logits가 같으면 이미 uniform이므로 derivative는 0이다.

165. 혼동하기 쉬운 부분 — Top-$p$와 Top-$k$

Top-\(k\)는 candidate count가 fixed다.

Top-\(p\)는 cumulative probability에 따라 candidate count가 달라진다.

166. 혼동하기 쉬운 부분 — Tail 제거와 Factuality

낮은 probability token을 제거해도 hallucination이 사라진다는 보장은 없다.

167. 혼동하기 쉬운 부분 — Low Temperature와 Correctness

Low temperature는 distribution을 sharp하게 만들 뿐 정답 probability 자체를 보정하는 것은 아니다.

168. 혼동하기 쉬운 부분 — 작업별 최적 parameter

Task별 temperature/top-\(p\) “최적값”은 보편적 상수가 아니다.

Model과 evaluation setting에 따라 달라진다.

169. 혼동하기 쉬운 부분 — Speculative Decoding

Correct rejection-correction algorithm을 사용하면 target distribution을 보존할 수 있다.

단순히 draft token을 target이 score한다고 해서 자동으로 exact sampling이 되는 것은 아니다.

170. 혼동하기 쉬운 부분 — GPU Complexity

Top-\(k\)와 Top-\(p\)의 exact asymptotic/kernel cost는 implementation에 따라 다르다.

Source의 \(O(V\log k)\)와 \(O(V\log V)\)는 특정 algorithmic intuition으로 이해해야 한다.

171. 전체 개념 연결

첫 단계는 다음과 같다.

\[\boxed{ \text{hidden state} \rightarrow \text{logits} }\]

172. Probability Flow

\[\boxed{ \text{logits} \rightarrow \text{Softmax} \rightarrow \text{categorical distribution} }\]

173. Temperature Flow

\[\boxed{ \text{logit scale} \rightarrow \text{probability ratios} \rightarrow \text{entropy} }\]

174. Truncation Flow

\[\boxed{ \text{full distribution} \rightarrow \text{candidate filtering} \rightarrow \text{renormalization} }\]

175. Generation Flow

\[\boxed{ Q_t( x_t\mid x_{<t} ) \rightarrow \text{sample next token} \rightarrow \text{append context} }\]

를 반복한다.

176. Speculation Flow

\[\boxed{ \text{draft proposal} \rightarrow \text{target verification} \rightarrow \text{accept/reject correction} }\]

177. 정리

Autoregressive LLM은 매 decoding step에서 vocabulary-size logit vector를 출력한다.

\[\boxed{ \mathbf z_t \in \mathbb R^V }\]

Softmax를 적용하면

\[\boxed{ p_i = P_\theta( X_t=x_i \mid x_{<t} ) = \frac{ e^{z_i} }{ \sum_j e^{z_j} } }\]

라는 next-token conditional categorical distribution을 얻는다.

이는 일반적인 Bayesian 의미의 posterior라고 부를 필요는 없다.

Temperature scaling은

\[\boxed{ p_i(T) = \frac{ e^{z_i/T} }{ \sum_j e^{z_j/T} } }\]

로 probability sharpness를 조절한다.

\(T>0\)에서는 token ranking은 변하지 않지만 probability ratio

\[\frac{p_i(T)}{p_j(T)} = e^{(z_i-z_j)/T}\]

가 변한다.

Unique maximum이 있을 때

\[\boxed{ T\to0^+ }\]

이면 distribution은 maximum token의 point mass로 수렴한다.

하지만 maximum logit이 \(r\)개 tied라면 limit은 tied maxima에 각각 \(1/r\)의 probability를 준다.

반대로

\[\boxed{ T\to\infty }\]

이면 finite vocabulary에서 uniform distribution으로 수렴한다.

Temperature-scaled entropy는

\[\boxed{ \frac{dH}{dT} = \frac{ \operatorname{Var}_{p_T}(z) }{ T^3 } \ge0 }\]

를 만족한다.

따라서 entropy는 temperature에 대해 nondecreasing이며 logits가 모두 동일하지 않으면 strict increase가 나타난다.

Top-\(k\)는 상위 \(k\)개 token만 유지한다.

\[\boxed{ S_k = \{ x_{(1)},\dots,x_{(k)} \} }\]

Top-\(p\)는

\[\boxed{ k^\ast = \min \left\{ k: \sum_{m=1}^{k} p_{(m)} \ge p \right\} }\]

를 만족하는 최소 candidate set을 사용한다.

따라서 Top-\(p\) candidate size는 distribution shape에 따라 동적으로 바뀐다.

원자료의 numerical example

\[\mathbf z = [4,2,1,-1]\]

을 정확히 재계산하면

\[\boxed{ p(T=1) \approx [ 0.839025, 0.113550, 0.041773, 0.005653 ] }\]

Entropy는 원자료의 0.5594가 아니라

\[\boxed{ H(T=1) \approx 0.556199 \text{ nats} }\]

또한

\[\boxed{ H(T=0.5) \approx 0.107406 }\]

이고

\[\boxed{ H(T=2) \approx 1.057255 }\]

따라서 source의 entropy numerical values에는 작은 계산 오차가 있지만

\[H(0.5)<H(1)<H(2)\]

라는 qualitative conclusion은 정확하다.

Top-\(k=2\)와 Top-\(p=0.9\)는 이 예제에서 동일하게

\[\boxed{ [ 0.880797, 0.119203, 0, 0 ] }\]

을 만든다.

Entropy는 다음과 같다.

\[\boxed{ 0.365334 \text{ nats} }\]

Min-\(p\)는 최고 token probability에 대한 relative threshold를 사용하고, presence/frequency penalty는 이전 token 사용 이력에 따라 logits를 수정할 수 있다.

단 “repetition penalty”의 exact implementation은 framework마다 다를 수 있다.

Speculative Decoding에서는 draft distribution \(q\)가 제안한 token에 대해

\[\boxed{ \alpha(x) = \min \left( 1, \frac{p(x)}{q(x)} \right) }\]

로 accept하고, rejection 시

\[\boxed{ r(x) \propto [p(x)-q(x)]_+ }\]

를 사용하면 ideal algorithm에서 target distribution \(p\)를 정확히 보존할 수 있다.

다만 exactness는 prescribed correction algorithm을 정확히 구현한다는 조건 아래의 결과다.

또한 Top-\(k\)를 항상 \(O(V\log k)\), Top-\(p\)를 항상 \(O(V\log V)\)이라고 단정할 수는 없다.

실제 GPU inference engine은 selection, partition, radix, fused kernels 등 다양한 algorithm을 사용할 수 있으므로 cost는 implementation-dependent다.

마지막으로 task별 decoding parameter는 heuristic이다.

\[\boxed{ \text{low temperature} \neq \text{guaranteed correctness} }\]

이고

\[\boxed{ \text{high temperature} \neq \text{guaranteed creativity quality} }\]

따라서 PS-13의 전체 흐름은

\[\boxed{ \text{Logits} \rightarrow \text{Softmax} \rightarrow \text{Temperature} \rightarrow \text{Candidate Filtering} \rightarrow \text{Renormalization} \rightarrow \text{Sampling} }\]

이며,

시스템 관점에서는

\[\boxed{ \text{Autoregressive Decode} \rightarrow \text{KV Cache} \rightarrow \text{Sampling Kernels} \rightarrow \text{Speculative Decoding} }\]

로 연결된다.
