ML-08 — Classification Basics & Cross-Entropy

분류 문제의 기본 구조와 확률 출력, Cross-Entropy 손실을 정리한다.

ML·딥러닝 · ML-08업데이트 2026.09.21
  • #Classification
  • #Cross-Entropy
  • #Softmax
  • #Log Loss

개념

ClassificationClassification은 입력 \(\boxed{ \mathbf x\in\mathbb R^D }\) 가 주어졌을 때, 해당 입력이 여러 개의 이산적인 Class 중 어느 Class에 속하는지 예측하는 Supervised Learning Problem이다.

Class Set을

\[\boxed{ \mathcal C = \{1,2,\dots,K\} }\]

라고 하자.

Hard Classification가장 단순한 Classification Output은 하나의 Class Index를 직접 선택하는 것이다.

\[\boxed{ \hat y = k }\]

하지만 현대 Machine Learning에서는 단순 Class 선택보다 각 Class의 Probability를 모델링하는 경우가 일반적이다.

Probabilistic Classification입력 \(\mathbf x\)가 주어졌을 때 각 Class에 속할 Conditional Probability를 모델링한다.

\[\boxed{ P( Y=k \mid \mathbf x ) }\]

for

\[k=1,\dots,K\]

표기·차원

Target VariableClassification의 Target은 연속적인 실수값이 아니라 이산적인 Class Index다.

\(\boxed{ Y\in\{1,\dots,K\} }\) Binary Classification에서는 \(\boxed{ Y\in\{0,1\} }\) 로 둘 수 있다.

Probability Vector전체 Prediction을 Vector로 쓰면

\[\boxed{ \mathbf p(\mathbf x) = \begin{bmatrix} P(Y=1\mid\mathbf x)\\ \vdots\\ P(Y=K\mid\mathbf x) \end{bmatrix} }\]

Probability Constraints각 Class Probability는

\[\boxed{ P(Y=k\mid\mathbf x)\ge0 }\]

을 만족한다.

또한

\[\boxed{ \sum_{k=1}^{K} P(Y=k\mid\mathbf x) = 1 }\]

Probability Simplex따라서 Classification Model의 Probability Output은 \(\boxed{ \mathbf p \in \Delta^{K-1} }\) 에 존재한다.

즉 \(K\)개의 Non-negative Probability가 합 1을 이루는 Simplex 위의 Vector다.

핵심 연산

Decision RuleProbability를 출력한 뒤 가장 높은 Probability를 가진 Class를 선택할 수 있다.

\[\boxed{ \hat y = \arg\max_k P(Y=k\mid\mathbf x) }\]

Probability Modeling의 장점Class Index 하나만 출력하는 것보다 Probability Distribution을 모델링하면

  • Prediction Confidence
  • Uncertainty
  • Expected Loss
  • Likelihood-Based Training

과 연결할 수 있다.

Classification의 학습 목표Training에서는 정답 Class에 높은 Probability를 부여하도록 Model Parameter를 조정한다.

즉 정답 Class를 \(c\)라고 하면

\[\boxed{ P_\theta( Y=c \mid \mathbf x ) \uparrow }\]

하도록 학습한다.

Binary Classification\(K=2\)인 경우 Binary Classification이다.

Target을 \(\boxed{ y\in\{0,1\} }\) 라고 하자.

Model이

\[\boxed{ \hat y = P_\theta( Y=1\mid\mathbf x ) }\]

를 출력한다고 하자.

Sigmoid OutputBinary Classification에서는 Logit \(z\in\mathbb R\) 을 Sigmoid에 통과시켜 Probability를 만들 수 있다.

\[\boxed{ \hat y = \sigma(z) = \frac1{1+e^{-z}} }\]

따라서

\[\boxed{ 0<\hat y<1 }\]

Probability of Class 0Class 1 Probability가 \(\hat y\) 이면 Class 0 Probability는 \(\boxed{ 1-\hat y }\) 따라서 Binary Distribution은 하나의 Scalar Probability로 표현할 수 있다.

Bernoulli PMFBinary Target \(y\in\{0,1\}\) 의 Bernoulli PMF는

\[\boxed{ P(Y=y\mid\mathbf x) = \hat y^y (1-\hat y)^{1-y} }\]

Bernoulli PMF — \(y=1\)만약

\[y=1\]

이면

\[P(Y=1\mid\mathbf x) = \hat y^1 (1-\hat y)^0\]

이므로

\[\boxed{ P(Y=1\mid\mathbf x) = \hat y }\]

Bernoulli PMF — \(y=0\)만약

\[y=0\]

이면

\[P(Y=0\mid\mathbf x) = \hat y^0 (1-\hat y)^1\]

이므로

\[\boxed{ P(Y=0\mid\mathbf x) = 1-\hat y }\]

Binary Cross-EntropyBinary Cross-Entropy는

\[\boxed{ \mathcal L_{\mathrm{BCE}} ( y,\hat y ) = - \left[ y\log\hat y + (1-y) \log(1-\hat y) \right] }\]

BCE — Positive Label\(y=1\)이면

\[\begin{aligned} \mathcal L_{\mathrm{BCE}} &= - [ \log\hat y+0 ]\\ &= \boxed{ -\log\hat y } \end{aligned}\]

BCE — Negative Label\(y=0\)이면

\[\begin{aligned} \mathcal L_{\mathrm{BCE}} &= - [ 0+\log(1-\hat y) ]\\ &= \boxed{ -\log(1-\hat y) } \end{aligned}\]

Correct-Class Probability 관점따라서 Binary Cross-Entropy는 항상 정답 Label에 Model이 부여한 Probability의 Negative Log와 연결된다.

\[\boxed{ \text{BCE} = -\log P_\theta( Y=y\mid\mathbf x ) }\]

Multiclass Classification\(K\ge3\)인 경우 Multiclass Classification을 생각한다.

Target Class를 \(c\in\{1,\dots,K\}\) 라고 하자.

One-Hot EncodingTarget Class를 One-Hot Vector

\[\boxed{ \mathbf y = [y_1,\dots,y_K]^T }\]

로 표현할 수 있다.

정답 Class가 \(c\)이면

\[\boxed{ y_c=1 }\]

이고

\[\boxed{ y_k=0 \quad(k\neq c) }\]

Model Probability VectorModel이 예측한 Class Probability Vector를

\[\boxed{ \hat{\mathbf y} = [ \hat y_1,\dots,\hat y_K ]^T }\]

라고 하자.

각 Probability는 \(\hat y_k\ge0\) 이고

\[\sum_k\hat y_k=1\]

SoftmaxMulticlass Classification에서는 Logit Vector

\[\boxed{ \mathbf z = [z_1,\dots,z_K]^T }\]

를 Softmax에 통과시킨다.

\[\boxed{ \hat y_k = \frac{ e^{z_k} }{ \sum_{j=1}^{K}e^{z_j} } }\]

Categorical Cross-EntropyCategorical Cross-Entropy는

\[\boxed{ \mathcal L_{\mathrm{CCE}} ( \mathbf y, \hat{\mathbf y} ) = - \sum_{k=1}^{K} y_k\log\hat y_k }\]

One-Hot CCEOne-Hot Target에서는 정답 Class \(c\)만 \(y_c=1\)이므로

\[\begin{aligned} \mathcal L_{\mathrm{CCE}} &= - \left[ y_c\log\hat y_c + \sum_{k\neq c} y_k\log\hat y_k \right]\\ &= \boxed{ -\log\hat y_c } \end{aligned}\]

Classification Loss의 핵심 구조따라서 Binary와 Multiclass 모두 기본적으로

\[\boxed{ \text{Loss} = -\log ( \text{probability assigned to correct class} ) }\]

라는 구조를 가진다.

Cross-Entropy의 정보이론적 형태두 Distribution \(P\) 와 \(Q\) 에 대해 Cross-Entropy는

\[\boxed{ H(P,Q) = -\sum_k P(k)\log Q(k) }\]

Classification에서는 Target Distribution이 \(P\), Model Prediction이 \(Q\) 역할을 한다.

Cross-Entropy는 거리인가?원자료는 Cross-Entropy를 두 Distribution 사이의 정보론적 차이를 측정하는 Loss라고 설명한다.

다만 엄밀하게 \(\boxed{ H(P,Q) }\) 는 일반적인 Metric Distance가 아니다.

예를 들어

\[H(P,P) = H(P)\]

로 일반적으로 0이 아니다.

Cross-Entropy와 KL DivergenceCross-Entropy는

\[\boxed{ H(P,Q) = H(P) + D_{KL}(P\|Q) }\]

로 분해된다.

Target Distribution \(P\)가 고정되어 있으면 \(H(P)\) 는 Model Parameter와 무관하다.

따라서

\[\boxed{ \min_QH(P,Q) \iff \min_QD_{KL}(P\|Q) }\]

핵심 식 — Classification

\[\boxed{ P(Y=k\mid\mathbf x) }\]

with

\[\boxed{ \sum_k P(Y=k\mid\mathbf x) = 1 }\]

핵심 식 — CCE

\[\boxed{ \mathcal L_{\mathrm{CCE}} = - \sum_k y_k\log\hat y_k }\]

One-Hot에서는

\[\boxed{ \mathcal L_{\mathrm{CCE}} = -\log\hat y_c }\]

핵심 식 — Bernoulli Likelihood

\[\boxed{ L(\theta) = \prod_{i=1}^{N} \hat y_i^{y_i} ( 1-\hat y_i )^{1-y_i} }\]

핵심 식 — Softmax + CCE Gradient

\[\boxed{ \nabla_{\mathbf z} \mathcal L = \hat{\mathbf y} - \mathbf y }\]

핵심 식 — LLM Token Loss

\[\boxed{ \mathcal L_t = -\log P_\theta( y_t^\ast \mid y_{<t} ) }\]

Sequence에서는

\[\boxed{ \mathcal L = -\sum_t \log P_\theta( y_t^\ast \mid y_{<t} ) }\]

성질·유도

One-Hot Target의 Entropy정답 Class가 하나로 확정된 One-Hot Distribution은

\[\boxed{ H(P)=0 }\]

따라서 이 경우

\[\boxed{ H(P,Q) = D_{KL}(P\|Q) }\]

MLE와 Cross-EntropyCross-Entropy는 단순히 경험적으로 선택한 Loss가 아니다.

Bernoulli 또는 Categorical Probabilistic Model의 Maximum Likelihood Estimation에서 자연스럽게 유도된다.

Binary DatasetBinary Classification Dataset을

\[\boxed{ \mathcal D = \{ (\mathbf x_i,y_i) \}_{i=1}^{N} }\]

라고 하자.

각 \(y_i\in\{0,1\}\)

Model Probability각 Sample에서 Model이 Class 1에 부여하는 Probability를

\[\boxed{ \hat y_i = P_\theta( Y=1\mid\mathbf x_i ) }\]

라고 하자.

Single-Sample Bernoulli Likelihood한 Sample의 Likelihood는

\[\boxed{ P_\theta( Y=y_i \mid \mathbf x_i ) = \hat y_i^{y_i} ( 1-\hat y_i )^{1-y_i} }\]

Dataset Likelihoodi.i.d. Dataset 가정 아래에서 전체 Likelihood는 Product로 분해된다.

\[\boxed{ L(\theta) = \prod_{i=1}^{N} \hat y_i^{y_i} ( 1-\hat y_i )^{1-y_i} }\]

Maximum Likelihood EstimationMLE는

\[\boxed{ \hat\theta_{\mathrm{MLE}} = \arg\max_\theta L(\theta) }\]

Product 형태를 직접 최적화하는 대신 Log를 취한다.

Log-Likelihood

\[\begin{aligned} \log L(\theta) &= \log \prod_{i=1}^{N} \hat y_i^{y_i} ( 1-\hat y_i )^{1-y_i}\\ &= \sum_{i=1}^{N} \log \left[ \hat y_i^{y_i} ( 1-\hat y_i )^{1-y_i} \right] \end{aligned}\]

Log Exponent Rule

\[\log(a^b)=b\log a\]

를 적용하면

\[\boxed{ \log L(\theta) = \sum_{i=1}^{N} \left[ y_i\log\hat y_i + (1-y_i) \log(1-\hat y_i) \right] }\]

Negative Log-LikelihoodLikelihood를 최대화하는 것은 Negative Log-Likelihood를 최소화하는 것과 같다.

\[\boxed{ -\log L(\theta) = - \sum_{i=1}^{N} \left[ y_i\log\hat y_i + (1-y_i) \log(1-\hat y_i) \right] }\]

Mean BCEDataset Size \(N\)으로 나누면

\[\boxed{ \mathcal L_{\mathrm{BCE}}(\theta) = - \frac1N \sum_{i=1}^{N} \left[ y_i\log\hat y_i + (1-y_i) \log(1-\hat y_i) \right] }\]

BCE와 MLE의 관계따라서

\[\boxed{ \text{Bernoulli MLE} \Longleftrightarrow \text{Binary Cross-Entropy minimization} }\]

Multiclass Dataset이제 각 Target이 \(K\)개 Class 중 하나라고 하자.

One-Hot Target을

\[\boxed{ \mathbf y = [y_1,\dots,y_K]^T }\]

라고 한다.

Categorical PMFModel Probability를

\[\hat y_k = P_\theta( Y=k\mid\mathbf x )\]

라고 하면 One-Hot Target의 Categorical PMF는

\[\boxed{ P_\theta( \mathbf Y=\mathbf y \mid \mathbf x ) = \prod_{k=1}^{K} \hat y_k^{y_k} }\]

왜 Product Form인가정답 Class가 \(c\)라면

\[y_c=1\]

이고 나머지는 0이므로

\[\prod_k \hat y_k^{y_k} = \hat y_c^1 \prod_{k\neq c} \hat y_k^0\]

따라서

\[\boxed{ = \hat y_c }\]

Negative LogCategorical PMF에 Negative Log를 취하면

\[\begin{aligned} -\log P_\theta( \mathbf Y=\mathbf y \mid \mathbf x ) &= -\log \prod_{k=1}^{K} \hat y_k^{y_k}\\ &= -\sum_{k=1}^{K} y_k\log\hat y_k \end{aligned}\]

CCE 유도따라서

\[\boxed{ \mathcal L_{\mathrm{CCE}} = - \sum_{k=1}^{K} y_k\log\hat y_k }\]

즉

\[\boxed{ \text{Categorical MLE} \Longleftrightarrow \text{Categorical Cross-Entropy minimization} }\]

NLL과 CCEOne-Hot Categorical Target에서는

\[\boxed{ \mathcal L_{\mathrm{CCE}} = -\log\hat y_c }\]

이므로 Sample-Level NLL과 같다.

따라서

\[\boxed{ \text{CCE} = \text{Categorical NLL} }\]

이라는 관계가 성립한다.

Softmax와 Cross-EntropyLogit Vector \(\mathbf z\) 에서 Softmax로 \(\hat{\mathbf y}\) 를 생성한다고 하자.

\[\boxed{ \hat y_k = \frac{ e^{z_k} }{ \sum_j e^{z_j} } }\]

Loss는

\[\boxed{ \mathcal L = -\sum_k y_k \log\hat y_k }\]

목표 GradientBackpropagation에서는 Logit \(z_i\) 에 대한

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_i } }\]

가 필요하다.

원자료는 이를 Softmax Derivative와 Chain Rule을 이용해 완전히 유도한다.

Softmax Diagonal DerivativeDL-03에서

\[\boxed{ \frac{ \partial\hat y_i }{ \partial z_i } = \hat y_i ( 1-\hat y_i ) }\]

를 유도했다.

Softmax Off-Diagonal Derivative\(k\neq i\)이면

\[\boxed{ \frac{ \partial\hat y_k }{ \partial z_i } = -\hat y_k\hat y_i }\]

Unified Softmax DerivativeKronecker Delta를 사용하면

\[\boxed{ \frac{ \partial\hat y_k }{ \partial z_i } = \hat y_k ( \delta_{ki}-\hat y_i ) }\]

Cross-Entropy Derivative

\[\mathcal L = -\sum_k y_k\log\hat y_k\]

이므로

\[\boxed{ \frac{ \partial\mathcal L }{ \partial\hat y_k } = -\frac{ y_k }{ \hat y_k } }\]

Chain Rule

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_i } = \sum_{k=1}^{K} \frac{ \partial\mathcal L }{ \partial\hat y_k } \frac{ \partial\hat y_k }{ \partial z_i } }\]

Diagonal / Off-Diagonal 분해원자료의 방식대로 \(k=i\)와 \(k\neq i\)를 나누면

\[\begin{aligned} \frac{ \partial\mathcal L }{ \partial z_i } &= - \frac{ y_i }{ \hat y_i } \hat y_i ( 1-\hat y_i )\\ &\quad+ \sum_{k\neq i} \left( -\frac{y_k}{\hat y_k} \right) ( -\hat y_k\hat y_i ) \end{aligned}\]

First Term첫 번째 항은 \(\boxed{ -y_i ( 1-\hat y_i ) }\) 전개하면 \(\boxed{ -y_i+y_i\hat y_i }\)

Second Term두 번째 항은

\[\boxed{ \sum_{k\neq i} y_k\hat y_i }\]

\(\hat y_i\)는 \(k\)에 의존하지 않으므로

\[\boxed{ \hat y_i \sum_{k\neq i} y_k }\]

Terms 결합따라서

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_i } = -y_i + y_i\hat y_i + \hat y_i \sum_{k\neq i} y_k }\]

One-Hot SumOne-Hot Vector는

\[\boxed{ \sum_{k=1}^{K}y_k=1 }\]

또한

\[y_i+\sum_{k\neq i}y_k=1\]

Final Scalar Gradient따라서

\[\begin{aligned} \frac{ \partial\mathcal L }{ \partial z_i } &= -y_i + \hat y_i \left( y_i+\sum_{k\neq i}y_k \right)\\ &= -y_i+\hat y_i \end{aligned}\]

즉

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_i } = \hat y_i-y_i }\]

Vector Gradient모든 Component를 모으면

\[\boxed{ \nabla_{\mathbf z} \mathcal L = \hat{\mathbf y} - \mathbf y }\]

정답 Class Gradient정답 Class를 \(c\)라고 하면

\[y_c=1\]

이므로

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_c } = \hat y_c-1 }\]

\(0<\hat y_c<1\)이므로 이 값은 음수다.

Gradient Descent에서 정답 LogitGradient Descent는

\[z_c \leftarrow z_c - \eta ( \hat y_c-1 )\]

을 수행한다.

\(\hat y_c-1<0\)이므로 \(\boxed{ z_c \text{ increases} }\) 방향이다.

오답 Class Gradient오답 Class \(k\neq c\)에서는

\[y_k=0\]

따라서

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_k } = \hat y_k >0 }\]

Gradient Descent에서 오답 Logit따라서

\[z_k \leftarrow z_k - \eta\hat y_k\]

이므로 오답 Logit은 감소하는 방향으로 업데이트된다.

Gradient Sum

\[\begin{aligned} \sum_i \frac{ \partial\mathcal L }{ \partial z_i } &= \sum_i ( \hat y_i-y_i )\\ &= 1-1\\ &= \boxed{0} \end{aligned}\]

이는 Softmax가 공통 Logit Shift에 불변인 성질과 일치한다.

“완벽한 상쇄”의 의미원자료는 Softmax의 Exponential과 Cross-Entropy의 Log가 상쇄되어 단순한 Gradient가 나온다고 설명한다.

이 직관은 유용하다.

결과적으로 복잡한 Jacobian을 명시적으로 계산하지 않고 \(\boxed{ \hat{\mathbf y}-\mathbf y }\) 형태를 얻는다.

Gradient Vanishing 보장에 대한 주의다만 원자료의

Softmax + Cross-Entropy가 Gradient Vanishing 없는 안정적인 Backpropagation을 보장한다

는 표현은 너무 강하다.

Logit Gradient는 단순해지지만 전체 Network Parameter Gradient는 이후 Jacobian Product의 영향을 받는다.

따라서

\[\boxed{ \nabla_{\mathbf z}L = \hat y-y }\]

만으로 깊은 Network 전체에서 Gradient Vanishing이 발생하지 않는다고 보장할 수는 없다.

Correct-Class Gradient Saturation정답 Probability가 이미

\[\hat y_c\approx1\]

이면

\[\boxed{ \hat y_c-1 \approx0 }\]

이는 Prediction이 이미 Target에 가까울 때 해당 Sample의 Logit Gradient가 작아지는 자연스러운 결과다.

Highly Wrong Prediction정답 Class Probability가

\[\hat y_c\approx0\]

이면

\[\boxed{ \hat y_c-1 \approx-1 }\]

따라서 정답 Logit에 대해 비교적 큰 Correction Signal이 생긴다.

혼동하기 쉬운 부분 — Classification과 RegressionClassification에서는 Target이 이산 Class이고 Model이 Class Probability를 출력하는 구조가 중심이다.

Regression에서는 일반적으로 Continuous Target을 예측한다.

Loss와 Output Distribution도 이에 따라 달라진다.

혼동하기 쉬운 부분 — Probability와 Class Prediction\(\boxed{ \hat{\mathbf y} }\) 는 Probability Distribution이고 \(\boxed{ \arg\max_k\hat y_k }\) 는 최종 Class Decision이다.

둘은 같은 객체가 아니다.

혼동하기 쉬운 부분 — Cross-Entropy와 DistanceCross-Entropy는 흔히 두 Distribution의 차이를 나타낸다고 설명하지만 Euclidean Distance 같은 Metric은 아니다.

특히

\[H(P,P) = H(P)\]

이므로 일반적으로 0이 아니다.

혼동하기 쉬운 부분 — CCE와 KL일반적으로

\[\boxed{ H(P,Q) = H(P) + D_{KL}(P\|Q) }\]

즉 CCE와 KL은 동일한 Quantity가 아니다.

One-Hot Target처럼

\[H(P)=0\]

인 특수한 경우에는 수치적으로 같아질 수 있다.

혼동하기 쉬운 부분 — Cross-Entropy와 NLLOne-Hot Categorical Classification에서는

\[\boxed{ \text{CCE} = \text{NLL} }\]

하지만 모든 Cross-Entropy 문제를 단일 관측의 NLL과 무조건 같은 개념으로 취급하면 안 된다.

혼동하기 쉬운 부분 — \(p-y\)

\[\boxed{ \nabla_zL=p-y }\]

는 Softmax 자체의 Derivative가 아니다.

Softmax 자체의 Jacobian은

\[\boxed{ J = \operatorname{diag}(p) - pp^T }\]

\(p-y\)는 Softmax와 Cross-Entropy를 결합한 결과다.

혼동하기 쉬운 부분 — Gradient Vanishing\(p-y\)가 단순하다고 해서 Deep Network 전체에서 Gradient Vanishing이 불가능해지는 것은 아니다.

Logit 이전 Layer들에 대한 Gradient는 Chain Rule로 추가 Jacobian을 거친다.

혼동하기 쉬운 부분 — One-Hot LabelOne-Hot Label은 Model의 Prediction Probability가 아니다.

이는 Training Target을 Distribution 형태로 표현한 것이다.

\[\boxed{ \mathbf y = [0,\dots,1,\dots,0] }\]

혼동하기 쉬운 부분 — Label SmoothingLabel Smoothing은 항상 좋은 것은 아니다.

강한 Smoothing은 Task에 따라 Discrimination이나 Probability Structure를 저해할 수 있다.

따라서 \(\epsilon\)은 Hyperparameter다.

혼동하기 쉬운 부분 — LLM과 ClassificationLLM Next-Token Prediction은 Vocabulary Token을 Class로 보는 관점에서 Categorical Classification과 동일한 수학 구조를 가진다.

하지만 전체 Language Modeling은 단일 독립 Classification 문제가 아니라 Context-Conditioned Sequence Modeling이다.

Classification은 입력 \(\mathbf x\) 가 주어졌을 때 이산 Class \(\boxed{ Y\in\{1,\dots,K\} }\) 를 예측하는 Supervised Learning Problem이다.

현대적인 Classification Model은 단순 Class Index보다

\[\boxed{ P( Y=k\mid\mathbf x ) }\]

라는 Conditional Probability Distribution을 모델링한다.

Binary Classification에서는

\[\boxed{ \hat y = P(Y=1\mid\mathbf x) }\]

를 사용하고 Bernoulli PMF는

\[\boxed{ P(Y=y\mid\mathbf x) = \hat y^y ( 1-\hat y )^{1-y} }\]

Negative Log를 취하면

\[\boxed{ \mathcal L_{\mathrm{BCE}} = - [ y\log\hat y + (1-y)\log(1-\hat y) ] }\]

를 얻는다.

Multiclass Classification에서는 One-Hot Target \(\mathbf y\) 와 Softmax Probability \(\hat{\mathbf y}\) 를 사용한다.

Categorical PMF는

\[\boxed{ P( \mathbf Y=\mathbf y \mid\mathbf x ) = \prod_k \hat y_k^{y_k} }\]

Negative Log를 취하면

\[\boxed{ \mathcal L_{\mathrm{CCE}} = -\sum_k y_k\log\hat y_k }\]

를 얻는다.

One-Hot Target에서는 정답 Class \(c\)만 남아서

\[\boxed{ \mathcal L_{\mathrm{CCE}} = -\log\hat y_c }\]

따라서 Classification에서 Cross-Entropy는 Bernoulli/Categorical Maximum Likelihood와 직접 연결된다.

Softmax는

\[\boxed{ \hat y_k = \frac{ e^{z_k} }{ \sum_j e^{z_j} } }\]

Softmax Derivative와 Cross-Entropy의 Chain Rule을 결합하면

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_i } = \hat y_i-y_i }\]

를 얻는다.

Vector Form은

\[\boxed{ \nabla_{\mathbf z} \mathcal L = \hat{\mathbf y} - \mathbf y }\]

원자료의 수치 예제에서는

\[\boxed{ \mathbf z = [2.0,1.0,0.1]^T }\]

이고 Softmax Probability는

\[\boxed{ \hat{\mathbf y} \approx [0.6590,0.2424,0.0986]^T }\]

정답이 Class 1이면

\[\boxed{ \mathcal L = -\ln0.6590 \approx 0.4170 }\]

이고

\[\boxed{ \nabla_{\mathbf z}\mathcal L \approx [-0.3410,0.2424,0.0986]^T }\]

따라서 Gradient Descent는 정답 Logit을 증가시키고 오답 Logit들을 감소시키는 방향으로 작용한다.

LLM에서는 Vocabulary의 각 Token을 Class로 볼 수 있다.

Position \(t\)의 Logit \(\mathbf z_t\in\mathbb R^V\) 에 Softmax를 적용하면

\[\boxed{ P_\theta( Y_t\mid y_{<t} ) }\]

를 얻는다.

정답 Token \(y_t^\ast\)에 대한 Loss는

\[\boxed{ \mathcal L_t = -\log P_\theta( y_t^\ast \mid y_{<t} ) }\]

따라서 LLM의 Autoregressive Next-Token Training은 매 Token Position에서 거대한 Categorical Cross-Entropy/NLL Problem을 해결하는 구조를 가진다.

Label Smoothing에서는 One-Hot Target을

\[\boxed{ \mathbf y_{\mathrm{smooth}} = (1-\epsilon)\mathbf y + \frac{\epsilon}{V} \mathbf1 }\]

로 바꾼다.

이는 Target Probability Mass 일부를 다른 Class에도 배분하여 극단적인 One-Hot Target을 완화한다.

다만 Label Smoothing이 항상 Generalization을 최대로 만든다는 보편적 정리는 아니며 \(\epsilon\)은 Model과 Task에 따라 조정해야 한다.

ML-08의 전체 흐름은

\[\boxed{ \text{Classification} \rightarrow \text{Conditional Probability} \rightarrow \text{Likelihood} \rightarrow \text{Cross-Entropy / NLL} }\]

Optimization 관점에서는

\[\boxed{ \text{Logits} \rightarrow \text{Softmax} \rightarrow \text{Cross-Entropy} \rightarrow \hat{\mathbf y}-\mathbf y }\]

LLM 관점에서는

\[\boxed{ \text{Context} \rightarrow \text{Vocabulary Logits} \rightarrow \text{Softmax} \rightarrow \text{Next-Token Probability} \rightarrow \text{Categorical NLL} }\]

로 그대로 확장된다.

예제·적용

Numerical Example — Setup원자료의 Example은

\[\boxed{ K=3 }\]

Class Classification이다.

Logit은

\[\boxed{ \mathbf z = \begin{bmatrix} 2.0\\ 1.0\\ 0.1 \end{bmatrix} }\]

Target은

\[\boxed{ \mathbf y = \begin{bmatrix} 1\\ 0\\ 0 \end{bmatrix} }\]

Exponential — Class 1

\[\boxed{ e^{2.0} \approx 7.3891 }\]

Exponential — Class 2

\[\boxed{ e^{1.0} \approx 2.7183 }\]

Exponential — Class 3

\[\boxed{ e^{0.1} \approx 1.1052 }\]

Exponential Sum

\[\begin{aligned} Z &= 7.3891 + 2.7183 + 1.1052\\ &= \boxed{ 11.2126 } \end{aligned}\]

First Softmax Probability

\[\begin{aligned} \hat y_1 &= \frac{7.3891}{11.2126}\\ &\approx \boxed{ 0.6590 } \end{aligned}\]

Second Softmax Probability

\[\begin{aligned} \hat y_2 &= \frac{2.7183}{11.2126}\\ &\approx \boxed{ 0.2424 } \end{aligned}\]

Third Softmax Probability

\[\begin{aligned} \hat y_3 &= \frac{1.1052}{11.2126}\\ &\approx \boxed{ 0.0986 } \end{aligned}\]

Probability Vector따라서

\[\boxed{ \hat{\mathbf y} = \begin{bmatrix} 0.6590\\ 0.2424\\ 0.0986 \end{bmatrix} }\]

Probability Sum은

\[\boxed{ 0.6590+0.2424+0.0986 = 1.0000 }\]

CCE Loss정답은 Class 1이므로

\[\mathcal L = -\log\hat y_1\]

따라서

\[\begin{aligned} \mathcal L &= -\ln(0.6590)\\ &\approx \boxed{ 0.4170 } \end{aligned}\]

Gradient

\[\nabla_{\mathbf z}\mathcal L = \hat{\mathbf y} - \mathbf y\]

이므로

\[\boxed{ \nabla_{\mathbf z} \mathcal L = \begin{bmatrix} -0.3410\\ 0.2424\\ 0.0986 \end{bmatrix} }\]

Class 1 UpdateClass 1 Gradient는 \(\boxed{ -0.3410 }\) 따라서 Gradient Descent에서는 \(z_1\)이 증가하는 방향으로 이동한다.

Class 2 UpdateClass 2 Gradient는 \(\boxed{ 0.2424 }\) 따라서 Gradient Descent에서 \(z_2\)는 감소하는 방향으로 이동한다.

Class 3 UpdateClass 3 Gradient는 \(\boxed{ 0.0986 }\) 따라서 \(z_3\)도 감소하는 방향으로 이동한다.

Gradient Magnitude의 의미오답 Class 중에서도 Probability가 높은 Class가 더 큰 Positive Gradient를 받는다.

이 예제에서는

\[0.2424 > 0.0986\]

이므로 Class 2 Logit이 Class 3보다 더 강하게 감소하는 방향의 Signal을 받는다.

DL-03과 연결DL-03에서는 Softmax Mechanism 자체를 유도했다.

\[\boxed{ \mathbf z \rightarrow \operatorname{Softmax} \rightarrow \hat{\mathbf y} }\]

ML-08에서는 여기에 Classification Target과 Likelihood를 붙인다.

\[\boxed{ \hat{\mathbf y} + \mathbf y \rightarrow \text{Cross-Entropy} }\]

ML-01과 연결ML-01에서 Empirical Risk는

\[\boxed{ \mathcal R_{\mathrm{emp}} = \frac1N \sum_i \mathcal L_i }\]

였다.

Classification에서는 \(\mathcal L_i\)로 BCE 또는 CCE를 사용할 수 있다.

따라서

\[\boxed{ \text{Cross-Entropy} \rightarrow \text{Empirical Risk} \rightarrow \text{ERM} }\]

으로 연결된다.

PS-11과 연결Likelihood를 최대화하는 것은 NLL을 최소화하는 것과 같다.

\[\boxed{ \arg\max_\theta L(\theta) = \arg\min_\theta [-\log L(\theta)] }\]

Classification Cross-Entropy가 MLE에서 나오는 이유가 바로 이 관계다.

Information Theory와 연결Cross-Entropy는

\[\boxed{ H(P,Q) = H(P) + D_{KL}(P\|Q) }\]

Target Distribution \(P\)가 고정되어 있으면 Cross-Entropy를 줄이는 것은 Model Distribution \(Q\)가 Target Distribution에 가까워지도록 만드는 것과 연결된다.

LLM Classification 관점Autoregressive LLM의 Next-Token Prediction은 Vocabulary의 각 Token을 하나의 Class로 보면 거대한 Multiclass Classification Problem으로 해석할 수 있다.

Vocabulary Size를 \(\boxed{ V }\) 라고 하자.

Vocabulary LogitsPosition \(t\)에서 Model은

\[\boxed{ \mathbf z_t \in \mathbb R^V }\]

의 Vocabulary Logit Vector를 출력한다.

Next-Token SoftmaxSoftmax를 적용하면

\[\boxed{ P_\theta( Y_t=k \mid y_{<t} ) = \frac{ e^{z_{t,k}} }{ \sum_{j=1}^{V} e^{z_{t,j}} } }\]

Target Token실제 정답 Token Index를 \(\boxed{ y_t^\ast }\) 라고 하자.

이 Target은 \(V\)차원 One-Hot Distribution으로 표현할 수 있다.

Token-Level Cross-Entropy한 Position의 Cross-Entropy는

\[\boxed{ \mathcal L_t = -\log P_\theta( y_t^\ast \mid y_{<t} ) }\]

즉 Vocabulary 전체에 대한 Categorical NLL이다.

Sequence Loss길이 \(T\)의 Sequence에서는

\[\boxed{ \mathcal L_{\mathrm{seq}} = -\sum_{t=1}^{T} \log P_\theta( y_t^\ast \mid y_{<t} ) }\]

원자료의 LLM 식도 이 형태다.

Mean Token Loss실제 Training에서는 유효 Token 수로 평균내어

\[\boxed{ \bar{\mathcal L} = -\frac1T \sum_{t=1}^{T} \log P_\theta( y_t^\ast \mid y_{<t} ) }\]

형태를 사용할 수 있다.

Pre-training과 SFT동일한 Next-Token Cross-Entropy 구조는

  • Autoregressive Pre-training
  • Supervised Fine-Tuning

모두에서 사용할 수 있다.

차이는 주로 어떤 Data와 Masking/Target Construction을 사용하는지에 있다.

“SFT의 핵심 목적함수”의 의미원자료는 이 Categorical NLL을 SFT의 핵심 Objective라고 설명한다.

이는 일반적인 Decoder-only SFT에서 맞는 구조다.

다만 모든 Alignment Method가 동일하게 단순 CCE만 사용하는 것은 아니다.

LLM Logit GradientToken Position \(t\)에서 Model Probability를 \(\mathbf p_t\) Target One-Hot을 \(\mathbf y_t\) 라고 하면

\[\boxed{ \nabla_{\mathbf z_t} \mathcal L_t = \mathbf p_t-\mathbf y_t }\]

Vocabulary Size와 GradientVocabulary가 매우 커져도 Logit-Level Gradient 구조는 동일하다.

\[\boxed{ \text{predicted probability} - \text{target distribution} }\]

Label Smoothing원자료는 One-Hot Target 대신 Label Smoothing을 적용하는 방법을 소개한다.

Smoothing Parameter를 \(\boxed{ \epsilon }\) 이라고 하자.

Label Smoothing Formula원자료의 정의는

\[\boxed{ \mathbf y_{\mathrm{smooth}} = (1-\epsilon)\mathbf y + \frac{\epsilon}{V} \mathbf1 }\]

Sum CheckOne-Hot Vector는

\[\sum_k y_k=1\]

이고

\[\sum_k \frac{\epsilon}{V} = \epsilon\]

따라서

\[\begin{aligned} \sum_k y_{\mathrm{smooth},k} &= (1-\epsilon) + \epsilon\\ &= \boxed{1} \end{aligned}\]

Correct-Class Target정답 Class \(c\)의 Smoothed Probability는

\[\boxed{ y_{\mathrm{smooth},c} = 1-\epsilon + \frac{\epsilon}{V} }\]

Incorrect-Class Target오답 Class \(k\neq c\)에서는

\[\boxed{ y_{\mathrm{smooth},k} = \frac{\epsilon}{V} }\]

따라서 Target Distribution이 완전한 One-Hot에서 약간 퍼진 Distribution으로 바뀐다.

Smoothed Cross-EntropyLoss는

\[\boxed{ \mathcal L_{\mathrm{smooth}} = - \sum_{k=1}^{V} y_{\mathrm{smooth},k} \log p_k }\]

Label Smoothing GradientSoftmax + Cross-Entropy의 동일한 구조를 적용하면

\[\boxed{ \nabla_{\mathbf z} \mathcal L_{\mathrm{smooth}} = \mathbf p - \mathbf y_{\mathrm{smooth}} }\]

Correct-Class Gradient 변화One-Hot에서는 정답 Class Gradient가 \(p_c-1\) 이었다.

Label Smoothing에서는

\[\boxed{ p_c - \left( 1-\epsilon+\frac{\epsilon}{V} \right) }\]

Target Probability가 정확히 1보다 작아진다.

Infinite Logit Margin과의 관계One-Hot Cross-Entropy에서는 Training Sample에 대해 정답 Probability를 계속 1에 가깝게 만들수록 Loss가 감소한다.

Linear-Separable Setting 등에서는 이는 Logit Margin이 계속 커지는 방향과 연결될 수 있다.

Label Smoothing은 Target을 완전한 One-Hot에서 벗어나게 하므로 이러한 극단적 확신을 줄이는 방향으로 작용할 수 있다.

Label Smoothing과 Overconfidence원자료는 Label Smoothing을 모델의 과도한 확신을 줄이는 방법으로 설명한다.

즉

\[\boxed{ \text{one-hot target} \rightarrow \text{smoothed target} }\]

을 통해 모든 Probability Mass를 정답 하나에만 요구하지 않는다.

Generalization 주장에 대한 주의원자료는 Label Smoothing이 Generalization Performance를 “극대화”한다고 표현한다.

하지만

\[\boxed{ \text{label smoothing} \Rightarrow \text{always maximum generalization} }\]

이라는 보편적인 정리는 아니다.

효과는 Dataset, Model, Calibration, Task 등에 의존한다.

Classification Accuracy와 Cross-EntropyAccuracy는

\[\boxed{ \mathbf1[ \hat y=y ] }\]

형태로 Correct/Incorrect만 평가한다.

Cross-Entropy는 Probability Magnitude까지 평가한다.

같은 Accuracy, 다른 Cross-Entropy두 Model이 모두 정답 Class를 Argmax로 선택하더라도 Model A:

\[p_c=0.9\]

Model B:

\[p_c=0.51\]

이라면 둘의 Accuracy는 동일할 수 있지만 Cross-Entropy는 다르다.

\[-\log0.9 < -\log0.51\]

Cross-Entropy의 민감도정답 Probability가 작을수록 Loss는 빠르게 증가한다.

\[\boxed{ p_c\rightarrow0^+ \Rightarrow -\log p_c \rightarrow\infty }\]

즉 정답에 극도로 낮은 Probability를 부여한 Prediction을 크게 Penalize한다.

Cross-Entropy MinimumOne-Hot Target에서 이상적으로

\[p_c\rightarrow1\]

이면

\[\boxed{ -\log p_c \rightarrow0 }\]

따라서 최소 가능한 Sample Loss는 0의 극한이다.

BCE vs CCEBinary Classification: \(\boxed{ -y\log p - (1-y)\log(1-p) }\) Multiclass Classification:

\[\boxed{ -\sum_k y_k\log p_k }\]

두 식 모두 Categorical/Bernoulli NLL이라는 공통 구조를 가진다.

Binary Softmax와 Sigmoid\(K=2\)인 Softmax는 두 Logit의 Difference를 이용해 Sigmoid 형태로 표현할 수 있다.

따라서 Binary Logistic Regression과 2-Class Softmax Classification은 밀접한 관계를 가진다.

Logit Difference두 Logit을 \(z_0,z_1\) 이라고 하면

\[P(Y=1) = \frac{ e^{z_1} }{ e^{z_0}+e^{z_1} }\]

분자·분모에 \(e^{-z_0}\)를 곱하면

\[\boxed{ P(Y=1) = \frac1{ 1+e^{-(z_1-z_0)} } }\]

Sigmoid Connection따라서

\[\boxed{ P(Y=1) = \sigma( z_1-z_0 ) }\]

즉 Binary Softmax는 Logit Difference의 Sigmoid로 볼 수 있다.

Numerical Stability실제 구현에서는 \(\operatorname{Softmax} + \log\) 를 분리해 Naive하게 계산하기보다 Stable Log-Softmax 또는 Fused Cross-Entropy를 사용하는 것이 일반적이다.

이는 DL-03의 Log-Sum-Exp Trick과 연결된다.

Stable CCE정답 Class \(c\)에 대해

\[\mathcal L = -\log \frac{ e^{z_c} }{ \sum_j e^{z_j} }\]

Log를 전개하면

\[\boxed{ \mathcal L = -z_c + \log \sum_j e^{z_j} }\]

Stable Log-Sum-Exp

\[m=\max_jz_j\]

라고 하면

\[\boxed{ \log \sum_j e^{z_j} = m + \log \sum_j e^{z_j-m} }\]

따라서 Overflow를 피하면서 CCE를 계산할 수 있다.

Cross-Entropy와 CalibrationCross-Entropy는 단순 Argmax Correctness뿐 아니라 Probability Assignment를 평가한다.

따라서 Probability Calibration과도 관련이 있다.

하지만 낮은 Cross-Entropy만으로 Model이 모든 의미에서 완벽히 Calibration되었다고 단정하지 않는다.

ML-08 전체 흐름Classification에서는

\[\boxed{ \mathbf x \rightarrow \text{logits} \rightarrow \text{probabilities} }\]

를 계산한다.

Target과 비교하면

\[\boxed{ \text{probabilities} + \text{target} \rightarrow \text{Cross-Entropy} }\]

MLE 연결Probabilistic Model 관점에서는

\[\boxed{ \text{Bernoulli / Categorical likelihood} \rightarrow \log \rightarrow \text{NLL} \rightarrow \text{Cross-Entropy} }\]

Backpropagation 연결Softmax와 CCE를 결합하면

\[\boxed{ \text{Softmax Jacobian} + \text{CCE derivative} \rightarrow \hat y-y }\]

따라서

\[\boxed{ \nabla_zL = \hat y-y }\]

LLM 연결Autoregressive LLM에서는

\[\boxed{ \text{Hidden State} \rightarrow \text{Vocabulary Logits} \rightarrow \text{Softmax} }\]

를 통해

\[\boxed{ P_\theta( Y_t\mid Y_{<t} ) }\]

를 만든다.

정답 Token에 대해

\[\boxed{ -\log P_\theta( y_t^\ast\mid y_{<t} ) }\]

를 계산한다.

정리

Classification은 입력에서 class label 또는 class probability를 예측하고, 확률 출력은 결정 규칙과 별도로 평가한다. Categorical target에 대한 cross-entropy는 target 확률에 해당하는 예측 log-probability를 벌점화하므로, one-hot·soft target·threshold 선택을 구분해야 한다.
