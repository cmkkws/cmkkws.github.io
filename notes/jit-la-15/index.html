LA-15 — Eigenvalues and Eigenvectors

고유값과 고유벡터, 고유공간 및 스펙트럼 성질을 정리한다.

수정 2026.09.21약 59분상태 작성 완료
학습 내용
  • Eigenvalue와 Eigenvector
  • 왜 정방행렬인가
  • Eigenvector는 Zero Vector가 아니다
  • Eigenvalue Equation의 의미

Eigenvalue와 Eigenvector

정방행렬

\[\boxed{ A\in\mathbb R^{N\times N} }\]

을 생각하자. 0이 아닌 Vector

\[\boxed{ \mathbf x\neq\mathbf0 }\]

가

\[\boxed{ A\mathbf x = \lambda\mathbf x }\]

를 만족한다면, \(\lambda\)를 Eigenvalue, \(\mathbf x\)를 \(\lambda\)에 대응하는 Eigenvector​라고 한다.

왜 정방행렬인가

Eigenvalue Equation

\[A\mathbf x = \lambda\mathbf x\]

에서 좌변과 우변의 Dimension이 같아야 한다.

\[\mathbf x\in\mathbb R^N\]

이면

\[A\mathbf x\in\mathbb R^N\]

이어야 하므로

\[\boxed{ A\in\mathbb R^{N\times N} }\]

인 Square Matrix가 필요하다.

Eigenvector는 Zero Vector가 아니다

만약

\[\mathbf x=\mathbf0\]

을 허용하면 모든 \(\lambda\)에 대해

\[A\mathbf0 = \lambda\mathbf0 = \mathbf0\]

이 성립한다. 그러면 Eigenvalue를 구별할 수 없다. 따라서 정의에서 반드시

\[\boxed{ \mathbf x\neq\mathbf0 }\]

를 요구한다.

Eigenvalue Equation의 의미

일반적인 Vector \(\mathbf v\)는 Linear Transformation \(A\)를 거치면서 방향과 크기가 모두 바뀔 수 있다. 하지만 Eigenvector는

\[\boxed{ A\mathbf x = \lambda\mathbf x }\]

이므로 변환 결과가 원래 Vector의 Scalar Multiple이다. 즉 해당 1차원 Subspace가 \(A\)에 의해 보존된다.

Invariant Direction

따라서 Eigenvector를 단순히 “회전하지 않는 축”이라고 표현하기보다

\[\boxed{ \operatorname{span}(\mathbf x) \text{가 }A\text{에 대해 invariant하다} }\]

라고 표현하는 것이 더 정확하다.

Positive Eigenvalue

만약

\[\lambda>0\]

이면

\[A\mathbf x\]

는 \(\mathbf x\)와 같은 방향에 있다. 특히

\[\lambda>1\]

이면 크기가 증가하고,

\[0<\lambda<1\]

이면 크기가 감소한다.

Negative Eigenvalue

만약

\[\lambda<0\]

이면

\[A\mathbf x = \lambda\mathbf x\]

는 반대 방향을 향한다. 크기는

\[\boxed{ |\lambda| }\]

배가 된다.

Zero Eigenvalue

만약

\[\lambda=0\]

이면 다음과 같다.

\[\boxed{ A\mathbf x=\mathbf0 }\]

즉 Eigenvector가 Null Space 안에 존재한다. 따라서 다음과 같다.

\[\boxed{ 0\text{ is an eigenvalue} \iff A\text{ is singular} }\]

Complex Eigenvalue

Real Matrix라도 Eigenvalue가 항상 Real인 것은 아니다. 예를 들어 Rotation Matrix는 Complex Eigenvalue를 가질 수 있다. 따라서 일반적으로

\[\boxed{ \lambda\in\mathbb C }\]

일 수 있다. 이 경우 대응 Eigenvector 역시 일반적으로

\[\boxed{ \mathbf x\in\mathbb C^N }\]

에서 고려해야 한다.

원자료 정의의 보완

원자료는

\[\mathbf x\in\mathbb R^N\]

과

\[\lambda\in\mathbb R \text{ 또는 } \mathbb C\]

를 동시에 적고 있다. 엄밀하게는 Complex Eigenvalue를 허용할 경우 Vector Space도

\[\boxed{ \mathbb C^N }\]

으로 확장하는 것이 자연스럽다.

Eigenvector Scaling

만약

\[A\mathbf x = \lambda\mathbf x\]

이고 \(c\neq0\)이면 다음과 같다.

\[A(c\mathbf x) = cA\mathbf x = c\lambda\mathbf x = \lambda(c\mathbf x)\]

따라서

\[\boxed{ c\mathbf x }\]

도 같은 Eigenvalue \(\lambda\)의 Eigenvector다.

Eigenvector는 유일하지 않다

따라서 Eigenvector는 보통 하나의 Vector 자체보다

\[\boxed{ \operatorname{span}(\mathbf x) }\]

라는 방향 또는 Subspace 관점으로 보는 것이 중요하다.

Eigenspace

특정 Eigenvalue \(\lambda\)에 대해

\[\boxed{ E_\lambda = \{ \mathbf x: A\mathbf x = \lambda\mathbf x \} }\]

를 생각한다. Zero Vector까지 포함하면 이 집합은 Subspace가 된다.

Eigenspace와 Null Space

Eigenvalue Equation을 정리하면 다음과 같다.

\[A\mathbf x - \lambda\mathbf x = 0\]

Identity Matrix를 사용하면 다음과 같다.

\[\boxed{ (A-\lambda I)\mathbf x = 0 }\]

따라서 다음과 같다.

\[\boxed{ E_\lambda = \mathcal N( A-\lambda I ) }\]

Eigenspace가 Subspace인 이유

Null Space는 항상 Subspace다. 따라서

\[\boxed{ E_\lambda = \mathcal N(A-\lambda I) }\]

도 Subspace다.

Characteristic Equation의 출발점

Eigenvalue Equation은 다음과 같다.

\[\boxed{ A\mathbf x = \lambda\mathbf x }\]

이를 한쪽으로 이동하면 다음과 같다.

\[\boxed{ (A-\lambda I)\mathbf x = 0 }\]

Nontrivial Solution 조건

Eigenvector는

\[\mathbf x\neq0\]

이어야 한다. 따라서 Homogeneous System

\[(A-\lambda I)\mathbf x = 0\]

이 Nontrivial Solution을 가져야 한다.

Singular Matrix 조건

Homogeneous System이 Nontrivial Solution을 가지려면

\[A-\lambda I\]

의 Null Space가 자명하지 않아야 한다. 즉

\[\boxed{ A-\lambda I \text{ is singular} }\]

이어야 한다.

Determinant Condition

Square Matrix가 Singular할 필요충분조건은 Determinant가 0인 것이다. 따라서

\[\boxed{ \det( A-\lambda I ) = 0 }\]

이어야 한다.

Characteristic Equation

따라서 Eigenvalue는

\[\boxed{ \det( A-\lambda I ) = 0 }\]

의 해다. 이 식을 Characteristic Equation이라고 한다.

Characteristic Polynomial

\[\boxed{ p(\lambda) = \det( A-\lambda I ) }\]

를 Characteristic Polynomial이라고 할 수 있다. \(N\times N\) Matrix에서는 \(\lambda\)에 대한 Degree \(N\) Polynomial이다.

다른 부호 Convention

다음 Convention도 많이 사용한다.

\[\boxed{ p_A(\lambda) = \det( \lambda I-A ) }\]

두 Polynomial은

\[\boxed{ \det(A-\lambda I) = (-1)^N \det(\lambda I-A) }\]

관계다. 따라서 Root, 즉 Eigenvalue는 동일하다.

Fundamental Theorem of Algebra

복소수 범위에서는 Degree \(N\) Polynomial이 Multiplicity를 포함하여 정확히 \(N\)개의 Root를 가진다. 따라서 \(N\times N\) Matrix는 Algebraic Multiplicity를 세면

\[\boxed{ N }\]

개의 Complex Eigenvalue를 가진다.

Algebraic Multiplicity

Eigenvalue \(\lambda\)가 Characteristic Polynomial의 Root로 몇 번 반복되는지를

\[\boxed{ \text{Algebraic Multiplicity} }\]

라고 한다.

Geometric Multiplicity

Eigenspace의 Dimension

\[\boxed{ \dim E_\lambda }\]

을 Geometric Multiplicity라고 한다. 즉 다음과 같다.

\[\boxed{ \operatorname{GM}(\lambda) = \dim \mathcal N(A-\lambda I) }\]

두 Multiplicity의 관계

항상 다음과 같다.

\[\boxed{ 1 \le \operatorname{GM}(\lambda) \le \operatorname{AM}(\lambda) }\]

Repeated Eigenvalue가 있다고 해서 반드시 여러 개의 독립 Eigenvector가 존재하는 것은 아니다.

Trace와 Eigenvalue

Algebraic Multiplicity를 포함하면 다음과 같다.

\[\boxed{ \operatorname{Tr}(A) = \sum_{i=1}^{N} \lambda_i }\]

원자료의 핵심 성질 중 하나다.

Determinant와 Eigenvalue

마찬가지로 다음과 같다.

\[\boxed{ \det(A) = \prod_{i=1}^{N} \lambda_i }\]

Trace는 Basis-Invariant

Matrix Representation은 Basis에 따라 바뀔 수 있지만 Similar Matrix는 같은 Trace를 가진다. 따라서 Eigenvalue의 합 역시 Linear Operator 자체의 성질과 연결된다.

Determinant의 기하학적 의미

Determinant는 Linear Transformation의 Signed Volume Scaling Factor와 연결된다. Eigenvalue가 존재하는 방향별 Scaling을 생각하면

\[\boxed{ \det(A) = \prod_i\lambda_i }\]

라는 관계를 직관적으로 이해할 수 있다. 단, 이 직관은 Diagonalizable Case에서 가장 직접적이다.

서로 다른 Eigenvalue

다음과 같이 서로 다른 Eigenvalue가 있다고 하자.

\[\boxed{ \lambda_1,\dots,\lambda_k }\]

그리고 대응 Eigenvector를

\[\boxed{ \mathbf x_1,\dots,\mathbf x_k }\]

라고 하자.

Linear Independence Theorem

서로 다른 Eigenvalue에 대응하는 Eigenvector들은 항상 Linearly Independent하다. 즉 다음과 같다.

\[\boxed{ \lambda_i\neq\lambda_j \Rightarrow \{ x_1,\dots,x_k \} \text{ linearly independent} }\]

증명의 시작

다음 Linear Combination이 있다고 하자.

\[\boxed{ c_1x_1+\cdots+c_kx_k=0 }\]

목표는

\[c_1=\cdots=c_k=0\]

임을 보이는 것이다.

양변에 \(A\) 적용

각 Eigenvector에 대해

\[Ax_i = \lambda_i x_i\]

이므로 다음과 같다.

\[\boxed{ c_1\lambda_1x_1 + \cdots+ c_k\lambda_kx_k = 0 }\]

원래 식에 \(\lambda_k\) 곱하기

원래 Linear Combination에 \(\lambda_k\)를 곱하면 다음과 같다.

\[\boxed{ c_1\lambda_kx_1 + \cdots+ c_k\lambda_kx_k = 0 }\]

두 식의 차

두 식을 빼면 \(x_k\) 항이 사라진다 다음과 같다.

\[\boxed{ \sum_{i=1}^{k-1} c_i( \lambda_i-\lambda_k ) x_i = 0 }\]

Induction 적용

\(x_1,\dots,x_{k-1}\)가 Linearly Independent하다고 가정하면 각 Coefficient는 0이어야 한다 다음과 같다.

\[\boxed{ c_i( \lambda_i-\lambda_k ) = 0 }\]

Distinct Eigenvalue 조건

\[\lambda_i\neq\lambda_k\]

이므로 다음과 같다.

\[\boxed{ \lambda_i-\lambda_k\neq0 }\]

따라서

\[\boxed{ c_i=0 }\]

for 다음과 같다.

\[i=1,\dots,k-1\]

마지막 Coefficient

원래 식에 다시 대입하면 다음과 같다.

\[c_kx_k=0\]

\(x_k\neq0\)이므로 다음과 같다.

\[\boxed{ c_k=0 }\]

결론

따라서 다음과 같다.

\[\boxed{ x_1,\dots,x_k \text{ are linearly independent} }\]

원자료의 귀납법 증명과 동일한 핵심 구조다.

Distinct Eigenvalue와 Diagonalization

\(N\times N\) Matrix가 서로 다른 Eigenvalue를 정확히 \(N\)개 가진다면 대응 Eigenvector \(N\)개가 Linearly Independent하다. 따라서 Matrix

\[\boxed{ P = [ x_1 \;\cdots\; x_N ] }\]

는 Invertible하다.

Diagonalization

이 경우

\[\boxed{ A = P\Lambda P^{-1} }\]

로 쓸 수 있다. 여기서 다음과 같다.

\[\boxed{ \Lambda = \operatorname{diag} ( \lambda_1,\dots,\lambda_N ) }\]

Diagonalization의 의미

복잡한 Linear Transformation \(A\)를 Eigenvector Basis에서 보면

\[\boxed{ \Lambda }\]

라는 Diagonal Scaling으로 단순화된다. 각 Coordinate가 Eigenvalue만큼 독립적으로 Scaling된다.

Repeated Eigenvalue

Eigenvalue가 반복된다고 해서 Matrix가 Diagonalizable하지 않은 것은 아니다. 핵심은 충분한 수의 Linearly Independent Eigenvector가 존재하는지 여부다.

Symmetric Matrix

Real Symmetric Matrix

\[\boxed{ A=A^T }\]

는 특별한 성질을 가진다. 모든 Eigenvalue가 Real이고 서로 Orthogonal한 Eigenvector Basis를 선택할 수 있다.

Spectral Theorem

Real Symmetric Matrix에서는

\[\boxed{ A = Q\Lambda Q^T }\]

로 쓸 수 있다. 여기서 다음과 같다.

\[\boxed{ Q^TQ=I }\]

일반 Matrix의 Eigenvector는 직교하지 않는다

서로 다른 Eigenvalue에 대응하는 Eigenvector가 Linearly Independent하다는 것은

\[\boxed{ \text{orthogonal} }\]

이라는 뜻은 아니다. Orthogonality는 Symmetric/Normal Matrix에서 얻는 더 강한 성질이다.

Spectral Radius

Matrix \(A\)의 Spectral Radius는 Eigenvalue 절댓값의 최댓값이다 다음과 같다.

\[\boxed{ \rho(A) = \max_i |\lambda_i| }\]

원자료의 정의가 바로 이 Quantity다.

Matrix Powers와 Eigenvector

Eigenvector \(x\)에 대해

\[Ax=\lambda x\]

이면 다음과 같다.

\[A^2x = A(\lambda x) = \lambda^2x\]

일반적으로 다음과 같다.

\[\boxed{ A^kx = \lambda^kx }\]

Eigenvalue가 1보다 작은 경우

만약

\[|\lambda|<1\]

이면 다음과 같다.

\[\boxed{ \lambda^k\rightarrow0 }\]

따라서 해당 Eigenvector 방향의 Component는 반복 적용 시 감소한다.

Eigenvalue가 1보다 큰 경우

만약

\[|\lambda|>1\]

이면 다음과 같다.

\[\boxed{ |\lambda|^k\rightarrow\infty }\]

따라서 해당 Eigenvector 방향의 Component가 반복적으로 증폭될 수 있다.

Eigenvalue 크기가 1인 경우

\[|\lambda|=1\]

이면 일반적으로

\[\lambda^k\]

가 0으로 수렴하지 않는다. 예를 들어

\[\lambda=1\]

이면 그대로 유지되고,

\[\lambda=-1\]

이면 부호가 반복적으로 바뀐다.

Matrix Powers의 수렴 조건

유한차원 Square Matrix에 대해 다음과 같다.

\[\boxed{ A^k\rightarrow0 \iff \rho(A)<1 }\]

이는 원자료의 핵심 Spectral-Radius 결과다.

Diagonalizable Case에서의 이해

만약

\[A=P\Lambda P^{-1}\]

이면 다음과 같다.

\[\boxed{ A^k = P\Lambda^kP^{-1} }\]

그리고 다음과 같다.

\[\Lambda^k = \operatorname{diag} ( \lambda_1^k,\dots,\lambda_N^k )\]

Spectral Radius가 1보다 작으면

모든

\[|\lambda_i|<1\]

이면 다음과 같다.

\[\lambda_i^k\rightarrow0\]

따라서

\[\boxed{ \Lambda^k\rightarrow0 }\]

이고 다음과 같다.

\[\boxed{ A^k\rightarrow0 }\]

Diagonalizable하지 않아도 성립

일반 Matrix에서는 Jordan Form을 사용할 수 있다. Jordan Block의 Power에는

\[k^m\lambda^k\]

와 같은 Polynomial Factor가 나타날 수 있지만

\[|\lambda|<1\]

이면 Exponential Decay가 Polynomial Growth를 이긴다. 따라서 여전히 다음과 같다.

\[\boxed{ A^k\rightarrow0 }\]

Spectral Radius와 Norm의 차이

Spectral Radius는

\[\boxed{ \rho(A) = \max_i|\lambda_i| }\]

이고 Operator 2-Norm은 다음과 같다.

\[\boxed{ \|A\|_2 = \sigma_{\max}(A) }\]

일반 Matrix에서는 둘이 같지 않다.

기본 관계

일반적으로 다음과 같다.

\[\boxed{ \rho(A) \le \|A\|_2 = \sigma_{\max}(A) }\]

Normal Matrix에서는 다음과 같다.

\[\boxed{ \rho(A) = \|A\|_2 }\]

Nonnormal Matrix의 주의

\(\rho(A)<1\)이어도 어떤 초기 구간에서는

\[\|A^k\|\]

가 일시적으로 증가할 수 있다. 이를 Transient Growth와 연결할 수 있다. 따라서 Spectral Radius는 주로 장기 asymptotic behavior를 설명한다.

Numerical Example

원자료의 Matrix는 다음과 같다.

\[\boxed{ A = \begin{bmatrix} 4&1\\ 2&3 \end{bmatrix} }\]

Characteristic Matrix

\[A-\lambda I = \begin{bmatrix} 4-\lambda&1\\ 2&3-\lambda \end{bmatrix}\]

Determinant

\[\begin{aligned} \det( A-\lambda I ) &= (4-\lambda)(3-\lambda)-2\\ &= 12-7\lambda+\lambda^2-2\\ &= \lambda^2-7\lambda+10 \end{aligned}\]

Factorization

\[\boxed{ \lambda^2-7\lambda+10 = (\lambda-5)(\lambda-2) }\]

따라서 Eigenvalue는 다음과 같다.

\[\boxed{ \lambda_1=5, \qquad \lambda_2=2 }\]

Trace Check

\[\operatorname{Tr}(A) = 4+3 = 7\]

그리고 다음과 같다.

\[\lambda_1+\lambda_2 = 5+2 = 7\]

따라서

\[\boxed{ \operatorname{Tr}(A) = \lambda_1+\lambda_2 }\]

가 확인된다.

Determinant Check

\[\det(A) = 4(3)-1(2) = 10\]

그리고 다음과 같다.

\[\lambda_1\lambda_2 = 5(2) = 10\]

따라서 다음과 같다.

\[\boxed{ \det(A) = \lambda_1\lambda_2 }\]

Eigenvector for \(\lambda=5\)

다음 Homogeneous System을 푼다 다음과 같다.

\[\boxed{ (A-5I)x_1=0 }\]

Matrix Form

\[A-5I = \begin{bmatrix} -1&1\\ 2&-2 \end{bmatrix}\]

따라서 다음과 같다.

\[-x_{11}+x_{12}=0\]

Eigenvector Direction

따라서

\[x_{11}=x_{12}\]

이므로 대표 Eigenvector를

\[\boxed{ x_1 = \begin{bmatrix} 1\\ 1 \end{bmatrix} }\]

로 선택할 수 있다.

Normalization

Norm은 다음과 같다.

\[\|x_1\|_2 = \sqrt{1^2+1^2} = \sqrt2\]

따라서 Unit Eigenvector는 다음과 같다.

\[\boxed{ \hat x_1 = \begin{bmatrix} 1/\sqrt2\\ 1/\sqrt2 \end{bmatrix} }\]

Eigenvector for \(\lambda=2\)

이번에는

\[\boxed{ (A-2I)x_2=0 }\]

을 푼다.

Matrix Form

\[A-2I = \begin{bmatrix} 2&1\\ 2&1 \end{bmatrix}\]

따라서 다음과 같다.

\[2x_{21}+x_{22}=0\]

Eigenvector Direction

\[x_{22} = -2x_{21}\]

이므로 대표 Eigenvector는 다음과 같다.

\[\boxed{ x_2 = \begin{bmatrix} 1\\ -2 \end{bmatrix} }\]

Normalized Eigenvector

Norm은 다음과 같다.

\[\sqrt{ 1^2+(-2)^2 } = \sqrt5\]

따라서 다음과 같다.

\[\boxed{ \hat x_2 = \begin{bmatrix} 1/\sqrt5\\ -2/\sqrt5 \end{bmatrix} }\]

원자료의 두 Eigenvector 계산은 정확하다.

직접 검증

첫 번째 Eigenvector에 대해 다음과 같다.

\[A \begin{bmatrix} 1\\ 1 \end{bmatrix} = \begin{bmatrix} 5\\ 5 \end{bmatrix} = 5 \begin{bmatrix} 1\\ 1 \end{bmatrix}\]

두 번째 직접 검증

\[A \begin{bmatrix} 1\\ -2 \end{bmatrix} = \begin{bmatrix} 2\\ -4 \end{bmatrix} = 2 \begin{bmatrix} 1\\ -2 \end{bmatrix}\]

두 Eigenvector는 Orthogonal한가

Dot Product는 다음과 같다.

\[\begin{aligned} x_1^Tx_2 &= [1,1] \begin{bmatrix} 1\\ -2 \end{bmatrix}\\ &= -1 \end{aligned}\]

따라서 다음과 같다.

\[\boxed{ x_1^Tx_2\neq0 }\]

왜 Orthogonal하지 않은가

Matrix

\[A = \begin{bmatrix} 4&1\\ 2&3 \end{bmatrix}\]

는

\[A^T\neq A\]

이므로 Symmetric Matrix가 아니다. 따라서 서로 다른 Eigenvalue의 Eigenvector가 Independent일 뿐 Orthogonal일 필요는 없다.

Diagonalization Example

Eigenvector Matrix를

\[\boxed{ P = \begin{bmatrix} 1&1\\ 1&-2 \end{bmatrix} }\]

라고 하자. 그리고 다음과 같다.

\[\boxed{ \Lambda = \begin{bmatrix} 5&0\\ 0&2 \end{bmatrix} }\]

그러면

\[\boxed{ A = P\Lambda P^{-1} }\]

로 표현할 수 있다.

Deep Network와 반복 Linear Map

원자료는 Neural Network의 반복적인 Linear Transformation을

\[\boxed{ h^{(l)} = Wh^{(l-1)} }\]

형태로 연결한다. 동일한 \(W\)를 반복 사용하면 다음과 같다.

\[\boxed{ h^{(L)} = W^Lh^{(0)} }\]

Eigenbasis에서의 반복

만약 \(W\)가 Diagonalizable하고

\[h^{(0)} = \sum_i c_ix_i\]

라면 다음과 같다.

\[\boxed{ h^{(L)} = \sum_i c_i\lambda_i^Lx_i }\]

따라서 반복 Linear System의 asymptotic behavior는 Eigenvalue와 직접 연결된다.

Forward Signal과 Spectral Radius

반복되는 동일 Linear Map에 한정하면

\[\rho(W)<1\]

인 경우 다음과 같다.

\[W^L\rightarrow0\]

반대로

\[\rho(W)>1\]

이면 일부 Eigen-direction에서 성장할 수 있다.

Deep Neural Network에서는 더 복잡하다

실제 Deep Network에서는 일반적으로 Layer마다

\[W^{(l)}\]

이 다르고 Nonlinearity도 존재한다. 따라서

\[\boxed{ h^{(L)} = W^Lh^{(0)} }\]

라는 단순한 동일행렬 반복 모델로 전체 Network를 설명할 수는 없다.

Gradient는 Jacobian Product

Backpropagation에서는 Gradient가 여러 Jacobian의 Product를 통과한다. 개략적으로 다음과 같다.

\[\boxed{ \frac{\partial h^{(L)}} {\partial h^{(0)}} = J_LJ_{L-1}\cdots J_1 }\]

Gradient Stability와 Singular Value

Gradient Norm의 증폭/감쇠를 직접 제어하는 데에는 일반 Matrix의 Eigenvalue보다 Singular Value와 Operator Norm이 더 직접적인 역할을 한다 다음과 같다.

\[\boxed{ \|Jv\|_2 \le \sigma_{\max}(J) \|v\|_2 }\]

Spectral Radius만으로 Gradient를 판단할 수 없는 이유

General Nonnormal Matrix에서는

\[\boxed{ \rho(W) \neq \sigma_{\max}(W) }\]

일 수 있다. 따라서

\[\rho(W)\approx1\]

만으로

\[\|Wv\|\]

가 안정적으로 보존된다고 보장할 수 없다.

Xavier Initialization

Xavier Initialization은 Layer의 Input/Output Dimension을 고려하여 Weight Variance를 조절한다. 핵심 목적은 Forward Activation과 Backward Gradient의 Variance가 Layer를 통과하며 지나치게 증가하거나 감소하지 않도록 하는 것이다.

He Initialization

He Initialization은 ReLU와 같은 Activation의 특성을 고려해 Weight Variance를 설정한다. 대표적으로 Fan-in 기준으로

\[\boxed{ \operatorname{Var}(W_{ij}) \approx \frac2{n_{\mathrm{in}}} }\]

형태가 사용된다.

Initialization과 Eigenvalue의 구분

원자료는 Xavier/He Initialization이 Eigenvalue Distribution을 직접 조절하여

\[\rho(W)\approx1\]

로 만든다고 설명한다. 하지만 더 정확하게는 다음과 같다.

\[\boxed{ \text{Xavier/He} \rightarrow \text{activation/gradient variance control} }\]

Spectral Radius를 직접 1에 맞추는 Algorithm으로 정의되는 것은 아니다.

Dynamical Isometry

Gradient Stability를 더 정교하게 분석할 때는 Network Jacobian의 Singular Value가 1 근처에 분포하는

\[\boxed{ \text{Dynamical Isometry} }\]

같은 개념이 사용될 수 있다. 이는 단순히 Weight Eigenvalue만 보는 것보다 직접적인 Gradient-Propagation 관점을 제공한다.

Spectral Normalization

원자료는 다음 변환을 제시한다 다음과 같다.

\[\boxed{ W_{\mathrm{SN}} = \frac{ W }{ \sigma_{\max}(W) } }\]

여기서 사용하는 것은 Singular Value

중요하게도

\[\boxed{ \sigma_{\max}(W) }\]

는 최대 Singular Value다. 일반 Matrix에서 최대 Eigenvalue 절댓값과 동일하지 않다.

Spectral Norm

Operator 2-Norm은 다음과 같다.

\[\boxed{ \|W\|_2 = \sigma_{\max}(W) }\]

따라서 \(W\neq0\)이면 다음과 같다.

\[\boxed{ \| W_{\mathrm{SN}} \|_2 = 1 }\]

Linear Map의 Lipschitz Constant

Linear Mapping

\[f(x)=Wx\]

의 Euclidean Lipschitz Constant는 다음과 같다.

\[\boxed{ \|W\|_2 }\]

따라서 Spectral Normalization은 Linear Layer의 Operator Norm을 직접 제어한다.

전체 Network의 Lipschitz Constant

여러 Layer가 합성되면 다음과 같다.

\[\boxed{ \operatorname{Lip} ( f_L\circ\cdots\circ f_1 ) \le \prod_l \operatorname{Lip}(f_l) }\]

따라서 Layer Norm 제어가 전체 Network Sensitivity 제어와 연결될 수 있다.

Spectral Normalization이 보장하지 않는 것

원자료는 Spectral Normalization이 Training Convergence Stability를 “원천 보장”한다고 표현한다. 하지만

\[\boxed{ \|W\|_2\le1 }\]

만으로

  • Optimization convergence
  • Generalization
  • 전체 Network 안정성

이 자동으로 보장되는 것은 아니다.

Continuous-Time State-Space Model

원자료는 SSM을 다음 식과 연결한다 다음과 같다.

\[\boxed{ \dot h(t) = Ah(t) + Bx(t) }\]

Zero-Input Dynamics

입력을 제거하면 다음과 같다.

\[\boxed{ \dot h(t) = Ah(t) }\]

해는 다음과 같다.

\[\boxed{ h(t) = e^{At} h(0) }\]

Continuous-Time Stability

Finite-dimensional Continuous-Time LTI System에서

\[\boxed{ \operatorname{Re}(\lambda_i(A))<0 \quad \forall i }\]

이면 Zero Solution이 Exponentially Stable하다.

Spectral Abscissa

Continuous-Time Stability에서는 Spectral Radius보다

\[\boxed{ \alpha(A) = \max_i \operatorname{Re} ( \lambda_i(A) ) }\]

라는 Spectral Abscissa가 더 직접적인 Quantity다. 안정 조건은 다음과 같다.

\[\boxed{ \alpha(A)<0 }\]

100. Discrete-Time System

Discrete-Time State Transition

\[\boxed{ h_{t+1} = \bar A h_t }\]

에서는 다음과 같다.

\[\boxed{ h_t = \bar A^t h_0 }\]

따라서 안정성 조건은 다음과 같다.

\[\boxed{ \rho(\bar A)<1 }\]

101. Continuous에서 Discrete로

Exact Discretization에서

\[\boxed{ \bar A = e^{\Delta A} }\]

라고 하면 Continuous Eigenvalue \(\lambda_i\)는

\[\boxed{ e^{\Delta\lambda_i} }\]

로 Mapping된다.

102. Negative Real Part와 Unit Disk

\[\operatorname{Re}(\lambda_i)<0\]

이면 다음과 같다.

\[\boxed{ | e^{\Delta\lambda_i} | = e^{ \Delta\operatorname{Re}(\lambda_i) } <1 }\]

따라서 Continuous-Time Stability와 Discrete-Time Spectral Radius 조건이 연결된다.

103. S4/Mamba 연결의 범위

원자료는 S4와 Mamba를 이 Stability Criterion과 연결한다. 이 연결은 SSM의 Linear State Dynamics를 이해하는 데 유용하다. 다만 실제 현대 SSM Architecture에는

  • Discretization
  • Structured Parameterization
  • Input-dependent/selective components

등이 추가될 수 있으므로 전체 Model의 동작을 고정된 \(A\) 하나의 Eigenvalue만으로 설명하지 않는다.

104. 핵심 식 — Eigenvalue Equation

\[\boxed{ Ax = \lambda x, \qquad x\neq0 }\]

105. 핵심 식 — Eigenspace

\[\boxed{ E_\lambda = \mathcal N( A-\lambda I ) }\]

106. 핵심 식 — Characteristic Equation

\[\boxed{ \det( A-\lambda I ) = 0 }\]

107. 핵심 식 — Trace와 Determinant

\[\begin{gathered} \boxed{ \operatorname{Tr}(A) = \sum_i\lambda_i } \\[6pt] \boxed{ \det(A) = \prod_i\lambda_i } \end{gathered}\]

Multiplicity를 포함한다.

108. 핵심 식 — Spectral Radius

\[\boxed{ \rho(A) = \max_i |\lambda_i| }\]

109. 핵심 식 — Matrix Power

\[\boxed{ A^kx_i = \lambda_i^kx_i }\]

그리고 다음과 같다.

\[\boxed{ A^k\rightarrow0 \iff \rho(A)<1 }\]

110. 핵심 식 — Spectral Normalization

\[\boxed{ W_{\mathrm{SN}} = \frac{ W }{ \sigma_{\max}(W) } }\]

111. 혼동하기 쉬운 부분 — 방향 불변

Eigenvector는 “변환 후 Vector가 정확히 같은 방향을 향한다”라고만 표현하면 \(\lambda<0\)을 설명하지 못한다. 더 정확하게는 다음과 같다.

\[\boxed{ \operatorname{span}(x) \text{가 invariant} }\]

112. 혼동하기 쉬운 부분 — Complex Eigenvalue

Real Matrix라도 Complex Eigenvalue가 존재할 수 있다. 이 경우 대응 Eigenvector도 Complex Vector Space에서 다룰 수 있다.

113. 혼동하기 쉬운 부분 — 독립과 직교

서로 다른 Eigenvalue의 Eigenvector는

\[\boxed{ \text{linearly independent} }\]

이지만 일반적으로

\[\boxed{ \text{orthogonal} }\]

일 필요는 없다.

114. 혼동하기 쉬운 부분 — Eigenvalue와 Singular Value

Eigenvalue:

\[\boxed{ Ax=\lambda x }\]

Singular Value 다음과 같다.

\[\boxed{ \sigma_i = \sqrt{ \lambda_i( A^TA ) } }\]

두 개념은 일반 Matrix에서 다르다.

115. 혼동하기 쉬운 부분 — Spectral Radius와 Spectral Norm

\[\boxed{ \rho(A) }\]

는 최대 Eigenvalue Magnitude고,

\[\boxed{ \|A\|_2 = \sigma_{\max}(A) }\]

는 최대 Singular Value다. 일반적으로 다음과 같다.

\[\boxed{ \rho(A) \le \|A\|_2 }\]

116. 혼동하기 쉬운 부분 — Gradient Explosion

실제 Deep Network Gradient는 동일한 Weight Matrix의 단순 Power가 아니라 Jacobian Product를 통과한다. 따라서

\[\boxed{ \rho(W)>1 }\]

하나만으로 일반 Neural Network의 Gradient Explosion을 판정하지 않는다.

117. 혼동하기 쉬운 부분 — Xavier/He

Xavier/He Initialization은

\[\boxed{ \rho(W)\approx1 }\]

을 직접 강제하는 기법이 아니다. 핵심은 Forward/Backward Variance의 통계적 Scale을 제어하는 것이다.

118. 혼동하기 쉬운 부분 — Spectral Normalization

Spectral Normalization의 분모는 일반적으로 다음과 같다.

\[\boxed{ \sigma_{\max}(W) }\]

이를 “최대 고유값”과 동일하게 부르면 일반 Matrix에서 오류가 된다.

119. 혼동하기 쉬운 부분 — Convergence Guarantee

Linear Layer의 Spectral Norm을 제어한다고 해서 Optimizer의 Training Convergence가 자동으로 보장되는 것은 아니다. 이는 Network의 Sensitivity와 Lipschitz Control에 관련된 하나의 Mechanism이다.

120. 전체 개념 연결

Eigenvalue Problem은

\[\boxed{ Ax=\lambda x }\]

에서 출발한다. 이를 정리하면 다음과 같다.

\[\boxed{ (A-\lambda I)x=0 }\]

Nontrivial Solution이 존재해야 하므로 다음과 같이 얻는다.

\[\boxed{ \det(A-\lambda I)=0 }\]

121. Geometry 연결

각 Eigenvector Direction에서는 Linear Transformation이 단순 Scaling으로 작용한다 다음과 같다.

\[\boxed{ x \rightarrow \lambda x }\]

122. Basis 연결

충분한 수의 Independent Eigenvector가 존재하면

\[\boxed{ A = P\Lambda P^{-1} }\]

로 Diagonalize할 수 있다. 복잡한 Linear Transformation을 Eigenbasis에서 독립 Scaling으로 해석할 수 있다.

123. Dynamics 연결

Repeated Transformation에서는

\[\boxed{ A^kx = \lambda^kx }\]

이므로 Eigenvalue Magnitude가 장기 Dynamics를 결정한다. 이것이 Spectral Radius와 Stability로 연결된다.

124. Deep Learning 연결

Neural Network에서는 단순 Weight Eigenvalue만이 아니라 Layer Jacobian의 Singular Value와 Product가 Gradient Propagation에 중요하다. 따라서

\[\boxed{ \text{Eigenvalues} \rightarrow \text{linear dynamics} }\]

와

\[\boxed{ \text{Singular values} \rightarrow \text{norm amplification} }\]

을 구분한다.

125. SSM 연결

Continuous-Time SSM에서는

\[\boxed{ \max_i \operatorname{Re}( \lambda_i(A) ) <0 }\]

이 Stability Criterion이 된다. Discrete-Time State Transition에서는

\[\boxed{ \rho(\bar A)<1 }\]

로 연결된다.

126. 정리

Eigenvalue와 Eigenvector는 Square Matrix가 특정 Direction에 어떻게 작용하는지를 설명한다. 기본 식은 다음과 같다.

\[\boxed{ Ax=\lambda x, \qquad x\neq0 }\]

이를 정리하면 다음과 같다.

\[\boxed{ (A-\lambda I)x=0 }\]

Nonzero Solution이 존재하기 위해서는

\[A-\lambda I\]

가 Singular해야 하므로

\[\boxed{ \det( A-\lambda I ) = 0 }\]

이라는 Characteristic Equation을 얻는다. 특정 \(\lambda\)에 대한 Eigenspace는 다음과 같다.

\[\boxed{ E_\lambda = \mathcal N(A-\lambda I) }\]

Algebraic Multiplicity를 포함한 Eigenvalue들은

\[\begin{gathered} \boxed{ \operatorname{Tr}(A) = \sum_i\lambda_i } \\[6pt] \boxed{ \det(A) = \prod_i\lambda_i } \end{gathered}\]

를 만족한다. 서로 다른 Eigenvalue에 대응하는 Eigenvector들은 항상 Linearly Independent하다. 따라서 \(N\times N\) Matrix가 \(N\)개의 서로 다른 Eigenvalue를 가지면

\[\boxed{ A = P\Lambda P^{-1} }\]

로 Diagonalize할 수 있다. Spectral Radius는 다음과 같다.

\[\boxed{ \rho(A) = \max_i|\lambda_i| }\]

Repeated Linear Transformation에서는

\[\boxed{ A^kx_i = \lambda_i^kx_i }\]

이므로 Eigenvalue Magnitude가 각 Eigen-direction의 장기 Scaling을 결정한다. 전체 Matrix Power는

\[\boxed{ A^k\rightarrow0 \iff \rho(A)<1 }\]

을 만족한다. 원자료의 예제

\[A = \begin{bmatrix} 4&1\\ 2&3 \end{bmatrix}\]

에서는 다음과 같다.

\[\boxed{ \lambda_1=5, \qquad \lambda_2=2 }\]

대응 Eigenvector는 각각

\[\boxed{ x_1 = \begin{bmatrix} 1\\ 1 \end{bmatrix} }\]

과 다음과 같다.

\[\boxed{ x_2 = \begin{bmatrix} 1\\ -2 \end{bmatrix} }\]

Normalized Form은 다음과 같다.

\[\begin{gathered} \boxed{ \hat x_1 = \begin{bmatrix} 1/\sqrt2\\ 1/\sqrt2 \end{bmatrix} } \\[6pt] \boxed{ \hat x_2 = \begin{bmatrix} 1/\sqrt5\\ -2/\sqrt5 \end{bmatrix} } \end{gathered}\]

두 Eigenvector는 서로 다른 Eigenvalue에 대응하므로 Linearly Independent하지만, Matrix가 Symmetric하지 않으므로 서로 Orthogonal하지는 않는다. Deep Learning에서는 Eigenvalue 개념이 반복 Linear Dynamics를 이해하는 데 유용하지만, Gradient Explosion/Vanishing을 일반적으로 분석할 때는 Jacobian Product와 Singular Value를 함께 봐야 한다. 따라서

\[\boxed{ \rho(W) }\]

와

\[\boxed{ \sigma_{\max}(W) }\]

를 혼동하지 않는다. Spectral Normalization은

\[\boxed{ W_{\mathrm{SN}} = \frac{ W }{ \sigma_{\max}(W) } }\]

을 사용하여 Linear Map의 Spectral Norm을 제어한다. 이는 Lipschitz Control과 연결되지만 Training Convergence 자체를 보장하는 것은 아니다. 또한 Xavier/He Initialization의 핵심은 Weight Eigenvalue를 직접 1 근처로 배치하는 것이 아니라 Activation과 Gradient의 Variance Scale을 안정화하는 것이다. State-Space Model에서는 Continuous-Time Dynamics

\[\boxed{ \dot h = Ah+Bx }\]

에서

\[\boxed{ \operatorname{Re}( \lambda_i(A) ) <0 }\]

가 Zero-input Exponential Stability와 연결된다. Discrete-Time System에서는 대응 조건이 다음과 같다.

\[\boxed{ \rho(\bar A)<1 }\]

따라서 LA-15의 전체 흐름은

\[\boxed{ \text{Linear Transformation} \rightarrow \text{Invariant Direction} \rightarrow \text{Eigenvalue/Eigenvector} \rightarrow \text{Characteristic Equation} }\]

에서 시작한다. 이후

\[\boxed{ \text{Eigenbasis} \rightarrow \text{Diagonalization} \rightarrow \text{Matrix Powers} \rightarrow \text{Spectral Stability} }\]

로 이어진다. Deep Learning 및 AI 시스템에서는

\[\begin{gathered} \boxed{ \text{Eigenvalues} \rightarrow \text{linear dynamics} } \\[6pt] \boxed{ \text{Singular values} \rightarrow \text{norm/gradient amplification} } \\[6pt] \boxed{ \text{Spectral properties} \rightarrow \text{training and state-space stability analysis} } \end{gathered}\]

로 확장된다.

127. 정리

Eigenvector는 선형변환의 방향이 보존되는 벡터이며 \(Av=\lambda v\)에서 \(\lambda\)가 그 방향의 scale 변화를 나타낸다. Eigenvalue·eigenspace와 고유기저의 존재 조건은 대각화와 반복 행렬 연산을 이해하는 기반이 된다.
