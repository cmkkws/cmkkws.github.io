LA-19 — Low-Rank Approximation & Eckart–Young–Mirsky Theorem

저랭크 근사와 절단 SVD, Eckart–Young–Mirsky 정리 및 압축 관점을 정리한다.

선형대수 · LA-19업데이트 2026.09.21

  • #Truncated SVD
  • #Eckart–Young–Mirsky

개념

Low-Rank Approximation행렬 \(A\in\mathbb R^{M\times N}\) 이 주어졌다고 하자. \(A\)의 Rank를 \(r=\operatorname{rank}(A)\) 라고 한다. Low-Rank Approximation의 목표는 \(A\)보다 훨씬 작은 Rank를 가진 행렬 \(A_k\) 로 \(A\)를 근사하는 것이다.

Target RankTarget Rank를 \(k<r\) 라고 하자. 근사 행렬은 \(A_k\in\mathbb R^{M\times N}\) 이고 일반적으로 \(\operatorname{rank}(A_k)\le k\) 라는 제약을 둔다.

원자료 Rank 정의 보완원자료에서는 \(r=\min(M,N)\) 이라고 적혀 있다. 하지만 일반적으로 다음과 같다 (\(\operatorname{rank}(A) \le \min(M,N)\)).

Equality \(\operatorname{rank}(A)=\min(M,N)\) 는 \(A\)가 Full Rank일 때만 성립한다. 따라서 본 자료에서는 \(r=\operatorname{rank}(A)\) 로 사용한다.

Approximation의 기본 목표Low-Rank Approximation에서는 \(A\approx A_k\) 를 원한다. 즉 Rank를 크게 줄이면서 원래 Matrix와의 차이를 작게 유지한다.

왜 Rank를 줄이는가Rank-\(k\) 구조는 Matrix가 실제로 사용하는 독립적인 Input/Output Direction의 수를 제한한다. 따라서 적절한 상황에서는 다음과 같다.

  • 저장 공간 감소
  • Matrix Multiplication 비용 감소
  • Noise Reduction
  • Dimensionality Reduction

이 식과 연결될 수 있다.

정보 보존이라는 표현의 범위원자료는 Low-Rank Approximation이 원본의 “핵심 기하학적 정보와 Variance를 최대한 보존한다”고 설명한다. 정확하게는 SVD Truncation이 특정 Matrix Norm 기준에서 최적이다. 즉 Norm error 최소화 는 보장되지만, 어떤 Application에서 의미론적·Task-level 정보까지 최대로 보존한다는 보편적 정리는 아니다.

표기·차원

Truncated SVD상위 \(k\)개 Component만 남기면 다음과 같다.

\[\boxed{ A_k = \sum_{i=1}^{k} \sigma_i u_i v_i^T }\]

Matrix Form으로는 다음과 같다.

\[\boxed{ A_k = U_k \Sigma_k V_k^T }\]

Shapes

\[\begin{gathered} \boxed{ U_k \in \mathbb R^{M\times k} } \\[6pt] \boxed{ \Sigma_k \in \mathbb R^{k\times k} } \\[6pt] \boxed{ V_k \in \mathbb R^{N\times k} } \end{gathered}\]

핵심 연산

Rank-Constrained OptimizationLow-Rank Approximation은 다음 Optimization Problem으로 표현할 수 있다 (\(\min_B \|A-B\|\)).

subject to 다음과 같다 (\(\operatorname{rank}(B)\le k\)).

원자료의 기본 정식화다.

어떤 Norm을 사용하는가대표적으로 \(\|\cdot\|_F\) 인 Frobenius Norm과 \(\|\cdot\|_2\) 인 Spectral Norm을 사용할 수 있다.

Frobenius NormMatrix \(E\in\mathbb R^{M\times N}\) 에 대해 다음과 같다.

\[\boxed{ \|E\|_F = \sqrt{ \sum_{i=1}^{M} \sum_{j=1}^{N} E_{ij}^2 } }\]

Trace 표현Frobenius Norm은 다음과 같다.

\[\boxed{ \|E\|_F^2 = \operatorname{Tr} ( E^TE ) }\]

로도 표현된다.

Singular Value 표현\(E\)의 Singular Value가 \(\tau_1,\dots,\tau_s\) 이면 다음과 같다.

\[\boxed{ \|E\|_F^2 = \sum_i\tau_i^2 }\]

Spectral NormSpectral 2-Norm은 다음과 같다.

\[\boxed{ \|E\|_2 = \sigma_{\max}(E) }\]

동치로 다음과 같다.

\[\boxed{ \|E\|_2 = \max_{\|x\|_2=1} \|Ex\|_2 }\]

Frobenius vs Spectral NormFrobenius Norm은 Matrix 전체 Entry 또는 모든 Singular Value의 에너지를 측정한다. Spectral Norm은 가장 크게 증폭되는 단일 Direction을 측정한다. 즉 두 Norm은 서로 다른 Error 의미를 가진다.

LA-18과 연결LA-18에서 SVD를 \(A = U\Sigma V^T\) 로 배웠다. Rank가 \(r\)이면 Reduced SVD는 다음과 같다.

\[\boxed{ A = U_r\Sigma_rV_r^T }\]

Singular ValuesSingular Value를 내림차순으로 \(\sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_r > 0\) 이라고 하자.

Rank-1 ExpansionSVD는 \(A = \sum_{i=1}^{r} \sigma_i u_i v_i^T\) 로 쓸 수 있다.

각 항의 Rank\(u_iv_i^T\) 는 Rank-1 Matrix다. 따라서 \(A\)는 \(r\)개의 Rank-1 Singular Component의 합으로 표현된다.

Rank\(\sigma_k>0\)이면 다음과 같다.

\[\boxed{ \operatorname{rank}(A_k)=k }\]

Optimization Problem에서는 더 일반적으로 \(\operatorname{rank}(B)\le k\) 라는 조건을 사용한다.

Eckart–Young–Mirsky TheoremEckart–Young–Mirsky 정리는 Truncated SVD가 Low-Rank Approximation Problem의 최적해임을 보여준다. Frobenius Norm에 대해 다음과 같다 (\(A_k \in \arg\min_{ \operatorname{rank}(B)\le k } \|A-B\|_F\)).

Spectral Norm에서도 최적Spectral Norm에서도 다음과 같다 (\(A_k \in \arg\min_{ \operatorname{rank}(B)\le k } \|A-B\|_2\)).

원자료의 핵심 정리와 같다.

“유일하게 결정된다”는 표현의 보완원자료는 최적 근사 \(A_k\)가 상위 \(k\)개 Singular Component로 유일하게 결정된다고 서술한다. 하지만 Singular Value가 cutoff 지점에서 반복되면 최적 Rank-\(k\) Approximation이 유일하지 않을 수 있다.

Uniqueness Condition대표적으로 \(\sigma_k>\sigma_{k+1}\) 이면 Truncated Singular Subspace가 분리되어 최적 Rank-\(k\) 근사가 유일하다. 반면 \(\sigma_k=\sigma_{k+1}\) 이면 반복 Singular Subspace 안에서 여러 최적해가 존재할 수 있다.

따라서 정확한 표현일반적으로는 \(A_k \text{ is an optimal rank-}k\text{ approximation}\) 이라고 표현한다. 유일성은 Singular Value multiplicity에 대한 추가 조건이 필요하다.

핵심 식 — Low-Rank Optimization\(\min_{ \operatorname{rank}(B)\le k } \|A-B\|\)

핵심 식 — Rank-1 Sum

\[\boxed{ A_k = \sum_{i=1}^{k} \sigma_i u_i v_i^T }\]

핵심 식 — Frobenius Minimum Error

\[\boxed{ \min_{ \operatorname{rank}(B)\le k } \|A-B\|_F = \sqrt{ \sum_{i=k+1}^{r} \sigma_i^2 } }\]

핵심 식 — Spectral Minimum Error

\[\boxed{ \min_{ \operatorname{rank}(B)\le k } \|A-B\|_2 = \sigma_{k+1} }\]

핵심 식 — Factorized Storage

\[\boxed{ A_k=BC }\]

with 다음과 같다 (\(B\in\mathbb R^{M\times k}, \qquad C\in\mathbb R^{k\times N}\)).

핵심 식 — Parameter CountDense: \(MN\) Low-rank 다음과 같다 (\(k(M+N)\)).

성질·유도

Residual MatrixTruncated SVD의 Residual을 \(E_k = A-A_k\) 라고 하자.

Residual Expansion전체 SVD에서 앞의 \(k\)개 항을 제거하면 다음과 같다.

\[\boxed{ E_k = \sum_{i=k+1}^{r} \sigma_i u_i v_i^T }\]

원자료의 Residual 식과 동일하다.

Frobenius Error 유도Frobenius Norm 제곱은 다음과 같다.

\[\boxed{ \|E_k\|_F^2 = \operatorname{Tr} ( E_k^TE_k ) }\]

Residual Transpose\(E_k = \sum_{i=k+1}^{r} \sigma_i u_i v_i^T\) 이므로 다음과 같다.

\[\boxed{ E_k^T = \sum_{i=k+1}^{r} \sigma_i v_i u_i^T }\]

Product Expansion따라서 다음과 같다.

\[E_k^TE_k = \sum_{i=k+1}^{r} \sum_{j=k+1}^{r} \sigma_i\sigma_j v_i u_i^Tu_j v_j^T\]

Left Singular Vector OrthogonalityLeft Singular Vectors는 Orthonormal이므로 다음과 같다.

\[\boxed{ u_i^Tu_j = \delta_{ij} }\]

따라서 \(i\neq j\)인 Cross Term이 사라진다.

Product Simplification그 결과 다음과 같다.

\[\boxed{ E_k^TE_k = \sum_{i=k+1}^{r} \sigma_i^2 v_iv_i^T }\]

Trace따라서 다음과 같다.

\[\begin{aligned} \|E_k\|_F^2 &= \sum_{i=k+1}^{r} \sigma_i^2 \operatorname{Tr} ( v_iv_i^T ) \end{aligned}\]

Unit Vector Trace\(\operatorname{Tr} ( v_iv_i^T ) = v_i^Tv_i = 1\) 이므로 다음과 같다.

\[\boxed{ \|E_k\|_F^2 = \sum_{i=k+1}^{r} \sigma_i^2 }\]

Frobenius Error따라서 다음과 같다.

\[\boxed{ \|A-A_k\|_F = \sqrt{ \sum_{i=k+1}^{r} \sigma_i^2 } }\]

원자료의 공식과 일치한다.

Spectral ErrorResidual \(E_k\)의 Nonzero Singular Value는 다음과 같다 (\(\sigma_{k+1}, \sigma_{k+2}, \dots, \sigma_r\)).

Maximum Residual Singular Value따라서 다음과 같다.

\[\boxed{ \|E_k\|_2 = \sigma_{k+1} }\]

즉 다음과 같다.

\[\boxed{ \|A-A_k\|_2 = \sigma_{k+1} }\]

Frobenius와 Spectral Error 비교Frobenius 다음과 같다.

\[\boxed{ \|A-A_k\|_F = \sqrt{ \sigma_{k+1}^2 +\cdots+ \sigma_r^2 } }\]

Spectral 다음과 같다.

\[\boxed{ \|A-A_k\|_2 = \sigma_{k+1} }\]

해석Spectral Norm Error는 버린 Component 중 가장 큰 하나가 결정한다. Frobenius Norm Error는 버린 모든 Singular Component의 Squared Magnitude를 누적한다.

왜 큰 Singular Value부터 남기는가Singular Component \(\sigma_i u_i v_i^T\) 의 Frobenius Norm은 다음과 같다 (\(\sigma_i\)).

따라서 큰 Singular Value를 가진 Component가 Matrix Norm에 더 크게 기여한다.

전체 Frobenius Energy

\[\boxed{ \|A\|_F^2 = \sum_{i=1}^{r} \sigma_i^2 }\]

Retained Energy상위 \(k\)개를 남겼을 때 보존된 Frobenius-energy fraction은 다음과 같다.

\[\boxed{ R_k = \frac{ \sum_{i=1}^{k} \sigma_i^2 }{ \sum_{i=1}^{r} \sigma_i^2 } }\]

Residual Energy버려진 비율은 다음과 같다.

\[\boxed{ 1-R_k = \frac{ \sum_{i=k+1}^{r} \sigma_i^2 }{ \sum_{i=1}^{r} \sigma_i^2 } }\]

“Variance 보존” 표현Data Matrix의 PCA Context에서는 Singular Value Square가 Variance와 직접 연결된다. 그러나 일반 Weight Matrix에서는 \(\sigma_i^2\) 를 곧바로 “Data Variance”라고 부르는 것은 부정확하다. 이 경우 Frobenius Energy 또는 Squared Singular Magnitude라고 표현하는 것이 적절하다.

혼동하기 쉬운 부분 — Matrix Rank일반적으로 다음과 같다 (\(\operatorname{rank}(A) \le \min(M,N)\)).

항상 \(\operatorname{rank}(A)=\min(M,N)\) 인 것은 아니다.

혼동하기 쉬운 부분 — Rank \(k\) 또는 Rank \(\le k\)Eckart–Young Optimization은 보통 \(\operatorname{rank}(B)\le k\) 로 쓴다. 상위 \(k\) Singular Value가 Positive이면 결과 \(A_k\)의 Rank는 정확히 \(k\)다.

혼동하기 쉬운 부분 — 최적성과 유일성Truncated SVD는 최적이다. 하지만 cutoff Singular Value가 반복되면 최적해가 유일하지 않을 수 있다.

혼동하기 쉬운 부분 — Norm“가장 좋은 Low-rank Approximation”이라고 할 때는 어떤 Error Measure를 사용하는지 명시해야 한다. Eckart–Young–Mirsky는 Frobenius 및 Spectral Norm 등에 대해 강력한 결과를 제공한다.

혼동하기 쉬운 부분 — Frobenius와 Spectral Error\(\|E_k\|_F\) 는 버린 모든 Singular Value를 반영하고, \(\|E_k\|_2\) 는 가장 큰 버린 Singular Value 하나가 결정한다.

혼동하기 쉬운 부분 — Energy와 VarianceData/PCA에서는 \(\sigma_i^2\) 가 Variance와 연결된다. 일반 Weight Matrix에서는 Frobenius Energy라고 표현하는 것이 더 정확하다.

혼동하기 쉬운 부분 — LoRALoRA는 Truncated SVD Algorithm이 아니다.

\(\Delta W=BA\) 라는 Low-rank Parameterization을 사용한다.

혼동하기 쉬운 부분 — Eckart–Young과 LoRAEckart–Young 정리는 LoRA가 특정 Rank에서 높은 Model Performance를 보존한다는 것을 증명하지 않는다. 이미 주어진 Matrix의 Norm Approximation에 관한 정리다.

혼동하기 쉬운 부분 — 99%Rank 8 또는 16으로 “성능의 99%”가 유지된다는 것은 본 정리의 Mathematical Consequence가 아니다. 실험 조건에 따라 달라지는 Empirical Claim이다.

혼동하기 쉬운 부분 — MLAMLA는 Truncated SVD를 직접 수행하는 Architecture라고 동일시하면 안 된다. Learned Low-Dimensional Latent Representation을 사용하는 구조로 이해하는 것이 적절하다.

혼동하기 쉬운 부분 — 90% KV 절감특정 Model의 Cache Reduction Ratio는 실제 Dimension과 Architecture를 통해 계산해야 한다. Eckart–Young 정리에서 90%라는 숫자가 나오는 것은 아니다.

Truncation작은 Singular Component를 제거한다 다음과 같다.

\[\boxed{ A_k = \sum_{i=1}^{k} \sigma_i u_iv_i^T }\]

OptimalityEckart–Young–Mirsky 정리에 의해 \(A_k\) 는 Frobenius/Spectral Norm 기준의 최적 Low-Rank Approximation이다.

Error버린 Singular Values가 정확히 Approximation Error를 결정한다 다음과 같다.

\[\begin{gathered} \boxed{ \|A-A_k\|_F^2 = \sum_{i=k+1}^{r} \sigma_i^2 } \\[6pt] \boxed{ \|A-A_k\|_2 = \sigma_{k+1} } \end{gathered}\]

Low-Rank Approximation은 Matrix \(A\in\mathbb R^{M\times N}\) 를 더 낮은 Rank의 Matrix로 근사하는 문제다. 먼저 다음과 같다.

\[\boxed{ r=\operatorname{rank}(A) \le \min(M,N) }\]

Target Rank를 \(k<r\) 로 선택하면 Optimization Problem은 다음과 같이 표현된다 (\(\min_{ \operatorname{rank}(B)\le k } \|A-B\|\)).

\(A\)의 SVD가 \(A = U\Sigma V^T = \sum_{i=1}^{r} \sigma_i u_iv_i^T\) 라고 하자. Singular Values는 다음과 같다.

\[\boxed{ \sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_r > 0 }\]

상위 \(k\)개 Component만 남기면 다음과 같다.

\[\boxed{ A_k = U_k\Sigma_kV_k^T = \sum_{i=1}^{k} \sigma_i u_iv_i^T }\]

Eckart–Young–Mirsky 정리에 의해 이 \(A_k\)는 Frobenius Norm과 Spectral Norm 기준의 최적 Rank-\(k\) Approximation이다. Frobenius Norm에서는 다음과 같다.

\[\boxed{ \|A-A_k\|_F = \sqrt{ \sum_{i=k+1}^{r} \sigma_i^2 } }\]

Spectral Norm에서는 다음과 같다.

\[\boxed{ \|A-A_k\|_2 = \sigma_{k+1} }\]

단, 최적성이 항상 유일성까지 의미하는 것은 아니다. 특히 \(\sigma_k=\sigma_{k+1}\) 처럼 cutoff에서 Singular Value가 반복되면 여러 최적 Rank-\(k\) Approximation이 존재할 수 있다. 원자료의 수치 예제:

\[A = \begin{bmatrix} 3&0\\ 0&2\\ 0&0 \end{bmatrix}\]

\(A\)에서는 다음과 같다.

\[\boxed{ \sigma_1=3, \qquad \sigma_2=2 }\]

\(k=1\)이면 다음과 같다.

\[\boxed{ A_1 = \begin{bmatrix} 3&0\\ 0&0\\ 0&0 \end{bmatrix} }\]

Residual은 다음과 같다.

\[\boxed{ E_1 = \begin{bmatrix} 0&0\\ 0&2\\ 0&0 \end{bmatrix} }\]

\(E_1\)이 성립하고, 다음과 같다.

\[\begin{gathered} \boxed{ \|A-A_1\|_F=2 } \\[6pt] \boxed{ \|A-A_1\|_2=2 } \end{gathered}\]

이 결과는 다음과 같다.

\[\boxed{ \sqrt{\sigma_2^2}=2 }\]

및 \(\sigma_2=2\) 와 정확히 일치한다. Low-Rank Matrix를 \(A_k=BC\) 로 저장하면 Dense Matrix의 \(MN\) Parameter 대신 \(k(M+N)\) 개의 Parameter만 필요하다. Matrix-Vector Product 역시 Dense \(O(MN)\) 에서 Factorized Representation을 사용하면 \(O(k(M+N))\) 로 계산할 수 있다.

단 이는 \(k\)가 충분히 작을 때의 이점이며 SVD Factorization 자체의 계산 비용과 구분해야 한다. PCA에서는 Centered Data Matrix의 Rank-\(k\) SVD가 Frobenius Norm 기준 최적 Rank-\(k\) Reconstruction을 제공한다. 이때 \(\sigma_i^2\) 는 Principal Variance와 연결된다.

LoRA에서는 \(\Delta W=BA\) 를 이용하여 \(\operatorname{rank}(\Delta W)\le r\) 라는 Low-rank Constraint를 적용한다. 하지만 LoRA는 Truncated SVD Algorithm이 아니며, Eckart–Young 정리가 LoRA의 Update가 intrinsically low-rank라는 사실이나 Rank 8/16에서 Task Performance의 99%를 보존한다는 것을 증명하지 않는다. Eckart–Young은 이미 주어진 Matrix에 대한 최적 Matrix-Norm Approximation을 설명한다.

MLA 역시 Low-dimensional Latent Representation이라는 점에서 Low-rank 관점과 연결할 수 있지만, 각 KV Representation에 SVD를 수행해 Top Singular Components를 직접 남기는 Algorithm으로 이해하면 안 된다. 따라서 LA-19의 핵심 흐름은 다음과 같다.

SVD → Singular Component Ranking → Truncation → Optimal Low-Rank Approximation

Error 관점에서는 다음과 같다.

discarded singular values → exact approximation error

Systems 관점에서는 low rank → fewer parameters → lower matrix-multiplication cost 로 연결된다. AI 관점에서는 Low-Rank Approximation → PCA / Compression 과 Low-Rank Parameterization → LoRA / latent bottleneck designs 을 구분하여 이해하는 것이 중요하다.

예제·적용

수치 예제원자료의 Matrix는 다음과 같다.

\[\boxed{ A = \begin{bmatrix} 3&0\\ 0&2\\ 0&0 \end{bmatrix} }\]

Rank두 Column이 Linearly Independent이므로 다음과 같다.

\[\boxed{ \operatorname{rank}(A)=2 }\]

따라서 다음과 같다.

\[\boxed{ r=2 }\]

Singular Values이미 LA-18과 같은 구조이므로 다음과 같다.

\[\boxed{ \sigma_1=3, \qquad \sigma_2=2 }\]

Left Singular Vectors

\[\begin{gathered} \boxed{ u_1 = \begin{bmatrix} 1\\ 0\\ 0 \end{bmatrix} } \\[6pt] \boxed{ u_2 = \begin{bmatrix} 0\\ 1\\ 0 \end{bmatrix} } \end{gathered}\]

Right Singular Vectors

\[\begin{gathered} \boxed{ v_1 = \begin{bmatrix} 1\\ 0 \end{bmatrix} } \\[6pt] \boxed{ v_2 = \begin{bmatrix} 0\\ 1 \end{bmatrix} } \end{gathered}\]

Rank-1 Target이제 \(k=1\) 로 둔다. 상위 Singular Component 하나만 남긴다.

Rank-1 Approximation

\[A_1 = \sigma_1 u_1 v_1^T\]

따라서 다음과 같다.

\[\begin{aligned} A_1 &= 3 \begin{bmatrix} 1\\ 0\\ 0 \end{bmatrix} \begin{bmatrix} 1&0 \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} 3&0\\ 0&0\\ 0&0 \end{bmatrix} } \end{aligned}\]

원자료 계산과 일치한다.

Rank 확인\(A_1\)에는 Nonzero Independent Direction이 하나뿐이다. 따라서 다음과 같다.

\[\boxed{ \operatorname{rank}(A_1)=1 }\]

Residual

\[E_1 = A-A_1\]

따라서 다음과 같다.

\[\boxed{ E_1 = \begin{bmatrix} 0&0\\ 0&2\\ 0&0 \end{bmatrix} }\]

Frobenius Error 직접 계산

\[\begin{aligned} \|E_1\|_F &= \sqrt{ 0^2+2^2 }\\ &= \boxed{ 2 } \end{aligned}\]

공식과 비교Eckart–Young–Mirsky Error Formula는 다음과 같다.

\[\boxed{ \|A-A_1\|_F = \sqrt{ \sigma_2^2 } }\]

즉 다음과 같다 (\(2\)).

Spectral ErrorResidual의 최대 Singular Value는 \(\sigma_2=2\) 이므로 다음과 같다.

\[\boxed{ \|A-A_1\|_2 = 2 }\]

원자료의 수치 결과와 정확히 일치한다.

이 예제에서 두 Error가 같은 이유버린 Singular Value가 하나뿐이기 때문이다. 즉 다음과 같다.

\[\boxed{ r-k=1 }\]

따라서 다음과 같다.

\[\|E_1\|_F = \sqrt{\sigma_2^2} = \sigma_2 = \|E_1\|_2\]

일반적으로는 같지 않다버린 Singular Value가 여러 개라면 다음과 같다 (\(\|E_k\|_F \ge \|E_k\|_2\)).

Equality는 특별한 경우에만 성립한다.

Parameter Storage원래 Dense Matrix \(A \in \mathbb R^{M\times N}\) 는 \(MN\) 개의 Scalar를 저장한다.

Low-Rank FactorsRank-\(k\) Approximation을 \(A_k = U_k\Sigma_kV_k^T\) 로 저장할 수도 있지만 \(B=U_k\Sigma_k\) 와 \(C=V_k^T\) 를 합쳐 \(A_k=BC\) 로 저장할 수 있다.

Factor Shapes

\[\begin{gathered} \boxed{ B\in\mathbb R^{M\times k} } \\[6pt] \boxed{ C\in\mathbb R^{k\times N} } \end{gathered}\]

Factorized Parameter Count필요한 Scalar 수는 다음과 같다.

\[\boxed{ Mk+kN = k(M+N) }\]

Storage Reduction 조건실제로 더 적은 저장 공간을 사용하려면 \(k(M+N)<MN\) 이어야 한다.

Target Rank 조건이를 \(k\)에 대해 정리하면 다음과 같다.

\[\boxed{ k < \frac{MN}{M+N} }\]

Square Matrix Example\(M=N=d\)라면 \(d^2\) 개가 \(2dk\) 개로 줄어든다. Compression이 되려면 다음과 같다.

\[\boxed{ k<\frac d2 }\]

Matrix-Vector MultiplicationDense Matrix에서는 다음과 같다.

\[y=Ax\]

계산에 대략 \(O(MN)\) 연산이 필요하다.

Factorized Multiplication\(A_k=BC\) 이면 다음과 같다.

\[\boxed{ A_kx = B(Cx) }\]

연산량먼저 \(Cx\) 에 \(O(kN)\) 이 필요하고, \(B(Cx)\) 에 \(O(Mk)\) 가 필요하다. 따라서 다음과 같다 (\(O( k(M+N) )\)).

계산량 감소 조건저장 공간과 마찬가지로 \(k\)가 충분히 작을 때 Dense \(O(MN)\) 보다 유리하다.

SVD 계산 비용과 사용 비용 구분Low-rank Factorization을 얻기 위한 SVD 계산 자체에도 비용이 든다. 따라서 factorization cost 와 factorized inference/storage cost 를 구분해야 한다.

대규모 Matrix대규모 Matrix에서는 Full SVD 대신:

  • Partial SVD
  • Randomized SVD
  • Iterative Singular-Value Methods

등을 사용할 수 있다. 목표가 상위 \(k\) Singular Component뿐이라면 전체 Spectrum을 모두 계산할 필요가 없을 수 있다.

PCA와 연결Centered Data Matrix \(X_c\) 의 SVD를 \(X_c = U\Sigma V^T\) 라고 하자.

PCA Rank-k Reconstruction상위 \(k\)개 Singular Direction을 사용하면 다음과 같다.

\[\boxed{ X_k = U_k\Sigma_kV_k^T }\]

PCA와 최적 ReconstructionEckart–Young–Mirsky 정리에 의해 이 \(X_k\)는 Centered Data Matrix에 대한 Frobenius Norm 기준 최적 Rank-\(k\) Reconstruction이다.

PCA VarianceCovariance가 \(\frac1M X_c^TX_c\) 이면 Principal Variance는 \(\frac{\sigma_i^2}{M}\) 에 비례한다. 따라서 PCA Context에서는 큰 Singular Value를 남기는 것이 큰 Variance Direction을 남기는 것과 연결된다.

Compression과 DenoisingData Matrix에서 작은 Singular Value가 Noise-dominated Direction에 대응하는 상황이라면 Truncation이 Denoising 효과를 낼 수 있다. 하지만 small singular value = noise 가 항상 성립하는 것은 아니다. Application Assumption이 필요하다.

LoRA 연결원자료는 Low-Rank Approximation을 LoRA와 연결한다. LoRA에서는 Pretrained Weight \(W_0\) 를 고정하고 Update를 \(\Delta W = BA\) 형태로 Parameterize한다.

LoRA Shapes예를 들어 \(W_0 \in \mathbb R^{ d_{\mathrm{out}} \times d_{\mathrm{in}} }\) 라면 다음과 같다.

\[\begin{gathered} \boxed{ B \in \mathbb R^{ d_{\mathrm{out}}\times r } } \\[6pt] \boxed{ A \in \mathbb R^{ r\times d_{\mathrm{in}} } } \end{gathered}\]

Rank ConstraintMatrix Product Rank 성질에 의해 다음과 같다 (\(\operatorname{rank}( \Delta W ) \le r\)).

이것이 기본 LoRA의 직접적인 Low-rank Constraint다.

Eckart–Young과 LoRA의 차이Eckart–Young–Mirsky 정리는 이미 주어진 Matrix를 가장 잘 Rank-\(k\) Matrix로 근사하는 문제를 다룬다. 즉 다음과 같다.

\[\boxed{ \text{given }A \rightarrow \text{best rank-}k\text{ approximation} }\]

LoRA는 다른 문제다LoRA는 Training 과정에서 \(\Delta W=BA\) 를 직접 학습한다. 즉 이미 완성된 Full-rank Update Matrix에 SVD를 적용하여 top component를 자르는 Algorithm이 아니다.

따라서 정리의 직접 적용 범위Eckart–Young은

특정 Update Matrix가 이미 주어졌을 때 그 Matrix의 최적 rank-\(r\) 근사가 무엇인가

이 식을 설명할 수 있다. 하지만 LoRA가 잘 작동한다 는 사실 자체를 Eckart–Young 정리만으로 증명하지는 않는다.

“Intrinsic Rank가 매우 낮다” 주장원자료는 Eckart–Young 정리에 따라 Weight Update의 Intrinsic Rank가 매우 낮다고 설명한다. 그러나 Eckart–Young 정리는 Matrix의 Singular Spectrum이 빠르게 감소한다는 것을 보장하지 않는다.

필요한 경험적 사실Low-rank Update가 좋은 Approximation이 되려면 실제 Update Matrix의 Singular Value가 충분히 빠르게 감소하는 등의 구조가 필요하다. 이는 empirical property이다.

이지 Eckart–Young 정리의 결론은 아니다.

Rank 8이나 16\(r=8,\;16\) 같은 값은 특정 Model/Task에서 유용할 수 있는 Hyperparameter Example이다. 모든 Model에 대해 고정된 최적 Rank가 아니다.

이 식은 문장은 Eckart–Young 정리에서 유도되지 않는다. Eckart–Young이 보장하는 것은 Matrix Norm Approximation Error다.

Rank와 표현력Rank-\(k\) Matrix \(B C\) 는 Input Space에서 최대 \(k\)차원의 Intermediate Subspace를 통해 Output으로 Mapping한다. 따라서 Rank Constraint는 Linear Map의 Degrees of Freedom을 줄인다.

  • 계산량 감소

Bias–Compression Trade-off따라서 \(k\downarrow \Rightarrow \text{compression}\uparrow\) 지만 동시에 \(\|A-A_k\| \text{ may increase}\) 한다.

Choosing kTarget Rank \(k\)는 여러 기준으로 선택할 수 있다. 예를 들어 Frobenius-energy fraction \(R_k = \frac{ \sum_{i=1}^{k}\sigma_i^2 }{ \sum_{i=1}^{r}\sigma_i^2 }\) 가 특정 Threshold를 넘도록 선택할 수 있다.

Example Criterion예를 들어 \(R_k\ge0.95\) 를 요구할 수 있다. 하지만 \(95\%\) 라는 Threshold 자체는 Application-dependent Design Choice다.

Singular Value DecayLow-Rank Approximation이 효과적인 Matrix에서는 Singular Value가 빠르게 감소하는 경우가 많다. 예 다음과 같다 (\(\sigma_1 \gg \sigma_2 \gg \cdots\)).

Slow Decay반대로 \(\sigma_i\) 가 천천히 감소하면 작은 Rank로 근사했을 때 Residual Energy가 크다.

Stable Rank엄밀한 Algebraic Rank 외에 \(\operatorname{srank}(A) = \frac{ \|A\|_F^2 }{ \|A\|_2^2 } = \frac{ \sum_i\sigma_i^2 }{ \sigma_1^2 }\) 라는 Stable Rank를 사용할 수 있다.

Stable Rank의 의미Stable Rank는 실제로 0이 아닌 Singular Value 개수만 세는 대신 Singular Spectrum의 Energy Distribution을 반영한다. 항상 다음과 같다 (\(\operatorname{srank}(A) \le \operatorname{rank}(A)\)).

Truncated SVD는 가장 큰 \(k\)개 singular value와 대응 벡터만 남겨 rank-\(k\) 행렬을 만든다. Eckart–Young–Mirsky 정리는 Frobenius·spectral norm에서 이 근사가 최적임을 보이며, 버려진 특이값이 재구성 오차와 압축 손실을 정한다.
