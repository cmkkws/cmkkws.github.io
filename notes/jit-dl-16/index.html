DL-16 — In-Context Learning (ICL) Basics

파라미터 갱신 없이 프롬프트 예시로 출력을 바꾸는 학습을 다룬다.

ML·딥러닝 · DL-16업데이트 2026.09.27
  • #In-Context Learning
  • #ICL
  • #Linear Attention
  • #Induction Head
  • #Task Vector

학습 목표

프롬프트의 시연 예시가 고정된 언어 모델의 출력을 바꾸는 원리를 이해한다. 선형 attention과 한 단계 경사하강법의 특정 조건에서의 대수적 대응을 유도하고, 실제 softmax Transformer의 일반적 작동과 구별한다. Induction head, task vector, 예시 선택, many-shot ICL, test-time training의 주장 수준도 나눈다.

문제 설정

예시 데이터쌍을 \(\mathcal D_k=((x_1,y_1),\ldots,(x_k,y_k))\), 새로운 질의를 \(x_\star\), 모델의 사전학습 파라미터를 \(\theta\)라고 쓴다. 예시는 순서가 있는 프롬프트 안에 들어가므로, 집합 표기 \(\{\cdot\}\)만으로는 실제 입력을 완전히 나타내지 못한다.

문맥 내 학습의 작동 정의

ICL에서는 해당 질의를 처리하는 동안 모델 가중치 \(\theta\)를 optimizer로 갱신하지 않고, 프롬프트에 넣은 예시를 조건으로 다음 토큰 또는 응답을 예측한다. 같은 \(\theta\)라도 프롬프트가 달라지면 출력 분포가 바뀔 수 있다.

\[p_\theta(y\mid x_1,y_1,\ldots,x_k,y_k,x_\star).\]

이는 추론 방식의 정의다. 추론 중 내부 활성화와 KV cache는 바뀔 수 있지만, 보통 의미의 가중치 학습과는 다르다.

응답의 토큰 분해

응답 \(y=(y_1,\ldots,y_m)\)가 여러 토큰이면 자기회귀 모형의 확률은 다음과 같이 분해된다.

\[p_\theta(y\mid c) =\prod_{t=1}^{m}p_\theta(y_t\mid c,y_{<t}),\qquad c=(x_1,y_1,\ldots,x_k,y_k,x_\star).\]

원자료의 \(\arg\max_y\)는 가능한 전체 응답열의 최대 확률을 뜻할 수 있으나 실제 생성은 근사 탐색 또는 sampling을 쓸 수 있다.

Zero-shot, one-shot, few-shot

\(k=0\)이면 예시가 없는 zero-shot, \(k=1\)이면 one-shot, 여러 예시면 few-shot이라고 부른다. 지시문, 라벨 목록, 출력 형식 설명도 조건 정보이며, 예시가 전혀 없다고 문맥 자체가 빈 것은 아니다.

미세조정과의 차이

지도 미세조정은 훈련 데이터에 대한 손실을 줄이도록 매개변수 \(\theta\)를 최적화한다.

\[\theta_{\rm FT}\in\arg\min_\theta \sum_{(x,y)\in\mathcal D_{\rm train}}\ell(f_\theta(x),y).\]

이와 달리 표준 ICL의 각 질의에서 \(\theta_{\rm PT}\)는 고정되어 있고, 프롬프트 \(c\)가 조건 입력이 된다. SFT도 추론할 때는 고정된 SFT 가중치로 ICL을 수행할 수 있으므로 두 개념은 배타적이지 않다.

내부 활성화와 가중치의 구별

Attention은 앞선 토큰으로부터 질의 위치의 표현을 계산한다. 그 표현을 질의마다 달리 만드는 것과 가중치 행렬을 영구 변경하는 것은 다른 사건이다. “암묵적 갱신”은 아래 toy 구성에서 유효한 계산 결과의 대응이지 추론 중 저장된 행렬이 실제로 바뀐다는 말이 아니다.

조건부 확률과 진짜 posterior

\(p_\theta(y\mid c)\)는 모델의 조건부 출력 분포다. 숨은 작업 \(T\)에 관한 Bayesian posterior \(p(T\mid\mathcal D_k)\)로 반드시 해석되는 것은 아니다. Bayesian ICL은 별도의 사전분포와 데이터 생성 가정 아래 가능한 해석이다.

선형 회귀 toy 문제의 shape

원자료의 선형 모델을 명확히 확장하자. \(X=[x_1,\ldots,x_k]\in\mathbb R^{d_{\rm in}\times k}\), \(Y=[y_1,\ldots,y_k]\in\mathbb R^{d_{\rm out}\times k}\), \(W_0\in\mathbb R^{d_{\rm out}\times d_{\rm in}}\), 질의 \(q\in\mathbb R^{d_{\rm in}}\)다.

제곱 손실

예시들의 손실을 합으로 정의한다.

\[\mathcal L(W)=\frac12\|WX-Y\|_F^2 =\frac12\sum_{i=1}^k\|Wx_i-y_i\|_2^2.\]

평균 손실 \(k^{-1}\mathcal L\)을 대신 쓰면 gradient에 \(1/k\)가 추가된다. 이 차이는 학습률 또는 attention 출력 스케일에 반영해야 한다.

손실의 행렬 미분

잔차 행렬을 \(R=WX-Y\)라 하면 \(dR=(dW)X\)이고,

\[d\mathcal L =\langle R,(dW)X\rangle_F =\langle RX^T,dW\rangle_F.\]

따라서

\[\nabla_W\mathcal L(W)=(WX-Y)X^T.\]

초기점에서의 한 단계 업데이트

\(W_0\)에서 크기 \(\eta\)의 한 단계 gradient descent를 가상으로 적용하면

\[W_1=W_0-\eta(W_0X-Y)X^T =W_0+\eta(Y-W_0X)X^T.\]

이 식은 \(\eta\)를 선택한 선형 회귀 손실의 정확한 대수식이다.

질의의 가상 갱신 예측

양변에 \(q\)를 곱하면

\[W_1q=W_0q+\eta(Y-W_0X)X^Tq.\]

두 번째 항이 예시의 잔차와 질의의 내적을 모아 계산한다는 것이 핵심이다.

Key와 Value의 구성

\(K=X\), \(V=Y-W_0X\)라고 특별히 구성하고 softmax가 없는 비정규화 bilinear 선형 attention을 정의한다.

\[A_{\rm lin}(q,K,V)=\eta VK^Tq =\eta\sum_{i=1}^k(y_i-W_0x_i)(x_i^Tq).\]

그러면 \(W_0q+A_{\rm lin}(q,X,Y-W_0X)=W_1q\)다.

대수적 동치가 성립하는 범위

방금 동치는 선택한 손실, 예시 인코딩 \(K=X\), \(V=Y-W_0X\), bilinear 합, 잔차 경로 \(W_0q\), 같은 스케일 \(\eta\)를 요구한다. 모델이 이런 표현을 실제 학습했는지는 동치식만으로 알 수 없다.

일반 softmax attention과의 차이

표준 head는 보통 다음 형태다.

\[A_{\rm soft}(q,K,V) =V\,\operatorname{softmax}\!\left(\frac{K^Tq}{\sqrt{d_k}}+m\right).\]

가중치는 정규화되고 대개 음수가 아닌 데 비해, \(x_i^Tq\)는 음수일 수도 있고 합이 1일 필요가 없다. 그러므로 위 한 단계 GD 등식을 임의의 softmax head에 그대로 대입할 수 없다.

학습률과 위치별 정규화

원자료의 첫 유도에는 \(\eta=1\), 수치 예제에는 \(\eta=0.1\)을 사용한다. 일관된 식은 \(\eta VK^Tq\)다. \(1/\sqrt{d_k}\)와 softmax, 위치 mask, 여러 head의 projection이 추가되면 별도 대응 조건이 필요하다.

여러 단계 최적화와의 거리

하나의 bilinear correction이 한 번의 GD 예측과 같아도 Transformer의 모든 레이어가 같은 목적에 대해 여러 GD 단계를 정확히 수행한다는 뜻은 아니다. 비선형성, normalization, 잔차 경로와 학습된 projection의 역할은 모델별로 다르다.

예제의 입력

원자료의 1차원 예제를 그대로 보존한다. \(W_0=1\), 시연 \((x_1,y_1)=(2,6)\), 질의 \(q=3\), 스케일 \(\eta=0.1\)이다. 예시는 \(y=3x\)와 일치하지만 시연 한 점만으로 데이터 생성 규칙 전체가 증명되지는 않는다.

시연에서의 초기 예측

\[\hat y_1=W_0x_1=1\cdot2=2,\qquad r_1=\hat y_1-y_1=2-6=-4.\]

Value에는 반대 부호의 보정 잔차 \(y_1-W_0x_1=4\)를 넣는다.

제곱 손실 검산

\[\mathcal L(W_0)=\frac12(2-6)^2=8.\]

손실은 음수가 아니며, 이 값은 업데이트 전 예시점의 손실이다.

기울기 검산

\[\frac{d\mathcal L}{dW}\bigg|_{W_0} =(W_0x_1-y_1)x_1=(-4)\cdot2=-8.\]

가상 갱신 검산

\[W_1=1-0.1(-8)=1.8.\]

이 값은 비교를 위한 toy 선형 모형의 가중치다. 실제 ICL에서 언어 모델의 저장된 가중치가 \(1.8\)로 바뀐 것은 아니다.

선형 attention 계산

\[K=[2],\quad V=[4],\quad \eta VK^Tq=0.1\cdot4\cdot2\cdot3=2.4.\]

두 경로의 출력 비교

\[W_0q+A_{\rm lin}=3+2.4=5.4,\qquad W_1q=1.8\cdot3=5.4.\]

수치가 정확히 일치한다. 참 관계 \(3q=9\)와는 다르다. 한 번의 작은 GD step이 이 예제를 완전히 학습했다는 결론은 나오지 않는다.

예제의 최적 스칼라 값

이 한 점을 정확히 맞추는 스칼라 최소자승 해는 \(W=6/2=3\)이다. \(W_1=1.8\)인 이유는 선택한 \(\eta\)에서 한 step만 계산했기 때문이다. \(\eta=1/4\)이면 한 번에 \(W=3\)이 되지만 다른 예제와 안정성에는 일반화할 수 없다.

입력 스케일의 영향

같은 \((x,y)\) 관계라도 \(x\)에 상수를 곱하면 제곱손실 Hessian과 안정한 step 크기가 변한다. 본 유도에서 “attention이 GD를 구현한다”는 말은 입력 표현과 \(\eta\)의 스케일도 포함한다.

Induction head의 동기

원자료의 \([A][B]\cdots[A]\to[B]\) 패턴은 이전에 본 \(A\) 뒤에 \(B\)가 왔다는 문맥을 이용해 다음 토큰 후보 \(B\)를 강화하는 회로의 도식이다. 특정 synthetic sequence와 일부 모델 회로에서 관찰된 설명으로 이해한다.

두 단계 회로의 직관

앞선 layer가 “\(A\) 다음에 있던 \(B\)”의 정보를 앞선 위치 표현에 남기고, 뒤 layer가 현재 \(A\)와 비슷한 과거 \(A\)를 검색할 수 있다. 이 설명은 attention pattern과 표현의 구성까지 분석해야 성립한다.

복사와 작업 수행의 차이

Induction 패턴은 반복되는 토큰 연쇄를 복사하는 능력을 설명할 수 있다. 하지만 번역, 규칙 추론, 실제 라벨 일반화의 모든 ICL 성능을 단일 회로가 설명한다고 단정할 수 없다.

Task vector 가설

예시에서 작업 관련 정보를 중간 표현으로 추출해 이후 질의에 영향을 준다는 가설이다. 추출 위치와 실험적 개입을 정한 특정 구성에서는 작업 벡터를 측정하고 다른 문맥에 주입해 효과를 검사할 수 있다.

가법식의 모델 지위

원자료의

\[h^{(\ell)}(x)\approx f_\ell(x)+v_{\rm task}\]

는 가법 분해를 선택한 분석 모형이다. 임의의 레이어에서 고유한 \(v_{\rm task}\in\mathbb R^{d_{\rm model}}\)가 정확히 분리된다는 항등식이 아니다. 기준 표현 \(f_\ell\)과 추출 위치를 정해야 차이 벡터가 의미를 갖는다.

순서 불변성 주장

Transformer의 위치 정보와 causal mask 때문에 시연의 순서와 간격이 출력에 영향을 줄 수 있다. 특정 task vector가 여러 프롬프트에서 일정한 방향을 보였다는 관찰을 모든 모델·예시 순서에 대한 불변성 정리로 확대하지 않는다.

실제 원인 확인

표현의 상관관계만으로 기능을 확정할 수 없다. 활성화 교체, 평균 벡터 주입, 제거 실험 및 통제 프롬프트 등에서 예측된 출력 변화가 나타나는지 확인해야 작업 벡터 해석이 강해진다.

예시가 제공하는 정보

예시는 작업 포맷, 입력 분포, 라벨 공간, 입력과 라벨의 대응 관계를 각각 전달할 수 있다. 이 정보들이 모두 같은 중요도를 가진다고 가정할 필요는 없다.

라벨 공간과 정확한 라벨

원자료는 라벨을 섞어도 성능 저하가 작다는 일부 실험 관찰을 소개한다. 이는 특정 benchmark, 시연 수와 모델에 의존하는 경험적 결과다. 정확한 관계를 학습해야 하는 새 작업에서 라벨 정확성이 불필요하다는 일반 법칙은 아니다.

시연 선택

질의와 관련 있는 예시를 고르면 해당 작업 분포를 더 잘 보여줄 수 있다. Cosine similarity, lexical retrieval, BM25, embedding search 등은 후보 선택 방법이다. 가장 유사한 예시가 항상 최적의 시연 집합은 아니며 중복, 다양성, 라벨 균형도 고려한다.

Retrieval과 ICL의 결합

RAG가 주로 참고 문서의 내용을 가져오는 상황과 시연 \((x_i,y_i)\)를 골라 출력 형식·규칙을 알려주는 상황은 목적이 다르다. 한 시스템이 두 종류의 검색을 함께 쓸 수 있다.

예시 순서

길이 제한, 위치 편향과 recency 때문에 동일한 시연 집합도 배열 순서에 따라 결과가 달라질 수 있다. 순서에 따른 성능 차이를 평가할 때 시연 선택 효과와 구분한다.

긴 문맥의 비용

시연을 늘리려면 프롬프트 토큰을 더 써야 한다. 사전 채우기 계산과 문맥 위치·서빙 비용이 증가하며 사용 가능한 window는 시스템마다 다르다. 큰 window가 곧 충분한 정보 활용을 보장하지는 않는다.

Many-shot ICL

수십~수천 시연을 담는 설정은 긴 문맥을 활용할 수 있다. 성능 변화는 모델, 데이터 품질, 라벨 정확성, 예시 순서, 맥락 길이에 따라 측정해야 하며 증가가 무조건 단조롭다고 단정하지 않는다.

In-context fine-tuning이라는 표현

많은 예시 뒤에 모델이 새로운 규칙을 따르는 현상을 비유적으로 부를 수 있다. optimizer가 실제 가중치를 바꾼 fine-tuning과는 구별한다. 두 방법의 성능 비교도 평가 설정이 정해져야 한다.

Test-time training

TTT는 추론 시점에 일부 상태나 파라미터를 손실의 gradient로 갱신하는 별도 계열이다. 표준 ICL은 그러한 갱신을 필요로 하지 않는다. 무엇을 갱신하고 다음 질의까지 그 상태를 유지하는지가 정의의 핵심이다.

KV cache와 TTT state

일반 autoregressive KV cache는 이전 토큰에서 계산된 Key와 Value를 저장해 재사용한다. 보통 gradient가 적용되는 trainable parameter 자체가 아니다. 특정 TTT 설계가 업데이트 가능한 상태를 따로 둘 수 있으나 이를 모든 KV cache의 속성으로 설명하지 않는다.

Reasoning과의 관계

추론 토큰을 늘리는 방식, 예시를 프롬프트에 제공하는 방식, test-time gradient를 수행하는 방식은 모두 추론 시 계산을 쓸 수 있지만 수학적으로 다른 절차다. 특정 reasoning RL 모델이 TTT layer를 쓴다고 원자료만으로 결론 내리지 않는다.

DL-17의 SFT와 연결

SFT는 조건부 응답의 학습 손실로 가중치를 변경한다. SFT 뒤에도 모델이 프롬프트 예시로 새로운 작업을 수행할 수 있다. “가중치 갱신 여부”와 “예시가 있는지”는 서로 다른 두 축이다.

ML-04의 회귀 연결

원자료의 선형 attention 등식은 제곱 손실 최소화의 gradient를 이용한다. 여러 샘플의 정확한 OLS 해 \((XX^T)^{-1}XY^T\) 또는 의사역행렬 해와 한 단계 GD는 일반적으로 다르다.

일반화의 한계

질의 \(q\)에 대한 \(W_1q\)의 값이 잘 맞는다고 해서 예시 분포 밖의 질의에서도 성능이 좋다는 보장은 없다. 수치 예제에서 실제 관계의 질의값 \(9\)와 one-step 출력 \(5.4\)를 구별한다.

오개념 교정 — 수학

선형 attention과 GD의 동치는 구성한 \(K,V\), loss, 스케일에 조건부다. 표준 softmax attention이 일반적으로 그 식과 정확히 같지 않다. 임시 표현의 변화는 저장된 네트워크 가중치의 경사갱신이 아니다.

오개념 교정 — 경험적 주장

Induction head와 task vector는 관찰·가설과 회로 수준의 개입 결과로 설명한다. 라벨 무작위화의 작은 영향, 예시 수 증가의 이점, SFT보다 좋은 성능은 특정 평가에서 검증해야 한다.

핵심 식

\[\begin{aligned} \nabla_W\mathcal L(W_0)&=(W_0X-Y)X^T,\\ W_1q&=W_0q+\eta(Y-W_0X)X^Tq,\\ A_{\rm lin}(q,X,Y-W_0X)&=\eta(Y-W_0X)X^Tq. \end{aligned}\]

전체 정리

ICL은 고정된 가중치 아래에서 예시가 포함된 프롬프트에 조건화하는 추론이다. 선형 회귀·비정규화 선형 attention을 특별히 구성하면 한 단계 GD 예측과 정확히 같다. 예제의 양쪽 결과는 \(5.4\)이며, 이는 참 관계의 질의값 \(9\)와 별개다. Induction head와 task vector는 다양한 가능 기제를 설명하지만 모든 ICL의 보편 법칙은 아니다.

학습 점검

  1. 예시 손실을 합 대신 평균으로 바꾸면 attention correction의 어느 계수가 달라지는가?
  2. Softmax head가 \(VK^Tq\)와 일반적으로 같을 수 없는 이유는 무엇인가?
  3. 수치 예제에서 가중치 \(1.8\)과 저장된 LLM 가중치는 각각 무엇인가?
  4. 일반 KV cache와 gradient로 갱신하는 TTT state는 어떻게 다른가?

정리

In-context learning은 parameter를 갱신하지 않고 prompt 안의 예시와 query에 조건화해 출력을 바꾸는 추론이다. 특정한 선형 attention·제곱손실 구성에서는 한 단계 gradient descent와 계산상 대응할 수 있지만, 이를 일반 Transformer의 모든 ICL이 실제로 학습을 수행한다는 뜻으로 확대할 수 없다.
