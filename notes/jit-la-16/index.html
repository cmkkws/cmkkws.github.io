LA-16 — Eigendecomposition & Diagonalization

대각화 조건과 고유분해, 행렬 거듭제곱 및 행렬함수 연결을 정리한다.

학습 내용

  • Eigendecomposition
  • LA-15와 연결

011. Diagonalization022. Eigendecomposition033. LA-15와 연결044. Eigenvector Matrix055. Eigenvalue Matrix066. Diagonalizability의 필요충분조건

1. Diagonalization

정방행렬

\[A\in\mathbb R^{N\times N}\]

에 대해 어떤 Invertible Matrix \(P\)와 Diagonal Matrix \(D\)가 존재하여

\[\boxed{ A=PDP^{-1} }\]

로 표현할 수 있다면 \(A\)를 Diagonalizable하다고 한다.

2. Eigendecomposition

대각화에서

\[P = \begin{bmatrix} p_1&p_2&\cdots&p_N \end{bmatrix}\]

의 Column들이 \(A\)의 Eigenvector이고,

\[D = \operatorname{diag} ( \lambda_1,\dots,\lambda_N )\]

의 Diagonal Element들이 대응 Eigenvalue라면

\[\boxed{ A=PDP^{-1} }\]

를 Eigendecomposition이라고 한다.

3. LA-15와 연결

LA-15에서 Eigenvalue와 Eigenvector는

\[\boxed{ Ap_i = \lambda_ip_i }\]

를 만족했다. LA-16에서는 이러한 Eigenvector들을 하나의 Basis로 모아 Matrix 전체를 단순한 Diagonal Transformation으로 바꾸는 방법을 다룬다.

4. Eigenvector Matrix

\(A\)가 \(N\)개의 Linearly Independent Eigenvector

\[p_1,\dots,p_N\]

를 가진다고 하자. 이를 Column으로 쌓는다 다음과 같다.

\[\boxed{ P = \begin{bmatrix} p_1&p_2&\cdots&p_N \end{bmatrix} }\]

5. Eigenvalue Matrix

대응 Eigenvalue를

\[\lambda_1,\dots,\lambda_N\]

이라고 하면 다음과 같다.

\[\boxed{ D = \operatorname{diag} ( \lambda_1,\dots,\lambda_N ) }\]

6. Diagonalizability의 필요충분조건

\(N\times N\) Matrix \(A\)가 Diagonalizable일 필요충분조건은 다음과 같다.

\[\boxed{ A\text{가 }N\text{개의 선형독립 Eigenvector를 갖는 것} }\]

즉 Eigenvector들이 \(\mathbb R^N\) 또는 적절한 Field에서 Basis를 이루어야 한다.

7. Eigenbasis

\(N\)개의 Independent Eigenvector가 존재하면

\[\boxed{ \{ p_1,\dots,p_N \} }\]

을 Eigenbasis라고 할 수 있다. 이 Basis에서는 \(A\)의 작용이 단순한 Coordinate별 Scaling이 된다.

8. 서로 다른 Eigenvalue

LA-15에서 서로 다른 Eigenvalue에 대응하는 Eigenvector들은 Linearly Independent임을 보였다. 따라서 \(N\times N\) Matrix가 서로 다른 Eigenvalue를 \(N\)개 가지면 다음과 같다.

\[\boxed{ A\text{는 diagonalizable} }\]

9. 충분조건이지 필요조건은 아니다

서로 다른 Eigenvalue가 \(N\)개라는 것은 강력한 충분조건이다. 하지만 Diagonalizable하기 위해 Eigenvalue가 모두 달라야 하는 것은 아니다. Repeated Eigenvalue를 가지고도 충분한 수의 Independent Eigenvector가 존재하면 Diagonalizable하다.

10. Algebraic Multiplicity

Eigenvalue \(\lambda\)가 Characteristic Polynomial의 Root로 반복되는 횟수를

\[\boxed{ \operatorname{AM}(\lambda) }\]

즉 Algebraic Multiplicity라고 한다.

11. Geometric Multiplicity

Eigenvalue \(\lambda\)의 Eigenspace

\[E_\lambda = \mathcal N( A-\lambda I )\]

의 Dimension을

\[\boxed{ \operatorname{GM}(\lambda) = \dim E_\lambda }\]

라고 한다.

12. 두 Multiplicity의 관계

항상 다음과 같다.

\[\boxed{ 1 \le \operatorname{GM}(\lambda) \le \operatorname{AM}(\lambda) }\]

13. Repeated Eigenvalue와 대각화

Repeated Eigenvalue가 있는 경우 \(A\)가 Diagonalizable하려면 전체적으로 충분한 Independent Eigenvector가 존재해야 한다. 동치인 표현 중 하나는 각 Eigenvalue에 대해

\[\boxed{ \operatorname{GM}(\lambda) = \operatorname{AM}(\lambda) }\]

가 성립하는 것이다.

14. Defective Matrix

충분한 수의 Independent Eigenvector를 갖지 못하는 Matrix를 흔히 Defective Matrix라고 한다. 이 경우

\[\boxed{ A=PDP^{-1} }\]

형태의 Diagonalization은 불가능하다.

15. Field에 대한 주의

Real Matrix가 \(\mathbb R\) 위에서는 Diagonalizable하지 않아도 \(\mathbb C\) 위에서는 Diagonalizable할 수 있다. 따라서

\[\boxed{ \text{diagonalizable over }\mathbb R }\]

과

\[\boxed{ \text{diagonalizable over }\mathbb C }\]

를 필요하면 구분한다.

16. Eigendecomposition 유도의 시작

각 Eigenvector는

\[Ap_i = \lambda_i p_i\]

를 만족한다. 이를 모든 \(i\)에 대해 동시에 적으면 다음과 같다.

\[\boxed{ A \begin{bmatrix} p_1&p_2&\cdots&p_N \end{bmatrix} = \begin{bmatrix} \lambda_1p_1& \lambda_2p_2& \cdots& \lambda_Np_N \end{bmatrix} }\]

17. 우변의 Matrix Product

다음 식이 성립한다 다음과 같다.

\[\begin{bmatrix} \lambda_1p_1& \cdots& \lambda_Np_N \end{bmatrix} = \begin{bmatrix} p_1& \cdots& p_N \end{bmatrix} \begin{bmatrix} \lambda_1&0&\cdots&0\\ 0&\lambda_2&\cdots&0\\ \vdots&\vdots&\ddots&\vdots\\ 0&0&\cdots&\lambda_N \end{bmatrix}\]

18. Matrix Notation

따라서 다음과 같이 얻는다.

\[\boxed{ AP=PD }\]

이 식은 Diagonalization을 이해하는 가장 중요한 중간식 중 하나다.

19. 왜 $P$가 Invertible인가

\(P\)의 Column들은 다음과 같다.

\[p_1,\dots,p_N\]

이들이 Linearly Independent하므로 다음과 같다.

\[\boxed{ \operatorname{rank}(P)=N }\]

따라서

\[\boxed{ P^{-1} }\]

가 존재한다.

20. Eigendecomposition 완성

\[AP=PD\]

의 오른쪽에 \(P^{-1}\)를 곱하면 다음과 같다.

\[APP^{-1} = PDP^{-1}\]

따라서 다음과 같다.

\[\boxed{ A=PDP^{-1} }\]

21. Similarity Transformation

같은 식을 다르게 정리하면 다음과 같다.

\[\boxed{ P^{-1}AP=D }\]

즉 \(A\)와 \(D\)는 Similar Matrices다.

22. Similar Matrix의 의미

\(A\)와 \(D\)는 서로 다른 Basis에서 동일한 Linear Operator를 표현한다. \(P^{-1}\)는 Original Coordinate를 Eigenbasis Coordinate로 바꾸고, \(D\)는 Eigenbasis에서 Scaling을 수행하고, \(P\)는 다시 Original Coordinate로 되돌린다.

23. Basis Change Flow

따라서 다음과 같다.

\[\boxed{ x \rightarrow P^{-1}x \rightarrow D(P^{-1}x) \rightarrow PDP^{-1}x }\]

24. Eigenbasis에서의 단순화

Eigenbasis에서는

\[\boxed{ D = \operatorname{diag} ( \lambda_1,\dots,\lambda_N ) }\]

이므로 각 Coordinate가 서로 섞이지 않는다. 각 방향은 단순히 자신의 Eigenvalue만큼 Scaling된다.

25. Diagonalization의 핵심 의미

따라서 Diagonalization은 복잡한 Linear Transformation을

\[\boxed{ \text{basis change} \rightarrow \text{independent scaling} \rightarrow \text{inverse basis change} }\]

로 분해하는 것이다.

26. Spectral Theorem

Real Symmetric Matrix

\[\boxed{ A=A^T }\]

는 특별한 성질을 가진다. Spectral Theorem에 의해 항상 Orthonormal Eigenbasis를 가진다.

27. Orthogonal Diagonalization

따라서 Real Symmetric Matrix는

\[\boxed{ A=Q\Lambda Q^T }\]

로 표현할 수 있다. 여기서 다음과 같다.

\[\boxed{ Q^TQ = QQ^T = I }\]

28. Orthogonal Matrix

\(Q\)의 Column들은 서로 Orthogonal하고 Unit Norm을 가진다. 즉 다음과 같다.

\[\boxed{ q_i^Tq_j = \delta_{ij} }\]

29. Inverse가 Transpose

Orthogonal Matrix에서는 다음과 같다.

\[\boxed{ Q^{-1} = Q^T }\]

따라서 일반 Diagonalization

\[PDP^{-1}\]

보다 구조가 더 단순해진다.

30. Real Eigenvalues

Real Symmetric Matrix의 Eigenvalue는 모두 Real이다. 따라서

\[\boxed{ \Lambda = \operatorname{diag} ( \lambda_1,\dots,\lambda_N ) }\]

에서 모든 \(\lambda_i\in\mathbb R\)이다.

31. Different Eigenvalues의 Orthogonality

Symmetric Matrix에서는 서로 다른 Eigenvalue에 대응하는 Eigenvector를 서로 Orthogonal하게 선택할 수 있다. 이는 일반 Matrix의 Eigenvector가 단지 Linearly Independent하다는 사실보다 강한 성질이다.

32. Repeated Eigenvalue

Repeated Eigenvalue가 존재하더라도 해당 Eigenspace 내부에서 Orthogonal Basis를 선택할 수 있다. 따라서 전체적으로 Orthonormal Eigenbasis를 구성할 수 있다.

33. Spectral Decomposition

Real Symmetric Matrix의 식

\[A = Q\Lambda Q^T\]

는 다음과 같이도 쓸 수 있다 다음과 같다.

\[\boxed{ A = \sum_{i=1}^{N} \lambda_iq_iq_i^T }\]

34. Rank-One Components

각

\[q_iq_i^T\]

는 \(q_i\) 방향으로의 Rank-One Orthogonal Projection Matrix다. 따라서 Symmetric Matrix를 Eigen-direction별 Scaling의 합으로 볼 수 있다.

35. 기하학적 해석

원자료는

\[Q^T \rightarrow \Lambda \rightarrow Q\]

를 각각 회전, Scaling, 역회전으로 설명한다. 더 정확히는 \(Q\)는 Orthogonal Transformation이므로 Rotation뿐 아니라 Reflection을 포함할 수도 있다.

36. 정확한 기하학적 표현

따라서

\[\boxed{ \text{orthogonal basis change} \rightarrow \text{axis-wise scaling} \rightarrow \text{inverse orthogonal transform} }\]

이라고 표현하는 것이 가장 일반적이다.

37. Matrix Powers

Diagonalization의 중요한 응용은

\[\boxed{ A^k }\]

를 단순화하는 것이다.

\[A=PDP^{-1}\]

라고 하자.

38. Square

\[\begin{aligned} A^2 &= (PDP^{-1}) (PDP^{-1})\\ &= PD \underbrace{ P^{-1}P }_{I} DP^{-1}\\ &= PD^2P^{-1} \end{aligned}\]

39. General Power

같은 Cancellation을 반복하면 다음과 같다.

\[\boxed{ A^k = PD^kP^{-1} }\]

40. Diagonal Matrix Power

\[D = \operatorname{diag} ( \lambda_1,\dots,\lambda_N )\]

이면 다음과 같다.

\[\boxed{ D^k = \operatorname{diag} ( \lambda_1^k,\dots,\lambda_N^k ) }\]

원자료의 핵심 관계다.

41. 왜 유용한가

일반 Dense Matrix의 거듭제곱은 Matrix Multiplication을 필요로 한다. 반면 Diagonal Matrix는 각 Diagonal Entry에 Scalar Power만 적용하면 된다. 따라서 반복 Dynamics와 Matrix Function 분석이 매우 단순해진다.

42. 원자료의 직접 계산 복잡도

원자료는 \(A^k\)를 순차적으로 직접 계산하는 비용을

\[\boxed{ O(kN^3) }\]

로 설명한다. 이는 Dense Matrix Multiplication을 \(k\)에 비례하여 반복하는 Naive Method를 가정한 것이다.

43. 더 효율적인 직접 계산

하지만 Diagonalization이 없어도 Exponentiation by Squaring을 사용하면 Dense Matrix Power를 대략

\[\boxed{ O(N^3\log k) }\]

수준의 Matrix Multiplication으로 계산할 수 있다. 따라서 \(O(kN^3)\)는 유일한 방법의 Complexity가 아니다.

44. Diagonalization 비용 검수

원자료는 Diagonalization 이후

\[O(N^3+kN)\]

으로 계산된다고 설명한다. 하지만 Full Dense Matrix

\[A^k = PD^kP^{-1}\]

자체를 명시적으로 구성하려면 마지막 Dense Matrix Multiplication에도 일반적으로

\[\boxed{ O(N^3) }\]

비용이 필요하다.

45. 정확한 Complexity 관점

Dense Setting에서는 대략

\[\boxed{ \text{eigendecomposition} = O(N^3) }\]

이고,

\[\boxed{ D^k }\]

계산은 \(N\)개의 Scalar Power 계산이다. 최종 Full Matrix를 재구성하면 Dense Matrix Multiplication 비용이 다시 필요하다.

46. Diagonalization의 실제 장점

따라서 Diagonalization의 가장 중요한 장점은 단순히 한 번의 \(A^k\) 계산 Complexity만 줄이는 것이 아니다. 특히 다음 상황에서 유용하다 다음과 같다.

\[\begin{gathered} \boxed{ \text{많은 }k\text{에 대해 반복 계산} } \\[6pt] \boxed{ A^kx\text{만 필요한 경우} } \\[6pt] \boxed{ \text{asymptotic behavior 분석} } \\[6pt] \boxed{ \text{matrix functions 계산} } \end{gathered}\]

47. Matrix Power Applied to Vector

만약 Full \(A^k\)가 아니라

\[A^kx\]

만 필요하다면 다음과 같다.

\[\boxed{ A^kx = PD^kP^{-1}x }\]

Diagonalization이 이미 알려져 있다면 두 번의 Dense Matrix-Vector Multiplication과 Diagonal Scaling으로 계산할 수 있다.

48. Matrix Functions

Diagonalization은 Matrix Power보다 더 일반적으로 Matrix Function을 계산하는 데 사용된다. 함수 \(f\)에 대해

\[\boxed{ f(A) = Pf(D)P^{-1} }\]

로 정의할 수 있다.

49. Function on Diagonal Matrix

\[D = \operatorname{diag} ( \lambda_1,\dots,\lambda_N )\]

이면 다음과 같다.

\[\boxed{ f(D) = \operatorname{diag} ( f(\lambda_1),\dots,f(\lambda_N) ) }\]

50. Matrix Exponential

대표적으로 다음과 같다.

\[\boxed{ e^{At} = Pe^{Dt}P^{-1} }\]

그리고 다음과 같다.

\[\boxed{ e^{Dt} = \operatorname{diag} ( e^{\lambda_1t}, \dots, e^{\lambda_Nt} ) }\]

51. Matrix Inverse

모든 Eigenvalue가 0이 아니면 다음과 같다.

\[\boxed{ A^{-1} = PD^{-1}P^{-1} }\]

여기서 다음과 같다.

\[D^{-1} = \operatorname{diag} \left( \frac1{\lambda_1}, \dots, \frac1{\lambda_N} \right)\]

52. Singular Condition

따라서 Diagonalizable Matrix에서는 다음과 같다.

\[\boxed{ A\text{ invertible} \iff \lambda_i\neq0 \quad\forall i }\]

이는

\[\det(A) = \prod_i\lambda_i\]

와도 일치한다.

53. Repeated Dynamics

\[x_{t+1} = Ax_t\]

라면 다음과 같다.

\[\boxed{ x_t = A^tx_0 = PD^tP^{-1}x_0 }\]

Eigenbasis에서는 각 Component가 독립적으로

\[\lambda_i^t\]

만큼 변한다.

54. Spectral Radius 연결

LA-15에서

\[\boxed{ \rho(A) = \max_i|\lambda_i| }\]

였다. Diagonalization은 왜 Eigenvalue가 장기 Dynamics를 결정하는지 직접 보여준다.

55. Numerical Example

원자료의 Matrix는 다음과 같다.

\[\boxed{ S = \begin{bmatrix} 3&1\\ 1&3 \end{bmatrix} }\]

Real Symmetric Matrix이므로 Spectral Theorem을 적용할 수 있다.

56. Characteristic Equation

\[S-\lambda I = \begin{bmatrix} 3-\lambda&1\\ 1&3-\lambda \end{bmatrix}\]

따라서 다음과 같다.

\[\det( S-\lambda I ) = (3-\lambda)^2-1\]

57. Polynomial Expansion

\[\begin{aligned} (3-\lambda)^2-1 &= 9-6\lambda+\lambda^2-1\\ &= \lambda^2-6\lambda+8 \end{aligned}\]

58. Factorization

\[\boxed{ \lambda^2-6\lambda+8 = (\lambda-4)(\lambda-2) }\]

따라서 다음과 같다.

\[\boxed{ \lambda_1=4, \qquad \lambda_2=2 }\]

59. First Eigenvector

\(\lambda_1=4\)일 때 다음과 같다.

\[S-4I = \begin{bmatrix} -1&1\\ 1&-1 \end{bmatrix}\]

따라서

\[-x_1+x_2=0\]

이고 다음과 같다.

\[\boxed{ x_1=x_2 }\]

60. First Unit Eigenvector

대표 Eigenvector를

\[\begin{bmatrix} 1\\ 1 \end{bmatrix}\]

로 선택하면 Norm은 \(\sqrt2\)다. 따라서 다음과 같다.

\[\boxed{ q_1 = \frac1{\sqrt2} \begin{bmatrix} 1\\ 1 \end{bmatrix} }\]

61. Second Eigenvector

\(\lambda_2=2\)이면 다음과 같다.

\[S-2I = \begin{bmatrix} 1&1\\ 1&1 \end{bmatrix}\]

따라서 다음과 같다.

\[x_1+x_2=0\]

62. Second Unit Eigenvector

원자료처럼

\[\boxed{ q_2 = \frac1{\sqrt2} \begin{bmatrix} -1\\ 1 \end{bmatrix} }\]

를 선택할 수 있다. Eigenvector의 부호는 임의이므로

\[\frac1{\sqrt2} \begin{bmatrix} 1\\ -1 \end{bmatrix}\]

도 동일하게 유효하다.

63. Orthogonality Check

\[q_1^Tq_2 = \frac12 \begin{bmatrix} 1&1 \end{bmatrix} \begin{bmatrix} -1\\ 1 \end{bmatrix} = 0\]

따라서 다음과 같다.

\[\boxed{ q_1\perp q_2 }\]

64. Orthogonal Matrix

두 Unit Eigenvector를 Column으로 배치한다 다음과 같다.

\[\boxed{ Q = \frac1{\sqrt2} \begin{bmatrix} 1&-1\\ 1&1 \end{bmatrix} }\]

65. Orthogonality of $Q$

\[\boxed{ Q^TQ=I }\]

따라서 다음과 같다.

\[\boxed{ Q^{-1}=Q^T }\]

66. Eigenvalue Matrix

\[\boxed{ \Lambda = \begin{bmatrix} 4&0\\ 0&2 \end{bmatrix} }\]

따라서 다음과 같다.

\[\boxed{ S = Q\Lambda Q^T }\]

67. Fifth Power

\[\boxed{ S^5 = Q\Lambda^5Q^T }\]

68. Diagonal Power

\[\Lambda^5 = \begin{bmatrix} 4^5&0\\ 0&2^5 \end{bmatrix}\]

이므로 다음과 같다.

\[\boxed{ \Lambda^5 = \begin{bmatrix} 1024&0\\ 0&32 \end{bmatrix} }\]

69. First Multiplication

\[Q\Lambda^5 = \frac1{\sqrt2} \begin{bmatrix} 1&-1\\ 1&1 \end{bmatrix} \begin{bmatrix} 1024&0\\ 0&32 \end{bmatrix}\]

따라서 다음과 같다.

\[\boxed{ Q\Lambda^5 = \frac1{\sqrt2} \begin{bmatrix} 1024&-32\\ 1024&32 \end{bmatrix} }\]

70. Multiply by $Q^T$

\[Q^T = \frac1{\sqrt2} \begin{bmatrix} 1&1\\ -1&1 \end{bmatrix}\]

이므로 다음과 같다.

\[S^5 = \frac12 \begin{bmatrix} 1024&-32\\ 1024&32 \end{bmatrix} \begin{bmatrix} 1&1\\ -1&1 \end{bmatrix}\]

71. Final Result

Matrix Multiplication을 수행하면 다음과 같다.

\[\boxed{ S^5 = \frac12 \begin{bmatrix} 1056&992\\ 992&1056 \end{bmatrix} }\]

따라서 다음과 같다.

\[\boxed{ S^5 = \begin{bmatrix} 528&496\\ 496&528 \end{bmatrix} }\]

원자료의 수치 결과와 일치한다.

72. Numerical Example의 의미

직접 \(S\)를 다섯 번 곱하는 대신

\[\boxed{ 4^5, \qquad 2^5 }\]

라는 Scalar Power를 계산한 뒤 Basis Transformation으로 복원했다. 이것이 Diagonalization의 핵심 계산 구조다.

73. Symmetric Matrix의 Spectral Expansion

이번 예제에서는

\[\boxed{ S = 4q_1q_1^T + 2q_2q_2^T }\]

로도 표현할 수 있다.

74. Matrix Power의 Spectral Expansion

따라서 다음과 같다.

\[\boxed{ S^5 = 4^5q_1q_1^T + 2^5q_2q_2^T }\]

이 표현은 각 Eigen-direction의 Contribution을 직접 보여준다.

75. PCA 연결

원자료는 Eigendecomposition을 Principal Component Analysis와 연결한다. Data Matrix를

\[X \in \mathbb R^{M\times D}\]

라고 하자.

76. Centered Data

각 Feature의 평균을 제거한 Data를

\[\boxed{ X_c }\]

라고 하자. PCA에서 Covariance Matrix를 구성할 때 이 Centering 과정이 중요하다.

77. Covariance Matrix

Population-style normalization을 사용하면 다음과 같다.

\[\boxed{ \Sigma = \frac1M X_c^TX_c }\]

Sample Covariance에서는 Convention에 따라

\[\boxed{ \frac1{M-1} X_c^TX_c }\]

를 사용할 수도 있다.

78. 원자료 식의 조건

원자료에는

\[\Sigma = \frac1N X^TX\]

형태가 제시되어 있다. 이것이 Covariance Matrix가 되려면 \(X\)가 이미 Column-wise Centered Data라는 조건이 필요하다. 그렇지 않으면 \(X^TX/N\)은 일반적으로 Second-Moment Matrix다.

79. Covariance Matrix는 Symmetric

\[\begin{aligned} \Sigma^T &= \left( \frac1M X_c^TX_c \right)^T\\ &= \frac1M X_c^TX_c\\ &= \Sigma \end{aligned}\]

따라서 다음과 같다.

\[\boxed{ \Sigma=\Sigma^T }\]

80. Positive Semidefinite

임의의 \(v\)에 대해 다음과 같다.

\[\begin{aligned} v^T\Sigma v &= \frac1M v^TX_c^TX_cv\\ &= \frac1M \|X_cv\|_2^2\\ &\ge0 \end{aligned}\]

따라서 다음과 같다.

\[\boxed{ \Sigma\succeq0 }\]

81. PCA Eigendecomposition

Spectral Theorem에 의해 다음과 같다.

\[\boxed{ \Sigma = Q\Lambda Q^T }\]

\(Q\)의 Column들은 Covariance Matrix의 Orthonormal Eigenvectors다.

82. Principal Directions

Eigenvector

\[q_i\]

는 Data Space의 Principal Direction을 나타낸다. 대응 Eigenvalue

\[\lambda_i\]

는 그 Direction에서의 Variance를 나타낸다.

83. Variance along a Direction

Unit Vector \(q_i\)에 Projection한 Data의 Variance는 다음과 같다.

\[\boxed{ q_i^T \Sigma q_i = \lambda_i }\]

84. Largest Principal Component

가장 큰 Eigenvalue

\[\lambda_1\]

에 대응하는 Eigenvector는 가장 큰 Variance를 갖는 Direction이다. 즉 첫 번째 Principal Component Direction이다.

85. PCA Coordinates

Data를 Eigenbasis로 변환하면 다음과 같다.

\[\boxed{ Z = X_cQ }\]

86. Transformed Covariance

\(Z\)의 Covariance는 다음과 같다.

\[\begin{aligned} \frac1MZ^TZ &= Q^T \left( \frac1MX_c^TX_c \right) Q\\ &= Q^T\Sigma Q\\ &= \boxed{ \Lambda } \end{aligned}\]

87. Uncorrelated Components

\(\Lambda\)가 Diagonal이므로 서로 다른 Principal Components 사이의 Covariance는 0이다. 따라서 PCA Coordinate들은 다음과 같다.

\[\boxed{ \text{uncorrelated} }\]

88. Uncorrelated와 Independent 구분

하지만

\[\boxed{ \text{uncorrelated} \not\Rightarrow \text{independent} }\]

가 일반적이다. Gaussian Distribution과 같은 추가 조건에서만 두 개념이 더 강하게 연결된다.

89. PCA와 Dimensionality Reduction

Eigenvalue가 큰 Direction 몇 개만 선택하면

\[\boxed{ Q_r = [ q_1,\dots,q_r ] }\]

로 Low-Dimensional Representation을 만들 수 있다 다음과 같다.

\[\boxed{ Z_r = X_cQ_r }\]

90. Explained Variance

전체 Variance는 다음과 같다.

\[\boxed{ \operatorname{Tr}(\Sigma) = \sum_i\lambda_i }\]

상위 \(r\)개 Component가 설명하는 Variance 비율은

\[\boxed{ \frac{ \sum_{i=1}^{r}\lambda_i }{ \sum_{i=1}^{D}\lambda_i } }\]

로 나타낼 수 있다.

91. Embedding Analysis 연결

LLM Embedding이나 Hidden Representation을 수집하여 PCA를 적용하면 Representation의 주요 Variance Direction을 분석할 수 있다. 다만 PCA의 큰 Variance Direction이 반드시 Semantically 중요한 Direction이라는 보장은 없다.

92. State-Space Model 연결

원자료는 Continuous-Time SSM

\[\boxed{ \dot h(t) = Ah(t) + Bx(t) }\]

과 Eigendecomposition을 연결한다.

93. Homogeneous System

우선 Input을 제외한

\[\boxed{ \dot h(t) = Ah(t) }\]

를 생각한다. 해는 다음과 같다.

\[\boxed{ h(t) = e^{At}h(0) }\]

94. Diagonalizable Transition Matrix

만약

\[A=PDP^{-1}\]

이면 다음과 같다.

\[\boxed{ e^{At} = Pe^{Dt}P^{-1} }\]

95. Element-Wise Exponential

\[D = \operatorname{diag} ( \lambda_1,\dots,\lambda_N )\]

이면 다음과 같다.

\[\boxed{ e^{Dt} = \operatorname{diag} ( e^{\lambda_1t}, \dots, e^{\lambda_Nt} ) }\]

96. Independent Modes

Eigenbasis에서는 State Dynamics가 Mode별로 분리된다. 각 Mode는

\[\boxed{ e^{\lambda_it} }\]

에 따라 독립적으로 증가하거나 감소한다.

97. Stability 연결

Continuous-Time System에서는

\[\boxed{ \operatorname{Re}(\lambda_i)<0 }\]

이면 해당 Mode가 Exponentially Decay한다. 모든 Mode가 이 조건을 만족하면 Zero-input System은 Exponentially Stable하다.

98. SSM 계산 효율에 대한 원자료 주장

원자료는 \(A\)를 Diagonalize하여

\[O(N^2) \rightarrow O(N)\]

Element-wise State Mixing으로 바꾸고 이것이 Mamba/S4의 Linear-time Decoding을 가능하게 한다고 설명한다. 이 설명은 핵심 아이디어를 지나치게 단순화한다.

99. Diagonal State Transition 자체의 장점

State Transition Matrix가 실제로 Diagonal이라면

\[\boxed{ Dh }\]

는 Element-wise Multiplication이므로

\[\boxed{ O(N) }\]

에 계산할 수 있다. Dense

\[Ah\]

는 일반적으로 다음과 같다.

\[\boxed{ O(N^2) }\]

이 차이는 정확하다.

100. 일반 Dense Matrix 대각화의 비용

하지만 임의의 Dense Matrix

\[A=PDP^{-1}\]

를 매 Step 적용하면

\[Ah = PDP^{-1}h\]

에서 \(P\)와 \(P^{-1}\)의 Dense Matrix-Vector Multiplication이 필요하다. 따라서 단순히 \(A\)가 Diagonalizable하다는 이유만으로 매 Step 계산이 자동으로

\[O(N)\]

이 되는 것은 아니다.

101. 구조화된 SSM의 핵심

S4 계열에서는 State Matrix에 특별한 Structure를 부여하고 이를 효율적으로 계산할 수 있도록 설계한다. 따라서 효율성은 단순한 일반 Eigendecomposition 하나가 아니라 Structured Parameterization과 Algorithm에서 나온다.

102. Mamba에 대한 주의

Mamba는 Selective State-Space Model을 사용하며 State Update의 일부 Parameter가 Input에 따라 달라질 수 있다. 따라서 전체 Architecture를

\[\boxed{ A=PDP^{-1} }\]

인 하나의 고정된 Dense Matrix 대각화만으로 설명하는 것은 부정확하다.

103. Linear-Time Sequence Processing

SSM 계열이 긴 Sequence를 효율적으로 처리하는 핵심은 Attention처럼 모든 Token Pair의

\[S^2\]

Interaction Matrix를 직접 구성하지 않고 State Recurrence 또는 Scan Structure를 활용한다는 데 있다.

\[\boxed{ A = PDP^{-1} }\]

105. 핵심 식 — Eigenvector Matrix Relation

\[\boxed{ AP = PD }\]

106. 핵심 식 — Similarity Transform

\[\boxed{ P^{-1}AP = D }\]

107. 핵심 식 — Spectral Theorem

Real Symmetric Matrix에 대해

\[\boxed{ A = Q\Lambda Q^T }\]

이고 다음과 같다.

\[\boxed{ Q^TQ=I }\]

108. 핵심 식 — Spectral Decomposition

\[\boxed{ A = \sum_i \lambda_iq_iq_i^T }\]

109. 핵심 식 — Matrix Power

\[\boxed{ A^k = PD^kP^{-1} }\]

110. 핵심 식 — Diagonal Power

\[\boxed{ D^k = \operatorname{diag} ( \lambda_1^k,\dots,\lambda_N^k ) }\]

111. 핵심 식 — Matrix Function

\[\boxed{ f(A) = Pf(D)P^{-1} }\]

112. 핵심 식 — Matrix Exponential

\[\boxed{ e^{At} = Pe^{Dt}P^{-1} }\]

113. 혼동하기 쉬운 부분 — 대각화 가능 조건

Eigenvalue가 존재한다고 해서 Matrix가 자동으로 Diagonalizable한 것은 아니다. 필요한 것은 다음과 같다.

\[\boxed{ N\text{개의 linearly independent eigenvectors} }\]

114. 혼동하기 쉬운 부분 — 서로 다른 Eigenvalue

서로 다른 Eigenvalue가 \(N\)개이면 Diagonalizable하다는 것은 충분조건이다. Repeated Eigenvalue가 있다고 바로 Diagonalization 불가능한 것은 아니다.

115. 혼동하기 쉬운 부분 — Eigendecomposition과 Spectral Theorem

일반 Diagonalizable Matrix:

\[\boxed{ A=PDP^{-1} }\]

Real Symmetric Matrix 다음과 같다.

\[\boxed{ A=Q\Lambda Q^T }\]

후자가 더 강한 구조다.

116. 혼동하기 쉬운 부분 — Orthogonal Transformation

Orthogonal Matrix는 Norm과 Angle을 보존한다. 하지만 반드시 순수 Rotation만 나타내는 것은 아니다.

\[\det(Q)=-1\]

이면 Reflection을 포함할 수 있다.

117. 혼동하기 쉬운 부분 — Matrix Power Complexity

Diagonalization은 Matrix Power를 수학적으로 매우 단순하게 만든다. 하지만 Full Dense Matrix \(A^k\)를 실제로 구성하는 연산이 항상

\[O(N^3+kN)\]

에서 정확히 끝난다고 볼 수는 없다. Dense Basis Transformation 비용을 고려해야 한다.

118. 혼동하기 쉬운 부분 — PCA Covariance

\[\frac1N X^TX\]

를 Covariance라고 부르려면 일반적으로 \(X\)가 Centered되어 있어야 한다. Centering이 없다면 Second-Moment Matrix와 Covariance를 구분해야 한다.

119. 혼동하기 쉬운 부분 — PCA Components

PCA Component는 서로 Uncorrelated하지만 일반적으로 Independent라고 보장할 수는 없다.

120. 혼동하기 쉬운 부분 — SSM 효율

임의의 Dense Matrix가 Diagonalizable하다는 사실만으로 Dense State Update가 자동으로 Linear Cost가 되는 것은 아니다. 실제 효율성에는 Matrix Structure와 Implementation이 필요하다.

121. 전체 개념 연결

LA-15에서는

\[\boxed{ Ap_i = \lambda_ip_i }\]

를 배웠다. LA-16에서는 Eigenvector들을 Basis Matrix \(P\)로 모아

\[\boxed{ AP=PD }\]

를 만든다.

122. Diagonalization Flow

\(P\)가 Invertible하므로

\[\boxed{ AP=PD }\]

에서 다음과 같이 얻는다.

\[\boxed{ A=PDP^{-1} }\]

즉 다음과 같다.

\[\boxed{ \text{Eigenvectors} \rightarrow \text{Eigenbasis} \rightarrow \text{Diagonalization} }\]

123. Symmetric Matrix Flow

Real Symmetric Matrix에서는 Eigenbasis를 Orthonormal하게 선택할 수 있다. 따라서 다음과 같다.

\[\boxed{ A = Q\Lambda Q^T }\]

이것이 Spectral Theorem이다.

124. Computational Flow

Diagonalization을 사용하면

\[\boxed{ A^k = PD^kP^{-1} }\]

이고 다음과 같다.

\[\boxed{ e^{At} = Pe^{Dt}P^{-1} }\]

따라서 Matrix Function을 Eigenvalue별 Scalar Function으로 분해할 수 있다.

125. PCA Flow

Centered Data에서

\[\boxed{ \Sigma = \frac1N X_c^TX_c }\]

를 만들고

\[\boxed{ \Sigma = Q\Lambda Q^T }\]

로 분해한다. 그 결과 Eigenvector는 Principal Direction, Eigenvalue는 해당 방향의 Variance가 된다.

126. SSM Flow

Linear State Dynamics에서는

\[\boxed{ \dot h=Ah }\]

의 해가 다음과 같다.

\[\boxed{ h(t) = e^{At}h(0) }\]

Diagonalization이 가능하면

\[\boxed{ e^{At} = Pe^{Dt}P^{-1} }\]

로 Mode별 Dynamics를 분리할 수 있다.

127. 정리

Diagonalization은 Square Matrix \(A\)를 Eigenvector Basis에서 Diagonal Matrix로 표현하는 방법이다. \(A\)가 \(N\)개의 Linearly Independent Eigenvector

\[p_1,\dots,p_N\]

를 가지면

\[\boxed{ P = [ p_1,\dots,p_N ] }\]

를 만들 수 있다. 각 Eigenvalue를

\[\lambda_1,\dots,\lambda_N\]

이라 하면 다음과 같다.

\[\boxed{ D = \operatorname{diag} ( \lambda_1,\dots,\lambda_N ) }\]

각 Eigenvalue Equation

\[Ap_i = \lambda_ip_i\]

을 Column 단위로 결합하면 다음과 같이 얻는다.

\[\boxed{ AP=PD }\]

\(P\)의 Column이 Linearly Independent이므로 \(P^{-1}\)이 존재하며 다음과 같다.

\[\boxed{ A=PDP^{-1} }\]

동일하게

\[\boxed{ P^{-1}AP=D }\]

이므로 \(A\)와 \(D\)는 Similar Matrix다. 즉 \(D\)는 Eigenbasis에서 \(A\)를 표현한 Matrix다. Diagonalizability의 핵심 조건은

\[\boxed{ N\text{개의 linearly independent eigenvectors} }\]

가 존재하는 것이다. 서로 다른 Eigenvalue가 \(N\)개이면 자동으로 이 조건을 만족하지만, 이것은 충분조건이지 필요조건은 아니다. Repeated Eigenvalue가 있어도 충분한 Eigenvector가 존재하면 Diagonalizable하다. Real Symmetric Matrix는 Spectral Theorem에 의해 항상 Orthogonally Diagonalizable하다 다음과 같다.

\[\boxed{ A = Q\Lambda Q^T }\]

여기서

\[\boxed{ Q^TQ=I }\]

이고 \(Q\)의 Column은 Orthonormal Eigenvector다. Diagonalization의 중요한 장점은 Matrix Power와 Matrix Function을 단순화한다는 것이다.

\[\boxed{ A^k = PD^kP^{-1} }\]

이고 다음과 같다.

\[\boxed{ D^k = \operatorname{diag} ( \lambda_1^k,\dots,\lambda_N^k ) }\]

마찬가지로

\[\boxed{ f(A) = Pf(D)P^{-1} }\]

이며, 특히 다음과 같다.

\[\boxed{ e^{At} = Pe^{Dt}P^{-1} }\]

원자료의 수치 예제에서는

\[S = \begin{bmatrix} 3&1\\ 1&3 \end{bmatrix}\]

이고 Eigenvalue는 다음과 같다.

\[\boxed{ 4,\;2 }\]

Normalized Eigenvector는 다음과 같다.

\[\begin{gathered} \boxed{ q_1 = \frac1{\sqrt2} \begin{bmatrix} 1\\ 1 \end{bmatrix} } \\[6pt] \boxed{ q_2 = \frac1{\sqrt2} \begin{bmatrix} -1\\ 1 \end{bmatrix} } \end{gathered}\]

따라서

\[\begin{gathered} \boxed{ Q = \frac1{\sqrt2} \begin{bmatrix} 1&-1\\ 1&1 \end{bmatrix} } \\[6pt] \boxed{ \Lambda = \begin{bmatrix} 4&0\\ 0&2 \end{bmatrix} } \end{gathered}\]

이고 다음과 같다.

\[\boxed{ S = Q\Lambda Q^T }\]

다섯 제곱은

\[\boxed{ S^5 = Q\Lambda^5Q^T }\]

이고

\[\boxed{ \Lambda^5 = \begin{bmatrix} 1024&0\\ 0&32 \end{bmatrix} }\]

이므로 다음과 같다.

\[\boxed{ S^5 = \begin{bmatrix} 528&496\\ 496&528 \end{bmatrix} }\]

PCA에서는 Centered Data Matrix \(X_c\)의 Covariance Matrix

\[\boxed{ \Sigma = \frac1N X_c^TX_c }\]

가 Symmetric Positive Semidefinite이므로

\[\boxed{ \Sigma = Q\Lambda Q^T }\]

로 Orthogonally Diagonalize할 수 있다. 이때 \(Q\)의 Column은 Principal Directions이고 \(\lambda_i\)는 해당 방향의 Variance다. 변환된 Data

\[\boxed{ Z=X_cQ }\]

의 Covariance는

\[\boxed{ Q^T\Sigma Q = \Lambda }\]

이므로 Principal Components는 서로 Uncorrelated하다. SSM에서는

\[\boxed{ \dot h=Ah }\]

의 State Transition이 다음과 같이 표현된다.

\[\boxed{ e^{At} }\]

\(A\)가 Diagonalizable하면

\[\boxed{ e^{At} = Pe^{Dt}P^{-1} }\]

이 되어 Dynamics를 Eigenmode별로 분석할 수 있다. 다만 임의의 Dense Matrix를 대각화했다는 사실만으로 매 Step의 Dense State Mixing이 자동으로 \(O(N)\)이 되는 것은 아니다. S4/Mamba와 같은 Efficient SSM의 계산 효율에는 실제 Matrix Structure, Recurrence/Scan Algorithm, Parameterization이 추가로 중요하다. 따라서 LA-16 전체 흐름은

\[\boxed{ \text{Eigenvalue/Eigenvector} \rightarrow \text{Eigenbasis} \rightarrow \text{Diagonalization} }\]

에서 시작하여

\[\boxed{ \text{Diagonalization} \rightarrow \text{Matrix Powers / Matrix Functions} }\]

으로 확장된다. Machine Learning에서는

\[\boxed{ \text{Symmetric Eigendecomposition} \rightarrow \text{PCA} }\]

와 연결되고, Sequence Model에서는

\[\boxed{ \text{Eigendecomposition} \rightarrow \text{State-space dynamics analysis} }\]

로 연결된다.
