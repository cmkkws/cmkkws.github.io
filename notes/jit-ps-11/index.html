PS-11 — Likelihood, Log-Likelihood, & Negative Log-Likelihood

Likelihood, Log-Likelihood, Negative Log-Likelihood의 정의와 최적화 관계를 정리한다.

1. Likelihood

관측 데이터셋을

\[\mathcal D = \{x_1,x_2,\dots,x_N\}\]

라고 하자.

확률모델의 파라미터를

\[\theta\]

라고 하면 Likelihood는 관측된 데이터를 고정한 상태에서 어떤 파라미터 \(\theta\)가 이 데이터를 얼마나 잘 설명하는지를 나타내는 함수다.

\[\boxed{ L(\theta\mid\mathcal D) = p(\mathcal D\mid\theta) }\]

중요한 점은

\[p(\mathcal D\mid\theta)\]

와

\[L(\theta\mid\mathcal D)\]

가 같은 수식값을 사용하지만 어떤 변수를 함수의 입력으로 보는지가 다르다는 것이다.

2. Probability vs Likelihood

확률은 파라미터를 고정한 상태에서 데이터가 어떻게 변하는지를 본다.

\[\boxed{ p(x\mid\theta) }\]

여기서는

\[\theta\]

가 고정되고

\[x\]

가 변수다.

반대로 Likelihood에서는 이미 데이터 \(x\)를 관측했다고 가정한다.

\[\boxed{ L(\theta\mid x) = p(x\mid\theta) }\]

여기서는

\[x\]

가 고정되고

\[\theta\]

가 변수다.

따라서

\[\boxed{ \text{Probability: }x\text{ varies} }\]
\[\boxed{ \text{Likelihood: }\theta\text{ varies} }\]

로 구분한다.

3. Likelihood는 Parameter Distribution이 아니다

Likelihood를

\[L(\theta\mid x)\]

라고 쓴다고 해서 이것이 \(\theta\)에 대한 Probability Distribution이라는 뜻은 아니다.

일반적으로

\[\boxed{ \int L(\theta\mid x)\,d\theta \neq1 }\]

일 수 있다.

즉 Likelihood는 Parameter Space에서 정규화된 Probability Density일 필요가 없다.

Likelihood의 역할은 서로 다른 \(\theta\) 값들이 관측 데이터를 얼마나 잘 설명하는지를 상대적으로 비교하는 것이다.

4. i.i.d. Dataset

관측 데이터

\[x_1,\dots,x_N\]

이 서로 독립이며 동일한 분포에서 추출되었다고 가정하자.

이를 i.i.d.라고 한다.

\[\boxed{ x_i \overset{\text{i.i.d.}}{\sim} p(x\mid\theta) }\]

독립성에 의해 Joint Probability는 각 Sample Probability의 곱으로 분해된다.

\[\boxed{ p(x_1,\dots,x_N\mid\theta) = \prod_{i=1}^{N} p(x_i\mid\theta) }\]

따라서 Dataset Likelihood는

\[\boxed{ L(\theta\mid\mathcal D) = \prod_{i=1}^{N} p(x_i\mid\theta) }\]

5. Maximum Likelihood Estimation

관측된 Dataset을 가장 잘 설명하는 Parameter를 찾는 방법이 Maximum Likelihood Estimation, MLE다.

\[\boxed{ \hat\theta_{\mathrm{MLE}} = \arg\max_\theta L(\theta\mid\mathcal D) }\]

i.i.d. 가정에서는

\[\boxed{ \hat\theta_{\mathrm{MLE}} = \arg\max_\theta \prod_{i=1}^{N} p(x_i\mid\theta) }\]

6. 왜 Probability Product가 문제인가

Dataset Size \(N\)이 커지면 매우 작은 Probability를 계속 곱하게 된다.

예를 들어 각 Probability가 대략

\[0.01\]

정도라고 하면

\[(0.01)^{1000}\]

과 같은 값은 극단적으로 작아진다.

유한 정밀도의 Floating-Point System에서는 이런 값이 표현 가능한 최소값보다 작아져

\[\boxed{ 0 }\]

으로 Underflow될 수 있다.

따라서 실제 계산에서는 Probability Product를 그대로 사용하지 않는다.

7. Log-Likelihood

Likelihood에 자연로그를 적용한 함수를 Log-Likelihood라고 한다.

\[\boxed{ \ell(\theta) = \log L(\theta\mid\mathcal D) }\]

i.i.d. Likelihood를 대입하면

\[\ell(\theta) = \log \left[ \prod_{i=1}^{N} p(x_i\mid\theta) \right]\]

로그의 곱셈 법칙

\[\log(ab)=\log a+\log b\]

를 이용하면

\[\boxed{ \ell(\theta) = \sum_{i=1}^{N} \log p(x_i\mid\theta) }\]

8. Product에서 Sum으로

Likelihood에서는

\[\prod_{i=1}^{N} p(x_i\mid\theta)\]

를 계산해야 한다.

Log-Likelihood에서는 이를

\[\sum_{i=1}^{N} \log p(x_i\mid\theta)\]

로 바꾼다.

따라서

\[\boxed{ \text{Probability Product} \xrightarrow{\log} \text{Log-Probability Sum} }\]

이 변환은 수치적으로 훨씬 안정적이고 미분도 단순하게 만든다.

9. Log-Likelihood 유도

Dataset Likelihood는

\[L(\theta) = p(x_1,\dots,x_N\mid\theta)\]

독립성에 의해

\[L(\theta) = \prod_{i=1}^{N} p(x_i\mid\theta)\]

양변에 Log를 취하면

\[\log L(\theta) = \log \left( \prod_{i=1}^{N} p(x_i\mid\theta) \right)\]

Logarithm의 곱셈 법칙을 적용하면

\[\begin{aligned} \log L(\theta) &= \log p(x_1\mid\theta) + \cdots + \log p(x_N\mid\theta)\\ &= \sum_{i=1}^{N} \log p(x_i\mid\theta) \end{aligned}\]

따라서

\[\boxed{ \ell(\theta) = \sum_{i=1}^{N} \log p(x_i\mid\theta) }\]

10. Logarithm과 Argmax

자연로그는 단조 증가 함수다.

즉

\[a>b>0\]

이면

\[\log a>\log b\]

따라서 Likelihood가 최대가 되는 Parameter와 Log-Likelihood가 최대가 되는 Parameter는 같다.

\[\boxed{ \arg\max_\theta L(\theta) = \arg\max_\theta\log L(\theta) }\]

즉 Log Transformation은 최적 Parameter의 위치를 바꾸지 않는다.

11. Negative Log-Likelihood

Machine Learning에서는 일반적으로 Objective를 최소화하는 형태로 구현한다.

그러나 MLE는

\[\max_\theta\ell(\theta)\]

문제다.

따라서 Log-Likelihood에 음수를 붙인다.

\[\boxed{ \mathcal L_{\mathrm{NLL}}(\theta) = -\ell(\theta) }\]

i.i.d. Dataset에서는

\[\boxed{ \mathcal L_{\mathrm{NLL}}(\theta) = -\sum_{i=1}^{N} \log p(x_i\mid\theta) }\]

12. MLE와 NLL Minimization

Likelihood Maximization은

\[\arg\max_\theta L(\theta)\]

Logarithm을 적용해도 최댓값 위치는 변하지 않는다.

\[= \arg\max_\theta\ell(\theta)\]

음수를 붙이면 최대화가 최소화로 바뀐다.

\[= \arg\min_\theta[-\ell(\theta)]\]

따라서

\[\boxed{ \arg\max_\theta L(\theta) = \arg\max_\theta \ell(\theta) = \arg\min_\theta \mathcal L_{\mathrm{NLL}}(\theta) }\]

13. Notation

14. Categorical Likelihood

PS-09에서 Categorical Target을 One-Hot Vector

\[\mathbf y = [y_1,\dots,y_V]^T\]

로 표현했다.

Categorical PMF는

\[\boxed{ p(\mathbf y\mid\mathbf p) = \prod_{k=1}^{V} p_k^{y_k} }\]

여기서

\[y_k\in\{0,1\}\]

이고

\[\sum_{k=1}^{V}y_k=1\]

15. Categorical Log-Likelihood

Categorical PMF에 Log를 취한다.

\[\log p(\mathbf y\mid\mathbf p) = \log \left( \prod_{k=1}^{V} p_k^{y_k} \right)\]

Logarithm의 성질을 사용하면

\[\boxed{ \log p(\mathbf y\mid\mathbf p) = \sum_{k=1}^{V} y_k\log p_k }\]

16. Categorical NLL

Negative Log를 취하면

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\sum_{k=1}^{V} y_k\log p_k }\]

Target이 One-Hot이고 정답 Index가 \(c\)이면

\[y_c=1\]

이고 나머지는 모두 \(0\)이다.

따라서

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\log p_c }\]

17. Cross-Entropy

Target Distribution \(\mathbf y\)와 Prediction Distribution \(\mathbf p\) 사이의 Cross-Entropy는

\[\boxed{ H(\mathbf y,\mathbf p) = -\sum_{k=1}^{V} y_k\log p_k }\]

One-Hot Categorical Target에서는

\[\boxed{ H(\mathbf y,\mathbf p) = -\log p_c }\]

따라서 이 설정에서는

\[\boxed{ \mathcal L_{\mathrm{NLL}} = H(\mathbf y,\mathbf p) }\]

18. Categorical NLL과 Cross-Entropy 동치 유도

Categorical PMF에서

\[p(\mathbf y\mid\mathbf p) = \prod_{k=1}^{V} p_k^{y_k}\]

Log를 취하면

\[\log p(\mathbf y\mid\mathbf p) = \sum_{k=1}^{V} y_k\log p_k\]

Negative Log를 취하면

\[-\log p(\mathbf y\mid\mathbf p) = -\sum_{k=1}^{V} y_k\log p_k\]

Cross-Entropy 정의와 동일하므로

\[\boxed{ \mathcal L_{\mathrm{NLL}} = H(\mathbf y,\mathbf p) }\]

19. Autoregressive Language Model Likelihood

Prompt를

\[x\]

Output Token Sequence를

\[y_1,\dots,y_T\]

라고 하자.

PS-02의 Chain Rule에 의해

\[\boxed{ P_\theta(y_{1:T}\mid x) = \prod_{t=1}^{T} P_\theta( y_t \mid y_{<t},x ) }\]

여기서

\[y_{<t} = (y_1,\dots,y_{t-1})\]

20. Autoregressive Log-Likelihood

Sequence Likelihood에 Log를 취한다.

\[\log P_\theta(y_{1:T}\mid x) = \log \prod_{t=1}^{T} P_\theta( y_t\mid y_{<t},x )\]

따라서

\[\boxed{ \log P_\theta(y_{1:T}\mid x) = \sum_{t=1}^{T} \log P_\theta( y_t\mid y_{<t},x ) }\]

21. Autoregressive NLL

Negative Log를 취하면

\[\boxed{ \mathcal L_{\mathrm{NLL}}(\theta) = -\sum_{t=1}^{T} \log P_\theta( y_t \mid y_{<t},x ) }\]

즉 LLM은 각 Token Position에서 정답 Token에 부여한 Log-Probability를 합산한 뒤 음수를 취한 Loss를 최소화한다.

22. Token-Level Loss

\(t\)번째 Token의 Loss는

\[\boxed{ \mathcal L_t = -\log P_\theta( y_t \mid y_{<t},x ) }\]

Sequence 전체 Loss는

\[\boxed{ \mathcal L_{\mathrm{seq}} = \sum_{t=1}^{T}\mathcal L_t }\]

실제 Training에서는 Token 수나 유효 Token 수로 나눈 평균 Loss를 사용하는 경우가 많다.

\[\boxed{ \bar{\mathcal L}_{\mathrm{NLL}} = -\frac1T \sum_{t=1}^{T} \log P_\theta( y_t\mid y_{<t},x ) }\]

23. LLM Cross-Entropy Training

각 Token Position에서 LLM은 Vocabulary 크기 \(V\)의 Logit Vector를 출력한다.

\[\mathbf z_t \in \mathbb R^V\]

Softmax를 적용하면

\[\mathbf p_t = \operatorname{Softmax}(\mathbf z_t)\]

이고 Categorical Distribution이 된다.

정답 Token을 \(y_t\)라고 하면 Token Loss는

\[\boxed{ -\log p_t(y_t) }\]

따라서 LLM Pre-training의 Next-Token Cross-Entropy는 Categorical NLL의 반복이다.

24. Softmax

Logit Vector를

\[\mathbf z = [z_1,\dots,z_V]^T\]

라고 하자.

Softmax Probability는

\[\boxed{ p_k = \frac{ e^{z_k} }{ \sum_{j=1}^{V}e^{z_j} } }\]

정답 Class를 \(c\)라고 하면

\[\mathcal L_{\mathrm{NLL}} = -\log p_c\]

25. NLL을 Logit으로 직접 표현하기

Softmax Probability를 NLL에 대입한다.

\[-\log p_c = -\log \left[ \frac{ e^{z_c} }{ \sum_j e^{z_j} } \right]\]

Logarithm을 분리하면

\[= -\log e^{z_c} + \log \sum_j e^{z_j}\]

따라서

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -z_c + \log \sum_{j=1}^{V} e^{z_j} }\]

이 식에서 두 번째 항이 Log-Sum-Exp다.

26. Numerical Overflow

Naive Softmax에서는

\[e^{z_j}\]

를 직접 계산한다.

Logit이 매우 크면 Exponential 값이 Floating-Point Range를 초과할 수 있다.

예를 들어

\[z_j=1000\]

이면

\[e^{1000}\]

은 일반적인 Floating-Point 계산에서 직접 표현하기 어렵다.

이 경우

\[\boxed{ \mathrm{Inf} }\]

가 발생할 수 있다.

27. Numerical Underflow

반대로 매우 작은 Logit Difference에 대해

\[e^{z_j}\]

가 표현 가능한 최소 양수보다 작아지면

\[\boxed{ 0 }\]

으로 Underflow될 수 있다.

이후

\[\log0 = -\infty\]

가 발생할 수 있다.

따라서 Softmax와 Log를 별도로 순진하게 계산하는 것은 수치적으로 위험할 수 있다.

28. Log-Sum-Exp

다음 값을 계산하고 싶다고 하자.

\[\log \left( \sum_{j=1}^{V} e^{z_j} \right)\]

Logit의 최댓값을

\[\boxed{ m = \max_j z_j }\]

라고 한다.

그러면 LSE는 다음과 같이 변형할 수 있다.

\[\boxed{ \log \left( \sum_{j=1}^{V} e^{z_j} \right) = m + \log \left( \sum_{j=1}^{V} e^{z_j-m} \right) }\]

29. Log-Sum-Exp 유도

원래 지수합은

\[\sum_j e^{z_j}\]

각 항을

\[e^{z_j} = e^m e^{z_j-m}\]

으로 쓴다.

따라서

\[\sum_j e^{z_j} = e^m \sum_j e^{z_j-m}\]

Log를 취하면

\[\log \sum_j e^{z_j} = \log \left[ e^m \sum_j e^{z_j-m} \right]\]

로그의 곱셈 법칙에 의해

\[= \log e^m + \log \sum_j e^{z_j-m}\]

이고

\[\log e^m=m\]

이므로

\[\boxed{ \log \sum_j e^{z_j} = m + \log \sum_j e^{z_j-m} }\]

30. 왜 LSE가 안정적인가

\(m\)은 가장 큰 Logit이다.

따라서 모든 \(j\)에 대해

\[z_j-m\le0\]

그러므로

\[\boxed{ 0< e^{z_j-m} \le1 }\]

가장 큰 Logit에서는

\[z_j=m\]

이므로

\[e^{z_j-m}=1\]

따라서 큰 양수 Logit 때문에 Exponential이 폭발하는 문제를 방지할 수 있다.

31. Stable Log-Softmax

Log-Softmax는 다음과 같이 쓸 수 있다.

\[\log p_k = z_k - \log\sum_j e^{z_j}\]

LSE를 사용하면

\[\boxed{ \log p_k = z_k - m - \log \sum_j e^{z_j-m} }\]

따라서 Softmax Probability 자체를 먼저 계산한 뒤 Log를 적용하지 않고 Log-Probability를 안정적으로 직접 계산할 수 있다.

32. Stable NLL

정답 Class가 \(c\)이면

\[\mathcal L_{\mathrm{NLL}} = -\log p_c\]

Stable Log-Softmax를 사용하면

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -z_c + m + \log \sum_j e^{z_j-m} }\]

이 형태는 매우 큰 Logit에서도 안정적으로 계산할 수 있다.

33. Example 1 — Bernoulli Dataset

관측 데이터가

\[\boxed{ \mathcal D = \{1,1,0,1\} }\]

이라고 하자.

Sample Count는

\[N=4\]

이고

  • 성공 \(3\)회
  • 실패 \(1\)회

다.

Bernoulli 성공 확률 Parameter를

\[\theta\]

라고 하자.

Likelihood는

\[\boxed{ L(\theta) = \theta^3(1-\theta) }\]

34. Example 1 — $\theta=0.8$

\(\theta=0.8\)이면

\[\begin{aligned} L(0.8) &= (0.8)^3(1-0.8)\\ &= 0.512(0.2)\\ &= \boxed{0.1024} \end{aligned}\]

Log-Likelihood는

\[\begin{aligned} \ell(0.8) &= \log0.1024\\ &\approx \boxed{-2.2788} \end{aligned}\]

NLL은

\[\boxed{ \mathcal L_{\mathrm{NLL}}(0.8) = 2.2788 }\]

35. Example 1 — $\theta=0.5$

\(\theta=0.5\)이면

\[\begin{aligned} L(0.5) &= (0.5)^3(0.5)\\ &= (0.5)^4\\ &= \boxed{0.0625} \end{aligned}\]

Log-Likelihood는

\[\begin{aligned} \ell(0.5) &= \log0.0625\\ &\approx \boxed{-2.7726} \end{aligned}\]

NLL은

\[\boxed{ \mathcal L_{\mathrm{NLL}}(0.5) = 2.7726 }\]

36. Example 1 — Parameter 비교

두 Likelihood를 비교하면

\[0.1024>0.0625\]

이므로

\[\boxed{ L(0.8)>L(0.5) }\]

Log-Likelihood도

\[-2.2788>-2.7726\]

NLL은 반대로

\[2.2788<2.7726\]

따라서 이 두 후보만 비교한다면

\[\boxed{ \theta=0.8 }\]

이 주어진 데이터를 더 잘 설명한다.

37. Example 2 — Extreme Logits

Vocabulary Size가

\[V=3\]

이라고 하자.

Logit Vector는

\[\boxed{ \mathbf z = \begin{bmatrix} 1000\\ 1001\\ 999 \end{bmatrix} }\]

정답 Token은 두 번째 Token이다.

38. Example 2 — Naive Softmax 문제

Naive 방식으로 계산하면

\[e^{1000}, \qquad e^{1001}, \qquad e^{999}\]

를 직접 구해야 한다.

일반적인 Floating-Point 계산에서는 매우 큰 값이므로 Overflow가 발생할 수 있다.

개념적으로

\[e^{1000}\rightarrow\mathrm{Inf}\]

등이 되면

\[\frac{\mathrm{Inf}} {\mathrm{Inf}}\]

형태가 발생해

\[\boxed{ \mathrm{NaN} }\]

을 만들 수 있다.

39. Example 2 — Maximum Logit

LSE를 사용한다.

최댓값은

\[\boxed{ m=1001 }\]

각 Logit에서 이를 뺀다.

\[\mathbf z-m = \begin{bmatrix} -1\\ 0\\ -2 \end{bmatrix}\]

40. Example 2 — Stable Exponential Sum

각 항은

\[e^{-1}\approx0.3679\]
\[e^0=1\]
\[e^{-2}\approx0.1353\]

따라서

\[\begin{aligned} \sum_j e^{z_j-m} &= 0.3679+1+0.1353\\ &= \boxed{1.5032} \end{aligned}\]

41. Example 2 — Log-Sum-Exp

LSE는

\[m + \log \sum_j e^{z_j-m}\]

따라서

\[\begin{aligned} \log \sum_j e^{z_j} &= 1001+\log1.5032\\ &\approx 1001+0.4076\\ &= \boxed{1001.4076} \end{aligned}\]

42. Example 2 — Stable NLL

정답 Logit은

\[z_c=1001\]

따라서

\[\mathcal L_{\mathrm{NLL}} = -z_c + \log \sum_j e^{z_j}\]

수치를 대입하면

\[\begin{aligned} \mathcal L_{\mathrm{NLL}} &= -1001+1001.4076\\ &= \boxed{0.4076} \end{aligned}\]

Overflow 없이 안정적인 Loss를 얻는다.

43. Perplexity

Language Model의 Perplexity는 일반적으로 평균 Token NLL의 Exponential로 정의한다.

길이 \(T\)의 Sequence에서 평균 NLL은

\[\boxed{ \bar{\mathcal L}_{\mathrm{NLL}} = -\frac1T \sum_{t=1}^{T} \log P_\theta( y_t\mid y_{<t} ) }\]

Perplexity는

\[\boxed{ \mathrm{PPL} = \exp( \bar{\mathcal L}_{\mathrm{NLL}} ) }\]

44. Perplexity의 Geometric Mean 표현

위 식을 전개하면

\[\mathrm{PPL} = \exp \left[ -\frac1T \sum_{t=1}^{T} \log p_t \right]\]

Log Sum을 Product로 바꾸면

\[\boxed{ \mathrm{PPL} = \left( \prod_{t=1}^{T} \frac1{p_t} \right)^{1/T} }\]

즉 정답 Token에 부여한 역확률의 Geometric Mean으로 볼 수 있다.

45. Perplexity 예시

평균 Token NLL이

\[\bar{\mathcal L}_{\mathrm{NLL}} = 2.3026\]

이라고 하자.

그러면

\[\mathrm{PPL} = e^{2.3026} \approx \boxed{10}\]

원 자료에서는 이를 모델이 평균적으로 약 10개의 유효한 후보 사이에서 불확실성을 가지는 것과 비슷한 직관으로 설명한다.

이는 직관적인 해석이며 실제 Distribution이 정확히 10개 Token에 균등하다는 뜻은 아니다.

46. Dataset Size와 NLL

총 NLL은 Sample이나 Token 수가 증가하면 자연스럽게 증가할 수 있다.

\[\mathcal L_{\mathrm{NLL}} = -\sum_{i=1}^{N} \log p_\theta(x_i)\]

따라서 서로 다른 Dataset Size를 비교할 때는 평균 NLL이 더 적절한 경우가 많다.

\[\boxed{ \bar{\mathcal L}_{\mathrm{NLL}} = -\frac1N \sum_{i=1}^{N} \log p_\theta(x_i) }\]

47. Law of Large Numbers 관점

데이터가

\[x_i \sim p_{\mathrm{data}}\]

에서 i.i.d.로 추출되었다고 하자.

평균 NLL은

\[-\frac1N \sum_{i=1}^{N} \log p_\theta(x_i)\]

\(N\)이 커지면 Law of Large Numbers에 의해 적절한 조건 아래

\[\boxed{ -\frac1N \sum_{i=1}^{N} \log p_\theta(x_i) \rightarrow \mathbb E_{x\sim p_{\mathrm{data}}} [ -\log p_\theta(x) ] }\]

로 수렴한다.

48. Expected NLL과 Cross-Entropy

Cross-Entropy는

\[\boxed{ H( p_{\mathrm{data}}, p_\theta ) = \mathbb E_{x\sim p_{\mathrm{data}}} [ -\log p_\theta(x) ] }\]

로 표현할 수 있다.

따라서 Large Dataset에서 평균 NLL은

\[\boxed{ \bar{\mathcal L}_{\mathrm{NLL}} \rightarrow H( p_{\mathrm{data}}, p_\theta ) }\]

와 연결된다.

이 관계는 이후 Information Theory에서 Entropy, Cross-Entropy, KL Divergence와 연결된다.

49. 왜 Log를 사용하는가 — Numerical Reason

Likelihood는

\[\prod_i p_i\]

형태다.

작은 수를 반복 곱하면 Underflow가 발생하기 쉽다.

Log를 취하면

\[\boxed{ \prod_i p_i \rightarrow \sum_i\log p_i }\]

가 되어 작은 Probability를 직접 계속 곱하지 않아도 된다.

50. 왜 Log를 사용하는가 — Optimization Reason

Product Objective의 미분은 여러 곱을 포함할 수 있다.

Log를 적용하면 Objective가 Sum으로 바뀐다.

\[\boxed{ \ell(\theta) = \sum_i \log p(x_i\mid\theta) }\]

따라서 각 Sample Contribution을 더하는 형태가 된다.

이는 Gradient-Based Optimization에 자연스럽게 연결된다.

51. Mini-Batch Training과 NLL

전체 Dataset NLL이

\[\mathcal L = -\sum_{i=1}^{N} \log p_\theta(x_i)\]

라면 각 Sample의 Contribution이 더해지는 구조다.

따라서 Mini-Batch \(\mathcal B\)에 대해서도

\[\boxed{ \mathcal L_{\mathcal B} = -\sum_{i\in\mathcal B} \log p_\theta(x_i) }\]

를 계산할 수 있다.

실제 구현에서는 Batch Mean을 사용하는 경우가 많다.

\[\boxed{ \bar{\mathcal L}_{\mathcal B} = -\frac1{|\mathcal B|} \sum_{i\in\mathcal B} \log p_\theta(x_i) }\]

52. NLL은 항상 비음수인가

Discrete Probability Mass에서는

\[0<p(x)\le1\]

이므로

\[\log p(x)\le0\]

따라서 Discrete Categorical/Bernoulli NLL은

\[\boxed{ -\log p(x)\ge0 }\]

하지만 연속 Distribution의 PDF는

\[f(x)>1\]

일 수 있다.

따라서

\[\log f(x)>0\]

이고

\[-\log f(x)<0\]

가 될 수도 있다.

즉

\[\boxed{ \text{Continuous-density NLL need not be non-negative.} }\]

53. NLL과 Cross-Entropy는 언제 같은가

Categorical Distribution에서 Target이 One-Hot이고 Prediction이 Softmax Probability라면

\[\boxed{ \mathcal L_{\mathrm{NLL}} = \mathcal L_{\mathrm{CE}} }\]

이는 Classification과 Next-Token Prediction에서 사용하는 대표적인 설정이다.

54. NLL과 Cross-Entropy의 범위 차이

NLL은 모델이 정의한 임의의 Probability Model 또는 Density Model에 대해 정의할 수 있다.

예를 들어 Gaussian Density에서도

\[-\log p_\theta(x)\]

형태의 NLL을 사용할 수 있다.

Cross-Entropy는 두 Probability Distribution 사이의 Expected Negative Log-Probability로 정의할 수 있으며, 이산분포에만 한정되는 개념은 아니다.

따라서 둘은 One-Hot Categorical Setting에서는 동일하지만 개념적으로 완전히 같은 용어는 아니다.

55. Naive Softmax 후 Log의 문제

다음 순서로 계산한다고 하자.

\[\mathbf p = \operatorname{Softmax}(\mathbf z)\]

그리고

\[\log\mathbf p\]

를 별도로 계산한다.

Softmax 단계에서 이미 어떤 Probability가 Numerical Underflow로

\[0\]

이 되어 버리면

\[\log0 = -\infty\]

반대로 Exponential이 Overflow하면

\[\mathrm{Inf}\]

또는

\[\mathrm{NaN}\]

이 발생할 수 있다.

따라서 실제 구현에서는 Log-Softmax와 NLL을 수치적으로 결합한 연산을 사용하는 것이 안전하다.

56. Stable Implementation 관점

원 자료에서는 PyTorch의 다음과 같은 구현을 연결한다.

  • F.cross_entropy()
  • nn.LogSoftmax()

이러한 연산은 Softmax Probability를 명시적으로 계산한 뒤 Log를 취하는 순진한 구현보다 수치적으로 안정적인 방식으로 Log-Sum-Exp를 처리한다.

개념적으로는 다음 흐름이다.

\[\boxed{ \text{Logits} \rightarrow \text{Log-Sum-Exp} \rightarrow \text{Log-Softmax} \rightarrow \text{NLL} }\]

57. Likelihood Scale 자체의 의미

Likelihood의 절댓값 자체만 보고 모델의 품질을 일반적으로 비교해서는 안 된다.

Likelihood 값은

  • Dataset Size
  • Distribution Type
  • Discrete / Continuous
  • Measurement Unit
  • Model Specification

등의 영향을 받는다.

같은 Dataset과 같은 Model Family 안에서 Parameter를 비교하는 것이 기본적인 Likelihood 해석이다.

58. Likelihood와 Posterior를 구분하기

PS-02의 Bayesian Posterior는

\[P(\theta\mid\mathcal D)\]

와 같은 Parameter에 대한 Probability Distribution이다.

반면 Likelihood는

\[L(\theta\mid\mathcal D) = p(\mathcal D\mid\theta)\]

Likelihood는 자체적으로 Parameter Distribution이 아니다.

Bayes' Theorem에서는

\[\boxed{ P(\theta\mid\mathcal D) \propto p(\mathcal D\mid\theta) P(\theta) }\]

처럼 Likelihood와 Prior를 결합하여 Posterior를 만든다.

59. Maximum Likelihood와 Bayesian Update

MLE는

\[\boxed{ \hat\theta_{\mathrm{MLE}} = \arg\max_\theta p(\mathcal D\mid\theta) }\]

Bayesian Inference에서는 Parameter 자체를 Random Variable로 보고

\[P(\theta)\]

라는 Prior를 추가한다.

따라서

\[\boxed{ \text{Likelihood} + \text{Prior} \rightarrow \text{Posterior} }\]

로 연결된다.

60. 주요 성질 정리

Likelihood

\[\boxed{ L(\theta\mid\mathcal D) = p(\mathcal D\mid\theta) }\]

i.i.d. Likelihood

\[\boxed{ L(\theta) = \prod_{i=1}^{N} p(x_i\mid\theta) }\]

Log-Likelihood

\[\boxed{ \ell(\theta) = \sum_{i=1}^{N} \log p(x_i\mid\theta) }\]

NLL

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\sum_{i=1}^{N} \log p(x_i\mid\theta) }\]

MLE Equivalence

\[\boxed{ \arg\max_\theta L = \arg\max_\theta\ell = \arg\min_\theta\mathcal L_{\mathrm{NLL}} }\]

61. Categorical NLL

Categorical One-Hot Target에서는

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\sum_{k=1}^{V} y_k\log p_k }\]

정답 Class \(c\)에 대해서는

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\log p_c }\]

이는 One-Hot Cross-Entropy와 동일하다.

62. Autoregressive LLM NLL

Autoregressive LLM에서는

\[\boxed{ P_\theta(y_{1:T}\mid x) = \prod_{t=1}^{T} P_\theta( y_t \mid y_{<t},x ) }\]

NLL은

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\sum_{t=1}^{T} \log P_\theta( y_t \mid y_{<t},x ) }\]

평균 Token NLL은

\[\boxed{ \bar{\mathcal L}_{\mathrm{NLL}} = -\frac1T \sum_{t=1}^{T} \log P_\theta( y_t \mid y_{<t},x ) }\]

63. Log-Sum-Exp

Logit Vector에서

\[m=\max_jz_j\]

라고 하면

\[\boxed{ \log \sum_j e^{z_j} = m+ \log \sum_j e^{z_j-m} }\]

이를 사용하면

\[z_j-m\le0\]

이므로 큰 Positive Logit에 의한 Exponential Overflow를 방지할 수 있다.

64. Perplexity

Language Model의 일반적인 Token-Level Perplexity는

\[\boxed{ \mathrm{PPL} = \exp( \bar{\mathcal L}_{\mathrm{NLL}} ) }\]

즉 총 NLL 자체가 아니라 Token 수로 평균한 NLL과 연결해야 Sequence Length에 따른 단순 Scaling 영향을 제거할 수 있다.

65. 정리

Likelihood는 관측된 Dataset을 고정하고 Parameter를 변화시키면서 데이터 적합도를 평가한다.

\[\boxed{ L(\theta\mid\mathcal D) = p(\mathcal D\mid\theta) }\]

i.i.d. Dataset에서는

\[\boxed{ L(\theta) = \prod_{i=1}^{N} p(x_i\mid\theta) }\]

Probability Product는 Numerical Underflow와 복잡한 Product Optimization 문제를 만들 수 있다.

Log를 적용하면

\[\boxed{ \ell(\theta) = \sum_{i=1}^{N} \log p(x_i\mid\theta) }\]

Log는 Monotonic Function이므로 최적점이 유지된다.

\[\boxed{ \arg\max L = \arg\max\ell }\]

최소화 문제로 바꾸기 위해 음수를 붙이면 NLL이 된다.

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\ell(\theta) }\]

따라서

\[\boxed{ \text{Maximum Likelihood} \iff \text{Maximum Log-Likelihood} \iff \text{Minimum NLL} }\]

Categorical One-Hot Prediction에서는

\[\boxed{ \mathcal L_{\mathrm{NLL}} = -\sum_k y_k\log p_k = -\log p_c }\]

이고 이는 Cross-Entropy와 동일하다.

Autoregressive LLM에서는 Chain Rule에 의해 Sequence Probability가

\[\boxed{ P_\theta(y_{1:T}\mid x) = \prod_{t=1}^{T} P_\theta( y_t\mid y_{<t},x ) }\]

로 분해되고 NLL은

\[\boxed{ -\sum_{t=1}^{T} \log P_\theta( y_t\mid y_{<t},x ) }\]

Softmax NLL에서는

\[\boxed{ -\log p_c = -z_c + \log \sum_j e^{z_j} }\]

이고 Log-Sum-Exp를 사용하여 안정적으로 계산한다.

\[\boxed{ \log \sum_j e^{z_j} = m+ \log \sum_j e^{z_j-m}, \qquad m=\max_jz_j }\]

Language Model Evaluation에서는 평균 Token NLL을 이용해 Perplexity를 계산한다.

\[\boxed{ \mathrm{PPL} = \exp \left[ -\frac1T \sum_{t=1}^{T} \log P_\theta( y_t\mid y_{<t} ) \right] }\]

전체 흐름은 다음과 같이 연결된다.

\[\boxed{ \text{Probability Model} \rightarrow \text{Likelihood} \rightarrow \text{Log-Likelihood} \rightarrow \text{NLL} \rightarrow \text{Optimization} }\]

LLM에서는 다음과 같다.

\[\boxed{ \text{Logits} \rightarrow \text{Log-Softmax} \rightarrow \text{Token NLL} \rightarrow \text{Cross-Entropy Training} }\]

그리고 평가에서는

\[\boxed{ \text{Average Token NLL} \rightarrow \text{Perplexity} }\]

로 연결된다.
