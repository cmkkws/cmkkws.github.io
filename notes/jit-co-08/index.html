1. 개요 및 학습 목표 (Overview & Objectives)

본 학습 자료는 미적분학 및 수치 계산 이론(Numerical Computation)의 핵심 기저이자 현대 대형 언어 모델(LLM)과 딥러닝 가속 시스템(vLLM, FlashAttention, PyTorch Autograd)의 수치적 안전성을 보장하는 수치적 안정성(Numerical Stability), 오버플로우/언더플로우(Overflow/Underflow), 그리고 Log-Sum-Exp (LSE) Trick 및 Safe / Online Softmax 메커니즘을 수학적·대수적으로 완전 정밀하게 규명합니다.

지수 함수(\(e^x\))는 인자 \(x\)가 조금만 커져도 폭발적으로 증가하며, 하드웨어의 부동소수점(Floating-Point, FP32/FP16/BF16) 표현 한계를 초과하여 NaN (Not a Number) 또는 Inf (Infinity)를 발생시킵니다. 반대로 \(x\)가 매우 음수이면 0으로 정밀도를 잃는 언더플로우(Underflow)가 발생합니다.

본 자료에서는 부동소수점 수치 연산의 한계 분석부터 시작하여, Softmax 및 Cross-Entropy 손실 계산 시 최댓값 차감 스케일링(\(C = \max_j x_j\))의 대수적 항등성 완전 유도 증명, Log-Sum-Exp (LSE) Trick의 수식 유도, 그리고 FlashAttention의 핵심 기저인 Online Softmax (타일링 연산) 수식 구조까지 단 하나의 생략 없이 정밀하게 다룹니다.

2. 부동소수점 표현 한계와 수치 불안정성 (Floating-Point Arithmetic)

(1) IEEE 754 부동소수점 표준 규격과 표현 상한

컴퓨터 메모리는 실수(Real Number)를 비트(Bit) 수에 따라 한정된 정밀도로 표현합니다.

  • 오버플로우 (Overflow): 계산 결과가 표의 \(x_{\max}\)를 초과하여 +Inf로 치환되고, 이후 모든 연산이 NaN으로 오염되는 현상.
  • 언더플로우 (Underflow): 계산 결과가 정밀도 하한(0 근처)보다 작아져 자릿수 저하(Underflow to Zero)가 발생, 분모가 0이 되어 ZeroDivisionError 또는 NaN이 발생하는 현상.

3. Safe Softmax & Log-Sum-Exp (LSE) Trick 대수적 유도 (Mathematical Derivation)

(1) Naive Softmax의 오버플로우 문제점

차원이 \(N\)인 입력 로짓 벡터 \(\mathbf{x} = [x_1, x_2, \dots, x_N]^T \in \mathbb{R}^N\)에 대해 표준 Softmax 확률 \(p_i\)는 다음과 같이 정의됩니다.

\[p_i = \text{softmax}(\mathbf{x})_i = \frac{e^{x_i}}{\sum_{j=1}^N e^{x_j}}\]
  • 만약 로짓 성분 중 \(x_k = 100\)만 존재하더라도, FP32 환경에서 \(e^{100} \approx 2.68 \times 10^{43} > 3.4 \times 10^{38}\)이므로 분모와 분자가 모두 +Inf가 되어 \(\frac{\text{Inf}}{\text{Inf}} = \text{NaN}\)을 반환합니다.
  • FP16 환경에서는 로짓 \(x_k = 12\)만 되어도 \(e^{12} \approx 162754 > 65504\)이므로 완전히 붕괴합니다.

(2) Safe Softmax의 대수적 완전 항등성 증명 (Safe Softmax Derivation)

정리 (Theorem): 임의의 스칼라 상수 \(C \in \mathbb{R}\)에 대해 Softmax 분모와 분자의 각 지수 인자에서 \(C\)를 빼주어도 확률 값 \(p_i\)는 수학적으로 완벽히 동일하다.

\[\text{softmax}(\mathbf{x})_i = \frac{e^{x_i - C}}{\sum_{j=1}^N e^{x_j - C}}\]

[증명 (Proof)]

  1. Softmax 정의의 분모와 분자에 \(e^{-C}\)를 곱합니다 (\(e^{-C} > 0\)이므로 항등 변환).
\[\text{softmax}(\mathbf{x})_i = \frac{e^{x_i}}{\sum_{j=1}^N e^{x_j}} = \frac{e^{x_i} \cdot e^{-C}}{\left( \sum_{j=1}^N e^{x_j} \right) \cdot e^{-C}}\]
  1. 지수 법칙 \(e^A \cdot e^B = e^{A+B}\) 및 분배 법칙을 분모의 각 항에 적용합니다.
\[\text{softmax}(\mathbf{x})_i = \frac{e^{x_i - C}}{\sum_{j=1}^N e^{x_j - C}} \quad \blacksquare\]

[최적 상수 $C$의 선택]

수치 오버플로우를 완전 방지하기 위해 \(C\)를 입력 로짓 벡터의 최댓값 \(C = \max_{1 \le j \le N} x_j\)로 설정합니다.

  • 이 때 모든 \(j\)에 대해 \(x_j - C \le 0\)이 보장되므로, 지수 연산 결과 \(e^{x_j - C} \in (0, 1]\) 범위에 상한 고정됩니다.
  • 최댓값을 가지는 성분은 \(e^{C - C} = e^0 = 1\)이 되므로 분모는 최소 \(1\) 이상을 유지하여 0으로 나눌 위험(Zero Division)이 원천 차단됩니다.

(3) Log-Sum-Exp (LSE) Trick 유도 및 Cross-Entropy 손실 수치 안정화

딥러닝의 분류 손실 함수인 Cross-Entropy Loss는 Log-Softmax 연산을 포함합니다.

\[\log p_i = \log \left( \frac{e^{x_i}}{\sum_{j=1}^N e^{x_j}} \right) = x_i - \log \left( \sum_{j=1}^N e^{x_j} \right)\]

여기서 분모의 지수 합에 로그를 취한 연산을 Log-Sum-Exp (LSE)라 합니다.

\[\text{LSE}(\mathbf{x}) = \log \left( \sum_{j=1}^N e^{x_j} \right)\]

[LSE Trick 변환]

\(C = \max_j x_j\)를 적용하면 다음과 같이 유도됩니다.

\[\begin{aligned} \text{LSE}(\mathbf{x}) &= \log \left( \sum_{j=1}^N e^{x_j - C + C} \right) \\ &= \log \left( e^C \cdot \sum_{j=1}^N e^{x_j - C} \right) \\ &= \log(e^C) + \log \left( \sum_{j=1}^N e^{x_j - C} \right) \\ &= C + \log \left( \sum_{j=1}^N e^{x_j - C} \right) \end{aligned}\]

따라서 수치적으로 안정한 Log-Softmax는 다음과 같이 연산됩니다.

\[\log p_i = x_i - C - \log \left( \sum_{j=1}^N e^{x_j - C} \right)\]

4. 수치 연산 및 오버플로우 비교 예제 (Concrete Calculation Example)

[문제 예제]

입력 로짓 벡터가 \(\mathbf{x} = [1000, 1002, 1001]^T\)로 주어졌을 때, Naive 계산과 Safe Softmax / LSE Trick 연산을 비교하시오.

1) Naive 연산 시도

  • \(e^{1000} = \text{Inf}\), \(e^{1002} = \text{Inf}\), \(e^{1001} = \text{Inf}\)
  • \(\text{Softmax}(\mathbf{x})_1 = \frac{\text{Inf}}{\text{Inf} + \text{Inf} + \text{Inf}} = \text{NaN}\) (연산 실패)

2) Safe Softmax 연산 ($C = \max(x_j) = 1002$)

  • \(x_1 - C = 1000 - 1002 = -2 \implies e^{-2} \approx 0.135335\)
  • \(x_2 - C = 1002 - 1002 = 0 \implies e^0 = 1.000000\)
  • \(x_3 - C = 1001 - 1002 = -1 \implies e^{-1} \approx 0.367879\)
  • 분모 지수 합: \(S = e^{-2} + e^0 + e^{-1} = 0.135335 + 1.000000 + 0.367879 = 1.503214\)

확률 결과값:

  • \(p_1 = \frac{0.135335}{1.503214} \approx \mathbf{0.0900} \; (9.00\%)\)
  • \(p_2 = \frac{1.000000}{1.503214} \approx \mathbf{0.6652} \; (66.52\%)\)
  • \(p_3 = \frac{0.367879}{1.503214} \approx \mathbf{0.2448} \; (24.48\%)\)
  • 전체 합: \(p_1 + p_2 + p_3 = 0.0900 + 0.6652 + 0.2448 = \mathbf{1.0000}\) (완벽 성립)

3) Log-Sum-Exp (LSE) 계산

\[\text{LSE}(\mathbf{x}) = 1002 + \log(1.503214) = 1002 + 0.407607 = \mathbf{1002.4076}\]

5. LLM 및 시스템 최적화 핵심 응용 (LLM & System Applications)

(1) FlashAttention의 Online Softmax (Safe Tiling Mechanism)

LLM의 Attention 연산 \(S = Q K^T \in \mathbb{R}^{N \times N}\)은 시퀀스 길이 \(N\)이 커질 때 메모리 HBM 재작성을 요구합니다. FlashAttention (Dao et al., 2022)은 SRAM 내부에서 블록 단위로 Softmax를 분할 연산하는 Online Softmax 알고리즘을 사용합니다.

블록 \(B_1, B_2\)가 차례로 입력될 때, 이전 국소 최댓값 \(m^{(1)}\)과 분모 \(d^{(1)}\)를 새로운 최댓값 \(m^{(2)} = \max(m^{(1)}, m^{(block2)})\)로 실시간 업데이트하는 보정 공식:

\[d^{(2)} = d^{(1)} \cdot e^{m^{(1)} - m^{(2)}} + \sum_{j \in B_2} e^{x_j - m^{(2)}}\]

이 재조정 스케일링(\(e^{m^{(1)} - m^{(2)}}\))을 통해 전체 메모리 복사 없이 수치적으로 안전한 정확한 Attention 결과 \(O = \text{Softmax}(QK^T)V\)를 산출합니다.

(2) PyTorch `torch.nn.CrossEntropyLoss`의 내장 통합

PyTorch에서는 torch.exp(logits)를 먼저 구한 뒤 torch.log()를 취하는 식의 구현을 금지합니다.

  • nn.LogSoftmax()와 nn.NLLLoss()를 결합한 nn.CrossEntropyLoss()는 내부 C++ CUDA 커널 수준에서 Log-Sum-Exp Trick을 단일 Fused Kernel로 처리하여 속도 향상과 수치적 안정성을 동시에 달성합니다.

6. 명확한 검증 기준 (Mastery Check)

  1. [ ] 부동소수점 오버플로우와 언더플로우가 발생하는 원인을 지수 함수 \(e^x\)의 형태 및 표현 상한과 연결지어 설명할 수 있다.
  2. [ ] Safe Softmax 수식에서 최댓값 \(C = \max_j x_j\)를 빼주어도 확률 분포가 왜 대수적으로 동일하게 유지되는지 증명할 수 있다.
  3. [ ] Log-Sum-Exp (LSE) Trick 수식을 유도하고, \(x = [1000, 1002, 1001]\) 예제에서 Naive 방식과 Safe 방식을 비교하여 결과를 계산할 수 있다.
  4. [ ] FlashAttention의 Online Softmax가 메모리 타일링 중 수치적 안전성을 유지하기 위해 이전 블록의 분모를 어떻게 보정(\(e^{m^{(old)} - m^{(new)}}\))하는지 이해한다.
