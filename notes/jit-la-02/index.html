LA-02 — Vector and Matrix Reduction / Pooling

Reduction은 배열의 특정 축(axis)을 따라 여러 값을 하나의 값으로 합치는 연산이다.

Reduction

Reduction은 배열의 특정 축(axis)을 따라 여러 값을 하나의 값으로 합치는 연산이다. 대표적인 연산은 다음과 같다.

  • sum: 합
  • mean: 평균
  • max: 최댓값
  • min: 최솟값

예를 들어

\[\mathbf{X}\in\mathbb{R}^{M\times N}\]

에서 열 방향의 값을 모두 더하면 각 행마다 하나의 값만 남는다.

\[\mathbb{R}^{M\times N} \rightarrow \mathbb{R}^{M}\]

반대로 행 방향의 값을 모두 더하면 각 열마다 하나의 값이 남는다.

\[\mathbb{R}^{M\times N} \rightarrow \mathbb{R}^{N}\]

Reduction을 이해할 때는 무슨 연산을 하는가보다 어느 축을 없애는가를 먼저 확인해야 한다.

Axis와 Shape

다음 행렬을 사용한다.

\[\mathbf{X}\in\mathbb{R}^{M\times N}\]

두 개의 축이 있다.

  • axis = 0: 첫 번째 축 \(M\)
  • axis = 1: 두 번째 축 \(N\)

일반적인 0-based axis 표기에서는

\[(M,N)\]

에서

\[\text{axis}=0\]

을 reduction하면 \(M\)축이 사라진다.

\[(M,N) \xrightarrow{\text{reduce axis }0} (N)\]

반대로

\[\text{axis}=1\]

을 reduction하면 \(N\)축이 사라진다.

\[(M,N) \xrightarrow{\text{reduce axis }1} (M)\]

3차원 텐서

\[\mathbf{T}\in\mathbb{R}^{B\times S\times D}\]

에서도 같은 원리를 사용한다.

한 축을 reduction한다는 것은 그 축의 여러 값을 하나로 모은다는 뜻이다.

Sum Reduction

Axis 0

행렬

\[\mathbf{X}\in\mathbb{R}^{M\times N}\]

에서 axis = 0을 따라 합을 구하면 각 열에 대해 \(M\)개의 값을 더한다.

\[s_j = \sum_{i=1}^{M}X_{ij}\]

전체 결과는 다음과 같다.

\[\mathbf{s} = \begin{bmatrix} \sum_{i=1}^{M}X_{i1} & \sum_{i=1}^{M}X_{i2} & \cdots & \sum_{i=1}^{M}X_{iN} \end{bmatrix}\]

Shape은 다음과 같이 변한다.

\[\mathbb{R}^{M\times N} \xrightarrow{\operatorname{sum}(\text{axis}=0)} \mathbb{R}^{N}\]

keepdims=True일 때 shape은 다음과 같다.

\[\mathbb{R}^{M\times N} \rightarrow \mathbb{R}^{1\times N}\]

Axis 1

axis = 1에서는 각 행 내부의 \(N\)개 값을 더한다.

\[s_i = \sum_{j=1}^{N}X_{ij}\]

전체 결과는 다음과 같다.

\[\mathbf{s} = \begin{bmatrix} \sum_{j=1}^{N}X_{1j}\\ \sum_{j=1}^{N}X_{2j}\\ \vdots\\ \sum_{j=1}^{N}X_{Mj} \end{bmatrix}\]

Shape은 다음과 같이 변한다.

\[\mathbb{R}^{M\times N} \xrightarrow{\operatorname{sum}(\text{axis}=1)} \mathbb{R}^{M}\]

keepdims=True일 때 shape은 다음과 같다.

\[\mathbb{R}^{M\times N} \rightarrow \mathbb{R}^{M\times1}\]

Mean Reduction

Mean reduction은 선택한 축의 값을 모두 더한 뒤 그 축의 원소 개수로 나눈다. 행렬

\[\mathbf{X}\in\mathbb{R}^{M\times N}\]

의 axis = 1에 대한 평균은 다음과 같다.

\[\bar{x}_i = \frac{1}{N} \sum_{j=1}^{N}X_{ij}\]

각 행의 \(N\)개 값이 하나의 평균값으로 바뀐다. 따라서 shape은 다음과 같이 변한다.

\[\mathbb{R}^{M\times N} \xrightarrow{\operatorname{mean}(\text{axis}=1)} \mathbb{R}^{M}\]

keepdims=True일 때 shape은 다음과 같다.

\[\mathbb{R}^{M\times N} \rightarrow \mathbb{R}^{M\times1}\]

반대로 axis = 0에 대한 평균은 다음과 같다.

\[\bar{x}_j = \frac{1}{M} \sum_{i=1}^{M}X_{ij}\]

결과 shape은 다음과 같다.

\[\mathbb{R}^{N}\]

keepdims=True일 때 shape은 다음과 같다.

\[\mathbb{R}^{1\times N}\]

Max Reduction

Max reduction은 지정한 축의 값 가운데 가장 큰 값 하나만 남긴다.

\[m_i = \max_{1\le j\le N}X_{ij}\]

이는 행렬의 각 행에서 가장 큰 값을 선택하는 경우다. 입력이

\[\mathbf{X}\in\mathbb{R}^{M\times N}\]

이라면 결과는 다음과 같다.

\[\operatorname{max}(\mathbf{X},\text{axis}=1) \in \mathbb{R}^{M}\]

keepdims=True일 때 shape은 다음과 같다.

\[\mathbb{R}^{M\times1}\]

Sum과 Mean은 여러 값을 합성한다. Max는 여러 값 중 하나를 선택한다.

Reduction을 행렬 곱으로 표현하기

Sum reduction은 모든 성분이 1인 벡터와의 행렬 곱으로 표현할 수 있다.

Axis 1 Sum

다음 원벡터를 정의한다.

\[\mathbf{1}_N = \begin{bmatrix} 1\\ 1\\ \vdots\\ 1 \end{bmatrix} \in \mathbb{R}^{N\times1}\]

행렬

\[\mathbf{X}\in\mathbb{R}^{M\times N}\]

에 오른쪽에서 곱한다.

\[\mathbf{y} = \mathbf{X}\mathbf{1}_N\]

Shape은 다음과 같다.

\[(M,N)(N,1) \rightarrow (M,1)\]

\(i\)번째 성분을 전개하면

\[y_i = \sum_{j=1}^{N} X_{ij}(\mathbf{1}_N)_j\]

원벡터의 각 성분은 다음과 같다.

\[(\mathbf{1}_N)_j=1\]

따라서 결과는 다음과 같다.

\[y_i = \sum_{j=1}^{N}X_{ij}\]

따라서 axis = 1 sum reduction은 다음과 같이 행렬 곱으로 표현한다.

\[\boxed{ \mathbf{X}\mathbf{1}_N }\]

Mean Reduction을 행렬 곱으로 표현하기

이번에는

\[\mathbf{1}_M^{T} = \begin{bmatrix} 1&1&\cdots&1 \end{bmatrix} \in \mathbb{R}^{1\times M}\]

을 사용한다. 행렬 왼쪽에서

\[\frac{1}{M}\mathbf{1}_M^T\]

를 곱한다.

\[\mathbf{z}^T = \frac{1}{M} \mathbf{1}_M^T\mathbf{X}\]

Shape은 다음과 같다.

\[(1,M)(M,N) \rightarrow (1,N)\]

\(j\)번째 성분은 다음과 같다.

\[z_j = \frac{1}{M} \sum_{i=1}^{M} (\mathbf{1}_M)_iX_{ij}\]

원벡터의 모든 성분이 1이므로 결과는 다음과 같다.

\[z_j = \frac{1}{M} \sum_{i=1}^{M}X_{ij}\]

즉, axis = 0 mean reduction은 다음과 같이 행렬 곱으로 표현한다.

\[\boxed{ \frac{1}{M} \mathbf{1}_M^T\mathbf{X} }\]

3차원 Tensor의 Axis Reduction

다음 텐서를 사용한다.

\[\mathbf{T} \in \mathbb{R}^{2\times3\times2}\]

두 개의 \(3\times2\) 행렬로 쓰면 다음과 같다.

\[\begin{gathered} T_{0,:,:} = \begin{bmatrix} 1&2\\ 3&4\\ 5&6 \end{bmatrix} \\[6pt] T_{1,:,:} = \begin{bmatrix} 7&8\\ 9&10\\ 11&12 \end{bmatrix} \end{gathered}\]

Shape의 각 축은 다음과 같다.

\[(B,S,D)=(2,3,2)\]

Axis 0: Sum

Batch 축을 합친다.

\[R_{s,d} = T_{0,s,d} + T_{1,s,d}\]

각 위치의 두 batch 값을 더한 결과는 다음과 같다.

\[\begin{gathered} [1,2]+[7,8]=[8,10] \\[6pt] [3,4]+[9,10]=[12,14] \\[6pt] [5,6]+[11,12]=[16,18] \end{gathered}\]

따라서 전체 결과는 다음과 같다.

\[\mathbf{R} = \begin{bmatrix} 8&10\\ 12&14\\ 16&18 \end{bmatrix}\]

Shape은 다음과 같이 바뀐다.

\[(2,3,2) \xrightarrow{\operatorname{sum}(\text{axis}=0)} (3,2)\]

첫 번째 축 \(B\)가 사라졌다.

Axis 1: Mean

이번에는 Sequence 축을 평균낸다.

\[R_{b,d} = \frac{1}{3} \sum_{s=1}^{3} T_{b,s,d}\]

첫 번째 batch의 평균은 다음과 같다.

\[\begin{gathered} \frac{1+3+5}{3}=3 \\[6pt] \frac{2+4+6}{3}=4 \end{gathered}\]

따라서 첫 번째 batch 결과는 다음과 같다.

\[R_{0,:} = [3,4]\]

두 번째 batch의 평균은 다음과 같다.

\[\begin{gathered} \frac{7+9+11}{3}=9 \\[6pt] \frac{8+10+12}{3}=10 \end{gathered}\]

따라서 두 번째 batch 결과는 다음과 같다.

\[R_{1,:} = [9,10]\]

최종 결과는 다음과 같다.

\[\mathbf{R} = \begin{bmatrix} 3&4\\ 9&10 \end{bmatrix}\]

Shape은 다음과 같이 변한다.

\[(2,3,2) \xrightarrow{\operatorname{mean}(\text{axis}=1)} (2,2)\]

두 번째 축 \(S\)가 사라졌다.

Keepdims

Reduction 이후에는 두 가지 방식으로 shape을 처리할 수 있다.

keepdims=False

Reduction한 축을 완전히 제거한다.

\[\mathbb{R}^{2\times3\times2} \xrightarrow{\operatorname{sum}(\text{axis}=1)} \mathbb{R}^{2\times2}\]

축의 수가

\[3\rightarrow2\]

로 줄어든다.

keepdims=True

Reduction한 축을 삭제하지 않고 크기 1로 남긴다.

\[\mathbb{R}^{2\times3\times2} \xrightarrow{\operatorname{sum}(\text{axis}=1,\ keepdims=True)} \mathbb{R}^{2\times1\times2}\]

축의 수는 그대로다.

\[3\rightarrow3\]

대신 reduction된 축의 크기는 다음과 같이 바뀐다.

\[3\rightarrow1\]

즉, 유지된 shape은 다음과 같다.

\[(B,S,D) \rightarrow (B,1,D)\]

Broadcasting

Broadcasting은 서로 다른 shape을 가진 배열을 성분별로 연산할 수 있도록 크기가 1인 축을 확장해서 해석하는 규칙이다. Reduction과 함께 자주 사용된다. 예를 들어

\[\mathbf{T} \in \mathbb{R}^{B\times S\times D}\]

에서 Sequence 축에 mean reduction을 적용하고 축을 유지한 결과는 다음과 같다.

\[\bar{\mathbf{T}} \in \mathbb{R}^{B\times1\times D}\]

원래 텐서의 shape은 다음과 같다.

\[(B,S,D)\]

평균 텐서의 shape은 다음과 같다.

\[(B,1,D)\]

두 번째 축의 크기가

\[1\rightarrow S\]

로 확장될 수 있으므로 두 배열 사이의 성분별 연산이 가능하다. Shape만 쓰면

\[(B,S,D)\]

과

\[(B,1,D)\]

사이에서 두 번째 축의 1이 \(S\)개 위치에 동일하게 적용되는 방식이다. 실제로 전체 데이터를 복사해서 새 텐서를 만든다는 의미와는 구분해야 한다. Broadcasting은 먼저 shape 호환 규칙으로 이해하면 된다.

Pooling

Pooling은 여러 값을 하나의 대표값으로 줄이는 연산이다. Reduction과 같은 연산자를 사용하지만, 보통 어떤 영역을 묶어서 요약하는가를 함께 지정한다.

Global Pooling

전체 축 또는 전체 영역을 한 번에 reduction한다. 예를 들어

\[\mathbf{H} = \begin{bmatrix} \mathbf{h}_1\\ \mathbf{h}_2\\ \vdots\\ \mathbf{h}_S \end{bmatrix}\]

에서 \(S\)개의 벡터를 평균한 결과는 다음과 같다.

\[\bar{\mathbf{h}} = \frac{1}{S} \sum_{i=1}^{S} \mathbf{h}_i\]

입력이

\[\mathbf{H}\in\mathbb{R}^{S\times D}\]

라면 결과 shape은 다음과 같다.

\[\bar{\mathbf{h}}\in\mathbb{R}^{D}\]

Local Pooling

전체가 아니라 일부 구간을 나누어 각각 reduction한다. 예를 들어 한 구간의 값이

\[[2,\ 5,\ 3]\]

이라면 Mean Pooling 결과는 다음과 같다.

\[\frac{2+5+3}{3} = \frac{10}{3}\]

Max Pooling 결과는 다음과 같다.

\[\max(2,5,3)=5\]

여러 구간을 이동하면서 같은 연산을 반복하면 입력 축의 크기가 줄어든다.

Reduction의 선형성

Sum reduction은 선형이다. 같은 shape을 가진 \(\mathbf{X}\), \(\mathbf{Y}\)와 스칼라 \(\alpha,\beta\)에 대해

\[\operatorname{Sum} ( \alpha\mathbf{X} + \beta\mathbf{Y} )\]

는

\[\alpha\operatorname{Sum}(\mathbf{X}) + \beta\operatorname{Sum}(\mathbf{Y})\]

와 같다. 즉, Sum의 선형성은 다음과 같이 표현한다.

\[\operatorname{Sum} ( \alpha\mathbf{X} + \beta\mathbf{Y}, \text{axis}=d ) = \alpha \operatorname{Sum} ( \mathbf{X}, \text{axis}=d ) + \beta \operatorname{Sum} ( \mathbf{Y}, \text{axis}=d )\]

Mean 역시 고정된 축의 크기에 대해 같은 형태의 선형성을 갖는다.

\[\operatorname{Mean} ( \alpha\mathbf{X} + \beta\mathbf{Y} ) = \alpha\operatorname{Mean}(\mathbf{X}) + \beta\operatorname{Mean}(\mathbf{Y})\]

Max reduction은 이 성질을 갖지 않는다.

여러 축의 Reduction

서로 다른 여러 축을 연속해서 sum reduction할 수 있다. 예를 들어

\[\mathbf{T} \in \mathbb{R}^{B\times S\times D}\]

에서 \(B\)축과 \(S\)축을 모두 합하면 \(D\)축만 남는다.

\[(B,S,D) \rightarrow (S,D) \rightarrow (D)\]

또는

\[(B,S,D) \rightarrow (B,D) \rightarrow (D)\]

로 계산할 수 있다. Sum의 경우 최종 결과는 같다.

\[\operatorname{Sum} ( \operatorname{Sum}(\mathbf{T},\text{axis}=1), \text{axis}=0 )\]

과

\[\operatorname{Sum} ( \mathbf{T}, \text{axes}=(0,1) )\]

은 같은 값을 만든다.

헷갈리는 부분

Axis 번호와 방향

axis = 0을 단순히 "행"이라고 외우면 헷갈릴 수 있다.

\[\mathbf{X}\in\mathbb{R}^{M\times N}\]

에서 axis = 0은 첫 번째 축 \(M\)을 reduction한다​는 뜻이다. 따라서 \(M\)이 사라지고 \(N\)이 남는다.

\[(M,N) \rightarrow (N)\]

axis = 1은 두 번째 축 \(N\)을 reduction한다.

\[(M,N) \rightarrow (M)\]

축 번호를 기준으로 판단하는 편이 정확하다.

Reduction과 keepdims

다음 두 결과는 값은 대응하지만 shape이 다르다.

\[\begin{gathered} \operatorname{sum}(\mathbf{X},\text{axis}=1) \in \mathbb{R}^{M} \\[6pt] \operatorname{sum}(\mathbf{X},\text{axis}=1,\text{keepdims=True}) \in \mathbb{R}^{M\times1} \end{gathered}\]

따라서 계산 결과의 값만 보지 말고 shape까지 확인해야 한다.

Reduction과 Pooling

Reduction은 특정 축의 여러 값을 합, 평균, 최대 등의 규칙으로 하나의 값으로 줄이는 연산 자체를 말한다. Pooling은 이런 reduction을 특정 영역에 적용하여 대표값을 만드는 방식이다. Global pooling은 전체 영역을 사용하고, local pooling은 부분 영역을 사용한다.

Reduction과 Broadcasting

Reduction은 축을 줄인다.

\[(B,S,D) \rightarrow (B,1,D)\]

Broadcasting은 크기 1인 축을 다른 배열과의 연산에 맞게 확장해서 해석한다.

\[(B,1,D) \rightarrow (B,S,D)\]

두 연산은 방향이 반대처럼 보이지만 서로 다른 연산이다.

정리

Reduction은 어느 축을 줄이는가가 기준이다.

\[\mathbf{T} \in \mathbb{R}^{D_1\times D_2\times\cdots\times D_K}\]

에서 하나의 축 \(D_j\)에 reduction을 적용하고 keepdims=False라면 해당 축이 제거된다.

\[\begin{gathered} D_1\times\cdots\times D_j\times\cdots\times D_K \\[6pt] \downarrow \\[6pt] D_1\times\cdots\times D_{j-1} \times D_{j+1}\times\cdots\times D_K \end{gathered}\]

keepdims=True라면 축은 남고 크기만 1이 된다.

\[\begin{gathered} D_1\times\cdots\times D_j\times\cdots\times D_K \\[6pt] \downarrow \\[6pt] D_1\times\cdots\times1\times\cdots\times D_K \end{gathered}\]
