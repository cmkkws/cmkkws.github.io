LA-18 — Singular Value Decomposition (SVD)

특이값분해의 기하학적 의미와 고유값 연결, 저랭크 근사·PCA·유사역행렬 활용을 정리한다.

개념

Singular Value Decomposition임의의 실수 행렬 \(A\in\mathbb R^{M\times N}\) 은 적절한 Orthogonal Matrix \(U,V\)와 Rectangular Diagonal Matrix \(\Sigma\)를 이용하여

\[\boxed{ A = U\Sigma V^T }\]

로 분해할 수 있다. 이를 Singular Value Decomposition, SVD​라고 한다.

SVD의 중요한 특징Eigendecomposition은 기본적으로 Square Matrix에 대해 정의되며 모든 Square Matrix가 Diagonalizable한 것도 아니다. 반면 SVD는 \(\boxed{ \text{모든 유한차원 실수 행렬} }\) 에 존재한다. 따라서

  • Square Matrix
  • Rectangular Matrix
  • Full-rank Matrix
  • Rank-deficient Matrix

를 모두 다룰 수 있다.

표기·차원

Full SVDFull SVD에서는

\[\boxed{ A = U\Sigma V^T }\]

이고 다음과 같다.

\[\begin{gathered} \boxed{ U\in\mathbb R^{M\times M} } \\[6pt] \boxed{ \Sigma\in\mathbb R^{M\times N} } \\[6pt] \boxed{ V\in\mathbb R^{N\times N} } \end{gathered}\]

Orthogonal Matrix U\(U\)는 Orthogonal Matrix이므로 다음과 같다.

\[\boxed{ U^TU = UU^T = I_M }\]

\(U\)의 Column을 \(u_1,\dots,u_M\) 이라 하면 이를 Left Singular Vectors라고 한다.

Orthogonal Matrix V\(V\) 역시 Orthogonal Matrix다 다음과 같다.

\[\boxed{ V^TV = VV^T = I_N }\]

\(V\)의 Column \(v_1,\dots,v_N\) 을 Right Singular Vectors라고 한다.

Singular Value Matrix\(\Sigma\)는 Rectangular Diagonal Matrix다. 대각선에 음이 아닌 값

\[\boxed{ \sigma_1 \ge \sigma_2 \ge \cdots \ge 0 }\]

가 배치된다. 이를 Singular Values라고 한다.

Rank와 Positive Singular Values행렬의 Rank를

\[\boxed{ r = \operatorname{rank}(A) }\]

라고 하면 Positive Singular Value의 개수는 정확히 \(r\)개다. 즉

\[\boxed{ \sigma_1 \ge \cdots \ge \sigma_r > 0 }\]

이고 나머지는 0이다. 원자료 역시 이 구조를 기본 SVD 정의로 사용한다.

SVD의 Shape 확인Matrix Product의 Shape은 다음과 같다.

\((M\times M) (M\times N) (N\times N)\) 따라서 최종 결과는 \(\boxed{ M\times N }\) 이며 원래 \(A\)의 Shape과 일치한다.

핵심 연산

Singular Value는 항상 NonnegativeSVD에서는 Convention으로 \(\boxed{ \sigma_i\ge0 }\) 로 정의한다. Eigenvalue처럼 음의 Singular Value는 사용하지 않는다.

SVD와 Eigendecomposition의 차이Eigendecomposition 다음과 같다.

\[\boxed{ A=PDP^{-1} }\]

SVD 다음과 같다.

\[\boxed{ A=U\Sigma V^T }\]

SVD에서는 일반적으로 왼쪽과 오른쪽의 Basis가 서로 다르다.

Square Matrix일 필요가 없다SVD는

\[A: \mathbb R^N \rightarrow \mathbb R^M\]

인 Linear Map에 적용된다. 따라서 Input Space와 Output Space의 Dimension이 서로 달라도 된다.

기하학적 해석Vector \(x\in\mathbb R^N\) 에 대해

\[y=Ax\]

라고 하자. SVD를 대입하면 다음과 같다.

\[\boxed{ y = U\Sigma V^Tx }\]

첫 번째 단계먼저

\[\boxed{ z = V^Tx }\]

를 계산한다. \(V\)는 Orthogonal Matrix이므로 Norm과 Angle을 보존한다.

Orthogonal Transformation따라서 \(V^T\)는

  • Rotation
  • Reflection
  • 또는 이들의 조합

으로 이해할 수 있다. 단순히 항상 Rotation이라고 부르는 것은 정확하지 않다.

두 번째 단계그다음

\[\boxed{ w = \Sigma z }\]

를 계산한다. 각 Singular Direction은 대응 Singular Value만큼 Scaling된다.

Scaling\(i\)번째 Singular Direction에서는 다음과 같다.

\[\boxed{ z_i \rightarrow \sigma_i z_i }\]

\(\sigma_i>1\)이면 확장,

\[0<\sigma_i<1\]

이면 축소된다.

Zero Singular Value

\[\sigma_i=0\]

이면 해당 Input Direction의 정보는 Output에서 완전히 사라진다. 즉 해당 방향은 Null Space와 연결된다.

세 번째 단계마지막으로 다음과 같다.

\[\boxed{ y = Uw }\]

\(U\) 역시 Orthogonal Transformation으로 Output Coordinate를 Left-Singular-Vector Basis로 Mapping한다.

전체 기하학적 흐름따라서 SVD는

\[\boxed{ \text{orthogonal transform} \rightarrow \text{axis-wise scaling} \rightarrow \text{orthogonal transform} }\]

으로 해석할 수 있다. 원자료의 Rotation → Stretch → Rotation 설명을 엄밀하게 수정하면 이 형태다.

Unit Sphere의 변환Input Unit Sphere를

\[\boxed{ S^{N-1} = \{ x\in\mathbb R^N: \|x\|_2=1 \} }\]

이라고 하자.

Right Singular Basis\(V^T\)는 Unit Sphere의 Shape을 변화시키지 않는다. Orthogonal Transformation이므로 다음과 같다.

\[\boxed{ \|V^Tx\|_2 = \|x\|_2 }\]

Singular Scaling\(\Sigma\)가 Sphere의 축을 \(\sigma_1,\dots,\sigma_r\) 에 따라 늘리거나 줄인다.

Left Singular Directions마지막으로 \(U\)가 결과를 Output Space의 방향으로 Orthogonally Transform한다. 따라서 Nonzero Principal Axis Direction은 \(\boxed{ u_i }\) 이고 대응 Axis Length는 다음과 같다.

\(\boxed{ \sigma_i }\)

Rank-deficient Case만약

\[r<\min(M,N)\]

이면 Zero Singular Value가 존재한다. 따라서 Unit Sphere의 Image는 Full-dimensional Ellipsoid가 아니라 Lower-dimensional Ellipsoid 또는 Degenerate Ellipsoid가 된다.

“사영” 표현 주의원자료는 Unit Sphere가 Ellipsoid로 “사영된다”고 표현한다. 하지만 일반 \(A\)는 Orthogonal Projection Operator일 필요가 없다. 더 정확한 표현은 다음과 같다.

\[\boxed{ \text{Unit Sphere가 Linear Map }A\text{에 의해 Ellipsoid로 매핑된다} }\]

특이값은 어디서 나오는가SVD와 Eigenvalue는 \(\boxed{ A^TA }\) 와 \(\boxed{ AA^T }\) 를 통해 연결된다.

A transpose A\(A\in\mathbb R^{M\times N}\) 이면 다음과 같다.

\[\boxed{ A^TA \in \mathbb R^{N\times N} }\]

Symmetry

\[\begin{aligned} (A^TA)^T &= A^T(A^T)^T\\ &= A^TA \end{aligned}\]

따라서 다음과 같다.

\(\boxed{ A^TA \text{ is symmetric} }\)

Positive Semidefinite임의의 \(x\in\mathbb R^N\) 에 대해 다음과 같다.

\[\begin{aligned} x^TA^TAx &= (Ax)^T(Ax)\\ &= \|Ax\|_2^2\\ &\ge0 \end{aligned}\]

따라서 다음과 같다.

\(\boxed{ A^TA\succeq0 }\)

Spectral Theorem 적용\(A^TA\)는 Real Symmetric PSD Matrix이므로

\[\boxed{ A^TA = V\Lambda V^T }\]

로 Orthogonally Diagonalize할 수 있다.

핵심 식 — Singular Values

\[\boxed{ \sigma_i = \sqrt{ \lambda_i( A^TA ) } }\]

핵심 식 — Mapping Relation

\[\boxed{ Av_i = \sigma_i u_i }\]

또한 다음과 같다.

\[\boxed{ A^Tu_i = \sigma_i v_i }\]

핵심 식 — Reduced SVD

\[\boxed{ A = U_r\Sigma_rV_r^T }\]

이는 Exact Representation이다.

핵심 식 — Rank-1 Expansion

\[\boxed{ A = \sum_{i=1}^{r} \sigma_i u_iv_i^T }\]

핵심 식 — Truncated SVD

\[\boxed{ A_k = \sum_{i=1}^{k} \sigma_i u_iv_i^T }\]

핵심 식 — Frobenius Error

\[\boxed{ \|A-A_k\|_F^2 = \sum_{i=k+1}^{r} \sigma_i^2 }\]

핵심 식 — Spectral Norm

\[\boxed{ \|A\|_2 = \sigma_{\max}(A) }\]

성질·유도

Eigenvalues are nonnegativePSD이므로 다음과 같다.

\(\boxed{ \lambda_i(A^TA)\ge0 }\)

Singular Value 정의Singular Value는

\[\boxed{ \sigma_i = \sqrt{ \lambda_i(A^TA) } }\]

로 정의할 수 있다. 따라서 자동으로 다음과 같다.

\(\sigma_i\ge0\)

Right Singular Vectors\(A^TA\)의 Eigenvector는 \(\boxed{ v_i }\) 이고

\[\boxed{ A^TAv_i = \sigma_i^2v_i }\]

를 만족한다. 이들이 Right Singular Vectors다.

A A transpose반대로 다음과 같다.

\[\boxed{ AA^T \in \mathbb R^{M\times M} }\]

이 Matrix 역시 Symmetric PSD다.

Left Singular Vectors\(AA^T\) 의 Eigenvector를 \(u_i\) 라고 하면 다음과 같다.

\[\boxed{ AA^Tu_i = \sigma_i^2u_i }\]

이들이 Left Singular Vectors다.

Positive Eigenvalues의 일치\(A^TA\)와 \(AA^T\)는 Shape이 다를 수 있다. 그러나 두 Matrix의 0이 아닌 Eigenvalue들은 Multiplicity까지 포함하여 동일하다. 그 값이 다음과 같다.

\(\boxed{ \sigma_i^2 }\)

Zero Eigenvalue 개수는 다를 수 있다예를 들어

\[M>N\]

이면 \(AA^T\)가 \(A^TA\)보다 더 큰 Matrix다. 따라서 추가적인 Zero Eigenvalue를 가질 수 있다.

원자료 SVD 대입 확인SVD

\[A=U\Sigma V^T\]

를 사용하면 다음과 같다.

\[\begin{aligned} A^TA &= V\Sigma^TU^TU\Sigma V^T\\ &= V\Sigma^T\Sigma V^T \end{aligned}\]

따라서 다음과 같다.

\[\boxed{ A^TA = V( \Sigma^T\Sigma ) V^T }\]

A A transpose 확인마찬가지로 다음과 같다.

\[\boxed{ AA^T = U( \Sigma\Sigma^T ) U^T }\]

원자료의 두 식과 동일하다.

SVD의 constructive 관점SVD의 존재를 이해할 때는 단순히 SVD 공식을 먼저 가정하는 대신 \(A^TA\) 의 Spectral Decomposition에서 시작할 수 있다.

Step 1먼저

\[\boxed{ A^TAv_i = \sigma_i^2v_i }\]

를 계산한다.

Step 2Positive Singular Value에 대해

\[\boxed{ u_i = \frac1{\sigma_i} Av_i }\]

라고 정의한다.

Unit Norm 확인\(v_i\)가 Unit Vector라면 다음과 같다.

\[\begin{aligned} \|u_i\|_2^2 &= \frac1{\sigma_i^2} v_i^TA^TAv_i\\ &= \frac1{\sigma_i^2} v_i^T ( \sigma_i^2v_i )\\ &= 1 \end{aligned}\]

Left Singular Vector의 Orthogonality\(i\neq j\)에 대해 다음과 같다.

\[\begin{aligned} u_i^Tu_j &= \frac1{\sigma_i\sigma_j} v_i^TA^TAv_j\\ &= \frac{\sigma_j^2}{ \sigma_i\sigma_j } v_i^Tv_j\\ &= 0 \end{aligned}\]

따라서 Positive Singular Value에 대응하는 \(u_i\)들도 Orthonormal하다.

핵심 관계식정의로부터 다음과 같다.

\[\boxed{ Av_i = \sigma_i u_i }\]

원자료의 핵심 관계식이다.

반대 방향 관계양변에 \(A^T\)를 적절히 적용하면

\[\boxed{ A^Tu_i = \sigma_i v_i }\]

도 얻는다.

증명

\[u_i = \frac1{\sigma_i}Av_i\]

이므로 다음과 같다.

\[\begin{aligned} A^Tu_i &= \frac1{\sigma_i} A^TAv_i\\ &= \frac1{\sigma_i} \sigma_i^2v_i\\ &= \boxed{ \sigma_iv_i } \end{aligned}\]

두 관계의 의미따라서

\[\boxed{ v_i \xrightarrow{A} \sigma_i u_i }\]

이고 다음과 같다.

\[\boxed{ u_i \xrightarrow{A^T} \sigma_i v_i }\]

Null Space 연결만약

\[\sigma_i=0\]

이면 다음과 같다.

\[A^TAv_i=0\]

그리고

\[\|Av_i\|_2^2 = v_i^TA^TAv_i = 0\]

이므로 다음과 같다.

\[\boxed{ Av_i=0 }\]

Right Null Space따라서 Zero Singular Value에 대응하는 Right Singular Vector들은 \(\boxed{ \mathcal N(A) }\) 를 생성한다.

Column SpaceNonzero Singular Value에 대응하는 \(u_1,\dots,u_r\) 은 \(\boxed{ \mathcal C(A) }\) 의 Orthonormal Basis를 이룬다.

Row SpaceNonzero Singular Value에 대응하는 \(v_1,\dots,v_r\) 은 \(\boxed{ \mathcal C(A^T) }\) 즉 Row Space의 Orthonormal Basis를 이룬다.

Left Null Space남은 Left Singular Vector들은 \(\boxed{ \mathcal N(A^T) }\) 를 생성한다.

Fundamental Subspaces와 SVD따라서 SVD는

  • Column Space
  • Row Space
  • Null Space
  • Left Null Space

를 하나의 분해 안에서 동시에 보여준다.

Full SVDFull SVD는 다음과 같다.

\[\boxed{ A = U\Sigma V^T }\]

여기서 \(U,V\) 모두 Square Orthogonal Matrix다.

Reduced 또는 Compact SVDRank가

\[r = \operatorname{rank}(A)\]

라고 하자. Positive Singular Value에 해당하는 부분만 남기면 다음과 같다.

\[\boxed{ A = U_r\Sigma_rV_r^T }\]

Shape은 다음과 같다.

\[\begin{gathered} \boxed{ U_r \in \mathbb R^{M\times r} } \\[6pt] \boxed{ \Sigma_r \in \mathbb R^{r\times r} } \\[6pt] \boxed{ V_r \in \mathbb R^{N\times r} } \end{gathered}\]

Reduced SVD는 정확한 분해중요하게

\[\boxed{ A = U_r\Sigma_rV_r^T }\]

는 Approximation이 아니다. Zero Singular Value에 대응하는 불필요한 Basis Vector만 제거했기 때문에 여전히 정확히 \(A\)를 복원한다.

Truncated SVD이제

\[k<r\]

라고 하자. 상위 \(k\)개의 Singular Component만 남기면 다음과 같다.

\[\boxed{ A_k = U_k\Sigma_kV_k^T }\]

Truncated SVD는 근사일반적으로 다음과 같다.

\(\boxed{ A_k\neq A }\) Rank는 다음과 같다.

\[\boxed{ \operatorname{rank}(A_k)\le k }\]

원자료 용어 보완원자료는 “Compact (Truncated) SVD”라는 표현으로 두 개념을 함께 사용한다. 하지만 엄밀하게는 구분하는 편이 좋다 다음과 같다.

\[\begin{gathered} \boxed{ \text{Reduced/Compact SVD} = \text{exact rank-}r\text{ representation} } \\[6pt] \boxed{ \text{Truncated SVD} = \text{rank-}k\text{ approximation},\quad k<r } \end{gathered}\]

Outer-Product RepresentationReduced SVD를 Column 단위로 전개하면 다음과 같다.

\[\boxed{ A = \sum_{i=1}^{r} \sigma_i u_iv_i^T }\]

원자료의 Rank-1 Sum 식과 동일하다.

각 항의 Rank\(u_iv_i^T\) 는 Nonzero Vector 두 개의 Outer Product이므로 다음과 같다.

\[\boxed{ \operatorname{rank} ( u_iv_i^T ) = 1 }\]

각 Singular Component따라서 \(\boxed{ \sigma_i u_iv_i^T }\) 를 \(A\)의 \(i\)번째 Rank-1 Singular Component라고 볼 수 있다.

Truncated Sum상위 \(k\)개만 남기면 다음과 같다.

\[\boxed{ A_k = \sum_{i=1}^{k} \sigma_i u_iv_i^T }\]

Eckart–Young–Mirsky 정리SVD의 핵심적인 Low-rank Approximation 성질은 다음과 같다. Rank가 \(k\) 이하인 모든 Matrix \(B\) 중에서 Truncated SVD \(A_k\)가 최적이다. Frobenius Norm에서는 다음과 같다.

\[\boxed{ A_k = \arg\min_{ \operatorname{rank}(B)\le k } \|A-B\|_F }\]

Spectral Norm에서도 최적또한 다음과 같다.

\[\boxed{ A_k = \arg\min_{ \operatorname{rank}(B)\le k } \|A-B\|_2 }\]

Frobenius Approximation Error

\[\boxed{ \|A-A_k\|_F^2 = \sum_{i=k+1}^{r} \sigma_i^2 }\]

Spectral Approximation Error

\[\boxed{ \|A-A_k\|_2 = \sigma_{k+1} }\]

의미따라서 Singular Value가 빠르게 감소한다면 작은 \(k\)만 사용해도 원래 Matrix를 비교적 정확하게 근사할 수 있다. 반대로 Singular Value가 천천히 감소한다면 강한 Low-rank Compression에서 오차가 커질 수 있다.

Frobenius Norm과 Singular ValuesSVD를 사용하면 다음과 같다.

\[\boxed{ \|A\|_F^2 = \sum_{i=1}^{r} \sigma_i^2 }\]

Spectral NormOperator 2-Norm은 다음과 같다.

\[\boxed{ \|A\|_2 = \sigma_1 = \sigma_{\max}(A) }\]

LA-15에서 Spectral Radius와 구분했던 Quantity다.

RankPositive Singular Value 수가 Rank이므로 다음과 같다.

\[\boxed{ \operatorname{rank}(A) = \#\{ i:\sigma_i>0 \} }\]

Nuclear NormSingular Value의 합

\[\boxed{ \|A\|_* = \sum_i\sigma_i }\]

을 Nuclear Norm이라고 한다. Low-rank Optimization에서 자주 등장한다.

Condition NumberFull-rank Square Matrix에서 2-Norm Condition Number는 다음과 같다.

\[\boxed{ \kappa_2(A) = \frac{ \sigma_{\max} }{ \sigma_{\min} } }\]

작은 Minimum Singular Value\(\sigma_{\min}\) 이 0에 가까우면 \(\kappa_2(A)\) 가 커진다. 즉 Matrix가 Ill-conditioned해진다.

Singular MatrixSquare Matrix에서

\[\boxed{ \sigma_{\min}=0 }\]

이면 \(A\)는 Singular하다.

PseudoinverseSVD는 Moore–Penrose Pseudoinverse를 자연스럽게 제공한다. Reduced SVD가

\[A = U_r\Sigma_rV_r^T\]

이면 다음과 같다.

\[\boxed{ A^\dagger = V_r \Sigma_r^{-1} U_r^T }\]

Inverse Singular Values

\[\boxed{ \Sigma_r^{-1} = \operatorname{diag} \left( \frac1{\sigma_1}, \dots, \frac1{\sigma_r} \right) }\]

Positive Singular Value만 뒤집는다.

Least Squares 연결LA-14의 Least Squares Minimum-Norm Solution은

\[\boxed{ x^\ast = A^\dagger b }\]

로 표현할 수 있다.

Rank-deficient Case의 장점Normal Equation의 \((A^TA)^{-1}\) 가 존재하지 않는 경우에도 SVD 기반 Pseudoinverse는 자연스럽게 Least Squares Solution을 정의할 수 있다.

혼동하기 쉬운 부분 — SVD와 EigendecompositionSVD는 Square Matrix일 필요가 없다. 또한 모든 Matrix에 존재한다. 반면 Eigendecomposition은 Square Matrix를 대상으로 하며 Diagonalization 가능 여부가 별도로 존재한다.

혼동하기 쉬운 부분 — Eigenvalue와 Singular ValueEigenvalue는

\[\boxed{ Ax=\lambda x }\]

에서 나온다. Singular Value는 다음과 같다.

\[\boxed{ \sigma_i = \sqrt{ \lambda_i(A^TA) } }\]

일반 Matrix에서는 둘을 동일시하면 안 된다.

혼동하기 쉬운 부분 — SignSingular Value는 항상 다음과 같다.

\(\boxed{ \sigma_i\ge0 }\) 원래 Matrix에 음수 성분이 있어도 그 부호는 Singular Vector 방향에 흡수될 수 있다. 원자료 예제의 \(-2\)가 바로 이런 경우다.

혼동하기 쉬운 부분 — Compact와 TruncatedReduced/Compact SVD는 Zero Singular Component만 제거한 Exact Decomposition이다. Truncated SVD는 Positive Singular Component 중 일부까지 제거한 Approximation이다.

혼동하기 쉬운 부분 — Ellipsoid Projection일반 Matrix \(A\)는 Orthogonal Projection Matrix가 아니다. Unit Sphere가 \(A\)에 의해 Ellipsoid로 매핑된다고 표현하는 것이 정확하다.

혼동하기 쉬운 부분 — Zero Singular Value

\[\sigma_i=0\]

은 해당 Right Singular Direction이 Null Space에 들어간다는 뜻이다. 즉 다음과 같다.

\[\boxed{ Av_i=0 }\]

혼동하기 쉬운 부분 — SVD UniquenessSingular Values는 정렬 Convention 아래 고정되지만 Singular Vectors는 Sign Ambiguity와 반복 Singular Value 때문에 유일하지 않을 수 있다.

혼동하기 쉬운 부분 — LoRALoRA가 SVD의 Top Singular Direction만 학습하도록 정의된 것은 아니다. 기본 제약은 다음과 같다.

\[\boxed{ \operatorname{rank}(\Delta W)\le r }\]

혼동하기 쉬운 부분 — Low-rank Weight CompressionTruncated SVD가 Matrix Approximation Error를 최소화한다는 것은 정확하다. 하지만 실제 LLM의 Accuracy/Loss 저하를 최소화한다는 보편적 보장은 아니다.

혼동하기 쉬운 부분 — “50% 압축”압축률은 \(M,N,k\) 에 따라 달라진다. SVD 자체가 50% 이상의 Weight Reduction을 자동 보장하지 않는다.

Singular Value Decomposition은 임의의 실수 Matrix \(A\in\mathbb R^{M\times N}\) 를

\[\boxed{ A = U\Sigma V^T }\]

로 분해하는 방법이다. \(U\)와 \(V\)는 Orthogonal Matrix이고 \(\Sigma\)는 Nonnegative Singular Value를 대각선에 갖는 Rectangular Diagonal Matrix다 다음과 같다.

\[\boxed{ U^TU=I_M, \qquad V^TV=I_N }\]

SVD의 기하학적 의미는 다음과 같다.

\[\boxed{ \text{orthogonal transform} \rightarrow \text{direction-wise scaling} \rightarrow \text{orthogonal transform} }\]

Right Singular Vector는

\[\boxed{ A^TAv_i = \sigma_i^2v_i }\]

를 만족하고, Left Singular Vector는

\[\boxed{ AA^Tu_i = \sigma_i^2u_i }\]

를 만족한다. 따라서 Singular Value는 다음과 같다.

\[\boxed{ \sigma_i = \sqrt{ \lambda_i(A^TA) } }\]

Positive Singular Value에서는

\[\boxed{ Av_i = \sigma_i u_i }\]

이고 다음과 같다.

\[\boxed{ u_i = \frac1{\sigma_i} Av_i }\]

또한 다음과 같다.

\[\boxed{ A^Tu_i = \sigma_i v_i }\]

Rank가 \(r\)이면 Reduced SVD는 다음과 같다.

\[\boxed{ A = U_r\Sigma_rV_r^T }\]

이는 Exact Decomposition이며 다음과 같다.

\[U_r \in \mathbb R^{M\times r}, \qquad \Sigma_r \in \mathbb R^{r\times r}, \qquad V_r \in \mathbb R^{N\times r}\]

Outer-Product 형태는 다음과 같다.

\[\boxed{ A = \sum_{i=1}^{r} \sigma_i u_iv_i^T }\]

상위 \(k<r\)개만 남기면

\[\boxed{ A_k = \sum_{i=1}^{k} \sigma_i u_iv_i^T }\]

라는 Truncated SVD를 얻는다. 이 \(A_k\)는 Rank-\(k\) 이하 Matrix 중 Frobenius Norm과 Spectral Norm 기준에서 최적의 Low-rank Approximation이다. Frobenius Error는 다음과 같다.

\[\boxed{ \|A-A_k\|_F^2 = \sum_{i=k+1}^{r} \sigma_i^2 }\]

원자료의 수치 예제

\[A = \begin{bmatrix} 3&0\\ 0&-2\\ 0&0 \end{bmatrix}\]

에서는

\[\boxed{ A^TA = \begin{bmatrix} 9&0\\ 0&4 \end{bmatrix} }\]

이므로 다음과 같다.

\[\boxed{ \sigma_1=3, \qquad \sigma_2=2 }\]

Right Singular Matrix는

\[\boxed{ V = I_2 }\]

이고 다음과 같다.

\[\begin{gathered} \boxed{ u_1 = \begin{bmatrix} 1\\ 0\\ 0 \end{bmatrix} } \\[6pt] \boxed{ u_2 = \begin{bmatrix} 0\\ -1\\ 0 \end{bmatrix} } \end{gathered}\]

Full SVD를 위해

\[\boxed{ u_3 = \begin{bmatrix} 0\\ 0\\ 1 \end{bmatrix} }\]

을 추가하면 다음과 같다.

\[\boxed{ U = \begin{bmatrix} 1&0&0\\ 0&-1&0\\ 0&0&1 \end{bmatrix} }\]

그리고

\[\boxed{ \Sigma = \begin{bmatrix} 3&0\\ 0&2\\ 0&0 \end{bmatrix} }\]

이므로

\[\boxed{ U\Sigma V^T = A }\]

가 정확히 복원된다. SVD는 Norm과 Rank에도 직접 연결된다 다음과 같다.

\[\begin{gathered} \boxed{ \|A\|_2 = \sigma_1 } \\[6pt] \boxed{ \|A\|_F^2 = \sum_i\sigma_i^2 } \\[6pt] \boxed{ \operatorname{rank}(A) = \#\{ i:\sigma_i>0 \} } \end{gathered}\]

Pseudoinverse는

\[\boxed{ A^\dagger = V_r \Sigma_r^{-1} U_r^T }\]

로 표현되어 Rank-deficient Least Squares까지 다룰 수 있다. PCA에서는 Centered Data

\[X_c = U\Sigma V^T\]

를 SVD하면 Right Singular Vectors \(V\)가 Principal Directions가 되고 Covariance Eigenvalue는 Singular Value의 제곱에 비례한다. LLM Weight Compression에서는

\[W \approx U_k\Sigma_kV_k^T\]

를 이용해 Low-rank Factorization을 만들 수 있다. 하지만 압축 효과는 Singular Spectrum과 선택한 Rank에 따라 달라지며, SVD 자체가 “50% 이상 압축하면서 성능 저하가 거의 없다”는 것을 보장하지 않는다. LoRA에서는

\[\boxed{ \Delta W=BA }\]

를 사용하여

\[\boxed{ \operatorname{rank}(\Delta W)\le r }\]

라는 Low-rank Update Constraint를 건다. 이것은 SVD와 수학적으로 밀접한 Low-rank 관점이지만, 기본 LoRA가 Pretrained Weight의 Top Singular Vector Directions에서만 Update하도록 설계된 것은 아니다. 따라서 LA-18의 전체 흐름은 다음과 같다.

\[\boxed{ \text{General Matrix} \rightarrow A^TA,\;AA^T \rightarrow \text{Singular Values/Vectors} \rightarrow \text{SVD} }\]

이후

\[\boxed{ \text{SVD} \rightarrow \text{Rank-1 Decomposition} \rightarrow \text{Low-rank Approximation} }\]

으로 확장된다. Machine Learning에서는

\[\boxed{ \text{SVD} \rightarrow \text{PCA / Least Squares / Compression} }\]

으로 연결되고, LLM에서는

\[\boxed{ \text{Low-rank Matrix Structure} \rightarrow \text{Weight Compression / LoRA} }\]

를 이해하기 위한 핵심 Linear Algebra 도구가 된다.

예제·적용

Numerical Example원자료의 Matrix는 다음과 같다.

\[\boxed{ A = \begin{bmatrix} 3&0\\ 0&-2\\ 0&0 \end{bmatrix} }\]

Shape은 다음과 같다.

\(\boxed{ 3\times2 }\)

A transpose A

\[A^T = \begin{bmatrix} 3&0&0\\ 0&-2&0 \end{bmatrix}\]

이므로 다음과 같다.

\[\begin{aligned} A^TA &= \begin{bmatrix} 3&0&0\\ 0&-2&0 \end{bmatrix} \begin{bmatrix} 3&0\\ 0&-2\\ 0&0 \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} 9&0\\ 0&4 \end{bmatrix} } \end{aligned}\]

Eigenvalues이미 Diagonal Matrix이므로 Eigenvalue는 다음과 같다.

\[\boxed{ \lambda_1=9, \qquad \lambda_2=4 }\]

Singular Values따라서 다음과 같다.

\[\begin{gathered} \boxed{ \sigma_1 = \sqrt9 = 3 } \\[6pt] \boxed{ \sigma_2 = \sqrt4 = 2 } \end{gathered}\]

Right Singular Vectors대응 Eigenvector는 다음과 같다.

\[\begin{gathered} \boxed{ v_1 = \begin{bmatrix} 1\\ 0 \end{bmatrix} } \\[6pt] \boxed{ v_2 = \begin{bmatrix} 0\\ 1 \end{bmatrix} } \end{gathered}\]

따라서 다음과 같다.

\[\boxed{ V = I_2 }\]

Sigma MatrixFull SVD의 \(\Sigma\)는 다음과 같다.

\[\boxed{ \Sigma = \begin{bmatrix} 3&0\\ 0&2\\ 0&0 \end{bmatrix} }\]

First Left Singular Vector

\[u_1 = \frac1{\sigma_1} Av_1\]

이므로 다음과 같다.

\[\begin{aligned} u_1 &= \frac13 \begin{bmatrix} 3\\ 0\\ 0 \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} 1\\ 0\\ 0 \end{bmatrix} } \end{aligned}\]

Second Left Singular Vector

\[\begin{gathered} u_2 = \frac1{2} Av_2 \\[6pt] Av_2 = \begin{bmatrix} 0\\ -2\\ 0 \end{bmatrix} \end{gathered}\]

이므로 다음과 같다.

\[\boxed{ u_2 = \begin{bmatrix} 0\\ -1\\ 0 \end{bmatrix} }\]

Third Left Singular VectorFull \(U\in\mathbb R^{3\times3}\)를 만들려면 \(u_1,u_2\)와 직교하는 Unit Vector 하나가 더 필요하다. 대표적으로

\[\boxed{ u_3 = \begin{bmatrix} 0\\ 0\\ 1 \end{bmatrix} }\]

을 선택할 수 있다.

U Matrix따라서 다음과 같다.

\[\boxed{ U = \begin{bmatrix} 1&0&0\\ 0&-1&0\\ 0&0&1 \end{bmatrix} }\]

Orthogonality 확인

\[\boxed{ U^TU=I_3 }\]

이고 다음과 같다.

\[\boxed{ V^TV=I_2 }\]

Reconstruction

\[U\Sigma = \begin{bmatrix} 1&0&0\\ 0&-1&0\\ 0&0&1 \end{bmatrix} \begin{bmatrix} 3&0\\ 0&2\\ 0&0 \end{bmatrix}\]

이므로 다음과 같다.

\[\boxed{ U\Sigma = \begin{bmatrix} 3&0\\ 0&-2\\ 0&0 \end{bmatrix} }\]

Final Reconstruction\(V^T=I\)이므로 다음과 같다.

\[\boxed{ U\Sigma V^T = \begin{bmatrix} 3&0\\ 0&-2\\ 0&0 \end{bmatrix} = A }\]

원자료의 수치 예제는 재검산 결과 정확하다.

SVD의 비유일성Singular Value 자체는 정렬 Convention 아래에서 고정되지만 Singular Vector는 항상 완전히 유일한 것은 아니다.

Sign Ambiguity한 Singular Pair에 대해

\[u_i \rightarrow -u_i\]

와

\[v_i \rightarrow -v_i\]

를 동시에 적용해도 \(\sigma_i u_iv_i^T\) 는 변하지 않는다.

Repeated Singular Values같은 Singular Value가 반복되면 해당 Singular Subspace 안에서 Orthogonal Basis를 다르게 선택할 수 있다. 따라서 Singular Vector가 개별적으로 유일하지 않을 수 있다.

Null-space BasisFull SVD에서 Zero Singular Value에 대응하는 추가 \(u_i,v_i\)들도 해당 Null Subspace 안에서 여러 방식으로 선택할 수 있다.

PCA와 SVD 연결Centered Data Matrix를

\[\boxed{ X_c \in \mathbb R^{M\times D} }\]

라고 하자. SVD를

\[\boxed{ X_c = U\Sigma V^T }\]

라고 한다.

Covariance MatrixPopulation-style normalization이면 다음과 같다.

\[\boxed{ C = \frac1M X_c^TX_c }\]

SVD 대입

\[\begin{aligned} C &= \frac1M V\Sigma^TU^TU\Sigma V^T\\ &= \frac1M V\Sigma^T\Sigma V^T \end{aligned}\]

PCA Directions따라서 Covariance Matrix의 Eigenvectors는 \(\boxed{ V }\) 의 Column들이다. 즉 Right Singular Vectors가 Principal Directions다.

PCA EigenvaluesCovariance Eigenvalue는 다음과 같다.

\[\boxed{ \frac{ \sigma_i^2 }{ M } }\]

Sample Covariance에서 \(1/(M-1)\)을 쓰면 대응 Scaling만 바뀐다.

PCA를 SVD로 직접 계산따라서 실제 PCA에서는 큰 Covariance Matrix를 명시적으로 생성하지 않고 Centered Data Matrix 자체에 SVD를 적용할 수 있다.

Low-rank CompressionMatrix \(W\in\mathbb R^{M\times N}\) 을 Rank-\(k\) Truncated SVD로

\[\boxed{ W \approx U_k\Sigma_kV_k^T }\]

라고 하자.

Factorized Storage다음 두 Matrix로 묶을 수 있다 다음과 같다.

\[\begin{gathered} \boxed{ B = U_k\Sigma_k \in \mathbb R^{M\times k} } \\[6pt] \boxed{ C = V_k^T \in \mathbb R^{k\times N} } \end{gathered}\]

그러면 다음과 같다.

\[\boxed{ W\approx BC }\]

Parameter Count원래 Matrix는 \(\boxed{ MN }\) 개의 Scalar를 가진다. Low-rank Factorization은 \(\boxed{ k(M+N) }\) 개의 Scalar가 필요하다.

언제 Compression이 되는가Factorized Representation이 더 작으려면

\[\boxed{ k(M+N)<MN }\]

이어야 한다. 즉 다음과 같다.

\[\boxed{ k < \frac{ MN }{ M+N } }\]

Compression RatioParameter 기준 비율은 대략 다음과 같다.

\[\boxed{ \frac{ k(M+N) }{ MN } }\]

따라서 Compression Ratio는 Matrix Shape와 선택한 \(k\)에 따라 달라진다.

Weight SVD Compression에 대한 원자료 주장원자료는 FFN 및 Attention Weight의 작은 Singular Value를 절단하여 “성능 저하를 최소화하면서 50% 이상” 압축할 수 있다고 설명한다.

50%는 보편적 보장이 아니다Truncated SVD 자체가 보장하는 것은 주어진 Rank-\(k\)에서 Matrix Norm 기준 최적 근사라는 사실이다. 하지만 \(\boxed{ 50\%\text{ 이상 compression} }\) 이나

\[\boxed{ \text{negligible model-quality loss} }\]

는 모든 LLM Weight에 대해 보장되지 않는다.

Model Performance와 Matrix Error 구분\(\|W-W_k\|\) 가 작다는 사실과 최종 Language Model의 Task Performance 저하가 작다는 사실은 동일하지 않다. Network Composition, Activation, Layer Sensitivity 등이 함께 영향을 준다.

LoRA 연결LoRA에서는 Pretrained Weight를 \(\boxed{ W_0 }\) 로 두고, 전체 Weight를 직접 Fine-tuning하지 않고 Low-rank Update

\[\boxed{ \Delta W = BA }\]

를 학습한다.

LoRA Shape예를 들어

\[W_0 \in \mathbb R^{d_{\mathrm{out}} \times d_{\mathrm{in}}}\]

일 때 다음과 같다.

\[\begin{gathered} \boxed{ B \in \mathbb R^{d_{\mathrm{out}}\times r} } \\[6pt] \boxed{ A \in \mathbb R^{r\times d_{\mathrm{in}}} } \end{gathered}\]

Rank ConstraintMatrix Product의 Rank 성질에 의해 다음과 같다.

\[\boxed{ \operatorname{rank}( \Delta W ) = \operatorname{rank}(BA) \le r }\]

이것이 LoRA의 직접적인 Linear-Algebraic 핵심이다.

LoRA와 SVD의 관계SVD는 모든 Rank-\(r\) Matrix를 Singular Directions의 합으로 표현할 수 있다는 점에서 Low-rank Update를 이해하는 수학적 언어를 제공한다. 하지만 LoRA가 Training 중 매 Step 명시적으로 SVD를 수행하는 것은 아니다.

원자료의 LoRA 설명 보완원자료는 LoRA가 업데이트를 “특이값이 높은 고유 부분공간 상에서만” 수행하도록 설계되었다고 설명한다. 이는 LoRA의 정의 자체로부터 나오지 않는다.

LoRA가 실제로 강제하는 것LoRA가 직접 강제하는 것은

\[\boxed{ \operatorname{rank}( \Delta W ) \le r }\]

이라는 Low-rank Constraint다.

강제하지 않는 것기본 LoRA는 \(\boxed{ \Delta W }\) 가 반드시 \(W_0\)의 Top Singular Vector Directions와 정렬되도록 강제하지 않는다. 학습된 Subspace는 Optimization과 Data에 의해 결정된다.

Pretrained Weight의 Spectrum원자료는 LLM Weight Matrix의 대부분의 “에너지”가 상위 몇 개 Singular Component에 집중된다고 일반화한다. 하지만 Singular Spectrum의 Decay Pattern은

  • Layer
  • Weight Type
  • Model
  • Training

에 따라 다를 수 있다. 따라서 이를 모든 LLM Weight에 대한 보편적 사실로 취급하지 않는다.

Energy 표현Frobenius Norm 관점에서 Matrix의 총 Squared Magnitude는 다음과 같다.

\[\boxed{ \|W\|_F^2 = \sum_i\sigma_i^2 }\]

Top-k Energy Fraction상위 \(k\)개 Singular Component의 Frobenius-energy fraction은

\[\boxed{ \frac{ \sum_{i=1}^{k} \sigma_i^2 }{ \sum_{i=1}^{r} \sigma_i^2 } }\]

로 정의할 수 있다.

Spectrum Decay와 Compression이 값이 빠르게 1에 접근하는 Matrix일수록 Low-rank Approximation이 효과적일 가능성이 높다. 하지만 이는 실제 Downstream Model Quality와 별개의 Quantity다.

SVD와 Neural Network NormLinear Layer

\[y=Wx\]

에 대해 다음과 같다.

\[\boxed{ \|Wx\|_2 \le \sigma_{\max}(W) \|x\|_2 }\]

Maximum Amplification따라서 \(\boxed{ \sigma_1 }\) 은 Unit Input에 대한 최대 Euclidean Norm Amplification Factor다.

Minimum AmplificationFull Column Rank이고 적절한 Dimension 조건에서는 최소 Singular Value가 가장 약하게 증폭되는 Direction과 연결된다 다음과 같다.

\[\boxed{ \sigma_{\min} \|x\|_2 \le \|Ax\|_2 }\]

DL Stability 연결따라서 Gradient/Activation Norm의 단일 Linear Layer 증폭을 분석할 때 Eigenvalue보다 Singular Value가 더 직접적이다. 이것이 LA-15의 Spectral Radius와 Spectral Norm 구분과 연결된다.

전체 개념 연결SVD는 임의의 Linear Map

\[\boxed{ A: \mathbb R^N \rightarrow \mathbb R^M }\]

을 다룬다.

Geometry Flow

\[\boxed{ x \rightarrow V^Tx \rightarrow \Sigma V^Tx \rightarrow U\Sigma V^Tx }\]

즉 다음과 같다.

\[\boxed{ \text{orthogonal basis change} \rightarrow \text{axis scaling} \rightarrow \text{orthogonal basis change} }\]

Eigenvalue Flow

\[\boxed{ A \rightarrow A^TA \rightarrow (\lambda_i,v_i) \rightarrow \sigma_i=\sqrt{\lambda_i} }\]

그다음

\[\boxed{ u_i = \frac{Av_i}{\sigma_i} }\]

를 계산한다.

Rank Flow

\[\boxed{ \sigma_i>0 }\]

인 Singular Value의 개수가 다음과 같다.

\(\boxed{ \operatorname{rank}(A) }\)

Approximation Flow

\[\boxed{ A = \sum_{i=1}^{r} \sigma_i u_iv_i^T }\]

에서 작은 Singular Components를 제거하면 \(\boxed{ A_k }\) 라는 Low-rank Approximation을 얻는다.

Machine Learning FlowSVD는

\[\begin{gathered} \boxed{ \text{SVD} \rightarrow \text{PCA} } \\[6pt] \boxed{ \text{SVD} \rightarrow \text{Pseudoinverse / Least Squares} } \\[6pt] \boxed{ \text{SVD} \rightarrow \text{Low-rank Compression} } \end{gathered}\]

으로 연결된다.

LLM FlowLLM에서는 Low-rank Matrix 관점이 \(\boxed{ \text{Weight Compression} }\) 및

\[\boxed{ \text{LoRA-style low-rank update} }\]

를 이해하는 데 사용될 수 있다. 하지만 두 기법 모두 “상위 Singular Vector만 사용한다”는 단순 설명으로 동일시하지 않는다.

정리

SVD는 임의의 실수 행렬을 \(A=U\Sigma V^T\)로 분해해 입력 방향 회전, singular-value scaling, 출력 방향 회전을 분리한다. 특이값은 rank와 에너지 크기를 드러내며, 이 분해가 저랭크 근사·PCA·pseudoinverse의 공통 기반이 된다.
