PS-15 — Pairwise Probability & Bradley-Terry Preference Model

쌍대 선호 확률에서 Bradley–Terry 모델과 DPO 목적함수까지 유도한다.

확률·통계 · PS-15업데이트 2026.09.27
  • #Pairwise Preference
  • #Bradley–Terry
  • #DPO

개념

Pairwise Preference Modeling이 필요한 이유분류 문제에서는 하나의 입력에 대해 class label을 예측한다.

회귀 문제에서는 하나의 입력에 대해 scalar target을 예측한다.

하지만 인간 선호도 데이터에서는 다음과 같은 형태가 자주 등장한다.

같은 prompt \(x\)에 대해 응답 \(y_1\)과 \(y_2\) 중 어느 쪽이 더 좋은가?

이때 관측되는 것은 absolute score가 아니라 pairwise preference다.

LLM Alignment에서의 기본 데이터 구조대표적인 preference datum은 \((x,y_w,y_l)\) 이다.

여기서:

  • \(x\): prompt
  • \(y_w\): preferred / winning response
  • \(y_l\): less-preferred / losing response

즉 관측되는 label은 \(y_w \succ y_l \mid x\) 이다.

핵심 문제관측 데이터는 상대적 비교인데, reward model은 각 응답에 scalar score \(r(x,y)\in\mathbb R\) 를 부여한다.

따라서 핵심 질문은 다음과 같다.

두 scalar reward가 주어졌을 때, 이를 어떻게 pairwise preference probability로 변환할 것인가?

Bradley–Terry model이 이 질문에 답한다.

표기·차원

Pairwise Preference Probability두 응답 \(y_1,y_2\) 가 있을 때 \(P( y_1\succ y_2 \mid x )\) 를 정의한다.

이는 prompt \(x\)가 주어졌을 때 평가자가 \(y_1\)을 \(y_2\)보다 선호할 조건부 확률이다.

Probability Range당연히 \(0 \le P( y_1\succ y_2 \mid x ) \le 1\) 이다.

No-tie Binary Comparison동점이 없고 두 선택지 중 정확히 하나만 선호된다고 가정하면 \(P( y_1\succ y_2 \mid x ) + P( y_2\succ y_1 \mid x ) = 1\) 이다.

Expectation NotationEmpirical dataset expectation notation으로는 \(\mathcal L_R(\theta) = - \mathbb E_{ (x,y_w,y_l)\sim\mathcal D } \left[ \log \sigma( r_\theta(x,y_w) - r_\theta(x,y_l) ) \right]\) 이다.

여기서 expectation은 population expectation이 아니라 dataset average를 의미하도록 notation convention을 명확히 해야 한다.

핵심 연산

“Anti-Symmetry” 용어 주의원자료는 위 확률 관계를 “상반 대칭성(Anti-Symmetry)”이라고 부른다.

하지만 order theory에서 antisymmetry는 보통 \(a\preceq b \text{ and } b\preceq a \Rightarrow a=b\) 같은 관계 성질을 뜻한다.

여기서는 \(P(a\succ b)+P(b\succ a)=1\) 이므로 binary complementarity, reciprocal symmetry, 또는 no-tie completeness라고 부르는 편이 더 명확하다.

Tie가 있으면Tie event를 허용하면 일반적으로 \(P(y_1\succ y_2) + P(y_2\succ y_1) < 1\) 일 수 있다.

남은 probability mass가 \(P(y_1\sim y_2)\) 에 할당될 수 있기 때문이다.

따라서 source의 합이 1이라는 식은 no-tie binary-comparison assumption 아래의 식이다.

Latent RewardBradley–Terry model은 각 응답에 latent scalar score를 둔다.

\(r_i = r(x,y_i)\) 라고 하자.

Positive StrengthBradley–Terry의 고전적 표현에서는 positive strength \(\lambda_i>0\) 를 사용한다.

LLM reward-model notation에서는 흔히 \(\lambda_i = e^{r_i}\) 로 parameterize할 수 있다.

Bradley–Terry Probability그럼 \(P( y_1\succ y_2 \mid x ) = \frac{ e^{r_1} }{ e^{r_1}+e^{r_2} }\) 이다.

Softmax 관점이 식은 두 class에 대한 Softmax와 동일하다.

즉 logits가 \([r_1,r_2]\) 일 때 첫 번째 선택지가 선택될 probability다.

Difference Form으로 변환분모와 분자에 \(e^{-r_1}\) 를 곱하면 \(P( y_1\succ y_2 \mid x ) = \frac{ 1 }{ 1+e^{r_2-r_1} }\) 이다.

Reward Difference\(\Delta = r_1-r_2\) 라고 정의하면 \(r_2-r_1 = -\Delta\) 이다.

SigmoidLogistic sigmoid를 \(\sigma(z) = \frac1{1+e^{-z}}\) 라고 하면 \(P( y_1\succ y_2 \mid x ) = \sigma( r_1-r_2 ) = \sigma(\Delta)\) 이다.

핵심 구조즉 Bradley–Terry model은 absolute reward가 아니라 \(r_1-r_2\) 라는 reward difference만 본다.

이 사실이 이후 reward-model identifiability와 DPO의 \(Z(x)\) cancellation에 매우 중요하다.

Reverse Preference반대 방향은 \(P( y_2\succ y_1 \mid x ) = \sigma( r_2-r_1 ) = \sigma(-\Delta)\) 이다.

Sigmoid Complementarity\(\sigma(-z) = 1-\sigma(z)\) 이므로 \(P( y_2\succ y_1 \mid x ) = 1- P( y_1\succ y_2 \mid x )\) 이다.

Equal Reward만약 \(r_1=r_2\) 이면 \(\Delta=0\) 이고 \(P( y_1\succ y_2 \mid x ) = \frac12\) 이다.

Large Positive Difference\(\Delta\to+\infty\) 이면 \(P(y_1\succ y_2\mid x) \to1\) 이다.

Large Negative Difference\(\Delta\to-\infty\) 이면 \(P(y_1\succ y_2\mid x) \to0\) 이다.

OddsBradley–Terry에서는 preference odds가 매우 간단하다.

\(\frac{ P(y_1\succ y_2\mid x) }{ P(y_2\succ y_1\mid x) } = e^{r_1-r_2}\) 이다.

Log-Odds따라서 \(\log \frac{ P(y_1\succ y_2\mid x) }{ P(y_2\succ y_1\mid x) } = r_1-r_2\) 이다.

즉 reward difference는 pairwise preference의 log-odds다.

Logistic Regression과 연결두 response feature의 차이를 어떤 function이 score한다고 보면 Bradley–Terry pairwise learning은 logistic regression 형태와 연결된다.

즉 pairwise label 1에 대한 logit이 \(\Delta = r(x,y_w)-r(x,y_l)\) 이다.

Binary Cross-Entropy ConnectionPreference label을 \(t=1\) 로 두고 predicted probability를 \(p=\sigma(\Delta)\) 라고 하면 loss는 \(-\log p\) 이다.

이는 binary cross-entropy에서 positive label에 해당한다.

General Binary Label만약 pair ordering을 고정하고 binary label \(t\in\{0,1\}\) 를 사용하면 \(\ell = -t\log\sigma(\Delta) - (1-t)\log(1-\sigma(\Delta))\) 이다.

Softplus FormPositive preference loss는 \(-\log\sigma(\Delta)\) 이고 이는 \(\log(1+e^{-\Delta})\) 와 같다.

즉 \(\ell(\Delta) = \operatorname{softplus}(-\Delta)\) 이다.

Numerical Stability실제 구현에서는 \(-\log\sigma(\Delta)\) 를 직접 계산하기보다 numerically stable softplus / log-sigmoid function을 사용하는 것이 좋다.

Gradient with respect to Difference

\[\ell(\Delta) = -\log\sigma(\Delta)\]

라 하자.

Sigmoid Derivative\(\sigma'(\Delta) = \sigma(\Delta) ( 1-\sigma(\Delta) )\) 이다.

Loss Derivative

\[\begin{aligned} \frac{\partial\ell}{\partial\Delta} &= -\frac{ \sigma'(\Delta) }{ \sigma(\Delta) }\\ &= - ( 1-\sigma(\Delta) )\\ &= \boxed{ \sigma(\Delta)-1 } \end{aligned}\]

Equivalent Form\(1-\sigma(\Delta) = \sigma(-\Delta)\) 이므로 \(\frac{\partial\ell}{\partial\Delta} = -\sigma(-\Delta)\) 이다.

원자료의 식과 동일하다.

Gradient Range\(0<\sigma(-\Delta)<1\) 이므로 finite \(\Delta\)에서 \(-1 < \frac{\partial\ell}{\partial\Delta} < 0\) 이다.

Wrong Ranking\(\Delta\to-\infty\) 이면 \(\frac{\partial\ell}{\partial\Delta} \to-1\) 이다.

따라서 gradient descent는 \(\Delta\)를 증가시키려는 강한 update를 만든다.

Correct High-Margin Ranking\(\Delta\to+\infty\) 이면 \(\frac{\partial\ell}{\partial\Delta} \to0\) 이다.

즉 이미 충분히 높은 margin을 가진 pair는 loss contribution이 작아진다.

Winner Reward Gradient\(\Delta = r_w-r_l\) 이므로 \(\frac{\partial\Delta}{\partial r_w} = 1\) 이다.

따라서 \(\frac{\partial\ell}{\partial r_w} = -\sigma(-\Delta)\) 이다.

Loser Reward Gradient\(\frac{\partial\Delta}{\partial r_l} = -1\) 이므로 \(\frac{\partial\ell}{\partial r_l} = +\sigma(-\Delta)\) 이다.

핵심 식 — Bradley–Terry\(P( y_1\succ y_2 \mid x ) = \frac{ e^{r_1} }{ e^{r_1}+e^{r_2} }\) 이다.

핵심 식 — Sigmoid Difference\(P( y_1\succ y_2 \mid x ) = \sigma( r_1-r_2 )\) 이다.

핵심 식 — Log-Odds\(\log \frac{ P(y_1\succ y_2\mid x) }{ P(y_2\succ y_1\mid x) } = r_1-r_2\) 이다.

핵심 식 — Reward Model Loss\(\mathcal L_R = - \mathbb E_{\mathcal D} [ \log \sigma( r_\theta(x,y_w) - r_\theta(x,y_l) ) ]\) 이다.

핵심 식 — Reward Difference Gradient\(\frac{ \partial\ell }{ \partial\Delta } = -\sigma(-\Delta)\) 이다.

핵심 식 — KL-Regularized Optimal Policy\(\pi^*(y\mid x) = \frac1{Z(x)} \pi_{\mathrm{ref}}(y\mid x) \exp \left( \frac{ r(x,y) }{\beta} \right)\) 이다.

핵심 식 — Implicit Reward\(r(x,y) = \beta \log \frac{ \pi^*(y\mid x) }{ \pi_{\mathrm{ref}}(y\mid x) } + \beta\log Z(x)\) 이다.

핵심 식 — DPO

\[\boxed{ \mathcal L_{\mathrm{DPO}} = - \mathbb E_{\mathcal D} \left[ \log \sigma \left( \beta \log \frac{ \pi_\theta(y_w\mid x) }{ \pi_{\mathrm{ref}}(y_w\mid x) } - \beta \log \frac{ \pi_\theta(y_l\mid x) }{ \pi_{\mathrm{ref}}(y_l\mid x) } \right) \right] }\]

성질·유도

Translation Invariance임의의 prompt-dependent scalar \(c(x)\) 를 모든 response reward에 더하자.

\(r'(x,y) = r(x,y)+c(x)\) 이다.

Difference는 변하지 않음

\[\begin{aligned} r'(x,y_1)-r'(x,y_2) &= r(x,y_1)+c(x) - r(x,y_2)-c(x)\\ &= \boxed{ r(x,y_1)-r(x,y_2) } \end{aligned}\]

Preference Probability Invariance따라서 \(P'( y_1\succ y_2 \mid x ) = P( y_1\succ y_2 \mid x )\) 이다.

Identifiability이 성질은 매우 중요하다.

Pairwise preference data만으로는 일반적으로 absolute reward level을 식별할 수 없다.

즉 \(r(x,y)\) 와 \(r(x,y)+c(x)\) 는 동일한 preference probabilities를 만든다.

식별되는 것은 Reward Difference따라서 pairwise Bradley–Terry likelihood가 직접 식별하는 핵심 quantity는 \(r(x,y_1)-r(x,y_2)\) 이다.

Absolute offset은 추가 convention 또는 regularization이 없으면 arbitrary하다.

Scale은 일반적으로 불변하지 않다Reward에 positive constant \(a\)를 곱하면 \(r'(x,y)=ar(x,y)\) 이고 \(\sigma( a\Delta )\) 가 된다.

일반적으로 \(\sigma(a\Delta) \neq \sigma(\Delta)\) 이다.

따라서 additive shift와 달리 scale은 preference confidence를 바꾼다.

Temperature Interpretation\(\sigma( \Delta/T )\) 처럼 temperature를 넣으면 reward scale과 temperature는 서로 trade-off할 수 있다.

따라서 latent reward의 scale interpretation은 model convention과 연결된다.

Random Utility InterpretationBradley–Terry는 latent random utility model로도 해석할 수 있다.

각 response utility를 \(U_i = r_i+\epsilon_i\) 라고 두고 적절한 noise distribution을 가정하면 \(P(U_1>U_2)\) 가 logistic difference form으로 이어진다.

중요한 점Bradley–Terry probability form은 단순한 임의 sigmoid가 아니라 latent utility difference를 logistic choice probability로 연결하는 모델로 이해할 수 있다.

Preference DatasetReward-model training dataset을 \(\mathcal D = \{ (x^{(i)},y_w^{(i)},y_l^{(i)}) \}_{i=1}^N\) 라고 하자.

각 datum은 \(y_w^{(i)} \succ y_l^{(i)} \mid x^{(i)}\) 라는 관측을 포함한다.

Reward ModelParameterized neural reward function을 \(r_\theta(x,y)\) 라고 한다.

보통 response 전체를 입력으로 받아 scalar 하나를 출력하는 model로 생각할 수 있다.

Pairwise Probability under the Model각 preference pair에 대해 \(P_\theta( y_w\succ y_l \mid x ) = \sigma \left( r_\theta(x,y_w) - r_\theta(x,y_l) \right)\) 이다.

Conditional Independence AssumptionDataset likelihood를 pairwise probability의 곱으로 쓰려면, 관측 pair들이 model parameter가 주어졌을 때 독립이라는 식의 factorization assumption이 필요하다.

즉 source의 product likelihood는 단순 algebra가 아니라 data-factorization assumption을 포함한다.

Likelihood그 가정 아래 \(\mathcal L(\theta) = \prod_{i=1}^N \sigma \left( r_\theta(x^{(i)},y_w^{(i)}) - r_\theta(x^{(i)},y_l^{(i)}) \right)\) 이다.

Log-Likelihood

\[\boxed{ \log\mathcal L(\theta) = \sum_{i=1}^N \log \sigma( \Delta_i ) }\]

where \(\Delta_i = r_\theta(x^{(i)},y_w^{(i)}) - r_\theta(x^{(i)},y_l^{(i)})\) 이다.

Negative Log-Likelihood\(\mathcal L_R(\theta) = - \frac1N \sum_{i=1}^N \log \sigma( \Delta_i )\) 처럼 mean NLL을 사용할 수 있다.

Gradient Descent DirectionGradient descent update \(r \leftarrow r-\eta \frac{\partial\ell}{\partial r}\) 를 생각하면 다음과 같다.

  • \(r_w\)는 증가하는 방향
  • \(r_l\)은 감소하는 방향

이 식으로 움직인다.

원자료의 직관은 이 의미에서 맞다.

그러나 두 Scalar를 독립 Parameter처럼 보면 안 된다실제 reward model에서는 \(r_w = r_\theta(x,y_w), \qquad r_l = r_\theta(x,y_l)\) 이고 둘 다 동일한 network parameter \(\theta\)의 함수다.

따라서 실제 parameter update는 \(\nabla_\theta r_w\) 와 \(\nabla_\theta r_l\) 를 통해 결합된다.

Parameter GradientChain rule로 \(\nabla_\theta\ell = -\sigma(-\Delta) \left[ \nabla_\theta r_w - \nabla_\theta r_l \right]\) 이다.

Convexity in ΔSecond derivative는 \(\frac{d^2\ell}{d\Delta^2} = \sigma(\Delta) \sigma(-\Delta) > 0\) 이다.

따라서 scalar difference \(\Delta\)에 대해서는 convex하다.

Neural Network Parameter에 대한 Convexity는 아님하지만 \(\Delta = r_\theta(x,y_w)-r_\theta(x,y_l)\) 가 deep network의 nonlinear function이므로 \(\ell(\theta)\) 가 \(\theta\)에 대해 convex하다는 뜻은 아니다.

Margin InterpretationBradley–Terry NLL은 winner-loser reward gap을 크게 만들도록 학습한다.

\(\Delta = r_w-r_l\) 가 클수록 pairwise loss는 작아진다.

Perfect Separation Problem만약 training pairs가 완전히 separable하고 explicit regularization이 없다면 logistic-type objective는 finite optimum보다 reward scale이 계속 커지는 방향을 선호할 수 있다.

따라서 reward scale calibration과 regularization이 실무에서 중요할 수 있다.

Preference Noise인간 선호는 deterministic하지 않을 수 있다.

같은 pair에서도 annotator마다 다른 선택을 할 수 있다.

Bradley–Terry의 probabilistic formulation은 이런 stochastic preference를 자연스럽게 표현한다.

Label Noise와 Reward Difference관측된 winner가 항상 latent “true best response”라는 가정을 할 필요는 없다.

Bradley–Terry likelihood는 pairwise label을 stochastic observation으로 모델링한다.

Annotator Heterogeneity평가자마다 preference function이 다르면 하나의 scalar reward model이 모든 평가자의 선호를 완전히 설명하지 못할 수 있다.

이는 model misspecification의 한 원인이다.

Pair Dependence같은 prompt에서 여러 response pair를 조합해 annotation했다면 pair observations가 통계적으로 독립하지 않을 수 있다.

따라서 product likelihood의 independence는 실용적 modeling assumption이지 항상 현실의 정확한 사실은 아니다.

RLHF Reward Model원자료는 Bradley–Terry loss를 InstructGPT-style reward modeling과 연결한다.

높은 수준의 pipeline은 Preference Data → Reward Model → Policy Optimization 이다.

Reward Model이 하는 일Reward model은 response quality의 absolute physical quantity를 측정하는 것이 아니라 preference labels를 설명하는 scalar score를 학습한다.

따라서 learned reward의 값 자체보다 response 간 상대적 차이가 더 직접적인 의미를 가진다.

Reward Hacking CaveatPolicy를 reward model에 대해 직접 최적화하면 reward model의 approximation error를 exploit할 수 있다.

따라서 reward-model score가 human utility와 완전히 동일하다고 가정하면 안 된다.

KL-Regularized RL Objective원자료는 다음 형태를 사용한다.

\(J(\pi) = \mathbb E_{ y\sim\pi(\cdot\mid x) } [ r(x,y) ] - \beta D_{\mathrm{KL}} \left( \pi(\cdot\mid x) \| \pi_{\mathrm{ref}}(\cdot\mid x) \right)\) 이다.

Prompt Averaging전체 dataset에서는 보통 prompt \(x\)에 대해서도 expectation을 취한다.

개별 \(x\)에 대한 derivation을 먼저 하고 나중에 \(x\)에 대해 평균내는 것이 algebraically 편하다.

KL Expansion\(D_{\mathrm{KL}}( \pi\|\pi_{\mathrm{ref}} ) = \mathbb E_{y\sim\pi} \left[ \log \frac{ \pi(y\mid x) }{ \pi_{\mathrm{ref}}(y\mid x) } \right]\) 이다.

Objective Expansion따라서 fixed \(x\)에서 \(J_x(\pi) = \mathbb E_{y\sim\pi} \left[ r(x,y) - \beta \log \frac{ \pi(y\mid x) }{ \pi_{\mathrm{ref}}(y\mid x) } \right]\) 이다.

Exponential-Tilt Distribution다음을 정의하자.

\(q_r(y\mid x) \propto \pi_{\mathrm{ref}}(y\mid x) \exp \left( \frac{ r(x,y) }{\beta} \right)\) 이다.

Partition Function정규화 상수를 \(Z(x) = \sum_y \pi_{\mathrm{ref}}(y\mid x) \exp \left( \frac{ r(x,y) }{\beta} \right)\) 라고 하자.

연속 action/output space라면 합 대신 integral이 필요할 수 있다.

Normalized Optimal-form Distribution\(q_r(y\mid x) = \frac1{Z(x)} \pi_{\mathrm{ref}}(y\mid x) \exp \left( \frac{ r(x,y) }{\beta} \right)\) 이다.

Objective를 KL로 재표현\(J_x(\pi) = -\beta D_{\mathrm{KL}} ( \pi(\cdot\mid x) \| q_r(\cdot\mid x) ) + \beta\log Z(x)\) 이다.

왜 최적정책이 나오는가KL divergence는 \(D_{\mathrm{KL}}(P\|Q)\ge0\) 이고 equality는 적절한 조건에서 \(P=Q\) 일 때다.

따라서 unrestricted policy class에서 \(\pi^*(y\mid x) = q_r(y\mid x)\) 이다.

Policy-class Caveat실제 neural policy class가 모든 distribution을 표현할 수 있다는 보장은 없다.

따라서 위 \(\pi^*=q_r\) 는 functional optimization의 idealized optimum이다.

실제 parameterized optimization에서는 approximate solution을 얻는다.

Support Condition만약 \(\pi_{\mathrm{ref}}(y\mid x)=0\) 인 곳에서는 KL 및 log-ratio에 support 문제가 생긴다.

DPO-style derivation은 reference와 policy의 relevant support 조건을 암묵적으로 필요로 한다.

Optimal Policy Formula\(\pi^*(y\mid x) = \frac1{Z(x)} \pi_{\mathrm{ref}}(y\mid x) \exp \left( \frac{ r(x,y) }{\beta} \right)\) 이다.

Logarithm양변의 log를 취하면 \(\log\pi^*(y\mid x) = \log\pi_{\mathrm{ref}}(y\mid x) + \frac{ r(x,y) }{\beta} - \log Z(x)\) 이다.

Reward를 풀기\(r(x,y) = \beta \log \frac{ \pi^*(y\mid x) }{ \pi_{\mathrm{ref}}(y\mid x) } + \beta\log Z(x)\) 이다.

Implicit Reward따라서 policy/reference log-ratio가 reward와 직접 연결된다.

\[\boxed{ r(x,y) = \beta \log \frac{ \pi^*(y\mid x) }{ \pi_{\mathrm{ref}}(y\mid x) } + c(x) }\]

where \(c(x)=\beta\log Z(x)\) 이다.

Bradley–Terry Translation Invariance와 연결Bradley–Terry는 같은 prompt에서 모든 response reward에 같은 \(c(x)\)를 더해도 변하지 않는다.

따라서 \(c(x)\) 가 pairwise difference에서 제거된다.

Winner-Loser Difference

\[\begin{aligned} r(x,y_w)-r(x,y_l) &= \beta \log \frac{ \pi^*(y_w\mid x) }{ \pi_{\mathrm{ref}}(y_w\mid x) }\\ &\quad- \beta \log \frac{ \pi^*(y_l\mid x) }{ \pi_{\mathrm{ref}}(y_l\mid x) } \end{aligned}\]

Z(x) Cancellation 조건정규화항이 상쇄되는 이유는 \(y_w\)와 \(y_l\)이 같은 prompt \(x\)에 대한 response들이기 때문이다.

둘의 prompt가 다르면 \(Z(x_w)\)와 \(Z(x_l)\)가 동일하다고 할 수 없다.

DPO ParameterizationDPO에서는 unknown optimal policy를 직접 \(\pi_\theta\) 로 parameterize하여 다음 log-ratio margin을 사용한다.

\(m_\theta = \beta \left[ \log \frac{ \pi_\theta(y_w\mid x) }{ \pi_{\mathrm{ref}}(y_w\mid x) } - \log \frac{ \pi_\theta(y_l\mid x) }{ \pi_{\mathrm{ref}}(y_l\mid x) } \right]\) 이다.

DPO LossBradley–Terry likelihood에 대입하면 \(\mathcal L_{\mathrm{DPO}}(\theta) = - \mathbb E_{\mathcal D} [ \log\sigma( m_\theta ) ]\) 이다.

Expanded DPO Loss즉 다음과 같다.

\[\boxed{ \mathcal L_{\mathrm{DPO}}(\theta) = - \mathbb E_{\mathcal D} \left[ \log\sigma \left( \beta \log \frac{ \pi_\theta(y_w\mid x) }{ \pi_{\mathrm{ref}}(y_w\mid x) } - \beta \log \frac{ \pi_\theta(y_l\mid x) }{ \pi_{\mathrm{ref}}(y_l\mid x) } \right) \right] }\]

원자료의 핵심 수식과 동일하다.

Sequence ProbabilityLanguage-model response \(y=(y_1,\dots,y_T)\) 의 probability는 autoregressive factorization으로 \(\pi_\theta(y\mid x) = \prod_{t=1}^{T} \pi_\theta( y_t \mid x,y_{<t} )\) 이다.

혼동하기 쉬운 부분

  • Anti-symmetry:\(P(a\succ b)+P(b\succ a)=1\) 은 no-tie binary model의 complementarity다.

    Order-theoretic antisymmetry와 구분한다.

  • Reward의 절대값:Pairwise data는 absolute reward level을 식별하지 않는다.

    같은 prompt에서 reward 전체에 constant를 더해도 prediction은 동일하다.

  • Reward Scale:Additive shift는 invariant지만 multiplicative scaling은 sigmoid confidence를 바꾼다.

  • Product Likelihood:Dataset likelihood를 pair probabilities의 곱으로 쓰는 것은 conditional independence/factorization assumption을 포함한다.

  • Gradient:Scalar \(\partial\ell/\partial\Delta\)가 -1에 가깝다는 것과 neural-network parameter gradient의 norm이 정확히 1이라는 것은 다르다.

    실제 gradient에는 \(\nabla_\theta r_w-\nabla_\theta r_l\) 가 곱해진다.

  • DPO의 Ratio:DPO의 ratio는 model weight ratio가 아니라 \(\pi_\theta(y\mid x) /\pi_{\mathrm{ref}}(y\mid x)\) 라는 sequence-probability ratio다.

  • Z(x) Cancellation:\(Z(x)\)가 사라지는 것은 winner와 loser가 같은 prompt \(x\)에 속하기 때문이다.

    Prompt가 다르면 같은 cancellation을 바로 적용할 수 없다.

  • DPO와 PPO:DPO는 pairwise offline objective라 explicit reward model/PPO rollout loop 없이 학습할 수 있다.

    하지만 모든 reinforcement-learning alignment 문제를 일반적으로 대체한다는 뜻은 아니다.

  • True Advantage:Group preference score나 pairwise reward difference를 classical RL advantage와 동일시하면 안 된다.

    각 quantity는 정의가 다르다.

  • Pairwise Model의 보편성:Bradley–Terry는 유용한 probabilistic model이지만 실제 인간 preference가 항상 scalar-transitive logistic model을 정확히 따른다는 보장은 없다.

    Bradley–Terry model은 두 response의 latent reward difference를 pairwise preference probability로 변환한다.

    \(P( y_1\succ y_2 \mid x ) = \sigma( r(x,y_1) - r(x,y_2) )\) 이다.

    중요한 것은 absolute reward가 아니라 difference다.

    따라서 prompt-dependent additive shift \(r'(x,y)=r(x,y)+c(x)\) 를 적용해도 preference probability는 변하지 않는다.

    이 때문에 pairwise preference data에서 reward의 absolute offset은 식별되지 않는다.

    Reward model training에서는 winner-loser pair에 대해 \(\mathcal L_R = - \mathbb E \left[ \log \sigma( r_w-r_l ) \right]\) 를 최소화한다.

    Scalar difference에 대한 gradient는 \(\frac{\partial\ell}{\partial\Delta} = -\sigma(-\Delta)\) 이다.

    따라서 ranking이 잘못된 pair에서는 강한 update가 발생하고, 이미 큰 positive margin을 가진 pair에서는 gradient가 작아진다.

    원자료의 numerical example \(r_w=2.5, \qquad r_l=1.0\) 에서는 \(\Delta=1.5\) 이고 \(P(y_w\succ y_l) \approx 0.817574\) 이다.

    Loss는 \(-\log0.817574 \approx 0.201413\) 이고 gradient는 \(-0.182426\) 이다.

    DPO의 출발점은 KL-regularized reward maximization이다.

    \(J(\pi) = \mathbb E_\pi[r] - \beta D_{\mathrm{KL}} ( \pi\|\pi_{\mathrm{ref}} )\) 를 functional optimization하면 idealized optimum은 \(\pi^*(y\mid x) = \frac1{Z(x)} \pi_{\mathrm{ref}}(y\mid x) e^{r(x,y)/\beta}\) 이다.

    이를 reward에 대해 풀면 \(r(x,y) = \beta \log \frac{ \pi^*(y\mid x) }{ \pi_{\mathrm{ref}}(y\mid x) } + \beta\log Z(x)\) 이다.

    Winner와 loser는 같은 prompt \(x\)에 대한 response들이므로 reward difference에서 \(\beta\log Z(x)\) 가 상쇄된다.

    따라서 pairwise Bradley–Terry likelihood에 policy/reference log-ratio를 직접 대입할 수 있다.

    최종 DPO objective는 다음과 같다.

    \[\boxed{ \mathcal L_{\mathrm{DPO}} = - \mathbb E_{\mathcal D} \left[ \log \sigma \left( \beta \log \frac{ \pi_\theta(y_w\mid x) }{ \pi_{\mathrm{ref}}(y_w\mid x) } - \beta \log \frac{ \pi_\theta(y_l\mid x) }{ \pi_{\mathrm{ref}}(y_l\mid x) } \right) \right] }\]

    여기서 ratio는 neural-network parameter ratio가 아니라 sequence probability ratio다.

    또한 \(\log\pi_\theta(y\mid x) = \sum_t \log \pi_\theta( y_t\mid x,y_{<t} )\) 이므로 실제 language model에서는 token log-probability sum으로 계산한다.

    DPO는 explicit reward model과 PPO-style online rollout loop 없이 pairwise preference data로 직접 policy를 학습할 수 있다는 장점이 있다.

    하지만 이는 Bradley–Terry preference model, fixed preference dataset, reference-policy log-ratio 등의 가정 위에 세워진 objective다.

    따라서 DPO ≠ all RLHF / all alignment problems의 보편적 대체물 이다.

    PS-15의 전체 핵심 흐름은 Pairwise Preference → Bradley–Terry → Reward Difference → Logistic NLL 에서 시작하고, LLM alignment에서는 Preference Data → Reward Model → RLHF 또는 KL-Regularized RL → Implicit Reward → DPO 로 연결된다.

예제·적용

Sequence Log-Probability따라서 \(\log\pi_\theta(y\mid x) = \sum_{t=1}^{T} \log \pi_\theta( y_t \mid x,y_{<t} )\) 이다.

DPO의 Log-Ratio는 Token Weight Ratio가 아님원자료는 “언어 모델의 가중치 비율(policy ratio)”이라고 표현한다.

여기서 ratio는 neural network weight ratio가 아니라 sequence probability ratio다.

즉 \(\frac{ \pi_\theta(y\mid x) }{ \pi_{\mathrm{ref}}(y\mid x) }\) 이다.

Token-wise Decomposition이 log-ratio는 \(\log \frac{ \pi_\theta(y\mid x) }{ \pi_{\mathrm{ref}}(y\mid x) } = \sum_t \log \frac{ \pi_\theta(y_t\mid x,y_{<t}) }{ \pi_{\mathrm{ref}}(y_t\mid x,y_{<t}) }\) 로 분해된다.

Sequence Length의 영향Raw sequence log-probability는 token log-probabilities의 합이므로 response length의 영향을 받는다.

DPO formulation과 dataset construction에서 length-related behavior가 나타날 수 있으며, 이를 단순 token-average loss와 동일시하면 안 된다.

DPO에서 β의 역할Source derivation에서 \(\beta\)는 KL regularization coefficient와 연결된다.

DPO loss 내부에서는 log-ratio difference의 scale을 조절한다.

β를 단순 Temperature로만 보면 안 된다수학적으로 sigmoid argument의 scale에 영향을 주므로 temperature-like 역할을 보일 수 있지만, derivation상 의미는 KL-regularized policy optimization의 coefficient와 연결되어 있다.

DPO Gradient w.r.t. Margin\(\ell_{\mathrm{DPO}} = -\log\sigma(m_\theta)\) 이므로 \(\frac{ \partial\ell_{\mathrm{DPO}} }{ \partial m } = -\sigma(-m)\) 이다.

Preferred Response 방향Gradient descent는 \(\log\pi_\theta(y_w\mid x) - \log\pi_{\mathrm{ref}}(y_w\mid x)\) 를 상대적으로 더 크게 만드는 방향을 선호한다.

Rejected Response 방향동시에 \(\log\pi_\theta(y_l\mid x) - \log\pi_{\mathrm{ref}}(y_l\mid x)\) 를 상대적으로 더 작게 만드는 방향을 선호한다.

Reference Model의 역할Reference model은 policy drift를 상대적으로 측정하는 기준을 제공한다.

DPO는 단순히 winner probability를 높이는 supervised objective와 다르게 reference-relative preference margin을 최적화한다.

DPO와 SFT의 차이SFT는 보통 preferred response 자체의 likelihood를 높인다.

DPO는 winner와 loser의 relative log-ratio margin을 직접 사용한다.

DPO와 Reward Modeling의 차이Explicit reward modeling에서는 \(r_\phi(x,y)\) 를 별도의 model로 학습한다.

DPO에서는 reward-equivalent quantity를 policy/reference log-ratio로 parameterize한다.

DPO와 PPO의 차이DPO objective 자체는 pairwise preference dataset에서 직접 gradient를 계산할 수 있어 on-policy RL rollout loop를 요구하지 않는 형태다.

그러나 “RLHF를 완전히 대체”는 과도함DPO가 explicit reward model과 PPO loop를 사용하지 않는다는 것은 맞다.

하지만 모든 alignment 목표, online exploration, long-horizon interaction, tool-use RL 등을 DPO가 일반적으로 대체한다는 뜻은 아니다.

Offline Preference OptimizationDPO는 기본적으로 fixed preference dataset을 사용하는 offline preference optimization 형태로 이해하는 것이 자연스럽다.

Distribution ShiftPreference dataset distribution과 현재 policy distribution이 크게 달라지면 training behavior가 달라질 수 있다.

이는 offline preference optimization의 중요한 caveat다.

Pairwise Model MisspecificationDPO derivation은 Bradley–Terry/logistic preference model을 사용한다.

실제 인간 preference가 이 sigmoid reward-difference form과 정확히 일치한다는 보장은 없다.

Cyclic Preference사람의 preference가 \(A\succ B,\quad B\succ C,\quad C\succ A\) 처럼 cyclic할 수 있다.

하나의 scalar reward function은 이런 모든 비이행적 preference를 완벽하게 표현하기 어렵다.

Transitivity의 함의Bradley–Terry의 scalar latent utility는 preference probabilities에 구조를 부여한다.

이것은 data를 압축하고 일반화하는 장점이 있지만 실제 선호의 복잡성을 제한하는 model assumption이기도 하다.

Numerical Example원자료는 다음과 같다.

\[r_w=2.50\]

\(r_l=1.00\) 을 사용한다.

Reward Difference\(\Delta = 2.50-1.00 = 1.50\) 이다.

Preference Probability\(P(y_w\succ y_l\mid x) = \sigma(1.5) = \frac1{1+e^{-1.5}}\) 이다.

Exponential Value\(e^{-1.5} \approx 0.223130\) 이다.

Exact Probability따라서 \(P(y_w\succ y_l\mid x) \approx 0.817574\) 이다.

즉 약 \(81.76\%\) 이다.

Reward-Model Loss\(\ell = -\log 0.817574 \approx 0.201413\) 이다.

Gradient\(\frac{\partial\ell}{\partial\Delta} = -\sigma(-1.5) \approx -0.182426\) 이다.

원자료의 numerical result와 일치한다.

Winner Gradient\(\frac{\partial\ell}{\partial r_w} \approx -0.182426\) 이다.

Loser Gradient\(\frac{\partial\ell}{\partial r_l} \approx +0.182426\) 이다.

One-step IntuitionGradient descent를 하면 winner score는 올라가고 loser score는 내려가도록 pressure가 생긴다.

다만 실제 neural reward model에서는 두 score가 공유 parameter를 통해 함께 변한다.

Reward Difference 0만약 \(r_w=r_l\) 이면 \(p=0.5\) 이고 \(\ell = -\log0.5 = \log2 \approx 0.693147\) 이다.

Difference가 충분히 크면\(\Delta\to+\infty\) 에서 \(\ell(\Delta)\to0\) 이다.

Difference가 매우 잘못되면\(\Delta\to-\infty\) 에서 \(\ell(\Delta) \sim -\Delta\) 처럼 거의 linear하게 커진다.

Hessian in Difference\(\ell''(\Delta) = \sigma(\Delta) ( 1-\sigma(\Delta) )\) 이다.

최대값은 \(\Delta=0\) 에서 \(1/4\) 이다.

Gradient SaturationCorrect high-margin pair에서는 gradient가 0에 가까워진다.

이것은 sigmoid/logistic loss의 saturation 특성이다.

Reward CalibrationPairwise accuracy가 높다고 해서 reward difference가 실제 human preference probability와 calibrated되어 있다는 보장은 없다.

Calibration은 별도 평가 문제다.

Pairwise Accuracy가장 단순한 metric은 \(\mathbf1[ r_w>r_l ]\) 의 평균이다.

NLL과 Accuracy의 차이Accuracy는 ranking correctness만 본다.

NLL은 prediction confidence까지 반영한다.

따라서 같은 accuracy라도 loss는 다를 수 있다.

Plackett–LuceBradley–Terry를 ranking으로 확장한 대표적 model이 Plackett–Luce다.

Sequential Choice InterpretationRanking \(y_1\succ y_2\succ\cdots\succ y_K\) 에 대해 \(P( y_1\succ\cdots\succ y_K ) = \prod_{k=1}^{K} \frac{ e^{r(y_k)} }{ \sum_{j=k}^{K} e^{r(y_j)} }\) 형태를 사용한다.

마지막 항\(k=K\)에서는 분자와 분모가 같아 1이므로 실제 정보는 앞의 단계들에서 생긴다.

Pairwise와 ListwiseBradley–Terry: pairwise comparison

Plackett–Luce: listwise ranking 이다.

KTO / IPO 연결의 범위원자료는 KTO와 IPO를 Bradley–Terry의 한계에 대한 변형으로 언급한다.

구체적 objective와 motivation은 각 방법마다 다르므로 “Bradley–Terry sigmoid 대칭성을 단순히 고친 모델”이라고만 요약하면 과도한 단순화가 될 수 있다.

본 PS-15에서는 pairwise logistic preference modeling과 DPO derivation에 초점을 둔다.

Preference Relation과 Reward OrderingBradley–Terry에서는 \(r_1>r_2\) 이면 \(P(y_1\succ y_2)>0.5\) 이다.

Reward Difference와 Confidence\(|r_1-r_2|\) 가 커질수록 pairwise probability가 0 또는 1에 가까워진다.

즉 reward gap은 model confidence와 연결된다.

Additive Constant가 무의미한 이유Pairwise preference는 difference만 보므로 \(r\mapsto r+c\) 는 관측 가능 quantity를 바꾸지 않는다.

이것은 statistical identifiability issue다.

Gauge Freedom 관점수학적으로는 reward function에 prompt-dependent additive gauge freedom이 있다고 볼 수 있다.

DPO derivation의 \(\beta\log Z(x)\) 도 바로 이런 additive term이다.

DPO에서 Cancellation의 핵심Winner와 loser가 동일한 prompt에 대해 비교되므로 \(\beta\log Z(x) - \beta\log Z(x) = 0\) 이 된다.

이것이 DPO Reduction의 핵심즉 DPO는 단순히 reward를 “없애는 trick”이 아니라:

  1. KL-regularized optimal policy와 reward의 관계를 구하고
  2. reward를 policy/reference log-ratio로 바꾸고
  3. pairwise difference에서 prompt-only normalization을 제거하고
  4. Bradley–Terry likelihood로 직접 학습

하는 구조다.

DPO의 핵심 Margin다음을 정의하자.

\(\Delta_{\log\pi} = \log \frac{ \pi_\theta(y_w\mid x) }{ \pi_{\mathrm{ref}}(y_w\mid x) } - \log \frac{ \pi_\theta(y_l\mid x) }{ \pi_{\mathrm{ref}}(y_l\mid x) }\) 이다.

DPO Loss의 간결한 형태\(\mathcal L_{\mathrm{DPO}} = - \mathbb E_{\mathcal D} [ \log \sigma( \beta \Delta_{\log\pi} ) ]\) 이다.

Positive Margin\(\Delta_{\log\pi}>0\) 이면 policy가 reference 대비 winner를 loser보다 상대적으로 더 선호한다는 뜻이다.

Negative Margin\(\Delta_{\log\pi}<0\) 이면 reference와 비교했을 때 현재 policy가 desired preference 방향과 반대로 이동한 것이다.

Reference-relative라는 점DPO는 \(\log\pi_\theta(y_w)-\log\pi_\theta(y_l)\) 만 보는 것이 아니다.

각 response에 대해 reference log-probability를 빼므로 relative to reference 라는 구조가 핵심이다.

왜 Reference를 쓰는가KL-regularized RL derivation에서 reference policy가 policy drift penalty의 기준이기 때문이다.

Reference Probability가 너무 작을 때Sequence log-ratio가 매우 커질 수 있으므로 support와 numerical stability가 중요하다.

실제 implementation은 log-probability domain에서 계산한다.

Sequence Probability Underflow긴 sequence의 raw probability \(\prod_t p_t\) 는 매우 작을 수 있다.

따라서 실제 계산에서는 \(\sum_t\log p_t\) 형태의 log-probability를 사용한다.

Padding MaskBatch에서 response length가 다르면 padding token을 sequence log-probability 합에 포함하지 않도록 mask가 필요하다.

Prompt Tokens vs Response TokensDPO의 response likelihood를 계산할 때 어떤 token 구간을 loss 대상으로 포함하는지는 implementation definition에 따라 명확히 해야 한다.

일반적으로 preference response의 conditional likelihood를 비교한다.

Pairwise Data Construction하나의 prompt에서 \(K\)개 responses를 ranking했다면 여러 pair를 만들 수 있다.

하지만 pair들이 같은 underlying ranking에서 파생되었기 때문에 statistical dependence가 생길 수 있다.

모든 Pair를 독립으로 세는 문제\(K\)개 ranking에서 \(\binom K2\) pairs를 모두 독립 sample처럼 취급하면 effective sample size를 과대평가할 수 있다.

Likelihood modeling과 annotation design을 구분해야 한다.

Tie-aware Extensions실제 human preference dataset에서는 tie 또는 “both bad” 같은 label이 있을 수 있다.

Bradley–Terry binary likelihood를 그대로 쓰려면 tie를 제거하거나 별도 처리해야 한다.

Davidson-type ExtensionPairwise comparison models에는 tie probability를 명시적으로 모델링하는 확장도 존재한다.

PS-15의 source는 no-tie Bradley–Terry에 초점을 둔다.

Scalar Reward의 한계한 scalar reward가:

  • helpfulness
  • safety
  • style
  • factuality
  • verbosity

같은 여러 preference dimension을 하나로 압축한다.

이 과정에서 trade-off 정보가 손실될 수 있다.

Multi-objective PreferencePreference가 context에 따라 여러 objective 사이에서 달라질 경우 하나의 stationary scalar reward model로 완벽하게 설명하기 어려울 수 있다.

Reward Model은 Ground Truth가 아니다Reward model은 preference annotation을 근사하는 learned predictor다.

따라서 \(r_\theta(x,y)\) 를 “진짜 인간 가치”와 동일시하면 안 된다.

DPO도 Preference Dataset 품질에 의존DPO는 explicit reward model을 제거하지만 preference labels의 noise, bias, coverage 문제를 제거하지는 않는다.

Preference Learning의 전체 흐름Pairwise labels → Bradley–Terry probability → logistic NLL 이다.

RLHF Reward Model Flow\((x,y_w,y_l) \rightarrow r_\theta(x,y_w),r_\theta(x,y_l) \rightarrow \sigma(r_w-r_l)\) 이다.

정리

Bradley–Terry 모델은 두 항목의 선호 확률을 reward 차이의 sigmoid \(P(i\succ j)=\sigma(r_i-r_j)\)로 표현한다. 공통 상수만큼 reward를 이동해도 확률이 같고, DPO는 reference policy와 preference pair의 log-probability 차이를 사용해 보상 차이를 직접 최적화한다.
