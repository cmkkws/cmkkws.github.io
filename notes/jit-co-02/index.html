CO-02 — Derivative, Partial Derivative & Gradient

Derivative, Partial Derivative, Gradient의 정의와 다변수 함수의 변화율을 정리한다.

미적분·최적화 · CO-02업데이트 2026.09.18
  • #Derivative
  • #Partial Derivative
  • #Gradient
  • #Directional Derivative

개념

Derivative일변량 실함수

\[f:\mathbb R\rightarrow\mathbb R\]

를 생각한다.

점 \(x\)에서의 미분계수(Derivative)는 입력값을 아주 조금 변화시켰을 때 함수값이 얼마나 빠르게 변하는지를 나타낸다.

정의는

\[\boxed{ f'(x) = \frac{df}{dx} = \lim_{h\rightarrow0} \frac{ f(x+h)-f(x) }{h} }\]

Geometric Interpretation of Derivative곡선

\[y=f(x)\]

위의 두 점 \((x,f(x))\) 와 \((x+h,f(x+h))\) 를 연결하면 Secant Line을 얻는다.

그 기울기는

\[\frac{ f(x+h)-f(x) }{h}\]

\(h\rightarrow0\)이면 두 점이 하나의 점으로 가까워지고 Secant Line은 Tangent Line으로 수렴한다.

따라서

\[\boxed{ f'(x) = \text{Tangent Slope at }x }\]

Local Linear Approximation미분 가능한 함수에서는 작은 변화량 \(\Delta x\)에 대해 \(f(x+\Delta x)\) 를 다음처럼 근사할 수 있다.

\[\boxed{ f(x+\Delta x) \approx f(x) + f'(x)\Delta x }\]

따라서

\[\boxed{ \Delta f \approx f'(x)\Delta x }\]

미분은 함수의 Local Linear Behavior를 나타낸다.

Multivariable FunctionDeep Learning에서는 대부분 함수가 하나의 Scalar Input만 가지지 않는다.

예를 들어

\[f: \mathbb R^D \rightarrow \mathbb R\]

인 함수를 생각한다.

입력은

\[\boxed{ \mathbf x = \begin{bmatrix} x_1\\ x_2\\ \vdots\\ x_D \end{bmatrix} }\]

이고 출력은 Scalar다.

이 경우 각 입력 변수에 대해 별도의 변화율을 계산해야 한다.

표기·차원

Gradient VectorScalar Function

\[f:\mathbb R^D\rightarrow\mathbb R\]

의 모든 1차 Partial Derivative를 모은 Column Vector를 Gradient라고 한다.

\[\boxed{ \nabla f(\mathbf x) = \begin{bmatrix} \dfrac{\partial f}{\partial x_1}\\ \dfrac{\partial f}{\partial x_2}\\ \vdots\\ \dfrac{\partial f}{\partial x_D} \end{bmatrix} \in \mathbb R^D }\]

Gradient의 Shape입력이 \(\mathbf x\in\mathbb R^D\) 이고 출력이 Scalar라면 Gradient도 \(D\)개의 성분을 가진다.

\[\boxed{ \nabla f(\mathbf x) \in \mathbb R^D }\]

각 Component는

\[\boxed{ [\nabla f(\mathbf x)]_i = \frac{\partial f}{\partial x_i} }\]

핵심 연산

Difference Quotient미분 정의에서

\[\frac{ f(x+h)-f(x) }{h}\]

는 두 점 사이의 평균 변화율이다.

입력 변화량은

\[\Delta x=h\]

이고 출력 변화량은

\[\Delta f = f(x+h)-f(x)\]

따라서

\[\boxed{ \frac{\Delta f}{\Delta x} = \frac{ f(x+h)-f(x) }{h} }\]

\(h\rightarrow0\)으로 보내면 순간 변화율을 얻는다.

Partial Derivative다변수 함수에서 한 변수만 변화시키고 나머지 변수는 모두 상수로 고정하여 계산하는 미분을 Partial Derivative라고 한다.

\(x_i\)에 대한 편미분은

\[\boxed{ \frac{\partial f(\mathbf x)} {\partial x_i} = \lim_{h\rightarrow0} \frac{ f( x_1,\dots,x_i+h,\dots,x_D ) - f( x_1,\dots,x_i,\dots,x_D ) }{h} }\]

Partial Derivative의 의미함수가 \(f(x_1,x_2)\) 라고 하자.

\(x_1\)에 대한 편미분에서는 \(x_2\) 를 상수로 취급한다.

\[\boxed{ \frac{\partial f}{\partial x_1} }\]

반대로 \(x_2\)에 대한 편미분에서는 \(x_1\) 을 상수로 취급한다.

\[\boxed{ \frac{\partial f}{\partial x_2} }\]

즉 각 좌표축 방향에서의 순간 변화율을 따로 측정한다.

Derivative와 Partial Derivative 비교일변수 함수에서는

\[f:\mathbb R\rightarrow\mathbb R\]

이므로 한 방향의 변화율만 존재한다.

\[\boxed{ \frac{df}{dx} }\]

다변수 함수에서는 여러 입력 방향이 존재하므로 각 변수별 변화율을 계산한다.

\[\boxed{ \frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_D} }\]

이 편미분들을 하나의 Vector로 모으면 Gradient가 된다.

Gradient의 Local Linearization다변수 함수에서 작은 변화 \(\Delta\mathbf x\) 를 가한다고 하자.

1차 Taylor Approximation은

\[\boxed{ f( \mathbf x+\Delta\mathbf x ) \approx f(\mathbf x) + \nabla f(\mathbf x)^T \Delta\mathbf x }\]

따라서 함수값 변화량은

\[\boxed{ \Delta f \approx \nabla f(\mathbf x)^T \Delta\mathbf x }\]

Gradient와 Dot Product다변수 공간에서 함수값 변화량은 Gradient와 이동 방향의 Inner Product로 결정된다.

\[\Delta f \approx \nabla f^T \Delta\mathbf x\]

Inner Product는

\[\nabla f^T \Delta\mathbf x = \|\nabla f\|_2 \| \Delta\mathbf x \|_2 \cos\theta\]

따라서 변화량은

  • Gradient의 크기
  • 이동 거리
  • 두 Vector 사이의 각도

에 의해 결정된다.

Directional Derivative좌표축 방향이 아니라 임의의 방향 \(\mathbf v\) 으로 이동할 때의 순간 변화율을 Directional Derivative라고 한다.

일반적으로 방향을 비교할 때 Unit Vector

\[\boxed{ \|\mathbf v\|_2=1 }\]

를 사용한다.

정의는

\[\boxed{ D_{\mathbf v}f(\mathbf x) = \lim_{h\rightarrow0} \frac{ f( \mathbf x+h\mathbf v ) - f(\mathbf x) }{h} }\]

Directional Derivative 유도작은 \(h\)에 대해 \(f( \mathbf x+h\mathbf v )\) 를 \(\mathbf x\) 주변에서 1차 Taylor Expansion한다.

\[f( \mathbf x+h\mathbf v ) = f(\mathbf x) + \nabla f(\mathbf x)^T (h\mathbf v) + \mathcal O(h^2)\]

따라서

\[\boxed{ f( \mathbf x+h\mathbf v ) = f(\mathbf x) + h \nabla f(\mathbf x)^T \mathbf v + \mathcal O(h^2) }\]

Directional Derivative 극한Directional Derivative 정의에 대입한다.

\[\begin{aligned} D_{\mathbf v}f(\mathbf x) &= \lim_{h\rightarrow0} \frac{ f(\mathbf x+h\mathbf v) - f(\mathbf x) }{h}\\ &= \lim_{h\rightarrow0} \left[ \nabla f(\mathbf x)^T \mathbf v + \mathcal O(h) \right] \end{aligned}\]

\(h\rightarrow0\)이면 Higher-Order Term이 사라진다.

따라서

\[\boxed{ D_{\mathbf v}f(\mathbf x) = \nabla f(\mathbf x)^T \mathbf v }\]

Directional Derivative와 Inner Product최종적으로

\[\boxed{ D_{\mathbf v}f(\mathbf x) = \langle \nabla f(\mathbf x), \mathbf v \rangle }\]

즉 임의의 방향으로의 순간 변화율은 Gradient와 해당 Direction Vector의 Dot Product다.

Directional Derivative의 기하학적 형태Gradient와 Unit Vector \(\mathbf v\)의 각도를 \(\theta\)라고 하자.

그러면

\[\begin{aligned} D_{\mathbf v}f &= \nabla f^T\mathbf v\\ &= \|\nabla f\|_2 \|\mathbf v\|_2 \cos\theta \end{aligned}\]

\(\|\mathbf v\|_2=1\)이므로

\[\boxed{ D_{\mathbf v}f = \|\nabla f\|_2 \cos\theta }\]

Steepest Ascent\(\cos\theta\)의 최댓값은 \(1\) 이는

\[\theta=0\]

즉 \(\mathbf v\)와 Gradient가 같은 방향일 때 발생한다.

따라서 Unit Steepest-Ascent Direction은

\[\boxed{ \mathbf v_{\mathrm{ascent}} = \frac{ \nabla f(\mathbf x) }{ \|\nabla f(\mathbf x)\|_2 } }\]

Maximum Directional DerivativeSteepest-Ascent Direction을 Directional Derivative에 대입하면

\[D_{\mathbf v}f = \|\nabla f\|_2\]

따라서

\[\boxed{ \max_{\|\mathbf v\|_2=1} D_{\mathbf v}f(\mathbf x) = \|\nabla f(\mathbf x)\|_2 }\]

즉 Gradient Norm은 가장 가파른 방향의 최대 순간 변화율이다.

Steepest Descent\(\cos\theta\)의 최솟값은 \(-1\) 이는

\[\theta=\pi\]

즉 Gradient와 정확히 반대 방향일 때 발생한다.

따라서 Unit Steepest-Descent Direction은

\[\boxed{ \mathbf v_{\mathrm{descent}} = - \frac{ \nabla f(\mathbf x) }{ \|\nabla f(\mathbf x)\|_2 } }\]

성질·유도

Minimum Directional Derivative이 방향에서

\[D_{\mathbf v}f = -\|\nabla f\|_2\]

따라서

\[\boxed{ \min_{\|\mathbf v\|_2=1} D_{\mathbf v}f(\mathbf x) = -\|\nabla f(\mathbf x)\|_2 }\]

즉 Negative Gradient Direction이 순간적으로 함수를 가장 빠르게 감소시킨다.

Cauchy–Schwarz 관점Directional Derivative는 \(\nabla f^T\mathbf v\) Cauchy–Schwarz Inequality에 의해

\[\left| \nabla f^T\mathbf v \right| \le \|\nabla f\|_2 \|\mathbf v\|_2\]

Unit Direction에서는

\[\boxed{ \left| D_{\mathbf v}f \right| \le \|\nabla f\|_2 }\]

등호는 두 Vector가 같은 방향 또는 정반대 방향일 때 성립한다.

Steepest Direction의 Norm 의존성Gradient와 Negative Gradient가 Steepest Direction이라는 결과는 이동 방향의 크기를 Euclidean Norm으로 제한한 경우다.

\[\boxed{ \|\mathbf v\|_2=1 }\]

다른 Norm을 사용해 Step Size를 정의하면 Steepest Direction의 형태도 달라질 수 있다.

이 Lecture에서는 기본적인 \(L_2\) Geometry를 사용한다.

Level Set함수값이 일정한 점들의 집합을 Level Set이라고 한다.

\[\boxed{ S_c = \{ \mathbf x\in\mathbb R^D : f(\mathbf x)=c \} }\]

2차원에서는 Level Curve 또는 Contour라고 부를 수 있다.

3차원 이상에서는 Level Surface라고 할 수 있다.

Level Set 위의 CurveLevel Set 위에서 움직이는 Smooth Curve를 \(\mathbf x(t)\) 라고 하자.

그리고

\[\mathbf x(0) = \mathbf x_0\]

라고 한다.

Curve 전체가 동일한 Level Set에 존재하므로

\[\boxed{ f( \mathbf x(t) ) = c }\]

Level Set의 Chain Rule양변을 \(t\)에 대해 미분한다.

\[\frac d{dt} f( \mathbf x(t) ) = 0\]

Chain Rule을 적용하면

\[\boxed{ \nabla f( \mathbf x(t) )^T \mathbf x'(t) = 0 }\]

Gradient는 Level Set에 수직\(t=0\)에서 \(\mathbf x'(0)\) 은 Level Surface의 Tangent Vector다.

그리고

\[\nabla f( \mathbf x_0 )^T \mathbf x'(0) = 0\]

Inner Product가 0이므로 두 Vector는 서로 직교한다.

\[\boxed{ \nabla f( \mathbf x_0 ) \perp \mathbf x'(0) }\]

Gradient as Normal VectorLevel Surface의 모든 Tangent Direction과 Gradient가 직교하므로 Gradient는 Level Surface의 Normal Direction이다.

\[\boxed{ \nabla f = \text{Normal Vector to the Level Set} }\]

따라서 Gradient는 같은 함수값을 유지하며 이동하는 방향이 아니라 Level Set을 가로질러 함수값을 가장 빠르게 변화시키는 방향을 가리킨다.

Contour Geometry2차원 함수 \(f(x_1,x_2)\) 를 생각하면 Contour Line은

\[f(x_1,x_2)=c\]

Gradient는 Contour에 수직이다.

\[\boxed{ \nabla f \perp \text{Contour} }\]

Negative Gradient 방향은 Contour를 가로질러 더 작은 함수값의 Level Set으로 이동하는 방향이다.

Gradient가 Zero인 경우만약

\[\nabla f(\mathbf x)=0\]

이라면

\[D_{\mathbf v}f(\mathbf x) = \nabla f(\mathbf x)^T\mathbf v = 0\]

따라서 모든 방향에서 1차 변화율이 0이다.

\[\boxed{ \nabla f=0 \Rightarrow D_{\mathbf v}f=0 \quad \forall\mathbf v }\]

이는 CO-01의 Stationary Point와 직접 연결된다.

Gradient와 Stationary PointCO-01에서 Stationary Point를

\[\boxed{ \nabla f( \mathbf x^\ast ) = 0 }\]

로 정의했다.

즉 Gradient는

  1. 함수가 증가하는 방향을 알려주고
  2. Negative Gradient는 감소 방향을 알려주며
  3. Gradient가 0이 되는 지점은 Stationary Point Candidate가 된다.

주요 식 정리

Derivative

\[\boxed{ f'(x) = \lim_{h\rightarrow0} \frac{ f(x+h)-f(x) }{h} }\]

Partial Derivative

\[\boxed{ \frac{\partial f} {\partial x_i} }\]

Gradient

\[\boxed{ \nabla f = \begin{bmatrix} \partial f/\partial x_1\\ \vdots\\ \partial f/\partial x_D \end{bmatrix} }\]

Directional Derivative

\[\boxed{ D_{\mathbf v}f = \nabla f^T\mathbf v }\]

Steepest Ascent

\[\boxed{ \mathbf v_{\mathrm{ascent}} = \frac{\nabla f}{\|\nabla f\|_2} }\]

Steepest Descent

\[\boxed{ \mathbf v_{\mathrm{descent}} = - \frac{\nabla f}{\|\nabla f\|_2} }\]

Level Set 핵심 관계Level Set은

\[\boxed{ f(\mathbf x)=c }\]

Level Set을 따라 움직이는 Tangent Vector \(\mathbf t\)에 대해서는

\[\boxed{ \nabla f^T\mathbf t=0 }\]

따라서

\[\boxed{ \nabla f \perp \text{Level Set} }\]

Gradient Descent 핵심 관계Parameter Update는

\[\boxed{ \mathbf{\theta}_{t+1} = \mathbf{\theta}_t - \eta \nabla L( \mathbf{\theta}_t ) }\]

1차 근사에서는

\[\boxed{ L( \mathbf{\theta}-\eta\nabla L ) - L( \mathbf{\theta} ) \approx - \eta \| \nabla L \|_2^2 }\]

따라서 충분히 작은 Step에서 Negative Gradient가 Local Descent Direction이 된다.

혼동하기 쉬운 부분 — Gradient vs DerivativeDerivative는 주로 Scalar-to-Scalar Function의 변화율을 의미한다.

\[f:\mathbb R\rightarrow\mathbb R\]

에서는 \(\boxed{ f'(x) }\) 를 사용한다.

Scalar-Valued Multivariable Function

\[f:\mathbb R^D\rightarrow\mathbb R\]

에서는 각 Partial Derivative를 모아 \(\boxed{ \nabla f }\) 를 사용한다.

혼동하기 쉬운 부분 — Partial Derivative vs Directional DerivativePartial Derivative

\[\frac{\partial f}{\partial x_i}\]

는 Coordinate Axis \(\mathbf e_i\) 방향의 Directional Derivative로 볼 수 있다.

실제로

\[\boxed{ D_{\mathbf e_i}f = \nabla f^T\mathbf e_i = \frac{\partial f}{\partial x_i} }\]

Directional Derivative는 이를 임의의 Direction으로 일반화한 것이다.

혼동하기 쉬운 부분 — Gradient DirectionGradient는 함수가 가장 빠르게 감소하는 방향이 아니다.

Gradient 자체는 \(\boxed{ \text{Steepest Ascent} }\) 방향이다.

가장 빠르게 감소하는 방향은 \(\boxed{ -\nabla f }\)

혼동하기 쉬운 부분 — Gradient NormGradient의 Direction은 Steepest Ascent Direction을 결정하고 Gradient Norm은 그 방향의 최대 Instantaneous Rate를 결정한다.

\[\boxed{ \text{Direction} = \frac{\nabla f}{\|\nabla f\|} }\]
\[\boxed{ \text{Maximum Rate} = \|\nabla f\| }\]

두 개념을 구분해야 한다.

Derivative는 일변수 함수의 순간 변화율이다.

\[\boxed{ f'(x) = \lim_{h\rightarrow0} \frac{ f(x+h)-f(x) }{h} }\]

다변수 함수에서는 각 변수별로 Partial Derivative를 계산한다.

\[\boxed{ \frac{\partial f} {\partial x_i} }\]

모든 Partial Derivative를 모으면 Gradient Vector를 얻는다.

\[\boxed{ \nabla f(\mathbf x) = \begin{bmatrix} \dfrac{\partial f}{\partial x_1}\\ \dfrac{\partial f}{\partial x_2}\\ \vdots\\ \dfrac{\partial f}{\partial x_D} \end{bmatrix} }\]

작은 Parameter 변화에 대해서는

\[\boxed{ f( \mathbf x+\Delta\mathbf x ) \approx f(\mathbf x) + \nabla f(\mathbf x)^T \Delta\mathbf x }\]

임의의 Unit Direction \(\mathbf v\)에 대한 Directional Derivative는

\[\boxed{ D_{\mathbf v}f = \nabla f^T\mathbf v }\]

Euclidean Norm 기준에서 Gradient 방향은 Steepest Ascent Direction이다.

\[\boxed{ \mathbf v_{\mathrm{ascent}} = \frac{\nabla f}{\|\nabla f\|_2} }\]

Negative Gradient는 Steepest Descent Direction이다.

\[\boxed{ \mathbf v_{\mathrm{descent}} = - \frac{\nabla f}{\|\nabla f\|_2} }\]

그리고 최대·최소 Directional Derivative는

\[\boxed{ \max D_{\mathbf v}f = \|\nabla f\|_2 }\]
\[\boxed{ \min D_{\mathbf v}f = -\|\nabla f\|_2 }\]

Level Set에서는

\[f(\mathbf x)=c\]

가 일정하므로 Tangent Direction \(\mathbf t\)에 대해

\[\boxed{ \nabla f^T\mathbf t=0 }\]

따라서

\[\boxed{ \nabla f \perp \text{Level Set} }\]

Deep Learning에서는 Loss를 \(L( \mathbf{\theta} )\) 라고 할 때 Parameter Update를

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \nabla L( \mathbf{\theta}^{(t)} ) }\]

로 수행하는 기본적인 Gradient Descent와 연결된다.

Transformer에서도 Loss Scalar에서

\[\mathbf W_Q, \mathbf W_K, \mathbf W_V, \mathbf E\]

등 모든 Parameter까지 편미분이 전파되고, 이 값들이 각 Parameter Tensor의 Gradient를 구성한다.

전체 흐름은 다음과 같다.

\[\boxed{ \text{Derivative} \rightarrow \text{Partial Derivative} \rightarrow \text{Gradient} }\]

Gradient의 기하학은

\[\boxed{ \nabla f \rightarrow \text{Directional Derivative} \rightarrow \text{Steepest Ascent/Descent} }\]

로 연결된다.

Optimization에서는

\[\boxed{ \text{Loss} \rightarrow \nabla L \rightarrow -\nabla L \rightarrow \text{Parameter Update} }\]

로 연결된다.

그리고 CO-01과 결합하면

\[\boxed{ \nabla L \rightarrow \nabla L=0 \rightarrow \text{Stationary Point} \rightarrow \nabla^2L \rightarrow \text{Local Geometry} }\]

라는 전체 구조가 완성된다.

예제·적용

Example — Function다음 2변수 함수를 생각한다.

\[\boxed{ f(x_1,x_2) = 2x_1^2 + 3x_1x_2 + 5x_2^2 }\]

다음을 계산한다.

  1. Gradient 일반식
  2. \(\mathbf x_0=[1,2]^T\)에서 Gradient
  3. Steepest Descent Direction
  4. 주어진 Unit Vector 방향의 Directional Derivative

원문의 계산 예제는 이러한 순서로 구성되어 있다.

Example — \(x_1\) Partial Derivative\(x_2\)를 Constant로 취급한다.

\[\frac{\partial f}{\partial x_1} = \frac{\partial}{\partial x_1} \left( 2x_1^2 + 3x_1x_2 + 5x_2^2 \right)\]

각 항을 미분하면

\[\boxed{ \frac{\partial f}{\partial x_1} = 4x_1+3x_2 }\]

Example — \(x_2\) Partial Derivative이번에는 \(x_1\)을 Constant로 취급한다.

\[\frac{\partial f}{\partial x_2} = \frac{\partial}{\partial x_2} \left( 2x_1^2 + 3x_1x_2 + 5x_2^2 \right)\]

따라서

\[\boxed{ \frac{\partial f}{\partial x_2} = 3x_1+10x_2 }\]

Example — Gradient두 Partial Derivative를 Column Vector로 묶는다.

\[\boxed{ \nabla f(\mathbf x) = \begin{bmatrix} 4x_1+3x_2\\ 3x_1+10x_2 \end{bmatrix} }\]

Example — Point \((1,2)\)점

\[\boxed{ \mathbf x_0 = \begin{bmatrix} 1\\ 2 \end{bmatrix} }\]

에서 첫 번째 Gradient Component는

\[\begin{aligned} \frac{\partial f}{\partial x_1} \bigg|_{(1,2)} &= 4(1)+3(2)\\ &= 4+6\\ &= \boxed{10} \end{aligned}\]

Example — Second Gradient Component두 번째 Component는

\[\begin{aligned} \frac{\partial f}{\partial x_2} \bigg|_{(1,2)} &= 3(1)+10(2)\\ &= 3+20\\ &= \boxed{23} \end{aligned}\]

따라서

\[\boxed{ \nabla f( \mathbf x_0 ) = \begin{bmatrix} 10\\ 23 \end{bmatrix} }\]

Example — Gradient NormGradient Norm은

\[\| \nabla f( \mathbf x_0 ) \|_2 = \sqrt{ 10^2+23^2 }\]

따라서

\[\boxed{ \| \nabla f( \mathbf x_0 ) \|_2 = \sqrt{629} \approx25.08 }\]

이는 해당 점에서 가능한 Unit Direction 가운데 최대 Directional Derivative의 크기다.

Example — Steepest Descent VectorNegative Gradient는

\[\boxed{ - \nabla f( \mathbf x_0 ) = \begin{bmatrix} -10\\ -23 \end{bmatrix} }\]

방향만을 나타내는 Unit Vector는

\[\boxed{ \mathbf v_{\mathrm{descent}} = - \frac1{\sqrt{629}} \begin{bmatrix} 10\\ 23 \end{bmatrix} }\]

Example — Given Direction원문에서 주어진 방향은

\[\boxed{ \mathbf v = \frac1{\sqrt5} \begin{bmatrix} 1\\ 2 \end{bmatrix} }\]

Norm을 확인하면

\[\|\mathbf v\|_2 = \frac1{\sqrt5} \sqrt{ 1^2+2^2 } = 1\]

이므로 Unit Vector다.

Example — Directional DerivativeDirectional Derivative는

\[D_{\mathbf v}f( \mathbf x_0 ) = \nabla f( \mathbf x_0 )^T \mathbf v\]

따라서

\[\begin{aligned} D_{\mathbf v}f( \mathbf x_0 ) &= \begin{bmatrix} 10&23 \end{bmatrix} \left[ \frac1{\sqrt5} \begin{bmatrix} 1\\ 2 \end{bmatrix} \right]\\ &= \frac1{\sqrt5} ( 10+46 )\\ &= \boxed{ \frac{56}{\sqrt5} } \end{aligned}\]

Example — Numerical Value수치적으로

\[\boxed{ D_{\mathbf v}f( \mathbf x_0 ) \approx25.044 }\]

값이 Positive이므로 이 방향으로 조금 이동하면 함수값은 1차 근사에서 증가한다.

원문의 계산과 동일하다.

Directional Derivative와 Maximum 비교해당 Point에서 최대 가능한 Unit-Direction 변화율은

\[\| \nabla f \|_2 = \sqrt{629} \approx25.08\]

주어진 방향의 Directional Derivative는 \(25.044\) 로 이에 매우 가깝다.

이는 주어진 \(\mathbf v\)가 Gradient와 상당히 비슷한 방향을 가리키고 있음을 의미한다.

Gradient DescentLoss Function을 \(L( \mathbf{\theta} )\) 라고 하자.

Gradient Descent는 현재 Parameter에서 Negative Gradient 방향으로 Parameter를 이동한다.

\[\boxed{ \mathbf{\theta}^{(t+1)} = \mathbf{\theta}^{(t)} - \eta \nabla L( \mathbf{\theta}^{(t)} ) }\]

여기서

\[\eta>0\]

는 Learning Rate다.

원문 역시 이 식을 Deep Learning 최적화와 직접 연결한다.

왜 Negative Gradient인가작은 Update를

\[\Delta\mathbf{\theta} = -\eta \nabla L\]

라고 하자.

1차 Taylor Approximation에 대입하면

\[\Delta L \approx \nabla L^T ( -\eta\nabla L )\]

따라서

\[\boxed{ \Delta L \approx -\eta \| \nabla L \|_2^2 }\]

\(\eta>0\)이면 \(\boxed{ \Delta L\le0 }\) 따라서 충분히 작은 Step에서는 Negative Gradient Update가 Loss를 감소시키는 방향을 제공한다.

Learning RateGradient가 방향과 Local Slope를 제공한다면 Learning Rate는 실제 이동량을 조절한다.

\[\boxed{ \Delta\mathbf{\theta} = -\eta\nabla L }\]

\(\eta\)가 너무 작으면 Update가 작아 Training이 느릴 수 있다.

\(\eta\)가 지나치게 크면 Local Linear Approximation이 유효한 영역을 크게 벗어나 Loss가 오히려 증가할 수도 있다.

따라서

\[\boxed{ -\nabla L = \text{direction} }\]
\[\boxed{ \eta = \text{step scale} }\]

로 구분한다.

Gradient Descent와 Steepest Descent의 관계Euclidean Geometry에서 Unit Direction 중 가장 빠르게 Loss를 감소시키는 방향은

\[-\frac{\nabla L}{\|\nabla L\|_2}\]

Gradient Descent에서는 보통 Unit Vector로 정규화하지 않고 \(-\eta\nabla L\) 를 사용한다.

따라서 Gradient Norm 자체도 Update Magnitude에 영향을 준다.

Neural Network Parameter GradientNeural Network의 Parameter를

\[\mathbf{\theta} = \{ W_1,b_1,W_2,b_2,\dots \}\]

라고 하자.

Loss가 Scalar라면 각 Parameter Element에 대해

\[\frac{\partial L} {\partial\theta_i}\]

를 계산할 수 있다.

모든 값을 모은 것이 전체 Parameter Gradient다.

\(\boxed{ \nabla_{\mathbf{\theta}}L }\)

Matrix Parameter GradientParameter가 Matrix \(\mathbf W\) 라면 각 원소에 대한 Partial Derivative를 모은 Gradient 역시 Matrix Shape으로 표현할 수 있다.

\[\boxed{ \nabla_{\mathbf W}L = \left[ \frac{ \partial L }{ \partial W_{ij} } \right] }\]

즉 Scalar Variable에서는 Derivative이고, 여러 Parameter를 모으면 Gradient Vector 또는 Gradient Tensor가 된다.

Transformer Parameter GradientTransformer에서는 예를 들어

\[\mathbf W_Q, \mathbf W_K, \mathbf W_V\]

와 Token Embedding Matrix \(\mathbf E\) 등이 Parameter가 된다.

Loss에서 이들 Parameter까지 Backpropagation하면

\[\boxed{ \frac{\partial L} {\partial W_{Q,ij}} }\]
\[\boxed{ \frac{\partial L} {\partial W_{K,ij}} }\]
\[\boxed{ \frac{\partial L} {\partial W_{V,ij}} }\]

등을 계산한다.

원자료도 Attention Weight와 Embedding Parameter에 대한 이러한 편미분들의 집합을 Gradient Matrix/Tensor와 연결한다.

Backpropagation의 역할Gradient를 직접 모든 Parameter에 대해 개별적으로 계산하면 매우 비효율적이다.

Neural Network는 여러 함수가 합성된 구조다.

\[L = f_n \circ f_{n-1} \circ \cdots \circ f_1\]

Backpropagation은 Chain Rule을 이용해 이 합성함수의 Gradient를 효율적으로 계산하는 방법이다.

이 Lecture에서는 Gradient 자체의 의미에 집중하고, 구체적인 Chain Rule 및 Backpropagation 전개는 이후 내용과 연결한다.

Gradient와 Parameter SensitivityGradient Component

\[\frac{\partial L} {\partial\theta_i}\]

의 절댓값이 크다는 것은 현재 Point 근처에서 \(\theta_i\) 변화에 Loss가 민감하다는 뜻이다.

반대로

\[\left| \frac{\partial L} {\partial\theta_i} \right| \approx0\]

이면 해당 Parameter 방향의 1차 Sensitivity가 작다.

따라서 Gradient는 Parameter별 Local Sensitivity를 동시에 표현한다.

Gradient Norm전체 Gradient Magnitude는

\[\boxed{ \| \nabla L \|_2 = \sqrt{ \sum_i \left( \frac{\partial L} {\partial\theta_i} \right)^2 } }\]

이 값은 현재 Point에서 Euclidean Unit Direction 중 가능한 최대 1차 변화율과 같다.

\[\boxed{ \max_{\|\mathbf v\|_2=1} D_{\mathbf v}L = \| \nabla L \|_2 }\]

Gradient가 작은 경우Gradient Norm이 작으면

\[\| \nabla L \|_2 \approx0\]

이는 모든 Unit Direction에서 1차 변화율이 작다는 뜻이다.

하지만 이것만으로 Local Minimum이라고 판단할 수 없다.

CO-01에서 확인했듯이

  • Local Minimum
  • Local Maximum
  • Saddle Point
  • Flat Region

에서도 Gradient가 0 또는 매우 작을 수 있다.

따라서

\[\boxed{ \text{Small Gradient} \neq \text{Guaranteed Minimum} }\]

Gradient와 Hessian 연결Gradient는 1차 미분 정보다.

\(\boxed{ \nabla f }\) Gradient를 다시 Parameter에 대해 미분하면 Hessian을 얻는다.

\[\boxed{ \nabla^2f = \mathbf H }\]

따라서

\[\boxed{ f \xrightarrow{\text{1st derivative}} \nabla f \xrightarrow{\text{derivative}} \mathbf H }\]

CO-01에서 Hessian은 Stationary Point의 Curvature를 판별하는 데 사용했다.

정리

편미분은 다른 좌표를 고정했을 때 한 좌표가 함수값을 바꾸는 정도이고, gradient는 각 좌표의 편미분을 모은 벡터다. 작은 변화에 대한 1차 근사는 \(df=\nabla f(\mathbf{x})^T d\mathbf{x}\)로 나타나며, gradient는 함수가 가장 빠르게 증가하는 방향을 가리킨다.
