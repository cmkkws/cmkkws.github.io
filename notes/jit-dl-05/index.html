DL-05 — Backpropagation & Auto-Differentiation

Backpropagation의 Chain Rule 전개와 Auto-Differentiation의 계산 원리를 정리한다.

수정 2026.09.21약 71분상태 작성 완료
학습 내용
  • Backpropagation
  • Backpropagation의 목적
  • Forward와 Backward
  • Chain Rule

1. Backpropagation

Neural Network Training에서는 먼저 Forward Propagation을 수행한다.

\[\boxed{ \mathbf x \rightarrow \hat{\mathbf y} \rightarrow L }\]

그다음 Scalar Loss

\[\boxed{ L }\]

가 각 Parameter에 얼마나 민감한지를 계산한다.

이를 위한 핵심 알고리즘이

\[\boxed{ \text{Backpropagation} }\]

2. Backpropagation의 목적

Parameter를

\[\boxed{ \mathbf{\theta} }\]

라고 하면 Training에 필요한 것은

\[\boxed{ \nabla_{\mathbf{\theta}}L }\]

즉 모든 Weight와 Bias에 대해

\[\frac{\partial L}{\partial\theta_i}\]

를 계산해야 한다.

3. Forward와 Backward

Forward에서는

\[\boxed{ \text{Parameters} \rightarrow \text{Activations} \rightarrow \text{Loss} }\]

방향으로 계산한다.

Backward에서는 반대로

\[\boxed{ \text{Loss} \rightarrow \text{Activations} \rightarrow \text{Parameters} }\]

방향으로 Derivative를 전달한다.

4. Chain Rule

Backpropagation의 수학적 기반은 Chain Rule이다.

Scalar 함수

\[L=L(y), \qquad y=f(x)\]

라면

\[\boxed{ \frac{dL}{dx} = \frac{dL}{dy} \frac{dy}{dx} }\]

5. 여러 함수의 합성

만약

\[x \rightarrow u \rightarrow v \rightarrow L\]

이라는 계산이 있다면

\[\boxed{ \frac{\partial L}{\partial x} = \frac{\partial L}{\partial v} \frac{\partial v}{\partial u} \frac{\partial u}{\partial x} }\]

Deep Network에서는 이 구조가 수많은 Tensor Operation으로 확장된다.

6. Computational Graph

DL-04에서 Neural Network Forward Pass를 DAG

\[\boxed{ \mathcal G=(\mathcal V,\mathcal E) }\]

형태의 Computational Graph로 표현했다.

각 Node는 Tensor나 Operation이고 Edge는 Dependency를 나타낸다.

Backpropagation은 이 Graph를 역방향으로 따라간다.

7. Local Derivative

각 Operation은 자신의 Input에 대한 Local Derivative를 계산할 수 있다.

예를 들어

\[y=f(x)\]

이면 Local Derivative는

\[\boxed{ \frac{\partial y}{\partial x} }\]

8. Upstream Gradient

현재 Node \(y\)까지 전달된 Gradient를

\[\boxed{ \bar y = \frac{\partial L}{\partial y} }\]

라고 생각할 수 있다.

그러면 Input Gradient는

\[\boxed{ \frac{\partial L}{\partial x} = \bar y \frac{\partial y}{\partial x} }\]

9. Reverse Gradient Flow

즉 각 Node에서는

\[\boxed{ \text{upstream gradient} \times \text{local derivative} }\]

를 계산하여 Parent Node로 전달한다.

이 작업을 Loss에서 Input 방향으로 반복한다.

10. Backpropagation의 핵심

전체 Network를 하나의 거대한 수식으로 먼저 전개한 뒤 미분하는 것이 아니다.

작은 Operation별 Local Derivative를 저장하거나 다시 계산하여 Chain Rule을 효율적으로 적용한다.

\[\boxed{ \text{Local derivatives} + \text{Chain Rule} \rightarrow \text{Global gradients} }\]

11. Differentiation 방법

원자료는 미분 방법을 크게 세 가지로 구분한다.

  1. Numerical Differentiation
  2. Symbolic Differentiation
  3. Automatic Differentiation

12. Numerical Differentiation

가장 단순한 Forward Difference는

\[\boxed{ f'(x) \approx \frac{ f(x+h)-f(x) }{ h } }\]

작은

\[h\]

를 이용하여 Derivative를 수치적으로 근사한다.

13. Numerical Differentiation의 근사 오차

Finite Difference는 정확한 Symbolic Derivative가 아니다.

\(h\)가 너무 크면

\[\boxed{ \text{Truncation Error} }\]

가 커진다.

14. Cancellation Error

반대로 \(h\)를 지나치게 작게 하면

\[f(x+h)\]

와

\[f(x)\]

가 Floating-Point에서 매우 가까워진다.

두 값을 빼면서

\[\boxed{ \text{Cancellation / Round-off Error} }\]

가 커질 수 있다.

15. Numerical Gradient 비용

Parameter Dimension이

\[D\]

라면 Forward Difference 방식으로 각 Coordinate를 따로 Perturb해야 한다.

원자료의 방식에서는 대략

\[\boxed{ D+1 }\]

회의 Forward Evaluation이 필요하다.

16. Numerical Differentiation의 역할

따라서 수십억 Parameter를 가진 Network의 Training Gradient를 Numerical Differentiation으로 계산하는 것은 현실적이지 않다.

다만 작은 Model에서 Autograd 결과를 확인하기 위한

\[\boxed{ \text{Gradient Check} }\]

에는 사용할 수 있다.

17. Symbolic Differentiation

Symbolic Differentiation은 함수 표현식 자체에 미분 규칙을 적용한다.

예를 들어

\[f(x)=x^2\sin x\]

를 Symbolically Differentiating하면

\[\boxed{ f'(x) = 2x\sin x+x^2\cos x }\]

를 얻는다.

18. Symbolic Expression Growth

복잡한 함수 합성에서는 Symbolic Expression이 매우 커질 수 있다.

이를

\[\boxed{ \text{Expression Swelling} }\]

이라고 한다.

19. Symbolic Differentiation에 대한 주의

원자료는 Symbolic Differentiation이 대규모 Neural Network에 적용 불가능하다고 표현한다.

더 정확하게는 대규모 Tensor Program Training에서는 전체 식을 Symbolically 전개하는 방식이 일반적으로 비효율적이므로 Autodiff가 훨씬 적합하다는 의미로 이해한다.

20. Automatic Differentiation

Automatic Differentiation은 프로그램을 Primitive Operation의 조합으로 본다.

예:

\[a=xy\]
\[b=\sin a\]
\[L=b^2\]

처럼 작은 연산으로 분해한다.

21. Primitive Operations

각 Primitive Operation은

  1. Forward Value
  2. Local Derivative Rule

을 알고 있다.

따라서 프로그램 전체에 Chain Rule을 자동 적용할 수 있다.

22. Autodiff는 Numerical Differentiation이 아니다

Autodiff는

\[\frac{ f(x+h)-f(x) }{ h }\]

처럼 Finite Difference를 이용하지 않는다.

따라서 \(h\) 선택에서 발생하는 Truncation Error를 기본 원리로 사용하지 않는다.

23. Autodiff는 Symbolic Differentiation도 아니다

Autodiff는 전체 Symbolic Formula를 거대하게 전개하는 대신 실제 Computational Graph의 연산에 Local Derivative Rule을 적용한다.

따라서

\[\boxed{ \text{Automatic Differentiation} \neq \text{Numerical Differentiation} }\]

이고

\[\boxed{ \text{Automatic Differentiation} \neq \text{pure Symbolic Differentiation} }\]

24. Forward-mode Autodiff

함수

\[\boxed{ f: \mathbb R^n \rightarrow \mathbb R^m }\]

을 생각한다.

Forward-mode는 Input 방향에서 Output 방향으로 Derivative 정보를 함께 전파한다.

25. Directional Derivative

Forward-mode는 특정 Input Direction

\[\mathbf v\]

에 대해

\[\boxed{ J_f(\mathbf x)\mathbf v }\]

즉 Jacobian-Vector Product, JVP를 효율적으로 계산하는 방식으로 볼 수 있다.

26. Reverse-mode Autodiff

Reverse-mode는 먼저 Forward Pass를 수행한 뒤 Output에서 Input 방향으로 Gradient를 전파한다.

이는

\[\boxed{ \mathbf v^TJ_f }\]

형태의 Vector-Jacobian Product, VJP와 연결된다.

27. Scalar Output

Deep Learning Training에서는 일반적으로 Loss가 Scalar다.

\[\boxed{ L: \mathbb R^D \rightarrow \mathbb R }\]

즉

\[m=1\]

이고 Parameter Dimension

\[D\]

는 매우 크다.

28. Reverse-mode가 적합한 이유

Scalar Loss에서 모든 Parameter Gradient

\[\boxed{ \nabla_\theta L \in \mathbb R^D }\]

가 필요하다.

Reverse-mode는 한 번의 Reverse Sweep에서 이 Gradient Vector 전체를 계산할 수 있다.

29. Forward-mode와 Reverse-mode 직관

대략적으로

\[\boxed{ n\ll m \Rightarrow \text{Forward-mode가 유리할 수 있음} }\]

이고

\[\boxed{ m\ll n \Rightarrow \text{Reverse-mode가 유리할 수 있음} }\]

Deep Learning은 후자에 해당한다.

30. Backpropagation과 Reverse-mode

Neural Network에서 사용하는 Backpropagation은 Reverse-mode Automatic Differentiation을 Neural Network Computational Graph에 적용한 대표적인 형태로 이해할 수 있다.

\[\boxed{ \text{Backpropagation} \subset \text{Reverse-mode AD framework} }\]

라는 관점이 유용하다.

31. Computational Complexity

Forward Computational Graph가

\[N\]

개의 Primitive Operation으로 구성되어 있다고 생각하자.

Forward Pass의 계산량이

\[O(N)\]

이라면 Reverse Sweep 역시 Local Derivative를 각 연산에 대해 처리하므로 일반적으로

\[\boxed{ O(N) }\]

규모의 계산량을 가진다.

32. “Forward 1회 비용”에 대한 주의

원자료는 Reverse-mode가

\[\mathcal O( 1\cdot\text{Forward} )\]

비용으로 모든 Gradient를 완벽히 계산한다고 표현한다.

핵심은 Parameter 수 \(D\)번 Forward를 반복하지 않고 Forward 계산량의 상수배 수준에서 Gradient 전체를 얻는다는 것이다.

정확한 상수배는 Operation과 Implementation에 따라 달라진다.

33. Time–Memory Trade-off

Reverse-mode는 계산량 측면에서는 효율적이지만 Backward에서 필요한 Forward Intermediate를 저장해야 한다.

따라서

\[\boxed{ \text{Reverse-mode efficiency} \leftrightarrow \text{activation memory} }\]

라는 Trade-off가 존재한다.

34. MLP Forward Setup

원자료의 \(L\)-Layer MLP를 생각한다.

Input은

\[\boxed{ \mathbf h^{(0)} = \mathbf x \in \mathbb R^{d_0} }\]

35. Layer Pre-Activation

\(l\)번째 Layer에서

\[\boxed{ \mathbf z^{(l)} = \mathbf W^{(l)} \mathbf h^{(l-1)} + \mathbf b^{(l)} }\]

36. Weight Shape

Column-Vector Convention에서

\[\boxed{ \mathbf W^{(l)} \in \mathbb R^{ d_l\times d_{l-1} } }\]

37. Bias Shape

\[\boxed{ \mathbf b^{(l)} \in \mathbb R^{d_l} }\]

따라서

\[\boxed{ \mathbf z^{(l)} \in \mathbb R^{d_l} }\]

38. Activation

Activation Function을 Element-wise 적용한다.

\[\boxed{ \mathbf h^{(l)} = \sigma_l( \mathbf z^{(l)} ) }\]

39. Final Output

마지막 Layer에서

\[\boxed{ \mathbf h^{(L)} = \hat{\mathbf y} }\]

이 Prediction과 Target을 Loss Function에 넣는다.

40. Error Vector

원자료는 각 Layer의 Pre-activation Gradient를

\[\boxed{ \mathbf{\delta}^{(l)} \equiv \frac{\partial L} {\partial\mathbf z^{(l)} } }\]

로 정의한다.

41. Error Vector Shape

\[\mathbf z^{(l)} \in \mathbb R^{d_l}\]

이므로

\[\boxed{ \mathbf{\delta}^{(l)} \in \mathbb R^{d_l} }\]

42. Component Definition

\(j\)번째 Component는

\[\boxed{ \delta_j^{(l)} = \frac{\partial L} {\partial z_j^{(l)} } }\]

43. Backpropagation Recursion 목표

상위 Layer

\[l+1\]

의

\[\mathbf{\delta}^{(l+1)}\]

를 이미 알고 있다고 하자.

목표는

\[\boxed{ \mathbf{\delta}^{(l)} }\]

를 구하는 것이다.

44. Dependency

\(z_j^{(l)}\)는 Activation

\[h_j^{(l)} = \sigma_l( z_j^{(l)} )\]

을 통해 다음 Layer의 여러 Neuron에 영향을 준다.

45. Next-Layer Component

\[\boxed{ z_k^{(l+1)} = \sum_{m=1}^{d_l} W_{km}^{(l+1)} h_m^{(l)} + b_k^{(l+1)} }\]

46. Activation 대입

\[h_m^{(l)} = \sigma_l( z_m^{(l)} )\]

이므로

\[\boxed{ z_k^{(l+1)} = \sum_m W_{km}^{(l+1)} \sigma_l( z_m^{(l)} ) + b_k^{(l+1)} }\]

47. Multivariate Chain Rule

\(z_j^{(l)}\)에서 Loss까지 여러 경로가 존재한다.

따라서

\[\boxed{ \delta_j^{(l)} = \sum_{k=1}^{d_{l+1}} \frac{\partial L} {\partial z_k^{(l+1)}} \frac{ \partial z_k^{(l+1)} }{ \partial z_j^{(l)} } }\]

48. Upper-Layer Delta 대입

정의에 의해

\[\frac{\partial L} {\partial z_k^{(l+1)}} = \delta_k^{(l+1)}\]

따라서

\[\boxed{ \delta_j^{(l)} = \sum_k \delta_k^{(l+1)} \frac{ \partial z_k^{(l+1)} }{ \partial z_j^{(l)} } }\]

49. Local Derivative

\[z_k^{(l+1)} = \sum_m W_{km}^{(l+1)} \sigma_l( z_m^{(l)} ) + b_k^{(l+1)}\]

를

\[z_j^{(l)}\]

로 미분하면

\[\boxed{ \frac{ \partial z_k^{(l+1)} }{ \partial z_j^{(l)} } = W_{kj}^{(l+1)} \sigma_l'( z_j^{(l)} ) }\]

50. Component Recursion

대입하면

\[\boxed{ \delta_j^{(l)} = \sum_k \delta_k^{(l+1)} W_{kj}^{(l+1)} \sigma_l'( z_j^{(l)} ) }\]

51. Activation Derivative 분리

\(\sigma_l'(z_j^{(l)})\)는 \(k\)에 의존하지 않으므로

\[\boxed{ \delta_j^{(l)} = \left( \sum_k W_{kj}^{(l+1)} \delta_k^{(l+1)} \right) \sigma_l'( z_j^{(l)} ) }\]

52. Matrix-Vector Product

합

\[\sum_k W_{kj}^{(l+1)} \delta_k^{(l+1)}\]

는

\[\boxed{ ( W^{(l+1)} )^T \mathbf{\delta}^{(l+1)} }\]

의 \(j\)번째 Component다.

53. Backpropagation Recursion

따라서

\[\boxed{ \mathbf{\delta}^{(l)} = \left[ ( \mathbf W^{(l+1)} )^T \mathbf{\delta}^{(l+1)} \right] \odot \sigma_l'( \mathbf z^{(l)} ) }\]

54. Hadamard Product

여기서

\[\boxed{ \odot }\]

는 Element-wise Product다.

즉 다음 Layer에서 전달된 Gradient와 현재 Activation Function의 Local Derivative를 Component-wise 곱한다.

55. Recursion의 직관

Backpropagation은 각 Layer에서

\[\boxed{ \text{next-layer error} \rightarrow W^T \rightarrow \text{activation derivative} }\]

의 순서로 Gradient를 이전 Layer로 전달한다.

56. Weight Transpose

Forward에서는

\[\boxed{ z^{(l+1)} = W^{(l+1)}h^{(l)}+b }\]

였다.

Backward에서는

\[\boxed{ ( W^{(l+1)} )^T \delta^{(l+1)} }\]

가 등장한다.

DL-01의 Linear Layer Backward와 동일한 구조다.

57. Weight Gradient

\(l\)번째 Layer의

\[W_{ij}^{(l)}\]

에 대한 Gradient를 계산한다.

Forward는

\[z_i^{(l)} = \sum_j W_{ij}^{(l)} h_j^{(l-1)} + b_i^{(l)}\]

58. Local Weight Derivative

따라서

\[\boxed{ \frac{ \partial z_i^{(l)} }{ \partial W_{ij}^{(l)} } = h_j^{(l-1)} }\]

59. Weight Chain Rule

\[\begin{aligned} \frac{ \partial L }{ \partial W_{ij}^{(l)} } &= \frac{\partial L} {\partial z_i^{(l)}} \frac{ \partial z_i^{(l)} }{ \partial W_{ij}^{(l)} }\\ &= \delta_i^{(l)} h_j^{(l-1)} \end{aligned}\]

60. Outer Product

전체 Weight Gradient는

\[\boxed{ \frac{\partial L} {\partial\mathbf W^{(l)} } = \mathbf{\delta}^{(l)} ( \mathbf h^{(l-1)} )^T }\]

61. Weight Gradient Shape

\[\mathbf{\delta}^{(l)} \in \mathbb R^{d_l}\]

이고

\[( h^{(l-1)} )^T \in \mathbb R^{1\times d_{l-1}}\]

이므로

\[\boxed{ \nabla_{W^{(l)}}L \in \mathbb R^{ d_l\times d_{l-1} } }\]

Weight 자체의 Shape과 같다.

62. Bias Gradient

\[\frac{ \partial z_i^{(l)} }{ \partial b_i^{(l)} } = 1\]

이므로

\[\boxed{ \frac{\partial L} {\partial\mathbf b^{(l)} } = \mathbf{\delta}^{(l)} }\]

Single Sample 기준이다.

63. Input-Activation Gradient

Pre-activation

\[z^{(l)} = W^{(l)}h^{(l-1)}+b\]

에서 이전 Activation으로 전달되는 Gradient는

\[\boxed{ \frac{\partial L} {\partial h^{(l-1)} } = ( W^{(l)} )^T \mathbf{\delta}^{(l)} }\]

64. Single-Sample Backward Summary

하나의 Layer에 대해

\[\boxed{ z=Wh+b }\]

이면

\[\boxed{ \nabla_WL = \delta h^T }\]
\[\boxed{ \nabla_bL = \delta }\]
\[\boxed{ \nabla_hL = W^T\delta }\]

65. Mini-Batch Convention

원자료의 Batch 일반화에서는 Sample을 Column으로 둔다.

\[\boxed{ H^{(l-1)} \in \mathbb R^{ d_{l-1}\times B } }\]

66. Batch Delta

\[\boxed{ \Delta^{(l)} \in \mathbb R^{ d_l\times B } }\]

각 Column이 한 Sample의

\[\delta^{(l)}\]

에 해당한다.

67. Mean-Loss Weight Gradient

Batch Loss를 Sample Average로 정의하면

\[\boxed{ \frac{\partial L} {\partial W^{(l)} } = \frac1B \Delta^{(l)} ( H^{(l-1)} )^T }\]

68. Reduction 방식 주의

앞의

\[\frac1B\]

는 Loss가 Batch Mean으로 정의되었을 때 등장한다.

Loss가 Batch Sum이면

\[\boxed{ \nabla_WL = \Delta H^T }\]

형태가 된다.

69. DL-01 Convention과 비교

DL-01에서는 Sample을 Row로 쌓아

\[X\in\mathbb R^{B\times d_{\mathrm{in}}}\]

으로 두었다.

그때는

\[\boxed{ \nabla_WL = X^TG }\]

였다.

현재 식과 Transpose 위치가 달라 보이는 이유는 Batch Orientation Convention이 다르기 때문이다.

70. Numerical Example — Network

원자료의 Network는

\[\boxed{ d_0=2, \qquad d_1=2, \qquad d_2=1 }\]

즉

\[2 \rightarrow 2 \rightarrow 1\]

MLP다.

71. First-Layer Weight

\[\boxed{ W^{(1)} = \begin{bmatrix} 0.1&0.2\\ 0.3&0.4 \end{bmatrix} }\]

72. First-Layer Bias

\[\boxed{ b^{(1)} = \begin{bmatrix} 0\\ 0 \end{bmatrix} }\]

73. Second-Layer Weight

\[\boxed{ W^{(2)} = \begin{bmatrix} 0.5&0.6 \end{bmatrix} }\]

74. Input and Target

Input은

\[\boxed{ x = \begin{bmatrix} 1\\ 2 \end{bmatrix} }\]

이고 Target은

\[\boxed{ y=2 }\]

75. Loss

Loss는

\[\boxed{ L = \frac12 ( \hat y-y )^2 }\]

76. First-Layer Pre-Activation

\[z^{(1)} = W^{(1)}x+b^{(1)}\]

첫 번째 Component는

\[0.1(1)+0.2(2) = \boxed{ 0.5 }\]

77. Second Hidden Pre-Activation

두 번째 Component는

\[0.3(1)+0.4(2) = 0.3+0.8 = \boxed{ 1.1 }\]

따라서

\[\boxed{ z^{(1)} = \begin{bmatrix} 0.5\\ 1.1 \end{bmatrix} }\]

78. Hidden ReLU

두 값 모두 Positive이므로

\[\boxed{ h^{(1)} = \operatorname{ReLU}( z^{(1)} ) = \begin{bmatrix} 0.5\\ 1.1 \end{bmatrix} }\]

79. Output Pre-Activation

\[\begin{aligned} z^{(2)} &= W^{(2)}h^{(1)} +b^{(2)}\\ &= 0.5(0.5) + 0.6(1.1)\\ &= 0.25+0.66\\ &= \boxed{ 0.91 } \end{aligned}\]

80. Prediction

Output Activation은 Identity이므로

\[\boxed{ \hat y = 0.91 }\]

81. Loss Calculation

\[\begin{aligned} L &= \frac12 ( 0.91-2 )^2\\ &= \frac12 (-1.09)^2\\ &= \frac12 (1.1881)\\ &= \boxed{ 0.59405 } \end{aligned}\]

82. Output Delta

Output Activation이 Identity이므로

\[\sigma_2'(z)=1\]

Squared Error에 대해

\[\frac{\partial L} {\partial\hat y} = \hat y-y\]

83. $\delta^{(2)}$

따라서

\[\begin{aligned} \delta^{(2)} &= (\hat y-y) \sigma_2'(z^{(2)})\\ &= (0.91-2)(1)\\ &= \boxed{ -1.09 } \end{aligned}\]

84. Second-Layer Weight Gradient

\[\frac{\partial L} {\partial W^{(2)} } = \delta^{(2)} ( h^{(1)} )^T\]

85. Numerical $W^{(2)}$ Gradient

\[\begin{aligned} \nabla_{W^{(2)}}L &= -1.09 \begin{bmatrix} 0.5&1.1 \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} -0.545&-1.199 \end{bmatrix} } \end{aligned}\]

86. Second-Layer Bias Gradient

Single Sample이므로

\[\boxed{ \frac{\partial L} {\partial b^{(2)} } = -1.09 }\]

87. Hidden ReLU Derivative

\[z^{(1)} = \begin{bmatrix} 0.5\\ 1.1 \end{bmatrix}\]

이고 두 값 모두 Positive다.

따라서

\[\boxed{ \sigma_1'( z^{(1)} ) = \begin{bmatrix} 1\\ 1 \end{bmatrix} }\]

88. Gradient Before ReLU

먼저

\[( W^{(2)} )^T \delta^{(2)}\]

를 계산한다.

\[\begin{aligned} &= \begin{bmatrix} 0.5\\ 0.6 \end{bmatrix} (-1.09)\\ &= \boxed{ \begin{bmatrix} -0.545\\ -0.654 \end{bmatrix} } \end{aligned}\]

89. Hidden Delta

ReLU Derivative를 Element-wise 곱하면

\[\begin{aligned} \delta^{(1)} &= \begin{bmatrix} -0.545\\ -0.654 \end{bmatrix} \odot \begin{bmatrix} 1\\ 1 \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} -0.545\\ -0.654 \end{bmatrix} } \end{aligned}\]

90. First-Layer Weight Gradient

\[\frac{\partial L} {\partial W^{(1)} } = \delta^{(1)}x^T\]

91. Outer Product

\[\begin{aligned} \nabla_{W^{(1)}}L &= \begin{bmatrix} -0.545\\ -0.654 \end{bmatrix} \begin{bmatrix} 1&2 \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} -0.545&-1.090\\ -0.654&-1.308 \end{bmatrix} } \end{aligned}\]

92. First-Layer Bias Gradient

Single Sample에서는

\[\boxed{ \nabla_{b^{(1)}}L = \delta^{(1)} = \begin{bmatrix} -0.545\\ -0.654 \end{bmatrix} }\]

93. Input Gradient

입력까지 Gradient를 전달하면

\[\boxed{ \nabla_xL = ( W^{(1)} )^T \delta^{(1)} }\]

94. Numerical Input Gradient

\[( W^{(1)} )^T = \begin{bmatrix} 0.1&0.3\\ 0.2&0.4 \end{bmatrix}\]

이므로

\[\begin{aligned} \nabla_xL &= \begin{bmatrix} 0.1&0.3\\ 0.2&0.4 \end{bmatrix} \begin{bmatrix} -0.545\\ -0.654 \end{bmatrix} \end{aligned}\]

95. First Input Component

\[0.1(-0.545) + 0.3(-0.654) = -0.0545-0.1962\]

따라서

\[\boxed{ -0.2507 }\]

96. Second Input Component

\[0.2(-0.545) + 0.4(-0.654) = -0.109-0.2616\]

이므로

\[\boxed{ -0.3706 }\]

따라서

\[\boxed{ \nabla_xL = \begin{bmatrix} -0.2507\\ -0.3706 \end{bmatrix} }\]

97. Example 전체 Gradient Flow

Forward:

\[\boxed{ x \rightarrow z^{(1)} \rightarrow h^{(1)} \rightarrow z^{(2)} \rightarrow L }\]

Backward:

\[\boxed{ L \rightarrow \delta^{(2)} \rightarrow \delta^{(1)} \rightarrow \nabla_xL }\]

98. Parameter Gradient Flow

동시에 각 Layer에서는

\[\boxed{ \delta^{(l)} \rightarrow \nabla_{W^{(l)}}L, \quad \nabla_{b^{(l)}}L }\]

을 계산한다.

따라서 한 번의 Reverse Sweep에서 모든 Layer Gradient를 얻는다.

99. Dynamic Computational Graph

원자료는 PyTorch의 torch.autograd가 Forward Pass 중 Operation을 추적하여 Dynamic Computational Graph를 구축한다고 설명한다.

Tensor Operation의 결과에는 Backward 계산을 위한 Dependency 정보가 연결된다.

100. Autograd Graph

Gradient Tracking이 활성화된 Tensor를 사용하여

\[y=f(x)\]

를 계산하면 Autograd Engine은 해당 연산의 Backward Rule과 Parent Dependency를 기록한다.

101. Scalar Loss

최종적으로

\[\boxed{ L }\]

이라는 Scalar Loss가 만들어진다.

이 Loss에서

text id="t8h55v" loss.backward()

를 호출하면 Reverse-mode 계산이 시작된다.

102. Backward Traversal

Backward는 Output Loss에서 그 Loss에 영향을 준 이전 Operation 방향으로 Computational Graph를 역순으로 처리한다.

즉

\[\boxed{ \text{loss} \rightarrow \text{intermediate operations} \rightarrow \text{leaf tensors / parameters} }\]

103. Leaf/Root 표현 주의

원자료는 Loss를 “leaf node”, Parameter를 “root node”라고 표현한다.

PyTorch 용어에서는 일반적으로 사용자가 생성하고 requires_grad=True인 Parameter Tensor를 leaf tensor라고 부른다.

따라서 이 부분은 Graph의 계산 방향과 PyTorch의 leaf tensor 용어를 구분하는 것이 정확하다.

104. Gradient Accumulation

하나의 Tensor가 여러 경로를 통해 Loss에 영향을 주면 각 경로의 Gradient Contribution이 합쳐져야 한다.

\[\boxed{ \frac{\partial L}{\partial x} = \sum_{\text{paths}} \text{path contribution} }\]

105. Residual Connection Example

Transformer의 Residual Connection처럼

\[y=x+f(x)\]

이면

\[\boxed{ \frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \left[ 1+f'(x) \right] }\]

형태로 여러 경로의 Gradient가 합쳐진다.

106. Backpropagation의 Graph 관점

따라서 Backpropagation의 본질은 단순히 “Layer를 뒤에서부터 미분”하는 것보다

\[\boxed{ \text{DAG 위에서 Reverse-mode Chain Rule을 실행} }\]

하는 것으로 보는 것이 정확하다.

107. Forward Activation Storage

Backward에서

\[\nabla_WL = \delta h^T\]

를 계산하려면 Forward에서 사용한

\[h\]

가 필요하다.

Activation Derivative를 계산할 때는

\[z\]

또는 이에 대응하는 Forward State가 필요할 수 있다.

108. Activation Memory

따라서 Reverse-mode AD에서는 Backward를 위해 일부 Forward Intermediate를 보존한다.

\[\boxed{ \text{Forward activations} \rightarrow \text{Backward local derivatives} }\]

109. LLM Training Memory

원자료는 긴 Sequence의 LLM Training에서 Activation Memory가 매우 중요해질 수 있음을 강조한다.

Sequence Length, Batch Size, Hidden Dimension, Layer Count가 커지면 저장해야 하는 Intermediate Tensor도 증가할 수 있다.

110. Memory Dominance 주의

다만

\[\boxed{ \text{activation memory} > \text{parameter memory} }\]

가 모든 LLM Training Configuration에서 항상 성립하는 것은 아니다.

전체 Memory는

  • Parameters
  • Gradients
  • Optimizer States
  • Activations
  • Temporary Buffers

등으로 구성된다.

111. Activation Checkpointing

Activation Memory를 줄이기 위한 대표적인 방법이

\[\boxed{ \text{Activation Checkpointing} }\]

Gradient Checkpointing이라고도 부른다.

112. Checkpointing 핵심

Forward Pass에서 모든 Intermediate Activation을 저장하는 대신 일부 Checkpoint만 저장한다.

\[\boxed{ \text{store fewer states} }\]

113. Recomputation

Backward에서 버렸던 Intermediate가 필요하면 가장 가까운 Checkpoint에서 해당 Forward Operation을 다시 실행한다.

\[\boxed{ \text{recompute during backward} }\]

114. Memory–Compute Trade-off

따라서

\[\boxed{ \text{less memory} \Longleftrightarrow \text{more computation} }\]

이라는 Trade-off가 발생한다.

115. $O(\sqrt L)$ Result

원자료는 Activation Memory를

\[O(L)\]

에서

\[O(\sqrt L)\]

로 줄일 수 있다고 설명한다.

이는 특정 Checkpoint Placement Strategy에서 얻을 수 있는 대표적인 Complexity Result다.

116. Checkpoint Complexity 주의

실제 Framework의 Checkpointing Memory와 Recompute 비용은

  • Segment Length
  • Checkpoint 위치
  • Block Architecture
  • Kernel Implementation

에 따라 달라진다.

따라서

\[\boxed{ O(\sqrt L) }\]

을 모든 Checkpointing 설정의 고정된 Memory Complexity로 해석하지 않는다.

117. Mixed Precision

대규모 Training에서는 FP32보다 낮은 Precision Format을 사용하여

  • Memory
  • Bandwidth
  • Tensor-Core Throughput

을 개선할 수 있다.

대표적으로

\[\boxed{ \text{FP16} }\]

과

\[\boxed{ \text{BF16} }\]

이 있다.

118. FP16 Gradient Underflow

Backward Gradient가 매우 작아지면 FP16의 표현 가능한 Range 아래로 떨어질 수 있다.

그러면 작은 Gradient가 0으로 Rounded될 수 있다.

이를

\[\boxed{ \text{Gradient Underflow} }\]

라고 한다.

119. FP16 Range의 정확한 구분

FP16의 가장 작은 positive normal 값은 약

\[\boxed{ 6.10\times10^{-5} }\]

하지만 Subnormal까지 포함하면 약

\[\boxed{ 5.96\times10^{-8} }\]

까지 표현할 수 있다.

따라서 원자료의 “\(6.5\times10^{-5}\) 미만이면 모두 Underflow”라는 표현은 정확하지 않다.

120. Loss Scaling

작은 FP16 Gradient가 Underflow되는 것을 줄이기 위해 Loss에 큰 Scale Factor를 곱할 수 있다.

\[\boxed{ L_{\mathrm{scaled}} = S_{\mathrm{loss}}L }\]

121. Gradient Scaling

Derivative의 선형성에 의해

\[\boxed{ \nabla_\theta L_{\mathrm{scaled}} = S_{\mathrm{loss}} \nabla_\theta L }\]

따라서 Backward 중 Gradient Magnitude가 커진다.

122. Unscaling

Optimizer Update 전에 다시

\[S_{\mathrm{loss}}\]

로 나눈다.

\[\boxed{ \nabla_\theta L = \frac1{ S_{\mathrm{loss}} } \nabla_\theta L_{\mathrm{scaled}} }\]

123. Dynamic Loss Scaling

고정된 Scale이 너무 크면 Overflow가 발생할 수 있다.

따라서 실제 Mixed-Precision Training에서는 Overflow 여부에 따라 Scale을 동적으로 조정하는

\[\boxed{ \text{Dynamic Loss Scaling} }\]

을 사용할 수 있다.

124. BF16과 Loss Scaling

BF16은 FP16보다 Mantissa Precision은 낮지만 Exponent Range는 FP32와 유사하다.

따라서 Gradient Underflow 측면에서 FP16보다 훨씬 넓은 Dynamic Range를 가진다.

결과적으로 BF16 Training에서는 FP16만큼 Loss Scaling이 필수적이지 않은 경우가 많다.

125. Vanishing Gradient와 Underflow의 차이

두 현상을 구분해야 한다.

Vanishing Gradient

Chain Rule과 Jacobian Product 때문에 Gradient Magnitude 자체가 수학적으로 매우 작아지는 현상.

Numerical Underflow

이미 작은 Gradient가 Floating-Point Format의 표현 범위 때문에 0으로 사라지는 현상.

\[\boxed{ \text{Vanishing} \neq \text{Underflow} }\]

126. DL-04와 연결

DL-04:

\[\boxed{ \text{Forward Computational Graph} }\]

DL-05:

\[\boxed{ \text{Reverse traversal of that graph} }\]

즉 두 강의는 Forward/Backward 한 쌍을 이룬다.

127. DL-01과 연결

DL-01에서

\[Y=XW+b\]

에 대해

\[\boxed{ \nabla_WL=X^TG }\]
\[\boxed{ \nabla_XL=GW^T }\]

를 유도했다.

DL-05의 MLP Backpropagation은 이 Linear Layer Gradient를 여러 Layer에 반복 적용한 구조다.

128. DL-03과 연결

Softmax + Cross-Entropy에서는 Output Logit Gradient가

\[\boxed{ \nabla_zL=p-y }\]

였다.

이 Gradient가 Transformer 또는 Classifier의 Output Layer에서 Backpropagation의 시작점이 된다.

129. CO-07과 연결

CO-07의 Matrix Calculus는 Backpropagation에서 각 Tensor Operation의 Local Gradient를 계산하기 위한 수학적 도구다.

\[\boxed{ \text{Matrix Calculus} \rightarrow \text{Local derivatives} \rightarrow \text{Backpropagation} }\]

130. CO-09과 연결

Backpropagation으로

\[\boxed{ \nabla_\theta L }\]

을 얻은 뒤 Optimizer가 Parameter Update를 수행한다.

Gradient Descent라면

\[\boxed{ \theta_{t+1} = \theta_t - \eta \nabla_\theta L }\]

131. Transformer Backpropagation

Transformer에서도 원리는 동일하다.

Forward에는

  • Linear Projection
  • Attention
  • Softmax
  • RMSNorm
  • Residual Addition
  • SwiGLU

등의 Operation이 존재한다.

각 Operation의 Local Derivative를 Reverse-mode로 연결한다.

132. Q/K/V Gradient

예를 들어

\[Q=XW_Q\]

이면

\[\boxed{ \nabla_{W_Q}L = X^T\nabla_QL }\]

이고

\[\boxed{ \nabla_XL\big|_Q = \nabla_QL\,W_Q^T }\]

K와 V Branch에서도 동일한 구조가 발생한다.

133. Branch Gradient Sum

\(X\)가 Q, K, V 세 Branch에 동시에 사용된다면

\[\boxed{ \nabla_XL = \nabla_XL\big|_Q + \nabla_XL\big|_K + \nabla_XL\big|_V + \cdots }\]

Computational Graph에서 여러 Child Edge의 Gradient가 Parent Node에서 합산되는 구조다.

134. Residual Gradient

Residual Connection

\[Y=X+F(X)\]

에서는 Identity Path가 존재한다.

Backward에서는

\[\boxed{ \nabla_XL = \nabla_YL + \nabla_FL \frac{\partial F}{\partial X} }\]

형태로 Gradient Contribution이 합쳐진다.

135. 핵심 식 — Error Vector

\[\boxed{ \delta^{(l)} = \frac{\partial L} {\partial z^{(l)} } }\]

136. 핵심 식 — Backprop Recursion

\[\boxed{ \delta^{(l)} = \left[ ( W^{(l+1)} )^T \delta^{(l+1)} \right] \odot \sigma_l'( z^{(l)} ) }\]

137. 핵심 식 — Weight Gradient

\[\boxed{ \nabla_{W^{(l)}}L = \delta^{(l)} ( h^{(l-1)} )^T }\]

138. 핵심 식 — Bias Gradient

Single Sample에서는

\[\boxed{ \nabla_{b^{(l)}}L = \delta^{(l)} }\]

139. 핵심 식 — Previous Activation Gradient

\[\boxed{ \nabla_{h^{(l-1)}}L = ( W^{(l)} )^T \delta^{(l)} }\]

140. 핵심 식 — Batch Gradient

원자료의 Column-Batch Convention과 Mean Reduction에서는

\[\boxed{ \nabla_{W^{(l)}}L = \frac1B \Delta^{(l)} ( H^{(l-1)} )^T }\]

141. 핵심 식 — Loss Scaling

\[\boxed{ L_{\mathrm{scaled}} = S_{\mathrm{loss}}L }\]
\[\boxed{ \nabla_\theta L_{\mathrm{scaled}} = S_{\mathrm{loss}} \nabla_\theta L }\]

142. 혼동하기 쉬운 부분 — Backpropagation과 Gradient Descent

Backpropagation은 Parameter를 Update하는 Algorithm이 아니다.

Backpropagation:

\[\boxed{ \nabla_\theta L \text{ 계산} }\]

Optimizer:

\[\boxed{ \theta \text{ 업데이트} }\]

143. 혼동하기 쉬운 부분 — Autodiff와 Backpropagation

Autodiff는 프로그램의 Derivative를 자동 계산하는 더 일반적인 Framework다.

Backpropagation은 Neural Network에서 Reverse-mode AD를 수행하는 대표적인 Algorithmic Procedure다.

144. 혼동하기 쉬운 부분 — Numerical Differentiation

Autodiff는 작은 \(h\)를 선택해 Finite Difference를 계산하지 않는다.

따라서 Autodiff를 Numerical Differentiation과 같은 방식으로 이해하면 안 된다.

145. 혼동하기 쉬운 부분 — $O(N)$

Backpropagation의

\[O(N)\]

은 일반적으로 Graph의 Primitive Operation 수에 선형적인 Reverse Sweep을 뜻한다.

Parameter 수나 Tensor 크기를 무시하고 모든 Operation을 동일 비용으로 보는 단순한 설명으로 받아들여야 한다.

실제 FLOPs는 Matrix Size에 따라 결정된다.

146. 혼동하기 쉬운 부분 — 한 번의 Backward

한 번의 Reverse Sweep으로 모든 Parameter Gradient를 얻을 수 있다는 것이 Reverse-mode의 핵심이다.

하지만

\[\boxed{ \text{Backward cost} = \text{exactly one Forward cost} }\]

라고 보편적으로 고정되는 것은 아니다.

147. 혼동하기 쉬운 부분 — Intermediate Activation

Backward를 위해 항상 모든 Forward Tensor를 그대로 보존하는 것은 아니다.

Autograd는 필요한 Tensor를 선택적으로 저장할 수 있고 Checkpointing은 일부 Tensor를 재계산한다.

148. 혼동하기 쉬운 부분 — ReLU at Zero

ReLU는

\[\operatorname{ReLU}(z) = \max(0,z)\]

\(z=0\)에서는 Classical Derivative가 정의되지 않는다.

Framework는 Backpropagation을 위해 특정 Subgradient Convention을 선택한다.

이번 원자료 예제에서는 \(z=0\)이 없으므로 문제가 발생하지 않는다.

149. 혼동하기 쉬운 부분 — $\delta$

\[\delta^{(l)}\]

는 Target Error 자체가 아니다.

정의는

\[\boxed{ \delta^{(l)} = \frac{\partial L} {\partial z^{(l)} } }\]

즉 Pre-activation에 대한 Loss Gradient다.

150. 혼동하기 쉬운 부분 — Batch Orientation

Sample을 Row로 쌓느냐 Column으로 쌓느냐에 따라

\[X^TG\]

또는

\[\Delta H^T\]

처럼 Formula의 Transpose 위치가 달라질 수 있다.

항상 Tensor Shape을 확인해야 한다.

151. 혼동하기 쉬운 부분 — Activation Memory

대규모 LLM에서 Activation Memory는 중요한 Bottleneck이 될 수 있지만 모든 설정에서 Parameter/Optimizer Memory보다 반드시 크다고 일반화하지 않는다.

152. 혼동하기 쉬운 부분 — $O(\sqrt L)$ Checkpointing

Checkpointing의

\[O(\sqrt L)\]

Memory Result는 특정 전략에서 나타나는 대표적 결과다.

Checkpoint Granularity에 따라 다른 Trade-off가 가능하다.

153. 혼동하기 쉬운 부분 — FP16 Range

\[6.1\times10^{-5}\]

근처는 FP16의 smallest positive normal value다.

그 아래에 Subnormal Range가 존재한다.

따라서 그 값보다 작은 모든 Gradient가 즉시 0이 되는 것은 아니다.

154. 혼동하기 쉬운 부분 — FP16과 BF16

FP16과 BF16은 둘 다 16-bit지만 Dynamic Range가 동일하지 않다.

BF16은 FP16보다 훨씬 넓은 Exponent Range를 가진다.

따라서 Loss Scaling 필요성도 동일하지 않다.

155. 전체 개념 연결

DL-04에서 Forward Graph를 만들었다.

\[\boxed{ x \rightarrow h^{(1)} \rightarrow \cdots \rightarrow L }\]

DL-05에서는 이 Graph를 반대로 따라간다.

\[\boxed{ L \rightarrow \delta^{(L)} \rightarrow \cdots \rightarrow \nabla_\theta L }\]

156. Mathematical Flow

각 Layer에서

\[\boxed{ z^{(l)} = W^{(l)}h^{(l-1)}+b^{(l)} }\]

Backward에서는

\[\boxed{ \delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma_l'(z^{(l)}) }\]

157. Parameter Flow

Error Vector가 계산되면

\[\boxed{ \nabla_{W^{(l)}}L = \delta^{(l)} (h^{(l-1)})^T }\]

이고

\[\boxed{ \nabla_{b^{(l)}}L = \delta^{(l)} }\]

158. Optimization Flow

그 결과

\[\boxed{ \text{Forward} \rightarrow L \rightarrow \text{Backward} \rightarrow \nabla_\theta L \rightarrow \text{Optimizer} }\]

라는 Training Loop가 완성된다.

159. LLM Flow

Transformer에서도

\[\boxed{ \text{Token Input} \rightarrow \text{Transformer Forward} \rightarrow \text{Token NLL} }\]

을 계산하고,

Reverse-mode AD를 통해

\[\boxed{ \text{Token NLL} \rightarrow \text{LM Head} \rightarrow \text{Transformer Blocks} \rightarrow \nabla_\theta L }\]

을 계산한다.

160. 정리

Backpropagation은 Scalar Loss에서 출발하여 Computational Graph를 역방향으로 따라가면서 Chain Rule을 적용해 모든 Learnable Parameter의 Gradient를 계산하는 Algorithm이다.

핵심은

\[\boxed{ \text{local derivative} \times \text{upstream gradient} }\]

를 반복하는 것이다.

Automatic Differentiation은 Program을 Primitive Operation의 Graph로 분해하고 Derivative Rule을 자동 적용한다.

Deep Learning에서는

\[L: \mathbb R^D \rightarrow \mathbb R\]

처럼 매우 많은 Parameter에서 하나의 Scalar Loss로 가기 때문에 Reverse-mode AD가 특히 적합하다.

Forward MLP는

\[\boxed{ z^{(l)} = W^{(l)}h^{(l-1)} + b^{(l)} }\]
\[\boxed{ h^{(l)} = \sigma_l( z^{(l)} ) }\]

로 구성된다.

Pre-activation Error Vector를

\[\boxed{ \delta^{(l)} = \frac{\partial L} {\partial z^{(l)} } }\]

로 정의하면 Backpropagation Recursion은

\[\boxed{ \delta^{(l)} = \left[ ( W^{(l+1)} )^T \delta^{(l+1)} \right] \odot \sigma_l'( z^{(l)} ) }\]

각 Layer의 Weight Gradient는 Outer Product

\[\boxed{ \nabla_{W^{(l)}}L = \delta^{(l)} ( h^{(l-1)} )^T }\]

이고 Bias Gradient는

\[\boxed{ \nabla_{b^{(l)}}L = \delta^{(l)} }\]

원자료의 수치 예제에서는

\[\boxed{ \hat y=0.91 }\]

이고

\[\boxed{ L=0.59405 }\]

Output Delta는

\[\boxed{ \delta^{(2)}=-1.09 }\]

따라서

\[\boxed{ \nabla_{W^{(2)}}L = [-0.545,-1.199] }\]

Hidden Layer로 역전파하면

\[\boxed{ \delta^{(1)} = \begin{bmatrix} -0.545\\ -0.654 \end{bmatrix} }\]

이고

\[\boxed{ \nabla_{W^{(1)}}L = \begin{bmatrix} -0.545&-1.090\\ -0.654&-1.308 \end{bmatrix} }\]

따라서 전체 Training 과정은

\[\boxed{ \text{Forward Propagation} \rightarrow \text{Scalar Loss} \rightarrow \text{Reverse-mode Autodiff} \rightarrow \text{Parameter Gradients} \rightarrow \text{Optimizer Update} }\]

로 이어진다.

대규모 LLM에서는 Reverse-mode가 Forward Activation을 필요로 하기 때문에 Memory 문제가 중요해진다.

Activation Checkpointing은

\[\boxed{ \text{store less} \rightarrow \text{recompute more} }\]

라는 Memory–Compute Trade-off를 사용한다.

Mixed Precision Training에서는 FP16 Gradient Underflow가 문제가 될 수 있으며 Loss Scaling으로

\[\boxed{ L_{\mathrm{scaled}} = S_{\mathrm{loss}}L }\]

를 사용한 뒤 Update 전에 Gradient를 다시 Unscale할 수 있다.

결국 DL-05의 핵심 흐름은

\[\boxed{ \text{Computational Graph} \rightarrow \text{Chain Rule} \rightarrow \text{Reverse-mode Autodiff} \rightarrow \text{Backpropagation} }\]

Transformer/LLM 관점에서는

\[\boxed{ \text{Next-Token Loss} \rightarrow \text{Output Head Gradient} \rightarrow \text{Transformer Block Gradients} \rightarrow \text{Q/K/V, FFN, Norm Parameter Gradients} }\]

로 확장된다.
