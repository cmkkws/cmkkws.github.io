DL-05 — Backpropagation & Auto-Differentiation

계산 그래프에서 기울기를 전달하는 역전파와 자동미분을 다룬다.

ML·딥러닝 · DL-05업데이트 2026.09.21
  • #Backpropagation
  • #Auto-Differentiation
  • #Chain Rule

개념

BackpropagationNeural Network Training에서는 먼저 Forward Propagation을 수행한다.

\[\boxed{ \mathbf x \rightarrow \hat{\mathbf y} \rightarrow L }\]

그다음 Scalar Loss \(L\) 가 각 Parameter에 얼마나 민감한지를 계산한다.

이를 위한 핵심 알고리즘이 Backpropagation

Backpropagation의 목적Parameter를 \(\mathbf{\theta}\) 라고 하면 Training에 필요한 것은 \(\nabla_{\mathbf{\theta}}L\)이다.

즉 모든 Weight와 Bias에 대해 \(\frac{\partial L}{\partial\theta_i}\) 를 계산해야 한다.

Forward와 BackwardForward에서는 Parameters → Activations → Loss 방향으로 계산한다.

Backward에서는 반대로 Loss → Activations → Parameters 방향으로 Derivative를 전달한다.

표기·차원

MLP Forward Setup원자료의 \(L\)-Layer MLP를 생각한다.

Input은 다음과 같다.

\[\boxed{ \mathbf h^{(0)} = \mathbf x \in \mathbb R^{d_0} }\]

Layer Pre-Activation\(l\)번째 Layer에서 다음과 같이 쓴다.

\[\boxed{ \mathbf z^{(l)} = \mathbf W^{(l)} \mathbf h^{(l-1)} + \mathbf b^{(l)} }\]

Weight ShapeColumn-Vector Convention에서 \(\mathbf W^{(l)} \in \mathbb R^{ d_l\times d_{l-1} }\)

Bias Shape\(\mathbf b^{(l)} \in \mathbb R^{d_l}\)

따라서 \(\mathbf z^{(l)} \in \mathbb R^{d_l}\)

Error Vector Shape\(\mathbf z^{(l)} \in \mathbb R^{d_l}\) 이므로 \(\mathbf{\delta}^{(l)} \in \mathbb R^{d_l}\)

핵심 연산

Chain RuleBackpropagation의 수학적 기반은 Chain Rule이다.

Scalar 함수 \(L=L(y), \qquad y=f(x)\) 라면:

\[\boxed{ \frac{dL}{dx} = \frac{dL}{dy} \frac{dy}{dx} }\]

여러 함수의 합성만약 \(x \rightarrow u \rightarrow v \rightarrow L\) 이라는 계산이 있다면:

\[\boxed{ \frac{\partial L}{\partial x} = \frac{\partial L}{\partial v} \frac{\partial v}{\partial u} \frac{\partial u}{\partial x} }\]

Deep Network에서는 이 구조가 수많은 Tensor Operation으로 확장된다.

Computational GraphDL-04에서 Neural Network Forward Pass를 DAG \(\mathcal G=(\mathcal V,\mathcal E)\) 형태의 Computational Graph로 표현했다.

각 Node는 Tensor나 Operation이고 Edge는 Dependency를 나타낸다.

Backpropagation은 이 Graph를 역방향으로 따라간다.

Local Derivative각 Operation은 자신의 Input에 대한 Local Derivative를 계산할 수 있다.

예를 들어 \(y=f(x)\) 이면 Local Derivative는 다음과 같다.

\[\boxed{ \frac{\partial y}{\partial x} }\]

Upstream Gradient현재 Node \(y\)까지 전달된 Gradient를 \(\bar y = \frac{\partial L}{\partial y}\) 라고 생각할 수 있다.

그러면 Input Gradient는 다음과 같다.

\[\boxed{ \frac{\partial L}{\partial x} = \bar y \frac{\partial y}{\partial x} }\]

Reverse Gradient Flow즉 각 Node에서는 \(\text{upstream gradient} \times \text{local derivative}\) 를 계산하여 Parent Node로 전달한다.

이 작업을 Loss에서 Input 방향으로 반복한다.

Backpropagation의 핵심전체 Network를 하나의 거대한 수식으로 먼저 전개한 뒤 미분하는 것이 아니다.

작은 Operation별 Local Derivative를 저장하거나 다시 계산하여 Chain Rule을 효율적으로 적용한다.

Local derivatives + Chain Rule → Global gradients

Differentiation 방법원자료는 미분 방법을 크게 세 가지로 구분한다.

  1. Numerical Differentiation
  2. Symbolic Differentiation
  3. Automatic Differentiation

Numerical Differentiation가장 단순한 Forward Difference는 다음과 같다.

\[\boxed{ f'(x) \approx \frac{ f(x+h)-f(x) }{ h } }\]

작은 \(h\) 를 이용하여 Derivative를 수치적으로 근사한다.

Numerical Differentiation의 근사 오차Finite Difference는 정확한 Symbolic Derivative가 아니다.

\(h\)가 너무 크면 Truncation Error 가 커진다.

Cancellation Error반대로 \(h\)를 지나치게 작게 하면 \(f(x+h)\) 와 \(f(x)\) 가 Floating-Point에서 매우 가까워진다.

두 값을 빼면서 Cancellation / Round-off Error 가 커질 수 있다.

Numerical Gradient 비용Parameter Dimension이 \(D\) 라면 Forward Difference 방식으로 각 Coordinate를 따로 Perturb해야 한다.

원자료의 방식에서는 대략 \(D+1\) 회의 Forward Evaluation이 필요하다.

Numerical Differentiation의 역할따라서 수십억 Parameter를 가진 Network의 Training Gradient를 Numerical Differentiation으로 계산하는 것은 현실적이지 않다.

다만 작은 Model에서 Autograd 결과를 확인하기 위한 Gradient Check 에는 사용할 수 있다.

ActivationActivation Function을 Element-wise 적용한다.

\[\boxed{ \mathbf h^{(l)} = \sigma_l( \mathbf z^{(l)} ) }\]

Final Output마지막 Layer에서 다음과 같이 쓴다.

\[\boxed{ \mathbf h^{(L)} = \hat{\mathbf y} }\]

이 Prediction과 Target을 Loss Function에 넣는다.

Error Vector원자료는 각 Layer의 Pre-activation Gradient를 \(\mathbf{\delta}^{(l)} \equiv \frac{\partial L} {\partial\mathbf z^{(l)} }\) 로 정의한다.

Component Definition\(j\)번째 Component는 다음과 같다.

\[\boxed{ \delta_j^{(l)} = \frac{\partial L} {\partial z_j^{(l)} } }\]

Backpropagation Recursion 목표상위 Layer \(l+1\) 의 \(\mathbf{\delta}^{(l+1)}\) 를 이미 알고 있다고 하자.

목표는 \(\mathbf{\delta}^{(l)}\) 를 구하는 것이다.

Dependency\(z_j^{(l)}\)는 Activation \(h_j^{(l)} = \sigma_l( z_j^{(l)} )\) 을 통해 다음 Layer의 여러 Neuron에 영향을 준다.

Next-Layer Component

\[\boxed{ z_k^{(l+1)} = \sum_{m=1}^{d_l} W_{km}^{(l+1)} h_m^{(l)} + b_k^{(l+1)} }\]

핵심 식 — Error Vector

\[\boxed{ \delta^{(l)} = \frac{\partial L} {\partial z^{(l)} } }\]

핵심 식 — Backprop Recursion

\[\boxed{ \delta^{(l)} = \left[ ( W^{(l+1)} )^T \delta^{(l+1)} \right] \odot \sigma_l'( z^{(l)} ) }\]

핵심 식 — Bias GradientSingle Sample에서는 다음과 같다.

\[\boxed{ \nabla_{b^{(l)}}L = \delta^{(l)} }\]

핵심 식 — Previous Activation Gradient

\[\boxed{ \nabla_{h^{(l-1)}}L = ( W^{(l)} )^T \delta^{(l)} }\]

핵심 식 — Batch Gradient원자료의 Column-Batch Convention과 Mean Reduction에서는 다음과 같다.

\[\boxed{ \nabla_{W^{(l)}}L = \frac1B \Delta^{(l)} ( H^{(l-1)} )^T }\]

성질·유도

Symbolic DifferentiationSymbolic Differentiation은 함수 표현식 자체에 미분 규칙을 적용한다.

예를 들어 \(f(x)=x^2\sin x\) 를 Symbolically Differentiating하면 \(f'(x) = 2x\sin x+x^2\cos x\) 를 얻는다.

Symbolic Expression Growth복잡한 함수 합성에서는 Symbolic Expression이 매우 커질 수 있다.

이를 Expression Swelling 이라고 한다.

Symbolic Differentiation에 대한 주의원자료는 Symbolic Differentiation이 대규모 Neural Network에 적용 불가능하다고 표현한다.

더 정확하게는 대규모 Tensor Program Training에서는 전체 식을 Symbolically 전개하는 방식이 일반적으로 비효율적이므로 Autodiff가 훨씬 적합하다는 의미로 이해한다.

Automatic DifferentiationAutomatic Differentiation은 프로그램을 Primitive Operation의 조합으로 본다.

예:

\[a=xy\]
\[b=\sin a\]

\(L=b^2\) 처럼 작은 연산으로 분해한다.

Primitive Operations각 Primitive Operation은 다음과 같다.

  1. Forward Value
  2. Local Derivative Rule

이 식을 알고 있다.

따라서 프로그램 전체에 Chain Rule을 자동 적용할 수 있다.

Autodiff는 Numerical Differentiation이 아니다Autodiff는 \(\frac{ f(x+h)-f(x) }{ h }\) 처럼 Finite Difference를 이용하지 않는다.

따라서 \(h\) 선택에서 발생하는 Truncation Error를 기본 원리로 사용하지 않는다.

Autodiff는 Symbolic Differentiation도 아니다Autodiff는 전체 Symbolic Formula를 거대하게 전개하는 대신 실제 Computational Graph의 연산에 Local Derivative Rule을 적용한다.

따라서 Automatic Differentiation ≠ Numerical Differentiation 이고 Automatic Differentiation ≠ pure Symbolic Differentiation

Forward-mode Autodiff함수 \(f: \mathbb R^n \rightarrow \mathbb R^m\) 을 생각한다.

Forward-mode는 Input 방향에서 Output 방향으로 Derivative 정보를 함께 전파한다.

Directional DerivativeForward-mode는 특정 Input Direction \(\mathbf v\) 에 대해 \(J_f(\mathbf x)\mathbf v\) 즉 Jacobian-Vector Product, JVP를 효율적으로 계산하는 방식으로 볼 수 있다.

Reverse-mode AutodiffReverse-mode는 먼저 Forward Pass를 수행한 뒤 Output에서 Input 방향으로 Gradient를 전파한다.

이는 \(\mathbf v^TJ_f\) 형태의 Vector-Jacobian Product, VJP와 연결된다.

Scalar OutputDeep Learning Training에서는 일반적으로 Loss가 Scalar다.

\[\boxed{ L: \mathbb R^D \rightarrow \mathbb R }\]

즉 \(m=1\) 이고 Parameter Dimension \(D\) 는 매우 크다.

Reverse-mode가 적합한 이유Scalar Loss에서 모든 Parameter Gradient \(\nabla_\theta L \in \mathbb R^D\) 가 필요하다.

Reverse-mode는 한 번의 Reverse Sweep에서 이 Gradient Vector 전체를 계산할 수 있다.

Forward-mode와 Reverse-mode 직관대략적으로 \(n\ll m \Rightarrow \text{Forward-mode가 유리할 수 있음}\) 이고 \(m\ll n \Rightarrow \text{Reverse-mode가 유리할 수 있음}\) Deep Learning은 후자에 해당한다.

Backpropagation과 Reverse-modeNeural Network에서 사용하는 Backpropagation은 Reverse-mode Automatic Differentiation을 Neural Network Computational Graph에 적용한 대표적인 형태로 이해할 수 있다.

\(\text{Backpropagation} \subset \text{Reverse-mode AD framework}\) 라는 관점이 유용하다.

Computational ComplexityForward Computational Graph가 \(N\) 개의 Primitive Operation으로 구성되어 있다고 생각하자.

Forward Pass의 계산량이 \(O(N)\) 이라면 Reverse Sweep 역시 Local Derivative를 각 연산에 대해 처리하므로 일반적으로 \(O(N)\) 규모의 계산량을 가진다.

“Forward 1회 비용”에 대한 주의원자료는 Reverse-mode가 \(\mathcal O( 1\cdot\text{Forward} )\) 비용으로 모든 Gradient를 완벽히 계산한다고 표현한다.

핵심은 Parameter 수 \(D\)번 Forward를 반복하지 않고 Forward 계산량의 상수배 수준에서 Gradient 전체를 얻는다는 것이다.

정확한 상수배는 Operation과 Implementation에 따라 달라진다.

Time–Memory Trade-offReverse-mode는 계산량 측면에서는 효율적이지만 Backward에서 필요한 Forward Intermediate를 저장해야 한다.

따라서 Reverse-mode efficiency ↔ activation memory 라는 Trade-off가 존재한다.

Activation 대입\(h_m^{(l)} = \sigma_l( z_m^{(l)} )\) 이므로 다음과 같이 쓴다.

\[\boxed{ z_k^{(l+1)} = \sum_m W_{km}^{(l+1)} \sigma_l( z_m^{(l)} ) + b_k^{(l+1)} }\]

Multivariate Chain Rule\(z_j^{(l)}\)에서 Loss까지 여러 경로가 존재한다.

따라서 다음과 같다.

\[\boxed{ \delta_j^{(l)} = \sum_{k=1}^{d_{l+1}} \frac{\partial L} {\partial z_k^{(l+1)}} \frac{ \partial z_k^{(l+1)} }{ \partial z_j^{(l)} } }\]

Upper-Layer Delta 대입정의에 의해:

\[\frac{\partial L} {\partial z_k^{(l+1)}} = \delta_k^{(l+1)}\]

따라서 다음과 같다.

\[\boxed{ \delta_j^{(l)} = \sum_k \delta_k^{(l+1)} \frac{ \partial z_k^{(l+1)} }{ \partial z_j^{(l)} } }\]

Local Derivative\(z_k^{(l+1)} = \sum_m W_{km}^{(l+1)} \sigma_l( z_m^{(l)} ) + b_k^{(l+1)}\) 를 \(z_j^{(l)}\) 로 미분하면 다음과 같다.

\[\boxed{ \frac{ \partial z_k^{(l+1)} }{ \partial z_j^{(l)} } = W_{kj}^{(l+1)} \sigma_l'( z_j^{(l)} ) }\]

Component Recursion대입하면 다음과 같다.

\[\boxed{ \delta_j^{(l)} = \sum_k \delta_k^{(l+1)} W_{kj}^{(l+1)} \sigma_l'( z_j^{(l)} ) }\]

Activation Derivative 분리\(\sigma_l'(z_j^{(l)})\)는 \(k\)에 의존하지 않으므로 다음과 같이 쓴다.

\[\boxed{ \delta_j^{(l)} = \left( \sum_k W_{kj}^{(l+1)} \delta_k^{(l+1)} \right) \sigma_l'( z_j^{(l)} ) }\]

Matrix-Vector Product합 \(\sum_k W_{kj}^{(l+1)} \delta_k^{(l+1)}\) 는 \(( W^{(l+1)} )^T \mathbf{\delta}^{(l+1)}\) 의 \(j\)번째 Component다.

Backpropagation Recursion따라서 다음과 같다.

\[\boxed{ \mathbf{\delta}^{(l)} = \left[ ( \mathbf W^{(l+1)} )^T \mathbf{\delta}^{(l+1)} \right] \odot \sigma_l'( \mathbf z^{(l)} ) }\]

Hadamard Product여기서 \(\odot\) 는 Element-wise Product다.

즉 다음 Layer에서 전달된 Gradient와 현재 Activation Function의 Local Derivative를 Component-wise 곱한다.

Recursion의 직관Backpropagation은 각 Layer에서 \(\text{next-layer error} \rightarrow W^T \rightarrow \text{activation derivative}\) 의 순서로 Gradient를 이전 Layer로 전달한다.

Weight TransposeForward에서는 \(z^{(l+1)} = W^{(l+1)}h^{(l)}+b\) 였다.

Backward에서는 \(( W^{(l+1)} )^T \delta^{(l+1)}\) 가 등장한다.

DL-01의 Linear Layer Backward와 동일한 구조다.

Weight Gradient\(l\)번째 Layer의 \(W_{ij}^{(l)}\) 에 대한 Gradient를 계산한다.

Forward는 다음과 같다.

\[z_i^{(l)} = \sum_j W_{ij}^{(l)} h_j^{(l-1)} + b_i^{(l)}\]

Local Weight Derivative따라서 다음과 같다.

\[\boxed{ \frac{ \partial z_i^{(l)} }{ \partial W_{ij}^{(l)} } = h_j^{(l-1)} }\]

Weight Chain Rule

\[\begin{aligned} \frac{ \partial L }{ \partial W_{ij}^{(l)} } &= \frac{\partial L} {\partial z_i^{(l)}} \frac{ \partial z_i^{(l)} }{ \partial W_{ij}^{(l)} }\\ &= \delta_i^{(l)} h_j^{(l-1)} \end{aligned}\]

Outer Product전체 Weight Gradient는 다음과 같다.

\[\boxed{ \frac{\partial L} {\partial\mathbf W^{(l)} } = \mathbf{\delta}^{(l)} ( \mathbf h^{(l-1)} )^T }\]

Weight Gradient Shape\(\mathbf{\delta}^{(l)} \in \mathbb R^{d_l}\) 이고 \(( h^{(l-1)} )^T \in \mathbb R^{1\times d_{l-1}}\) 이므로 \(\nabla_{W^{(l)}}L \in \mathbb R^{ d_l\times d_{l-1} }\) Weight 자체의 Shape과 같다.

Bias Gradient\(\frac{ \partial z_i^{(l)} }{ \partial b_i^{(l)} } = 1\) 이므로 다음과 같이 쓴다.

\[\boxed{ \frac{\partial L} {\partial\mathbf b^{(l)} } = \mathbf{\delta}^{(l)} }\]

Single Sample 기준이다.

Input-Activation GradientPre-activation \(z^{(l)} = W^{(l)}h^{(l-1)}+b\) 에서 이전 Activation으로 전달되는 Gradient는 다음과 같다.

\[\boxed{ \frac{\partial L} {\partial h^{(l-1)} } = ( W^{(l)} )^T \mathbf{\delta}^{(l)} }\]

Single-Sample Backward Summary하나의 Layer에 대해 \(z=Wh+b\) 이면 다음과 같다.

\[\boxed{ \nabla_WL = \delta h^T }\]
\[\boxed{ \nabla_bL = \delta }\]
\[\boxed{ \nabla_hL = W^T\delta }\]

Mini-Batch Convention원자료의 Batch 일반화에서는 Sample을 Column으로 둔다 (\(H^{(l-1)} \in \mathbb R^{ d_{l-1}\times B }\)).

Batch Delta\(\Delta^{(l)} \in \mathbb R^{ d_l\times B }\)

각 Column이 한 Sample의 \(\delta^{(l)}\) 에 해당한다.

Mean-Loss Weight GradientBatch Loss를 Sample Average로 정의하면 다음과 같다.

\[\boxed{ \frac{\partial L} {\partial W^{(l)} } = \frac1B \Delta^{(l)} ( H^{(l-1)} )^T }\]

Reduction 방식 주의앞의 \(\frac1B\) 는 Loss가 Batch Mean으로 정의되었을 때 등장한다.

Loss가 Batch Sum이면 \(\nabla_WL = \Delta H^T\) 형태가 된다.

DL-01 Convention과 비교DL-01에서는 Sample을 Row로 쌓아 \(X\in\mathbb R^{B\times d_{\mathrm{in}}}\) 으로 두었다.

그때는 \(\nabla_WL = X^TG\) 였다.

현재 식과 Transpose 위치가 달라 보이는 이유는 Batch Orientation Convention이 다르기 때문이다.

혼동하기 쉬운 부분

  • Backpropagation과 Gradient Descent:Backpropagation은 Parameter를 Update하는 Algorithm이 아니다.

    Backpropagation: \(\nabla_\theta L \text{ 계산}\) Optimizer: \(\theta \text{ 업데이트}\)

  • Autodiff와 Backpropagation:Autodiff는 프로그램의 Derivative를 자동 계산하는 더 일반적인 Framework다.

    Backpropagation은 Neural Network에서 Reverse-mode AD를 수행하는 대표적인 Algorithmic Procedure다.

  • Numerical Differentiation:Autodiff는 작은 \(h\)를 선택해 Finite Difference를 계산하지 않는다.

    따라서 Autodiff를 Numerical Differentiation과 같은 방식으로 이해하면 안 된다.

  • \(O(N)\):Backpropagation의 \(O(N)\) 은 일반적으로 Graph의 Primitive Operation 수에 선형적인 Reverse Sweep을 뜻한다.

    Parameter 수나 Tensor 크기를 무시하고 모든 Operation을 동일 비용으로 보는 단순한 설명으로 받아들여야 한다.

    실제 FLOPs는 Matrix Size에 따라 결정된다.

  • 한 번의 Backward:한 번의 Reverse Sweep으로 모든 Parameter Gradient를 얻을 수 있다는 것이 Reverse-mode의 핵심이다.

    하지만 Backward cost = exactly one Forward cost 라고 보편적으로 고정되는 것은 아니다.

  • Intermediate Activation:Backward를 위해 항상 모든 Forward Tensor를 그대로 보존하는 것은 아니다.

    Autograd는 필요한 Tensor를 선택적으로 저장할 수 있고 Checkpointing은 일부 Tensor를 재계산한다.

  • ReLU at Zero:ReLU는 다음과 같다.

    \[\operatorname{ReLU}(z) = \max(0,z)\]

    \(z=0\)에서는 Classical Derivative가 정의되지 않는다.

    Framework는 Backpropagation을 위해 특정 Subgradient Convention을 선택한다.

    이번 원자료 예제에서는 \(z=0\)이 없으므로 문제가 발생하지 않는다.

  • \(\delta\):\(\delta^{(l)}\) 는 Target Error 자체가 아니다.

    정의는 다음과 같다.

    \[\boxed{ \delta^{(l)} = \frac{\partial L} {\partial z^{(l)} } }\]

    즉 Pre-activation에 대한 Loss Gradient다.

  • Batch Orientation:Sample을 Row로 쌓느냐 Column으로 쌓느냐에 따라 \(X^TG\) 또는 \(\Delta H^T\) 처럼 Formula의 Transpose 위치가 달라질 수 있다.

    항상 Tensor Shape을 확인해야 한다.

  • Activation Memory:대규모 LLM에서 Activation Memory는 중요한 Bottleneck이 될 수 있지만 모든 설정에서 Parameter/Optimizer Memory보다 반드시 크다고 일반화하지 않는다.

  • \(O(\sqrt L)\) Checkpointing:Checkpointing의 \(O(\sqrt L)\) Memory Result는 특정 전략에서 나타나는 대표적 결과다.

    Checkpoint Granularity에 따라 다른 Trade-off가 가능하다.

  • FP16 Range:\(6.1\times10^{-5}\)

    근처는 FP16의 smallest positive normal value다.

    그 아래에 Subnormal Range가 존재한다.

    따라서 그 값보다 작은 모든 Gradient가 즉시 0이 되는 것은 아니다.

  • FP16과 BF16:FP16과 BF16은 둘 다 16-bit지만 Dynamic Range가 동일하지 않다.

    BF16은 FP16보다 훨씬 넓은 Exponent Range를 가진다.

    따라서 Loss Scaling 필요성도 동일하지 않다.

    Backpropagation은 Scalar Loss에서 출발하여 Computational Graph를 역방향으로 따라가면서 Chain Rule을 적용해 모든 Learnable Parameter의 Gradient를 계산하는 Algorithm이다.

    핵심은 \(\text{local derivative} \times \text{upstream gradient}\) 를 반복하는 것이다.

    Automatic Differentiation은 Program을 Primitive Operation의 Graph로 분해하고 Derivative Rule을 자동 적용한다.

    Deep Learning에서는 \(L: \mathbb R^D \rightarrow \mathbb R\) 처럼 매우 많은 Parameter에서 하나의 Scalar Loss로 가기 때문에 Reverse-mode AD가 특히 적합하다.

    Forward MLP는 다음과 같다.

    \[\boxed{ z^{(l)} = W^{(l)}h^{(l-1)} + b^{(l)} }\]

    \(h^{(l)} = \sigma_l( z^{(l)} )\) 로 구성된다.

    Pre-activation Error Vector를 \(\delta^{(l)} = \frac{\partial L} {\partial z^{(l)} }\) 로 정의하면 Backpropagation Recursion은 다음과 같다.

    \[\boxed{ \delta^{(l)} = \left[ ( W^{(l+1)} )^T \delta^{(l+1)} \right] \odot \sigma_l'( z^{(l)} ) }\]

    각 Layer의 Weight Gradient는 Outer Product \(\nabla_{W^{(l)}}L = \delta^{(l)} ( h^{(l-1)} )^T\) 이고 Bias Gradient는 다음과 같다.

    \[\boxed{ \nabla_{b^{(l)}}L = \delta^{(l)} }\]

    원자료의 수치 예제에서는 \(\hat y=0.91\) 이고:

    \[\boxed{ L=0.59405 }\]

    Output Delta는 다음과 같다.

    \[\boxed{ \delta^{(2)}=-1.09 }\]

    따라서 다음과 같다.

    \[\boxed{ \nabla_{W^{(2)}}L = [-0.545,-1.199] }\]

    Hidden Layer로 역전파하면 다음과 같다.

    \[\boxed{ \delta^{(1)} = \begin{bmatrix} -0.545\\ -0.654 \end{bmatrix} }\]

    \(\delta^{(1)}\)이 성립하고, :

    \[\boxed{ \nabla_{W^{(1)}}L = \begin{bmatrix} -0.545&-1.090\\ -0.654&-1.308 \end{bmatrix} }\]

    따라서 전체 Training 과정은 Forward Propagation → Scalar Loss → Reverse-mode Autodiff → Parameter Gradients → Optimizer Update 로 이어진다.

    대규모 LLM에서는 Reverse-mode가 Forward Activation을 필요로 하기 때문에 Memory 문제가 중요해진다.

    Activation Checkpointing은 store less → recompute more 라는 Memory–Compute Trade-off를 사용한다.

    Mixed Precision Training에서는 FP16 Gradient Underflow가 문제가 될 수 있으며 Loss Scaling으로 \(L_{\mathrm{scaled}} = S_{\mathrm{loss}}L\) 를 사용한 뒤 Update 전에 Gradient를 다시 Unscale할 수 있다.

    결국 DL-05의 핵심 흐름은 Computational Graph → Chain Rule → Reverse-mode Autodiff → Backpropagation이다.

    Transformer/LLM 관점에서는 Next-Token Loss → Output Head Gradient → Transformer Block Gradients → Q/K/V, FFN, Norm Parameter Gradients 로 확장된다.

FP16 Gradient UnderflowBackward Gradient가 매우 작아지면 FP16의 표현 가능한 Range 아래로 떨어질 수 있다.

그러면 작은 Gradient가 0으로 Rounded될 수 있다.

이를 Gradient Underflow 라고 한다.

FP16 Range의 정확한 구분FP16의 가장 작은 positive normal 값은 약 \(6.10\times10^{-5}\) 하지만 Subnormal까지 포함하면 약 \(5.96\times10^{-8}\) 까지 표현할 수 있다.

따라서 원자료의 “\(6.5\times10^{-5}\) 미만이면 모두 Underflow”라는 표현은 정확하지 않다.

Loss Scaling작은 FP16 Gradient가 Underflow되는 것을 줄이기 위해 Loss에 큰 Scale Factor를 곱할 수 있다.

\[\boxed{ L_{\mathrm{scaled}} = S_{\mathrm{loss}}L }\]

Gradient ScalingDerivative의 선형성에 의해:

\[\boxed{ \nabla_\theta L_{\mathrm{scaled}} = S_{\mathrm{loss}} \nabla_\theta L }\]

따라서 Backward 중 Gradient Magnitude가 커진다.

UnscalingOptimizer Update 전에 다시 \(S_{\mathrm{loss}}\) 로 나눈다.

\[\boxed{ \nabla_\theta L = \frac1{ S_{\mathrm{loss}} } \nabla_\theta L_{\mathrm{scaled}} }\]

Dynamic Loss Scaling고정된 Scale이 너무 크면 Overflow가 발생할 수 있다.

따라서 실제 Mixed-Precision Training에서는 Overflow 여부에 따라 Scale을 동적으로 조정하는 Dynamic Loss Scaling 을 사용할 수 있다.

BF16과 Loss ScalingBF16은 FP16보다 Mantissa Precision은 낮지만 Exponent Range는 FP32와 유사하다.

따라서 Gradient Underflow 측면에서 FP16보다 훨씬 넓은 Dynamic Range를 가진다.

결과적으로 BF16 Training에서는 FP16만큼 Loss Scaling이 필수적이지 않은 경우가 많다.

Vanishing Gradient와 Underflow의 차이두 현상을 구분해야 한다.

Vanishing GradientChain Rule과 Jacobian Product 때문에 Gradient Magnitude 자체가 수학적으로 매우 작아지는 현상.

Numerical Underflow이미 작은 Gradient가 Floating-Point Format의 표현 범위 때문에 0으로 사라지는 현상.

각 Operation의 Local Derivative를 Reverse-mode로 연결한다.

Q/K/V Gradient예를 들어 \(Q=XW_Q\) 이면 \(\nabla_{W_Q}L = X^T\nabla_QL\) 이고:

\[\boxed{ \nabla_XL\big|_Q = \nabla_QL\,W_Q^T }\]

\[\boxed{ \nabla_XL = \nabla_XL\big|_Q + \nabla_XL\big|_K + \nabla_XL\big|_V + \cdots }\]

\[\boxed{ x \rightarrow h^{(1)} \rightarrow \cdots \rightarrow L }\]

\[\boxed{ L \rightarrow \delta^{(L)} \rightarrow \cdots \rightarrow \nabla_\theta L }\]

Mathematical Flow각 Layer에서 다음과 같이 쓴다.

\[\boxed{ z^{(l)} = W^{(l)}h^{(l-1)}+b^{(l)} }\]

Backward에서는 다음과 같다.

\[\boxed{ \delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma_l'(z^{(l)}) }\]

Parameter FlowError Vector가 계산되면 \(\nabla_{W^{(l)}}L = \delta^{(l)} (h^{(l-1)})^T\) 이고:

\[\boxed{ \nabla_{b^{(l)}}L = \delta^{(l)} }\]

Optimization Flow그 결과 \(\text{Forward} \rightarrow L \rightarrow \text{Backward} \rightarrow \nabla_\theta L \rightarrow \text{Optimizer}\) 라는 Training Loop가 완성된다.

LLM FlowTransformer에서도 Token Input → Transformer Forward → Token NLL 을 계산하고, Reverse-mode AD를 통해 \(\text{Token NLL} \rightarrow \text{LM Head} \rightarrow \text{Transformer Blocks} \rightarrow \nabla_\theta L\) 을 계산한다.

정리

Backpropagation은 computational graph를 거꾸로 따라가며 chain rule로 각 parameter에 대한 loss gradient를 계산한다. Reverse-mode automatic differentiation은 scalar loss 하나에서 많은 입력·parameter의 미분을 효율적으로 모으지만, 계산 순서와 저장된 중간값이 메모리 비용을 만든다.
