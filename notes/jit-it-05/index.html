IT-05 — Conditional Entropy

Conditional Entropy의 정의와 조건부 불확실성, 관련 성질을 정리한다.

정보이론 · IT-05업데이트 2026.09.18
  • #Conditional Entropy
  • #Conditional Distribution
  • #Uncertainty

개념

Conditional Entropy — 두 이산 확률변수

\[X\in\mathcal X, \qquad Y\in\mathcal Y\]

를 생각한다. \(X\)의 값을 이미 관측하여 알고 있을 때 \(Y\)에 여전히 남아 있는 평균적인 불확실성을 Conditional Entropy라고 한다. \(\boxed{ H(Y\mid X) }\) 핵심 직관은

\[\boxed{ \text{Observe }X \rightarrow \text{Remaining uncertainty about }Y }\]

Entropy에서 Conditional Entropy로 — Shannon Entropy는 \(Y\) 자체의 불확실성을 측정한다.

\[\boxed{ H(Y) = -\sum_y p(y)\log_2p(y) }\]

Conditional Entropy는 추가 정보 \(X\) 를 알고 있는 상태에서 \(Y\)의 불확실성을 측정한다. \(\boxed{ H(Y\mid X) }\) 따라서

\[\boxed{ H(Y) = \text{uncertainty before observing }X }\]
\[\boxed{ H(Y\mid X) = \text{residual uncertainty after observing }X }\]

로 구분할 수 있다.

표기·차원

Conditional Probability — \(X=x\)가 주어졌을 때 \(Y=y\)의 조건부 확률은

\[\boxed{ p(y\mid x) = \frac{ p(x,y) }{ p(x) } }\]

단, \(p(x)>0\) 인 경우를 생각한다. Conditional Entropy는 바로 이 조건부 분포 \(p(y\mid x)\) 를 사용한다.

Conditional Self-Information — \(X=x\)를 이미 알고 있는 상황에서 \(Y=y\)가 관측되었을 때의 정보량은

\[\boxed{ I(y\mid x) = -\log_2p(y\mid x) }\]

Conditional Entropy는 이 Conditional Self-Information의 평균이다.

핵심 연산

Conditional Entropy Definition — 정의는

\[\boxed{ H(Y\mid X) = -\sum_{x\in\mathcal X} \sum_{y\in\mathcal Y} p(x,y) \log_2p(y\mid x) }\]

Expectation 형태로는

\[\boxed{ H(Y\mid X) = \mathbb E_{(X,Y)\sim p(x,y)} [ -\log_2p(Y\mid X) ] }\]

왜 Joint Probability로 가중하는가 — Conditional Self-Information은 \(-\log p(y\mid x)\) 하지만 실제 평균을 계산할 때는 Pair \((x,y)\) 가 발생하는 Probability가 필요하다. 그 Probability는 \(\boxed{ p(x,y) }\) 따라서

\[H(Y\mid X) = \sum_{x,y} p(x,y) I(y\mid x)\]

형태가 된다.

Fixed \(X=x\) Conditional Entropy — 특정 \(X=x\)가 주어졌다고 하자. 이때 \(Y\)의 Conditional Distribution은 \(p(y\mid x)\) 이 Distribution 자체의 Shannon Entropy는

\[\boxed{ H(Y\mid X=x) = -\sum_y p(y\mid x) \log_2p(y\mid x) }\]

Conditional Entropy as Weighted Average — 전체 Conditional Entropy는 각 \(x\)별 Entropy를 \(p(x)\)로 가중평균한 값이다.

\[\boxed{ H(Y\mid X) = \sum_x p(x) H(Y\mid X=x) }\]

즉

\[\boxed{ \text{Conditional Entropy} = \text{average of context-specific entropies} }\]

Weighted-Average Form 완전 전개 —

\[H(Y\mid X) = \sum_x p(x) H(Y\mid X=x)\]

에

\[H(Y\mid X=x) = -\sum_y p(y\mid x) \log_2p(y\mid x)\]

를 대입한다. 그러면

\[\boxed{ H(Y\mid X) = \sum_x p(x) \left[ -\sum_y p(y\mid x) \log_2p(y\mid x) \right] }\]

Joint Form과의 동치 — 조건부 확률의 Product Rule에 의해 \(\boxed{ p(x)p(y\mid x) = p(x,y) }\) 따라서

\[\begin{aligned} H(Y\mid X) &= -\sum_x\sum_y p(x)p(y\mid x) \log_2p(y\mid x)\\ &= \boxed{ -\sum_x\sum_y p(x,y) \log_2p(y\mid x) } \end{aligned}\]

두 정의가 정확히 같다.

핵심 식 정리 — Definition —

Conditional Entropy —

\[\boxed{ H(Y\mid X) = -\sum_x\sum_y p(x,y) \log_2 p(y\mid x) }\]

Expectation Form —

\[\boxed{ H(Y\mid X) = \mathbb E[ -\log_2p(Y\mid X) ] }\]

Weighted Form —

\[\boxed{ H(Y\mid X) = \sum_x p(x) H(Y\mid X=x) }\]

핵심 식 정리 — Bounds — \(\boxed{ 0 \le H(Y\mid X) \le H(Y) }\) 독립이면 \(\boxed{ H(Y\mid X) = H(Y) }\) 이고 결정론적이면

\[\boxed{ Y=f(X) \Rightarrow H(Y\mid X)=0 }\]

핵심 식 정리 — Mutual Information — \(\boxed{ H(Y)-H(Y\mid X) = I(X;Y) }\) 이고

\[\boxed{ I(X;Y) = D_{KL} \left( p(x,y) \| p(x)p(y) \right) }\]

따라서 \(\boxed{ H(Y\mid X) = H(Y)-I(X;Y) }\)

핵심 식 정리 — Chain Rule — \(\boxed{ H(X,Y) = H(X) + H(Y\mid X) }\) 이고 \(\boxed{ H(X,Y) = H(Y) + H(X\mid Y) }\)

핵심 식 정리 — LLM — Autoregressive Next-Token Conditional Entropy는 \(\boxed{ H( Y_t\mid Y_{<t} ) }\) 특정 Prefix에서는

\[\boxed{ H( Y_t\mid Y_{<t}=y_{<t} ) = - \sum_{y_t} P( y_t\mid y_{<t} ) \log P( y_t\mid y_{<t} ) }\]

핵심 식 정리 — Cross-Entropy —

\[\boxed{ \mathbb E_P[ -\log Q_\theta( Y\mid X ) ] = H_P(Y\mid X) + \mathbb E_X D_{KL} \left( P(Y\mid X) \| Q_\theta(Y\mid X) \right) }\]

따라서

\[\boxed{ \text{Cross-Entropy} \ge \text{Conditional Entropy} }\]

성질·유도

Conditional Entropy의 범위 — 이산 확률변수에서 Conditional Entropy는 비음수다. \(\boxed{ H(Y\mid X)\ge0 }\) 그리고 원자료의 핵심 정리에 의해 \(\boxed{ H(Y\mid X) \le H(Y) }\) 따라서 \(\boxed{ 0 \le H(Y\mid X) \le H(Y) }\)

Independent Case — \(X\)와 \(Y\)가 독립이면 \(\boxed{ p(y\mid x) = p(y) }\) for all relevant \(x,y\)이다. 따라서 \(X\)를 알아도 \(Y\)의 Distribution이 변하지 않는다. Conditional Entropy는 \(\boxed{ H(Y\mid X) = H(Y) }\)

Independence의 의미 — 독립에서는 \(X\) 가 \(Y\)를 예측하는 데 추가 정보를 제공하지 않는다. 따라서

\[\boxed{ \text{observe }X \rightarrow \text{no reduction in uncertainty about }Y }\]

이고 \(\boxed{ H(Y)-H(Y\mid X)=0 }\)

Deterministic Case — 반대로 \(Y\)가 \(X\)의 결정론적 함수라고 하자. \(\boxed{ Y=f(X) }\) \(X=x\)를 알면 \(Y\)의 값도 정확히 결정된다. 따라서 각 \(x\)에 대해 Conditional Distribution은 하나의 값에 Probability 1을 가진다.

Deterministic Conditional Entropy — Deterministic Distribution의 Entropy는 0이므로 \(\boxed{ H(Y\mid X=x)=0 }\) for every \(x\)이다. 따라서 \(\boxed{ H(Y\mid X)=0 }\)

두 극단 — Conditional Entropy의 두 대표적인 극단은 다음과 같다.

Independence —

\[\boxed{ X\perp Y \Rightarrow H(Y\mid X)=H(Y) }\]

Deterministic Dependence —

\[\boxed{ Y=f(X) \Rightarrow H(Y\mid X)=0 }\]

Conditioning Reduces Entropy — 원자료의 핵심 정리는 \(\boxed{ H(Y\mid X) \le H(Y) }\) 즉 평균적으로 \(X\)에 대해 조건화한 뒤 남은 \(Y\)의 불확실성은 \(Y\)를 아무 정보 없이 볼 때의 불확실성을 넘지 않는다.

Equality Condition — 등호 \(H(Y\mid X)=H(Y)\) 가 성립하는 조건은 \(\boxed{ X\perp Y }\) 즉 모든 relevant \(x,y\)에 대해 \(\boxed{ p(x,y) = p(x)p(y) }\) 인 경우다.

증명의 시작 — 다음 Difference를 계산한다. \(\boxed{ H(Y)-H(Y\mid X) }\) 정의를 대입하면

\[\begin{aligned} H(Y)-H(Y\mid X) &= -\sum_y p(y)\log_2p(y)\\ &\quad+ \sum_x\sum_y p(x,y)\log_2p(y\mid x) \end{aligned}\]

Marginal Probability 사용 — Marginal Probability는

\[\boxed{ p(y) = \sum_x p(x,y) }\]

따라서 첫 번째 항을 Double Sum으로 변환할 수 있다.

\[\boxed{ -\sum_y p(y)\log_2p(y) = -\sum_x\sum_y p(x,y)\log_2p(y) }\]

Double Sum 통합 — 따라서

\[\begin{aligned} H(Y)-H(Y\mid X) &= -\sum_x\sum_y p(x,y)\log_2p(y)\\ &\quad+ \sum_x\sum_y p(x,y)\log_2p(y\mid x) \end{aligned}\]

하나의 Sum으로 묶으면

\[\boxed{ H(Y)-H(Y\mid X) = \sum_x\sum_y p(x,y) [ \log_2p(y\mid x) - \log_2p(y) ] }\]

Log Ratio — Logarithm의 차는 Ratio의 Log다.

\[\log a-\log b = \log\frac ab\]

이므로

\[\boxed{ H(Y)-H(Y\mid X) = \sum_x\sum_y p(x,y) \log_2 \frac{ p(y\mid x) }{ p(y) } }\]

Conditional Probability 대입 —

\[p(y\mid x) = \frac{ p(x,y) }{ p(x) }\]

를 대입한다. 그러면

\[\frac{ p(y\mid x) }{ p(y) } = \frac{ p(x,y) }{ p(x)p(y) }\]

따라서

\[\boxed{ H(Y)-H(Y\mid X) = \sum_x\sum_y p(x,y) \log_2 \frac{ p(x,y) }{ p(x)p(y) } }\]

KL Divergence 연결 — 우변은 \(p(x,y)\) 와 \(p(x)p(y)\) 사이의 KL Divergence다. 따라서

\[\boxed{ H(Y)-H(Y\mid X) = D_{KL} \left( p(x,y) \| p(x)p(y) \right) }\]

Mutual Information — 이 Quantity는 두 변수 사이의 Mutual Information으로 정의된다.

\[\boxed{ I(X;Y) = D_{KL} \left( p(x,y) \| p(x)p(y) \right) }\]

따라서 \(\boxed{ I(X;Y) = H(Y)-H(Y\mid X) }\)

Conditional Entropy와 Mutual Information — 앞 식을 재배열하면 \(\boxed{ H(Y\mid X) = H(Y)-I(X;Y) }\) 즉

  • 원래 \(Y\)의 불확실성: \(H(Y)\)
  • \(X\)가 제공하는 정보: \(I(X;Y)\)
  • 남은 불확실성: \(H(Y\mid X)\)

로 분해할 수 있다.

핵심 정보 분해 — 개념적으로

\[\boxed{ \text{Original uncertainty} - \text{information obtained from }X = \text{residual uncertainty} }\]

즉 \(\boxed{ H(Y) - I(X;Y) = H(Y\mid X) }\)

KL Non-Negativity — KL Divergence는 항상 비음수다. \(\boxed{ D_{KL}(P\|Q)\ge0 }\) 따라서 \(H(Y)-H(Y\mid X) \ge0\) 식을 정리하면 \(\boxed{ H(Y\mid X) \le H(Y) }\) 가 증명된다.

Equality Condition 유도 — 등호가 성립하려면

\[D_{KL} \left( p(x,y) \| p(x)p(y) \right) = 0\]

이어야 한다. KL Divergence가 0이 되려면 두 Distribution이 동일해야 하므로 \(\boxed{ p(x,y) = p(x)p(y) }\) 즉 \(\boxed{ X\perp Y }\)

IT-04와의 연결 — IT-04에서는

\[\boxed{ H(X)+H(Y)-H(X,Y) = D_{KL} \left( p(x,y) \| p(x)p(y) \right) }\]

를 얻었다. IT-05에서는

\[\boxed{ H(Y)-H(Y\mid X) = D_{KL} \left( p(x,y) \| p(x)p(y) \right) }\]

를 얻는다. 따라서

\[\boxed{ H(X)+H(Y)-H(X,Y) = H(Y)-H(Y\mid X) }\]

Chain Rule of Entropy와 연결 — 앞 식을 정리하면 \(H(X,Y) = H(X)+H(Y\mid X)\) 를 얻는다. 즉 \(\boxed{ H(X,Y) = H(X) + H(Y\mid X) }\) 이는 Joint Entropy를

  1. 먼저 \(X\)를 기술하는 데 필요한 정보
  2. \(X\)를 알고 난 뒤 \(Y\)를 추가로 기술하는 데 필요한 정보

로 분해하는 형태다.

Symmetric Chain Rule — 같은 방식으로 순서를 바꾸면 \(\boxed{ H(X,Y) = H(Y) + H(X\mid Y) }\) 따라서

\[\boxed{ H(X)+H(Y\mid X) = H(Y)+H(X\mid Y) }\]

혼동하기 쉬운 부분 — Conditioning — \(H(Y\mid X)\) 는 특정 \(x\) 하나에 대한 Entropy가 아니다. 각 조건별 Entropy \(H(Y\mid X=x)\) 를 \(p(x)\)로 평균한 값이다.

\[\boxed{ H(Y\mid X) = \sum_x p(x)H(Y\mid X=x) }\]

혼동하기 쉬운 부분 — 특정 관측값 — 평균적으로는 \(H(Y\mid X)\le H(Y)\) 가 성립하지만 특정 조건값 \(x\)에서는 \(H(Y\mid X=x)\) 가 \(H(Y)\)보다 클 수도 있다. 정리가 보장하는 것은 \(X\) 전체에 대해 평균한 Conditional Entropy다.

혼동하기 쉬운 부분 — Independence — \(H(Y\mid X)=H(Y)\) 라는 것은 \(X\)를 관측해도 평균적으로 \(Y\)에 대한 정보가 추가되지 않는다는 뜻이다. 이는 \(\boxed{ I(X;Y)=0 }\) 과 같고, 이산형 표준 설정에서는 \(\boxed{ X\perp Y }\) 와 연결된다.

혼동하기 쉬운 부분 — Deterministic Relation — \(H(Y\mid X)=0\) 이면 \(X\)를 알고 난 뒤 \(Y\)에 평균적인 불확실성이 남지 않는다. 원자료의 대표적인 경우는 \(\boxed{ Y=f(X) }\) 이때 각 \(x\)에 대응하는 \(y\)가 확정적으로 결정된다.

혼동하기 쉬운 부분 — Context Length — 정보이론의 \(H(Y\mid X,Z)\le H(Y\mid X)\) 는 true distribution에 대한 평균적인 Entropy 관계다. 이를 곧바로

\[\boxed{ \text{more prompt tokens} \Rightarrow \text{always better LLM answer} }\]

로 해석하면 안 된다. 추가 Context가 실제로 관련 정보를 담고 있는지, 모델이 그것을 활용할 수 있는지는 별도의 문제다.

혼동하기 쉬운 부분 — Cross-Entropy — Conditional Entropy와 Cross-Entropy는 같은 개념이 아니다. 참 Distribution \(P\)만 사용하면 \(\boxed{ H_P(Y\mid X) }\) 모델 Distribution \(Q_\theta\)를 사용하면 \(\boxed{ \mathcal H(P,Q_\theta) }\) 그 차이는

\[\boxed{ \mathbb E_X D_{KL} ( P(\cdot\mid X) \| Q_\theta(\cdot\mid X) ) }\]

Conditional Entropy는 \(X\)를 알고 난 뒤 \(Y\)에 남는 평균적인 불확실성을 측정한다.

\[\boxed{ H(Y\mid X) = -\sum_x\sum_y p(x,y) \log_2p(y\mid x) }\]

이는 각 \(x\)에 대한 Conditional Entropy의 가중평균과 같다.

\[\boxed{ H(Y\mid X) = \sum_x p(x) H(Y\mid X=x) }\]

\(X,Y\)가 독립이면 \(\boxed{ p(y\mid x)=p(y) }\) 이므로 \(\boxed{ H(Y\mid X)=H(Y) }\) 반대로 \(Y\)가 \(X\)의 결정론적 함수이면 \(\boxed{ H(Y\mid X)=0 }\) Conditional Entropy의 핵심 정리는 \(\boxed{ H(Y\mid X)\le H(Y) }\) 두 값의 차이를 전개하면

\[\boxed{ H(Y)-H(Y\mid X) = \sum_{x,y} p(x,y) \log_2 \frac{ p(x,y) }{ p(x)p(y) } }\]

이는

\[\boxed{ D_{KL} \left( p(x,y) \| p(x)p(y) \right) }\]

이며 동시에 Mutual Information이다. \(\boxed{ I(X;Y) = H(Y)-H(Y\mid X) }\) 따라서 \(\boxed{ H(Y\mid X) = H(Y)-I(X;Y) }\) IT-04의 Joint Entropy와 결합하면 Entropy Chain Rule을 얻는다. \(\boxed{ H(X,Y) = H(X) + H(Y\mid X) }\) 원자료의 수치 예제에서는

\[\boxed{ H(Y\mid X=t_1) = 0.7219\text{ bits} }\]
\[\boxed{ H(Y\mid X=t_2) = 0.9710\text{ bits} }\]

이고

\[\boxed{ H(Y\mid X) = 0.8465\text{ bits} }\]

반면 \(\boxed{ H(Y) = 0.9710\text{ bits} }\) 이므로

\[\boxed{ H(Y)-H(Y\mid X) = 0.1245\text{ bits} }\]

만큼 불확실성이 감소한다. 이 값이 바로 \(\boxed{ I(X;Y) }\) Autoregressive LLM에서는 이전 Token Sequence \(Y_{<t}\) 가 조건이 되고 다음 Token \(Y_t\) 의 평균적인 잔여 불확실성을 \(\boxed{ H(Y_t\mid Y_{<t}) }\) 로 표현할 수 있다. Training에서 모델의 Conditional Distribution을 \(Q_\theta( Y_t\mid Y_{<t} )\) 라고 하면 Expected Cross-Entropy는

\[\boxed{ \mathbb E[ \mathcal L_{CE} ] = H_P( Y_t\mid Y_{<t} ) + \mathbb E_{Y_{<t}} D_{KL} \left( P( Y_t\mid Y_{<t} ) \| Q_\theta( Y_t\mid Y_{<t} ) \right) }\]

로 분해된다. 따라서 LLM 관점의 전체 흐름은

\[\boxed{ \text{Context} \rightarrow \text{Conditional Distribution} \rightarrow \text{Conditional Entropy} \rightarrow \text{Residual Next-Token Uncertainty} }\]

Training 관점에서는

\[\boxed{ \text{True Conditional Entropy} + \text{Model Distribution Error} = \text{Expected Cross-Entropy} }\]

로 연결된다. 정보이론 전체의 흐름으로 보면

\[\boxed{ \text{Self-Information} \rightarrow \text{Entropy} \rightarrow \text{Joint Entropy} \rightarrow \text{Conditional Entropy} }\]

이며 다음 단계에서 \(\boxed{ H(Y)-H(Y\mid X) }\) 를 독립적인 핵심 Quantity인 Mutual Information으로 본격적으로 다룰 수 있다.

예제·적용

Numerical Example — Joint Distribution — 원자료의 Joint Distribution은 다음과 같다.

Conditional Probability for \(t_1\) — \(p(t_1)=0.5\) 따라서

\[\begin{aligned} p(u_1\mid t_1) &= \frac{ p(t_1,u_1) }{ p(t_1) }\\ &= \frac{0.4}{0.5}\\ &= \boxed{0.8} \end{aligned}\]

그리고

\[\boxed{ p(u_2\mid t_1) = \frac{0.1}{0.5} = 0.2 }\]

Conditional Distribution for \(t_1\) — 따라서 \(\boxed{ p(Y\mid X=t_1) = [0.8,0.2] }\) 이 Distribution의 Entropy를 계산한다.

\(H(Y\mid X=t_1)\) —

\[H(Y\mid X=t_1) = - [ 0.8\log_20.8 + 0.2\log_20.2 ]\]

근사값은 \(\log_20.8 \approx -0.3219\) \(\log_20.2 \approx -2.3219\) 따라서

\[\begin{aligned} H(Y\mid X=t_1) &\approx -[0.8(-0.3219)+0.2(-2.3219)]\\ &= 0.2575+0.4644\\ &= \boxed{ 0.7219\text{ bits} } \end{aligned}\]

Conditional Probability for \(t_2\) — \(p(t_2)=0.5\) 따라서

\[\boxed{ p(u_1\mid t_2) = \frac{0.2}{0.5} = 0.4 }\]

그리고

\[\boxed{ p(u_2\mid t_2) = \frac{0.3}{0.5} = 0.6 }\]

Conditional Distribution for \(t_2\) — 따라서 \(\boxed{ p(Y\mid X=t_2) = [0.4,0.6] }\)

\(H(Y\mid X=t_2)\) —

\[H(Y\mid X=t_2) = - [ 0.4\log_20.4 + 0.6\log_20.6 ]\]

근사값은 \(\log_20.4 \approx -1.3219\) \(\log_20.6 \approx -0.7370\) 따라서

\[\begin{aligned} H(Y\mid X=t_2) &\approx 0.5288+0.4422\\ &= \boxed{ 0.9710\text{ bits} } \end{aligned}\]

Weighted Average — 전체 Conditional Entropy는

\[H(Y\mid X) = \sum_x p(x) H(Y\mid X=x)\]

따라서

\[\begin{aligned} H(Y\mid X) &= 0.5(0.7219) + 0.5(0.9710)\\ &= 0.3610+0.4855\\ &= \boxed{ 0.8465\text{ bits} } \end{aligned}\]

Unconditional Entropy \(H(Y)\) — Marginal Distribution은 \(\boxed{ p(Y) = [0.6,0.4] }\) 따라서

\[\begin{aligned} H(Y) &= - [ 0.6\log_20.6 + 0.4\log_20.4 ]\\ &\approx \boxed{ 0.9710\text{ bits} } \end{aligned}\]

Conditioning Reduces Entropy 검증 — 계산 결과

\[\boxed{ H(Y\mid X) = 0.8465\text{ bits} }\]

이고 \(\boxed{ H(Y) = 0.9710\text{ bits} }\) 따라서 \(\boxed{ 0.8465 < 0.9710 }\) 으로 \(\boxed{ H(Y\mid X)<H(Y) }\) 가 확인된다.

감소한 불확실성 — 차이는

\[\begin{aligned} H(Y)-H(Y\mid X) &= 0.9710-0.8465\\ &= \boxed{ 0.1245\text{ bits} } \end{aligned}\]

이 값은 \(\boxed{ I(X;Y) }\)

IT-04 Numerical Result와 연결 — IT-04에서 같은 Joint Distribution에 대해 \(H(X,Y) = 1.8465\text{ bits}\) 이고 \(H(X) = 1.0\text{ bit}\) 였다. Chain Rule을 사용하면

\[\begin{aligned} H(X,Y) &= H(X)+H(Y\mid X)\\ &= 1.0+0.8465\\ &= \boxed{ 1.8465\text{ bits} } \end{aligned}\]

즉 계산 결과가 정확히 일치한다.

Entropy Diagram 관점 — 세 Quantity는 다음 관계를 가진다. \(\boxed{ H(Y) = I(X;Y) + H(Y\mid X) }\) 그리고 \(\boxed{ H(X) = I(X;Y) + H(X\mid Y) }\) Joint Entropy는 \(\boxed{ H(X,Y) = H(X)+H(Y\mid X) }\)

Conditional Entropy의 방향성 — 일반적으로 \(\boxed{ H(Y\mid X) \neq H(X\mid Y) }\) Conditioning의 방향이 다르기 때문이다. 하지만 Mutual Information은 Symmetric하다. \(\boxed{ I(X;Y) = I(Y;X) }\)

Autoregressive Language Model — Autoregressive LLM에서는 이전 Token Sequence를

\[\boxed{ Y_{<t} = (Y_1,\dots,Y_{t-1}) }\]

라고 한다. 다음 Token Random Variable은 \(\boxed{ Y_t }\) 모델은 Conditional Distribution

\[\boxed{ P_\theta( Y_t \mid Y_{<t} ) }\]

를 예측한다.

Next-Token Conditional Entropy — 원자료에서는 다음 Token의 조건부 불확실성을 \(\boxed{ H( Y_t \mid Y_{<t} ) }\) 로 표현한다. 정의는

\[\boxed{ H( Y_t \mid Y_{<t} ) = - \sum_{y_{<t}} \sum_{y_t} P(y_{<t},y_t) \log_2 P( y_t\mid y_{<t} ) }\]

Fixed Context의 Entropy — 실제 LLM Inference에서는 특정 Prefix \(y_{<t}\) 가 이미 고정되어 있다. 이 특정 Context에서 모델 또는 참 분포가 갖는 Next-Token Entropy는

\[\boxed{ H( Y_t \mid Y_{<t}=y_{<t} ) = - \sum_{y_t} P( y_t\mid y_{<t} ) \log P( y_t\mid y_{<t} ) }\]

전체 Conditional Entropy는 이러한 Context별 Entropy를 Prefix Distribution에 대해 평균한 Quantity다.

Context as Conditioning Variable — LLM에서는 Prefix \(Y_{<t}\) 가 Conditioning Variable 역할을 한다. 따라서 \(\boxed{ H( Y_t\mid Y_{<t} ) }\) 는 이전 Token Information이 주어진 뒤 다음 Token에 남아 있는 평균적인 불확실성을 나타낸다.

Unconditional vs Conditional Token Entropy — Context를 사용하지 않는다면 \(\boxed{ H(Y_t) }\) 를 생각할 수 있다. Context를 사용하면 \(\boxed{ H( Y_t\mid Y_{<t} ) }\) 정보이론적 정리에 의해 동일한 joint distribution에서 random variable \(Y_{<t}\) 전체로 조건화한 평균적 의미에서는

\[\boxed{ H( Y_t\mid Y_{<t} ) \le H(Y_t) }\]

Context Length에 대한 중요한 구분 — 원자료는 Context Length 확장을 Conditional Entropy 감소와 연결한다. 다만 \(H(Y\mid X)\le H(Y)\) 가 직접 말하는 것은 정보를 가진 Random Variable \(X\)에 조건화했을 때의 평균 Entropy 관계​다. 따라서

\[\boxed{ \text{longer context} \Rightarrow \text{every individual prediction becomes more accurate} }\]

라는 의미는 아니다. Context가 실제로 Next Token과 관련된 정보를 포함할 때 예측에 유용할 수 있다는 정보이론적 기반으로 이해한다.

추가 Conditioning Variable — 예를 들어 Context를 두 부분으로 나누어 \(C_1, \qquad C_2\) 라고 하자. 정보이론에서는 평균적으로

\[\boxed{ H(Y\mid C_1,C_2) \le H(Y\mid C_1) }\]

즉 추가 Random Variable을 조건으로 제공하면 평균 Conditional Entropy는 증가하지 않는다.

실제 LLM과의 차이 — 앞의 결과는 true joint distribution에 정의된 Shannon Conditional Entropy에 관한 것이다. 실제 LLM은 \(Q_\theta( Y_t\mid Y_{<t} )\) 라는 근사 모델을 사용한다. 따라서 더 긴 Context를 입력한다고 해서 유한한 모델의 실제 Accuracy가 반드시 단조롭게 개선된다는 보장은 이 Entropy 정리만으로는 얻을 수 없다.

Cross-Entropy Training — 참 Conditional Distribution을 \(\boxed{ P( Y\mid X ) }\) 라고 하고 모델 Prediction Distribution을 \(\boxed{ Q_\theta( Y\mid X ) }\) 라고 하자. Conditional Cross-Entropy는 모델이 참 Sample에 부여하는 Negative Log-Probability의 평균이다.

Expected Conditional Cross-Entropy — 자연로그를 사용하면

\[\boxed{ \mathcal H( P,Q_\theta ) = \mathbb E_{(X,Y)\sim P} [ -\log Q_\theta( Y\mid X ) ] }\]

LLM에서는 \(X=Y_{<t}\) \(Y=Y_t\) 로 대응할 수 있다.

Conditional Cross-Entropy 전개 — Expectation을 전개하면

\[\boxed{ \mathcal H(P,Q_\theta) = - \sum_x p(x) \sum_y p(y\mid x) \log q_\theta(y\mid x) }\]

이 값이 Expected Next-Token Cross-Entropy와 연결된다.

Conditional Entropy 항 더하고 빼기 — 다음 항을 더하고 뺀다. \(-\log p(y\mid x)\) 그러면

\[-\log q_\theta(y\mid x) = -\log p(y\mid x) + \log \frac{ p(y\mid x) }{ q_\theta(y\mid x) }\]

Expected Cross-Entropy 분해 — Expectation을 취하면 첫 번째 항은 Conditional Entropy가 된다.

\[\boxed{ H_P(Y\mid X) = \mathbb E_P[ -\log P(Y\mid X) ] }\]

두 번째 항은 각 Context에서의 KL Divergence를 평균한 값이 된다. 따라서 정확하게는

\[\boxed{ \mathcal H(P,Q_\theta) = H_P(Y\mid X) + \mathbb E_{X\sim P} \left[ D_{KL} \left( P(Y\mid X) \| Q_\theta(Y\mid X) \right) \right] }\]

원자료의 표현 — 원자료에서는 이를 압축하여

\[\boxed{ \mathbb E[ \mathcal L_{CE} ] = H( Y_t\mid Y_{<t} ) + D_{KL} \left( P( Y_t\mid Y_{<t} ) \| Q_\theta( Y_t\mid Y_{<t} ) \right) }\]

형태로 표현한다. 엄밀히는 Context가 Random Variable이면 KL Term 역시 Context Distribution에 대한 평균으로 이해하면 된다.

Cross-Entropy Lower Bound — KL Divergence는 비음수이므로

\[\boxed{ \mathbb E_X [ D_{KL} ( P(\cdot\mid X) \| Q_\theta(\cdot\mid X) ) ] \ge0 }\]

따라서

\[\boxed{ \mathcal H( P,Q_\theta ) \ge H_P(Y\mid X) }\]

Optimal Model Distribution — 이론적으로 모델이 참 Conditional Distribution을 정확히 표현하여

\[\boxed{ Q_\theta( Y\mid X ) = P( Y\mid X ) }\]

가 된다면 KL Term은 0이다. 따라서

\[\boxed{ \mathcal H( P,Q_\theta ) = H_P(Y\mid X) }\]

Irreducible Conditional Uncertainty — 원자료에서는 이 참 Conditional Entropy를 모델이 제거할 수 없는 최소 한계 Loss와 연결한다. 핵심은 true conditional distribution 자체에 불확실성이 존재하면 완벽한 Distribution Model이라도 Sample-Level Outcome을 항상 확정적으로 예측할 수는 없다는 점이다. \(\boxed{ H_P(Y\mid X) }\) 는 그 true distribution 아래의 고유한 평균 Conditional Uncertainty다.

Irreducible Loss 해석의 조건 — 이 해석은

  • 참 Distribution \(P\)가 정의되어 있고
  • 평가 Loss가 Log-Loss/Cross-Entropy이며
  • Model Class가 충분히 표현 가능하고
  • Distribution-level expectation을 고려하는

이론적 설정에서 이해한다. 실제 Dataset의 유한 Sample Training Loss가 반드시 정확히 이 값에 도달한다는 의미는 아니다.

LLM Training 연결 — Next-Token Training에서는 각 Prefix \(y_{<t}\) 에 대해 실제 Token \(y_t\) 의 Model Probability를 높인다. Token Loss는

\[\boxed{ \mathcal L_t = -\log Q_\theta( y_t\mid y_{<t} ) }\]

Dataset 전체에서 평균하면 Conditional Cross-Entropy Estimate가 된다.

Conditional Entropy와 NLL 차이 — Conditional Entropy는 참 Distribution 자체를 사용한다.

\[\boxed{ H_P(Y\mid X) = \mathbb E_P[ -\log P(Y\mid X) ] }\]

Training NLL은 모델 Distribution을 사용한다.

\[\boxed{ \mathbb E_P[ -\log Q_\theta(Y\mid X) ] }\]

따라서 두 값의 차이가 Conditional KL Divergence다.

핵심 분해 —

\[\boxed{ \text{Model Cross-Entropy} = \text{Intrinsic Conditional Entropy} + \text{Model Mismatch} }\]

즉

\[\boxed{ \mathcal H(P,Q_\theta) = H_P(Y\mid X) + \mathbb E_X D_{KL} ( P(\cdot\mid X) \| Q_\theta(\cdot\mid X) ) }\]

정리

Conditional entropy \(H(Y\mid X)\)는 \(X\)를 관측한 뒤에도 남는 \(Y\)의 불확실성을 각 조건의 확률로 평균한 값이다. \(H(X,Y)=H(X)+H(Y\mid X)\)이고 조건부 entropy는 \(H(Y)\) 이하이며, 독립일 때만 관측 전후의 불확실성이 같다.
