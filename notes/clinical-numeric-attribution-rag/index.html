1. 연구 질문과 목표

치과 분할구강(Split-mouth)·안과 양안(Paired-eye) 시험과 평행군(Parallel-group)에서 임상 수치의 집계 단위, 치료군, 시점, 분모 및 환자 공유 관계를 평가하는 연구 질문과 검증 프레임워크를 정립함.

1. 배경 및 문제 진단

기존 임상시험 수치 추출 평가에서 LLM 출력과 정답 간 불일치가 빈번하게 관찰됨. 수치 자체를 잘못 추출하거나, 수치를 정확히 읽고도 치료군·집계 단위(환자·치아·안구 등)·추적 시점·분모에 잘못 연결하면 전체 일치율(Exact Match)이 급격히 저하됨. 표 머리글·각주와 본문의 배정 설명을 함께 해석해야 하는 복합 설계 문헌에서 귀속 오류의 발생 기전을 규명하고 전체 일치율에 미치는 영향을 실증함.

2. 핵심 연구 목적

상용 API 모델과 로컬 오픈소스 가중치 모델을 대상으로, 각 기반 모델의 기본 추론선(Baseline)에서 다음 개선 방법을 순차 적용함.

  1. 계층 구조 보존 파싱
  2. 임상 맥락 기반 RAG(근거 검색·청킹)
  3. 귀속 관계 지도 미세조정(SFT, LoRA 적용)

각 단계에서 수치 오인식과 맥락 오귀속이 얼마나 감소하는지 정량적으로 검증하고 최적 파이프라인 구성을 도출함.

3. 통제 및 검증 프레임워크

  • 평가 기준 일원화. 동일한 평가 문항과 채점 기준을 바탕으로 전체 일치율, 수치 일치율, 슬롯별(단위·군·시점·분모) 귀속 정확도, 수치 일치·귀속 불일치율을 다차원으로 측정함.
  • 모듈별 기여도 평가. 파싱과 검색 방식을 한 번에 하나씩 바꾸어 수치 추출과 귀속 성능을 비교함. 충분한 근거를 제공한 뒤에도 귀속 오류가 남으면 파인튜닝을 후속 실험으로 검토함.

4. 추출 항목과 정답·평가지표

임상시험 문헌에서 수치 추출, 맥락 귀속, 원문 근거를 독립 평가함. 선행연구 3편의 방법론을 바탕으로 문항·정답 레코드와 수치별 최소 근거를 구축함.

1. 벤치마크 평가 방식 차용 근거

2. 통합 평가지표 체계

가상 채점 예시

Question: At 3 months after surgery, report the sample size and counting unit for each group (A and B) in the visual acuity analysis. Cite the source evidence for each answer.

• 정답 (Gold): A군 = 30안, B군 = 28안 [표 2의 3개월 행·A/B군 열 + 안구 단위를 밝힌 각주 a] • 모델 답변 (Model): A군 = 28명, B군 = 30명 [표 2 인용, 각주 누락]

본 평가지표 체계는 수치 추출 정확도와 맥락 귀속 정확도를 독립적으로 분리 산출함. 동일 통계량 종류 내에서 숫자를 1:1로 선대조한 후, 치료군·단위·분모 등의 귀속 필드를 슬롯별로 채점함. 따라서 군이 뒤바뀌어 전체 일치(EM)가 0점인 경우에도 수치 추출 정확도는 보존되어 모델의 오답 원인을 직교 진단할 수 있음. 귀속 정확도는 수치가 일치하고 해당 필드가 평가 대상인 항목을 분모로 산출함. 문항별 채점 결과를 시험(Trial) 단위로 1차 평균하여 시험별 가중치를 균등화함.

3. 문항 제작 및 정답 주석 규격

문항 후보 전수 열거 및 선정. 원문(Abstract, Results, Methods)에서 비교군 쌍 × 결과 지표 × 측정 시점 조건 튜플을 전수 열거하고, 표·그림 및 각주의 계층 구조를 보존함. 방법 절은 배정 단위와 결과 정의·분석 집단 확인에 사용함. 최종값과 변화량은 구분하여 열거하며, 동일 결과의 반복 보고는 단일화함. 원문 검증을 거쳐 확정된 후보 목록에서 사전에 고정한 규칙과 난수 시드로 평가 문항을 층화 추출하여 표준 템플릿으로 생성함. 모든 실험 조건에서 동일한 문항 세트를 동결하여 적용함.

모델 평가 인터페이스 및 답변 프롬프트. 문항은 영문 표준 템플릿으로 제공되며, 모델은 주어진 시험 조건(군·지표·시점·측정 조건)을 바탕으로 요구 통계량과 귀속 필드를 구조화된 JSON 레코드로 도출함.

Answer prompt: Use the supplied trial report to answer the question. Return one JSON record per requested statistic with its value and required attribution fields. Distinguish the outcome-specific analysis denominator from the number randomized. Use not_reported for values absent from the report and indeterminate when the supplied evidence is insufficient or ambiguous. When citations are requested, include the table cells, headers, footnotes, or passages needed to support each value and its attribution.

4. 단계별 실험 검증 절차

모듈별 성능 차이를 평가하기 위해 다음 비교를 순차 진행함.

  1. 구조 보존 효과 검증: 동일 모델·근거에서 일반 텍스트/평면 표 vs JATS XML 계층 JSON 간 전체 일치율(EM)을 비교함.
  2. RAG 검색 효과 검증: 전문 입력과 검색 입력을 비교함. 검색 조건에서는 질문 전체 검색과 항목별 검색을 동일한 모델·코퍼스·최종 근거 토큰 상한으로 비교함. 항목별 검색은 문항에 명시된 시험 조건(군·지표·시점·측정 조건)을 바탕으로 질의를 구성함. 검색 대상에는 방법 절을 포함하며, 충분한 근거 회수율과 귀속 정확도 차이를 측정함.
  3. 원문 근거 제공 진단(Oracle Test): 검색 결과로 오답이 나온 문항에 인간이 검수한 충분한 원문 근거를 제공함. 답변이 교정되는 경우(검색 실패)와 오류가 지속되는 경우(추론·귀속 실패)를 분리하여 단계별 기여도를 검증함.

5. 정답 주석 및 품질 관리 원칙

독립 이중 주석 및 합의. 검수자 3명 중 논문마다 2명을 배정함. 두 검수자는 모델 답변과 서로의 주석을 보지 않은 상태에서 치료군, 결과 지표, 측정 시점, 집계 단위, 분석 분모와 각 수치의 원문 근거를 독립적으로 기록함. 최초 주석을 비교해 불일치한 항목은 같은 두 검수자가 원문을 한 번 더 독립적으로 확인한 뒤, 근거를 대조해 최종 정답에 합의함. 재확인 후에도 합의되지 않은 문항은 보류(확정 평가셋 제외) 처리함.

개발 파일럿. 네 설계군을 포함함. 사람이 원문에서 독립적으로 만든 목록을 기준으로 생성기의 후보 재현율과 정밀도, 누락 유형 및 반복 실행 간 후보 일치도를 기록함. 두 검색 방식이 필수 표·각주·배정 문단을 함께 회수했는지 문항별로 비교함. 후보 목록 검수, 검수자별 최초 주석, 재확인·합의 시간을 따로 재고 합의 전 필드별 일치도를 기록함. 파일럿 편수는 작업량과 설계별 사례 확보 가능성을 검토해 정함.

5. 원문 구조화와 검증

JATS XML을 절·문단·표·각주 단위로 파싱해 원문 위치를 보존하고, 연구를 대표하는 문항 후보를 원문과 대조함.

1. 문헌 분할과 사용 범위

JATS XML 495편을 개발 후보 99편과 평가 후보 396편으로 나눔. 1차 선별 후 남은 463편은 개발 후보 93편과 평가 후보 370편이며, 기존 분할을 유지해 각각 12편과 48편을 층화 추출함. 두 표본은 치과·안과 각 6편과 각 24편으로 구성함. 동일 시험의 복수 보고서가 두 후보군에 걸쳐 있는지 대조한 뒤 분할을 확정함.

개발 후보 93편에서 절 제목과 논문 전개를 조사해 인식 규칙을 조정함. 개발 표본 12편에서 절 역할·문항 후보·원문 근거를 대조하고, 규칙과 프롬프트를 고정한 뒤 평가 표본 48편에 적용함.

2. 절 계층 파싱 및 역할 분류

ElementTree로 초록, 원문 절 제목, 상하위 관계, 등장 순서, XML ID 또는 XPath를 추출함. sec-type과 표준 제목 규칙을 먼저 적용함. Clinical outcomes처럼 역할이 모호한 제목은 상위 절과 본문 앞 1~2문단을 함께 제공해 LLM으로 분류하고, 근거가 부족하면 보류함. 제목 변형의 빈도, 역할별 배치 순서, 문맥 확인이 필요한 절의 비율을 집계함. 한 절에 방법과 결과가 섞여 있으면 문단 단위로 확인함.

3. 질환·핵심 지표 포착과 문항 후보 검증

제목과 초록을 첫 검색 단서로 활용하고, Methods에서 연구 대상과 일차 지표를 확인한 뒤, Results에서 실제 보고된 수치 조합을 교차 검증함. 처음 발견한 위치와 최종 판정 근거 위치를 분리 기록하여 후보 누락과 오연결 감소 효과를 측정함.

CONSORT 2025(항목 14)에 따라 측정 변수, 분석 방식, 집계 방식과 시점을 기록함. Methods에서 지표와 측정 시점을 연결하고, Results의 본문·표·각주에서 두 군의 결과가 같은 시점·조건·통계량으로 보고됐는지 확인함. 저자가 명시한 핵심 비교, 일차 결과와 주 평가 시점을 우선함. 일차 결과나 주 평가 시점이 명시되지 않으면 그 사실을 기록하고, 연구 목적에 직접 연결되며 양 군 결과가 확인되는 조합을 후보로 남김. 검증된 후보는 통계량과 근거 인용을 명시하는 영문 템플릿으로 변환함.

4. 표·각주·본문 연결 및 파일럿 검증

계층 JSON에 절, 문단, 표와 셀을 기록함. 셀 ID, 행·열 인덱스, 병합 범위, 다단 머리글과 각주 참조를 보존하고, 배정 문단 등 관련 근거의 원문 위치를 연결함. 개발 표본 12편에서 사람이 확인한 원문 근거와 대조해 절 역할 일치율, 유효 조합 비율, 대표 후보 누락 건수를 집계함. 값 왜곡과 머리글·각주 연결 누락도 기록함.

XML과 PDF를 함께 확보한 개발 문헌에서는 같은 표를 대상으로 pdfplumber와 Docling의 셀·머리글 복원율과 처리 시간을 비교함. 복잡한 표나 수식에서 오류가 발생한 사례에 MinerU 2.5를 적용해 복원 결과를 대조함.

원문 구조화와 검증 절차

6. 근거 구성과 검색

전문(Full-text) 입력, 키워드 검색(BM25), 계층 구조 기반 청킹 검색 및 오라클(Oracle) 근거 제공 조건을 설정하여 검색 모듈의 성능 기여도를 분리 측정함.

  • a. 표현 형식별 근거 제공(평면 vs 구조 JSON): 동일 문헌·문항에서 사전에 확정된 표·각주·배정 문단을 일반 텍스트/마크다운 표와 계층 구조 JSON 형태로 각각 제공함. 두 조건 간 포함된 텍스트와 수치가 완전히 동일함을 검증하고, 토큰 소모량 및 문맥 초과 여부를 측정함.
  • b. 검색 파이프라인 벤치마크(BM25 · BGE-M3 · 하이브리드): 고정 길이(Fixed-size) 청킹 대비 계층 구조(Structural) 청킹의 검색 성능을 동일 토큰 예산 하에서 비교함. BM25 어휘 검색을 기본선으로 두고, 의학 용어 어휘 불일치 해소를 위해 BGE-M3 기반 밀집 검색 및 상호 순위 결합(RRF) 하이브리드 검색을 순차 적용함.
  • c. 오라클 근거 기반 검색-추론 오류 직교 분리: 검색 실패로 인한 오답과 모델 추론 능력 부족으로 인한 오답을 분리하기 위해, 정답 도출에 필요한 충분한 원문 구간(Oracle Spans)을 직접 주입하는 진단 조건을 병행함.
  • d. 질문 전체 검색과 항목별 검색 비교: 양 조건에 같은 원문의 초록·방법·결과 절과 표 제목·머리글·각주를 포함한 검색 자료를 제공함. 문항, 파서, 청킹, 검색기, 답변 모델과 출력 형식을 고정함. 항목별 검색은 배포된 질문에서 비교군·지표·시점·측정 조건과 요청한 통계량을 읽어 하위 질의를 구성함. 양 조건에서 같은 원문 위치의 중복 청크를 제거하고 같은 토크나이저로 최종 근거 입력의 총 토큰 상한을 적용함. 실제 입력 토큰 수, 검색 호출 수와 지연 시간도 기록함. 질의 분해 자체의 효과를 주장하려면 검색 후보 예산과 결과 결합 방식의 영향도 별도로 대조함.

7. 구조화 추출과 학습

4대 핵심 귀속 슬롯을 출력하는 엄격한 JSON 스키마를 정의하고, 로컬 LLM 양자화 추론 파이프라인 및 단계별 추출(Chain-of-Thought) 전략을 검증함.

  • a. 로컬 모델 환경 검증 및 스키마 기반 출력: RTX 4080 SUPER(16GB VRAM) 환경에서 Qwen3-8B 4비트(Q4_K_M) 양자화 추론을 기준으로 최장 입력의 메모리 안정성을 검증함. 온도(Temperature=0) 등 생성 파라미터를 고정하고, 비교군 쌍·결과 지표·시점별 수치와 분모를 규격화된 JSON으로 추출함.
  • b. 문맥 길이 및 자원 제약 최적화: 긴 문맥 입력 시 문맥 절삭이나 VRAM 한도 초과가 발생하는 경우, 동일 아키텍처 경량 모델(Qwen 계열 소형 모델) 및 컨텍스트 윈도우 확장 기법을 적용하여 입력 보존율, 추론 지연시간, 안정성을 종합 평가함.
  • c. 단일 추론 vs 단계별(CoT) 귀속 파이프라인 비교: 단일 프롬프트 일괄 추출과 다단계 추출(원문 근거 선택 → 임상 설계 및 단위 귀속 판정 → 군별 수치 추출)의 정확도를 비교함. 도메인 특화 모델(BioMistral-7B 등)을 추가하여 범용 모델과의 도메인 적응 성능 차이를 분석함.

8. 기준선·개선 조건 비교

최종 표본을 시험 ID 기준으로 개발셋과 확인평가셋에 나누어, 파싱·검색·학습 모듈별 기여도를 기준선(Baseline)과 정량 비교함.

  • a. 모듈별 성능 비교 및 어블레이션(Ablation): 동일 기반 모델에서 평면 텍스트/표(기준선) vs 계층 구조 JSON(파싱 기여도) vs RAG 검색 입력(검색 기여도) 간 전체 일치율(All-fields EM) 및 귀속 정확도를 비교함. 개발셋에서 프롬프트 및 파라미터를 고정한 뒤 확인평가셋에서 최종 성능을 검증함.
  • b. 품질 기준 및 확장 통제 기준: 문항별 원문 근거 확보율 90% 이상, 라벨 이중 검수 완료, 입력 누락 0건을 확인평가 진행의 필수 조건으로 적용함. 자원 제약이나 데이터 불완전성이 발생할 경우 명문화된 중단 및 보완 프로토콜에 따라 처리함.
  • c. 지도 미세조정(SFT/LoRA) 및 추론 강화 검증: 충분한 원문 근거 제공 후에도 오귀속이 잔존하는 경우, TRL·PEFT 기반 QLoRA로 단순 수치 학습 조건과 수치 + 단위·설계 귀속 동시 학습 조건을 비교함. 확인평가셋은 학습 및 하이퍼파라미터 튜닝에서 철저히 배제하여 데이터 누수를 원천 차단함.

9. 정량 평가와 오류 분석

전체 일치율(All-fields EM), 슬롯별 귀속 정확도, 근거 회수율을 주지표로 채택하고 통계적 유의성 검정과 4대 단계별 오류 분석을 수행함.

  • a. 통합 평가지표 산출 및 시험 단위 가중 집계: 평면 텍스트 대비 계층 구조 JSON 조건의 전체 일치율 차이를 주 평가 척도로 산출함. 문항별 채점 결과를 시험(Trial) 단위로 평균 집계하여 특정 시험 편중을 방지하고, 미응답·파싱 실패도 전체 분모에 엄격히 산입함. 수치는 일치했으나 귀속이 틀린 비율(수치 일치·귀속 불일치율)을 핵심 진단 지표로 별도 보고함.
  • b. 통계적 가설 검정 및 신뢰구간(Bootstrap CI) 분석: 짝지은 재표집(Paired Bootstrap, B=1,000)을 적용하여 95% 신뢰구간을 산출함. 신뢰구간 하한이 0을 초과할 경우 기법의 유효한 개선으로 판정하고, 하한이 10%p 이상일 경우 실질적 임상 유효성 목표를 달성한 것으로 판정함.
  • c. 단계별 직교 오류 분석 및 재현 분산 측정: 오답 문항에 대해 문서 변환 오류 / 검색 누락 / 모델 추론 실패 / JSON 파서 오류의 4대 직교 원인을 분류·집계함. 동일 프롬프트 3회 반복 추론을 통해 생성 변동성(온도=0 조건의 결정론적 재현성)과 토큰당 추론 비용을 종합 측정함.

10. 결과 보고와 재현 자료

선행 벤치마크(Yun 66문항) 탐색 보고서와 재현 아티팩트를 보존하고, 최종 선정한 자체 평가 표본의 재현 패키지를 구축함.

  • a. 종단 간 재현 패키지(End-to-End Artifacts) 구축: 문헌 식별자 목록 → 계층 구조 JSON → 전문가 합의 정답 → 근거 청크 묶음 → 모델 동결 응답 → 채점 결과를 SHA-256 해시로 상호 검증하는 통합 재현 패키지를 구축함.
  • b. FAIR 원칙 준수 공개 배포: 저작권 정책을 준수하여 원문 재배포가 제한되는 문헌은 다운로드 스크립트와 정답 주석, 평가 코드, 실험 환경 설정(Dockerfile / 가상환경 사양)을 오픈소스로 공개함.
  • c. 오류 데이터셋 자산화 및 보고서 발간: 연구 가설 검증 결과와 함께 실패 사례, 파서 한계, 모호 문항의 판정 기준집을 독립 산출물로 정리하여 의료 문헌 RAG 후속 연구를 위한 참조 표준으로 기여함.
