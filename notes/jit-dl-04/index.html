DL-04 — Forward Propagation & Computational Graph

Forward Propagation의 연산 순서와 Computational Graph 표현을 정리한다.

수정 2026.09.21약 70분상태 작성 완료
학습 내용
  • Forward Propagation
  • Prediction에서 Loss까지
  • Layer Notation
  • Affine Transformation
011. Forward Propagation022. Prediction에서 Loss까지033. Layer Notation044. Affine Transformation055. Pre-Activation066. Activation Function

1. Forward Propagation

Neural Network는 입력

\[\boxed{ \mathbf x }\]

를 받아 여러 Layer의 연산을 순서대로 적용하여 최종 Prediction

\[\boxed{ \hat{\mathbf y} }\]

를 생성한다.

입력에서 출력 방향으로 계산을 진행하는 이 과정을 Forward Propagation 또는 Forward Pass라고 한다.

전체 흐름은

\[\boxed{ \mathbf x \rightarrow \text{Layer 1} \rightarrow \text{Layer 2} \rightarrow \cdots \rightarrow \text{Layer }L \rightarrow \hat{\mathbf y} }\]

2. Prediction에서 Loss까지

Training에서는 Prediction을 만드는 것으로 Forward Pass가 끝나지 않는다.

Target

\[\mathbf y\]

와 Prediction

\[\hat{\mathbf y}\]

를 Loss Function에 넣어 Scalar Loss

\[\boxed{ \mathcal L( \hat{\mathbf y}, \mathbf y ) }\]

까지 계산한다.

따라서 Training Forward Pass 전체는

\[\boxed{ \mathbf x \rightarrow \hat{\mathbf y} \rightarrow \mathcal L }\]

3. Layer Notation

입력을

\[\boxed{ \mathbf a^{(0)} = \mathbf x }\]

라고 하자.

\(l\)번째 Layer에서

\[\mathbf a^{(l-1)}\]

는 이전 Layer의 Activation이고,

\[\mathbf W^{(l)}\]

은 Weight Matrix,

\[\mathbf b^{(l)}\]

은 Bias,

\[\mathbf z^{(l)}\]

은 Pre-activation,

\[\mathbf a^{(l)}\]

은 Post-activation이다.

4. Affine Transformation

\(l\)번째 Layer에서 가장 먼저 수행하는 연산은

\[\boxed{ \mathbf z^{(l)} = \mathbf W^{(l)} \mathbf a^{(l-1)} + \mathbf b^{(l)} }\]

이를 Affine Transformation이라고 한다.

Linear Transformation

\[\mathbf W^{(l)} \mathbf a^{(l-1)}\]

에 Bias를 더한 형태다.

5. Pre-Activation

Activation Function을 적용하기 전의 값이

\[\boxed{ \mathbf z^{(l)} }\]

따라서

\[\boxed{ \mathbf z^{(l)} = \mathbf W^{(l)} \mathbf a^{(l-1)} + \mathbf b^{(l)} }\]

를 Pre-activation이라고 한다.

6. Activation Function

Pre-activation에 Nonlinear Activation Function

\[\sigma_l\]

를 적용한다.

\[\boxed{ \mathbf a^{(l)} = \sigma_l \left( \mathbf z^{(l)} \right) }\]

대표적인 Activation Function으로는

  • ReLU
  • GELU
  • SiLU

등이 있다.

7. Post-Activation

Activation Function을 통과한

\[\boxed{ \mathbf a^{(l)} }\]

을 Post-activation 또는 Activation이라고 한다.

따라서 하나의 Layer는

\[\boxed{ \mathbf a^{(l-1)} \rightarrow \mathbf z^{(l)} \rightarrow \mathbf a^{(l)} }\]

의 두 단계로 볼 수 있다.

8. Layer Recurrence

\(l=1,\dots,L\)에 대해

\[\boxed{ \mathbf z^{(l)} = \mathbf W^{(l)} \mathbf a^{(l-1)} + \mathbf b^{(l)} }\]
\[\boxed{ \mathbf a^{(l)} = \sigma_l( \mathbf z^{(l)} ) }\]

을 반복한다.

최종적으로

\[\boxed{ \mathbf a^{(L)} = \hat{\mathbf y} }\]

를 얻는다.

9. Neural Network as Function Composition

각 Layer를 하나의 함수

\[f_l\]

이라고 하면

\[\mathbf a^{(l)} = f_l( \mathbf a^{(l-1)} )\]

따라서 전체 Neural Network는

\[\boxed{ f = f_L \circ f_{L-1} \circ \cdots \circ f_1 }\]

이라는 Function Composition으로 볼 수 있다.

10. Forward Propagation의 본질

따라서 Forward Propagation은 단순히 “Layer를 지나간다”는 표현보다

\[\boxed{ \text{함수 합성을 순서대로 평가하는 과정} }\]

으로 이해할 수 있다.

11. Single-Sample Convention

Column Vector Convention에서는

\[\mathbf a^{(l-1)} \in \mathbb R^{d_{l-1}}\]

이고

\[\mathbf W^{(l)} \in \mathbb R^{d_l\times d_{l-1}}\]

라면

\[\boxed{ \mathbf z^{(l)} = \mathbf W^{(l)} \mathbf a^{(l-1)} + \mathbf b^{(l)} }\]

Shape은

\[(d_l\times d_{l-1}) (d_{l-1}\times1) = d_l\times1\]

12. Mini-Batch Convention

원자료의 수치 예제에서는 여러 Sample을 Row로 쌓는 Mini-batch Convention을 사용한다.

\[\boxed{ \mathbf X \in \mathbb R^{B\times d_{\mathrm{in}}} }\]

이 Convention에서는

\[\boxed{ \mathbf Z = \mathbf X\mathbf W + \mathbf1_B\mathbf b }\]

를 사용한다.

13. Batch Shape

만약

\[\mathbf X \in \mathbb R^{B\times d_{\mathrm{in}}}\]

이고

\[\mathbf W \in \mathbb R^{d_{\mathrm{in}}\times d_{\mathrm{out}}}\]

이면

\[\boxed{ \mathbf X\mathbf W \in \mathbb R^{B\times d_{\mathrm{out}}} }\]

Bias는 각 Row에 Broadcasting된다.

14. 두 Convention의 관계

따라서

\[\mathbf W\mathbf a\]

와

\[\mathbf X\mathbf W\]

가 서로 다르게 보일 수 있다.

이는 본질적으로 같은 Affine Transformation을

  • Column-vector single-sample convention
  • Row-wise mini-batch convention

으로 표현한 차이다.

Shape을 항상 함께 확인해야 한다.

15. Computational Graph

복잡한 Forward Pass 전체를 Computational Graph로 표현할 수 있다.

Computational Graph는

\[\boxed{ \mathcal G = (\mathcal V,\mathcal E) }\]

형태의 Directed Graph다.

Neural Network 계산은 일반적으로 Directed Acyclic Graph, 즉 DAG 형태로 표현된다.

16. DAG

DAG는

\[\boxed{ \text{Directed Acyclic Graph} }\]

의 약자다.

  • Directed: Edge에 방향이 존재한다.
  • Acyclic: 계산 의존성을 따라가다 다시 같은 Node로 돌아오는 Cycle이 없다.

이러한 구조 때문에 연산을 의존성 순서대로 실행할 수 있다.

17. Nodes

Graph의 Node

\[v_i\in\mathcal V\]

는

  • Scalar
  • Vector
  • Matrix
  • Tensor

와 같은 변수 또는

  • Matrix Multiplication
  • Addition
  • ReLU
  • Softmax

와 같은 Operation을 나타낼 수 있다.

18. Directed Edges

Edge

\[(v_j,v_i) \in \mathcal E\]

는

\[v_i\]

를 계산하기 위해

\[v_j\]

의 결과가 필요하다는 Dependency를 표현한다.

즉

\[\boxed{ v_j \rightarrow v_i }\]

는 Tensor/Data가 \(v_j\)에서 \(v_i\) 방향으로 흐른다는 뜻이다.

19. Parent Nodes

원자료에서는 각 Node의 값을 다음과 같이 표현한다.

\[\boxed{ v_i = f_i \left( \{ v_j \mid v_j \in \operatorname{Parents}(v_i) \} \right) }\]

즉 Node \(v_i\)는 자신의 Parent Node들이 계산된 뒤에야 계산할 수 있다.

20. Topological Evaluation

DAG에서는 Parent Node를 먼저 계산하고 Child Node를 나중에 계산한다.

따라서 Forward Pass는 Computational Graph를 Topological Order로 평가하는 과정으로 볼 수 있다.

\[\boxed{ \text{Parents} \rightarrow \text{Operation} \rightarrow \text{Child} }\]

21. Layered Computational Graph

일반적인 \(L\)-Layer Network는

\[\boxed{ \mathbf x = \mathbf a^{(0)} \rightarrow \mathbf z^{(1)} \rightarrow \mathbf a^{(1)} \rightarrow \cdots \rightarrow \mathbf z^{(L)} \rightarrow \mathbf a^{(L)} }\]

의 구조를 가진다.

22. Loss Node까지 포함

Training Graph에는 마지막에 Loss Node가 추가된다.

\[\boxed{ \mathbf x \rightarrow \cdots \rightarrow \mathbf a^{(L)} = \hat{\mathbf y} \rightarrow \mathcal L( \hat{\mathbf y}, \mathbf y ) }\]

Target

\[\mathbf y\]

도 Loss Node의 Parent 중 하나다.

23. Computational Graph가 중요한 이유

Forward Pass를 Graph로 표현하면

  • 어떤 연산이 어떤 값에 의존하는지
  • 어떤 순서로 계산해야 하는지
  • Backpropagation에서 어떤 경로로 Gradient가 전달되어야 하는지

를 명확하게 표현할 수 있다.

24. Local Operation

큰 Neural Network도 Computational Graph 관점에서는 작은 Local Operation의 조합이다.

예를 들어

\[\boxed{ Z=XW+b }\]
\[\boxed{ A=\operatorname{ReLU}(Z) }\]

처럼 각 Node는 비교적 단순한 함수를 계산한다.

25. Global Function from Local Functions

이러한 Local Function을 연결하면 전체 Network Function이 만들어진다.

\[\boxed{ \text{Local Operations} \rightarrow \text{Computational Graph} \rightarrow \text{Global Model} }\]

26. Intermediate Activation

Forward Pass에서 최종 Prediction 이외에도 많은 중간 Tensor가 계산된다.

예:

\[\boxed{ \mathbf z^{(l)} }\]
\[\boxed{ \mathbf a^{(l)} }\]

이를 Intermediate Activation Tensor라고 한다.

27. Intermediate Activation이 필요한 이유

Training에서는 Forward Pass 이후 Backpropagation을 수행한다.

Backward 연산에는 Forward에서 계산했던 값이 다시 필요한 경우가 많다.

예를 들어

\[A=\operatorname{ReLU}(Z)\]

라면 ReLU의 Gradient를 계산할 때

\[Z\]

의 부호 정보가 필요하다.

28. Linear Layer Backward

Linear Layer

\[Y=XW\]

에서는 CO-07에서

\[\boxed{ \frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y} }\]

를 배웠다.

따라서 Weight Gradient를 계산하려면 Forward Pass의 Input

\[\boxed{ X }\]

가 다시 필요하다.

29. Forward 값과 Backward의 관계

즉

\[\boxed{ \text{Forward intermediate values} \rightarrow \text{Backward gradient computation} }\]

이 때문에 Training에서는 Forward에서 계산한 일부 Tensor를 보존한다.

30. Activation Memory

저장되는 Activation Tensor는 GPU Memory를 차지한다.

따라서 Training Memory는 Parameter Memory만으로 결정되지 않는다.

원자료는

\[\boxed{ \text{Parameter memory} + \text{Activation memory} }\]

의 구분을 강조한다.

31. Activation Memory의 주요 변수

원자료의 Transformer 예제에서는 다음 Symbol을 사용한다.

\[\boxed{ B = \text{batch size} }\]
\[\boxed{ S = \text{sequence length} }\]
\[\boxed{ d = \text{hidden dimension} }\]
\[\boxed{ L = \text{number of layers} }\]
\[\boxed{ N_h = \text{number of attention heads} }\]

32. Precision

Tensor의 Element 하나당 저장 Byte 수를

\[\boxed{ p }\]

라고 하자.

예를 들어 특정 Floating-Point Format에서는 Element마다 일정한 Byte가 필요하다.

따라서

\[\boxed{ \text{Tensor memory} = \text{number of elements} \times p }\]

33. Normalization Activation

원자료의 대표적인 Transformer Block 메모리 회계에서는 RMSNorm 또는 LayerNorm 관련 Activation을

\[\boxed{ B\times S\times d }\]

크기로 둔다.

Element 수는

\[\boxed{ BSd }\]

34. Q, K, V Projection

Query, Key, Value Projection을 각각

\[B\times S\times d\]

로 단순화하면 세 Tensor를 합하여

\[\boxed{ 3BSd }\]

개의 Element가 된다.

35. Attention Score

Naive Dense Attention에서는 Head별 Attention Score가

\[S\times S\]

Matrix를 만든다.

전체 Batch와 Head를 포함하면

\[\boxed{ N_hBS^2 }\]

개의 Element 규모가 된다.

36. Attention Softmax

Naive Implementation에서는 Attention Score 또는 Softmax 결과와 관련된

\[\boxed{ N_hBS^2 }\]

규모의 Intermediate가 Training Memory에 큰 영향을 줄 수 있다.

특히 Sequence Length에 대해 Quadratic하게 증가한다.

37. Attention Output

원자료의 회계에서는 Attention Output Projection 관련 Activation을

\[\boxed{ BSd }\]

크기로 둔다.

38. Residual Path

Residual Addition 또는 관련 Tensor 역시 대표적으로

\[\boxed{ BSd }\]

크기의 Activation을 가진다.

39. FFN Activation

원자료는 단순화된 \(4d\) FFN Width를 사용하여 두 Intermediate Tensor를

\[2\times ( B\times S\times4d )\]

로 계산한다.

따라서

\[\boxed{ 8BSd }\]

개의 Element가 된다.

40. Source의 Layer Memory 근사

원자료의 단순화된 합산 결과는

\[\boxed{ M_{\mathrm{layer}} \approx \left( 14BSd + N_hBS^2 \right)p }\]

이는 Transformer Block 내부의 대표 Activation들을 단순 합산한 근사식이다.

41. 전체 Layer Activation Memory

모든 \(L\)개 Layer에서 같은 정도의 Activation을 저장한다고 단순화하면

\[\boxed{ M_{\mathrm{total\_act}} = L M_{\mathrm{layer}} }\]

따라서 source의 단순 모델에서는

\[\boxed{ M_{\mathrm{total\_act}} \propto L }\]

42. Batch Size Scaling

근사식에서

\[B\]

는 모든 주요 항에 곱해져 있다.

따라서 다른 조건을 고정하면

\[\boxed{ B\uparrow \Rightarrow M_{\mathrm{act}}\uparrow }\]

Source의 단순 계산에서는 Batch Size에 대해 Linear Scaling이다.

43. Hidden Dimension Scaling

\(BSd\) 형태의 Activation은 Hidden Dimension \(d\)에 비례한다.

따라서

\[\boxed{ d\uparrow \Rightarrow \text{hidden-state activation memory}\uparrow }\]

44. Sequence Length Scaling

Source의 근사식에는

\[BSd\]

와

\[N_hBS^2\]

가 모두 있다.

따라서 Sequence Length는

  • Hidden Activation에는 Linear
  • Naive Attention Matrix에는 Quadratic

하게 영향을 줄 수 있다.

45. 메모리 산식에 대한 중요한 주의

앞의

\[14BSd+N_hBS^2\]

는 모든 Transformer 구현에 그대로 적용되는 보편적인 정확식이 아니다.

실제 저장 Tensor는

  • Architecture
  • FFN Expansion Ratio
  • GQA/MQA 여부
  • Dropout
  • Fused Kernel
  • Attention Kernel
  • Autograd Implementation

에 따라 달라진다.

즉 source의 식은 대표적인 구조를 이해하기 위한 근사 회계로 사용한다.

46. SwiGLU Width 주의

원자료에서는 FFN을

\[4d\]

Width로 두고

\[8BSd\]

를 계산한다.

하지만 실제 SwiGLU 기반 LLM에서는 Intermediate Width가 정확히

\[4d\]

라고 고정되는 것은 아니다.

따라서 실제 Model Memory를 계산할 때는 해당 Architecture의

\[\boxed{ d_{\mathrm{ff}} }\]

를 직접 사용해야 한다.

47. Attention Matrix 저장 주의

Naive Attention에서는

\[S\times S\]

Attention Matrix가 명시적으로 존재할 수 있다.

그러나 FlashAttention과 같은 Memory-Efficient Kernel에서는 전체

\[N_hBS^2\]

Matrix를 HBM에 그대로 Materialize하지 않을 수 있다.

따라서 이 항 역시 구현에 의존한다.

48. Training Memory 전체 구성

Activation 외에도 Training에는 일반적으로

  • Parameters
  • Gradients
  • Optimizer States
  • Temporary Buffers
  • Activations

등의 Memory가 필요하다.

따라서

\[\boxed{ \text{total training VRAM} \neq \text{activation memory only} }\]

49. Numerical Example — Input

이제 원자료의 2-Layer Network를 직접 Forward Propagation한다.

Batch Input은

\[\boxed{ \mathbf X = \begin{bmatrix} 1.0&0.5&-1.0\\ 0.0&2.0&1.0 \end{bmatrix} }\]

Shape은

\[\boxed{ 2\times3 }\]

즉

\[B=2, \qquad d_{\mathrm{in}}=3\]

50. First-Layer Weight

\[\boxed{ \mathbf W^{(1)} = \begin{bmatrix} 0.2&-0.4\\ 0.5&0.1\\ -0.1&0.8 \end{bmatrix} }\]

Shape은

\[\boxed{ 3\times2 }\]

따라서 Hidden Dimension은

\[\boxed{ d_{\mathrm{hidden}}=2 }\]

51. First-Layer Bias

\[\boxed{ \mathbf b^{(1)} = \begin{bmatrix} 0.1&-0.2 \end{bmatrix} }\]

Batch의 두 Row에 동일하게 Broadcasting된다.

52. First-Layer Shape Check

Matrix Product는

\[(2\times3)(3\times2) = \boxed{ 2\times2 }\]

따라서

\[\boxed{ \mathbf Z^{(1)} \in \mathbb R^{2\times2} }\]

53. First Row — First Hidden Unit

첫 번째 Sample과 첫 번째 Hidden Unit의 Dot Product는

\[\begin{aligned} z_{11}^{(1)\prime} &= (1.0)(0.2) + (0.5)(0.5) + (-1.0)(-0.1)\\ &= 0.2+0.25+0.1\\ &= \boxed{ 0.55 } \end{aligned}\]

54. First Row — Second Hidden Unit

\[\begin{aligned} z_{12}^{(1)\prime} &= (1.0)(-0.4) + (0.5)(0.1) + (-1.0)(0.8)\\ &= -0.4+0.05-0.8\\ &= \boxed{ -1.15 } \end{aligned}\]

55. Second Row — First Hidden Unit

\[\begin{aligned} z_{21}^{(1)\prime} &= (0)(0.2) + (2)(0.5) + (1)(-0.1)\\ &= 0+1.0-0.1\\ &= \boxed{ 0.9 } \end{aligned}\]

56. Second Row — Second Hidden Unit

\[\begin{aligned} z_{22}^{(1)\prime} &= (0)(-0.4) + (2)(0.1) + (1)(0.8)\\ &= 0+0.2+0.8\\ &= \boxed{ 1.0 } \end{aligned}\]

57. First Affine Product

따라서 Bias를 더하기 전 Matrix Product는

\[\boxed{ \mathbf X\mathbf W^{(1)} = \begin{bmatrix} 0.55&-1.15\\ 0.90&1.00 \end{bmatrix} }\]

58. Bias Addition

Bias를 각 Row에 더한다.

\[\mathbf Z^{(1)} = \begin{bmatrix} 0.55+0.1&-1.15-0.2\\ 0.90+0.1&1.00-0.2 \end{bmatrix}\]

따라서

\[\boxed{ \mathbf Z^{(1)} = \begin{bmatrix} 0.65&-1.35\\ 1.00&0.80 \end{bmatrix} }\]

59. ReLU

첫 번째 Layer의 Activation Function은

\[\boxed{ \operatorname{ReLU}(z) = \max(0,z) }\]

Element-wise로 적용한다.

60. First Activation

\[\mathbf A^{(1)} = \begin{bmatrix} \max(0,0.65)&\max(0,-1.35)\\ \max(0,1.00)&\max(0,0.80) \end{bmatrix}\]

따라서

\[\boxed{ \mathbf A^{(1)} = \begin{bmatrix} 0.65&0\\ 1.00&0.80 \end{bmatrix} }\]

61. ReLU가 만든 변화

Pre-activation의

\[-1.35\]

는 ReLU를 통과하며

\[\boxed{ 0 }\]

이 된다.

반면 Positive Value는 그대로 유지된다.

62. Second-Layer Weight

두 번째 Layer Weight는

\[\boxed{ \mathbf W^{(2)} = \begin{bmatrix} 1.0\\ -0.5 \end{bmatrix} }\]

Shape은

\[\boxed{ 2\times1 }\]

63. Second-Layer Bias

Bias는

\[\boxed{ \mathbf b^{(2)} = \begin{bmatrix} 0.5 \end{bmatrix} }\]

Output Dimension은

\[\boxed{ 1 }\]

64. Second-Layer Shape Check

\[\mathbf A^{(1)} \in \mathbb R^{2\times2}\]

이고

\[\mathbf W^{(2)} \in \mathbb R^{2\times1}\]

이므로

\[\boxed{ \mathbf A^{(1)} \mathbf W^{(2)} \in \mathbb R^{2\times1} }\]

65. First Output Before Bias

첫 번째 Sample은

\[\begin{aligned} 0.65(1.0) + 0(-0.5) &= \boxed{ 0.65 } \end{aligned}\]

66. Second Output Before Bias

두 번째 Sample은

\[\begin{aligned} 1.00(1.0) + 0.80(-0.5) &= 1.00-0.40\\ &= \boxed{ 0.60 } \end{aligned}\]

67. Second Linear Product

따라서

\[\boxed{ \mathbf A^{(1)} \mathbf W^{(2)} = \begin{bmatrix} 0.65\\ 0.60 \end{bmatrix} }\]

68. Final Prediction

Bias \(0.5\)를 더하면

\[\hat{\mathbf Y} = \begin{bmatrix} 0.65+0.5\\ 0.60+0.5 \end{bmatrix}\]

따라서

\[\boxed{ \hat{\mathbf Y} = \begin{bmatrix} 1.15\\ 1.10 \end{bmatrix} }\]

69. Identity Output Activation

두 번째 Layer의 Activation Function은 Identity이므로

\[\boxed{ \mathbf A^{(2)} = \mathbf Z^{(2)} = \hat{\mathbf Y} }\]

70. Target

Target Vector는

\[\boxed{ \mathbf y = \begin{bmatrix} 1.50\\ 0.00 \end{bmatrix} }\]

71. Prediction Error

Prediction Error는

\[\begin{aligned} \hat{\mathbf Y} - \mathbf y &= \begin{bmatrix} 1.15\\ 1.10 \end{bmatrix} - \begin{bmatrix} 1.50\\ 0 \end{bmatrix}\\ &= \boxed{ \begin{bmatrix} -0.35\\ 1.10 \end{bmatrix} } \end{aligned}\]

72. Squared Errors

각 Sample의 Squared Error는

\[(-0.35)^2 = \boxed{ 0.1225 }\]

이고

\[(1.10)^2 = \boxed{ 1.2100 }\]

73. MSE

Batch Size가

\[B=2\]

이므로

\[\begin{aligned} \mathcal L &= \frac12 [ 0.1225+1.2100 ]\\ &= \frac12 (1.3325)\\ &= \boxed{ 0.66625 } \end{aligned}\]

74. Numerical Example 전체 흐름

이번 Forward Pass는

\[\boxed{ X \rightarrow Z^{(1)} \rightarrow A^{(1)} \rightarrow Z^{(2)} \rightarrow \hat Y \rightarrow \mathcal L }\]

순서로 진행된다.

75. Example Computational Graph

좀 더 세부적으로 쓰면

\[X,W^{(1)},b^{(1)} \rightarrow Z^{(1)}\]
\[Z^{(1)} \rightarrow \operatorname{ReLU} \rightarrow A^{(1)}\]
\[A^{(1)},W^{(2)},b^{(2)} \rightarrow Z^{(2)}\]
\[Z^{(2)},y \rightarrow \mathcal L\]

76. Shared Dependencies

예를 들어

\[W^{(1)}\]

은

\[Z^{(1)}\]

을 통해 이후 모든 Node에 간접적인 영향을 준다.

즉

\[\boxed{ W^{(1)} \rightarrow Z^{(1)} \rightarrow A^{(1)} \rightarrow Z^{(2)} \rightarrow \mathcal L }\]

라는 Dependency Path가 존재한다.

77. Forward와 Backpropagation

Forward Pass에서는 Graph의 Edge 방향으로 값을 계산한다.

\[\boxed{ \text{input} \rightarrow \text{loss} }\]

Backpropagation에서는 이 Graph의 Dependency를 역방향으로 따라가며 Chain Rule을 적용한다.

\[\boxed{ \text{loss} \rightarrow \text{parameters} }\]

78. Forward Pass가 Backward를 준비한다

따라서 Forward Propagation은 Prediction만 계산하는 단계가 아니다.

Training에서는

\[\boxed{ \text{Backward에 필요한 computation state를 생성하는 단계} }\]

이기도 하다.

79. Decoder-Only Transformer Forward Pass

원자료는 Decoder-only Transformer의 Forward Pass를 거대한 Computational Graph로 표현한다.

입력 Token Sequence에서 시작하여 여러 Transformer Block을 거친 뒤 Vocabulary Logit과 Loss를 계산한다.

80. Token Representation

Source는 첫 단계를 개략적으로

\[\boxed{ \mathbf X_0 = \operatorname{Embedding}(\mathbf t) + \text{position information} }\]

이라는 의미로 설명한다.

즉 Token ID가 Continuous Hidden Representation으로 변환된다.

81. RoPE에 대한 구조적 주의

원자료에는

\[\operatorname{Embedding}(\mathbf t)+\operatorname{RoPE}\]

처럼 표현되어 있다.

다만 현대 Decoder-only Transformer의 일반적인 RoPE 사용에서는 RoPE를 Embedding Vector에 단순히 더하는 방식이라기보다 Attention 내부의 Query/Key에 회전 변환으로 적용한다.

따라서 source의 표현은 Forward Graph의 Position Information을 간략화한 도식으로 이해한다.

82. Pre-Norm Transformer Block

원자료의 Decoder Block은 Pre-Norm Residual 구조로 표현된다.

첫 번째 Sub-layer는 개략적으로

\[\boxed{ \mathbf X_l' = \mathbf X_{l-1} + \operatorname{GQA} \left( \operatorname{RMSNorm} ( \mathbf X_{l-1} ) \right) }\]

83. Attention Residual Path

즉 첫 번째 경로는

\[\boxed{ X_{l-1} \rightarrow \operatorname{RMSNorm} \rightarrow \operatorname{Attention} \rightarrow \operatorname{Residual Add} }\]

Residual Connection 때문에 입력

\[X_{l-1}\]

도 Addition Node의 Parent가 된다.

84. FFN Residual Path

두 번째 Sub-layer는 source에서

\[\boxed{ \mathbf X_l = \mathbf X_l' + \operatorname{SwiGLU} \left( \operatorname{RMSNorm}( \mathbf X_l' ) \right) }\]

로 표현한다.

85. Transformer Block DAG

따라서 하나의 Block은 개념적으로

\[\boxed{ X \rightarrow \operatorname{Norm} \rightarrow \operatorname{Attention} \rightarrow + \rightarrow \operatorname{Norm} \rightarrow \operatorname{FFN} \rightarrow + }\]

라는 DAG 구조를 가진다.

86. Residual Connection과 DAG

Residual Connection은 Graph에서 Branch를 만든다.

예를 들어

\[X\]

가

  1. RMSNorm–Attention 경로
  2. Residual 직접 경로

두 곳으로 전달된다.

이후 두 Branch가 Addition Node에서 합쳐진다.

87. $N$ Transformer Blocks

이 Block을

\[N\]

번 반복하면

\[\boxed{ X_0 \rightarrow X_1 \rightarrow \cdots \rightarrow X_N }\]

이 된다.

각 Block 내부에서는 다시 여러 Branch와 Matrix Operation이 존재한다.

88. Final Normalization

마지막 Transformer Block 이후 Final RMSNorm을 적용한다.

\[\boxed{ H = \operatorname{RMSNorm} ( X_N ) }\]

로 생각할 수 있다.

89. Unembedding / LM Head

Row-wise Hidden-State Convention에서

\[H \in \mathbb R^{B\times S\times d}\]

이고 Output Weight를

\[W_{\mathrm{unembed}} \in \mathbb R^{d\times V}\]

라고 두면

\[\boxed{ Z_{\mathrm{logits}} = HW_{\mathrm{unembed}} }\]

결과 Shape은

\[\boxed{ B\times S\times V }\]

90. Vocabulary Logits

각 Token Position마다 Vocabulary Size

\[V\]

개의 Logit이 생성된다.

즉

\[\boxed{ \mathbf z_t \in \mathbb R^V }\]

DL-03에서 이 Logit에 Softmax를 적용하여 Next-Token Probability를 얻었다.

91. Softmax Output

\[\boxed{ \mathbf p_t = \operatorname{Softmax} ( \mathbf z_t ) }\]

그리고 정답 Token

\[y_t\]

의 Probability를 사용해 Cross-Entropy/NLL을 계산한다.

92. Language Modeling Loss

Source의 구조를 정리하면

\[\boxed{ \mathcal L = -\sum_t \log \operatorname{Softmax} ( \mathbf z_t )_{y_t} }\]

실제 Training에서는 Masking과 Reduction 방식에 따라 유효 Token에 대한 평균 또는 합을 사용할 수 있다.

93. LLM Forward DAG 전체

전체적으로

\[\boxed{ \text{Token IDs} \rightarrow \text{Embedding} \rightarrow \text{Transformer Blocks} \rightarrow \text{Final Norm} \rightarrow \text{LM Head} \rightarrow \text{Logits} \rightarrow \text{Loss} }\]

94. Forward Graph의 크기

LLM에서는 Layer 하나가 단순한

\[Wx+b\]

연산 하나가 아니다.

하나의 Block 내부에

  • Norm
  • Q/K/V Projection
  • Attention Score
  • Softmax
  • Value Aggregation
  • Output Projection
  • Residual
  • FFN

등 수많은 Node가 존재한다.

95. Activation Memory Problem

Training에서는 이 거대한 Graph의 여러 Intermediate Activation이 Backward에서 다시 필요하다.

Sequence Length와 Batch Size가 커질수록 Activation Memory도 증가한다.

따라서 대규모 Model Training에서는 Activation Storage가 중요한 Memory Bottleneck이 될 수 있다.

96. Activation Checkpointing

원자료는 해결 방법으로 Activation Checkpointing 또는 Gradient Checkpointing을 제시한다.

핵심 아이디어는

\[\boxed{ \text{모든 Intermediate를 저장하지 않는다} }\]

97. Checkpoint

Computational Graph의 일부 Node만 저장한다.

예를 들어

\[\boxed{ \text{Transformer Block input/output} }\]

과 같은 경계 Tensor를 Checkpoint로 선택할 수 있다.

98. Discard Intermediate Activations

Checkpoint 사이에서 생성되는 세부 Intermediate Activation은 Forward 이후 버릴 수 있다.

즉 Memory를 절약한다.

99. Recompute

Backward에서 해당 Activation이 다시 필요하면 저장된 Checkpoint로부터 Forward Operation 일부를 다시 계산한다.

\[\boxed{ \text{store less} \rightarrow \text{recompute more} }\]

100. Memory–Compute Trade-off

Activation Checkpointing의 본질은

\[\boxed{ \text{Memory} \leftrightarrow \text{Compute} }\]

Trade-off다.

Memory Consumption을 줄이는 대신 추가 Forward Computation이 필요하다.

101. Source의 $O(\sqrt L)$ 주장

원자료는 Checkpointing을 통해 Activation Memory를

\[O(L)\]

에서

\[O(\sqrt L)\]

수준으로 줄일 수 있다고 설명한다.

이 형태는 특정 Checkpoint 배치 전략을 분석할 때 나타나는 대표적인 결과로 이해하는 것이 적절하다.

모든 Gradient Checkpointing 구현이 항상 정확히 같은 Complexity를 갖는 것은 아니다.

102. 33% FLOPs 주장에 대한 주의

원자료는 추가 연산량을 약

\[33\%\]

라고 표현한다.

하지만 실제 Recompute Overhead는

  • Checkpoint 위치
  • 몇 개의 Operation을 재계산하는지
  • Kernel 비용
  • Architecture

에 따라 달라진다.

따라서

\[\boxed{ \text{checkpointing} \Rightarrow \text{exactly 33\% more FLOPs} }\]

라는 보편적인 법칙으로 해석하지 않는다.

103. Checkpointing의 핵심 결과

보편적으로 유지되는 핵심은

\[\boxed{ \text{less stored activation memory} }\]

를 얻기 위해

\[\boxed{ \text{additional recomputation} }\]

을 수행한다는 점이다.

104. Computational Graph와 Checkpointing의 관계

Checkpointing은 단순한 GPU Memory Trick이 아니라 Computational Graph를 어디에서 끊어 저장할 것인지 결정하는 문제다.

즉

\[\boxed{ \text{Computational Graph structure} \rightarrow \text{checkpoint placement} \rightarrow \text{memory/compute trade-off} }\]

105. DL-03과 연결

DL-03에서는

\[\boxed{ \text{Logits} \rightarrow \text{Softmax} \rightarrow \text{Cross-Entropy} }\]

를 다뤘다.

DL-04에서는 이것이 전체 Forward Computational Graph의 마지막 부분에 위치한다.

\[\boxed{ \text{Network Forward} \rightarrow \text{Logits} \rightarrow \text{Softmax/NLL} }\]

106. CO-07과 연결

CO-07에서는 Linear Layer의 Backpropagation을 다뤘다.

\[Y=XW\]

일 때

\[\boxed{ \frac{\partial L}{\partial W} = X^TG }\]

였다.

이 식에서

\[X\]

가 필요하므로 Forward Activation을 저장해야 하는 이유를 DL-04에서 다시 확인할 수 있다.

107. CO-09과 연결

CO-09에서는 Loss의 Gradient를 이용하여 Parameter를 Update했다.

\[\boxed{ \theta_{t+1} = \theta_t-\eta\nabla_\theta L }\]

하지만

\[\nabla_\theta L\]

을 얻으려면 먼저 Forward Pass로

\[L\]

을 계산하고 Computational Graph를 구성해야 한다.

108. ML-01과 연결

ML-01의 Empirical Risk는

\[\boxed{ \mathcal R_{\mathrm{emp}} = \frac1N \sum_i \mathcal L_i }\]

였다.

각

\[\mathcal L_i\]

를 계산하려면 Model의 Forward Propagation이 먼저 수행되어야 한다.

따라서

\[\boxed{ \text{ERM Objective} \rightarrow \text{Forward Pass} \rightarrow \text{Loss} \rightarrow \text{Gradient} }\]

로 연결된다.

109. 핵심 식 — Forward Layer

Single-Sample Convention에서는

\[\boxed{ \mathbf z^{(l)} = \mathbf W^{(l)} \mathbf a^{(l-1)} + \mathbf b^{(l)} }\]
\[\boxed{ \mathbf a^{(l)} = \sigma_l( \mathbf z^{(l)} ) }\]

110. 핵심 식 — Batch Layer

Row-wise Batch Convention에서는

\[\boxed{ \mathbf Z^{(l)} = \mathbf A^{(l-1)} \mathbf W^{(l)} + \mathbf1_B \mathbf b^{(l)} }\]

111. 핵심 식 — Computational Graph Node

\[\boxed{ v_i = f_i \left( \operatorname{Parents}(v_i) \right) }\]

라는 형태로 각 Node를 표현할 수 있다.

112. 핵심 식 — Source Activation Memory Approximation

원자료의 단순화된 Transformer Activation Memory는

\[\boxed{ M_{\mathrm{layer}} \approx \left( 14BSd + N_hBS^2 \right)p }\]

전체 Layer에 대해

\[\boxed{ M_{\mathrm{total\_act}} = L M_{\mathrm{layer}} }\]

단, 이는 특정 Activation 저장 가정을 사용한 대표 근사식이다.

113. 핵심 식 — Numerical Forward Pass

첫 Layer:

\[\boxed{ Z^{(1)} = XW^{(1)}+b^{(1)} }\]
\[\boxed{ A^{(1)} = \operatorname{ReLU} ( Z^{(1)} ) }\]

둘째 Layer:

\[\boxed{ \hat Y = A^{(1)}W^{(2)} + b^{(2)} }\]

Loss:

\[\boxed{ \mathcal L = \frac1B \| \hat Y-y \|_2^2 }\]

114. 핵심 수치 결과

원자료의 Example에서는

\[\boxed{ Z^{(1)} = \begin{bmatrix} 0.65&-1.35\\ 1.00&0.80 \end{bmatrix} }\]

ReLU 이후

\[\boxed{ A^{(1)} = \begin{bmatrix} 0.65&0\\ 1.00&0.80 \end{bmatrix} }\]

115. 핵심 출력 결과

최종 Prediction은

\[\boxed{ \hat Y = \begin{bmatrix} 1.15\\ 1.10 \end{bmatrix} }\]

이고

\[\boxed{ \mathcal L = 0.66625 }\]

116. 혼동하기 쉬운 부분 — Forward와 Training

Forward Propagation은 Parameter를 Update하는 과정이 아니다.

Forward에서는

\[\boxed{ \theta \text{를 사용해 } \hat y,L \text{을 계산} }\]

한다.

Parameter Update는 Backward로 Gradient를 계산한 뒤 Optimizer가 수행한다.

117. 혼동하기 쉬운 부분 — Pre-Activation과 Activation

\[\boxed{ z^{(l)} }\]

은 Activation Function 적용 전이고

\[\boxed{ a^{(l)} }\]

은 Activation Function 적용 후다.

둘을 같은 Tensor로 취급하면 안 된다.

118. 혼동하기 쉬운 부분 — Computational Graph

Computational Graph는 Neural Network의 Layer Diagram과 완전히 같은 개념으로 한정되지 않는다.

Layer 하나도 여러 Operation Node로 나눌 수 있다.

즉 Graph는 실제 계산 Dependency를 더 세밀하게 나타낼 수 있다.

119. 혼동하기 쉬운 부분 — DAG

DAG라는 것은 Model에 반복적인 Layer 구조가 없어야 한다는 뜻이 아니다.

같은 형태의 Transformer Block이 여러 번 반복되어도 각 Forward Pass의 연산 Node는 시간/Layer 순서에 따라 별개의 Node이므로 계산 Dependency Graph는 DAG로 표현할 수 있다.

120. 혼동하기 쉬운 부분 — Activation Memory

“모든 Intermediate Tensor를 반드시 그대로 저장한다”가 원칙은 아니다.

Autograd Engine과 Kernel Implementation은 Backward에 필요한 값만 저장하거나 다른 Representation을 저장할 수 있다.

Checkpointing에서는 일부 값을 의도적으로 저장하지 않는다.

121. 혼동하기 쉬운 부분 — Memory Dominance

원자료는 Activation Memory의 중요성을 강조하지만

\[\boxed{ \text{training memory가 항상 activation에 의해 지배된다} }\]

고 일반화할 수는 없다.

Parameter 수, Optimizer State, Precision, Batch Size, Sequence Length 등에 따라 주요 Memory Source가 달라진다.

122. 혼동하기 쉬운 부분 — $S^2$ Memory

\[N_hBS^2\]

항은 Naive Dense Attention의 대표적인 Intermediate 규모다.

FlashAttention 계열 구현에서는 전체 Attention Matrix를 HBM에 저장하지 않을 수 있으므로 실제 Memory Footprint가 달라진다.

123. 혼동하기 쉬운 부분 — RoPE

RoPE는 일반적인 Absolute Position Embedding처럼

\[\text{Token Embedding}+\text{Position Vector}\]

형태로 단순히 더해지는 방식과 동일하지 않다.

현대 Transformer에서는 보통 Attention 내부의 Query와 Key에 Rotary Transformation을 적용한다.

124. 혼동하기 쉬운 부분 — Checkpointing Complexity

\[O(L) \rightarrow O(\sqrt L)\]

은 특정 Checkpoint Schedule에서 얻을 수 있는 대표적인 Memory–Compute 분석이다.

모든 Framework의 Gradient Checkpointing을 설명하는 고정된 Complexity는 아니다.

125. 혼동하기 쉬운 부분 — Recompute Cost

추가 FLOPs 역시 정확히 고정된 값이 아니다.

핵심 관계는

\[\boxed{ \text{memory saving} \Longleftrightarrow \text{recomputation cost} }\]

126. 전체 개념 연결

Forward Propagation에서는

\[\boxed{ a^{(0)} = x }\]

에서 시작한다.

각 Layer에서

\[\boxed{ a^{(l-1)} \rightarrow z^{(l)} \rightarrow a^{(l)} }\]

을 계산한다.

최종적으로

\[\boxed{ a^{(L)} = \hat y }\]

를 얻고

\[\boxed{ \hat y,y \rightarrow \mathcal L }\]

을 계산한다.

127. Computational Graph 연결

이 모든 계산은

\[\boxed{ \text{Variables} + \text{Operations} + \text{Dependencies} }\]

를 가진 DAG로 표현할 수 있다.

따라서

\[\boxed{ \text{Mathematical Function} \rightarrow \text{Computational Graph} \rightarrow \text{Forward Evaluation} }\]

128. Memory 연결

Training에서는 Backpropagation을 위해 Forward Intermediate가 다시 필요하다.

따라서

\[\boxed{ \text{Forward} \rightarrow \text{Intermediate Activations} \rightarrow \text{Activation Memory} }\]

Memory가 부족하면

\[\boxed{ \text{store fewer activations} \rightarrow \text{recompute} }\]

라는 Activation Checkpointing을 사용할 수 있다.

129. Transformer 연결

Decoder-only LLM에서는

\[\boxed{ \text{Tokens} \rightarrow \text{Hidden States} \rightarrow \text{Transformer Blocks} \rightarrow \text{Vocabulary Logits} }\]

이후

\[\boxed{ \text{Logits} \rightarrow \text{Softmax / Cross-Entropy} \rightarrow \text{Loss} }\]

로 이어진다.

130. Training 전체 연결

전체 Deep Learning Training Pipeline에서 DL-04의 위치는 다음과 같다.

\[\boxed{ \text{Data} \rightarrow \text{Forward Propagation} \rightarrow \text{Loss} \rightarrow \text{Backpropagation} \rightarrow \text{Optimizer Update} }\]

즉 Forward Propagation은 모든 Gradient-Based Training의 출발점이다.

131. 정리

Forward Propagation은 입력 Tensor를 Neural Network의 Computational Graph를 따라 전방향으로 전달하여 Prediction과 Loss를 계산하는 과정이다.

\(l\)번째 Layer에서는

\[\boxed{ z^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)} }\]

를 계산하고

\[\boxed{ a^{(l)} = \sigma_l( z^{(l)} ) }\]

를 적용한다.

이를 반복하면

\[\boxed{ a^{(0)} = x \rightarrow a^{(1)} \rightarrow \cdots \rightarrow a^{(L)} = \hat y }\]

를 얻는다.

Training에서는 최종적으로

\[\boxed{ \hat y,y \rightarrow \mathcal L }\]

까지 계산한다.

이 전체 연산은 DAG

\[\boxed{ \mathcal G = (\mathcal V,\mathcal E) }\]

형태의 Computational Graph로 표현할 수 있다.

각 Node는

\[\boxed{ v_i = f_i( \operatorname{Parents}(v_i) ) }\]

와 같이 Parent Node의 결과에 의존한다.

따라서 Forward Pass는 DAG를 Dependency Order에 따라 평가하는 과정이다.

Forward에서 생성되는

\[z^{(l)}, \qquad a^{(l)}\]

등의 Intermediate Activation은 Backpropagation에서 다시 필요할 수 있다.

예를 들어

\[Y=XW\]

의 Weight Gradient는

\[\boxed{ \frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y} }\]

이므로 Forward Input \(X\)가 필요하다.

따라서

\[\boxed{ \text{Forward values} \rightarrow \text{Backward gradients} }\]

라는 연결이 존재한다.

원자료의 단순화된 Transformer Activation Memory Model은

\[\boxed{ M_{\mathrm{layer}} \approx ( 14BSd + N_hBS^2 )p }\]

이고

\[\boxed{ M_{\mathrm{total\_act}} = LM_{\mathrm{layer}} }\]

다만 이 식은 모든 Transformer 구현에 보편적으로 동일한 정확식이 아니라 특정 저장 가정 아래의 대표적인 근사식이다.

원자료의 2-Layer Example에서는

\[\boxed{ X = \begin{bmatrix} 1&0.5&-1\\ 0&2&1 \end{bmatrix} }\]

에서 시작하여

\[\boxed{ Z^{(1)} = \begin{bmatrix} 0.65&-1.35\\ 1.00&0.80 \end{bmatrix} }\]

을 얻는다.

ReLU를 적용하면

\[\boxed{ A^{(1)} = \begin{bmatrix} 0.65&0\\ 1.00&0.80 \end{bmatrix} }\]

이고 두 번째 Layer를 지나

\[\boxed{ \hat Y = \begin{bmatrix} 1.15\\ 1.10 \end{bmatrix} }\]

을 얻는다.

Target

\[\boxed{ y = \begin{bmatrix} 1.5\\ 0 \end{bmatrix} }\]

에 대한 MSE는

\[\boxed{ \mathcal L = 0.66625 }\]

Decoder-only Transformer에서는 같은 원리가 훨씬 큰 Graph로 확장된다.

\[\boxed{ \text{Token Representation} \rightarrow \text{Transformer Blocks} \rightarrow \text{Final Norm} \rightarrow \text{LM Head} \rightarrow \text{Logits} \rightarrow \text{Loss} }\]

대규모 LLM Training에서는 이 Forward Graph의 Intermediate Activation 저장 비용이 커질 수 있기 때문에 Activation Checkpointing을 사용할 수 있다.

핵심은

\[\boxed{ \text{save fewer forward states} \rightarrow \text{recompute during backward} }\]

따라서 DL-04 전체의 핵심 구조는

\[\boxed{ \text{Input} \rightarrow \text{Forward Computational Graph} \rightarrow \text{Prediction} \rightarrow \text{Loss} }\]

이고,

Training 관점에서는

\[\boxed{ \text{Forward} \rightarrow \text{Activation Storage} \rightarrow \text{Backward} }\]

대규모 LLM 시스템에서는 이것이 다시

\[\boxed{ \text{Computational Graph} \rightarrow \text{Activation Memory} \rightarrow \text{Checkpoint / Recompute Trade-off} }\]

로 연결된다.
