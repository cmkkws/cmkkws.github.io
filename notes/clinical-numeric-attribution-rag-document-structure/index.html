문헌 분할, 교체 및 동일 시험 누수 감사

원문 500편(JATS XML 495 · PDF 5) 중 JATS XML 1차 선별 463편(개발 93 · 평가 370)에서 개발 표본 원문 재검토로 3편을 제외해 현재 적격 후보는 460편(개발 90 · 평가 370)이다. 개발 표본 12편 중 부적격 3편과 배정 근거 상충 1편 총 **4편을 동일 설계군 내에서 교체(난수 시드 20261115)**했다.

  • 동일 시험 교차 분할 누수 감사: 전체 후보 460편 중 시험 식별자가 추출된 321편을 대상으로 등록번호·IRB·과제번호·저자·본문 유사도를 점검한 결과, 검수 배정 60편 내부 교차 중복은 **0건**이다. 배정 표본 밖의 IRB 일치 1쌍(PMID 37322663–37322655)과 본문 유사도 후보 2쌍은 평가 확장 전 분리·제외할 예정이다.

JATS XML 계층 파싱과 대·소목차 3단계 분류

Python xml.etree.ElementTree로 JATS XML을 파싱해 초록·본문·부록·별도 표 영역(floats-group)을 구분하고, 문서 → 절 → 하위 절 → 문단·표 → 셀 계층 구조와 원문 XML ID(node_id)·경로를 보존한다.

1) 논리·공간 좌표 보존과 개발 93편 파싱 결과

  1. XML 경로(xml_path)·2차원 격자(row, column) 인코딩: 화면상 PDF 픽셀 좌표 대신 XML 트리 경로(예: 2/1/5/2)와 rowspan/colspan을 펼친 표 내부 행렬 좌표를 저장하며, 병합된 모든 좌표에 동일한 원문 셀 ID를 유지한다.
  2. 다단 머리글·각주·외부 표 참조 결합: <headers>·<thead>·scope와 행·열 겹침 범위로 다단 머리글을 셀에 연결하고 <fn>/<table-wrap-foot> 문단을 보존한다. 본문 밖 별도 표 영역(floats-group)의 표는 Results 문단의 <xref> 참조로 연결한다.
  3. 개발 93편 배치 처리 결과: 1차 개발 후보 93편 전체에서 구조화 JSON을 생성했고, 표 래퍼 320개 중 294개는 셀 구조로 파싱, 26개는 이미지 표로 분리 기록했다.

2) 대목차·소목차 3단계 역할 판정 규칙

논문마다 절 제목·순서가 달라 Introduction → Methods → Results → Discussion 순서를 일괄 강제하지 않고 아래 3단계로 판정한다.

  1. 제목 사전·sec-type 규칙 우선 판정: 장절 번호를 제거·정규화한 제목 사전과 XML sec-type 태그로 개발 93편의 본문 대목차 491개를 분류한다(규칙 충돌 시 자동 보류). 제목만으로 모호한 14개 대목차는 본문 내용과 앞뒤 절을 직접 대조해 확정했다.
  2. 희귀·충돌 제목 PubMedBERT 유사도 (score_margin): 출현 빈도 2회 이하 희귀 제목과 충돌 항목은 NeuML/pubmedbert-base-embeddings(L2 정규화)로 4개 역할(Introduction·Methods·Results·Discussion) 앵커 문구와 코사인 유사도를 계산해 역할별 최댓값 및 1·2위 점수 격차(score_margin)를 산출한 뒤 앞뒤 앵커 문맥과 결합한다.
  3. 상위 대목차 종속 소목차 분류 (>50% 유지 규칙): 같은 소목차명(예: Clinical outcomes)도 상위 절(Methods 9종 별칭 vs Results 4종 별칭)에 따라 역할을 분리한다. 하위 소목차 594개 중 316개를 규칙 배정하고, 적격 개발 문헌 92편(논평 1편 제외) 중 과반(> 50%)에서 반복된 소목차(Statistical analysis, 55/92편)만 검색 목차의 독립 단위로 유지한다.

문항 후보 생성, 가중 근거 회수 및 4단계 시점 선택

제목·초록에서 비교군·결과 지표를 탐색하되 최종 판정은 반드시 Methods(설계·분모 정의)와 Results 표·각주(실측 수치·분석 조건) 대조에 근거한다. 동일 지표라도 측정 조건·분석 집단·통계량·집계 단위가 다르면 별도 결과로 분리한다.

1) 탐색 단서 vs 최종 판정 근거 대조표

2) 제약 JSON 스키마 기반 후보 생성 (qwen3.8-27b-q4_k_m)

  • 2조건 비교 (개발 12편 · 24건): 로컬 qwen3.8-27b-q4_k_m(temperature=0, seed=20261115, max_tokens=256, thinking=OFF)에 ① 제목·초록 vs **② 제목·초록 + 검색 목차·표 캡션**을 대조했다. 자유 서술 근거는 원문 수치 복사 및 출력 절단을 유발해, 출력을 intervention·comparator·outcome·time·condition·support 6개 키 JSON으로 고정하고 support는 원문 XML 노드 ID 1개(PMID...:경로 정규식)로 제한했다.
  • 후보 우선순위: 프롬프트 명시 일차 결과 → 시험 목적 직접 관련 결과 순으로 고르며, 다중군 시험이면 명시적 대조군 + 본문 첫 번째 활성군을 쌍으로 묶고 p-value 단독 보고는 제외한다.

3) 시점·근거 ID 분리 및 가중 합산 근거 회수 알고리즘

모델이 고른 time·support에 갇히지 않도록 검색 질의는 {지표, 지표 정규식, 비교군 쌍, 측정 조건}만 사용하며, search_outlines로 분류된 Methods·Results 문단과 Results/인용(<xref>) 표를 아래 가중 점수로 순위화한다.

  • 문단 공통 점수: 정규식 지표 완전 일치(+4) + 불용어 제거 단어 커버리지(+3 × 비율) + 조건 단어 일치(최대 +2) + 상위 절 제목 관련도(최대 +3)
  • Methods 추가 가점: 평가·시점 표현 동시 등장(+2) + primary/main outcome 언급(+2) + 무작위 배정 어휘(+2) + 군 단어 포함(군당 +1) + 배정 문장 양 군 동시 명시(+4)
  • 표(table-wrap) 점수: 2 × 캡션 관련도 + 구조 텍스트(머리글·각주·문자 셀) 관련도 + 절 제목(최대 3) + 인용 Results 문단 최고점 × 0.5(최대 3)
  • 회수 상한 및 참조 문단 보충: Methods 상위 10문단, Results 상위 8문단, 표 상위 3개를 회수하며, 선정 표를 본문에서 <xref>로 인용한 Results 문단이 빠진 경우 추가 편입한다.

4) 4단계 대표 시점 선택 규칙

표·각주(T0–Tf, d3, d21 등)의 시간 표현을 hour(1/24일) · day(1일) · week(7일) · month(30일) · year(365일) 환산 일수로 정규화하고 baseline · visit · change · interval · event 5종(time_kind)으로 구분한 뒤 아래 순서로 결정한다.

  1. 양 군 쌍 존재 필터: 양 군 수치 셀이 같은 표(representation)에 쌍으로 존재하는 시점만 후보로 유지한다.
  2. Methods 주 평가 시점 우선: primary endpoint/outcome 문장이 단일 시점을 지목하면 최우선 선택한다(다수 시점 충돌 또는 표 미보고 시 보류).
  3. 마지막 치료 후 시점 선택: 미지정 시 동일 유형(time_kind) 시점이 1개면 단독 채택하고, 여럿이면 환산 일수가 가장 큰 마지막 치료 후 시점을 선택한다(동률 시 보류, 유의확률·효과크기 미사용).

표 셀 연결(극성·분모) 및 개발 12편 파일럿 검증

검색 1순위 표를 중심으로 수치 셀·다단 머리글·각주·Methods 배정 문단을 결합해 영문 문항과 검수용 정답 레코드를 생성했다.

1) 표 약어 극성 검증, 조건 일치 및 분모 확정 세부 규칙

  • 극성 충돌 패널티 및 연결 임계값: Methods·초록·각주·약어 표에서 Group A/B, T/C, experimental/control 약어 사전을 구축하고 열/행 머리글·밴드 행(band)·상속 열(carry)로 소속 군을 판정한다. 단어를 공유하지만 의미가 반대인 군(fixed vs unfixed, with vs without, receiving vs not receiving, 농도 %)이 충돌하면 0점 패널티를 부여하며, 두 군 중 최고 일치 점수가 0.6 미만이거나 1·2위 점수 격차가 0.15 미만이면 보류한다.
  • 표 내 조건·집단 일치 필터: p-value·신뢰구간(CI) 행·열을 제외하고, ITT/PP/VRS/VAS/air-blast/tactile/logMAR 태그 및 변화량(change from baseline) 여부를 대조해 양 군이 동일 조건에 놓인 쌍만 통과시킨다(통합 대조군·쌍 비교만 보고된 경우 보류).
  • 통계량 분리 및 분석 분모 코드북: mean ± SD/mean (SD)는 1(평균)·2(SD), median (IQR)은 7(중앙값)·9(IQR 하한)·9(IQR 상한)으로 분리하고 단일 셀 mean은 같은/다음 행의 인접 SD와 결합한다. 분석 분모(n)는 머리글 n=...과 인접 n 셀 값이 단일 양의 정수로 일치할 때만 **4(분석 분모, 범위 1:실제 분석)**로 확정하며(상충 시 2:판정 불가, 부재 시 1:미보고), 배정 수나 타 행 사건 수 대체를 금지한다.

2) 개발 12편 파일럿 검증 결과

3) 영문 표준 템플릿 및 블라인드 검수·동결 과제

개발 8편에서 생성한 영문 8문항(50개 값 슬롯)에는 모두 아래 공통 지시를 결합했다.

"For each arm, give the measurement unit, the unit of analysis, and the sample size actually used for the requested summary. If a field is not reported or cannot be established, say so. Cite the supporting text or the relevant table row, column, and footnote."

  • v3 블라인드 독립 검수 진행: 3인 검수자(Reviewer_A: 5문항·30슬롯 / Reviewer_B: 6문항·38슬롯 / Reviewer_C: 5문항·32슬롯)용 v3 엑셀(배정목록_40편)과 관리자 대조 통합본(Manager_Assigned.xlsx · 배정현황_60편)으로 독립 합의 및 필드별 일치도·소요 시간을 계측 중이다.
  • 평가 48편 동결 및 별도 검증: 평가 48편 적용 전 문항 선택 순서·프롬프트·검색 범위·셀 연결·보류 규칙을 동결하며, XML 없는 PDF 5편(pdfplumber·Docling 복원)과 이미지 표(93편 중 26개)는 독립 검증 항목으로 분리한다.
