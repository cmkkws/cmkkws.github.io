Least Squares Approximation

선형 시스템

\[\boxed{ A\mathbf x=\mathbf b }\]

를 생각하자. 여기서 다음과 같다.

\[\begin{gathered} \boxed{ A\in\mathbb R^{M\times N} } \\[6pt] \boxed{ \mathbf x\in\mathbb R^N } \\[6pt] \boxed{ \mathbf b\in\mathbb R^M } \end{gathered}\]

Exact Solution

만약 어떤

\[\mathbf x\]

가 존재하여

\[A\mathbf x=\mathbf b\]

를 정확히 만족한다면 이를 Exact Solution이라고 할 수 있다. 이 경우 다음과 같다.

\[\boxed{ \mathbf b\in\mathcal C(A) }\]

Column Space

행렬 \(A\)의 Column Space는 \(A\)의 열벡터들의 모든 Linear Combination으로 이루어진 공간이다 다음과 같다.

\[\boxed{ \mathcal C(A) = \{ A\mathbf x \mid \mathbf x\in\mathbb R^N \} }\]

따라서 모든 Model Prediction

\[A\mathbf x\]

는 반드시

\[\mathcal C(A)\]

안에 존재한다.

Overdetermined System

방정식 수가 미지수 수보다 많은 경우

\[\boxed{ M>N }\]

를 Overdetermined System이라고 한다. 즉

\[A\in\mathbb R^{M\times N}\]

에서 Row가 Column보다 많다.

중요한 주의 — Overdetermined라고 해가 없는 것은 아니다

\[M>N\]

이라는 사실 자체가 Exact Solution이 존재하지 않는다는 뜻은 아니다. Exact Solution 존재 여부는

\[\boxed{ \mathbf b\in\mathcal C(A) }\]

인지에 의해 결정된다.

Inconsistent System

만약

\[\boxed{ \mathbf b\notin\mathcal C(A) }\]

라면 어떤 \(\mathbf x\)를 선택해도

\[A\mathbf x=\mathbf b\]

를 정확히 만족할 수 없다. 이 경우 선형 시스템은 Inconsistent하다.

Approximation Problem

Exact Solution이 없다면 목표를 바꾼다.

\[\boxed{ A\mathbf x }\]

가 \(\mathbf b\)와 가능한 한 가까워지도록 \(\mathbf x\)를 선택한다. 즉

\[\boxed{ A\mathbf x \approx \mathbf b }\]

를 만드는 문제다.

Residual Vector

Prediction과 Observation 사이의 차이를 Residual Vector라고 한다. 원자료의 Convention을 따르면 다음과 같다.

\[\boxed{ \mathbf e(\mathbf x) = \mathbf b-A\mathbf x }\]

Residual Shape

\[\mathbf b \in \mathbb R^M\]

이고

\[A\mathbf x \in \mathbb R^M\]

이므로 다음과 같다.

\[\boxed{ \mathbf e \in \mathbb R^M }\]

Residual Component

\(i\)번째 Observation의 Residual은 다음과 같다.

\[\boxed{ e_i = b_i-(A\mathbf x)_i }\]

즉 실제 값에서 예측 값을 뺀 값이다.

Sum of Squared Errors

Residual의 Euclidean Norm 제곱은 다음과 같다.

\[\boxed{ \|\mathbf e\|_2^2 = \sum_{i=1}^{M}e_i^2 }\]

이를 Sum of Squared Errors, SSE라고 한다.

Least Squares Objective

따라서 Least Squares Problem은 다음과 같다.

\[\boxed{ \hat{\mathbf x} = \arg\min_{\mathbf x\in\mathbb R^N} \| \mathbf b-A\mathbf x \|_2^2 }\]

원자료의 기본 정의가 바로 이 식이다.

Loss Function

Loss를

\[\boxed{ L(\mathbf x) = \| \mathbf b-A\mathbf x \|_2^2 }\]

라고 정의한다. 따라서 다음과 같다.

\[\boxed{ \hat{\mathbf x} = \arg\min_{\mathbf x} L(\mathbf x) }\]

Geometric Interpretation

Prediction

\[A\mathbf x\]

는 항상

\[\mathcal C(A)\]

위에 존재한다. 따라서 Least Squares는

\[\boxed{ \mathbf b \text{와 } \mathcal C(A) \text{ 사이에서 가장 가까운 점을 찾는 문제} }\]

로 볼 수 있다.

Projection Point

최적해를

\[\hat{\mathbf x}\]

라고 하면 최적 Prediction은 다음과 같다.

\[\boxed{ \mathbf p = A\hat{\mathbf x} }\]

\(\mathbf p\)는

\[\mathcal C(A)\]

위에 존재한다.

Orthogonal Projection

Euclidean Distance를 최소화하는 \(\mathbf p\)는 \(\mathbf b\)를

\[\mathcal C(A)\]

위로 직교 정사영한 점이다. 즉 다음과 같다.

\[\boxed{ \mathbf p = \operatorname{Proj}_{\mathcal C(A)} (\mathbf b) }\]

Optimal Residual

최적 Residual은 다음과 같다.

\[\boxed{ \mathbf e = \mathbf b-A\hat{\mathbf x} }\]

Geometric Projection의 성질에 의해 이 Residual은 Column Space에 직교한다.

Orthogonality Condition

따라서 다음과 같다.

\[\boxed{ \mathbf e \perp \mathcal C(A) }\]

즉 \(A\)의 모든 Column

\[\mathbf a_i\]

에 대해 다음과 같다.

\[\boxed{ \mathbf a_i^T \mathbf e = 0 }\]

Residual 대입

Residual

\[\mathbf e = \mathbf b-A\hat{\mathbf x}\]

를 대입하면 다음과 같다.

\[\boxed{ \mathbf a_i^T ( \mathbf b-A\hat{\mathbf x} ) = 0 }\]

for 다음과 같다.

\[i=1,\dots,N\]

Matrix Form

모든 Column에 대한 직교 조건을 하나로 모으면 다음과 같다.

\[\boxed{ A^T ( \mathbf b-A\hat{\mathbf x} ) = \mathbf0 }\]

Normal Equation

식을 전개하면 다음과 같다.

\[A^T\mathbf b - A^TA\hat{\mathbf x} = 0\]

따라서 다음과 같이 얻는다.

\[\boxed{ A^TA\hat{\mathbf x} = A^T\mathbf b }\]

이를 Normal Equation이라고 한다.

왜 Normal이라는 이름인가

여기서 Normal은 확률분포의 Normal Distribution을 의미하지 않는다. Residual이 Column Space에

\[\boxed{ \text{normal} = \text{orthogonal} }\]

하다는 기하학적 의미와 연결된다.

Normal Equation의 Dimension

\[A \in \mathbb R^{M\times N}\]

이면 다음과 같다.

\[A^T \in \mathbb R^{N\times M}\]

따라서 다음과 같다.

\[\boxed{ A^TA \in \mathbb R^{N\times N} }\]

Right-Hand Side Shape

\[A^T \in \mathbb R^{N\times M}\]

이고

\[\mathbf b \in \mathbb R^M\]

이므로 다음과 같다.

\[\boxed{ A^T\mathbf b \in \mathbb R^N }\]

따라서 Normal Equation의 양변 Dimension은 일치한다.

Algebraic Derivation

이제 동일한 Normal Equation을 Matrix Calculus로 유도한다. Loss는 다음과 같다.

\[\boxed{ L(\mathbf x) = ( \mathbf b-A\mathbf x )^T ( \mathbf b-A\mathbf x ) }\]

Quadratic Expansion

전개하면 다음과 같다.

\[\begin{aligned} L(\mathbf x) &= \mathbf b^T\mathbf b - \mathbf b^TA\mathbf x\\ &\quad- \mathbf x^TA^T\mathbf b + \mathbf x^TA^TA\mathbf x \end{aligned}\]

Scalar Symmetry

\[\mathbf b^TA\mathbf x\]

는 Scalar다. 따라서 다음과 같다.

\[\boxed{ \mathbf b^TA\mathbf x = \mathbf x^TA^T\mathbf b }\]

Simplified Expansion

따라서 다음과 같다.

\[\boxed{ L(\mathbf x) = \mathbf b^T\mathbf b - 2\mathbf x^TA^T\mathbf b + \mathbf x^TA^TA\mathbf x }\]

First Gradient Term

\[\mathbf b^T\mathbf b\]

는 \(\mathbf x\)와 무관한 Constant다. 따라서 다음과 같다.

\[\boxed{ \nabla_{\mathbf x} ( \mathbf b^T\mathbf b ) = 0 }\]

Second Gradient Term

Matrix Calculus Identity

\[\nabla_{\mathbf x} ( \mathbf c^T\mathbf x ) = \mathbf c\]

를 사용하면 다음과 같다.

\[\boxed{ \nabla_{\mathbf x} [ -2\mathbf x^TA^T\mathbf b ] = -2A^T\mathbf b }\]

Quadratic Gradient

일반적으로 다음과 같다.

\[\nabla_{\mathbf x} ( \mathbf x^TB\mathbf x ) = (B+B^T)\mathbf x\]

여기서

\[B=A^TA\]

는 Symmetric이므로 다음과 같다.

\[\boxed{ \nabla_{\mathbf x} ( \mathbf x^TA^TA\mathbf x ) = 2A^TA\mathbf x }\]

Full Gradient

따라서 다음과 같다.

\[\boxed{ \nabla_{\mathbf x}L = -2A^T\mathbf b + 2A^TA\mathbf x }\]

Stationary Condition

최적점에서

\[\nabla_{\mathbf x}L = 0\]

이면 다음과 같다.

\[-2A^T\mathbf b + 2A^TA\mathbf x = 0\]

2를 제거하면 다음과 같이 얻는다.

\[\boxed{ A^TA\mathbf x = A^T\mathbf b }\]

두 유도의 일치

Geometric Derivation:

\[\boxed{ \mathbf e \perp \mathcal C(A) }\]

에서 Normal Equation을 얻었다. Calculus Derivation:

\[\boxed{ \nabla L=0 }\]

에서 같은 식을 얻었다. 두 관점이 정확히 동일한 해를 설명한다.

Hessian

Loss의 Hessian은 다음과 같다.

\[\boxed{ \nabla_{\mathbf x}^2L = 2A^TA }\]

Positive Semidefinite

임의의 Vector \(\mathbf v\)에 대해 다음과 같다.

\[\begin{aligned} \mathbf v^TA^TA\mathbf v &= (A\mathbf v)^T (A\mathbf v)\\ &= \|A\mathbf v\|_2^2\\ &\ge0 \end{aligned}\]

따라서 항상 다음과 같다.

\[\boxed{ A^TA\succeq0 }\]

Convexity

따라서 Least Squares Loss

\[L(\mathbf x)\]

는 일반적으로 Convex Function이다. 즉 Local Minimum은 Global Minimum이다.

Full Column Rank

만약

\[\boxed{ \operatorname{rank}(A)=N }\]

이라면 \(A\)의 Column들이 Linearly Independent하다. 이때

\[A\mathbf v=0\]

을 만족하는 Vector는

\[\mathbf v=0\]

뿐이다.

Positive Definite

Full Column Rank라면 \(\mathbf v\neq0\)에 대해 다음과 같다.

\[\|A\mathbf v\|_2^2>0\]

따라서 다음과 같다.

\[\boxed{ A^TA\succ0 }\]

Strict Convexity

이 경우 Hessian

\[2A^TA\]

가 Positive Definite이므로 다음과 같다.

\[\boxed{ L(\mathbf x) \text{는 Strictly Convex} }\]

따라서 Least Squares Minimizer는 유일하다.

Rank-Deficient Case

반대로

\[\operatorname{rank}(A)<N\]

이면

\[A^TA\]

는 Singular할 수 있다. 이 경우 Least Squares Minimum은 존재하더라도 \(\mathbf x\) 자체가 유일하지 않을 수 있다.

중요한 구분

따라서 다음과 같다.

\[\boxed{ \text{Convex} \not\Rightarrow \text{unique minimizer} }\]

유일성을 위해서는 추가로 Full Column Rank와 같은 조건이 필요하다.

Closed-Form Solution

Full Column Rank이면

\[A^TA\]

가 Invertible이다. 따라서

\[A^TA\hat{\mathbf x} = A^T\mathbf b\]

의 양변에

\[(A^TA)^{-1}\]

을 곱하면 다음과 같다.

\[\boxed{ \hat{\mathbf x} = (A^TA)^{-1} A^T\mathbf b }\]

Pseudoinverse

Full Column Rank Case에서는

\[\boxed{ A^\dagger = (A^TA)^{-1}A^T }\]

라고 쓸 수 있다. 따라서 다음과 같다.

\[\boxed{ \hat{\mathbf x} = A^\dagger\mathbf b }\]

Pseudoinverse에 대한 정확한 범위

원자료는 위 식을 Left Pseudo-inverse라고 설명한다. 이 Formula는

\[\boxed{ \operatorname{rank}(A)=N }\]

인 Full Column Rank Case에서 성립한다. Rank-Deficient Case의 일반 Moore–Penrose Pseudoinverse는 이 식 하나로 정의할 수 없다.

Projection Matrix

Full Column Rank에서 Prediction은 다음과 같다.

\[\mathbf p = A\hat{\mathbf x}\]

Closed-Form Solution을 대입하면 다음과 같다.

\[\mathbf p = A (A^TA)^{-1} A^T \mathbf b\]

Projection Operator

따라서

\[\boxed{ P = A (A^TA)^{-1} A^T }\]

라고 정의하면 다음과 같다.

\[\boxed{ \mathbf p=P\mathbf b }\]

\(P\)는 \(\mathcal C(A)\) 위로의 Orthogonal Projection Matrix다.

Projection Matrix Symmetry

Transpose를 취하면

\[P^T = A (A^TA)^{-1} A^T\]

이므로 다음과 같다.

\[\boxed{ P^T=P }\]

Projection Matrix Idempotence

Projection을 두 번 적용해도 결과는 같다 다음과 같다.

\[\boxed{ P^2=P }\]

따라서 \(P\)는 실제 Linear Algebra에서의 Projection Operator다.

Residual Projection

Residual은 다음과 같다.

\[\mathbf e = \mathbf b-\mathbf p\]

따라서 다음과 같다.

\[\boxed{ \mathbf e = (I-P)\mathbf b }\]

Orthogonal Decomposition

\(\mathbf b\)는

\[\boxed{ \mathbf b = \mathbf p+\mathbf e }\]

로 분해된다. 여기서

\[\boxed{ \mathbf p\in\mathcal C(A) }\]

이고 다음과 같다.

\[\boxed{ \mathbf e\in\mathcal C(A)^\perp }\]

Pythagorean Structure

두 Vector가 직교하므로 다음과 같다.

\[\boxed{ \|\mathbf b\|_2^2 = \|\mathbf p\|_2^2 + \|\mathbf e\|_2^2 }\]

Least Squares의 기하학적 구조를 보여주는 중요한 관계다.

Numerical Example Setup

원자료의 Example은 다음과 같다.

\[\begin{gathered} \boxed{ A = \begin{bmatrix} 1&1\\ 1&2\\ 1&3 \end{bmatrix} } \\[6pt] \boxed{ \mathbf b = \begin{bmatrix} 1\\ 3\\ 3 \end{bmatrix} } \end{gathered}\]

Dimensions

\[A \in \mathbb R^{3\times2}\]

이므로 다음과 같다.

\[\boxed{ M=3, \qquad N=2 }\]

따라서 Overdetermined System이다.

Transpose

\[\boxed{ A^T = \begin{bmatrix} 1&1&1\\ 1&2&3 \end{bmatrix} }\]

First Entry of \(A^TA\)

첫 번째 Row와 첫 번째 Column의 Dot Product는 다음과 같다.

\[1^2+1^2+1^2 = \boxed{ 3 }\]

Off-Diagonal Entry

\[1(1)+1(2)+1(3) = 1+2+3 = \boxed{ 6 }\]

Symmetry에 의해 반대쪽 Off-Diagonal도 6이다.

Final Entry

\[1^2+2^2+3^2 = 1+4+9 = \boxed{ 14 }\]

\(A^TA\)

따라서 다음과 같다.

\[\boxed{ A^TA = \begin{bmatrix} 3&6\\ 6&14 \end{bmatrix} }\]

\(A^T\mathbf b\)

첫 번째 Component는 다음과 같다.

\[1+3+3 = \boxed{ 7 }\]

두 번째 Component는 다음과 같다.

\[1(1)+2(3)+3(3)\]

즉 다음과 같다.

\[1+6+9 = \boxed{ 16 }\]

Right-Hand Side

따라서 다음과 같다.

\[\boxed{ A^T\mathbf b = \begin{bmatrix} 7\\ 16 \end{bmatrix} }\]

Determinant

\[\det(A^TA) = (3)(14)-(6)(6)\]

따라서 다음과 같다.

\[\boxed{ \det(A^TA)=42-36=6 }\]

0이 아니므로 Invertible이다.

Inverse

2×2 Inverse Formula를 적용하면 다음과 같다.

\[\boxed{ (A^TA)^{-1} = \frac16 \begin{bmatrix} 14&-6\\ -6&3 \end{bmatrix} }\]

Least Squares Solution

\[\hat{\mathbf x} = (A^TA)^{-1} A^T\mathbf b\]

이므로 다음과 같다.

\[\hat{\mathbf x} = \frac16 \begin{bmatrix} 14&-6\\ -6&3 \end{bmatrix} \begin{bmatrix} 7\\ 16 \end{bmatrix}\]

Matrix Multiplication

첫 번째 Component는 다음과 같다.

\[14(7)-6(16) = 98-96 = \boxed{ 2 }\]

두 번째 Component는 다음과 같다.

\[-6(7)+3(16) = -42+48 = \boxed{ 6 }\]

Final Solution

따라서 다음과 같다.

\[\boxed{ \hat{\mathbf x} = \frac16 \begin{bmatrix} 2\\ 6 \end{bmatrix} = \begin{bmatrix} 1/3\\ 1 \end{bmatrix} }\]

원자료의 계산과 일치한다.

Prediction Vector

\[\mathbf p = A\hat{\mathbf x}\]

따라서 다음과 같다.

\[\boxed{ \mathbf p = \begin{bmatrix} 4/3\\ 7/3\\ 10/3 \end{bmatrix} }\]

Residual Vector

\[\mathbf e = \mathbf b-\mathbf p\]

이므로 다음과 같다.

\[\boxed{ \mathbf e = \begin{bmatrix} -1/3\\ 2/3\\ -1/3 \end{bmatrix} }\]

Orthogonality Check

\[A^T\mathbf e = \begin{bmatrix} 1&1&1\\ 1&2&3 \end{bmatrix} \begin{bmatrix} -1/3\\ 2/3\\ -1/3 \end{bmatrix}\]

First Orthogonality Component

\[-\frac13 + \frac23 - \frac13 = \boxed{0}\]

Second Orthogonality Component

\[-\frac13 + \frac43 - 1 = 0\]

따라서 다음과 같다.

\[\boxed{ A^T\mathbf e = \mathbf0 }\]

SSE 계산

Residual Norm 제곱은 다음과 같다.

\[\begin{aligned} \|\mathbf e\|_2^2 &= \left( -\frac13 \right)^2 + \left( \frac23 \right)^2 + \left( -\frac13 \right)^2\\ &= \frac19+\frac49+\frac19\\ &= \boxed{ \frac23 } \end{aligned}\]

따라서 최소 SSE는 다음과 같다.

\[\boxed{ L(\hat{\mathbf x}) = \frac23 }\]

Linear Regression Interpretation

Example Matrix의 첫 Column은 모두 1이다.

\[A = \begin{bmatrix} 1&1\\ 1&2\\ 1&3 \end{bmatrix}\]

따라서 Model은

\[\boxed{ \hat y = \beta_0+\beta_1x }\]

형태의 Linear Regression으로 해석할 수 있다.

Regression Parameters

Least Squares Solution은 다음과 같다.

\[\begin{gathered} \boxed{ \hat\beta_0 = \frac13 } \\[6pt] \boxed{ \hat\beta_1 = 1 } \end{gathered}\]

따라서 Regression Line은 다음과 같다.

\[\boxed{ \hat y = \frac13+x }\]

OLS

이와 같이 Squared Residual Sum을 최소화하는 Linear Regression을 Ordinary Least Squares, OLS라고 한다 다음과 같다.

\[\boxed{ \hat{\mathbf{\beta}} = \arg\min_{\mathbf{\beta}} \| \mathbf y-X\mathbf{\beta} \|_2^2 }\]

OLS와 MLE 연결

추가로 Regression Noise를

\[\boxed{ \mathbf{\epsilon} \sim \mathcal N( 0,\sigma^2I ) }\]

라고 가정하면 Gaussian Likelihood의 MLE는 OLS Objective와 연결된다. 즉 적절한 Gaussian Noise Assumption 아래에서 다음과 같다.

\[\boxed{ \text{OLS} \leftrightarrow \text{Maximum Likelihood} }\]

Normal Equation을 직접 풀어도 되는가

수학적으로

\[\hat x = (A^TA)^{-1}A^Tb\]

는 명확하지만 실제 Numerical Computation에서는 반드시 역행렬을 명시적으로 계산하는 것이 최선은 아니다.

Conditioning 문제

Condition Number 관점에서

\[A^TA\]

를 구성하면 Numerical Conditioning이 악화될 수 있다. 특히 다음 관계가 성립한다.

\[\boxed{ \kappa(A^TA) = \kappa(A)^2 }\]

따라서 큰 문제에서는 QR 또는 SVD 기반 Least Squares Solver가 더 안정적일 수 있다.

Closed Form과 실제 구현 구분

따라서

\[\boxed{ (A^TA)^{-1}A^Tb }\]

는 이론적 이해에는 매우 중요하지만, 실제 Numerical Linear Algebra에서는

\[\boxed{ \text{QR / SVD / specialized least-squares solver} }\]

를 사용할 수 있다.

Rank-Deficient Least Squares

Rank가 부족해도 Least Squares Problem 자체는 정의할 수 있다. 이 경우 최소 Norm Solution을 Moore–Penrose Pseudoinverse로

\[\boxed{ \hat x = A^\dagger b }\]

라고 정의할 수 있다.

Chinchilla Scaling Law 연결 — 원자료

원자료는 LLM Scaling Law 예로

\[\boxed{ L(N,D) = E + \frac{A}{N^a} + \frac{B}{D^b} }\]

를 제시한다. 여기서

  • \(N\): Parameter Scale
  • \(D\): Data Scale
  • \(L\): Loss

와 같은 Quantity 사이의 Power-Law 관계를 모델링한다.

원자료의 로그 변환 주장 검수

원자료는 이 식의 양변에 Log를 취하면 Linear Equation으로 변환하여 OLS로 \(a,b,A,B\)를 추정할 수 있다고 설명한다. 하지만

\[L = E + AN^{-a} + BD^{-b}\]

는 합 형태다. 따라서 단순히 Log를 취하면

\[\boxed{ \log L = \log \left( E + AN^{-a} + BD^{-b} \right) }\]

이 된다.

단순 선형화가 되지 않는 이유

일반적으로 다음과 같다.

\[\boxed{ \log(a+b) \neq \log a+\log b }\]

따라서 위 Scaling Law 전체는 단순 Log Transform만으로 \(a,b,A,B\)에 대해 Linear Regression Problem이 되지 않는다.

Power Law의 단순한 경우

반면 하나의 Term만 있는

\[\boxed{ y=Cx^\alpha }\]

라면 다음과 같다.

\[\log y = \log C + \alpha\log x\]

이 경우

\[\boxed{ \log y \text{ vs } \log x }\]

에 대해 Linear Least Squares를 사용할 수 있다.

Scaling Law Fitting의 정확한 해석

따라서 복수 항이 더해진 Chinchilla 형태는 일반적으로

\[\boxed{ \text{Nonlinear Regression} }\]

또는 적절히 변형된 Fitting Procedure를 필요로 할 수 있다. Least Squares의 아이디어 자체는 사용할 수 있지만

\[\boxed{ \text{simple log transform} \Rightarrow \text{ordinary linear least squares} }\]

라고 일반화해서는 안 된다.

Gauss–Newton 연결 — 원자료

원자료는 2차 Optimization과 Least Squares를 연결하면서

\[\boxed{ \Delta\theta = - (J^TJ)^{-1} J^T\mathbf r }\]

형태를 제시한다. 이 식은 Nonlinear Least Squares의 Gauss–Newton Method와 연결된다.

Nonlinear Least Squares

Residual Function을

\[\boxed{ \mathbf r(\theta) \in \mathbb R^M }\]

라고 하자. Objective는 다음과 같다.

\[\boxed{ L(\theta) = \frac12 \| \mathbf r(\theta) \|_2^2 }\]

Residual Linearization

현재 Parameter \(\theta\)에서 작은 Update \(\Delta\theta\)를 생각한다. Residual을 First-Order Taylor Expansion하면 다음과 같다.

\[\boxed{ \mathbf r( \theta+\Delta\theta ) \approx \mathbf r(\theta) + J\Delta\theta }\]

여기서

\[\boxed{ J = \frac{ \partial\mathbf r }{ \partial\theta } }\]

는 Residual Jacobian이다.

Local Least Squares Subproblem

따라서 다음 Update를

\[\boxed{ \min_{\Delta\theta} \| \mathbf r + J\Delta\theta \|_2^2 }\]

로 구할 수 있다. 즉 Nonlinear Problem을 Local Linear Least Squares Problem으로 근사한다.

Gauss–Newton Normal Equation

LA-14의 Normal Equation을 그대로 적용하면 다음과 같다.

\[\boxed{ J^TJ \Delta\theta = -J^T\mathbf r }\]

Gauss–Newton Step

\(J^TJ\)가 Invertible한 적절한 조건 아래에서 다음과 같다.

\[\boxed{ \Delta\theta = - (J^TJ)^{-1} J^T\mathbf r }\]

원자료에 제시된 Update 식이 바로 이 구조다.

Gauss–Newton 설명 보완

원자료의 “비선형 손실면을 2차 손실 함수로 일차 근사”라는 표현은 다소 혼동될 수 있다. 더 정확하게는

\[\boxed{ \text{Residual Function을 first-order linearize} }\]

하고, 그 결과 얻은 Squared Residual Objective가 \(\Delta\theta\)에 대해 Quadratic이 되는 구조다.

Newton과 Gauss–Newton

일반 Newton Method는

\[\boxed{ \Delta\theta = - H^{-1} \nabla L }\]

을 사용한다. Gauss–Newton은 Nonlinear Least Squares에서 Hessian을

\[\boxed{ H \approx J^TJ }\]

형태로 근사한다.

Deep Learning 연결

대규모 Neural Network에서는 정확한 Hessian Inverse를 직접 계산하는 것은 현실적으로 매우 어렵다. 하지만

  • Gauss–Newton Matrix
  • Fisher Information Matrix
  • Curvature Approximation

같은 구조에서 Least Squares와 유사한

\[J^TJ\]

형태가 등장한다.

핵심 식 — Least Squares

\[\boxed{ \hat{\mathbf x} = \arg\min_{\mathbf x} \| \mathbf b-A\mathbf x \|_2^2 }\]

핵심 식 — Residual

\[\boxed{ \mathbf e = \mathbf b-A\mathbf x }\]

핵심 식 — Orthogonality

최적점에서는 다음과 같다.

\[\boxed{ A^T ( \mathbf b-A\hat{\mathbf x} ) = 0 }\]

핵심 식 — Normal Equation

\[\boxed{ A^TA\hat{\mathbf x} = A^T\mathbf b }\]

핵심 식 — Closed Form

Full Column Rank일 때 다음과 같다.

\[\boxed{ \hat{\mathbf x} = (A^TA)^{-1} A^T\mathbf b }\]

100. 핵심 식 — Projection Matrix

Full Column Rank일 때 다음과 같다.

\[\boxed{ P = A (A^TA)^{-1} A^T }\]

그리고 다음과 같다.

\[\boxed{ \mathbf p=P\mathbf b }\]

101. 혼동하기 쉬운 부분 — Overdetermined System

\[M>N\]

이라고 해서 Exact Solution이 반드시 없는 것은 아니다. 해 존재 여부는

\[\boxed{ \mathbf b\in\mathcal C(A) }\]

인지에 달려 있다.

102. 혼동하기 쉬운 부분 — Convexity와 유일성

Least Squares Objective는 항상 Convex지만 Rank-Deficient Case에서는 Minimizer가 여러 개일 수 있다 다음과 같다.

\[\boxed{ \text{Full column rank} \Rightarrow \text{unique minimizer} }\]

103. 혼동하기 쉬운 부분 — Pseudoinverse

\[(A^TA)^{-1}A^T\]

는 Full Column Rank에서의 Formula다. 일반 Rank-Deficient Case의 Moore–Penrose Pseudoinverse를 항상 이 식으로 계산할 수 있는 것은 아니다.

104. 혼동하기 쉬운 부분 — Projection

여기서 Projection Matrix는 실제로

\[\boxed{ P^2=P }\]

을 만족한다. DL-01에서 Transformer의 Q/K/V를 “Projection”이라고 부를 때의 느슨한 용어와 구분한다.

105. 혼동하기 쉬운 부분 — Normal Equation 구현

Normal Equation이 수학적으로 Closed Form을 준다고 해서 실제 Software에서 항상 Explicit Inverse를 계산해야 하는 것은 아니다. Numerical Stability를 위해 QR/SVD Solver가 더 적합할 수 있다.

106. 혼동하기 쉬운 부분 — Scaling Law

단일 Power Law

\[y=Cx^\alpha\]

는 Log Transform으로 Linearize할 수 있다. 하지만

\[E+AN^{-a}+BD^{-b}\]

처럼 여러 항의 합은 단순 Log Transform으로 바로 Linear OLS가 되지 않는다.

107. 혼동하기 쉬운 부분 — Gauss–Newton

Gauss–Newton은 Loss 전체를 단순히 “일차 Taylor Approximation”하는 것이 아니다. Residual을 First-order로 Linearize하고 그 Squared Norm을 최소화한다.

108. 전체 개념 연결

Exact Linear System에서는

\[\boxed{ A\mathbf x=\mathbf b }\]

를 해결한다. Exact Solution이 존재하지 않으면

\[\boxed{ A\mathbf x\approx\mathbf b }\]

를 목표로 바꾼다.

109. Geometric Flow

\[\boxed{ \mathbf b \rightarrow \text{Projection onto }\mathcal C(A) \rightarrow A\hat{\mathbf x} }\]

Residual은 다음과 같다.

\[\boxed{ \mathbf b-A\hat{\mathbf x} \perp \mathcal C(A) }\]

110. Algebraic Flow

Orthogonality에서 다음과 같이 얻는다.

\[\boxed{ A^T( \mathbf b-A\hat{\mathbf x} )=0 }\]

따라서 다음과 같다.

\[\boxed{ A^TA\hat{\mathbf x} = A^T\mathbf b }\]

111. Optimization Flow

같은 결과를

\[\boxed{ L(\mathbf x) = \|\mathbf b-A\mathbf x\|^2 }\]

의 Gradient로부터 얻을 수 있다 다음과 같다.

\[\boxed{ \nabla L = -2A^T\mathbf b + 2A^TA\mathbf x }\]

112. Machine Learning Flow

Linear Regression에서는

\[\boxed{ \text{Design Matrix} \rightarrow \text{Least Squares} \rightarrow \text{OLS} }\]

로 연결된다.

113. Nonlinear Optimization Flow

Nonlinear Least Squares에서는 Residual을 Linearize하여 다음과 같이 얻는다.

\[\boxed{ r(\theta+\Delta\theta) \approx r(\theta)+J\Delta\theta }\]

그 결과

\[\boxed{ \text{Least Squares} \rightarrow \text{Gauss–Newton} }\]

으로 연결된다.

114. 정리

Least Squares는 Exact Solution이 존재하지 않을 수 있는 선형 시스템에서 Residual의 Euclidean Norm을 최소화하는 근사 문제다 다음과 같다.

\[\boxed{ \hat x = \arg\min_x \|b-Ax\|_2^2 }\]

Prediction

\[Ax\]

는 항상 \(A\)의 Column Space에 존재하므로 Least Squares는 \(\mathbf b\)를

\[\mathcal C(A)\]

위로 Orthogonal Projection하는 문제로 해석할 수 있다. 최적 Residual

\[e = b-A\hat x\]

는 Column Space와 직교해야 한다. 따라서

\[\boxed{ A^Te=0 }\]

이고 다음과 같다.

\[\boxed{ A^T( b-A\hat x )=0 }\]

이를 정리하면

\[\boxed{ A^TA\hat x = A^Tb }\]

라는 Normal Equation을 얻는다. 동일한 결과는

\[L(x) = (b-Ax)^T(b-Ax)\]

를 미분해도 얻어진다.

\[\boxed{ \nabla_xL = -2A^Tb + 2A^TAx }\]

이므로 Stationary Condition에서 Normal Equation이 나온다. Hessian은 다음과 같다.

\[\boxed{ \nabla_x^2L = 2A^TA }\]

\(A^TA\)는 항상 Positive Semidefinite이므로 Least Squares Objective는 Convex다. 추가로

\[\boxed{ \operatorname{rank}(A)=N }\]

이면 \(A^TA\)는 Positive Definite가 되어 Minimizer가 유일하다. 이 경우

\[\boxed{ \hat x = (A^TA)^{-1}A^Tb }\]

라는 Closed-Form Solution을 얻는다. 원자료의 수치 예제에서는

\[\begin{gathered} A = \begin{bmatrix} 1&1\\ 1&2\\ 1&3 \end{bmatrix} \\[6pt] b = \begin{bmatrix} 1\\ 3\\ 3 \end{bmatrix} \end{gathered}\]

이고, 다음과 같다.

\[\begin{gathered} \boxed{ A^TA = \begin{bmatrix} 3&6\\ 6&14 \end{bmatrix} } \\[6pt] \boxed{ A^Tb = \begin{bmatrix} 7\\ 16 \end{bmatrix} } \end{gathered}\]

따라서 다음과 같다.

\[\boxed{ \hat x = \begin{bmatrix} 1/3\\ 1 \end{bmatrix} }\]

Prediction은

\[\boxed{ p = \begin{bmatrix} 4/3\\ 7/3\\ 10/3 \end{bmatrix} }\]

이고 Residual은 다음과 같다.

\[\boxed{ e = \begin{bmatrix} -1/3\\ 2/3\\ -1/3 \end{bmatrix} }\]

실제로

\[\boxed{ A^Te=0 }\]

이므로 Residual이 Column Space와 직교한다. 또한 최소 SSE는 다음과 같다.

\[\boxed{ \|e\|_2^2 = \frac23 }\]

LLM Scaling Law와 연결할 때는 주의가 필요하다. 단일 Power Law

\[y=Cx^\alpha\]

는 Log Transform으로 Linear Regression 형태가 되지만,

\[L(N,D) = E+AN^{-a}+BD^{-b}\]

와 같이 여러 항이 더해진 모델은 단순 로그 변환만으로 OLS가 되지 않는다. 따라서 이 경우 Least Squares Fitting의 아이디어는 사용 가능하지만 일반적으로 Nonlinear Regression 문제로 다루어야 한다. Nonlinear Least Squares에서는 Residual을

\[\boxed{ r(\theta+\Delta\theta) \approx r(\theta) + J\Delta\theta }\]

로 Linearize한다. 그 결과 Local Least Squares Problem

\[\boxed{ \min_{\Delta\theta} \| r+J\Delta\theta \|^2 }\]

이 생기고 Normal Equation으로부터 다음과 같이 얻는다.

\[\boxed{ J^TJ\Delta\theta = -J^Tr }\]

이것이 Gauss–Newton Method와 Least Squares가 연결되는 핵심이다. 전체 흐름은 다음과 같다.

\[\boxed{ \text{Inconsistent Linear System} \rightarrow \text{Residual} \rightarrow \text{Least Squares} \rightarrow \text{Orthogonal Projection} \rightarrow \text{Normal Equation} }\]

Machine Learning에서는

\[\boxed{ \text{Least Squares} \rightarrow \text{Linear Regression / OLS} }\]

로 연결되고, Optimization에서는

\[\boxed{ \text{Least Squares} \rightarrow \text{Gauss–Newton / curvature approximation} }\]

으로 확장된다.

115. 정리

Least squares는 \(\hat x=\arg\min_x\|Ax-b\|_2^2\)로 관측 벡터와 column space 사이의 거리를 최소화한다. 최적 residual \(b-A\hat x\)는 \(A\)의 열공간에 직교하고, 이 조건이 normal equation과 선형회귀 OLS의 projection 해석으로 이어진다.
