DL-01 — Affine Transformation & Linear Layer

Affine Transformation과 Linear Layer의 연산 구조, 차원과 기하학적 의미를 정리한다.

ML·딥러닝 · DL-01업데이트 2026.09.21
  • #Affine Transformation
  • #Linear Layer
  • #Weight Matrix
  • #Bias

개념

Linear LayerDeep Learning에서 가장 기본적인 연산 중 하나는 입력 Vector에 Weight Matrix를 곱하고 Bias를 더하는 것이다.

대표적인 형태는

\[\boxed{ \mathbf y = \mathbf x\mathbf W+\mathbf b }\]

이 연산은

  • MLP
  • Attention Projection
  • Output Head
  • Feed-Forward Network

등 거의 모든 Neural Network Architecture에 반복적으로 등장한다.

Linear TransformationVector Space \(\mathbb R^{d_{\mathrm{in}}}\) 에서 \(\mathbb R^{d_{\mathrm{out}}}\) 으로 가는 함수

\[\boxed{ T: \mathbb R^{d_{\mathrm{in}}} \rightarrow \mathbb R^{d_{\mathrm{out}}} }\]

를 생각한다.

\(T\)가 Linear Transformation이려면 두 성질을 만족해야 한다.

Additivity첫 번째 조건은

\[\boxed{ T( \mathbf u+\mathbf v ) = T(\mathbf u)+T(\mathbf v) }\]

이를 Additivity라고 한다.

Homogeneity두 번째 조건은 Scalar \(c\in\mathbb R\) 에 대해

\[\boxed{ T(c\mathbf u) = cT(\mathbf u) }\]

이를 Homogeneity 또는 Scalar Multiplication Preservation이라고 한다.

두 조건의 통합두 조건을 합치면

\[\boxed{ T( a\mathbf u+b\mathbf v ) = aT(\mathbf u)+bT(\mathbf v) }\]

즉 Linear Combination을 보존한다.

Matrix Representation유한차원 Euclidean Space에서 Linear Transformation은 Matrix Multiplication으로 표현할 수 있다.

Column-Vector Convention에서는

\[\boxed{ \mathbf y = \mathbf W\mathbf x }\]

이고, Row-Vector Convention에서는

\[\boxed{ \mathbf y = \mathbf x\mathbf W }\]

Origin PreservationLinear Transformation에서는

\[\mathbf x=\mathbf0\]

을 대입하면

\[T(\mathbf0) = T(0\mathbf x) = 0T(\mathbf x)\]

따라서

\[\boxed{ T(\mathbf0)=\mathbf0 }\]

Linear Transformation의 기하학적 의미Linear Transformation은

  • Scaling
  • Rotation
  • Reflection
  • Shear
  • Projection

등을 표현할 수 있다.

그러나 반드시 Origin을 Origin에 유지한다.

Affine TransformationAffine Transformation은 Linear Transformation에 Translation을 추가한다.

\[\boxed{ T(\mathbf x) = \mathbf x\mathbf W+\mathbf b }\]

여기서 \(\boxed{ \mathbf b }\) 가 Bias 또는 Translation Vector다.

표기·차원

Affine Transformation의 ShapeRow-Vector Convention에서

\[\boxed{ \mathbf x \in \mathbb R^{d_{\mathrm{in}}} }\]
\[\boxed{ \mathbf W \in \mathbb R^{ d_{\mathrm{in}} \times d_{\mathrm{out}} } }\]

이면

\[\boxed{ \mathbf x\mathbf W \in \mathbb R^{d_{\mathrm{out}}} }\]

따라서 Bias도

\[\boxed{ \mathbf b \in \mathbb R^{d_{\mathrm{out}}} }\]

이어야 한다.

Origin MappingAffine Transformation에서

\[\mathbf x=\mathbf0\]

이면

\[T(\mathbf0) = \mathbf0\mathbf W+\mathbf b\]

이므로

\[\boxed{ T(\mathbf0) = \mathbf b }\]

따라서 일반적으로 Origin을 고정하지 않는다.

Broadcasting의 명시적 표현모든 성분이 1인 Column Vector를

\[\boxed{ \mathbf1_B \in \mathbb R^{B} }\]

라고 하면

\[\boxed{ \mathbf1_B\mathbf b^T \in \mathbb R^{ B\times d_{\mathrm{out}} } }\]

Batch Affine Layer따라서 Mini-batch 전체의 Forward Pass는

\[\boxed{ \mathbf Y = \mathbf X\mathbf W + \mathbf1_B\mathbf b^T }\]

Shape은

\[\boxed{ \mathbf Y \in \mathbb R^{ B\times d_{\mathrm{out}} } }\]

Bias Broadcasting실제 Framework에서는 \(\mathbf1_B\mathbf b^T\) 를 명시적으로 생성할 필요가 없다.

보통 \(\boxed{ XW+b }\) 라고 작성하면 \(b\)가 Batch Dimension으로 Broadcasting된다.

Shape Check

\[(B\times d_{\mathrm{in}}) (d_{\mathrm{in}}\times d_{\mathrm{out}})\]

은 \(\boxed{ B\times d_{\mathrm{out}} }\) Bias Term 역시

\[(B\times1) (1\times d_{\mathrm{out}})\]

이므로 \(\boxed{ B\times d_{\mathrm{out}} }\) 따라서 두 Tensor를 더할 수 있다.

핵심 연산

Linear vs AffineLinear:

\[\boxed{ \mathbf y = \mathbf x\mathbf W }\]

Affine:

\[\boxed{ \mathbf y = \mathbf x\mathbf W+\mathbf b }\]

즉

\[\boxed{ \text{Affine} = \text{Linear} + \text{Translation} }\]

Bias가 0이면만약

\[\boxed{ \mathbf b=\mathbf0 }\]

이면

\[\mathbf y = \mathbf x\mathbf W\]

이므로 Affine Transformation은 Linear Transformation으로 축소된다.

중요한 용어 구분Deep Learning Framework에서는 Bias 유무와 관계없이 ``text Linear Layer `` 라고 부르는 경우가 많다.

하지만 수학적으로 \(\boxed{ Wx+b }\) 는 일반적으로 Linear Transformation이 아니라 Affine Transformation이다.

Bias의 기하학적 역할Bias는 Linear Transformation으로 얻은 출력 전체를 Translation한다.

\[\boxed{ \mathbf x\mathbf W \rightarrow \mathbf x\mathbf W+\mathbf b }\]

즉 변환된 공간의 기준 위치를 이동시킨다.

Scalar Example1차원에서

\[\boxed{ y=wx+b }\]

를 생각하자.

\(b=0\)이면 직선은 반드시 Origin을 지난다.

\(b\neq0\)이면 직선을 위아래로 이동시킬 수 있다.

Decision Boundary ExampleBinary Linear Classifier의 Decision Function을

\[\boxed{ g(\mathbf x) = \mathbf w^T\mathbf x+b }\]

라고 하면 Decision Boundary는

\[\boxed{ \mathbf w^T\mathbf x+b=0 }\]

Bias 없는 Decision Boundary만약

\[b=0\]

이면

\[\mathbf w^T\mathbf x=0\]

이 Hyperplane은 반드시 Origin을 지난다.

Bias가 있는 Decision Boundary\(b\neq0\)이면

\[\boxed{ \mathbf w^T\mathbf x=-b }\]

따라서 Orientation을 결정하는 \(\mathbf w\)와 별개로 Boundary 위치를 이동시킬 수 있다.

Bias 역할의 범위원자료는 Bias가 Decision Boundary를 자유롭게 이동시키는 역할을 강조한다.

이는 Linear Classifier에서 직관적으로 명확하다.

다만 모든 Deep Network에서 Bias 하나의 역할을 오직 Decision Boundary Translation으로만 해석할 필요는 없다.

여러 Layer에서는 Intermediate Representation 자체를 이동시키는 Parameter로도 작동한다.

Deep Learning Linear LayerDeep Learning에서는 입력 Feature Vector를 새로운 Feature Space로 Projection하기 위해

\[\boxed{ \mathbf y = \mathbf x\mathbf W+\mathbf b }\]

를 사용한다.

Dimension Expansion만약

\[d_{\mathrm{out}} > d_{\mathrm{in}}\]

이면

\[\boxed{ \mathbb R^{d_{\mathrm{in}}} \rightarrow \mathbb R^{d_{\mathrm{out}}} }\]

으로 Dimension을 확장한다.

Dimension Reduction반대로

\[d_{\mathrm{out}} < d_{\mathrm{in}}\]

이면 Output Dimension이 줄어든다.

\[\boxed{ \mathbb R^{d_{\mathrm{in}}} \rightarrow \mathbb R^{d_{\mathrm{out}}} }\]

Dimension Preservation

\[d_{\mathrm{out}} = d_{\mathrm{in}}\]

인 경우에도 새로운 Coordinate/Feature Mixing을 수행할 수 있다.

따라서 Linear Layer의 목적이 항상 Dimension Change인 것은 아니다.

Mini-Batch InputBatch Size를 \(\boxed{ B }\) 라고 하자.

각 Sample을 Row로 쌓으면

\[\boxed{ \mathbf X \in \mathbb R^{ B\times d_{\mathrm{in}} } }\]

Weight Matrix

\[\boxed{ \mathbf W \in \mathbb R^{ d_{\mathrm{in}} \times d_{\mathrm{out}} } }\]

따라서 \(\mathbf X\mathbf W\) 의 Shape은 \(\boxed{ B\times d_{\mathrm{out}} }\)

Bias VectorBias는

\[\boxed{ \mathbf b \in \mathbb R^{d_{\mathrm{out}}} }\]

Batch의 모든 Sample에 동일한 Bias를 더한다.

Homogeneous CoordinatesAffine Transformation은 Bias Addition 때문에 순수 Matrix Multiplication 하나로 보이지 않는다.

Homogeneous Coordinate를 이용하면 이를 하나의 Matrix Product로 통합할 수 있다.

Augmented InputRow Vector

\[\mathbf x \in \mathbb R^{d_{\mathrm{in}}}\]

에 1을 하나 추가한다.

\[\boxed{ \tilde{\mathbf x} = [ \mathbf x,1 ] }\]

따라서

\[\boxed{ \tilde{\mathbf x} \in \mathbb R^{ d_{\mathrm{in}}+1 } }\]

Augmented WeightWeight와 Bias를 하나의 Matrix에 결합한다.

\[\boxed{ \tilde{\mathbf W} = \begin{bmatrix} \mathbf W\\ \mathbf b^T \end{bmatrix} }\]

Shape은

\[\boxed{ \tilde{\mathbf W} \in \mathbb R^{ (d_{\mathrm{in}}+1) \times d_{\mathrm{out}} } }\]

Homogeneous Product그러면

\[\tilde{\mathbf x} \tilde{\mathbf W} = [ \mathbf x,1 ] \begin{bmatrix} \mathbf W\\ \mathbf b^T \end{bmatrix}\]

Product ExpansionBlock Matrix Multiplication을 수행하면

\[\boxed{ [ \mathbf x,1 ] \begin{bmatrix} \mathbf W\\ \mathbf b^T \end{bmatrix} = \mathbf x\mathbf W + \mathbf b }\]

Homogeneous Coordinate Interpretation즉 원래 공간에서의 Affine Transformation을 한 차원 증가된 공간에서 Matrix Multiplication 형태로 표현할 수 있다.

\[\boxed{ \text{Affine in original coordinates} \rightarrow \text{linear representation in homogeneous coordinates} }\]

중요한 표현상의 주의원자료는 이를 “아핀 변환이 고차원 선형 공간의 선형변환과 완벽히 동치”라고 표현한다.

더 정확하게는

\[\boxed{ \text{homogeneous-coordinate representation을 통해 affine map을 matrix multiplication으로 표현할 수 있다} }\]

는 의미로 이해한다.

원래 \(\mathbb R^{d_{\mathrm{in}}}\) 위의 Map 자체가 Bias 때문에 Linear Map으로 바뀌는 것은 아니다.

핵심 식 — Linear Transformation

\[\boxed{ y=xW }\]

Origin은

\[\boxed{ 0\mapsto0 }\]

으로 유지된다.

핵심 식 — Affine Transformation

\[\boxed{ y=xW+b }\]

Origin은

\[\boxed{ 0\mapsto b }\]

핵심 식 — Batch Forward

\[\boxed{ Y = XW + 1_Bb^T }\]

핵심 식 — Weight Gradient

\[\boxed{ \frac{\partial L} {\partial W} = X^TG }\]

핵심 식 — Bias Gradient

\[\boxed{ \frac{\partial L} {\partial b} = G^T1_B }\]

핵심 식 — Input Gradient

\[\boxed{ \frac{\partial L} {\partial X} = GW^T }\]

핵심 식 — Q/K/V Projection

\[\boxed{ Q=XW_Q }\]
\[\boxed{ K=XW_K }\]
\[\boxed{ V=XW_V }\]

핵심 식 — FFN Dimension Flow

\[\boxed{ d_{\mathrm{model}} \rightarrow d_{\mathrm{ff}} \rightarrow d_{\mathrm{model}} }\]

성질·유도

Backpropagation SetupForward Layer를

\[\boxed{ \mathbf Y = \mathbf X\mathbf W + \mathbf1_B\mathbf b^T }\]

라고 하자.

Loss를 \(L\) 이라고 한다.

Upstream Gradient출력에 대한 상류 Gradient를

\[\boxed{ \mathbf G = \frac{\partial L} {\partial\mathbf Y} }\]

라고 정의한다.

Shape은

\[\boxed{ \mathbf G \in \mathbb R^{ B\times d_{\mathrm{out}} } }\]

필요한 세 GradientLinear Layer Backward에서는 세 가지를 계산해야 한다.

\[\boxed{ \frac{\partial L}{\partial\mathbf W} }\]
\[\boxed{ \frac{\partial L}{\partial\mathbf b} }\]
\[\boxed{ \frac{\partial L}{\partial\mathbf X} }\]

Weight Gradient의 ComponentBatch Sample Index를 \(j\), Input Dimension을 \(i\), Output Dimension을 \(k\)라고 하자.

Forward Component는

\[\boxed{ Y_{jk} = \sum_i X_{ji}W_{ik} + b_k }\]

\(W_{ik}\)에 대한 Local Derivative\(Y_{jk}\) 를 \(W_{ik}\) 로 미분하면

\[\boxed{ \frac{\partial Y_{jk}} {\partial W_{ik}} = X_{ji} }\]

Weight Chain Rule따라서

\[\begin{aligned} \frac{\partial L} {\partial W_{ik}} &= \sum_{j=1}^{B} \frac{\partial L} {\partial Y_{jk}} \frac{\partial Y_{jk}} {\partial W_{ik}}\\ &= \sum_{j=1}^{B} G_{jk}X_{ji} \end{aligned}\]

Matrix Form of Weight Gradient위 Component 식은 Matrix Multiplication

\[\boxed{ \frac{\partial L} {\partial\mathbf W} = \mathbf X^T\mathbf G }\]

와 같다.

원자료의 핵심 Backpropagation 식이다.

Weight Gradient Shape

\[\mathbf X^T \in \mathbb R^{ d_{\mathrm{in}}\times B }\]

이고

\[\mathbf G \in \mathbb R^{ B\times d_{\mathrm{out}} }\]

이므로

\[\boxed{ \mathbf X^T\mathbf G \in \mathbb R^{ d_{\mathrm{in}}\times d_{\mathrm{out}} } }\]

이는

\[\boxed{ \operatorname{shape} \left( \frac{\partial L}{\partial W} \right) = \operatorname{shape}(W) }\]

와 일치한다.

Bias GradientForward Component에서 \(Y_{jk}\) 는 \(b_k\)에 대해

\[\boxed{ \frac{\partial Y_{jk}} {\partial b_k} = 1 }\]

Bias Chain Rule따라서

\[\begin{aligned} \frac{\partial L} {\partial b_k} &= \sum_{j=1}^{B} \frac{\partial L} {\partial Y_{jk}} \\ &= \boxed{ \sum_{j=1}^{B} G_{jk} } \end{aligned}\]

Bias Gradient Vector FormVector 형태로

\[\boxed{ \frac{\partial L} {\partial\mathbf b} = \mathbf G^T\mathbf1_B }\]

동일하게

\[\boxed{ \frac{\partial L} {\partial\mathbf b} = \sum_{j=1}^{B}\mathbf g_j }\]

라고 쓸 수 있다.

Bias Gradient의 의미같은 Bias Vector가 모든 Batch Sample에 공유되므로 각 Sample에서 들어오는 Gradient가 Batch Axis를 따라 모두 합쳐진다.

\[\boxed{ \text{shared bias} \rightarrow \text{sum gradients across batch} }\]

Input Gradient이제

\[\boxed{ \frac{\partial L} {\partial X_{ji}} }\]

를 계산한다.

\(X_{ji}\)는 같은 Sample \(j\)의 모든 Output Dimension \(k\)에 영향을 준다.

Local Derivative wrt Input

\[Y_{jk} = \sum_i X_{ji}W_{ik}+b_k\]

이므로

\[\boxed{ \frac{\partial Y_{jk}} {\partial X_{ji}} = W_{ik} }\]

Input Chain Rule따라서

\[\begin{aligned} \frac{\partial L} {\partial X_{ji}} &= \sum_{k=1}^{d_{\mathrm{out}}} \frac{\partial L} {\partial Y_{jk}} \frac{\partial Y_{jk}} {\partial X_{ji}}\\ &= \sum_k G_{jk}W_{ik} \end{aligned}\]

Matrix Form of Input GradientMatrix 형태로

\[\boxed{ \frac{\partial L} {\partial\mathbf X} = \mathbf G\mathbf W^T }\]

Input Gradient Shape

\[\mathbf G \in \mathbb R^{ B\times d_{\mathrm{out}} }\]

이고

\[\mathbf W^T \in \mathbb R^{ d_{\mathrm{out}}\times d_{\mathrm{in}} }\]

이므로

\[\boxed{ \mathbf G\mathbf W^T \in \mathbb R^{ B\times d_{\mathrm{in}} } }\]

이는 \(\mathbf X\)의 Shape과 동일하다.

Linear Layer Backward 핵심따라서

\[\boxed{ Y=XW+b }\]

에 대해

\[\boxed{ \frac{\partial L}{\partial W} = X^TG }\]
\[\boxed{ \frac{\partial L}{\partial b} = G^T1_B }\]
\[\boxed{ \frac{\partial L}{\partial X} = GW^T }\]

혼동하기 쉬운 부분 — Linear vs Affine\(\boxed{ Wx+b }\) 는 일반적으로 Affine이다.

Deep Learning API에서 Linear라고 이름 붙더라도 수학적 Linear Transformation과 용어를 구분한다.

혼동하기 쉬운 부분 — BiasBias는 단순히 “추가되는 작은 숫자”가 아니다.

Representation 전체를 Translation할 수 있는 Learnable Parameter다.

혼동하기 쉬운 부분 — ProjectionLinear Layer를 Projection이라고 부르는 경우가 많지만 모든 Matrix Multiplication이 엄밀한 Linear Algebra의 Projection Operator인 것은 아니다.

예를 들어 일반적인 \(W_Q\) 는 반드시

\[P^2=P\]

를 만족하는 Projection Matrix가 아니다.

여기서 Projection은 보통 새 Feature Space로 Mapping한다는 느슨한 의미다.

혼동하기 쉬운 부분 — Homogeneous CoordinatesHomogeneous Coordinates를 사용한다고 해서 원래 Affine Map이 원래 공간에서 Linear Map이 되는 것은 아니다.

차원을 확장해 Matrix Multiplication으로 표현하는 것이다.

혼동하기 쉬운 부분 — Bias GradientBias가 모든 Sample에 공유되므로 \(\nabla_bL\) 는 Batch Dimension을 따라 합한다.

Loss Reduction이 Mean인지 Sum인지에 따라 상류 Gradient \(G\) 자체의 Scale은 달라질 수 있다.

혼동하기 쉬운 부분 — Gradient ShapeParameter Gradient는 해당 Parameter와 같은 Shape을 가진다.

\(\boxed{ \nabla_WL \sim W }\) \(\boxed{ \nabla_bL \sim b }\) \(\boxed{ \nabla_XL \sim X }\)

혼동하기 쉬운 부분 — Q/K/V Bias어떤 Transformer Architecture가 Bias를 사용하지 않는다고 해서 모든 Transformer가 Bias를 제거한다는 뜻은 아니다.

이는 Architecture별 설계 선택이다.

혼동하기 쉬운 부분 — FFN Width\(4d\) 와

\[\frac83d\]

는 대표적인 Architecture Recipe에서 나타나는 비율이다.

모든 Transformer/LLM의 고정된 수학적 요구조건은 아니다.

혼동하기 쉬운 부분 — Linear Layer만 여러 개 쌓기Linear 또는 Affine Layer 사이에 Nonlinearity가 없다면 여러 Layer를 하나의 Affine Transformation으로 합칠 수 있다.

예를 들어 \((xW_1+b_1)W_2+b_2\) 는 \(\boxed{ x(W_1W_2) + (b_1W_2+b_2) }\) 따라서 깊이 자체만으로 Nonlinear Expressiveness가 생기는 것은 아니다.

DL-01 전체 구조Linear Transformation: \(\boxed{ xW }\) Affine Transformation: \(\boxed{ xW+b }\) Deep Learning Linear Layer: \(\boxed{ XW+b }\)

Linear Transformation은

\[\boxed{ T( a\mathbf u+b\mathbf v ) = aT(\mathbf u) + bT(\mathbf v) }\]

를 만족한다.

Matrix로는

\[\boxed{ y=xW }\]

형태로 표현할 수 있으며 Origin을 Origin에 Mapping한다.

\[\boxed{ T(0)=0 }\]

Affine Transformation은 Bias Translation을 추가한다.

\[\boxed{ y=xW+b }\]

따라서

\[\boxed{ T(0)=b }\]

가 되어 Origin이 이동할 수 있다.

Mini-batch에서는

\[\boxed{ X \in \mathbb R^{ B\times d_{\mathrm{in}} } }\]
\[\boxed{ W \in \mathbb R^{ d_{\mathrm{in}}\times d_{\mathrm{out}} } }\]

이고

\[\boxed{ Y = XW + 1_Bb^T \in \mathbb R^{ B\times d_{\mathrm{out}} } }\]

Homogeneous Coordinates를 사용하면

\[\boxed{ [x,1] \begin{bmatrix} W\\ b^T \end{bmatrix} = xW+b }\]

가 되어 Affine Operation을 확장된 Coordinate에서 하나의 Matrix Product로 표현할 수 있다.

Backward에서는 상류 Gradient

\[\boxed{ G = \frac{\partial L}{\partial Y} }\]

가 주어졌을 때

\[\boxed{ \frac{\partial L}{\partial W} = X^TG }\]
\[\boxed{ \frac{\partial L}{\partial b} = G^T1_B }\]
\[\boxed{ \frac{\partial L}{\partial X} = GW^T }\]

를 얻는다.

원자료의 수치 예제에서는

\[X = \begin{bmatrix} 1&2&0\\ 0&1&1 \end{bmatrix}\]
\[W = \begin{bmatrix} 0.5&-1\\ 1&0\\ -0.5&2 \end{bmatrix}\]
\[b = \begin{bmatrix} 0.1\\ -0.2 \end{bmatrix}\]

에 대해

\[\boxed{ Y = \begin{bmatrix} 2.6&-1.2\\ 0.6&1.8 \end{bmatrix} }\]

을 얻는다.

상류 Gradient

\[G = \begin{bmatrix} 1&-0.5\\ 0&2 \end{bmatrix}\]

가 주어지면

\[\boxed{ \frac{\partial L}{\partial W} = \begin{bmatrix} 1&-0.5\\ 2&1\\ 0&2 \end{bmatrix} }\]

Bias Gradient는

\[\boxed{ \frac{\partial L}{\partial b} = \begin{bmatrix} 1\\ 1.5 \end{bmatrix} }\]

이고 Input Gradient는

\[\boxed{ \frac{\partial L}{\partial X} = \begin{bmatrix} 1&1&-1.5\\ -2&0&4 \end{bmatrix} }\]

Transformer Self-Attention에서는 동일한 Linear Layer 구조로

\[\boxed{ Q=XW_Q, \qquad K=XW_K, \qquad V=XW_V }\]

를 생성한다.

Bias가 없다면 이 Projection은 수학적으로 순수 Linear Transformation이다.

FFN에서도

\[\boxed{ d_{\mathrm{model}} \rightarrow d_{\mathrm{ff}} \rightarrow d_{\mathrm{model}} }\]

형태의 Linear Projection을 사용하고 중간에 Nonlinear 또는 Gated Activation을 삽입한다.

따라서 DL-01의 전체 흐름은

\[\boxed{ \text{Linear Algebra} \rightarrow \text{Affine Transformation} \rightarrow \text{Linear Layer} \rightarrow \text{Backpropagation} }\]

Transformer 관점에서는

\[\boxed{ \text{Hidden States} \rightarrow \text{Q/K/V Linear Projections} \rightarrow \text{Attention} }\]

그리고

\[\boxed{ \text{Hidden States} \rightarrow \text{FFN Linear Expansion} \rightarrow \text{Nonlinearity} \rightarrow \text{Linear Contraction} }\]

로 연결된다.

즉 Linear Layer는 Transformer와 LLM의 가장 기본적인 Learnable Mapping이다.

Block 내부 대부분의 Learnable Mapping은 Matrix Multiplication 기반 Linear Projection이다.

Self-Attention InputSequence Hidden State를

\[\boxed{ X \in \mathbb R^{ N\times d_{\mathrm{model}} } }\]

이라고 하자.

여기서 \(N\) 은 Sequence Length다.

Query ProjectionQuery는

\[\boxed{ Q = XW_Q }\]

Weight Shape은 원자료에서

\[\boxed{ W_Q \in \mathbb R^{ d_{\mathrm{model}} \times d_k } }\]

로 둔다.

Query Shape따라서

\[(N\times d_{\mathrm{model}}) (d_{\mathrm{model}}\times d_k)\]

이므로

\[\boxed{ Q \in \mathbb R^{N\times d_k} }\]

Key Projection

\[\boxed{ K = XW_K }\]

원자료의 단순 표기에서는

\[\boxed{ W_K \in \mathbb R^{ d_{\mathrm{model}}\times d_k } }\]

Value Projection

\[\boxed{ V = XW_V }\]

Weight는

\[\boxed{ W_V \in \mathbb R^{ d_{\mathrm{model}}\times d_v } }\]

Q/K/V는 같은 구조Q, K, V의 의미는 서로 다르지만 Linear Algebra 관점에서는 모두 동일한 구조다.

\[\boxed{ X \rightarrow XW }\]

즉 세 개의 서로 다른 Learnable Projection Matrix를 사용한다.

Bias가 없다면원자료의 Q/K/V 식에는 Bias가 없다.

\[Q=XW_Q\]
\[K=XW_K\]
\[V=XW_V\]

이 경우 엄밀한 수학 용어로는 Affine Transformation이 아니라 Linear Transformation이다.

Bias 제거에 대한 원자료 주장원자료는 LLaMA, PaLM 등의 Bias 제거를

  • RoPE/RMSNorm 상호작용 안정성
  • Memory Optimization

등과 연결한다.

다만 이 자료 자체에서는 이러한 이유에 대한 별도의 수학적 유도는 제공하지 않는다.

따라서 해당 부분은 아키텍처 설계 선택에 대한 설명으로 유지한다.

Bias의 비용Bias Parameter 수는 Projection Output Dimension에 비례한다.

대형 Matrix Weight와 비교하면 Parameter 수 자체는 상대적으로 작을 수 있다.

따라서 Bias 제거를 단순히 큰 Memory Reduction 하나로만 설명하기보다는 Architecture Recipe의 일부로 이해하는 것이 적절하다.

Attention Score로 연결Q와 K를 만들고 나면 \(\boxed{ QK^T }\) 를 계산한다.

Scaled Dot-Product Attention에서는

\[\boxed{ \operatorname{Softmax} \left( \frac{ QK^T }{ \sqrt{d_k} } \right) }\]

를 사용한다.

DL-03과 연결DL-01:

\[\boxed{ X \rightarrow Q,K,V }\]

DL-03:

\[\boxed{ QK^T \rightarrow \text{Softmax} }\]

따라서 Linear Projection이 Attention의 입력 Representation을 생성한다.

Q Projection Backpropagation

\[Q=XW_Q\]

라고 하고 상류 Gradient를

\[G_Q = \frac{\partial L}{\partial Q}\]

라고 하면 DL-01의 일반식에 의해

\[\boxed{ \frac{\partial L} {\partial W_Q} = X^TG_Q }\]

Input Gradient from QQuery Branch에서 Input으로 흐르는 Gradient는

\[\boxed{ \frac{\partial L} {\partial X} \bigg|_Q = G_QW_Q^T }\]

Multiple Branch Gradients같은 \(X\)에서 Q, K, V 세 Branch가 갈라지므로 최종 Input Gradient에는 각 경로의 Contribution이 합쳐진다.

개념적으로

\[\boxed{ \frac{\partial L}{\partial X} = G_QW_Q^T + G_KW_K^T + G_VW_V^T + \cdots }\]

형태가 된다.

FFN Linear TransformationTransformer의 Feed-Forward Network도 Linear Layer를 반복 사용한다.

원자료의 전통적 MLP 표현은

\[\boxed{ \operatorname{FFN}(x) = \sigma( xW_1+b_1 ) W_2+b_2 }\]

FFN Expansion첫 번째 Matrix는

\[\boxed{ W_1 \in \mathbb R^{ d_{\mathrm{model}} \times d_{\mathrm{ff}} } }\]

따라서

\[\boxed{ d_{\mathrm{model}} \rightarrow d_{\mathrm{ff}} }\]

로 Dimension을 확장한다.

FFN Contraction두 번째 Weight는

\[\boxed{ W_2 \in \mathbb R^{ d_{\mathrm{ff}} \times d_{\mathrm{model}} } }\]

따라서

\[\boxed{ d_{\mathrm{ff}} \rightarrow d_{\mathrm{model}} }\]

로 다시 축소한다.

FFN 전체 구조따라서

\[\boxed{ d_{\mathrm{model}} \rightarrow d_{\mathrm{ff}} \rightarrow d_{\mathrm{model}} }\]

이라는 Bottleneck 반대 형태의 Expansion–Projection 구조를 가진다.

Nonlinearity가 필요한 이유만약 두 Layer 사이에 Nonlinearity가 없다면

\[(XW_1)W_2 = X(W_1W_2)\]

즉 두 Linear Transformation을 하나의 Matrix로 합칠 수 있다.

Composition of Linear Maps\(\boxed{ T_2( T_1(x) ) }\) 에서 두 함수가 모두 Linear이면 전체도 Linear다.

따라서 깊은 Network의 표현력을 얻으려면 Linear Layer 사이에 Nonlinear Operation이 필요하다.

FFN Nonlinearity전통적으로 ReLU나 GELU가 사용되고, 현대 LLM에서는 Gated Activation인 SwiGLU 계열이 흔히 사용된다.

즉 단순히 \(xW_1W_2\) 가 아니라 Nonlinear/Gated Operation이 중간에 존재한다.

SwiGLU의 구조적 차이SwiGLU는 일반적인 \(\sigma(xW_1)W_2\) 보다 여러 Projection을 사용한다.

개략적으로

\[\boxed{ \operatorname{SwiGLU}(x) = [ \operatorname{SiLU}(xW_g) \odot (xW_u) ] W_d }\]

형태로 생각할 수 있다.

SwiGLU와 Linear LayerSwiGLU도 핵심 Learnable Operations는

\[\boxed{ xW_g, \qquad xW_u, \qquad hW_d }\]

라는 Linear Projection이다.

따라서 DL-01의 Linear Layer Mathematics가 그대로 적용된다.

\(4d\) FFN Width원자료는 전통적인 FFN에서

\[\boxed{ d_{\mathrm{ff}} \approx 4d_{\mathrm{model}} }\]

을 대표적 값으로 제시한다.

이는 Transformer에서 흔히 사용된 설계 비율이지만 모든 Model에 고정된 법칙은 아니다.

SwiGLU의 \(8/3\) 비율원자료는 SwiGLU에서

\[\boxed{ d_{\mathrm{ff}} \approx \frac83 d_{\mathrm{model}} }\]

을 제시한다.

이 비율은 Gated FFN의 Parameter Count를 전통적인 \(4d\) FFN과 비슷하게 맞추려는 설계에서 자주 등장하는 값으로 볼 수 있다.

\(8/3\)은 보편 상수가 아님다만 실제 LLM의 Intermediate Size는 Hardware-friendly Multiple이나 Architecture Design에 따라 조정된다.

따라서

\[\boxed{ d_{\mathrm{ff}} = \frac83d_{\mathrm{model}} }\]

을 모든 SwiGLU Model에 정확히 적용되는 수학적 법칙으로 해석하지 않는다.

Linear Layer의 Parameter CountBias가 있는 Linear Layer의 Parameter 수는

\[\boxed{ d_{\mathrm{in}}d_{\mathrm{out}} + d_{\mathrm{out}} }\]

Bias가 없다면

\[\boxed{ d_{\mathrm{in}}d_{\mathrm{out}} }\]

Linear Layer의 Forward Cost한 Sample의 Dense Matrix-Vector Multiplication은 대략

\[\boxed{ O( d_{\mathrm{in}}d_{\mathrm{out}} ) }\]

의 Arithmetic Cost를 가진다.

Batch에서는 이 비용이 Batch Size에 따라 증가한다.

Weight Gradient의 의미

\[\boxed{ \frac{\partial L}{\partial W} = X^TG }\]

는 Input Feature와 Output Error Signal의 결합을 Batch 전체에서 누적하는 구조다.

Outer-Product 관점한 Sample만 있다면 \(x \in \mathbb R^{d_{\mathrm{in}}}\) 이고 \(g \in \mathbb R^{d_{\mathrm{out}}}\) 일 때

\[\boxed{ \nabla_WL = x^Tg }\]

형태의 Outer Product가 된다.

Batch Gradient는 이러한 Sample별 Contribution의 합이다.

Bias Gradient의 의미

\[\boxed{ \nabla_bL = \sum_jg_j }\]

이므로 Bias는 특정 Feature Input과 곱해지지 않는다.

각 Output Dimension의 Error Signal이 그대로 누적된다.

Input Gradient의 의미

\[\boxed{ \nabla_XL = GW^T }\]

는 Output-Space Gradient를 Weight Transpose를 통해 Input Feature Space로 다시 전달한다.

Weight Transpose의 역할Forward:

\[\boxed{ XW : d_{\mathrm{in}} \rightarrow d_{\mathrm{out}} }\]

Backward:

\[\boxed{ GW^T : d_{\mathrm{out}} \rightarrow d_{\mathrm{in}} }\]

Forward–Backward 연결Forward에서는

\[\boxed{ X,W,b \rightarrow Y }\]

Backward에서는

\[\boxed{ G \rightarrow \nabla_WL, \nabla_bL, \nabla_XL }\]

Transformer 연결Attention에서는

\[\boxed{ X \rightarrow Q,K,V }\]

를 Linear Projection으로 만든다.

FFN에서도

\[\boxed{ X \rightarrow XW_1 \rightarrow \text{Nonlinearity} \rightarrow W_2 }\]

를 사용한다.

따라서 Linear Layer는 Transformer의 거의 모든 Learnable Transformation의 기본 단위다.

정리

Linear layer는 입력에 행렬을 곱하고 bias를 더하는 affine map \(\mathbf{y}=W\mathbf{x}+\mathbf{b}\)다. 행렬 곱은 좌표를 섞고 bias는 평행이동을 담당하며, 출력 차원은 \(W\)의 행 수로 정해진다.
