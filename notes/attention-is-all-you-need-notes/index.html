[논문리뷰] Attention Is All You Need

Vaswani et al. (2017) · Transformer · Self-Attention

수정 2026.08.24약 22분발표 2017
  • Transformer
  • Self-Attention
  • Machine Translation
  • Sequence Modeling
011. 논문 정보022. 핵심 요약033. 배경044. 핵심 용어055. Architecture066. 평가 및 결과

1. 논문 정보

2. 핵심 요약

RNN 계열 모델(LSTM·GRU 포함)은 언어 모델링과 기계번역 같은 sequence 문제를 주도했지만, 각 hidden state가 이전 시점의 계산에 의존해 한 sequence 내부를 병렬화하기 어렵다. 초기 Seq2Seq는 encoder의 마지막 state에 입력 정보를 압축한다는 병목도 있었다.

ConvS2S와 ByteNet은 convolution으로 위치 간 최대 경로 길이를 각각 \(O(n)\)과 \(O(\log_k n)\) 수준으로 줄였고, attention은 떨어진 위치의 관계를 직접 계산했다. 다만 당시 attention은 주로 recurrent encoder–decoder와 함께 사용됐다.

Transformer는 recurrence와 convolution을 제거하고 stacked self-attention·encoder–decoder attention·position-wise FFN으로 sequence를 처리한다. 레이어 내부의 순차 연산 단계와 위치 간 최대 경로 길이는 \(O(1)\)이지만, self-attention layer의 계산 복잡도는 \(O(n^2d)\)이므로 전체 계산량이 \(O(1)\)이라는 뜻은 아니다.

3. 배경

1. 기존 모델의 구조적 한계

1) 병렬 계산의 한계

\[h_t=f_\theta(h_{t-1},x_t)=\tanh\!\left(W_{hh}h_{t-1}+W_{xh}x_t+b_h\right)\]

RNN에서 시점 t의 hidden state hₜ는 입력 xₜ뿐 아니라 직전 hidden state hₜ₋₁에 의존한다. 따라서 hₜ₋₁의 계산이 끝나기 전에는 hₜ를 구할 수 없고, 한 sequence 안의 time step을 동시에 처리하기 어렵다. LSTM과 GRU는 장기 의존성 학습을 개선하지만 이 순차 의존성(inherently sequential nature) 자체를 제거하지는 않는다.

2) Seq2Seq의 고정 길이 context bottleneck

초기 encoder–decoder Seq2Seq는 encoder의 마지막 hidden state에 입력 sequence의 정보를 모아 decoder로 전달했다. 입력이 길어질수록 서로 다른 위치의 정보를 하나의 고정 길이 벡터에 압축해야 하므로 앞부분 정보와 세부 관계가 약해질 수 있다.

2. RNN 기반 Seq2Seq + Attention

Attention은 decoder의 각 단계가 encoder의 모든 hidden state를 비교해 필요한 정보를 선택하도록 하여 고정 길이 context bottleneck을 완화한다. 위 그림은 Transformer 이전의 attention 기반 encoder–decoder를 개념적으로 보여준다. Transformer는 여기서 recurrence까지 제거하고 self-attention으로 입력 위치들의 관계를 동시에 계산하므로 encoder와 학습 시 decoder 연산의 병렬화를 크게 높인다. 단, autoregressive inference에서는 출력 token을 순서대로 생성한다.

Dot-Product Attention의 계산

Transformer는 Score → Softmax → Weighted Sum이라는 원리는 유지하되, hidden state를 matrix 형태의 Q·K·V로 표현해 여러 위치의 attention을 병렬 계산하고 score를 \(\sqrt{d_k}\)로 scaling한다.

4. 핵심 용어

5. Architecture

1. Input Embedding

입력 token ID \(t_i\)를 learned embedding vector \(x_i\)로 변환한다. Transformer base의 \(d_{model}\)은 512이므로 token 하나는 512차원이고, 길이 \(n\)의 문장은 \(n\times512\) 행렬로 표현된다. 원 논문은 입력·출력 embedding과 pre-softmax linear transformation의 weight matrix를 공유하며, embedding 출력에는 \(\sqrt{d_{model}}\)을 곱한다.

\[t_i\mapsto x_i\in\mathbb{R}^{512},\qquad X_{\mathrm{embedding}}\in\mathbb{R}^{n\times512},\qquad d_{\mathrm{model}}=512\]

2. Positional Encoding

Self-attention 연산 자체에는 token 순서 정보가 없으므로 embedding에 위치 표현을 더한다. 원 논문은 학습 parameter가 없는 고정 sin·cos positional encoding을 사용하며, learned positional embedding과도 유사한 성능을 확인했다.

\[\begin{aligned}X_{\mathrm{input}}&=X_{\mathrm{embedding}}+PE\\PE_{(pos,2i)}&=\sin\!\left(\frac{pos}{10000^{2i/d_{\mathrm{model}}}}\right)\\PE_{(pos,2i+1)}&=\cos\!\left(\frac{pos}{10000^{2i/d_{\mathrm{model}}}}\right)\end{aligned}\]

3. Q·K·V 생성

그림은 encoder self-attention에서 첫 번째 위치 \(i=1\)의 표현을 갱신하는 계산을 펼쳐 보인다. 이 경우 Q·K·V의 source는 모두 같은 입력 \(X\)다. 각 \(x_j\)를 서로 다른 learned matrix로 투영한 뒤 \(Q_1\)을 모든 \(K_j\)와 비교하고, 그 가중치로 \(V_j\)를 모아 첫 번째 위치의 문맥 표현을 만든다.

4. Scaled Dot-Product Attention

\[Z=\operatorname{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V\]

\(d_k\)가 커지면 dot product의 크기도 커져 softmax가 gradient가 매우 작은 영역으로 들어가기 쉽다. \(\sqrt{d_k}\)로 나누는 scaling은 score의 크기를 완화해 학습을 안정시킨다.

그림은 이해를 위해 한 위치와 한 attention 흐름을 중심으로 나타낸다. Multi-Head Attention에서는 각 head가 이 계산을 독립적으로 수행하고, head 출력을 concatenate한 뒤 \(W^O\)로 최종 투영한다.

5. Multi-Head Attention

각 head는 독립적인 \(W_i^Q\), \(W_i^K\), \(W_i^V\)를 학습하고 서로 다른 projection 공간에서 attention을 계산한다. 하나의 Q·K·V 결과를 나중에 8등분하는 구조가 아니다.

\[\operatorname{head}_i=\operatorname{Attention}(XW_i^Q,XW_i^K,XW_i^V)\]
\[\operatorname{MultiHead}(X)=\operatorname{Concat}(\operatorname{head}_1,\ldots,\operatorname{head}_h)W^O\]

여러 head는 서로 다른 위치와 representation subspace의 정보를 동시에 학습할 수 있다. 주어–동사, 대명사–선행사, 근거리·장거리 관계는 가능한 해석 예시이며 head별 역할이 미리 고정되는 것은 아니다.

6. Add & Norm

\[Z=\operatorname{LayerNorm}\!\left(X+\operatorname{MultiHeadAttention}(X)\right)\]

원 2017 Transformer는 \(\operatorname{Sublayer}\rightarrow\operatorname{Add}\rightarrow\operatorname{Norm}\) 순서의 post-norm 구조다.

7. Position-wise Feed-Forward Network

\[\operatorname{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2\]

8. FFN 뒤 Add & Norm

\[Y=\operatorname{LayerNorm}\!\left(Z+\operatorname{FFN}(Z)\right)\]

9. Encoder Block 반복

원 논문은 서로 다른 parameter를 갖는 encoder block을 \(N=6\)번 쌓는다. 각 block을 지나도 sequence 길이와 \(d_{model}\)은 유지되고, 각 token vector에 담긴 문맥 정보만 갱신된다.

\[X\in\mathbb{R}^{n\times512}\;\longrightarrow\;Z^{(1)}\;\longrightarrow\;\cdots\;\longrightarrow\;Z^{(6)}\in\mathbb{R}^{n\times512}\]

10. Decoder에서 달라지는 점

Decoder도 \(N=6\)개 layer를 쌓지만, 각 layer에는 masked self-attention과 encoder–decoder attention이 모두 들어간다. 세 sublayer 뒤에는 각각 residual connection과 layer normalization이 적용된다.

학습에서는 정답 출력을 한 칸 오른쪽으로 이동하고 mask를 적용해 여러 위치를 병렬 계산한다. 반면 autoregressive inference에서는 직전까지 생성한 token을 입력으로 사용하므로 출력 token을 순서대로 생성한다.

11. Linear & Softmax

\[p(y_t\mid y_{<t},x)=\operatorname{softmax}(W_{\mathrm{vocab}}s_t+b)\]

마지막 decoder 표현 \(s_t\)를 vocabulary 차원으로 선형 변환한 뒤 softmax로 다음 token의 확률분포를 만든다. 원 논문은 이 pre-softmax weight를 입력·출력 embedding weight와 공유한다.

6. 평가 및 결과

  1. WMT 2014 영→독 번역에서 28.4 BLEU를 기록해 ensemble을 포함한 기존 최고 성능보다 2 BLEU 이상 높았으며, 8×P100 GPU로 3.5일 학습했다.
  2. WMT 2014 영→불 번역에서는 초록과 Table 2에 보고된 41.8 BLEU를 기록했으며, 이전 최고 단일 모델보다 훨씬 적은 학습 비용으로 높은 성능을 달성했다.
  3. 영어 constituency parsing에서도 WSJ-only 91.3 F1, semi-supervised 92.7 F1을 기록해 번역 이외 과제로의 일반화 가능성을 보였다.

7. 결론 및 영향

  1. Transformer는 recurrent layer를 multi-head self-attention으로 대체한 최초의 attention 기반 sequence transduction model로 제시됐다.
  2. 기존 recurrent·convolutional 모델보다 높은 병렬화와 빠른 학습을 보이면서 번역에서 SOTA 성능을 달성해 attention 중심 구조의 가능성을 입증했다.
  3. 향후 이미지·오디오·비디오로의 확장, local·restricted attention, generation의 순차성 감소를 후속 연구 방향으로 제시했다.
