PS-08 — Standard Score (Z-score) & Normalization

Z-score의 평균·분산 성질, 표본 표준화와 보상 정규화의 적용 범위를 정리한다.

확률·통계 · PS-08업데이트 2026.09.26
  • #Z-score
  • #Standardization
  • #Sample Variance
  • #GRPO

개념

Standard Score가 필요한 이유서로 다른 확률변수나 Feature는 평균, 분산, 단위가 서로 다를 수 있다.

예를 들어 한 Feature는 cm 단위이고 다른 Feature는 kg 단위일 수 있으며, 두 Feature의 수치 범위도 크게 다를 수 있다.

이런 경우 원래 값을 직접 비교하면 단순히 Scale이 큰 Feature가 더 커 보일 수 있다.

이를 보정하기 위해 각 값을 자신의 평균과 표준편차를 기준으로 표현하는 방법이 Standard Score 또는 Z-score다.

핵심 직관Z-score는 관측값이 평균에서 몇 표준편차만큼 떨어져 있는지를 나타낸다.

예를 들어 \(z=2\) 이면 해당 값은 평균보다 표준편차 2개만큼 위에 있다는 뜻이다.

반대로 \(z=-1.5\) 이면 평균보다 표준편차 1.5개만큼 아래에 있다.

원자료의 핵심 목표원자료는 Z-score를 통해:

\[\boxed{ \mathbb E[Z]=0 }\]

및:

\[\boxed{ \operatorname{Var}(Z)=1 }\]

이 됨을 기댓값의 선형성과 분산의 affine transformation 성질로 증명한다.

또한 이를 Feature Scaling과 GRPO의 group-relative reward normalization에 연결한다.

표기·차원

Population Z-score 정의확률변수 \(X\)의 평균을 다음과 같이 쓴다.

\[\boxed{ \mu=\mathbb E[X] }\]

분산을 다음과 같이 쓴다.

\[\boxed{ \sigma^2=\operatorname{Var}(X) }\]

표준편차를 \(\sigma=\sqrt{\operatorname{Var}(X)}\) 라고 하자.

존재 조건Z-score \(\frac{X-\mu}{\sigma}\) 를 정의하려면 적어도 \(0<\sigma<\infty\) 가 필요하다.

즉 분산이 유한하고 0이 아니어야 한다.

핵심 연산

Z-scorePopulation Z-score를 \(Z = \frac{X-\mu}{\sigma}\) 로 정의한다.

이는 \(X\)에 대한 affine transformation이다.

Centering먼저 \(X-\mu\) 는 평균을 0으로 이동시킨다.

이를 Centering이라고 한다.

Scaling이후 표준편차 \(\sigma\)로 나누면 원래 Scale을 표준편차 단위로 바꾼다.

즉 \(X \rightarrow X-\mu \rightarrow \frac{X-\mu}{\sigma}\) 의 두 단계다.

Z-score는 Projection이 아니다원자료는 표준화를 어떤 의미에서 “표준 분포로 사영”하는 것처럼 설명한다.

하지만 일반적인 Linear Algebra 의미에서 Z-score transformation을 projection이라고 부르는 것은 부정확하다.

Projection operator는 보통 \(P^2=P\) 와 같은 idempotence 구조를 가진다.

Z-score는 단순한 affine location-scale transformation이다.

따라서 더 정확하게 Z-score standardization = centering + rescaling 이라고 부른다.

가장 중요한 오해Z-score standardization을 적용한다고 해서 임의의 분포가 Standard Normal Distribution으로 변하는 것은 아니다.

즉 일반적으로 다음과 같이 쓴다.

\[\boxed{ Z=\frac{X-\mu}{\sigma} \not\Rightarrow Z\sim\mathcal N(0,1) }\]

항상 보장되는 것은 Mean과 Variance적절한 조건 아래 항상 보장되는 것은 다음과 같다.

\[\boxed{ \mathbb E[Z]=0 }\]

및:

\[\boxed{ \operatorname{Var}(Z)=1 }\]

분포의 shape 자체는 그대로 affine transformation된다.

Gaussian인 경우만약 \(X\sim\mathcal N(\mu,\sigma^2)\) 라면 특별히:

\[\boxed{ Z = \frac{X-\mu}{\sigma} \sim \mathcal N(0,1) }\]

즉 표준화가 표준정규분포를 만드는 것은 원래 \(X\)가 Gaussian일 때다.

Bernoulli 예시예를 들어 \(X\sim\operatorname{Bernoulli}(p)\) 이면 Z-score를 적용해도 가능한 값은 두 개뿐이다.

따라서 mean 0, variance 1은 될 수 있지만 Gaussian이 되는 것은 아니다.

Exponential 예시\(X\)가 Exponential Distribution을 따른다면 Z-score transformation 후에도 분포는 비대칭적이다.

즉 standardization은 skewness를 자동으로 제거하지 않는다.

평균 0 증명\(Z = \frac{X-\mu}{\sigma}\) 이므로 다음과 같이 쓴다.

\[\mathbb E[Z] = \mathbb E \left[ \frac{X-\mu}{\sigma} \right]\]

Scalar를 밖으로\(\sigma\)는 constant이므로 다음과 같이 쓴다.

\[\mathbb E[Z] = \frac1\sigma \mathbb E[X-\mu]\]

순서 보존\(\sigma>0\)이므로 \(z(x) = \frac{x-\mu}{\sigma}\) 는 \(x\)에 대한 strictly increasing affine transformation이다.

따라서 다음과 같다.

\[x_1<x_2 \Rightarrow z_1<z_2\]

즉 순위는 변하지 않는다.

거리의 재척도화두 값 \(x_1,x_2\)에 대해:

\[z_1-z_2 = \frac{x_1-x_2}{\sigma}\]

따라서 pairwise difference는 단순히 \(1/\sigma\)배 rescaling된다.

Correlation과 Standardization두 확률변수 \(X,Y\) 를 각각 \(Z_X = \frac{X-\mu_X}{\sigma_X}, \qquad Z_Y = \frac{Y-\mu_Y}{\sigma_Y}\) 로 표준화하자.

Standardized Covariance그러면:

\[\operatorname{Cov}(Z_X,Z_Y) = \frac{ \operatorname{Cov}(X,Y) }{ \sigma_X\sigma_Y }\]

Correlation우변은 바로 Pearson Correlation이므로 다음과 같이 쓴다.

\[\boxed{ \operatorname{Cov}(Z_X,Z_Y) = \rho_{XY} }\]

즉 correlation은 standardized variables의 covariance로 이해할 수 있다.

Sample Data관측값 \(x_1,\dots,x_N\) 이 있다고 하자.

Sample mean은 다음과 같다.

\[\boxed{ \bar x = \frac1N \sum_{i=1}^N x_i }\]

두 가지 분산 conventionCentered squared deviations를 \(SS = \sum_{i=1}^N (x_i-\bar x)^2\) 라고 하자.

Population-style empirical variance는 다음과 같다.

\[\boxed{ s_N^2 = \frac1N SS }\]

Unbiased Sample Variance통상적인 unbiased sample variance estimator는 다음과 같다.

\[\boxed{ s^2 = \frac1{N-1} SS }\]

표준편차도 다르다따라서 \(s_N = \sqrt{ \frac1N SS }\) 와 \(s = \sqrt{ \frac1{N-1} SS }\) 는 서로 다르다.

Sample Z-score with \(s_N\)만약 \(z_i = \frac{ x_i-\bar x }{ s_N }\) 를 사용하면 \(\frac1N \sum_i z_i = 0\) 이고:

\[\boxed{ \frac1N \sum_i z_i^2 = 1 }\]

Sample Z-score with \(s\)반면 \(z_i = \frac{ x_i-\bar x }{ s }\) 를 사용하면 다음과 같다.

\[\frac1N \sum_i z_i = 0\]

이지만:

\[\boxed{ \frac1{N-1} \sum_i z_i^2 = 1 }\]

\(N\)-denominator variance로 보면같은 \(z_i=(x_i-\bar x)/s\)에 대해:

\[\frac1N \sum_i z_i^2 = \frac{N-1}{N}\]

즉 denominator convention을 섞으면 “표준화 후 분산이 정확히 1”이라는 말이 틀릴 수 있다.

핵심 규칙표본 표준화에서 standard deviation denominator 와 variance check denominator 를 일치시켜야 한다.

원자료 Sample Z-score 보완원자료는 \(s = \sqrt{ \frac1{N-1} \sum_i (x_i-\bar x)^2 }\) 를 제시하면서 sample Z-score를 정의한다.

이는 통상적인 표본 표준편차 convention으로 타당하다.

다만 이 경우 transformed values의 분산을 확인할 때도 \(1/(N-1)\) convention을 사용해야 정확히 1이 된다.

Standardization과 Normalization 용어실무에서는 용어가 혼용되기도 하지만 보통 다음과 같이 구분한다.

Standardization:

\[\boxed{ z = \frac{x-\mu}{\sigma} }\]

Min-Max Scaling:

\[\boxed{ x' = \frac{ x-x_{\min} }{ x_{\max}-x_{\min} } }\]

핵심 식 — Population Z-score

\[\boxed{ Z = \frac{ X-\mu }{ \sigma } }\]

핵심 식 — Mean

\[\boxed{ \mathbb E[Z]=0 }\]

핵심 식 — Variance

\[\boxed{ \operatorname{Var}(Z)=1 }\]

핵심 식 — Sample Mean

\[\boxed{ \bar x = \frac1N \sum_i x_i }\]

핵심 식 — Population-style Sample Variance

\[\boxed{ s_N^2 = \frac1N \sum_i (x_i-\bar x)^2 }\]

핵심 식 — Unbiased Sample Variance

\[\boxed{ s^2 = \frac1{N-1} \sum_i (x_i-\bar x)^2 }\]

핵심 식 — Correlation

\[\boxed{ \rho_{XY} = \operatorname{Cov} \left( \frac{X-\mu_X}{\sigma_X}, \frac{Y-\mu_Y}{\sigma_Y} \right) }\]

핵심 식 — Group Relative NormalizationSource의 group-normalization 표현은 다음과 같다.

\[\boxed{ A_i = \frac{ R_i-\bar R }{ \sigma_R+\epsilon } }\]

성질·유도

기댓값 선형성

\[\mathbb E[X-\mu] = \mathbb E[X] - \mathbb E[\mu]\]

상수의 기댓값은 자기 자신이므로 다음과 같이 쓴다.

\[\mathbb E[\mu]=\mu\]

결과

\[\begin{aligned} \mathbb E[Z] &= \frac1\sigma (\mu-\mu)\\ &= \boxed{ 0 } \end{aligned}\]

분산 1 증명Affine transformation의 분산은 다음과 같다.

\[\boxed{ \operatorname{Var}(aX+b) = a^2\operatorname{Var}(X) }\]

Z-score에 적용\(Z = \frac1\sigma X - \frac\mu\sigma\) 이므로 다음과 같이 쓴다.

\[\operatorname{Var}(Z) = \frac1{\sigma^2} \operatorname{Var}(X)\]

\(\operatorname{Var}(X)=\sigma^2\)따라서 다음과 같다.

\[\begin{aligned} \operatorname{Var}(Z) &= \frac1{\sigma^2} \sigma^2\\ &= \boxed{ 1 } \end{aligned}\]

Z-score의 부호\(z>0\) 이면 관측값이 평균보다 크다.

\(z<0\) 이면 관측값이 평균보다 작다.

\(z=0\) 이면 관측값이 평균과 같다.

Z-score의 절댓값\(|z|\) 는 평균으로부터 떨어진 거리를 표준편차 단위로 나타낸다.

예를 들어 \(|z|=3\) 이면 평균에서 표준편차 3개만큼 떨어져 있다.

단위 제거\(X\)가 cm 단위라면 \(X-\mu\) 도 cm 단위이고 \(\sigma\)도 cm 단위다.

따라서 \(\frac{X-\mu}{\sigma}\) 에서는 단위가 소거된다.

즉 Z-score는 dimensionless quantity다.

서로 다른 변수 비교예를 들어 시험 A의 점수 85와 시험 B의 점수 90을 단순 비교하는 것은 불충분할 수 있다.

각 시험의 평균과 표준편차가 다르기 때문이다.

Z-score를 사용하면 각 점수가 자신의 분포에서 상대적으로 어느 위치에 있는지 비교할 수 있다.

Min-Max Scaling\(x_{\max}>x_{\min}\)일 때 training data 기준으로 \(x' = \frac{ x-x_{\min} }{ x_{\max}-x_{\min} }\) 를 적용하면 training sample의 최소값은 0, 최대값은 1이 된다.

새로운 데이터에서는 범위를 벗어날 수 있다Training data에서 얻은 \(x_{\min}, x_{\max}\) 를 새로운 test sample에 적용했을 때 test value가 training minimum보다 작거나 maximum보다 크면:

\[x'<0\]

또는 다음과 같다.

\[x'>1\]

이 될 수 있다.

따라서 “항상 \([0,1]\)”이라는 설명은 fitted dataset의 observed range 안에서만 정확하다.

Z-score의 rangeZ-score는 이론적으로 \((-\infty,\infty)\) 범위를 가질 수 있다.

단 실제 finite dataset에서는 관측된 값들에 의해 유한한 범위가 나타난다.

Outlier와 Z-score원자료는 Z-score가 Min-Max보다 이상치에 상대적으로 강건하다고 설명한다.

하지만 Z-score는 평균과 표준편차를 사용하므로 outlier에 민감하다.

평균의 비강건성극단적인 관측값 하나가 평균 \(\bar x\) 를 크게 이동시킬 수 있다.

표준편차의 비강건성표준편차는 squared deviation을 사용한다.

따라서 extreme outlier는 \((x_i-\bar x)^2\) 를 크게 만들어 scale estimate 자체를 크게 바꿀 수 있다.

더 정확한 비교Min-Max Scaling도 outlier에 매우 민감하다.

Z-score 역시 outlier에 민감하지만 영향 방식이 다르다.

따라서 Z-score is robust to outliers 라고 단정하면 안 된다.

Robust ScalingOutlier robustness가 필요하면 median과 IQR을 사용하는 \(x' = \frac{ x-\operatorname{median}(x) }{ \operatorname{IQR}(x) }\) 같은 Robust Scaling을 고려할 수 있다.

데이터 누수 주의Standardization parameter \(\mu,\sigma\) 또는 sample estimate \(\bar x,s\) 는 training data에서만 추정해야 한다.

Test Data 처리Test data에는 training set에서 구한 \(\bar x_{\text{train}}, \qquad s_{\text{train}}\) 을 그대로 사용해야 한다.

Test set 자체의 mean/std를 사용하면 data leakage가 발생할 수 있다.

Feature-wise StandardizationDataset matrix가 \(X\in\mathbb R^{N\times D}\) 이고 row가 sample, column이 feature라고 하자.

일반적으로 각 feature \(j\)에 대해 \(Z_{ij} = \frac{ X_{ij}-\mu_j }{ \sigma_j }\) 를 적용한다.

Column Mean각 standardized feature에 대해 population-style convention에서는 다음과 같다.

\[\boxed{ \frac1N \sum_{i=1}^N Z_{ij} = 0 }\]

Column Variance같은 denominator convention을 사용하면 각 feature variance는 1이 된다.

Standardization은 Whitening이 아니다Feature-wise Z-score standardization은 각 coordinate의 평균과 variance를 맞춘다.

하지만 feature 간 covariance는 일반적으로 남는다.

즉 \(\operatorname{Cov}(Z) \neq I\) 일 수 있다.

Whitening과 비교Whitening은 covariance matrix 자체를 \(\Sigma \rightarrow I\) 로 만드는 변환이다.

Z-score standardization은 diagonal variance만 맞춘다.

따라서 standardization ≠ whitening

Correlation Matrix각 feature를 Z-score standardize한 후 covariance matrix를 계산하면 correlation matrix와 연결된다.

즉 standardized variables의 covariance가 pairwise correlation을 나타낸다.

PCA와 StandardizationPCA를 covariance matrix에 적용할지 correlation matrix에 적용할지는 feature scale의 의미에 따라 달라진다.

Feature 단위가 크게 다르고 이를 동등하게 다루고 싶다면 standardization 후 PCA를 적용할 수 있다.

항상 표준화해야 하는 것은 아니다Feature의 absolute scale 자체가 의미를 가진다면 무조건 unit variance로 만드는 것이 적절하지 않을 수 있다.

Standardization은 modeling choice이지 모든 문제에서 필수 theorem은 아니다.

Gradient Descent 직관Scale이 크게 다른 feature를 사용하면 일부 optimization problem에서 objective contour가 elongated될 수 있다.

이는 gradient descent의 step efficiency를 악화시킬 수 있다.

원자료의 "정원 형태" 표현 보완원자료는 standardization을 적용하면 loss landscape가 원형으로 정형화된다고 설명한다.

이는 매우 단순한 quadratic problem에서 직관적으로 나타날 수 있지만 일반 deep neural network에서는 보장되지 않는다.

더 정확한 표현Feature scaling은 optimization conditioning을 개선할 수 있다.

하지만 Z-score ⇏ perfectly spherical loss landscape

혼동하기 쉬운 부분

  • 표준분포:Mean 0, variance 1을 만족한다고 해서 Standard Normal Distribution인 것은 아니다.

  • Normalization 용어:실무에서는 normalization이 넓은 의미로 쓰인다.

    Min-Max Scaling만 normalization이라고 부르기도 하고 Z-score까지 포함해 normalization이라고 부르기도 한다.

    문맥을 확인해야 한다.

  • Sample Variance:\(1/N\)과 \(1/(N-1)\)은 목적이 다르다.

    어느 것을 사용했는지에 따라 표준화 후 variance를 검증할 때 denominator도 맞춰야 한다.

  • Outlier Robustness:Z-score는 mean과 standard deviation을 사용하므로 robust estimator가 아니다.

  • Whitening:각 feature variance를 1로 만드는 것과 covariance matrix 전체를 identity로 만드는 것은 다르다.

  • PCA:PCA 전에 standardization을 할지 여부는 feature scale의 의미에 따라 결정해야 한다.

    무조건 표준화하는 것이 정답은 아니다.

  • Loss Landscape:Feature standardization이 optimization conditioning을 개선할 수는 있지만 deep network의 loss landscape를 항상 원형으로 만들지는 않는다.

  • \(\epsilon\):Normalization denominator에 \(\epsilon\)을 넣으면 transformed variance가 수학적으로 정확히 1이 아닐 수 있다.

  • Reward Scale Invariance:\(\epsilon=0\)이고 positive affine transformation이라면 exact invariance를 보일 수 있다.

    \(\epsilon>0\) 또는 negative scale에서는 조건이 달라진다.

  • GRPO 전체 Objective:Reward Z-score normalization은 GRPO의 한 구성요소다.

    GRPO 전체를 단순히:

    \[A_i = \frac{ R_i-\bar R }{ \sigma_R+\epsilon }\]

    하나로 설명하면 부족하다.

  • Critic 제거:Critic/value model을 사용하지 않는 것과 reward model/verifier가 전혀 없는 것은 다른 이야기다.

  • Gradient 안정성:Standardized reward는 scale variation을 줄이는 데 도움을 줄 수 있지만 gradient explosion/vanishing을 완전히 방지한다는 theorem은 아니다.

    Standard Score 또는 Z-score는 확률변수의 위치와 scale을 정규화하는 affine transformation이다.

    Population 평균과 표준편차가 \(\mu=\mathbb E[X], \qquad \sigma=\sqrt{\operatorname{Var}(X)}\) 이고 \(0<\sigma<\infty\) 이면 \(Z = \frac{ X-\mu }{ \sigma }\) 로 정의한다.

    기댓값의 선형성에 의해 \(\mathbb E[Z]=0\) 이고 분산의 affine transformation 성질에 의해:

    \[\boxed{ \operatorname{Var}(Z)=1 }\]

    하지만 이것이 \(Z\sim\mathcal N(0,1)\) 을 의미하지는 않는다.

    원래 \(X\sim\mathcal N(\mu,\sigma^2)\) 일 때만 standardized variable이 Standard Normal이 된다.

    Sample Data에서는 \(\bar x = \frac1N \sum_i x_i\) 를 사용하고 variance denominator convention을 명확히 해야 한다.

    Population-style empirical standard deviation \(s_N = \sqrt{ \frac1N \sum_i (x_i-\bar x)^2 }\) 를 사용하면 \(z_i = \frac{ x_i-\bar x }{ s_N }\) 에 대해 \(1/N\) variance가 정확히 1이다.

    반면 unbiased sample standard deviation \(s = \sqrt{ \frac1{N-1} \sum_i (x_i-\bar x)^2 }\) 를 사용하면 \(1/(N-1)\) sample variance가 정확히 1이다.

    Min-Max Scaling은 다음과 같다.

    \[\boxed{ x' = \frac{ x-x_{\min} }{ x_{\max}-x_{\min} } }\]

    Z-score와 Min-Max 모두 outlier의 영향을 받을 수 있으며 Z-score가 robust estimator인 것은 아니다.

    Feature-wise standardization은 각 feature의 mean과 variance를 조절하지만 feature 간 covariance를 제거하지 않는다.

    따라서 standardization ≠ whitening

    원자료의 reward numerical example에서는 \(R=[2,5,3,10]\) 이고:

    \[\boxed{ \bar R=5 }\]

    \(1/G\) convention의 variance는 \(\sigma_R^2=9.5\) 이고:

    \[\boxed{ \sigma_R\approx3.082207 }\]

    \(\epsilon\)을 무시하면 normalized rewards는 \(A \approx [ -0.97333, 0, -0.64889, 1.62221 ]\) 이고 평균은 0, \(1/G\) variance는 1이다.

    그러나 실제 denominator가 \(\sigma_R+\epsilon\) 이면 \(\operatorname{Var}(A) = \frac{ \sigma_R^2 }{ (\sigma_R+\epsilon)^2 }\) 이므로 \(\epsilon>0\)일 때 variance는 엄밀히 1보다 조금 작다.

    Group-relative normalization은 동일 prompt에서 나온 여러 rewards의 mean을 빼고 scale을 맞춤으로써 상대적인 optimization signal을 구성하는 데 사용할 수 있다.

    Positive affine reward transformation에 대해서는 \(\epsilon=0\)일 때 normalized signal이 invariant하지만, \(\epsilon\)이 있으면 exact invariance가 완전히 유지되지는 않는다.

    또한 reward standardization은 GRPO 전체 objective가 아니라 하나의 구성요소로 이해해야 한다.

    PS-08의 전체 흐름은 Raw Variable → Centering → Scaling → Standard Score 이며, Machine Learning에서는 Z-score → Feature Scaling / Correlation / Optimization Conditioning 및 Group Reward Statistics → Relative RL Signal 로 연결된다.

GRPO 연결 — Source에서의 핵심원자료는 group-relative policy optimization에서 동일한 prompt에 대해 여러 output을 sampling하고 reward를 비교하는 구조를 Z-score와 연결한다.

개념적으로 다음과 같이 쓴다.

\[\boxed{ \text{same prompt} \rightarrow G\text{ responses} \rightarrow G\text{ rewards} \rightarrow \text{group-relative signal} }\]

Critic-free Relative Signal전통적인 actor-critic 방식에서는 value estimate가 baseline 역할을 할 수 있다.

Group-relative 방식은 동일 prompt에 대한 여러 responses의 상대적 reward 정보를 활용함으로써 별도의 learned critic 없이 advantage-like signal을 구성할 수 있다는 아이디어를 가진다.

Baseline 역할Group mean \(\bar R\) 를 빼면 \(R_i-\bar R\) 가 된다.

이는 해당 response가 같은 prompt의 다른 samples에 비해 상대적으로 얼마나 좋은지를 나타낸다.

Scale Normalization추가로 group standard deviation으로 나누면 reward scale 차이를 줄인다.

\[\boxed{ \frac{ R_i-\bar R }{ \sigma_R } }\]

Mean-Zero Relative Signal동일 denominator를 사용하면 group normalized values의 합은 다음과 같다.

\[\boxed{ \sum_iA_i=0 }\]

즉 group 안에서 positive와 negative relative signal이 균형을 이룬다.

Affine Reward InvarianceReward에 positive affine transformation \(R_i' = aR_i+b, \qquad a>0\) 를 적용한다고 하자.

Mean Transformation

\[\bar R' = a\bar R+b\]

Standard Deviation Transformation

\[\sigma_R' = a\sigma_R\]

Normalized Signal\(\epsilon=0\)이면 다음과 같다.

\[\frac{ R_i'-\bar R' }{ \sigma_R' } = \frac{ a(R_i-\bar R) }{ a\sigma_R } = \boxed{ \frac{ R_i-\bar R }{ \sigma_R } }\]

즉 positive scale과 translation에 invariant하다.

\(\epsilon\)이 있으면 완전한 invariance는 깨질 수 있다실제 denominator가 \(\sigma_R+\epsilon\) 이면 additive \(\epsilon\) 때문에 exact scale invariance는 엄밀히 깨질 수 있다.

다만 \(\sigma_R\)가 \(\epsilon\)보다 충분히 크면 근사적으로 유지된다.

Negative Scaling만약 \(a<0\) 이면 normalized score의 부호가 뒤집힌다.

따라서 모든 affine transformation에 완전히 invariant하다고 말하면 안 된다.

GRPO에서 Z-score라는 표현의 범위실제 algorithm formulation은 논문/구현에 따라 reward aggregation, group normalization, token-level application, clipping 등의 세부사항이 추가될 수 있다.

따라서 다음과 같다.

\[A_i = \frac{ R_i-\bar R }{ \sigma_R+\epsilon }\]

하나가 GRPO 전체 objective를 나타내는 것은 아니다.

PPO와 GRPO 비교높은 수준에서 PPO는 learned value function 또는 advantage estimator와 함께 사용되는 경우가 많다.

GRPO 계열은 group-relative comparisons를 이용해 value model 의존도를 줄이는 방향으로 설명할 수 있다.

"Critic 완전 제거" 표현Source의 핵심은 별도의 value/critic model을 사용하지 않고 group-relative reward signal을 만드는 데 있다.

다만 실제 training system 전체에서 모든 auxiliary evaluation component가 사라진다는 뜻은 아니다.

Reward model이나 rule-based verifier 등은 별도로 존재할 수 있다.

보상 폭발/소실을 "방지"한다는 표현Normalization은 reward scale을 안정화하여 optimization conditioning에 도움을 줄 수 있다.

하지만 reward Z-score normalization

만으로 gradient explosion/vanishing이 수학적으로 방지된다고 보장할 수는 없다.

더 정확한 표현Standardized reward/advantage는 update scale variation을 줄이고 상대 비교를 쉽게 만들 수 있다.

하지만 gradient behavior는 policy ratio, clipping, sequence length, optimizer, model Jacobian 등에도 의존한다.

Batch Normalization과 Z-scoreBatchNorm 역시 mini-batch statistics를 사용해 activation을 center/scale한다.

개략적으로 \(\hat x = \frac{ x-\mu_B }{ \sqrt{ \sigma_B^2+\epsilon } }\) 형태를 가진다.

그러나 BatchNorm은 단순 Z-score 이상BatchNorm에는 learnable parameters \(\gamma,\beta\) 가 추가된다.

\[\boxed{ y = \gamma\hat x+\beta }\]

따라서 최종 output의 mean 0, variance 1이 보장되는 것은 아니다.

LayerNorm과 비교LayerNorm도 비슷한 center/scale 구조를 사용하지만 normalization axis가 다르다.

Feature preprocessing용 dataset-level Z-score와 LayerNorm을 동일한 연산으로 보면 안 된다.

RMSNorm과 비교RMSNorm은 일반적으로 mean centering 없이 RMS scale을 사용한다.

따라서 RMSNorm ≠ Z-score standardization

Standardization과 Softmax Temperature둘 다 scale을 조절하지만 목적과 수학이 다르다.

Z-score는 mean과 variance를 기준으로 affine transformation을 수행한다.

Temperature scaling은 logits를 \(z_i/T\) 로 바꾸어 softmax distribution sharpness를 조절한다.

Standardization과 Feature Geometry각 coordinate의 scale을 맞추면 Euclidean distance나 dot-product 기반 method에서 특정 high-scale feature가 거리 계산을 지배하는 현상을 줄일 수 있다.

그러나 방향 상관구조는 남는다Feature-wise Z-score만으로 correlated feature axes가 decorrelate되지는 않는다.

즉 geometry는 완전히 spherical해지지 않는다.

Standardization과 Linear RegressionLinear regression에서 feature scale이 크게 다르면 optimization과 coefficient interpretation에 영향을 줄 수 있다.

Standardization 후 coefficient는 feature의 표준편차 단위 변화와 연결해 해석할 수 있다.

Regularization과 ScaleL1/L2 regularization은 coefficient magnitude에 직접 penalty를 준다.

Feature scale이 다르면 동일한 coefficient magnitude의 의미가 feature마다 달라질 수 있다.

따라서 standardization은 regularized linear models에서 특히 중요할 수 있다.

KNN과 거리 기반 모델KNN, K-means 등 거리 기반 알고리즘은 feature scale에 매우 민감하다.

Z-score scaling은 각 feature를 비교 가능한 scale로 맞추는 대표적 방법이다.

Tree-based ModelDecision Tree나 Random Forest처럼 threshold split을 사용하는 model은 monotonic feature rescaling에 상대적으로 덜 민감하다.

따라서 모든 model에서 standardization 효과가 동일하지 않다.

Z-score와 Outlier Detection절댓값이 큰 Z-score를 outlier heuristic으로 사용할 수 있다.

예를 들어 Gaussian assumption 아래 \(|Z|>3\) 같은 rule을 사용할 수 있다.

하지만 일반 분포에서는 주의분포가 heavy-tailed하거나 skewed하면 \(|Z|>3\) 을 보편적인 outlier criterion으로 사용하면 부정확할 수 있다.

Z-score threshold의 의미는 distribution assumption에 의존한다.

Gaussian에서의 확률 해석만약 \(Z\sim\mathcal N(0,1)\) 이면 다음과 같다.

\[P(|Z|\le1) \approx 0.6827\]
\[P(|Z|\le2) \approx 0.9545\]
\[P(|Z|\le3) \approx 0.9973\]

다시 강조이 68-95-99.7 rule은 Gaussian Distribution에 대한 결과다.

모든 standardized variable에 자동으로 적용되는 규칙이 아니다.

Sample Standardization Matrix FormDataset \(X\in\mathbb R^{N\times D}\) 에서 feature mean vector를 \(\mu \in \mathbb R^D\) 라고 하자.

CenteringCentered matrix는 다음과 같다.

\[\boxed{ X_c = X-\mathbf1_N\mu^T }\]

Shape은 다음과 같다 (\(X_c\in\mathbb R^{N\times D}\)).

Scaling MatrixFeature standard deviations를 \(\sigma_1,\dots,\sigma_D\) 라고 하고:

\[D_\sigma = \operatorname{diag} ( \sigma_1,\dots,\sigma_D )\]

라 하자.

Matrix Standardization모든 \(\sigma_j>0\)이면 다음과 같다.

\[\boxed{ Z = X_c D_\sigma^{-1} }\]

Zero-Variance Feature어떤 feature가 모든 training sample에서 동일하면 다음과 같다.

\[\sigma_j=0\]

이때 Z-score division은 정의되지 않는다.

실무 처리Zero-variance feature는 정보가 없으므로 제거하거나 별도 처리할 수 있다.

단순히 매우 작은 \(\epsilon\)을 넣는 것은 numerical division을 막아줄 뿐 해당 feature에 정보가 생기는 것은 아니다.

Population vs Estimated Statistics이론에서는 \(\mu,\sigma\) 를 population parameter로 사용한다.

실제 ML preprocessing에서는 이를 모르므로 training sample에서 \(\hat\mu,\hat\sigma\) 를 추정한다.

Finite-Sample Uncertainty따라서 test distribution 관점에서 standardized feature의 실제 population mean과 variance가 정확히 0과 1이 되지는 않을 수 있다.

Training sample에서는 chosen convention에 따라 정확히 맞을 수 있지만 population에서는 추정오차가 존재한다.

Distribution ShiftTraining 때 구한 \(\hat\mu_{\text{train}}, \hat\sigma_{\text{train}}\) 를 deployment data에 적용했을 때 distribution shift가 크면 standardized deployment values의 mean과 variance가 0과 1에서 벗어날 수 있다.

Z-score의 Inverse TransformStandardized value \(z\) 에서 원래 scale로 되돌리려면:

\[\boxed{ x = \sigma z+\mu }\]

Invertibility\(\sigma>0\)이면 Z-score transformation은 one-to-one affine map이다.

따라서 정보 자체를 잃는 transformation은 아니다.

Min-Max InverseMin-Max scaling도 \(x = x_{\min} + x' ( x_{\max}-x_{\min} )\) 로 inverse transform할 수 있다.

Numerical Stability실제 구현에서는 denominator가 너무 작을 때 numerical instability가 생길 수 있다.

따라서 normalization layer나 reward normalization에서는 \(\epsilon\) 을 추가하는 경우가 많다.

\(\sigma+\epsilon\) vs \(\sqrt{\sigma^2+\epsilon}\)구현마다 \(\sigma+\epsilon\) 을 쓰거나 \(\sqrt{ \sigma^2+\epsilon }\) 형태를 사용할 수 있다.

두 식은 정확히 동일하지 않다.

따라서 algorithm formula를 인용할 때는 source convention을 유지해야 한다.

전체 개념 연결PS-08의 기본 흐름은 다음과 같다.

\[\boxed{ X \rightarrow X-\mu \rightarrow \frac{X-\mu}{\sigma} }\]

Statistical Flowlocation → centering 및 scale → unit-variance scaling

Geometry FlowFeature-wise standardization은 coordinate axis마다 scale을 맞춘다.

하지만 axis 간 covariance를 제거하지는 않는다.

ML Flowfeature scaling → better numerical conditioning in some models 로 연결된다.

Correlation Flow두 변수를 각각 표준화하면 covariance가 correlation과 일치한다.

Z-score → correlation

RL Flow동일 prompt의 여러 rewards를 center/scale하면 group-relative optimization signal을 만들 수 있다.

group rewards → relative normalized signal

정리

Z-score \(Z=(X-\mu)/\sigma\)는 평균을 빼고 표준편차로 나누어 population mean 0, variance 1의 scale로 표현한다. Sample statistic을 쓸 때의 보정과 min–max normalization은 성질이 다르고, 정규분포를 가정하지 않아도 표준화할 수 있지만 정규성 자체가 생기지는 않는다.
