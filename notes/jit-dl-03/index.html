DL-03 — Softmax Mechanism

Softmax의 확률 변환 과정과 수치 안정성, 미분 구조를 정리한다.

ML·딥러닝 · DL-03업데이트 2026.09.21
  • #Softmax
  • #Logits
  • #Probability
  • #Jacobian

개념

Softmax Mechanism — Classification과 Language Modeling에서는 Neural Network가 마지막 단계에서 직접 Probability를 출력하기보다 먼저 임의의 실수값 Vector를 출력하는 경우가 많다. 이 Vector를

\[\boxed{ \mathbf z = [z_1,z_2,\dots,z_K]^T \in \mathbb R^K }\]

라고 한다. 각 \(z_i\)를 Logit이라고 한다. Softmax는 이 Logit Vector를 Probability Vector로 변환한다.

\[\boxed{ \mathbb R^K \xrightarrow{\text{Softmax}} \Delta^{K-1} }\]

Probability Simplex — Softmax의 출력은

\[\boxed{ \mathbf S(\mathbf z) = [S_1,\dots,S_K]^T }\]

각 Component는 \(S_i>0\) 이고

\[\sum_{i=1}^{K}S_i=1\]

을 만족한다. 따라서 출력은 \((K-1)\)차 Probability Simplex \(\boxed{ \Delta^{K-1} }\) 위에 존재한다.

표기·차원

Softmax Definition — Softmax의 \(i\)번째 출력은

\[\boxed{ S_i(\mathbf z) = \frac{ e^{z_i} }{ \sum_{j=1}^{K}e^{z_j} } }\]

for \(i=1,\dots,K\)

Numerator — 각 Class \(i\)의 Logit을 Exponential에 통과시킨다. \(\boxed{ e^{z_i} }\) Exponential Function은 항상 양수이므로 \(\boxed{ e^{z_i}>0 }\)

Partition Function — 분모를

\[\boxed{ Z = \sum_{j=1}^{K} e^{z_j} }\]

라고 둘 수 있다. 그러면

\[\boxed{ S_i = \frac{e^{z_i}}{Z} }\]

\(Z\)는 모든 Exponential Score를 정규화하는 역할을 한다.

Jacobian Shape — 입력도 \(K\)차원이고 출력도 \(K\)차원이므로

\[\boxed{ \mathbf J_{\mathrm{softmax}} \in \mathbb R^{K\times K} }\]

핵심 연산

Non-Negativity — 모든 \(z_i\in\mathbb R\)에 대해 \(e^{z_i}>0\) 또한 \(Z>0\) 이므로 \(\boxed{ S_i(\mathbf z)>0 }\)

Normalization — Softmax 출력을 모두 합하면

\[\begin{aligned} \sum_{i=1}^{K}S_i &= \sum_{i=1}^{K} \frac{ e^{z_i} }{ \sum_{j=1}^{K}e^{z_j} }\\ &= \frac{ \sum_{i=1}^{K}e^{z_i} }{ \sum_{j=1}^{K}e^{z_j} }\\ &= \boxed{1} \end{aligned}\]

Categorical Distribution — 따라서

\[\boxed{ \mathbf p = \mathbf S(\mathbf z) }\]

를 Categorical Distribution의 Probability Parameter로 사용할 수 있다. 즉

\[\boxed{ p_i = P(Y=i) = S_i(\mathbf z) }\]

Logit의 의미 — Softmax 이전의 \(z_i\)는 Probability가 아니다. 일반적으로 \(z_i<0\) 일 수도 있고

\[\sum_i z_i \neq1\]

이어도 된다. Softmax가 이를 Probability Distribution으로 변환한다.

\[\boxed{ \text{Logits} \rightarrow \text{Softmax} \rightarrow \text{Probabilities} }\]

Logit Difference — 두 Softmax Probability의 비율은

\[\frac{S_i}{S_j} = \frac{e^{z_i}}{e^{z_j}}\]

따라서

\[\boxed{ \frac{S_i}{S_j} = e^{z_i-z_j} }\]

즉 Probability Ratio는 Logit의 절댓값보다는 Logit Difference에 의해 결정된다.

Log-Odds — 앞 식의 Log를 취하면

\[\boxed{ \log \frac{S_i}{S_j} = z_i-z_j }\]

따라서 두 Class 사이의 상대적 Logit Difference가 Probability Ratio의 Log와 직접 연결된다.

Shift Invariance — Softmax는 모든 Logit에 동일한 상수 \(c\in\mathbb R\) 를 더해도 출력이 변하지 않는다.

\[\boxed{ \operatorname{Softmax} ( \mathbf z+c\mathbf1 ) = \operatorname{Softmax} ( \mathbf z ) }\]

Shift Invariance 유도 —

\[\begin{aligned} S_i( \mathbf z+c\mathbf1 ) &= \frac{ e^{z_i+c} }{ \sum_j e^{z_j+c} }\\ &= \frac{ e^{z_i}e^c }{ e^c \sum_j e^{z_j} }\\ &= \frac{ e^{z_i} }{ \sum_j e^{z_j} } \end{aligned}\]

따라서

\[\boxed{ S_i( \mathbf z+c\mathbf1 ) = S_i(\mathbf z) }\]

Shift Invariance의 의미 — Softmax는 \(z_1,\dots,z_K\) 의 절대적인 위치에는 관심이 없다. 모든 값에 같은 Constant를 더하거나 빼도 Probability는 그대로다. 즉

\[\boxed{ \text{relative logits matter} }\]

Numerical Stability와 연결 — Shift Invariance는 단순한 이론적 성질이 아니다. 실제 계산에서는 \(\boxed{ c = -\max_jz_j }\) 를 선택한다. 즉 모든 Logit에서 최대값을 빼고 Softmax를 계산한다.

Softmax는 Vector-Valued Function — Softmax는

\[\boxed{ \mathbf S: \mathbb R^K \rightarrow \mathbb R^K }\]

인 Vector-Valued Function이다. 따라서 Derivative는 Scalar가 아니라 Jacobian Matrix다.

Softmax Jacobian — Jacobian은

\[\boxed{ \mathbf J_{\mathrm{softmax}} = \left[ \frac{ \partial S_i }{ \partial z_j } \right]_{K\times K} }\]

즉 모든 Output Component와 모든 Input Logit 사이의 Partial Derivative를 모은 Matrix다.

Off-Diagonal Quotient Rule — 따라서

\[\frac{ \partial S_i }{ \partial z_j } = \frac{ 0 - e^{z_i}e^{z_j} }{ \left( \sum_ke^{z_k} \right)^2 }\]

Off-Diagonal Derivative — 이를 Softmax Probability로 표현하면

\[\boxed{ \frac{ \partial S_i }{ \partial z_j } = -S_iS_j }\]

for \(i\neq j\)

Off-Diagonal Derivative의 부호 — \(S_i>0, \qquad S_j>0\) 이므로 \(\boxed{ -S_iS_j<0 }\) 따라서 다른 Class의 Logit \(z_j\)를 증가시키면 \(S_i\)는 감소한다. 이는 모든 Probability의 합이 1이어야 하기 때문이다.

Kronecker Delta — 두 Case를 하나의 식으로 결합하기 위해 Kronecker Delta를 사용한다.

\[\boxed{ \delta_{ij} = \begin{cases} 1,&i=j\\ 0,&i\neq j \end{cases} }\]

Unified Jacobian Element — 두 경우를 통합하면

\[\boxed{ \frac{ \partial S_i }{ \partial z_j } = S_i ( \delta_{ij}-S_j ) }\]

이는 Softmax Jacobian의 핵심 Component Formula다.

Matrix Form — Jacobian 전체를 Matrix로 표현하면

\[\boxed{ \mathbf J_{\mathrm{softmax}} = \operatorname{diag}(\mathbf S) - \mathbf S\mathbf S^T }\]

\(\operatorname{diag}(S)\) — \(\operatorname{diag}(\mathbf S)\) 는

\[\boxed{ \begin{bmatrix} S_1&0&\cdots&0\\ 0&S_2&\cdots&0\\ \vdots&&\ddots&\vdots\\ 0&0&\cdots&S_K \end{bmatrix} }\]

Outer Product — \(\mathbf S\mathbf S^T\) 의 \((i,j)\) Element는 \(\boxed{ S_iS_j }\) 따라서

\[\operatorname{diag}(\mathbf S) - \mathbf S\mathbf S^T\]

의 대각 Element는 \(S_i-S_i^2\) 이고 비대각 Element는 \(-S_iS_j\)

Jacobian은 Symmetric — 두 Matrix \(\operatorname{diag}(\mathbf S)\) 와 \(\mathbf S\mathbf S^T\) 모두 Symmetric이다. 따라서

\[\boxed{ \mathbf J_{\mathrm{softmax}} = \mathbf J_{\mathrm{softmax}}^T }\]

Jacobian Row Sum — \(j\)에 대해 Sum하면

\[\begin{aligned} \sum_j \frac{\partial S_i}{\partial z_j} &= S_i \sum_j ( \delta_{ij}-S_j )\\ &= S_i \left( 1-\sum_jS_j \right)\\ &= 0 \end{aligned}\]

따라서

\[\boxed{ \mathbf J_{\mathrm{softmax}}\mathbf1 = \mathbf0 }\]

Shift Invariance와 Jacobian — 앞에서

\[\operatorname{Softmax}( \mathbf z+c\mathbf1 ) = \operatorname{Softmax}(\mathbf z)\]

임을 확인했다. 즉 \(\mathbf1\) 방향으로 Logit을 이동해도 출력이 변하지 않는다. 따라서 Jacobian에서 \(\boxed{ \mathbf1 }\) 은 Zero-Eigenvalue Direction이 된다.

핵심 식 — Softmax —

\[\boxed{ S_i(\mathbf z) = \frac{ e^{z_i} }{ \sum_j e^{z_j} } }\]

핵심 식 — Jacobian Element —

\[\boxed{ \frac{ \partial S_i }{ \partial z_j } = S_i( \delta_{ij}-S_j ) }\]

핵심 식 — Jacobian Matrix —

\[\boxed{ \mathbf J_{\mathrm{softmax}} = \operatorname{diag}(\mathbf S) - \mathbf S\mathbf S^T }\]

핵심 식 — Stable Softmax —

\[\boxed{ S_i = \frac{ e^{z_i-C} }{ \sum_j e^{z_j-C} }, \qquad C=\max_jz_j }\]

핵심 식 — Log-Sum-Exp —

\[\boxed{ \log \sum_j e^{z_j} = C + \log \sum_j e^{z_j-C} }\]

핵심 식 — Cross-Entropy —

\[\boxed{ \mathcal L = -\sum_k y_k\log S_k }\]

One-Hot에서는 \(\boxed{ \mathcal L = -\log S_c }\)

핵심 식 — Logit Gradient —

\[\boxed{ \nabla_{\mathbf z} \mathcal L = \mathbf S-\mathbf y }\]

핵심 식 — LLM Output Head —

\[\boxed{ \mathbf z_t = \mathbf W_{\mathrm{head}} \mathbf h_t }\]
\[\boxed{ \mathbf p_t = \operatorname{Softmax} ( \mathbf z_t ) }\]
\[\boxed{ \mathcal L_t = -\log p_{t,y_t} }\]

성질·유도

Jacobian 유도의 준비 — Softmax Component는

\[S_i = \frac{e^{z_i}} { \sum_{k=1}^{K}e^{z_k} }\]

다음을 정의한다. \(\boxed{ u=e^{z_i} }\)

\[\boxed{ v= \sum_{k=1}^{K}e^{z_k} }\]

그러면

\[S_i=\frac uv\]

Quotient Rule — 몫의 미분법은

\[\boxed{ \left( \frac uv \right)' = \frac{ u'v-uv' }{ v^2 } }\]

Softmax는 \(i=j\)와 \(i\neq j\)에서 Numerator의 미분이 달라지므로 두 경우를 나누어 계산한다.

Case 1 — Diagonal Element — 먼저 \(\boxed{ i=j }\) 인 경우를 생각한다. 즉

\[\frac{\partial S_i}{\partial z_i}\]

를 계산한다.

Numerator Derivative — \(u=e^{z_i}\) 이므로

\[\boxed{ \frac{\partial u}{\partial z_i} = e^{z_i} }\]

Denominator Derivative —

\[v= \sum_{k=1}^{K}e^{z_k}\]

이므로

\[\boxed{ \frac{\partial v}{\partial z_i} = e^{z_i} }\]

Quotient Rule 대입 — 따라서

\[\frac{\partial S_i}{\partial z_i} = \frac{ e^{z_i} \left( \sum_k e^{z_k} \right) - e^{z_i}e^{z_i} }{ \left( \sum_k e^{z_k} \right)^2 }\]

첫 번째 항 정리 — 첫 번째 부분은

\[\frac{ e^{z_i} \sum_ke^{z_k} }{ \left( \sum_ke^{z_k} \right)^2 }\]

분모 하나를 약분하면

\[\boxed{ = \frac{ e^{z_i} }{ \sum_ke^{z_k} } = S_i }\]

두 번째 항 정리 — 두 번째 부분은

\[\frac{ e^{2z_i} }{ \left( \sum_ke^{z_k} \right)^2 }\]

이는 \(\boxed{ S_i^2 }\)

Diagonal Derivative — 따라서

\[\boxed{ \frac{ \partial S_i }{ \partial z_i } = S_i-S_i^2 }\]

이고

\[\boxed{ \frac{ \partial S_i }{ \partial z_i } = S_i(1-S_i) }\]

Diagonal Derivative의 부호 — Probability이므로 \(0<S_i<1\) 따라서 \(\boxed{ S_i(1-S_i)>0 }\) 즉 자신의 Logit \(z_i\)가 증가하면 자신의 Probability \(S_i\)도 증가한다.

Case 2 — Off-Diagonal Element — 이제 \(\boxed{ i\neq j }\) 인 경우

\[\frac{ \partial S_i }{ \partial z_j }\]

를 계산한다.

Numerator Derivative — Numerator \(u=e^{z_i}\) 는 \(z_j\)와 독립이므로

\[\boxed{ \frac{\partial u} {\partial z_j} = 0 }\]

for \(i\neq j\)

Denominator Derivative — 반면

\[v= \sum_k e^{z_k}\]

에는 \(e^{z_j}\) 가 포함된다. 따라서

\[\boxed{ \frac{\partial v} {\partial z_j} = e^{z_j} }\]

Jacobian Rank — 모든 \(S_i>0\)인 일반적인 Softmax에서는 Shift-Invariance Direction 때문에 Jacobian이 Full Rank가 아니다. 일반적으로

\[\boxed{ \operatorname{rank} ( \mathbf J_{\mathrm{softmax}} ) = K-1 }\]

즉 Probability Simplex가 \(K-1\)차원이라는 사실과 연결된다.

Jacobian과 Categorical Covariance — Categorical One-Hot Random Vector를 \(\mathbf Y\) 라고 하고 \(\mathbb E[\mathbf Y]=\mathbf S\) 라고 하면 Covariance는

\[\boxed{ \operatorname{Cov}(\mathbf Y) = \operatorname{diag}(\mathbf S) - \mathbf S\mathbf S^T }\]

따라서 Softmax Jacobian은 Categorical Distribution의 Covariance Matrix와 같은 형태다.

Positive Semi-Definite Structure — Covariance Matrix는 Positive Semi-Definite이므로

\[\boxed{ \mathbf J_{\mathrm{softmax}} \succeq0 }\]

즉 모든 Vector \(\mathbf v\)에 대해

\[\boxed{ \mathbf v^T \mathbf J_{\mathrm{softmax}} \mathbf v \ge0 }\]

Numerical Stability 문제 — Softmax의 직접 계산은 \(e^{z_i}\) 를 포함한다. 만약 \(z_i\) 가 매우 크면 Exponential이 Floating-Point 표현 범위를 넘어갈 수 있다. 원자료의 예는 \(\boxed{ z_i=1000 }\)

Overflow — Naive하게 \(e^{1000}\) 을 계산하면 일반적인 Floating-Point 환경에서 Overflow가 발생할 수 있다. 그러면 이후 연산에서

  • inf
  • NaN

등이 발생할 수 있다.

Underflow — 반대로 Logit이 매우 작은 음수라면 \(e^{z_i}\) 가 표현 가능한 최소 양수보다 작아져 0으로 Underflow될 수 있다. 따라서 직접적인 Exponential 계산은 안정적으로 구현해야 한다.

Maximum Shift — 다음을 정의한다. \(\boxed{ C = \max_jz_j }\) 그리고 새로운 Logit을 \(\boxed{ z_i' = z_i-C }\) 로 정의한다. Shift Invariance에 의해 Softmax 결과는 변하지 않는다.

Stable Softmax — 따라서

\[\boxed{ S_i(\mathbf z) = \frac{ e^{z_i-C} }{ \sum_j e^{z_j-C} } }\]

로 계산할 수 있다.

Stable Exponential Range — \(C\)가 Maximum이므로 \(\boxed{ z_i-C\le0 }\) 따라서 \(\boxed{ 0< e^{z_i-C} \le1 }\) 큰 양의 Exponential을 계산하지 않으므로 Overflow 문제를 방지한다.

Underflow는 완전히 사라지는가? — Maximum Shift는 Overflow를 안정적으로 제거하지만 매우 작은 Probability에 해당하는 항은 여전히 Floating-Point에서 Underflow될 수 있다. 다만 이러한 경우 작은 항이 0에 가까워지는 것은 계산상 훨씬 관리하기 쉬우며, Log-Probability가 필요한 경우에는 별도의 Log-Sum-Exp 계산을 사용한다.

Log-Sum-Exp — 다음 Quantity를 생각한다.

\[\boxed{ \operatorname{LSE}(\mathbf z) = \log \sum_j e^{z_j} }\]

Maximum \(C=\max_jz_j\) 를 이용하면

\[\begin{aligned} \operatorname{LSE}(\mathbf z) &= \log \left[ e^C \sum_j e^{z_j-C} \right]\\ &= \boxed{ C + \log \sum_j e^{z_j-C} } \end{aligned}\]

Log-Softmax — Softmax의 Log Probability는

\[\log S_i = z_i - \log \sum_j e^{z_j}\]

따라서

\[\boxed{ \log S_i = z_i - \operatorname{LSE}(\mathbf z) }\]

Stable LSE를 사용하면 Log-Softmax도 안정적으로 계산할 수 있다.

Cross-Entropy Loss — 정답을 One-Hot Vector

\[\boxed{ \mathbf y = [y_1,\dots,y_K]^T }\]

라고 하자. Categorical Cross-Entropy는

\[\boxed{ \mathcal L = -\sum_{k=1}^{K} y_k\log S_k }\]

One-Hot Label — 정답 Class Index를 \(c\)라고 하면 \(y_c=1\) 이고 \(y_k=0 \qquad (k\neq c)\) 따라서 Loss는 \(\boxed{ \mathcal L = -\log S_c }\) 로 단순화된다.

Cross-Entropy와 NLL — Categorical Distribution에서 정답 Class \(c\)가 관측되었을 때 \(\boxed{ -\log S_c }\) 는 Negative Log-Likelihood와 같다. 따라서 One-Hot Target에서는

\[\boxed{ \text{Categorical Cross-Entropy} = \text{NLL} }\]

Logit Gradient의 목표 — Backpropagation에서는

\[\boxed{ \nabla_{\mathbf z}\mathcal L }\]

가 필요하다. 원자료는 Softmax Jacobian과 Cross-Entropy의 Chain Rule을 결합하여 이를 유도한다.

Chain Rule — 각 Logit \(z_i\)에 대해

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_i } = \sum_{k=1}^{K} \frac{ \partial\mathcal L }{ \partial S_k } \frac{ \partial S_k }{ \partial z_i } }\]

Loss를 \(S_k\)로 미분 —

\[\mathcal L = -\sum_k y_k\log S_k\]

이므로

\[\boxed{ \frac{ \partial\mathcal L }{ \partial S_k } = -\frac{y_k}{S_k} }\]

Softmax Derivative 대입 — 앞에서

\[\boxed{ \frac{ \partial S_k }{ \partial z_i } = S_k( \delta_{ki}-S_i ) }\]

를 유도했다. 이를 Chain Rule에 대입한다.

Gradient 전개 —

\[\begin{aligned} \frac{ \partial\mathcal L }{ \partial z_i } &= \sum_k \left( -\frac{y_k}{S_k} \right) S_k( \delta_{ki}-S_i )\\ &= -\sum_k y_k( \delta_{ki}-S_i ) \end{aligned}\]

First Term — Kronecker Delta에 의해

\[\boxed{ \sum_k y_k\delta_{ki} = y_i }\]

따라서 첫 부분은 \(-y_i\)

Second Term — 두 번째 항은

\[S_i \sum_k y_k\]

One-Hot Probability Vector는

\[\boxed{ \sum_k y_k=1 }\]

이므로

\[\boxed{ S_i\sum_ky_k = S_i }\]

Final Logit Gradient — 따라서

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_i } = S_i-y_i }\]

Vector Form은

\[\boxed{ \nabla_{\mathbf z}\mathcal L = \mathbf S-\mathbf y }\]

Gradient의 의미 — 정답 Class \(c\)에서는

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_c } = S_c-1 <0 }\]

Gradient Descent는 Negative Gradient 방향으로 이동하므로 정답 Logit \(z_c\)를 증가시키는 방향으로 Update한다.

Incorrect Classes — 오답 Class \(j\neq c\)에서는 \(y_j=0\) 이므로

\[\boxed{ \frac{ \partial\mathcal L }{ \partial z_j } = S_j>0 }\]

Gradient Descent에서는 이 Logit들을 감소시키는 방향으로 Update한다.

Gradient Sum — Gradient Component의 합은

\[\begin{aligned} \sum_i (S_i-y_i) &= \sum_iS_i - \sum_iy_i\\ &= 1-1\\ &= \boxed{0} \end{aligned}\]

이는 Softmax의 Shift Invariance와 일관된다.

혼동하기 쉬운 부분 — Logits와 Probabilities — Logit은 Probability가 아니다. \(\boxed{ \mathbf z\in\mathbb R^K }\) 이지만 Softmax Probability는 \(\boxed{ \mathbf S \in \Delta^{K-1} }\)

혼동하기 쉬운 부분 — Softmax는 Element-wise가 아니다 — Sigmoid처럼 각 Component를 완전히 독립적으로 변환하는 함수가 아니다. 분모

\[\sum_j e^{z_j}\]

를 모든 Component가 공유한다. 따라서 하나의 Logit 변화가 모든 Softmax Probability에 영향을 준다. 이 때문에 Jacobian에 Off-Diagonal Term \(\boxed{ -S_iS_j }\) 가 존재한다.

혼동하기 쉬운 부분 — Largest Logit — 가장 큰 Logit을 가진 Class가 가장 높은 Softmax Probability를 가진다. 그러나 \(\boxed{ \max_iS_i }\) 가 반드시 1에 가깝다는 뜻은 아니다. Logit 사이의 상대적 Difference에 따라 Distribution의 Concentration이 결정된다.

혼동하기 쉬운 부분 — Shift Invariance — \(\mathbf z\) 와 \(\mathbf z+1000\mathbf1\) 은 매우 다른 숫자처럼 보이지만 Softmax Probability는 같다. 따라서 Softmax는 Common Offset을 식별하지 않는다.

혼동하기 쉬운 부분 — Stable Softmax — Maximum을 빼는 것은 Approximation이 아니다. Shift Invariance 때문에

\[\boxed{ \operatorname{Softmax}( \mathbf z ) = \operatorname{Softmax}( \mathbf z-\max(\mathbf z) ) }\]

가 수학적으로 정확히 성립한다.

혼동하기 쉬운 부분 — \(S-y\) — \(\boxed{ \nabla_zL=S-y }\) 는 Softmax 함수만의 Derivative가 아니다. 이는

\[\boxed{ \text{Softmax} + \text{Categorical Cross-Entropy} }\]

를 결합했을 때 나타나는 결과다. Softmax 자체의 Derivative는 Jacobian

\[\boxed{ \operatorname{diag}(S)-SS^T }\]

혼동하기 쉬운 부분 — Temperature — Temperature는 Probability Distribution을 바꾸지만 \(T>0\)에서는 Logit Ranking을 바꾸지 않는다. 따라서

\[\boxed{ \arg\max z_i = \arg\max S_i(z;T) }\]

다만 Sampling Probability는 크게 달라질 수 있다.

혼동하기 쉬운 부분 — Attention Softmax — Attention Weight가 합 1이라는 이유만으로 이를 모델의 최종 Next-Token Probability와 동일한 의미로 해석하면 안 된다. Attention Softmax와 Output Softmax는 같은 수학 함수를 사용하지만 서로 다른 축과 의미에 적용된다.

혼동하기 쉬운 부분 — FlashAttention — FlashAttention은 Dense Attention의 모든 Pairwise Interaction을 없애서 일반적인 Attention 계산을 선형시간으로 바꾸는 방법이 아니다. 핵심은 Tiling과 Online Softmax를 사용하여

\[\boxed{ \text{HBM traffic와 intermediate materialization을 줄이는 것} }\]

Softmax는 임의의 Real-Valued Logit Vector \(\mathbf z\in\mathbb R^K\) 를 Categorical Probability Vector로 변환한다.

\[\boxed{ S_i = \frac{ e^{z_i} }{ \sum_j e^{z_j} } }\]

모든 Output은 Positive이고

\[\boxed{ \sum_iS_i=1 }\]

을 만족한다. Softmax는 모든 Logit에 같은 Constant를 더해도 변하지 않는다.

\[\boxed{ \operatorname{Softmax} ( \mathbf z+c\mathbf1 ) = \operatorname{Softmax} ( \mathbf z ) }\]

이 Shift Invariance를 이용하면 \(C=\max_jz_j\) 를 빼서 Stable Softmax를 계산할 수 있다.

\[\boxed{ S_i = \frac{ e^{z_i-C} }{ \sum_j e^{z_j-C} } }\]

Softmax의 Jacobian은 대각·비대각 Element를 각각 계산하면

\[\boxed{ \frac{ \partial S_i }{ \partial z_j } = S_i( \delta_{ij}-S_j ) }\]

이고 Matrix Form은

\[\boxed{ J_{\mathrm{softmax}} = \operatorname{diag}(S)-SS^T }\]

Cross-Entropy

\[\mathcal L = -\sum_k y_k\log S_k\]

와 결합하면 복잡한 Jacobian 연산이 정리되어

\[\boxed{ \nabla_{\mathbf z}\mathcal L = \mathbf S-\mathbf y }\]

라는 매우 단순한 Gradient를 얻는다. 원자료의 Example에서는 \(\mathbf z = [2.0,1.0,0.1]^T\) 에서

\[\boxed{ \mathbf S \approx [0.6590,0.2424,0.0986]^T }\]

이고 Class 1이 정답이면 \(\boxed{ \mathcal L \approx 0.4170 }\) Logit Gradient는

\[\boxed{ \nabla_{\mathbf z}\mathcal L \approx [-0.3410,0.2424,0.0986]^T }\]

LLM에서는 최종 Hidden State를 Vocabulary Logit으로 Projection한다.

\[\boxed{ \mathbf z_t = W_{\mathrm{head}} \mathbf h_t }\]

Softmax를 적용하여 \(\boxed{ P_\theta( Y_t\mid Y_{<t} ) }\) 를 얻고 정답 Token의 Negative Log-Probability를 Training Loss로 사용한다.

\[\boxed{ \mathcal L_t = -\log P_\theta( y_t\mid y_{<t} ) }\]

Transformer Attention에서도 Softmax는

\[\boxed{ \operatorname{Softmax} \left( \frac{ QK^T }{ \sqrt{d_k} } \right) }\]

형태로 사용된다. 따라서 Softmax는 Transformer에서 서로 다른 두 핵심 역할을 수행한다.

\[\boxed{ \text{Attention Scores} \rightarrow \text{Attention Distribution} }\]

그리고

\[\boxed{ \text{Vocabulary Logits} \rightarrow \text{Next-Token Distribution} }\]

DL-03 전체의 핵심 흐름은

\[\boxed{ \text{Logits} \rightarrow \text{Softmax} \rightarrow \text{Categorical Probability} }\]

에서 시작하여

\[\boxed{ \text{Softmax Jacobian} \rightarrow \text{Cross-Entropy} \rightarrow \mathbf S-\mathbf y }\]

로 Backpropagation과 연결된다. LLM 관점에서는

\[\boxed{ \text{Transformer Hidden State} \rightarrow \text{Vocabulary Logits} \rightarrow \text{Softmax} \rightarrow \text{Token NLL} \rightarrow \text{Backpropagation} }\]

이라는 전체 학습 경로의 마지막 핵심 단계다.

예제·적용

Numerical Example — Setup — 원자료의 Example은 \(\boxed{ K=3 }\) 이고 Logit은

\[\boxed{ \mathbf z = \begin{bmatrix} 2.0\\ 1.0\\ 0.1 \end{bmatrix} }\]

Target은 Class 1이다.

\[\boxed{ \mathbf y = \begin{bmatrix} 1\\ 0\\ 0 \end{bmatrix} }\]

Maximum Shift — Maximum Logit은

\[\boxed{ C = \max(2.0,1.0,0.1) = 2.0 }\]

Shifted Logits — 따라서

\[\begin{aligned} \mathbf z' &= \mathbf z-C\mathbf1\\ &= \boxed{ \begin{bmatrix} 0\\ -1\\ -1.9 \end{bmatrix} } \end{aligned}\]

Exponential Terms — 각 Exponential은 \(\boxed{ e^0=1 }\) \(\boxed{ e^{-1} \approx0.3679 }\) \(\boxed{ e^{-1.9} \approx0.1496 }\)

Exponential Sum — 분모는

\[\begin{aligned} Z &= 1 + 0.3679 + 0.1496\\ &= \boxed{ 1.5175 } \end{aligned}\]

First Probability —

\[\begin{aligned} S_1 &= \frac1{1.5175}\\ &\approx \boxed{ 0.6590 } \end{aligned}\]

Second Probability —

\[\begin{aligned} S_2 &= \frac{0.3679}{1.5175}\\ &\approx \boxed{ 0.2424 } \end{aligned}\]

Third Probability —

\[\begin{aligned} S_3 &= \frac{0.1496}{1.5175}\\ &\approx \boxed{ 0.0986 } \end{aligned}\]

Probability Check —

\[0.6590 + 0.2424 + 0.0986 = \boxed{ 1.0000 }\]

따라서 정상적인 Categorical Probability Vector다.

Jacobian \(J_{11}\) —

\[\begin{aligned} J_{11} &= S_1(1-S_1)\\ &= 0.6590(1-0.6590)\\ &\approx \boxed{ 0.2247 } \end{aligned}\]

Jacobian \(J_{12}\) —

\[\begin{aligned} J_{12} &= -S_1S_2\\ &= -(0.6590)(0.2424)\\ &\approx \boxed{ -0.1597 } \end{aligned}\]

Jacobian \(J_{13}\) —

\[\begin{aligned} J_{13} &= -S_1S_3\\ &= -(0.6590)(0.0986)\\ &\approx \boxed{ -0.0650 } \end{aligned}\]

Full Jacobian — 원자료의 근사값을 사용하면

\[\boxed{ \mathbf J_{\mathrm{softmax}} \approx \begin{bmatrix} 0.2247&-0.1597&-0.0650\\ -0.1597&0.1836&-0.0239\\ -0.0650&-0.0239&0.0889 \end{bmatrix} }\]

Jacobian Row Sum Check — 첫 번째 Row를 보면 \(0.2247 - 0.1597 - 0.0650 = \boxed{0}\) 다른 Row도 반올림 오차 범위에서 0이 된다. 이는 \(\boxed{ \mathbf J\mathbf1=\mathbf0 }\) 와 일치한다.

Cross-Entropy Loss — 정답은 Class 1이므로 \(\mathcal L = -\ln S_1\) 따라서

\[\begin{aligned} \mathcal L &= -\ln(0.6590)\\ &\approx \boxed{ 0.4170 } \end{aligned}\]

Logit Gradient —

\[\nabla_{\mathbf z}\mathcal L = \mathbf S-\mathbf y\]

이므로

\[\boxed{ \nabla_{\mathbf z}\mathcal L = \begin{bmatrix} -0.3410\\ 0.2424\\ 0.0986 \end{bmatrix} }\]

Gradient Interpretation — 정답 Class의 Gradient는 \(-0.3410\) Gradient Descent에서는 \(z_1\) 이 증가하는 방향으로 Update한다. 반면 오답 Class에서는 \(0.2424, \qquad 0.0986\) 의 Positive Gradient가 발생하므로 해당 Logit은 감소하는 방향으로 Update한다.

Temperature Softmax — 원자료의 제목에는 Temperature Control이 포함되어 있지만 본문에는 별도의 수식 전개가 없다. 일반적인 Temperature Softmax는 다음과 같이 정의한다.

\[\boxed{ S_i( \mathbf z;T ) = \frac{ e^{z_i/T} }{ \sum_j e^{z_j/T} } }\]

where \(T>0\)

\(T=1\) — \(\boxed{ T=1 }\) 이면 일반 Softmax와 같다.

\[\boxed{ S_i( \mathbf z;1 ) = S_i(\mathbf z) }\]

High Temperature — \(T>1\) 이면 Logit Difference가

\[\frac{ z_i-z_j }{T}\]

로 작아진다. 따라서 Probability Distribution은 상대적으로 평평해진다. 고정된 유한 Logit에서

\[\boxed{ T\rightarrow\infty \Rightarrow S_i\rightarrow\frac1K }\]

Low Temperature — \(0<T<1\) 이면 Logit Difference가 확대된다. 따라서 Probability Mass가 큰 Logit 쪽으로 더 집중된다. 고유한 Maximum Logit이 존재하면 \(\boxed{ T\rightarrow0^+ }\) 에서 Softmax Distribution은 해당 Maximum Class에 집중한다.

Temperature는 Logit Ranking을 바꾸지 않는다 — \(T>0\)이면 \(z_i>z_j\) 일 때

\[\frac{z_i}{T} > \frac{z_j}{T}\]

따라서

\[\boxed{ \arg\max_i z_i = \arg\max_i S_i( \mathbf z;T ) }\]

Temperature는 Ranking보다 Distribution의 Concentration을 조절한다.

LLM Output Head — 원자료는 LLM의 마지막 Hidden State를

\[\boxed{ \mathbf h_t \in \mathbb R^d }\]

로 둔다. Language Modeling Head Weight를

\[\boxed{ \mathbf W_{\mathrm{head}} \in \mathbb R^{V\times d} }\]

라고 하자.

Vocabulary Logits — Bias를 생략하면

\[\boxed{ \mathbf z_t = \mathbf W_{\mathrm{head}} \mathbf h_t }\]

Shape은 \((V\times d) (d\times1) = V\times1\) 이므로

\[\boxed{ \mathbf z_t \in \mathbb R^V }\]

Next-Token Distribution — Softmax를 적용하면

\[\boxed{ P_\theta( Y_t=i \mid y_{<t} ) = \frac{ e^{z_{t,i}} }{ \sum_{j=1}^{V} e^{z_{t,j}} } }\]

즉

\[\boxed{ \mathbf h_t \rightarrow \mathbf z_t \rightarrow \operatorname{Softmax} \rightarrow P_\theta( Y_t\mid y_{<t} ) }\]

로 이어진다.

LLM Training Loss — 실제 정답 Token Index를 \(c\)라고 하면

\[\boxed{ \mathcal L_t = -\log P_\theta( Y_t=c \mid y_{<t} ) }\]

따라서 Softmax와 Cross-Entropy의 결합 Gradient가 LLM Output Head Training에도 직접 사용된다.

Vocabulary-Logit Gradient — One-Hot Target \(\mathbf y_t\) 에 대해

\[\boxed{ \nabla_{\mathbf z_t} \mathcal L_t = \mathbf p_t-\mathbf y_t }\]

Vocabulary Size가 매우 커도 Logit-Level Gradient 구조는 동일하다.

Output Head Weight Gradient —

\[\mathbf z_t = \mathbf W_{\mathrm{head}} \mathbf h_t\]

이므로 Matrix Calculus를 적용하면

\[\boxed{ \frac{ \partial\mathcal L_t }{ \partial \mathbf W_{\mathrm{head}} } = ( \mathbf p_t-\mathbf y_t ) \mathbf h_t^T }\]

Shape은

\[(V\times1)(1\times d) = \boxed{ V\times d }\]

로 \(\mathbf W_{\mathrm{head}}\)와 같다.

Hidden-State Gradient — 같은 Linear Layer에서

\[\boxed{ \frac{ \partial\mathcal L_t }{ \partial\mathbf h_t } = \mathbf W_{\mathrm{head}}^T ( \mathbf p_t-\mathbf y_t ) }\]

이 Gradient가 Transformer의 이전 Layer들로 Backpropagation된다.

Attention에서도 Softmax — Softmax는 Output Head에만 사용되지 않는다. Scaled Dot-Product Attention에서는

\[\boxed{ \mathbf A = \operatorname{Softmax} \left( \frac{ \mathbf Q\mathbf K^T }{ \sqrt{d_k} } \right) }\]

Softmax는 각 Query에 대해 Key Dimension 방향으로 Attention Probability를 정규화한다.

Attention Row — 하나의 Query \(i\)에 대한 Attention Score를 \(\mathbf a_i\) 라고 하면

\[\boxed{ \sum_j A_{ij} = 1 }\]

따라서 각 Query의 Attention Weight Row는 하나의 Categorical-like Probability Vector 형태를 가진다.

Large Attention Matrix — Sequence Length가 \(N\) 이면 Dense Attention Score Matrix는 \(\boxed{ N\times N }\) Shape이다. Naive Implementation에서 이 Intermediate Matrix 전체를 HBM에 materialize하면 큰 Memory Traffic과 Storage Cost가 발생한다.

Online Softmax — 원자료는 FlashAttention의 핵심 요소 중 하나로 Online Softmax를 소개한다. 전체 Vector를 한 번에 보관하지 않고 Block별로 처리하면서

  • Running Maximum
  • Running Normalization Sum

을 갱신한다.

Running Maximum — 이전 Block까지의 Maximum을 \(m_{\mathrm{old}}\) 현재 Block Maximum을 \(m_{\mathrm{block}}\) 이라고 하면 새로운 Maximum은

\[\boxed{ m_{\mathrm{new}} = \max( m_{\mathrm{old}}, m_{\mathrm{block}} ) }\]

왜 Running Maximum이 필요한가 — Stable Softmax에서는 \(e^{z_i-m}\) 형태가 필요하다. 새 Block에서 더 큰 Maximum이 나타나면 이전에 계산한 Exponential Sum을 새로운 Reference Maximum 기준으로 Rescale해야 한다. 이것이 Online Softmax의 핵심 아이디어다.

Running Denominator 개념 — 기존 Normalization Sum이 \(d_{\mathrm{old}}\) 이라고 하자. Reference Maximum이

\[m_{\mathrm{old}} \rightarrow m_{\mathrm{new}}\]

으로 바뀌면 이전 Contribution은

\[\boxed{ d_{\mathrm{old}} e^{ m_{\mathrm{old}} - m_{\mathrm{new}} } }\]

로 Rescale할 수 있다. 현재 Block Contribution을 더하면 새로운 Denominator를 구성할 수 있다.

Online Softmax의 의미 — 즉

\[\boxed{ \text{stable softmax} + \text{running statistics} }\]

를 사용하면 전체 Score Row를 동시에 저장하지 않고도 Softmax Normalization을 계산할 수 있다.

FlashAttention 관련 복잡도 주의 — 원자료는 FlashAttention이 Memory Bandwidth를 \(O(N^2) \rightarrow O(N)\) 로 줄인다고 표현한다. 이 문장은 그대로 전체 Attention 계산복잡도가 \(O(N^2) \rightarrow O(N)\) 이 된다는 의미로 해석하면 안 된다. Dense Attention의 기본 Pairwise Score 계산 자체는 여전히 Quadratic Structure를 가진다.

FlashAttention에서 실제 핵심 — 더 정확한 핵심은

\[\boxed{ N\times N \text{ attention matrix를 HBM에 전부 materialize하지 않는다} }\]

는 것이다. Tile 단위로 계산하고 On-Chip Memory를 활용함으로써 HBM Read/Write Traffic을 크게 줄이고 Memory Efficiency를 개선한다.

Softmax의 두 사용 위치 — Transformer에서는 Softmax가 크게 두 위치에서 등장한다.

Attention —

\[\boxed{ \operatorname{Softmax} \left( \frac{ QK^T }{ \sqrt{d_k} } \right) }\]

Output Distribution —

\[\boxed{ \operatorname{Softmax} ( W_{\mathrm{head}}h_t ) }\]

두 Softmax의 역할 차이 — Attention Softmax는

\[\boxed{ \text{which keys should this query attend to?} }\]

를 정규화한다. Output Softmax는

\[\boxed{ \text{which vocabulary token should come next?} }\]

에 대한 Probability Distribution을 만든다. 수학 함수는 동일하지만 의미가 다르다.

Softmax와 IT 시리즈 연결 — IT-02에서 Distribution의 Entropy는

\[\boxed{ H(\mathbf p) = -\sum_i p_i\log p_i }\]

였다. Softmax가 Probability \(\mathbf p\) 를 생성하므로 Softmax Output의 Entropy를 계산할 수 있다. Temperature를 변경하면 이 Distribution의 Concentration과 Entropy도 변한다.

Softmax와 ML-01 연결 — ML-01에서 LLM의 Token-Level Loss는 \(-\log P_\theta( y_t\mid y_{<t} )\) 였다. DL-03에서는 그 Probability가 실제로

\[\boxed{ P_\theta( y_t\mid y_{<t} ) = \operatorname{Softmax} ( \mathbf z_t )_{y_t} }\]

에서 나온다는 구조를 확인한다.

Softmax와 CO-07 연결 — CO-07에서 Linear Layer \(Y=XW\) 의 Backpropagation을 다뤘다. Output Head에서도

\[\mathbf z = W_{\mathrm{head}}\mathbf h\]

라는 Linear Mapping 뒤에 Softmax가 붙는다. 따라서

\[\boxed{ \text{Linear Layer} \rightarrow \text{Softmax} \rightarrow \text{Cross-Entropy} }\]

가 하나의 연속적인 계산 그래프를 구성한다.

전체 개념 연결 — Neural Network는 먼저 Logit을 만든다. \(\boxed{ \mathbf z }\) Softmax가 Probability를 만든다.

\[\boxed{ \mathbf z \rightarrow \mathbf p }\]

Cross-Entropy가 Target과 비교한다.

\[\boxed{ \mathbf p \rightarrow \mathcal L }\]

Backpropagation에서는

\[\boxed{ \nabla_{\mathbf z}\mathcal L = \mathbf p-\mathbf y }\]

를 얻는다.

LLM 전체 연결 — LLM에서는 Transformer의 Hidden State가 \(\boxed{ \mathbf h_t }\) Language Head를 통과하면

\[\boxed{ \mathbf h_t \rightarrow \mathbf z_t }\]

Softmax를 적용하면

\[\boxed{ \mathbf z_t \rightarrow P_\theta( Y_t\mid Y_{<t} ) }\]

정답 Token과 비교하면

\[\boxed{ P_\theta \rightarrow -\log P_\theta( y_t\mid y_{<t} ) }\]

따라서 전체 흐름은

\[\boxed{ \text{Hidden State} \rightarrow \text{Logits} \rightarrow \text{Softmax} \rightarrow \text{Next-Token Distribution} \rightarrow \text{NLL} }\]

Attention 전체 연결 — Self-Attention에서는 먼저 Score를 계산한다.

\[\boxed{ \frac{ QK^T }{ \sqrt{d_k} } }\]

그 뒤 Softmax를 적용한다.

\[\boxed{ A = \operatorname{Softmax} \left( \frac{ QK^T }{ \sqrt{d_k} } \right) }\]

그리고 Value를 가중합한다. \(\boxed{ AV }\) 따라서

\[\boxed{ Q,K \rightarrow \text{Attention Scores} \rightarrow \text{Softmax} \rightarrow \text{Attention Weights} \rightarrow V\text{ aggregation} }\]

정리

Softmax는 logits를 \(p_i=\exp(z_i)/\sum_j\exp(z_j)\)로 정규화해 합이 1인 클래스 확률로 바꾼다. 입력에 같은 상수를 더해도 결과는 같고, 계산 전 최댓값을 빼면 overflow 위험을 낮추며, Jacobian은 각 확률이 모든 logit에 의존하는 구조를 보여준다.
