PS-12 — Maximum Likelihood Estimation (MLE) & MAP

Maximum Likelihood Estimation과 MAP 추정의 목적함수, 유도와 차이를 정리한다.

확률·통계 · PS-12업데이트 2026.09.18
  • #Maximum Likelihood Estimation
  • #MAP
  • #Prior
  • #Posterior

개념

Point Estimation관측 데이터셋을 \(\mathcal D = \{\mathbf x_1,\mathbf x_2,\dots,\mathbf x_N\}\) 이라고 하자.

이 데이터가 어떤 확률모델 \(P(\mathbf x\mid\mathbf{\theta})\) 에서 생성되었다고 가정한다.

여기서 \(\mathbf{\theta}\) 는 아직 알 수 없는 모델의 Parameter Vector다.

Point Estimation의 목표는 관측된 데이터를 사용하여 \(\mathbf{\theta}\)의 값을 하나의 추정치로 결정하는 것이다.

\[\boxed{ \mathcal D \rightarrow \hat{\mathbf{\theta}} }\]

Parameter EstimationParameter Space를 \(\Theta\) 라고 하자.

실제 Parameter는 \(\mathbf{\theta}\in\Theta\)이다.

관측 데이터를 이용하여 계산되는 Estimator를 \(\hat{\mathbf{\theta}}\) 라고 한다.

Point Estimation은 전체 Parameter Distribution을 출력하는 것이 아니라 하나의 대표값을 출력한다 (\(\hat{\mathbf{\theta}} \in \Theta\)).

Maximum Likelihood EstimationMLE는 관측 데이터를 가장 높은 Likelihood로 설명하는 Parameter를 선택한다.

Likelihood는 PS-11에서 \(L(\mathbf{\theta}) = P(\mathcal D\mid\mathbf{\theta})\) 로 정의했다.

따라서 MLE는 다음과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}\in\Theta} P(\mathcal D\mid\mathbf{\theta}) }\]

Frequentist Interpretation of MLEMLE의 관점에서는 Parameter \(\mathbf{\theta}\) 를 확률변수가 아니라 알 수 없는 고정된 값으로 본다.

즉 다음과 같다.

\[\boxed{ \mathbf{\theta} = \text{Fixed but unknown parameter} }\]

데이터가 주어지면 그 데이터를 가장 잘 설명하는 Parameter를 찾는다.

MLE 자체에는 Parameter에 대한 Prior Distribution이 들어가지 않는다.

표기·차원

Notation

핵심 연산

i.i.d. Likelihood데이터가 i.i.d.라고 가정하면 다음과 같다.

\[P(\mathcal D\mid\mathbf{\theta}) = \prod_{i=1}^{N} P(\mathbf x_i\mid\mathbf{\theta})\]

따라서 다음과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}} \prod_{i=1}^{N} P(\mathbf x_i\mid\mathbf{\theta}) }\]

Log-Likelihood Form of MLELogarithm은 단조 증가 함수이므로 Likelihood의 Maximizer를 바꾸지 않는다.

따라서 다음과 같다.

\[\hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}} \log P(\mathcal D\mid\mathbf{\theta})\]

i.i.d. 가정을 사용하면 다음과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}} \sum_{i=1}^{N} \log P(\mathbf x_i\mid\mathbf{\theta}) }\]

MLE와 NLLPS-11에서 Negative Log-Likelihood를 \(\mathcal L_{\mathrm{NLL}}(\mathbf{\theta}) = - \sum_{i=1}^{N} \log P(\mathbf x_i\mid\mathbf{\theta})\) 로 정의했다.

따라서 Log-Likelihood Maximization은 NLL Minimization과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\min_{\mathbf{\theta}} \mathcal L_{\mathrm{NLL}}(\mathbf{\theta}) }\]

MLE에서 NLL로의 유도먼저:

\[P(\mathcal D\mid\mathbf{\theta}) = \prod_{i=1}^{N} P(\mathbf x_i\mid\mathbf{\theta})\]

Log를 적용하면 다음과 같다.

\[\log P(\mathcal D\mid\mathbf{\theta}) = \sum_{i=1}^{N} \log P(\mathbf x_i\mid\mathbf{\theta})\]

따라서 다음과 같다.

\[\hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}} \sum_{i=1}^{N} \log P(\mathbf x_i\mid\mathbf{\theta})\]

Maximization에서 Minimization으로목적함수에 음수를 붙이면 다음과 같다.

\[\arg\max f(\theta) = \arg\min[-f(\theta)]\]

따라서 다음과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\min_{\mathbf{\theta}} \left[ - \sum_{i=1}^{N} \log P(\mathbf x_i\mid\mathbf{\theta}) \right] }\]

즉 다음과 같다.

\[\boxed{ \text{MLE} \iff \text{NLL Minimization} }\]

Maximum A PosterioriMAP는 데이터가 주어졌을 때 Parameter의 Posterior Probability를 최대화한다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\max_{\mathbf{\theta}} P(\mathbf{\theta}\mid\mathcal D) }\]

MLE와 달리 MAP에서는 Parameter에 대한 Prior가 존재한다 (\(P(\mathbf{\theta})\)).

Bayesian Interpretation of MAPMAP 관점에서는 Parameter 자체를 Random Variable로 취급한다.

관측 이전에는 Prior Distribution \(P(\mathbf{\theta})\) 가 있다.

데이터 \(\mathcal D\) 를 관측하면 Bayes' Theorem을 사용하여 Posterior \(P(\mathbf{\theta}\mid\mathcal D)\) 로 업데이트한다 (\(P(\mathbf{\theta}) \xrightarrow{\mathcal D} P(\mathbf{\theta}\mid\mathcal D)\)).

MAP는 이 Posterior의 Mode를 선택한다.

Bayes' Theorem for ParametersBayes' Theorem에 의해:

\[\boxed{ P(\mathbf{\theta}\mid\mathcal D) = \frac{ P(\mathcal D\mid\mathbf{\theta}) P(\mathbf{\theta}) }{ P(\mathcal D) } }\]

각 항은 다음과 같다.

  • \(P(\mathbf{\theta})\): Prior
  • \(P(\mathcal D\mid\mathbf{\theta})\): Likelihood
  • \(P(\mathcal D)\): Evidence
  • \(P(\mathbf{\theta}\mid\mathcal D)\): Posterior

MAP에서 Evidence 제거MAP는 \(\arg\max_{\mathbf{\theta}} P(\mathbf{\theta}\mid\mathcal D)\) 를 구한다.

Bayes' Theorem을 대입하면 다음과 같다.

\[\arg\max_{\mathbf{\theta}} \frac{ P(\mathcal D\mid\mathbf{\theta}) P(\mathbf{\theta}) }{ P(\mathcal D) }\]

Evidence \(P(\mathcal D)\) 는 \(\mathbf{\theta}\)에 대한 함수가 아니다.

따라서 Argmax에서 제거할 수 있다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\max_{\mathbf{\theta}} P(\mathcal D\mid\mathbf{\theta}) P(\mathbf{\theta}) }\]

Log-MAP ObjectiveLogarithm을 적용하면 다음과 같다.

\[\hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\max_{\mathbf{\theta}} \log \left[ P(\mathcal D\mid\mathbf{\theta}) P(\mathbf{\theta}) \right]\]

Log Product Rule에 의해:

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\max_{\mathbf{\theta}} \left[ \log P(\mathcal D\mid\mathbf{\theta}) + \log P(\mathbf{\theta}) \right] }\]

MAP Minimization Objective음수를 붙이면 다음과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\min_{\mathbf{\theta}} \left[ -\log P(\mathcal D\mid\mathbf{\theta}) - \log P(\mathbf{\theta}) \right] }\]

i.i.d. Dataset에서는 다음과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\min_{\mathbf{\theta}} \left[ - \sum_{i=1}^{N} \log P(\mathbf x_i\mid\mathbf{\theta}) - \log P(\mathbf{\theta}) \right] }\]

MAP = NLL + Prior PenaltyPS-11의 NLL을 사용하면 다음과 같다.

\[-\log P(\mathcal D\mid\mathbf{\theta}) = \mathcal L_{\mathrm{NLL}}\]

따라서 MAP Objective는 \(\mathcal L_{\mathrm{MAP}} = \mathcal L_{\mathrm{NLL}} - \log P(\mathbf{\theta})\) 형태다.

즉 MAP = Data Fit + Prior Penalty 로 해석할 수 있다.

MLE와 MAP 비교

Uniform Prior와 MLEPrior가 Parameter Space에서 상수라고 가정하자.

\[P(\mathbf{\theta})=C\]

그러면 \(\log P(\mathbf{\theta}) = \log C\) 는 Parameter에 무관한 상수다.

따라서 MAP Objective에서 제거할 수 있다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \hat{\mathbf{\theta}}_{\mathrm{MLE}} }\]

즉 적절한 Uniform Prior에서는 MAP가 MLE로 환원된다.

Gaussian PriorParameter에 Zero-Mean Isotropic Gaussian Prior를 둔다 (\(\mathbf{\theta} \sim \mathcal N( \mathbf0, \sigma_0^2\mathbf I )\)).

\(d\)차원에서 Density는 다음과 같다.

\[\boxed{ P(\mathbf{\theta}) = \left( \frac1{\sqrt{2\pi\sigma_0^2}} \right)^d \exp \left[ - \frac{ \|\mathbf{\theta}\|_2^2 }{ 2\sigma_0^2 } \right] }\]

Gaussian Prior의 LogLogarithm을 취하면 다음과 같다.

\[\begin{aligned} \log P(\mathbf{\theta}) &= -\frac d2 \log( 2\pi\sigma_0^2 ) - \frac{ \|\mathbf{\theta}\|_2^2 }{ 2\sigma_0^2 } \end{aligned}\]

따라서 다음과 같다.

\[\boxed{ -\log P(\mathbf{\theta}) = \frac{ \|\mathbf{\theta}\|_2^2 }{ 2\sigma_0^2 } + \text{constant} }\]

Gaussian Prior와 L2 PenaltyMAP Objective는 다음과 같다.

\[\mathcal L_{\mathrm{MAP}} = \mathcal L_{\mathrm{NLL}} - \log P(\mathbf{\theta})\]

Gaussian Prior를 대입하고 \(\mathbf{\theta}\)에 무관한 상수를 제거하면 다음과 같다.

\[\boxed{ \mathcal L_{\mathrm{MAP}} = \mathcal L_{\mathrm{NLL}} + \frac1{2\sigma_0^2} \|\mathbf{\theta}\|_2^2 }\]

즉 Zero-Mean Gaussian Prior는 L2-type Penalty와 연결된다.

성질·유도

Gaussian Observation NoiseRegression에서 Target을 \(y_i\) 모델 Prediction을 \(f_{\mathbf{\theta}}(\mathbf x_i)\) 라고 하자.

Gaussian Noise를 가정하면 다음과 같다.

\[\boxed{ P( y_i \mid \mathbf x_i,\mathbf{\theta} ) = \frac1{\sqrt{2\pi\sigma^2}} \exp \left[ - \frac{ ( y_i-f_{\mathbf{\theta}}(\mathbf x_i) )^2 }{ 2\sigma^2 } \right] }\]

Gaussian NLL전체 Dataset의 NLL은 다음과 같다.

\[\begin{aligned} \mathcal L_{\mathrm{NLL}} &= \frac N2 \log( 2\pi\sigma^2 )\\ &\quad+ \frac1{2\sigma^2} \sum_{i=1}^{N} \left( y_i - f_{\mathbf{\theta}}(\mathbf x_i) \right)^2 \end{aligned}\]

Parameter Optimization에서 상수를 제거하면 다음과 같다.

\[\boxed{ \mathcal L_{\mathrm{NLL}} \propto \sum_{i=1}^{N} \left( y_i - f_{\mathbf{\theta}}(\mathbf x_i) \right)^2 }\]

즉 Gaussian Likelihood의 MLE는 Squared Error Minimization과 연결된다.

Gaussian Likelihood + Gaussian PriorLikelihood NLL과 Prior Penalty를 결합하면 다음과 같다.

\[\mathcal L_{\mathrm{MAP}} = \frac1{2\sigma^2} \sum_i ( y_i-f_{\mathbf{\theta}}(\mathbf x_i) )^2 + \frac1{2\sigma_0^2} \|\mathbf{\theta}\|_2^2\]

전체에 \(2\sigma^2\)를 곱하면 최적점은 변하지 않는다.

\[\boxed{ \mathcal L_{\mathrm{MAP}} \propto \sum_i ( y_i-f_{\mathbf{\theta}}(\mathbf x_i) )^2 + \frac{\sigma^2}{\sigma_0^2} \|\mathbf{\theta}\|_2^2 }\]

Regularization Coefficient다음을 정의하자.

\[\boxed{ \lambda = \frac{\sigma^2}{\sigma_0^2} }\]

그러면 \(\mathcal L_{\mathrm{MAP}} = \mathcal L_{\mathrm{MSE}} + \lambda \|\mathbf{\theta}\|_2^2\) 형태로 표현할 수 있다.

Normalization Convention에 따라 \(\lambda\) 앞의 상수는 달라질 수 있지만 핵심 구조는 동일하다.

Prior Variance와 Regularization StrengthGaussian Prior의 분산 \(\sigma_0^2\) 가 작아지면 Prior는 Parameter를 원점 근처에 강하게 집중시킨다.

\(\sigma_0^2\downarrow\) 이면 다음과 같다.

\[\frac1{\sigma_0^2}\uparrow\]

따라서 L2 Penalty가 강해진다.

반대로 \(\sigma_0^2\uparrow\) 이면 Prior가 넓어지고 Regularization은 약해진다.

Geometric InterpretationMLE Loss Landscape가 \(\mathcal L_{\mathrm{NLL}}(\mathbf{\theta})\) 라고 하자.

Gaussian Prior는 여기에 \(\lambda \|\mathbf{\theta}\|_2^2\) 라는 원점을 중심으로 한 Quadratic Bowl을 더한다.

따라서 다음과 같다.

\[\boxed{ \mathcal L_{\mathrm{MAP}} = \mathcal L_{\mathrm{NLL}} + \lambda \|\mathbf{\theta}\|_2^2 }\]

이 추가항은 큰 Parameter Norm에 더 큰 비용을 부여한다.

MAP Shrinkage InterpretationGaussian Prior는 Parameter가 원점 근처에 존재할 가능성을 높게 설정한다.

따라서 MAP Estimate는 Likelihood만 사용하는 MLE보다 Parameter를 원점 방향으로 Shrink할 수 있다.

MLE Solution → MAP Shrinkage toward Prior

이는 Bias를 추가하는 대신 Variance나 Overfitting을 줄이는 Regularization 관점과 연결할 수 있다.

Pre-training as MLEAutoregressive LLM에서 Sequence Probability는 다음과 같다.

\[P_{\mathbf{\theta}} (y_{1:T}) = \prod_{t=1}^{T} P_{\mathbf{\theta}} ( y_t\mid y_{<t} )\]

따라서 Log-Likelihood는 다음과 같다.

\[\boxed{ \sum_{t=1}^{T} \log P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

Pre-training은 이 값이 커지도록 Parameter를 최적화하는 것으로 해석할 수 있다.

LLM NLL ObjectiveMLE를 Minimization Form으로 쓰면:

\[\boxed{ \mathcal L_{\mathrm{LM}} = - \sum_{t=1}^{T} \log P_{\mathbf{\theta}} ( y_t\mid y_{<t} ) }\]

즉 Next-Token Cross-Entropy Training은 Categorical Likelihood에 대한 MLE와 연결된다.

Supervised Fine-TuningSFT에서도 주어진 Input–Target Sequence에 대해 정답 Token의 Conditional Probability를 높이는 형태의 Cross-Entropy가 일반적으로 사용된다.

\[\boxed{ \max_{\mathbf{\theta}} \sum_t \log P_{\mathbf{\theta}} ( y_t \mid x,y_{<t} ) }\]

따라서 Standard Next-Token SFT 역시 Conditional Likelihood Maximization의 형태로 해석할 수 있다.

Weight Regularization의 MAP 관점Gaussian Prior를 Parameter에 부여하면 MAP Objective에 \(\lambda \|\mathbf{\theta}\|_2^2\) 형태의 Penalty가 나타난다.

따라서 L2 Regularization은 Gaussian Prior MAP의 확률적 해석을 가진다.

다만 실제 Optimizer에서 사용하는 Weight Decay의 구현은 Optimizer 종류에 따라 L2 Penalty와 정확히 동일하지 않을 수 있다.

특히 AdamW는 Gradient Loss에 L2 Term을 단순 추가하는 방식과 Weight Decay를 분리한다.

따라서 Gaussian Prior MAP ↔ L2-type regularization interpretation 으로 이해하는 것이 안전하다.

MLE와 MAP의 Fundamental DifferenceMLE는 \(P(\mathcal D\mid\mathbf{\theta})\) 만 사용한다.

MAP는 \(P(\mathcal D\mid\mathbf{\theta}) P(\mathbf{\theta})\) 를 사용한다.

즉 MLE = Data only

MAP = Data + Prior

MAP도 Point EstimateMAP는 Bayesian Framework를 사용하지만 Posterior Distribution 전체를 유지하는 방법은 아니다.

MAP는 Posterior \(P(\mathbf{\theta}\mid\mathcal D)\) 의 가장 높은 지점 하나만 선택한다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \operatorname{mode} P(\mathbf{\theta}\mid\mathcal D) }\]

따라서 MAP 역시 Point Estimation이다.

Full Bayesian Inference와 MAPFull Bayesian Inference에서는 Posterior 전체를 사용한다 (\(P(\mathbf{\theta}\mid\mathcal D)\)).

Prediction에서도 Parameter를 하나로 고정하지 않고 Posterior에 대해 Marginalization할 수 있다.

예를 들어 다음과 같다.

\[\boxed{ P(y\mid x,\mathcal D) = \int P(y\mid x,\mathbf{\theta}) P(\mathbf{\theta}\mid\mathcal D) \,d\mathbf{\theta} }\]

MAP는 이러한 Posterior 전체 대신 하나의 Mode만 사용한다.

주요 식 정리

MLE

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}} P(\mathcal D\mid\mathbf{\theta}) }\]

MLE Log Form

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}} \sum_i \log P( \mathbf x_i \mid \mathbf{\theta} ) }\]

MLE NLL Form

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\min_{\mathbf{\theta}} \mathcal L_{\mathrm{NLL}} }\]

MAP

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\max_{\mathbf{\theta}} P( \mathbf{\theta} \mid \mathcal D ) }\]

MAP with Bayes

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\max_{\mathbf{\theta}} P( \mathcal D \mid \mathbf{\theta} ) P( \mathbf{\theta} ) }\]

MAP Loss Form

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\min_{\mathbf{\theta}} \left[ \mathcal L_{\mathrm{NLL}} - \log P(\mathbf{\theta}) \right] }\]

혼동하기 쉬운 부분 — MLE와 MAPMLE는 Prior가 없는 Estimation이다.

MAP는 Prior를 사용한다.

하지만 MAP 역시 Posterior 전체를 반환하지 않는다.

따라서 MAP ≠ Full Bayesian Inference

혼동하기 쉬운 부분 — Uniform PriorMLE를 항상 "Uniform Prior를 사용한 MAP"이라고 표현하려면 Parameter Space와 Prior의 Properness 등에 주의해야 한다.

직관적으로는 \(\theta\)에 대한 Prior가 Optimization 영역에서 상수라면 MAP Objective → MLE Objective

핵심은 Prior Term이 Parameter Optimization에 영향을 주지 않는다는 것이다.

혼동하기 쉬운 부분 — L2와 Weight DecayGaussian Prior를 사용한 MAP는 L2 Penalty를 자연스럽게 만든다 (\(\lambda \|\mathbf{\theta}\|_2^2\)).

그러나 Optimizer 구현에서 weight_decay라는 이름으로 수행되는 연산이 모든 경우 L2 Penalty Gradient와 정확히 동일한 것은 아니다.

특히 AdamW는 Weight Decay를 Gradient Update와 Decoupled하게 적용한다.

따라서 Gaussian MAP ↔ L2 Regularization 은 확률적 해석으로 사용하고 Optimizer 구현과는 구분한다.

Parameter Estimation의 목표는 Dataset으로부터 미지의 Parameter를 추정하는 것이다.

\[\boxed{ \mathcal D \rightarrow \hat{\mathbf{\theta}} }\]

MLE는 Dataset Likelihood를 최대화한다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}} P( \mathcal D \mid \mathbf{\theta} ) }\]

i.i.d. Dataset에서는 다음과 같다.

\[\boxed{ P( \mathcal D \mid \mathbf{\theta} ) = \prod_i P( \mathbf x_i \mid \mathbf{\theta} ) }\]

Logarithm을 적용하면 \(\log P( \mathcal D \mid \mathbf{\theta} ) = \sum_i \log P( \mathbf x_i \mid \mathbf{\theta} )\) 이고 MLE는 NLL Minimization과 같다.

\[\boxed{ \text{MLE} \iff \text{Minimum NLL} }\]

MAP는 Posterior를 최대화한다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\max_{\mathbf{\theta}} P( \mathbf{\theta} \mid \mathcal D ) }\]

Bayes' Theorem을 적용하면 다음과 같다.

\[\boxed{ P( \mathbf{\theta} \mid \mathcal D ) \propto P( \mathcal D \mid \mathbf{\theta} ) P( \mathbf{\theta} ) }\]

따라서 MAP Objective는 다음과 같다.

\[\boxed{ \mathcal L_{\mathrm{MAP}} = \mathcal L_{\mathrm{NLL}} - \log P( \mathbf{\theta} ) }\]

Gaussian Prior를 사용하면 \(-\log P( \mathbf{\theta} ) \propto \|\mathbf{\theta}\|_2^2\) 가 되어 L2-type Regularization과 연결된다.

Bernoulli Distribution의 MLE는 다음과 같다.

\[\boxed{ \hat p_{\mathrm{MLE}} = \frac{k}{N} }\]

Beta Prior를 사용하면 적절한 내부 Mode 조건 아래:

\[\boxed{ \hat p_{\mathrm{MAP}} = \frac{ k+\alpha-1 }{ N+\alpha+\beta-2 } }\]

LLM Pre-training과 표준적인 Next-Token SFT에서는 \(\max_{\mathbf{\theta}} \sum_t \log P_{\mathbf{\theta}} ( y_t \mid y_{<t} )\) 형태의 Conditional MLE를 사용한다.

따라서 전체 연결은 다음과 같다.

Probability Model → Likelihood → MLE → NLL Minimization

Bayesian 관점에서는 Likelihood + Prior → Posterior → MAP

Deep Learning에서는 MLE → Cross-Entropy / NLL Training 그리고 Gaussian Prior 해석에서는 MAP → L2-type Regularization 으로 연결된다.

예제·적용

Bernoulli MLE SetupBernoulli Dataset을 생각한다.

\[\mathcal D = \{x_1,\dots,x_N\}\]

각 Sample은 \(x_i\in\{0,1\}\)이다.

Success가 총 \(k\) 번 발생했다고 하자.

즉 다음과 같다.

\[\boxed{ \sum_{i=1}^{N}x_i=k }\]

Bernoulli PMF단일 Sample의 PMF는 다음과 같다.

\[\boxed{ P(x_i\mid p) = p^{x_i} (1-p)^{1-x_i} }\]

Likelihood는 다음과 같다.

\[L(p) = \prod_{i=1}^{N} p^{x_i} (1-p)^{1-x_i}\]

Bernoulli Log-LikelihoodLog를 취하면 다음과 같다.

\[\ell(p) = \sum_{i=1}^{N} \left[ x_i\log p + (1-x_i)\log(1-p) \right]\]

\(\sum x_i=k\)를 사용하면 다음과 같다.

\[\boxed{ \ell(p) = k\log p + (N-k)\log(1-p) }\]

Bernoulli MLE Derivative\(p\)에 대해 미분한다.

\[\boxed{ \frac{d\ell(p)}{dp} = \frac{k}{p} - \frac{N-k}{1-p} }\]

MLE에서는 이를 0으로 둔다.

\[\frac{k}{p} - \frac{N-k}{1-p} = 0\]

Bernoulli MLE Solution식을 정리하면 다음과 같다.

\[\frac{k}{p} = \frac{N-k}{1-p}\]

교차 곱하면 다음과 같다.

\[k(1-p) = p(N-k)\]

전개하면 다음과 같다.

\[k-kp = Np-kp\]

따라서 \(Np=k\) 이고:

\[\boxed{ \hat p_{\mathrm{MLE}} = \frac{k}{N} }\]

즉 Bernoulli MLE는 관측된 Success Frequency다.

Beta PriorBernoulli Parameter \(p\)에 Beta Prior를 둔다 (\(p \sim \operatorname{Beta}(\alpha,\beta)\)).

Density는 다음과 같다.

\[\boxed{ P(p) = \frac1{B(\alpha,\beta)} p^{\alpha-1} (1-p)^{\beta-1} }\]

Bernoulli Likelihood + Beta PriorPosterior는 다음과 같다.

\[P(p\mid\mathcal D) \propto P(\mathcal D\mid p)P(p)\]

Bernoulli Likelihood는 다음과 같다.

\[P(\mathcal D\mid p) \propto p^k (1-p)^{N-k}\]

Beta Prior와 곱하면 다음과 같다.

\[P(p\mid\mathcal D) \propto p^{k+\alpha-1} (1-p)^{N-k+\beta-1}\]

즉 Posterior도 Beta Distribution이다.

Beta Posterior따라서 \(p\mid\mathcal D \sim \operatorname{Beta} ( \alpha+k, \beta+N-k )\) 이는 Beta–Bernoulli Conjugacy다.

MAP는 이 Posterior의 Mode를 선택한다.

Beta-Bernoulli MAP ObjectiveLog Posterior에서 \(\mathbf{\theta}\)와 무관한 상수를 제거하면 다음과 같다.

\[\boxed{ \log P(p\mid\mathcal D) = (k+\alpha-1)\log p + (N-k+\beta-1) \log(1-p) + C }\]

Beta-Bernoulli MAP Derivative\(p\)에 대해 미분하면 다음과 같다.

\[\boxed{ \frac{d}{dp} \log P(p\mid\mathcal D) = \frac{k+\alpha-1}{p} - \frac{N-k+\beta-1}{1-p} }\]

Interior Mode를 구하기 위해 이를 0으로 둔다.

Beta-Bernoulli MAP Solution

\[\frac{k+\alpha-1}{p} = \frac{N-k+\beta-1}{1-p}\]

교차 곱하면 다음과 같다.

\[(k+\alpha-1)(1-p) = (N-k+\beta-1)p\]

정리하면 다음과 같다.

\[k+\alpha-1 = p( N+\alpha+\beta-2 )\]

따라서 적절한 \(\alpha,\beta\)에서 Interior Mode는 다음과 같다.

\[\boxed{ \hat p_{\mathrm{MAP}} = \frac{ k+\alpha-1 }{ N+\alpha+\beta-2 } }\]

Uniform Beta Prior만약:

\[\alpha=1, \qquad \beta=1\]

이라면 Beta Prior는 \([0,1]\)에서 Uniform하다.

MAP 식에 대입하면 다음과 같다.

\[\hat p_{\mathrm{MAP}} = \frac{k}{N}\]

따라서 다음과 같다.

\[\boxed{ \hat p_{\mathrm{MAP}} = \hat p_{\mathrm{MLE}} }\]

Prior가 MAP에 주는 영향MAP Estimate는 다음과 같다.

\[\frac{ k+\alpha-1 }{ N+\alpha+\beta-2 }\]

Likelihood의 실제 Count인 \(k\)와 \(N-k\)에 Prior Parameter \(\alpha-1\), \(\beta-1\)가 추가된 형태로 볼 수 있다.

따라서 작은 Dataset에서는 Prior의 영향이 상대적으로 크다.

Large-Sample InterpretationData Size \(N\)이 증가하면 Log-Likelihood Sum은 일반적으로 \(N\)에 비례하여 증가한다.

\[\sum_{i=1}^{N} \log P(x_i\mid\theta)\]

반면 고정된 Prior의 Log Probability는 하나의 항이다.

따라서 적절한 조건에서 Dataset이 매우 커지면 Likelihood가 Posterior Mode를 지배하여 MAP와 MLE가 가까워질 수 있다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} \approx \hat{\mathbf{\theta}}_{\mathrm{MLE}} \qquad (N\text{ large}) }\]

Example 3 — MLE Objective2차원 Weight Vector를 다음과 같이 쓴다.

\[\mathbf w = \begin{bmatrix} w_1\\ w_2 \end{bmatrix}\]

\(\mathbf w\)라고 하자.

NLL이 다음처럼 주어졌다.

\[\boxed{ \mathcal L_{\mathrm{NLL}}(\mathbf w) = (w_1-3)^2 + (w_2-4)^2 }\]

MLE는 이 Loss를 최소화한다.

Example 3 — MLE Solution두 Squared Term이 동시에 0이 되는 지점은 다음과 같다.

\[w_1=3\]
\[w_2=4\]

따라서 다음과 같다.

\[\boxed{ \hat{\mathbf w}_{\mathrm{MLE}} = \begin{bmatrix} 3\\ 4 \end{bmatrix} }\]

Norm은 다음과 같다.

\[\|\hat{\mathbf w}_{\mathrm{MLE}}\|_2 = \sqrt{3^2+4^2} = \boxed{5}\]

Example 3 — Gaussian PriorData Variance를 다음과 같이 쓴다.

\[\sigma^2=1\]

Prior Variance를 \(\sigma_0^2=0.5\) 라고 하자.

원 자료의 Scaling Convention에서는 다음과 같다.

\[\boxed{ \lambda = \frac{\sigma^2}{\sigma_0^2} = 2 }\]

따라서 MAP Objective는 다음과 같다.

\[\boxed{ \mathcal L_{\mathrm{MAP}} = (w_1-3)^2 + (w_2-4)^2 + 2(w_1^2+w_2^2) }\]

Example 3 — \(w_1\) Optimization\(w_1\)에 대해 미분한다.

\[\frac{\partial\mathcal L_{\mathrm{MAP}}} {\partial w_1} = 2(w_1-3)+4w_1\]

따라서 \(6w_1-6=0\) 이고:

\[\boxed{ w_1=1 }\]

Example 3 — \(w_2\) Optimization\(w_2\)에 대해 미분한다.

\[\frac{\partial\mathcal L_{\mathrm{MAP}}} {\partial w_2} = 2(w_2-4)+4w_2\]

따라서 \(6w_2-8=0\) 이고:

\[\boxed{ w_2 = \frac43 \approx1.333 }\]

Example 3 — MAP Solution따라서 다음과 같다.

\[\boxed{ \hat{\mathbf w}_{\mathrm{MAP}} = \begin{bmatrix} 1\\ 1.333 \end{bmatrix} }\]

Norm은 다음과 같다.

\[\begin{aligned} \|\hat{\mathbf w}_{\mathrm{MAP}}\|_2 &\approx \sqrt{ 1^2+(1.333)^2 }\\ &\approx \boxed{1.667} \end{aligned}\]

MLE의 Norm \(5\)보다 크게 작아졌다.

Prior의 영향과 Bias강한 Prior를 사용하면 MAP Estimate가 Prior가 선호하는 영역으로 강하게 이동한다.

이는 작은 Dataset에서는 Overfitting을 완화할 수 있지만 Prior가 잘못 설정되면 Bias를 만들 수 있다.

따라서 Strong Prior → Stronger Prior Bias 라는 Trade-off가 존재한다.

MLE Consistency원 자료에서는 MLE의 대표적인 점근적 성질로 Consistency를 제시한다.

적절한 Identifiability와 Regularity Conditions 아래에서 Sample Size가 증가하면 \(\hat{\mathbf{\theta}}_{\mathrm{MLE}}\) 가 실제 Parameter \(\mathbf{\theta}^\ast\) 로 Probability Convergence한다.

\[\boxed{ \lim_{N\rightarrow\infty} P \left( \| \hat{\mathbf{\theta}}_{\mathrm{MLE}} - \mathbf{\theta}^\ast \| > \epsilon \right) = 0 }\]

Asymptotic Efficiency원 자료에서는 충분한 Regularity Conditions 아래에서 MLE가 Large-Sample Limit에서 Cramér–Rao Lower Bound와 연결되는 점근적 효율성을 제시한다.

즉 큰 Sample에서 MLE의 분산이 가능한 최소 분산 한계에 접근하는 성질이다.

\[\boxed{ \text{MLE} \xrightarrow[N\to\infty]{} \text{Asymptotically efficient} }\]

이 성질은 모든 상황에서 자동으로 성립하는 것이 아니라 필요한 정규성 조건이 존재한다.

MLE InvarianceMLE는 Parameter Transformation에 대한 Invariance 성질을 가진다.

\(\hat{\mathbf{\theta}}_{\mathrm{MLE}}\)가 \(\mathbf{\theta}\)의 MLE라면 적절한 함수 \(g\)에 대해 \(g(\mathbf{\theta})\)의 MLE는 \(g( \hat{\mathbf{\theta}}_{\mathrm{MLE}} )\) 로 얻을 수 있다.

원 자료에서는 특히 One-to-One Transformation을 중심으로 이 성질을 설명한다.

MLE와 MAP의 데이터 크기MAP의 Log Objective는 다음과 같다.

\[\sum_{i=1}^{N} \log P( \mathbf x_i\mid\mathbf{\theta} ) + \log P(\mathbf{\theta})\]

첫 항은 Sample Size \(N\)에 따라 누적된다.

Prior Term은 Dataset Size 증가에 따라 같은 방식으로 반복 합산되지 않는다.

따라서 큰 Dataset에서는 적절한 조건에서 Likelihood가 상대적으로 더 큰 영향을 가질 수 있다.

MLE와 OverfittingMLE 자체가 반드시 Overfitting을 일으킨다는 뜻은 아니다.

하지만 Parameter가 매우 많고 Data가 제한적인 Model에서는 Training Likelihood를 지나치게 높이면서 Generalization이 악화될 수 있다.

MAP에서는 Prior를 추가하여 Parameter Space의 특정 영역을 선호하도록 제한할 수 있다.

Likelihood Fit + Prior Constraint

MLE와 NLL의 핵심 연결MLE는 다음과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MLE}} = \arg\max_{\mathbf{\theta}} P(\mathcal D\mid\mathbf{\theta}) }\]

Log를 적용하면 다음과 같다.

\[\boxed{ = \arg\max_{\mathbf{\theta}} \log P(\mathcal D\mid\mathbf{\theta}) }\]

Negative Log를 적용하면 다음과 같다.

\[\boxed{ = \arg\min_{\mathbf{\theta}} \mathcal L_{\mathrm{NLL}} }\]

이것이 Statistical Estimation과 Deep Learning Loss를 연결하는 핵심이다.

MAP의 핵심 연결MAP는 다음과 같다.

\[\boxed{ \hat{\mathbf{\theta}}_{\mathrm{MAP}} = \arg\max_{\mathbf{\theta}} P(\mathbf{\theta}\mid\mathcal D) }\]

Bayes' Theorem으로 다음과 같이 쓴다.

\[\boxed{ = \arg\max_{\mathbf{\theta}} P(\mathcal D\mid\mathbf{\theta}) P(\mathbf{\theta}) }\]

Negative Log Form에서는 다음과 같다.

\[\boxed{ = \arg\min_{\mathbf{\theta}} \left[ \mathcal L_{\mathrm{NLL}} - \log P(\mathbf{\theta}) \right] }\]

Gaussian Prior의 핵심 연결Gaussian Prior \(\mathbf{\theta} \sim \mathcal N( 0,\sigma_0^2I )\) 에서는 다음과 같다.

\[-\log P(\mathbf{\theta}) = \frac1{2\sigma_0^2} \|\mathbf{\theta}\|_2^2 + C\]

따라서 Gaussian Prior → L2-type Regularization 으로 연결된다.

정리

MLE는 관측 data의 likelihood를 최대화하고 MAP는 prior를 곱한 posterior를 최대화한다. Log 공간에서는 \(\log p(\theta\mid D)=\log p(D\mid\theta)+\log p(\theta)+\text{constant}\)이므로 MAP의 prior 항이 regularization처럼 작동하지만, prior와 likelihood 가정에 따라 해가 달라진다.
