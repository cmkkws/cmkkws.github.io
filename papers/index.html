TRANSFORMER

Attention Is All You Need

순환 연산 대신 Attention으로 토큰 사이의 관계를 연결한다. 학습 시 시퀀스의 위치를 병렬로 처리할 수 있게 됐지만, 자기회귀 생성은 여전히 한 토큰씩 진행된다.

Scaled dot-product attention
  • Token → Q / K / V
  • Similarity → Softmax → Weighted aggregation
Transformer 리뷰 원문 (새 창)

2018 — 2019

THE GREAT SPLIT

Encoder / Decoder

같은 Transformer에서 서로 다른 학습 목표가 갈라진다. BERT는 양방향 문맥으로 가려진 토큰을 복원하고, GPT는 앞선 문맥으로 다음 토큰을 예측한다.

  • BERT · Encoder-only · Masked language modeling
  • GPT · Decoder-only · Causal language modeling
  • BERT의 기본 MLM 목표는 왼쪽부터 생성하는 목표와 다르다. 이해·검색을 위한 encoder의 역할은 계속 남는다.
BERT 리뷰 원문 (새 창)

2018 → 2019 → 2020

ONE TOKEN AT A TIME

GPT-1 → GPT-2 → GPT-3

다음 토큰의 확률분포에서 출력을 선택하고, 그 출력을 다시 문맥에 붙인다. Decoder의 causal mask는 미래 토큰을 보지 못하게 한다.

Autoregressive language-model factorization
  • The → The future → The future of intelligence
  • Pre-training + Fine-tuning → Zero-shot → Few-shot
GPT-1 리뷰 GPT-2 리뷰 원문 (새 창)

2020

SCALE CHANGES CAPABILITY

Parameters · Data · Compute

규모와 학습 자원이 커지며, 텍스트로 준 지시와 예시만으로 과제를 수행하는 능력이 확장된다. In-context learning에서는 문맥이 바뀌지만 모델의 가중치는 갱신하지 않는다.

  • Zero-shot
  • Few-shot
  • In-context learning · No gradient update
원문 (새 창)

ARCHITECTURE → FOUNDATION

A GENERATIVE FOUNDATION

Decoder-only convergence

범용 생성형 LLM의 중심에는 causal language modeling이 자리 잡는다. Encoder를 대체했다는 의미가 아니라, 생성 중심의 기반 위에 새로운 학습과 추론 방법이 쌓인다는 뜻이다.

  • A shared token stream
  • Architecture is the beginning, not the whole system
원문 (새 창)

2022

FOLLOW HUMAN INTENT

InstructGPT / RLHF

그럴듯한 다음 토큰을 예측하는 것과 사용자가 원하는 답을 만드는 것은 다르다. 지도 파인튜닝 이후 사람의 응답 선호로 reward model을 학습하고, PPO로 정책을 조정한다.

  • Pretrained LLM → Supervised fine-tuning
  • Human preference → Reward model → PPO
  • Helpful responses, not only likely continuations
원문 (새 창)

2023 — 2024

DIFFERENT ROUTES TO ALIGNMENT

DPO / GRPO

DPO는 선호 쌍으로 정책을 직접 최적화해 별도의 reward-model 학습을 생략한다. DeepSeekMath의 GRPO는 한 질문의 응답 그룹에서 상대적 advantage를 구하며 별도 value network를 사용하지 않는다.

  • DPO · Chosen / rejected response pairs
  • GRPO · Group-relative rewards
  • 두 방법은 같은 알고리즘이 아니다.
원문 (새 창)

2022

FROM LANGUAGE TO REASONING

Chain-of-thought

답만 출력하는 대신 중간 단계를 생성한 뒤 답에 도달한다. Few-shot CoT와 “Let's think step by step.”을 사용하는 zero-shot CoT는 서로 다른 prompting 설정이다.

  • Problem → Intermediate steps → Answer
  • Generated steps are not a guarantee of correctness
원문 (새 창)

2024

MORE THINKING. MORE COMPUTE.

Test-time compute scaling

학습을 끝낸 뒤에도 추가 추론 자원을 사용할 수 있다. 여러 후보를 탐색·평가하거나 답을 수정하며, 문제의 난도와 평가 방식에 맞춰 계산 예산을 배분한다.

  • Explore → Verify → Select
  • Training compute ≠ Inference compute
  • 더 긴 출력이 언제나 더 정확한 답을 뜻하지는 않는다.
원문 (새 창)

2025

REASONING THROUGH RL

DeepSeek-R1-Zero / DeepSeek-R1

R1-Zero는 사전학습 모델에 먼저 SFT를 하지 않고 GRPO를 적용한다. 정답의 정확성과 출력 형식에 대한 규칙 기반 보상을 사용하며, R1은 cold-start 데이터와 다단계 학습으로 이를 보완한다.

  • R1-Zero · RL without preliminary SFT
  • Outcome / format reward · Not process reward
  • R1 · Cold start + Multi-stage training
원문 (새 창)

MODEL → EXECUTION

INTELLIGENCE IS ALSO A SYSTEMS PROBLEM

LLM systems

같은 모델도 메모리 이동, 캐시 구조, 활성 연산에 따라 실행 비용이 달라진다. 이제 시선을 토큰의 의미에서 GPU 안의 데이터 흐름으로 옮긴다.

  • GPU · Memory hierarchy
  • KV cache · Serving
  • Sparse experts · Conditional compute
원문 (새 창)

2022 — 2024

MOVE LESS DATA

FlashAttention 1 → 2 → 3

FlashAttention은 attention 행렬 전체를 HBM에 저장하는 대신 SRAM에서 tile 단위로 처리하는 IO-aware exact attention이다. 후속 연구는 병렬 작업 분배와 하드웨어 활용을 개선한다.

  • HBM ↔ SRAM · Memory traffic
  • Tiling · Online softmax
  • Less memory movement, same attention computation
원문 (새 창)

2023 — 2024

RETHINK THE CACHE

MHA → GQA → MLA

GQA는 여러 query head가 더 적은 KV head를 공유한다. DeepSeek-V2의 MLA는 key·value 정보를 압축된 latent representation에 저장해 캐시를 줄인다. 서로 다른 설계이며 동등한 성능을 보장하는 변환은 아니다.

  • MHA · Per-head K / V
  • GQA · Shared K / V groups
  • MLA · Compressed latent cache
원문 (새 창)

2017 →

ACTIVATE ONLY WHAT YOU NEED

Sparse mixture of experts

Router가 토큰마다 일부 expert를 선택한다. 전체 파라미터가 늘어도 토큰당 활성 파라미터가 같은 비율로 늘지는 않으며, 통신과 load balancing 비용은 여전히 고려해야 한다.

  • Token → Router → Selected experts
  • More parameters ≠ Proportional active compute
